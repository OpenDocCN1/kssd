# 看雪软件安全文档库

* [在线阅读](https://kssd.flygon.net)

## 下载

### Docker

```
docker pull apachecn0/kssd
docker run -tid -p <port>:80 apachecn0/kssd
# 访问 http://localhost:{port} 查看文档
```

### NPM

```
npm install -g kssd
kssd <port>
# 访问 http://localhost:{port} 查看文档
```
