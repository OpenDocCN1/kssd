Easy Applet Builder 能够帮助你轻松创建 38 种 Java applet，它们能够使你的主页变得更为专业。

这些全部可以定制（字体、颜色等）applet 被分为五个分类：图像（淡入/淡出、星状闪烁、放大/缩小等）、文字（日期、滚动、波浪等）、航行（登录、菜单、链接等）、游戏（`LightOn`、`Puzzle`、`TicTacToe`）、工具（留言本、`IP` 查找器等）。最新版本增加了一个新的 applet，并对帮助和教程进行了增强。
