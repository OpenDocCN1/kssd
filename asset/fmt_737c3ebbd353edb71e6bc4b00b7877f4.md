## DFCGASPROTECT 2.x 脱壳系列(二)

### 目标
`DVD Fab Gold 2.9.3.5`

### 工具
`Olydbg1.1(diy 版)`、`LORDPE`、`ImportREC1.6F`

### 任务
简单的脱壳

### 操作平台
`Windows XP sp2`

### 作者
`LOVEBOOM[DFCG][FCG][US]`

### 相关链接
自己搜索下

### 简要说明
其实这个版本的还是更先脱的，只是整理的时候更后整理出来。看这篇文章之前建议先看我的第一篇文章，否则有些过程可能不好理解。

### 详细过程

到了壳的入口点后直接搜索以下命令:

```

```


找到地址后，在上面的地址处下硬件断点，执行发生中断后取消硬件断点。
