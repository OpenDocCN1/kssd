### 伪代码整理

上面的代码整理为以下伪代码逻辑：

```asm
CMP [441C78],EBX
JNZ @F
PUSH 431BDA
CALL [436454]
POP ECX
@@:
  CALL @C1
```

### 执行流程与进一步分析

运行再次中断到 `jmp [esp-4]` 处后，`f8` 一次到这里:

```asm
00431BDE  - FF25 B0644300     JMP DWORD PTR DS:[4364B0] ; msvcrt._controlfp  
```

到原程序代码处后，再 `F8` 进了 API 中，进入后 `ALT+F9` 再次返回到壳中:

```asm
00F80475    59                POP ECX                 ; ☆☆☆☆☆  
00F80476    E9 04040000       JMP 00F8087F  
……  
00F8087F    59                POP ECX                 ; ☆☆☆☆☆  
00F80880    C3                RETN                    ; ☆☆☆☆☆  
00F80881  ^ E9 90FFFFFF       JMP 00F80816  
```

所以 `@c1` 的代码就是:

```asm
  PUSH 30000  
  PUSH 10000  
  CALL 431BDE  
  POP ECX  
  POP ECX  
  RETN  
```
