## 【算法总结】

有两种注册算法，分别使用了 3 次标准 MD5 运算

\--------------------------------------------------------------

## 【算法注册机】

VB 代码

```vb
Private Sub Command1_Click()
    If Len(Text1.Text) = 0 Then
        Text2.Text = "请输入用户名!"
    Else
        Text2.Text = Mid((MD5(MD5(UCase(Text1.Text)) & "125" & MD5("125"))), 7, 10)  'MD5 模块，"125"也可以是"135"
    End If
End Sub
```
