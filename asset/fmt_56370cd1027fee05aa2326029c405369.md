从上面我们可以得到两个重要信息 `4BB138`, `8E802A`

1. 先到 `8E802A`

   我们可以发现一直从 `8E8010` 到 `8E8BE4` 都是 `0xD` 字节的 `XOr` 解密程序

   `(8E8BE4 - 8E8010 + 1) / 0XD = 0XE9 = 233` 个函数

2. 再到 `4BB138`

   这应该是 Thunk 值表的位置，将 Dump 窗口转到这里, `BB000` 开始, size `54F`

   发现其中 `4BB130` 到 `4BB4E3` 都指向 `008E8XXX` 段, 中间有 4 个不是

   `(4BB4E3 - 4BB130 + 1) / 4 - 4 = 0xE9 = 233`

在 `49BF36` 临时加一段程序修复, 修复后不再需要 `XOR` 解密段了(`8E8010-8E8BE4`)

```
          pusha

          mov esi,4BB130

          mov edi,esi

Next:     lodsd

          cmp eax,8E8010

          jb OK

          cmp eax,8E8BE4

          ja OK

          mov edx,eax

          mov eax,[edx+1]      ;[edx+1]指向 push 的数据

          xor eax,[edx+8]      ;[edx+8]处是原来 xor 的数据

OK:        stosd

          cmp esi,4BB4E4

          jb Next

          popa
```
