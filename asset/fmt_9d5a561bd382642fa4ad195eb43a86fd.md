由可以知道程序的 `OEP` 是在 `401000`，至于为什么是在这里，让自己跟踪理解。

```
005A6191   >- FF25 00605A00 JMP NEAR DWORD PTR DS:\[5A6000\]       ;  skw.00401000
```

patch `FF25` 为 `CC25`，目的是让程序运行到此处时出现 `int 3` 异常,并让调试进程接管。
