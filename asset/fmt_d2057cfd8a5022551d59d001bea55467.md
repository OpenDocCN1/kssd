
# winhotkey V1.0 破解方法

> 原文：[`www.pediy.com/kssd/pediy12/141662.html`](https://www.pediy.com/kssd/pediy12/141662.html)

`winhotkey` 是个很不错的快捷键程序，适合喜欢快捷简约风格的人使用。

从 `Ollydbg` 中找到了软件在注册表中写入的安装日期。把此日期删除后，设置此项进制写入和读取，这个软件就没有时间限制了。

注册表中的这个项是 `HKEY_LOCAL_MACHINE\SOFTWARE\Classes\CLSID\{7292FB08-129E-483C-8803-C39A80A66F43}` 下的 `date`，当注册成功后，`name` 和 `key` 都会写到这下面。

破解了好几天了，没弄成功。开始时编写程序删除这个项，因为我自己编写的程序每天都运行，常驻后台（还有其他功能），后来干脆限制这个项不可读写，这下搞定了。
