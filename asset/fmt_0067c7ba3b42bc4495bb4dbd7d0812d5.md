## 中断选择

基本不说了！就是谈论一下究竟下什么中断较了好？

许多（我的朋友也内）`bpx hmemcpy`，确定也能中断就是比较麻烦！

我就先用`bpx getwindowtexta`（不行），好就用一个能拦多数特殊软件的`bpx getdlgitemtexta`! 这当然好用了，多数用拦灰色菜单的软件还记得我破解的`winamp`吗？（你没有听过，如果想看一看就下载看雪论坛 2！我的破解入门篇）

这里最好用较简单的数好，我就用了`12121212`！会有人问为什么不用大哥哥的`78787878`了？你试一试就知道，好了如果用这个就要等很久才会出现或不出现错误对话框，也就是很难拦阻！

## 工具与步骤

这久很多我过程没有介绍用什么工具？

是`trw2000`!

1. 输入`12121212`
2. `ctrl+n`
3. `bpx getdlgiemtexta`
4. 按`F10` 44 次来到这里：

......

```

016F:04CC6338  LEA       ECX,[ESP+0518]
016F:04CC633F  PUSH      EAX
```

其实来到这里就`game over`!:

为什么？

```
016F:04CC635C  LEA       EAX,[ESP+B0]
```

光标来到这里就会出现:`ss:[7191c0]=32313231`

一般是`d 32313231`，现在不灵了！

请看一下寄存器窗口中的：

`esp=007191c0`

`d esp`

就出现你用的`e-mail`。我的就是`peter@163.net`

再`d 7191c0`

就是`12121212`

它是由`32313231`组成出来的！

`ss`就是浮标寄存器，要用`softice`也许才能看到`32313231`。为什么是注册码？请各大客如果愿意用`softice`来看，发现如果有错就指出来谢谢！

```
016F:04CC6363  PUSH      EDX
016F:04CC6364  PUSH      EAX
016F:04CC6365  CALL      `DFXG11!?dfxpEnterSerialNumber@@YAHPAD0PAH10101@Z`
```

(这里也是做注册机要找地方）

如果有错也欢迎指出来！
