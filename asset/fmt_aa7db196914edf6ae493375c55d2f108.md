```c
#include "ntddk.h"

ULONG d_origKiFastCallEntry; // Original value of ntoskrnl!KiFastCallEntry

VOID OnUnload(IN PDRIVER_OBJECT DriverObject)
{
    __asm
    {
        mov ecx, 0x176
        xor edx,edx
        mov eax, d_origKiFastCallEntry     // Hook function address
        wrmsr                       // Write to the IA32_SYSENTER_EIP register
    }
}

// Hook function
__declspec(naked) MyKiFastCallEntry()
{
    __asm
    {
        jmp [d_origKiFastCallEntry]
    }
}

NTSTATUS DriverEntry(IN PDRIVER_OBJECT theDriverObject, IN PUNICODE_STRING theRegistryPath)
{
    theDriverObject->DriverUnload = OnUnload;
    __asm
    {
        mov ecx, 0x176  //SYSENTER_EIP_MSR
        rdmsr                 // read the value of the IA32_SYSENTER_EIP register
        mov d_origKiFastCallEntry, eax
        mov eax, MyKiFastCallEntry    // Hook function address
        wrmsr                       // Write to the IA32_SYSENTER_EIP register
    }
    return STATUS_SUCCESS;
}
```

`Hook` 的核心思路是修改 `MSR`，具体修改 `SYSENTER_EIP_MSR`（`176`）所指向的 `KiFastCallEntry` 地址。

### 用户空间进程

*   **会话管理器进程 `SMSS.exe`**：系统中第一个根据映像文件创建的进程，负责加载和初始化 `win32` 子系统的内核模块 `Win32.sys`，创建 `win32` 子系统服务器进程 `CSRSS.exe` 以及登录进程 `WinLogon.exe`。
*   **`Windows` 子系统服务器进程 `CSRSS.exe`**：负责维护 `Windows` 子系统的日常事务，为子系统中的各个进程提供服务。
*   **登录进程 `WinLogon.exe`**：负责用户登录和安全相关事务。启动后创建 `LSASS` 进程和系统服务管理进程 `Services.exe`。`XP` 的文件保护功能（`WFP`）也在此进程中实现（涉及 `sfc.dll` 和 `sfc_os.dll`）。
*   **本地安全和认证进程 `LSASS.exe`**：负责用户身份验证。全称 Local Security Authority Subsystem Service。
*   **服务管理进程 `Services.exe`**：负责启动和管理系统服务程序，如 `Spoolsv.exe`（打印机脱机服务）、`WmiPrvSE.exe`（`WMI` 提供器管理服务）等；`SvcHost.exe` 是一个通用的服务宿主程序。
*   **`OS/2` 子系统和 `POSIX` 子系统服务进程**：用于在 `Windows` 系统中运行 `OS/2` 和符合 `POSIX` 标准的程序。
*   **壳程序（Shell）**：默认为 `Explorer.exe`，负责显示开始菜单、任务栏和桌面图标等。

### 调试信息的发送时机

*   在进程创建时，如果没有其他线程存在，则发送进程创建通知；否则发送线程创建通知。在线程结束时，如果进程内剩余线程数不为 `0`，则发送线程退出通知；否则发送进程退出通知。
*   在调用 `LoadDll` 时，涉及 `NtMap` 和 `NtUnmap` 操作均会发送给调试子系统，以判断是否有必要发送调试事件。
*   其他异常事件都会判断是否需要发送调试信息。在需要发送时，系统会挂起进程（除了被调试的线程本身），待调试器处理完毕返回后，再恢复进程。

`_KTHREAD` 结构体中，`FreezeCount` 和 `SuspendCount` 成员表示当前挂起和冻结的线程数量：
