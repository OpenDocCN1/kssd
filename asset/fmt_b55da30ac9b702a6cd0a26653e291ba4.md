
# 【破解总结】

## 【算法总结】

1. 注册码算法与用户名无关
2. 注册码长度必须为 `9` 位
3. 注册码第 `1` 位与第 `4` 位之和大于 `8`
4. 注册码第 `1`、`3`、`4` 位之和取 `10` 的余数必须与第 `6` 位相等
5. 注册码第 `2` 位必须大于 `5`
6. 注册码第 `5` 位必须小于 `3`
