# 算法注册机

## 易语言代码

```
.版本 2

.支持库 dp1

.局部变量 MD5_1, 文本型
.局部变量 MD5_2, 文本型

.判断开始 (编辑框 1.内容 ＝ "")
    编辑框 2.内容 ＝ “输入有误，请重新输入。”
.默认
    MD5_1 ＝ 到大写 (取数据摘要 (到字节集 (编辑框 1.内容)))
    MD5_2 ＝ 到大写 (取数据摘要 (到字节集 (取文本中间 (MD5_1, 17, 11))))
    编辑框 2.内容 ＝ “LdfFla-” ＋ 取文本中间 (MD5_1, 13, 2) ＋ 取文本中间 (MD5_2, 20, 3)
.判断结束
```
