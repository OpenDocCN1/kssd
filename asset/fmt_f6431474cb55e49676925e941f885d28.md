注:上面这个循环是将用户名不到 32 位的补齐到 32 位,以用户名为`caoxinyu`为例计算如下:

第一次循环:

```
      0x75/0x8=0xE

      0x75*0x8=0xA8 因用 al 寄存器计算,故 0x3A8-->0xA8

      0xE+0xA8=0xB6

    将计算所得的 0xB6 接到用户名 caoxinyu 的后面,变为:63616F78696E7975B6
```

第二次循环:

```
      0xB6/0x9=0x14

      0xB6*0x9=0x66

      0x14+0x66=0x7A

    将计算所得的 0x7A 再接到用户名的后面,变为:63616F78696E7975B67A
```

如此经过 32-8 次循环,补齐到 32 位的用户名为:

```
    63616F78696E7975B67AD0021839220000000000000000000000000000000000
```
