## 关于寄存器操作的疑惑

理论上，如下三句必须去掉，否则会影响栈平衡：

```
POP EDI     //编译生成 debug 版本的程序则需要把这
POP ESI     //三个注释去掉
POP EBX
```

可是，真的去掉，有极其容易使被注入的 `IE` 出现异常，而退出。

问题的关键，我猜测是挂钩函数 `HookSend`，破坏了寄存器，只要保存好寄存器的值，应该可以解决。
