### 破解思路

从上面可以看出。

将：

```
004CB0BD 741F               JZ        004CB0DE
```

改为：

```
004CB0BD 751F               JNZ       004CB0DE
```

就可以注册。

整理一下，用 `Ultraedt` 打开 `xf.exe`。

找到：

```
74 1F E8 C4 92
```

```
75 1F E8 C4 92
```
