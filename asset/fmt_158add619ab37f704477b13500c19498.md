## 算法总结

1. 注册码必须是 16 位长！不能包含任何非数字字符！
2. 我们帮注册码按顺序写成 `X1,X2,X3,X4,X5,X6,X7,X8,X9,X10,X11,X12,X13,X14,X15,X16`
3. 那么就要满足这样的条件：
   - `22 = X1 + X2 + X3 + X4`
   - `30 = X5 + X8 + X11 + X14`
   - `8 = X7 + X10 + X13 + X16`
