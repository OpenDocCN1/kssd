### 注册机代码

**VB6.0 版本**（在盗版 XPsp2、VB6.0 下编译测试通过）

```vb
Private Sub Text1_Change()
    Dim MacID, SN As Long
    Const X = 20071

    MacID = Text1.Text

    If Len(MacID) <= 0 Then
    Else
        SN = Left(Left(MacID, 4) * X, 8)
    End If

    Text2.Text = SN

End Sub
```

1. 取机器码前 4 位作为运算码（带符号）
