
# PC Security 5.1

> 原文：`[www.pediy.com/kssd/pediy04/kanxue350.htm](https://www.pediy.com/kssd/pediy04/kanxue350.htm)`

## 破解目标
`PC Security 5.1`

## 下载地址
`http://nj.onlinedown.net/PCSECURITY.HTM`

## 软件简介
这个存取控制软件功能非常强大，它除了可以让你关闭我的电脑、控制台、显示器设定、启动、拨号网路、桌面捷径、工作列等以及隐藏桌面图标和 Windows 工作列的功能外，还可锁住硬盘中任何目录下的文件。而且它还附有一个 `Lock System`，和屏幕保护程序一样在电脑闲置一段时间后会自动启动防护（亦可手动启动）。

## 破解原因
我的手提电脑（又破又旧）经常要带到上班的地方使用，有时我要临时离开，不希望有人乱碰我的电脑。`PC Security 5.1` 容量虽小，功能却很强大，它可以定时锁定电脑，可以保护任何文件和文件夾，还有其它大量的保护。

## 使用工具
`Trw2000 1.23` & `W32dasm`

## 破解过程
安装运行 `PC Security 5.1`，安装完后双击系统托盘的小红锁图标，进入它的 `Setting` 窗口，程序提示只能试用 30 天并要求注册，随便乱填，按注册，程序报错自动退出。好了，用 `W32dasm` 反汇编 `Security.exe` 找出错的字串，可是找不到，呵呵~~~~~~看来要动态的啦~~~~~

再次进入，填入 `Sam Von`, `67676767`, `bpx hmemcpy`，按注册，`Trw` 拦下来了。然后用 `F12` 找到出错的 `Call` 再慢慢找注册的判断，请看下面的代码
