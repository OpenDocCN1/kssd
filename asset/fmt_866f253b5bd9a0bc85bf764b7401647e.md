今天我想跟大家讨论一个问题, 有兴趣的朋友, 欢迎分享

现在是 2010 年的夏季了, 是 "未来时代"

我们都是对软件安全充满热诚的人, 大家在使用调试器奋斗的日子都不短了。大家在学习的道路上, 都有机会接触到这些课题：

1. 关于软件的保护, 例如壳, 或自身保护, 甚至 vm
2. windows 系统内核, 驱动保护, rootkit 技术
3. 密码学, 算法 …
4. windows 病毒, 系统漏洞攻击, 夺取系统权力的技巧
5. 写作系统工具, 监视工具

( 因为我们不是弄 linux 的, 所以上面强调是 windows )

这些是我们的 "领域"

从 windows 2000 直至 windows xp, 发展迅速, 调试工具 OD, IDA 成熟, 令这个领域十分成熟, 充满了生命力

但是, 在 2010 年, 有一些东西转变了.

1. 很多软件都是 GPL 开源的, 源码给大家看, 像 firefox
2. 大家都依然用 windows 的, 但很多人的 windows 只是用来上网, 浏览网页, 我们启动 windows 就是为了开动 Browser,
我们的快乐都在网上, 我们生活在 Browser 里 (youtube, facebook, 土豆, twitter, 新闻网)
3. 我们会玩游戏, 但很多人已经转移到 X Box, PS3, PSP, NDS, 甚至是 : iphone
4. Windows 坏了, 我们便重灌, 只要数据没有事, 有备份好, windows 中毒便重灌了
5. 我们真正使用 windows 的工作, 大概是 : Photoshop, AutoCAD, BT, 玩游戏, 和商业会计软件, 简单来说 : 一些需要大量 CPU 和 ram 的事情
6. 吸引开发人员赚钱的工作, 都跑到 mobile 平台上

总结上面的事情, 我的感觉是 : 渐渐大家都不理会家中的 windows 了

我们把 I.T. 科技视为一种不断发展的产业, 但是现在来到了 "收音机" 的旅程了, 像 "收音机" 发展的最终结局, 大家都认为这个东西已经很成熟了,

也习惯它了, radio 收很好了, 不需要花钱改良了, 成本也不高了, 更不是甚么先进科技了, 大家都认为它的发展, 已经到达终结

收音机, 它的发展任务已经完成

Windows, 也将会走过这条路, 不管现在是 windows 7 或是 Mac OS leopard, 甚至 Ubuntu, 大家真的在乎吗 ?

那一个功能, 是独特地出现在某一个 OS 平台上 ?

我们注意到甚么 ?

当 Mac 机转用了 Intel CPU, 跟 PowerPC 说再见

当 Intel 发展到 4 核心, 并且不再把频率速度 mark 在产品名称上的时候,

当我们看到 ARM 低功耗 CPU 在市场上引起极大关注的时候,

当我们看到 netbook 平价私人计算机在市场成功冒起, 渐渐取代 notebook 成为行政人员计算机的时候

当行政人员使用 black berry 和 iphone 和写电邮,

当大家谈论 Google Chome OS

这一切, 都在说明我们使用的平台, 正在一步一步地转变了

软件, 将来会变得不一样, 我们不能用 softice 或 OD 去打开它

软件工业, 将来或许会成为一个已发展行业 : 应该存在的软件, 都已经开发出来了, 大家不需要再写甚么软件, 应该有的, 都已经有了,

甚至它可能不用付钱 (开源的, 或是云瑞应用, 在 web 上免费执行)

软件安全, 或许会变成了关注网络软件的 web 安全问题, 例如 XSS 的问题, 或是 firmware 的问题

我们这一代人, 经历了 I.T. 故事的第一集 (1990 年 至 2010 年)

我们的角色是 : 软件世界的魔法师, 巫士

现在, 我们即将经历故事的第二集

你的角色, 将会是甚么 ?
