上面的变换看似复杂，实际上可以简化为一个循环，其逆运算就是把各个 bit 调换回去，如下：

```
int a = 0x0B26;     //变换后的
int b = 0;          //变换前的
int index[] = {15,11,7,3,14,10,6,2,13,9,5,1,12,8,4,0};

for(int k = 0; k < 16; k++)
{
    b <<= 1;
    b |=  (a >> index[k]) & 1;
}
```

这样就可以写出`keymaker`来，一个注册码是`01-0184-4056-8888`。注意`VerifySN()`函数实际上应该返回`0x0B`，这点在安装时不判断，但是其主程序在运行时会判断，若不等于`0x0B`则无法运行，主要是因为它用这个返回值来区分该公司的不同软件。
