### 算法总结

通过上述循环，可以得到对应注册名的注册码的第一部分“`7125506504722`”。

算法逻辑可总结如下：

- 注册名长度为 `L`
- `N(I)` 为注册名第 `I` 位字符
- `M(I)` 为预设字串“`seamoon`”第 `I` 位字符
- 循环次数为 `X`

则注册码第 `(X-I+1)` 位为：

```
((N(I) + M(I) + X + I - 1) % 9) + 30
```

以填入的注册名第 1 位“`l`”为例，注册码第 `(0D-1+1)` 位为：

```
(6C + 73 + 0D + 1 - 1) % 9 + 30 = 32，即“2”
```

所以倒数第一位注册码为 `2`。

00407335  |. 80C2 30           ADD DL,30                        // `dl`+30，这是注册码的最后一位
