下面这段代码的作用是把上面生成的字符串中的：
`A` 替换成 `M`、`1` -> `O` (`4F`)、`2` -> `3`、`r` -> `7`、`4` -> `J`、`5` -> `6`、`8` -> `D`、`0` (`30H`) -> `M`、`E` -> `D`
所以：`CDA0AD69ABA584B16970766D` -> `CDMMMD69MBM6DJBO697M766D`
