### `VCALL` 命令

| 命令 | `VCALL` |
| :--- | :--- |
| 作用 | 显示 `VxD` 调用 |
| 用法 | `Vcall *` - 显示所有的 `VxD` 调用<br>`Vcall num` - 如果指定的 `num` < `10000h`，显示所有的 `VxD` 调用；如果指定的 `num` > `10000h`，则显示所指定的 `VxD` 调用<br>例：<br>`Vcall partial-name`<br>`Vcall 0d`<br>`Vcall 100001`<br>`Vcall *sys*` |

![](img/93ee8f4c6034afd7fa4624e57bd959ec.jpg)

### `VM` 命令

| 命令 | `VM [VMID]` |
| :--- | :--- |
| 作用 | 显示虚拟机的信息。 |
| 用法 | 如果 `VM` 命令不加参数，将显示系统中所有虚拟机的信息。如果加 `VMID` 参数，该 `VM` 的寄存器值将被显示。<br>这里的寄存器值是在 `VM` 控制块用户区中的寄存器值。所以，这些寄存器表示的是最后当有内存地址切换时存入该控制块时的值。<br>当 `TRW2000` 弹出时正好某个 `VM` 正在运行的话，在寄存器窗口中的值才是真正当前的值，而不是用 `VM` 命令在命令窗口中看到的值。<br>有一点要注意:如果你在某个中断例程中的头几句指令处，而此时这个 `VM` 的寄存器值正在被存入控制块，那么可能当前只有 `CS:IP` 的值(由 `VM` 显示)是真的。其余的有可能还没有存入控制块。 |

![](img/93ee8f4c6034afd7fa4624e57bd959ec.jpg)

### `VXD` 命令

| 命令 | `VXD [VXDNAME]` |

| 用法 | 无参数 |

### 条件断点语法

| 类别 | 条件断点语法 |
| :--- | :--- |
| 说明 | 几乎所有的断点都可以通过如下的语法：<br>`BP?? <parameters> \IF ([conditions)\] \DO "[statement"\]`<br>而且开始的 2 个字母 `'BP'` 可以代换成 `'GO'`，即:<br>`GO?? <parameters> \IF ([conditions)\] \DO "[statement"\]`<br>来设置条件断点。 `TRW2000` 能够根据要求设置、使用和清除这些断点。 |

![](img/93ee8f4c6034afd7fa4624e57bd959ec.jpg)

### 条件 (Conditions)

| 类别 | 条件语法 |
| :--- | :--- |
| 说明 | 条件必须用闭括符括起来。 |

支持的运算符及其含义：

```text
Operator Meaning
== Logical Equal
!= Logical Not equal
> Logical Greater than
>= Logical Greater than or equal to
< Logical Less than
<= Logical Less than or equal to
& Bit and
| Bit or
^ Bit xor
>> Bit shift right
<< Bit shift left
;not support
! Logical NOT
&& Logical AND
|| Logical OR
+ add
- sub
* mul
/ division
% mod
() parenthesis
(byte)
(word)
(dword)
* get value from point
+ positive
- negative
```

示例：

```text
g if ((byte)*eip==c2)
g if (*esp==ebx)
go if (eip>401000&&eip<10000000)
```

注意：未注册版本，条件表达式长度有限制。

### 执行语句 (Do Statement)

| 类别 | 执行语句语法 |
| :--- | :--- |
| 说明 | `<statement>` 可以是任何有效的 `TRW2000` 的命令，但必须用双引号 `""` 引起来。 |

示例：

```text
BPX cs:401000 if (eax>200) do "d eax"
GOX 401000 if (cs!=28) do "d ss:esp"
G if (eip<1000)
```
