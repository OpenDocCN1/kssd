# Analysis

分析如下：

a. 多数跳转目标为 `0041DE7B`。跳转后执行 `retn` 返回，标记为未注册状态。

b. 其余跳转均为内部循环，唯一例外为：

```
0041DE6B JGE SHORT flashget.0041DE90
```

跳转至 `0041DE90` 后执行返回，确认为注册成功路径。

子程序逻辑分段：

- `0041DC80` - `0041DDD8`：初始判断
- `0041DDDA` - `0041DE6D`：进阶判断
- `0041DE7B` - `0041DE8F`：注册码错误返回
- `0041DE90` - `0041DEC5`：注册码正确返回

策略：将起始处跳转至 `0041DE90`。

# Modification

在 `0041DD27` 将 `JE 0041DE7B` 修改为 `jmp 0041DE90`。

使用 `odbg` 修改后，记录二进制为 `E96401000090`。

# Notes

`fg1.65` 及早期版本无法从寄存器直接提取注册码，而是通过循环计算验证。

本修改仅修补文件，未破解注册码算法。

历史使用算号器会因定期在线验证复现广告。`lucian` 指出 `fg` 需联网验证，故文件修改更稳妥。

# Appendix

在 `004128EB` 附近发现：子程序在注册码错误时令 `EAX` 为 `0`；正确时（经上述 5 步）令 `EAX` 为 `1`。

```
004128f2 MOV DWORD PTR SS:[EBP+284],EAX
```

只要 `DWORD PTR SS:[EBP+284]`（`0053bb74`）非 `0` 即可去除广告。

替代方案：

1. 将 `MOV DWORD PTR SS:[EBP+284],EAX` 改为 `MOV DWORD PTR SS:[EBP+284],ECX`
2. 将 `004128EB CALL 0041DC80` 改为 `nop` 或 `CALL 00425790`（`mov eax,1`）
