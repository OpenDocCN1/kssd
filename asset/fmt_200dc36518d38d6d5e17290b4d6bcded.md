这个软件的注册很特别,我破解的方法也很特别, 所以说解软件,一定不能轻易放弃,要从不同的地方入手,多想想办法一定会有收获的! 

首先是固定的前三位：`Ee@`   

然后是固定的后四位：`%(b)`   

中间部分这样算：   

假设你的 ID 是： `123456789A`   

那你就这样排： `8 5 1 A 3 7`   

应该是这样的。   

可以用 C 写个注册机的。

```c
main()   
{ char serials[11], register_code[14];   

  printf("chm 帮助编辑器 v2.6 注册机\n\n");   

  printf("软件序号：");   

  gets(serials);   

  register_code[0]='E';   

  register_code[1]='e';   

  register_code[2]='@';   

  register_code[3]=serials[7];   

  register_code[4]=serials[4];   

  register_code[5]=serials[0];   

  register_code[6]=serials[9];   

  register_code[7]=serials[2];   

  register_code[8]=serials[6];   

  register_code[9]='%';   

  register_code[10]='(';   

  register_code[11]='*';   

  register_code[12]=')';   

  register_code[13]='\0';   

  printf("注 册 码：%s",register_code);   

}
```
