# Rootkit Detection

The detection method is based on comparing MBR sectors. User-mode code uses the Windows API to read a fake MBR content:

```c
hFile = CreateFile( "\\\\.\\PHYSICALDRIVE0", GENERIC_READ, ...
ReadFile( hFile, Buffer, 512, ...
```

The kernel part of the scanner can read the real MBR content using the raw pointer of the `\\Driver\\Disk` device with `MajorFunction[IRP_MJ_READ]=CLASSPNP!ClassReadWrite`.

If the two MBR contents are different, the machine is infected.

# Removal

An infected machine can be cleaned by using the `fixmbr` command in the "Recovery Console" mode.
