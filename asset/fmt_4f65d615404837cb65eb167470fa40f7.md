
# DesktopX v1.0

> 原文：[`www.pediy.com/kssd/pediy05/pediy50527.htm`](https://www.pediy.com/kssd/pediy05/pediy50527.htm)

目标软件：`DesktopX v1.0`

下载地址：[`qiuyong.x168.net/image/talismandesktop/desktopx_1.0.htm`](http://qiuyong.x168.net/image/talismandesktop/desktopx_1.0.htm)

软件简介：`DesktopX` 是一套革命性的桌面设置工具，用户可以往桌面上添加物件，它以物件的方式可完全的自定桌面，包括一切如：`我的电脑`、`运行`、`开关机`、`垃圾箱`、`打开程序`或`文件夹`等。通过这些物件的使用，用户可以创造一个非常活泼的独特的桌面。父母可以为孩子创建一个非常可爱活泼的适于孩子学习的桌面环境。

使用工具：`TRW2000`，`FengMa's Toy Beta1`
