## Switch 语句分析

再看下面代码：

```c
#include "stdio.h"

int  boxer()
{
  printf("please input a number: ");
  int a;
  scanf("%d",&a);
  switch(a)
  {
  case 0:
    {
    printf("c=0");
    }
  case 1:
    {
    printf("c=1");
    break;
    }
  case 100:
    {
    printf("a=100");
    }

  default:
    {
    printf("default");
    }
  }

  return 0;
}

void  main()
{
  boxer();
}
```

反汇编看看。。。由于只是改了判断语句，所以我们只看改的部分
