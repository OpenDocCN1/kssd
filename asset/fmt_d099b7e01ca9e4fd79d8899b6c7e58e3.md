### 逻辑描述

这个 `call_1` 比较简单。就是一个简单变换，它生成的是一个同机器码相同长度的序列。记为 `machine ---> machine_e`：

大致过程：

```c
for (i=0; i<strlen((char*)machine); ++i)
{
    machine_e[i] = machine[i] ^ ((WORD)key >> 8);
    key += (BYTE)machine_e[i];
    key = (WORD)((WORD)(key * 0xCE09) + 0x585B);
}
```
