## 一、来到 OEP

`arm` 加壳查找 `OEP` 比较简单：

`alt+m` 打开内存窗口

在 `401000` 下内存断点

`F9` 运行后，会出现如下的异常

```
0184FDCB  PREFIX LOCK:                 ; Superfluous prefix  ==>异常
0184FDCC  ???                          ; Unknown command
0184FDCE  ENTER 3360,0C9
```

## 二、查找 IAT

继续上一步，先不要动 `OD`，打开 `ucfir16f` 程序，在 `OEP` 处输入：`00747128-400000=347128`

通过 `ImportREC` 会得到 `IAT` 的 `RAV`：`0036BFFC`，大小：`000008E0`，让 `ImportREC` 查找会得到很多无效的指针

`IAT` 的位置是：`0036BFFC+400000=76BFFC`

在 `OD` 的命令行处输入 `d 76BFFC` 会看到 `IAT` 表，如下

```
0076BFFC  00 00 00 00 0C 16 E4 77   .....鋡
0076C004  7B 96 3C 00 7E 17 E4 77   {?.~鋡
0076C00C  BC 1B E4 77 EA 1B E4 77   ?鋡?鋡
0076C014  1E A7 3C 00 E3 A4 E4 77   ?.悚鋡
0076C01C  79 BA E4 77 4E DB E4 77   y 轰 wN 垆 w
```
