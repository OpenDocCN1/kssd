## 将代码注入到节中的方法

将代码添加到节里的方法可以突破对齐的限制。我们只需要将代码分段注入到其它的几个节里就行了。所以只要 文件的对齐长度 - 实际长度 > 病毒长度 就可以了。另外，有的病毒还可以将代码注入到几个系统文件中。比如 “莫国防”病毒 (`win32.mgf`) 就是把自己的前 `3kb` 放到了 `kernel32.dll` 的节空隙，后 `2kb` 放到了 `user32.dll` 的节空隙中。

### 优势

把节添加到代码空隙中的好处是可以避免杀毒程序的一种叫“长度检查”的杀毒方法。因为这样添加的病毒代码不会改变文件的长度。

当然，在这里为了简单，我们是直接添加的一个节。

## 代码自身重定位

**问：** C 码是指 C 写的代码吗？C 不能够实现代码自身的首地址的定向，而汇编可以通过在代码开头：

```
call @f
@@:
pop ebx
sub ebx, offset @b
```

来实现自身的重定位。

## 设置节的属性

关于节的段是属性的问题，我们通过以下方式：

```
or dword ptr [esi+24h], 0a0000020h   ; 该节属性定为可执行代码(esi 指向的是 SECTION_HEADER)
```

在保持原先的属性不变的情况下，加上可执行的属性。这样我们的代码就能够运行了，而又不会影响宿主程序本身的执行。

## 加壳程序的实现

加壳程序也是通过类似的方式将外壳代码放到要加壳的程序里的。不过，为了 `ANTI-DEBUGGER`，在跳回 `OEP` 之前做了许多保护措施和陷阱。
