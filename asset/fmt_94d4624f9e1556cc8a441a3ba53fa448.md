#### WHAT THE ROCK SAYS

Andy is a Windows Rename utility especially designed for managing picture and music files.

Features:
* Rename Files or Folders in a Single Click
* Rename Files or Folders using Sequential Numbering or Lettering
* Create New Names based on the Original Name
* Change the Case of File or Folder Names
* Word List support and user template for Change Case
* Set the File Date and Time
* Set the File or Folder Attributes
* Move, Copy and Delete Files or Folders
* Rename Files and Folders with Search and Replace
* Arrange Pictures for numbering via Thumbnail Images
* Full size Picture Viewer linked to the Rename List
* Edit MP3 Tags
* Subfolder Support for most Actions
* MS Office Style Toolbars
* Drag and Drop Support
* Favorites List
* Template support for saving and reusing New Names
* Plus much More!

**!!WARNING!!**
Andy does exactly what you tell it. If you rename, delete or move system or software files... your computer may stop functioning.
