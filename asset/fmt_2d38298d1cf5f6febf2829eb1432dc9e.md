### 2. Hold On! Just a Minute...

To bypass the check of the number of tries. There are 3 chances for solving this crackme; it's not enough.

In the code:

```
XXXX:004022A0  MOV  AX,[0040A074]              ; numbers of tests already done
XXXX:004022A6  INC  AX
```
