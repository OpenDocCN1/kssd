### 结论

#### 1、注册码需要满足的条件有 3 个

```c
x % V3[i] == 0;
((x / V3[i] ) ^ 234fdf ) % 0fffa == V2 
((((x / V3[i] ) ^ 234fdf ) / 0fffa ) ^ 1F8a ) & 0xFF ==V1
```

做注册机时可以先求出 `(x / V3[i] ) ^ 234fdf );`，然后求出 `x`：

```c
SN = x * 256 + (0xFF - (sum(x 的各个字节) % 0xFF)    
char* g_dir = "3456789ABCDEFGHJKLMNPQRSTUVWXY";
while(SN > 0)
{
  printf("%c", g_dir[SN % 30]);
  SN /= 30;
}
printf("%c", '\n');
```

结果即为一个有效的序列号
