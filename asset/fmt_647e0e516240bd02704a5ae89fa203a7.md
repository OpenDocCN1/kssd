于是，我先建一个假的注册表值，导入

`HKEY_LOCAL_MACHINE\SOFTWARE\HappyClock\License`

其中有两个字符串值：`name` 和 `Keygen`

`name=Y2VHK5TE`

`keygen=123456`

如下：

`Windows Registry Editor Version 5.00`

```
[HKEY_LOCAL_MACHINE\SOFTWARE\HappyClock]

[HKEY_LOCAL_MACHINE\SOFTWARE\HappyClock\License]
"name"="Y2VHK5TE"
"keygen"="123456"
```
