## 工具说明

语言：`JavaScript`

web 开发中，`xml` 现在使用的越来越多，良好的书写格式应该是程序员的基本要求，有了这个格式调整工具，应该是所有 web 程序员值得庆幸的事！

## 使用说明

该工具是以一个 `EmEditor` 插件形式提供的，将代码另存为 `xmlHTMLIndent.jsee`，然后在 `EmEditor` 中添加自定义宏来使用。你也可以将这段 `JS` 用在 Web 项目中的 在线编辑 功能中。
