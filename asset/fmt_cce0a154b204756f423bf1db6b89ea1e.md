## 关键位置定位与分析

调用注册框、过期提示的位置找到了，那么我们接下来就需要找控制这个位置的跳转了。使用 `Ctrl + F2` 直接在 `0106009F` 处中断，此时注册框还未出现，说明确实在注册框显示前中断下来了。接下来单步执行，寻找关键跳转：

```
010600F9     8BD8               mov ebx,eax                ; 给 eax 清 0
010600FB     85DB               test ebx,ebx
010600FD     0F84 92000000      je 01060195                ; 让他跳
```

将 `eax` 清 `0` 之后，按 `F9` 运行。程序界面正常显示，且没有注册框。

**注意**：上述方法只需给 `eax` 清 `0`，不需要改动代码。如果通过修改代码使 `eax` 为 `0`，之后必须将代码改回去，否则程序会异常。

## 脱壳方案

接下来你有 `2` 种选择：

### 1. 手动脱壳

由于手动脱壳的教程较多，这里仅提供步骤指引：

1. 从上述过程中找到 `010600F9` 是关键位置，在此处下硬件执行断点。
2. 设置 `OD` (OllyDbg) 忽略除 `INT3`、指定异常外的所有异常。
3. 按 `F9`，在 `INT3` 中断处停下，查找 `#85` 特征，按照常规方法处理 `IAT`。
4. `IAT` 处理完毕后，由于硬件断点存在，按 `F9` 会再次中断在 `010600F9`，此时 `eax` 被清 `0`。
5. 删除硬件执行断点，按照常规方法补代码修复变形 `Call`。
6. 收工。（注意：前 `4` 个步骤中 `010600F9` 处的硬件执行断点始终存在）

手动脱 `ASProtect` 是痛苦且漫长的过程，在此过程中你可能会想到 Volx 大侠的贡献，他为大家带来了极大的福利。

### 2. 脚本脱壳

将 Volx 大侠的脚本稍作修改即可实现脱壳。

载入 `Packed.Unregistered`，使用修改后的脚本很快就能到达 `OEP`。强大的脚本此时已帮你 `Dump` 下内存，修复脚本尚未修复的地方，完成脱壳。

**说明**：文章中附带的脚本仅针对 `2.3.06.26` 版本的壳，它可以脱去 `2.3.06.26` 不需要注册以及需要注册的目标程序。

**附件下载**：`By Pass ASProtect.2.3.06.26.rar`
