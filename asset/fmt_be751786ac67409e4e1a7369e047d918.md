## 破解过程

使用 `PEiD` 查壳，结果为 `Microsoft` `Visual` `C++` `7.0` [Debug]，无壳。

运行程序并输入注册信息：

```
Name: snake
Activation: 123456789ABC
```

点击 “Activate” 按钮后提示错误信息，并将注册信息写入到注册表中。

使用 `OD` 载入程序，下断点 `bp` `RegQueryValueExA`，按 `F9` 运行。断下后，连续按 `N` 次 `F9`，直到堆栈显示内容如下：

```

0012D8F8   000000A8  |hKey = A8
0012D8FC   00DD6EB0  |ValueName = "sn"
0012D900   00000000  |Reserved = NULL

0012D90C   0012D91C  \\pBufSize = 0012D91C
```
