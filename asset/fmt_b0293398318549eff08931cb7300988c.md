# 2. 总结

1. 注册码和机器码位数一致。
2. 根据机器码每位不同的字符找出相应的注册码。
3. 机器码和注册码对应的方式如下表示：

   机器码：`0` `2` `4` `6` `8`  
   注册码：`U` `L` `O` `V` `E`

如果机器码不是上述字符，那么进行下面计算（转为 ASCII 码）：

`SN = (M + 21) and 7F`

结果转为 ASCII 码字符即可。
