第二个 `call` 中调用了 `div ebx`,后面利用他算出来的商数跟三参和四参计算得到 `eax` 和 `edx`

`div` 后的商数就 3 种情况 0、1、2

```cpp
#include<iostream.h>

int _stdcall l(int i);

void main()
{
  int value=0;
  for(int i=0;i<=0xFFFFFFFF;i++)
  {
    value=l(i);
    if(value==0xA5164792 || value==0x4A2C8F17|| value==0x0000000D)//因为就三种情况
    {
      cout<<i<<endl;
      return;
    }
  }
}

int _stdcall l(int i)
{
  return 0x69948F1B*i;
}
```

第二个 `call` 出来的 `eax` 我个人认为要是 `0xD`,正好盖掉返回值处
