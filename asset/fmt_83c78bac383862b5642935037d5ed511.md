### Registration Code Calculation (Case Length 20/14H)

The text notes: "Let's look at the case where the registration code length is 20 (14H): (call `004E6494` is key!)"

Following the entry into `004E6494`, we see a loop that calculates the registration code. (Note: The code was refilled with: `12345678901234567891`).

```asm
004E64DF   |. /7E 39             jle short winchm.004E651A  
004E64E1   |. |BB 01000000       mov ebx,1               ;  Calculating registration code!!  
004E64E6   |> |8BC3            /mov eax,ebx             ;  Starts loop count from 1 to determine which digit of the reg code to use  
004E64E8   |. |99               |cdq                     ;  Extends the sign of the word in EAX into EDX  
004E64E9   |. |52               |push edx                 ; /Arg2  
```
