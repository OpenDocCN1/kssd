
## 算法分析总结

1. 把我们输入的用户名转化为 16 进制数存起。
2. 再把 16 进制数倒过来，比如以前 `123456` 倒过来就是 `654321` 了。
3. 再分别取出固定字串 `flv67u986e` 中的前 4 位（`flv6`）和 5-9 位（`7u986`）。
4. 再把它们组成注册码：`flv6`－16 进制数倒过来的前 4 位 `7u986`－16 进制数倒过来字串的 5－8 位。这就是注册码了。
5. 我两个用户名测试了一下得到注册码。

(1). 第一个用户名是 `wangwei`，转化为 16 进制数是 `77616E67776569`，倒过来就是 `96567776E61677`，得到注册码就 `flv6－9656` `7u986－7776`。

(2). 第二个用户名是 `sdrf5678lk`，转化为 16 进制数是 `73647266353637386C6B`，倒过来就是 `B6C68373635366274637`，得到注册码就 `flv6－B6C6` `7u986－8373`。

### 注册机算法

```c
#include <stdio.h>
int zifen(char *s, int *u) //-------------> 关键是 zifen() 这个函数它的作用是
{ // 把我们的字符的 ACSII 值进行置换，如：i 的 ACSII 值是
    // 69 通过 zifen() 就变为 96 了
    while (*s != '\0')
    {
        *u = *s % 0X10;
        u++;
        *u = *s / 0X10;
        u++;
        s++;
    }
} // <---------------
int main()
{
    int i = 0, j = 0, k = 0;
    char a[30]; // 用来接收用户名字符串
    char b[3] = {'0'}; // 存放用户名最后 4 个字符，而且是倒序好的；
    int f[8] = {'0'}; // 用来存放 zifen() 这个函数处理好的字符；
    printf("请输不小于 4 位的用户名： \n");
    scanf("%s", &a); // 接收用户名字符串
    while (a[i] != '\0') //-----------> 计算用户名的位数
    {
        i++;
        j++;
    } // <---------------

    for (i = (j - 1); i >= (j - 4); i--) //--------------> 取用户名的最后 4 位并进行倒序
    {
        b[k] = a[i];
        k++;
    } // <--------------

    zifen(b, f); // 处理倒序好的字符
    printf("你的注册码是：\n"); //------------ 打印出注册码
    printf("flv6-");
    for (i = 0; i < 4; i++)
        printf("%X", f[i]);
    printf("7u986-");
    for (i = 4; i <= 7; i++)
        printf("%X", f[i]);
    printf("\n"); //-----------
}
```
