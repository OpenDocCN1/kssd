
# Vista 引导过程分析（一）

这是几周心血来潮想研究下 bootkit，正好偶有个 vista 的虚拟机镜像，就搞了一下，结果就出了今天大家看到的这个半成品。（并且是很少的一部分）

## 1. 制作 Vista 的 Bochs 镜像

### 工具

把 VMware 镜像转成 image 格式：`qemu-img.exe`

```
qemu-img.exe x:\xx.vmdk x:\xx.img
```

## 2. 设置 Bochs

直接拷贝 `dlxlinux` 的设置，修改 `bochsrc.bxrc` 里的：

```
ata0-master: type=disk, path="vista.img", cylinders = 0, heads=64, spt=64
```

*   `cylinders` 设为 `0`
*   后面 `heads` 和 `spt` 设为 `8` 的整数倍
