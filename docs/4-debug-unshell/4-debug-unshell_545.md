> `P6^(HASH+MAGIC)%P7 = Z1`

> `(Z2*P5)%P7 = Z2`

> `Z2^(R)%P7 = Z0`

> `P6^(r)%P7 = Z0`

> 于是乎

> `(Z1*P5)^(R)%P7 = Z0`

> `(P6^(HASH+MAGIC)*P5)^(R)%P7 = P6^(r)%P7`

> 另一组是

> `(P1+HASH+MAGIC) = N`

> `N%P3 = S1`

> `S1^(-1)%P3 = S2`

> 所以有

> `(r*S2)%P3 = R`

> `(R*S1)%P3 = r`

> 所以

> `(R*N)%P3 = r`

> `(R*(P1+HASH+MAGIC))%P3 = r`
