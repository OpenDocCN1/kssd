

# 发布 PESpin 1.32 自动脱壳机

> 原文：[`www.pediy.com/kssd/pediy11/124054.html`](https://www.pediy.com/kssd/pediy11/124054.html)

前几天做第 1 阶段第 4 道脱壳题，现在做了一个 PESpin1.32 自动脱壳机，测试了几个程序，运行良好。  
在用 PESpin1.32 加壳的时候，如果把以下保护选项全部选择，本程序可以成功脱壳：  
API Redirection  
Antidump protection  
Remove OEP  
Code redirection  
Debug Blocker  
  
(有没有选择 "Add Debugger detection 都可以")
