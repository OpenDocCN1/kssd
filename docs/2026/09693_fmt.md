
# VFX&EXE文件加密的克星

## VFX&EXE文件加密的解密的方法

准备工具：`UNALLFOX2.1`、`PEditor 1.7`（看雪上有）

以`PCFT202`：

1. 先安装，然后对要运行的文件输入密码（`PCFT`），然后把`PCFT`最小化。
2. 启动运行`PEditor 1.7`，选`TASKS`。
3. 不退出`PCFT`程序，重新热启动计算机。
4. 把`C:\WINDOWS\History\0\Aejbgdb.EXE`拷贝出来。

   （把`C:\WINDOWS\History\`拷贝出来，改名；
   用`attrib \*.\* -s -h`；
   然后在资源管理器中拷贝`0\Aejbgdb.exe`出来，改名；
   去隐藏：`attrib \*.exe -h`；
   用`UNFOXALL`反编译。）
