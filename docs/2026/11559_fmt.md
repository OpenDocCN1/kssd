
# [原创]基于SSL的操作网页POST自动化

这是一个猜测密保答案的工具,

密保答案页面使用SSL加密.附件是一个之前给别人开发的一个工具。

核心用的`SSL SOCKET`来`POST`数据

里面还有一个我之前封装的`IEcomcontrol`的类 像韩国游戏 需要网页登录的都可以做来自动登录。包括调用`JS` 我已包装的很完善了。

有一点不懂的是 如何用非阻塞方式来 使用`SSL SOCKET`

因为多次猜测之后，网站服务器屏蔽了我的`IP` 我就连不上了, `ssl_connect`死在了那里。

很多人写有关于操作网页的程序 都打开网页的 我个人不喜欢,

我喜欢直接用`SOCKET` 快速 简洁 方便.用着爽.唯一不足就是速度太快 导致容易被屏蔽。
