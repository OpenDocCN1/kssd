
# [原创] Radamant勒索病毒分析

## 1. 概述

从 Github 上获取的一个 Radmnant 勒索样本，样本具有早期勒索病毒的主要特征，比较典型。虽然勒索病毒现在都不这么玩了，但还是可以学习其功能实现的思路和方法。因为还在学习这方面的内容，所以分析过程尽可能比较详细地列出来，分析结果可能存在一些遗漏或错误，也请大家指教。图片从 word 拷贝过来比较模糊，所以把 idb 文件放在附件了，病毒文件来源于 Github 上的 theZoo 项目。

## 4. 基础静态分析

### 4.1 检测加壳

首先，使用 `PEiD` 检测该勒索病毒是否加壳。虽然 `PEiD` 显示“Nothing found”，但 EP Section 显示了“UPX1”节区，应该只进行了壳的特征值处理。显然，这是使用了常见的 `UPX` 压缩壳对病毒进行了加壳。

![](https://bbs.kanxue.com/upload/attach/201912/860819_MFEVXPECHPXW654.jpg)

### 4.2 UPX 脱壳

前面分析得知病毒已使用了 `upx` 进行压缩，所以使用 `upx` 命令行工具进行脱壳，脱壳过程显示如下：

![](https://bbs.kanxue.com/upload/attach/201912/860819_KP57HC4PGTJNCDV.jpg)

成功获得了脱壳后的 `Radmant.exe` 病毒文件。

### 4.3 导入表分析

使用 `PEid` 分析病毒的导入表，发现有 7 个模块被导入。下面分析一些主要模块的导入函数，可以得到其中的一些关键信息。

1. `kernel32.dll`：除了一些病毒必须的函数外，该模块还导入了 `GetLogicalDrives`、`GetFileSize` 等函数，估计与文件加密部分有关。

![](https://bbs.kanxue.com/upload/attach/201912/860819_FPKWJY7NSJCCGN3.jpg)

2. `advapi32.dll`：勒索病毒中常见导入模块，与密钥生成、注册表写入有关。

![](https://bbs.kanxue.com/upload/attach/201912/860819_PBDEZJ24QUBFFHR.jpg)

3. `dnsapi.dll` 和 `ws2_32.dll`：发现了诸如 `socket`、`connect`、`DnsQuery_A` 等函数，与病毒的网络行为有关，且很有可能和消息通信相关。

![](https://bbs.kanxue.com/upload/attach/201912/860819_TTQTEZDP76UJXGM.jpg)

4. `SHELL32.dll`：该模块导入了两个关键的函数 `SHGetFolderPathA` 和 `ShellExecuteA`, 表明病毒除运行本身外还运行了其他外部程序也可以是病毒释放的程序。

![](https://bbs.kanxue.com/upload/attach/201912/860819_HXVRTNP8GY45QYF.jpg)

### 4.4 资源段分析

使用 `Resource Hacker` 查看病毒的资源段，如下图所示：

![](https://bbs.kanxue.com/upload/attach/201912/860819_8W35GGAPMAJEPTX.jpg)

发现了一个资源 ID 为 `1033` 的自定义资源，且该资源未被加密。分析似乎与文件信息有关，文件名为“DirectX”。暂时没有什么头绪，待后续分析。

## 5. 详细分析

### WinMain()

从模块入口定位到该函数，经过分析，发现这个函数是病毒的主函数，且没有使用任何的混淆反调试等保护手段。以下是对主函数逻辑的分析：

![](https://bbs.kanxue.com/upload/attach/201912/860819_REDCJPDQZUJDDGZ.jpg)

下面，按顺序和层次一一分析其中的关键函数。

### check_my_path() 检查文件路径

这个函数获取了病毒文件当前的路径名和文件名，然后检查该病毒程序是否按照指定的路径和名称在运行：

![](https://bbs.kanxue.com/upload/attach/201912/860819_ZZ5R9HZQB2KKFDS.jpg)

### copyMeToWin() 拷贝自身到指定路径

上一个函数检查文件路径，若不在指定目录以指定名称运行，则将自身拷贝到一个指定的目录下，重命名为 `DirectX.exe`，文件属性设置为隐藏，然后运行拷贝后的病毒程序：

![](https://bbs.kanxue.com/upload/attach/201912/860819_XKPET8856GNMBDY.jpg)

如下图所示，病毒样本拷贝到对应目录下：

![](https://bbs.kanxue.com/upload/attach/201912/860819_G66M8WUG3AP299K.jpg)

拷贝完成，调用 `Delself()` 函数新建一个批处理文件 `aaa.bat`，删除原病毒样本：

![](https://bbs.kanxue.com/upload/attach/201912/860819_8X6NUUDST9M2QHE.jpg)

### checkARun() 注册表查询

这个函数检查注册表是否写入了该病毒程序。

![](https://bbs.kanxue.com/upload/attach/201912/860819_S98JNBQ8ZEXTK6A.jpg)

### UACME() 创建互斥体

这个函数创建了一个名为“`radamantv2.1`”的互斥体，防止双开；没有异常，则使用 WMI 命令行，启动病毒进程：

![](https://bbs.kanxue.com/upload/attach/201912/860819_CQJA6SSBUD5HEVE.jpg)

### SetARun() 注册表写入

这个函数在注册表写入病毒文件位置。

![](https://bbs.kanxue.com/upload/attach/201912/860819_PG5H62KW8T4SDAT.jpg)

如下图，为注册表的写入验证：

![](https://bbs.kanxue.com/upload/attach/201912/860819_YFR8QRQM6Z2TEKN.jpg)

### getID() 计算 MD5 值作为 ID

这个函数，根据系统信息、计算机名、硬件信息等多种信息，计算出一个 `MD5` 值，并将这个 `MD5` 值作为标识 `ID` 用于后面功能的实现：

![](https://bbs.kanxue.com/upload/attach/201912/860819_JFN7B5G252VKPVZ.jpg)

如下图，在虚拟机上得到的 ID：

![](https://bbs.kanxue.com/upload/attach/201912/860819_65YPZ3P4SEGG558.jpg)

### decrypt_domain() 解密密文得到域名

这个函数的参数是一个加密了域名，使用 `AES` 算法和解密密钥，计算最终可以得到未加密的域名：

![](https://bbs.kanxue.com/upload/attach/201912/860819_923EBEFQATX26YE.jpg)

如下图，解密得到的服务器域名为“`tangotango.com`”, 这是一级控制服务器的域名：

![](https://bbs.kanxue.com/upload/attach/201912/860819_S2N3SZ327R578CJ.jpg)

### GetIP() 域名解析并发送请求

这个函数，首先向域名“`checkup.dyndns.org`”发送一个 `GET` 请求，该域名会返回宿主机的外网地址：

![](https://bbs.kanxue.com/upload/attach/201912/860819_N5WGZY6DW7NDWC7.jpg)

![](https://bbs.kanxue.com/upload/attach/201912/860819_KJFFQATJYFS2SR5.jpg)

### getDomainsFromReg() 注册表获取域名

这个函数比较直观，从注册表中获取一个域名列表。第一次运行，查询不到域名，所以先执行后面的函数。

![](https://bbs.kanxue.com/upload/attach/201912/860819_9CBDBH9ZNQNR64N.jpg)

### SendDataToServer() 发送数据到服务器

上一个函数判断了注册表中是否有域名列表。若没有，就执行这个函数。该函数向服务器的 IP 地址发送了一个 `POST` 请求，并从返回的数据中获取指定的值根据下一个函数判断，这个值为域名：

![](https://bbs.kanxue.com/upload/attach/201912/860819_N5HX6CQ9GPCP452.jpg)

![](https://bbs.kanxue.com/upload/attach/201912/860819_JBPA9BYNSWS8MZ5.jpg)

动态调试这个函数，显示向一级域名发送请求二级域名的消息：

![](https://bbs.kanxue.com/upload/attach/201912/860819_4KY59ZKCPARSQ3X.jpg)

这里设置一级域名服务器“`tangotango.com`”为另一个虚拟机地址，`POST` 的消息如下：

![](https://bbs.kanxue.com/upload/attach/201912/860819_3DSMRBFJBJD9MKH.jpg)

### setDomains() 注册表写入域名

这个函数同样比较直观，将上一个函数获得的域名，写入注册表中。

![](https://bbs.kanxue.com/upload/attach/201912/860819_BRCVA6ZDNFC3Q9D.jpg)

在虚拟机中，执行这个函数在虚拟机中写入了一个注册表键值：键为宿主机 id；值为一个二级域名实际控制域名。由于服务器失效，这里的为自己构造的域名和指向另一个虚拟机的IP地址：

![](https://bbs.kanxue.com/upload/attach/201912/860819_D3YX4HA27RA4VXJ.jpg)

### dowork() 病毒主线程

这个函数是病毒的主线程，实现了病毒的主要功能。这个函数首先把宿主机的 id 先前计算得到的与IP地址发送到 `domain_list[]` 中存储的域名地址，然后接收服务器传回来的命令，通过 `exec_command()` 函数执行命令。

![](https://bbs.kanxue.com/upload/attach/201912/860819_35U9ATMAUM5MUSS.jpg)

如下图，将宿主机 IP 和 id 发送到注册表中的二级域名：

![](https://bbs.kanxue.com/upload/attach/201912/860819_8W8S8NEHT94JB6H.jpg)

#### exec_command() 命令执行

这个函数是 `dowork()` 病毒主线程调用的命令执行函数。这个函数，可执行的命令包括：

删除自身命令；命令更新命令；发送宿主机信息命令；加密文件命令；解密文件命令；显示勒索信息；显示解密信息。具体显示如下：

![](https://bbs.kanxue.com/upload/attach/201912/860819_CMWGWJKVPND6FVF.jpg)

![](https://bbs.kanxue.com/upload/attach/201912/860819_RMJSRV6QMRZ2JX5.jpg)

##### DelSelf() 删除自身

这个函数执行批处理文件删除自身进程、文件等。

![](https://bbs.kanxue.com/upload/attach/201912/860819_6EQ6D7APBYNXQUJ.jpg)

##### update_me() 命令更新

这个函数，从服务器下载 `build.exe` 文件并更新指令集。

![](https://bbs.kanxue.com/upload/attach/201912/860819_CK8V9FFTA2ZE78F.jpg)

由于服务器失效，所以不能下载目标文件。

##### SendMyInfo() 发送宿主信息

这个函数将宿主机系统信息和密钥发送到服务器。

![](https://bbs.kanxue.com/upload/attach/201912/860819_GMM3UYTBUCBUE48.jpg)

![](https://bbs.kanxue.com/upload/attach/201912/860819_3R3VM96HNSNJ6ES.jpg)

##### encrypt_PC 加密文件

这个函数是宿主机的加密函数，实现了获取 `RSA` 加密公钥和寻找并加密文件的功能：

![](https://bbs.kanxue.com/upload/attach/201912/860819_BK4G9NEW4V484JF.jpg)

###### FindAndCryprFiles() 寻找并加密文件

这个函数在加密文件命令的函数下调用。其主要功能就是获取磁盘信息，使用一个递归函数搜索文件，并加密所有文件。

![](https://bbs.kanxue.com/upload/attach/201912/860819_QY2YTYAD2SNENUD.jpg)

###### Search() 递归搜索文件，加密文件

这个函数由上一个函数 `FindAndCryprFiles` 调用。主要实现了两部分的内容：递归搜索文件；`AES` 算法加密或解密文件。

解密部分：

![](https://bbs.kanxue.com/upload/attach/201912/860819_EE9AYEM779MT63E.jpg)

加密部分：

![](https://bbs.kanxue.com/upload/attach/201912/860819_8T82SRYQ36DJS6H.jpg)

在加密时，先从服务器获取本机 id 的 `RSA` 私钥，用来加密接下来生成的 `AES` 密钥。然后用 `AES` 密钥加密文件如服务器未指定加密的文件类型，则默认加密所以类型的文件。

如下图，为加密 `test.txt` 的过程：

![](https://bbs.kanxue.com/upload/attach/201912/860819_MYPF5DPMB4E84UR.jpg)

加密完成显示如下原文件之后会删除：

![](https://bbs.kanxue.com/upload/attach/201912/860819_A32FSEPB84QEVPZ.jpg)
