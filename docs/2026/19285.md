取得`root`权限（因各类设备方法不同，这里不展开说明）

1) 进入 `Android` 设备终端中：

```
adb shell
```

2) 切换为 `Android` 设备的 `root` 用户：

```
su -
```

3) 设置 `adbd` 服务的指定端口号：

```
# setprop service.adb.tcp.port 5555
```

注：`5555` 虽是默认的，这里也要设一下，也可以是自定义的，但是什么必要。

4) 重启 `adbd` 服务：

```
# start adbd
```

注：`# stop adbd` 命令将会停止 `adbd` ，只能重启了 `Android` 设备了
