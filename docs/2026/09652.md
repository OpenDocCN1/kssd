## 开发思路

### 思路一：个性化工作表标签栏

有时候我们可能需要区分不同的工作表，那么可以通过修改标签栏的颜色来实现：

```
>>> import openpyxl

>>> # 创建工作簿

>>> wb = openpyxl.Workbook()

>>> # 创建工作表

>>> ws1 = wb.create_sheet(title = "zy1")

>>> ws2 = wb.create_sheet(title = "zy2")

>>> ws3 = wb.create_sheet(title = "zy3")

>>> # 个性化工作表

>>> ws1.sheet_properties.tabColor = "FF0000"

>>> ws2.sheet_properties.tabColor = "00FF00"

>>> ws3.sheet_properties.tabColor = "0000FF"

>>> # 保存

>>> wb.save(r"C:\Users\Administrator\Demo.xlsx")
```

### 思路二：调整行高和列宽

在 Excel 中要修改行高和列宽，只需要通过鼠标的拖拽操作就可以实现。

使用 `openpyxl`，同样可以通过修改工作表的 `row_dimensions` 和 `column_dimensions` 来实现同样的操作。

在 `row_dimensions` 中，使用具体的数字来表示将要修改第几行的高度，比如 `row_dimensions[2].height = 100` 是将第 1 行的高度修改为 100；

在 `column_dimensions` 中，则要使用字母来表示对应的列号，比如 `column_dimensions['C'].width = 50`，是将第 C 列的宽度修改为 50。

注意，这个高度和宽度的单位是不一样的，所以你会发现这 “100” 的尺度竟然比 “50” 还大：

### 思路三：合并和拆分单元格

利用工作表的 `merge_cells()` 和 `unmerge_cells()` 可以快速地合并和拆分指定区域的单元格。

```
# 合并单元格

>>> ws2.merge_cells("A1:C3")

>>> # 给合并后的单元格赋值

>>> ws2['A1']='I love China!'

>>> wb.save(r"C:\Users\Administrator\Demo.xlsx")
```

合并后效果如下：

![](https://bbs.kanxue.com/upload/attach/201801/784718_93PVP2W3XUH4F7V.jpg)

```
>>> # 拆分单元格

>>> ws1.unmerge_cells('A1:C2')

>>> wb.save(r"C:\Users\Administrator\Demo.xlsx")
```

注意：当初是怎么合并的，就应该怎么拆分，也就是说拆分的范围必须跟当初的合并保持一致。

### 思路四：冻结窗口

有时候我们的工作表非常庞大，比如我们拿到一个全国人口普查数据的 Excel 表格 （附件）

![](https://bbs.kanxue.com/upload/attach/201801/784718_NKGXZWBZR9GTWDB.jpg)

因为数据比较多，所以当我们查看中间某个数据的时候，就很难直观的看出这是个啥？

![](https://bbs.kanxue.com/upload/attach/201801/784718_885S6VB497P5SWW.jpg)

这时候，冻结窗口的功能就显得非常的牛逼

设置工作表的 `freeze_panes` 属性即可实现冻结窗口。

比如上面人口普查的表格，理想的情况是将蓝色的行和黄色的列冻结起来。

那么我们可以将 `freeze_panes` 设置为 `'B8'` 即可：

```
>>> wb = openpyxl.load_workbook(r"C:\Users\goodb\Desktop\A0101a.xlsx")

>>> ws = wb.active

>>> ws.freeze_panes = 'B8'

>>> wb.save(r"C:\Users\goodb\Desktop\A0101a.xlsx")
```

![](https://bbs.kanxue.com/upload/attach/201801/784718_ZDE7UGGMSZV69TK.jpg)

如果需要解冻，只需要将 `freeze_panes` 设置为 `None` 或 `'A1'` 即可。
