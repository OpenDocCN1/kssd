# [原创]IDA 在解析 IA64 中的 brl 指令时存在一个 Bug

brl 指令如下：

![](https://bbs.kanxue.com/upload/attach/201901/16282_QCN6T43WCBV7QPM.png)

其中：target64 = IP + ((i << 59 | imm39 << 20 | imm20b) << 4)

应该是由于 IDA 在取 imm39 时取的 0-38 bits，按照文档应该是 2-40 bits。

比如：

400000000463CF50 05 00 00 00 01 00 05 00 00 00 00 00    nop.m 0
400000000463CF5C 50 78 E0 C0                                          brl.few 0x40000000194447A0;; // should be 0x400000000a4447a0

在 IDA v6.8 上做的测试，不知在最新版本中是否还存在。
