使用adb install 电脑apk路径 安装CrackMe01.apk，界面如下：
![图片描述](upload/attach/202007/894007\_UZFSQW8BCC7X4MN.png)
开启IDA监听端口（要事先把IDA-dbgsrv目录下的android-server置到模拟器中，这里是/data/local/tmp下，修改名称为as并赋给可执行权限），用./as开启端口监听，默认端口是23946，app崩溃
![图片描述](upload/attach/202007/894007\_K2XNX8QNRN3JS7B.png)
猜测可能存在端口检测，更改端口为31928，命令：./as -p31928
成功过app调试端口检测，接着进行端口转发
![图片描述](upload/attach/202007/894007\_6BTRCYYAEQQU3X3.png)
### 3.5 IDA以Debug模式动态调试apk
先打开DDMS，用于模拟器进程监听。
打开app主界面，使用adb shell dumpsys activity top命令获取当前界面信息
![图片描述](upload/attach/202007/894007\_55WNNFQ2EC4V2JH.png)
使用adb shell am start -D -n com.yaotong.crackme/.MainActivity命令以Debug模式启动app指定界面
![图片描述](upload/attach/202007/894007\_8JJ3W9969MM47NN.png)
然后打开IDA Debugger附加CrackMe01.apk app进程
![图片描述](upload/attach/202007/894007\_G6UD4NQRH6XPAWN.png)
![图片描述](upload/attach/202007/894007\_H98KB9A2UJ9B33U.png)
![图片描述](upload/attach/202007/894007\_WU5Q4ZVD82VS8H3.png)
勾选Debug选项（加载so要挂起载入）
![图片描述](upload/attach/202007/894007\_AYCV67VAN7PWN23.png)
![图片描述](upload/attach/202007/894007\_SSN5MTS4Y98F724.png)
IDA Debug模式动态调试配置完成。
为什么不用直接动态调试？经发现，该apk运行时会自己附加一个子进程，IDA中直接动态调试会显示两个Pid的该进程（可以进入/proc/进程id/status进行信息查看，子进程的TracePid就是父进程的Pid），由于一个进程只能被附加一次
，因此不能再对子进程进行附加，对父进程调试也发生了错误，而Debug模式动态调试则没有问题。
### 3.6 破除反调试
F9然后执行jdb -connect com.sun.jdi.SocketAttach:hostname=127.0.0.1,port=端口号，端口号是DDMS对应进程的端口，且执行后图标变成绿色。
加载libwolf.so进来（进程现在挂起状态），找到这个so的导出函数（Debugger-Module list）
![图片描述](upload/attach/202007/894007\_6QV78H5NFU2NZCV.png)
在jni\_onload函数下断点，然后F9
![图片描述](upload/attach/202007/894007\_9A8VD4J86XNGSD2.png)
程序断在这里
经测试函数在下图中的函数执行后会使调试中断
![图片描述](upload/attach/202007/894007\_XNDQ6GP45B53SFS.png)
怀疑是反调试相关函数，尝试不让这个函数执行，找到改指令对应的内存指令数据
并修改为（00）（据说是注释）
![图片描述](upload/attach/202007/894007\_JJGA4Y8JVKZQYKQ.png)
变为
![图片描述](upload/attach/202007/894007\_RAGJR3363BX6FHX.png)
![图片描述](upload/attach/202007/894007\_ATJ3SERBJZT5C9B.png)
应用之，反调试成功破除。
### 3.7 取得明文密码
从导出函数列表中可以看到许多加解密相关，猜测是把密文解密成明文然后与输入作比较，直接在Decrypt函数中的CMP（compare）指令下断点。
按F9让相关so加载进来，之后回到apk随便输入然后点按钮验证以触发解密函数。
按F9程序在指定地方断下，密码明文很可能在某一个寄存器中，找到R7寄存器（指向堆）jump过去查看存放内容
![图片描述](upload/attach/202007/894007\_5VGMEVMWTCEC8Z6.png)
红圈存放的hello5.1应该就是密码
![图片描述](upload/attach/202007/894007\_JW3K4FDC3A2ZBAA.png)
果然
