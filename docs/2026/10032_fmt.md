
# [原创]网络版U盘小偷

上个月照着书敲了些代码，自己改动了下，写成了篇u盘小偷的帖子，结果成了正式会员，哇咔咔，那滋味真叫幸福啊![](https://bbs.kanxue.com/view/img/face/41.gif)。下面是单机版的U盘小偷链接：`http://bbs.pediy.com/showthread.php?t=142952`

本来打算尽快写出网络版的出来的，无奈这个月LZ有时堕落有时发呆，没几天干正事的，所以一直拖到现在才写成一个网络版的雏形，就发出来吧~~

关于这个网络版的U盘小偷，需要的就是结合单机的U盘小偷和socket编程，socket编程当初楼主上课有讲过，无奈楼主当初就以酱油男，想想都后悔啊！只好又再学一遍了。
