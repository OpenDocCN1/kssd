好像很受欢迎的样子，而且它还提到了`LD2KReg.ini`，再看看后面的代码，应该是判断注册的地方，程序很简单，将`004A4DCF`的`jne 004A4E08`改为`je 004A4E08`即可成为注册版。

`LD2KReg.ini`文件内容变为：

```ini
[Register]
Register=C5VPQ1;=SMQ
```

我想用没改过的汉化版做一下测试，可它显示已经是注册版了，不知这个文件在别的机器上管不管用？我用的是WIN2000，该文件在`C:\WINNT`下，WIN98我就不清楚了。
