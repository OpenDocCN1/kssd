# [旧帖][原创]从iphone平台移植过来的方格数字游戏(汇编实现)0.00雪花

这个游戏是我在iOS平台看到的一个小游戏，
这个游戏界面很简单，但是很有意思。

游戏开始会有九个格子，每个格子都会有一些看似随机的数字，每当你点击一个格子的数字，这个格子里的数字会减去1，而它周围（上下左右）格子里面的数字会增加1，然后你的目标是将所有格子里面的数字都变为0。另外需要主要的是，游戏有步数的限制，也就是说你只能在规定的步数完成操作，考验智力的小游戏，到后面有点难度哦

当然在IOS上此款游戏，界面比较炫，而且关卡设置也更丰富多彩，我这里只是初步实现了一下，关卡还没设置上限，所以到后面的时候肯定会有一些数字显示上的问题，暂时还未修正，不过刚开始几关玩起来还是蛮爽的，哈哈。

由于是汇编实现的，所以界面很烂，我还不知道如何使用masm优化界面，有库吗？还不了解。
