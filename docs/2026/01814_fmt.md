
# 菜鸟破解录(12)之 AxMan3.10 (3千字)

## 基本信息

- 软件名称：AxMan
- 版本：3.10
- 简介：一个非常不错的文件分割工具，该工具的主要作用是可以将大文件切成几个小文件便于拷贝到软盘或作为电子邮件附件发送。对于分割的文件，程序提供自动合并功能，同时该工具也提供非常简单的操作界面和操作方式以方便用户使用。
- 作者：xiA Qin
- 等级：很菜....很菜....
- 破解日期：2000年7月24日
- 破解工具：Trw2000 1.22
- 破解目的：学习注册码的破解（简单）
- 说明：本文是在我的软件破解记录上整理出来的，只作技术交流。如若有纰漏，请各位大侠多指教！

## 破解过程

运行程序，输入注册信息。

```
name:          xiA Qin
&任意输入
Company:      China
&任意输入
Registration: 1234567890        &任意输入
```

下指令`bpx hmemcpy` // 下中断点

按F5回到程序，按OK，这时会被Trw2000拦截到。

下指令`bd *` // 屏障中断点

下指令`pmodule` // 直接跳到程序的领空

按F10来到下面的代码：
