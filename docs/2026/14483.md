
# [原创]简单的分析

对android的逆向分析一般如下所示。首先是观察其权限。如下

![](https://bbs.kanxue.com/upload/attach/201212/257009_qdcdc36vmovnvg2.png)

接着查看接收器，服务等等，如下图

![](https://bbs.kanxue.com/upload/attach/201212/257009_jyczbjz7ebaxgvn.png)

具体步骤如下：首先从`BootReceiver`入手，主要是利用`android.intent.action.PHONE_STATE`以及`android.intent.action.BOOT_COMPLETED`这两个动作启动`ManageService`。即当手机重启或者电话状态改变时启动服务`ManageService`。

![](https://bbs.kanxue.com/upload/attach/201212/257009_1z1mnszeg7jz6ij.png)

转移到`ManageService`服务，代码如下

![](https://bbs.kanxue.com/upload/attach/201212/257009_o6rbljkjgc36l32.png)

其中`b`为定时器，判断条件为`j.a(this.a, j.l(this))`。转到`j`类查看器函数`a`作用。转跳以后发现`j`类中函数`a`的个数很多，我们在定位函数`a`时需要借助一些条件进行排除。

首先`j.a(this.a, j.l(this))`的参数个数为2，`j.l`的返回类型为`string`。通过以上一些条件，我们可以确定`j.a`函数的代码。而参数`this.a`根据定义为`context`类型。

![](https://bbs.kanxue.com/upload/attach/201212/257009_9bi7kpjndbykhhx.png)

从而我们可以定位出函数`j.a`。代码如下

![](https://bbs.kanxue.com/upload/attach/201212/257009_c09te3yn2qt34gk.png)

我们可以确定下来该判断条件就是是否存在该安装包，如果存在则停止。不存在则启动服务`startService(new Intent(this, Providers.class))`。转跳到`Providers`，其部分代码如下

![](https://bbs.kanxue.com/upload/attach/201212/257009_e9v60s6wfwq8e90.png)

可以看到主要是要对`j.a`进行判断，可以看到，这里面的两个参数都是`string`类型的，据此我们定位到`j.a`。代码如下。可以看到`jd-gui`解析失败。大体可以看到是执行`linux`指令

![](https://bbs.kanxue.com/upload/attach/201212/257009_hcn6wxt1nfiz26g.png)

可以利用`smali`文件进一步判断，其`smali`代码如下

![](https://bbs.kanxue.com/upload/attach/201212/257009_b0qraldmtv1w3v9.png)

主要的作用是将`assets`中的`config.dat`（其本身为`apk`）变为`config.apk`，并且安装。

接着查看`Providers`。其构造函数`onCreate`如下

![](https://bbs.kanxue.com/upload/attach/201212/257009_uhpgc1gsl3xk6wv.png)

其中比较重要的是`new n(this.a).a()`，`new e(this.a, this.b).a()`这两个条件。定位到`n.a()`函数，其代码如下。

![](https://bbs.kanxue.com/upload/attach/201212/257009_wu5v0ogfkhih5f7.png)

可见`n.a()`函数主要是对`crptdat0`进行操作，利用魔法字可以很容易的判断其文件格式，发现标识符为`elf`，为`so`文件。使用`IDA`打开，观察`strings table`可以快速判断其文件的主要作用，该文件的作用进行`root`。

![](https://bbs.kanxue.com/upload/attach/201212/257009_dg40i3hbzioazvz.png)

定位到`e.a()`函数

![](https://bbs.kanxue.com/upload/attach/201212/257009_b47no7qwbujgjy1.png)

充分说明需要根据参数个数，类型，返回值等进行准确定位。同时对于附件中的文件我们也应该仔细分析

利用`IDA`分析`assets`中的`so`文件`crptdat1`，查看字串表，发现其主要作用是查看是否存在线程数限制（该漏洞的主要原理是因为线程数超过范围），如果没有限制，则利用`srptdat0`来进行`root`。

![](https://bbs.kanxue.com/upload/attach/201212/257009_ppnudmbt4phtwtf.png)

查看附件中的`config.dat`文件（本身为`apk`文件），进行分析。打开`APK`文件，我们首先观察其权限，以及是否存在图标等情况。如下图可见，说明该文件不存在图标，而且开机自启动，具有很多敏感权限，以服务的形式运行。

![](https://bbs.kanxue.com/upload/attach/201212/257009_ze7n3vinpbss9gf.png)

接着看代码，比较快捷的办法直接是查看敏感函数。这里我们可以看到它是可以静默发送彩信的。

![](https://bbs.kanxue.com/upload/attach/201212/257009_65n9nj514zib7gf.png)
