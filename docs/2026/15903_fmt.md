### c. 寻求突破口

每每请求一个视频的时候，会抓到一个 `api/MvDetail/detail` 的请求，我们先解密 `response` 的 `body`。

在 `json` 里有几个字段发人深省，`isVip`、`daily_view`、`isfree` 以及 `coins`。

我们进行了这些值的篡改，老板，再来一箱营养快线！

### d. 最终代码

```javascript
Java.perform(function() {
    var crutial_util = Java.use('com.****.lib.encrypt.b');

    crutial_util.a.overload('java.lang.String', 'java.lang.String').implementation = function (x, y) {
        var ret = this.a(x, y);
        var final = ret
            .replace('"daily_view":0', '"daily_view":2')
            .replace('"isVip":false', '"isVip":true')
            .replace(/"isfree":0/g, '"isfree":1')
            .replace(/"coins":\d/g, '"coins":0');

        return final;
    };
});
```

好了，也是几行代码。
