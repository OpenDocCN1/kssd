
# [已解决]OD 右键菜单项，如何下断

![](https://bbs.kanxue.com/upload/attach/201207/86770_i9q0qqqmbc81w2v.png)

需要获取OD窗口上的一些信息，想通过OD本身右键菜单中的复制来实现，运行副本OD，附加待调试的OD主程序，尝试下断 `WM_COMMAND`、`WM_NOTIFY`、`WM_MENUCOMMAND` 都没能断下来，请知道的朋友指点下方向，谢谢。

**问题已解决：**

经过自己的调试跟踪，发现只需调用OD中的两处函数，即可达到右键菜单复制的目的，我需要的是右边的注释，所以获取后，进行了一些处理，VC6.0实现函数如下：

```
// 获取当前命令行的注释
// uCurEip 需获取行的EIP地址
// uNextEip 下条指令的EIP，通过上条指令的EIP+指令长度获得
// szCmt 输出缓冲
// 返回注释的长度
int GetCmdComment(ULONG uCurEip, ULONG uNextEip, char * szCmt)
{
    char buf[1024]={0};
    ULONG uDataAddr = uBaseAddr + 0x000CD6A8;        // uBaseAddr OD基址，我用的是全局变量，
    ULONG uGetCmtProc1 = uBaseAddr + 0x00046618;     // 其它位置获取的，结果类似0x400000
    ULONG uGetCmtProc2 = uBaseAddr + 0x00054068;
    char *pAsm = NULL, *pCmt = NULL;

    _asm
    {
        pushad
        pushfd
        push uNextEip
        push uCurEip
        push uDataAddr
        call uGetCmtProc1
        mov ebx, eax
        add esp, 0xC
        test ebx, ebx
        je end
        push ebx
        call uGetCmtProc2
        add esp, 0x4
        mov pAsm, ecx
        end:
        popfd
        popad
    }

    strcpy(szCmt, "\0");

    if (pAsm != NULL)
    {
        strcpy(buf, pAsm);
        pCmt = strchr(buf, '\r');
        if (pCmt != NULL)
            *pCmt = '\0';
        pCmt = strchr(buf, '\n');
        if (pCmt != NULL)
            *pCmt = '\0';
        pCmt = strrchr(buf, ';');
        if (pCmt != NULL)
        {
            while (*pCmt==';' || *pCmt==' ')
                *pCmt ++;
            strcpy(szCmt, pCmt);
        }
    }

    return strlen(szCmt);
}
```
