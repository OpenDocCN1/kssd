# 解题过程
1. ssh 连接
```
ssh fd@pwnable.kr -p2222
```
![](upload/attach/202101/760268\_QJZQDQN6QQCKXRW.png)
2. 查看当前文件列表
```
ls -al
```
![](upload/attach/202101/760268\_T2YS5Y2YV7YGHQ9.png)
发现 flag 文件，但 fd 用户没有该文件的读权限
3. 查看 fd.c 文件
```
cat fd.c
```
![](upload/attach/202101/760268\_TMGVY9J6X2Z6M2C.png)
我们的目标是执行'system("/bin/cat flag");'这一语句，所以'strcmp("LETMEWIN\n",buf)==0'
所以 buf == "LETMEWIN\n"
所以 read(fd, buf, 32);应完成对 buf 的赋值
所以 fd == 0；
- 注
- fd == 0为标准输入
- fd == 1为标准输出
- fd == 2为标准错误输出
所以 argv[1] == 1234H 即 4660D
4. 执行 fd 程序，获得flag
```
输入 ./fd 4660 回车后输入 LETMEWIN 获得flag:
mommy! I think I know what a file descriptor is!!
```
![](upload/attach/202101/760268\_3WGY7AZJFKUAVVC.png)
