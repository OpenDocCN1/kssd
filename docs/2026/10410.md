# [原创]VC/MFC中翻页控件实现

偶尔有时候需要用到翻页控件，就琢磨着写了一个，用一个dlg作为父窗口，从CButton派生一个CMyButton按钮作为翻页中的一项，有多少页就动态创建多少个按钮，处理一下按钮之间的逻辑关系遇到>>的时候就显示后续页，遇到<<的时候就显示前面的页。。。。。
