## 替换linker
最重要的问题，需要重启手机替代的linker才会生效。
```
adb push linker64 /data/local/tmp
adb push linker /data/local/tmp
chmod +x /data/local/tmp/linker\*
mount -o rw,remount /
cp /data/local/tmp/linker\* /system/bin/ -rf
```
