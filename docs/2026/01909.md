SYSTEM MECHANIC 3.5的注册码。
程序用aspack压缩过。
用trw2000载入，选enter code
name: backboy
code: 78787878
设断点bpx 0137:004943c9
F5(enter)
ok(enter)
d eax(enter)
相关段如下  0137：00494388 push eax  D EAX 可见正确注册码 D EDX 可见

                  输入的假码
            0137: 0049439a pop  eax
            0137: 0049439b call 00403f58
  此处进行注册码比对
            0137: 004943a0 jnz 004943a7
  此处一跳就..
此处得出的注册码与注册机给出的不同，但都能用。
一个可用的注册码如下：
NAME:backboy
CODE:90919-PR845-7747173554
程序将注册名及注册码保存在注册表的HKEY\_CURRENT\_USER\Software\iolo\System Mechanic下。
