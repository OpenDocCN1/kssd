## 绕过手段

思路比较简单，替换整条证书链为一个正常设备的证书链即可：

1. 可以通过 Hook Java 层代码。
2. 编写一个 Magisk 插件：<mark class="encrypted">fb2K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6V1L8$3!0E0i4K6u0V1L8h3q4F1i4K6u0r3j5Y4W2H3j5i4y4K6K9$3g2&6j5i4c8@1k6i4y4@1j5i4c8A6L8$3^5`.</mark>

Hook Java 层已经比较熟练了。由于后续期望强化对异常设备的检测，而大多数对抗检测的工具又是通过 Magisk 插件实现的，因此打算用 Magisk 插件实现一遍。

参考 <mark class="encrypted">3f8K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6U0K9r3W2@1k6i4u0G2L8h3q4F1i4K6u0r3f1r3I4S2P5f1W2F1N6r3g2Y4M7X3W2@1P5f1k6A6P5l9`.`.</mark> 大佬编写的插件进行学习，对大佬进行拙劣的模仿。
