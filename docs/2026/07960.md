
# [讨论]VT的那些事儿续篇

Windows7 Windows8下面VT的各种蓝屏，卡死，failed错误

## 1. `bugcheck 0x7F 0x08`

初始化前，看看是否有HV，HV是万恶的~~

将`Cpuid`处理`eax=1`的`ecx`的31位 `== 1` 就是有HV了，然后还是不要继续VT了~

另外就是在HV不工作的时候`vmexit`里处理`cpuid`的`EAX==1`,`ECX`的31位必须clear给0，否则会导致某些2B的驱动以为hv了，然后调用不可思议的`WDMSR`

## 2. `bugcheck 0x7F 0x0D`

`GUEST_XX_LIMIT`和`AccessRight`的问题

大多数情况把`GDT`,`IDT`,`TR`之外的`Limit`都`0xFFFFFFFF`，至于`AccessRight`看情况就好了

初始化时`guest_dr7`写成`0x400`，这是个有趣的问题，很少见~
