# [原创]利用stackpivot和ROP绕过ASLR+DEP学习笔记

**概念**
非栈溢出的情况下往往难以在栈上构造ROP链来绕过ASLR+DEP，而使用stackpivot技术可以解决这个问题，所谓stackpivot就是利用类似xchg eax,esp的指令使esp指向任意地址，配合C++的一些特性容易将esp指向自己的ROP链。
**实例**
CVE 2011-2462在rt3d+14CAAD执行任意代码

```
mov     eax, [ecx]  ; 取对象的虚函数表指针，而这个指针指向被释放的堆，记[ecx] = lpVtbl
push    1
push    0
push    0EBh
push    ecx
call    dword ptr [eax+1Ch]  ; 调用虚函数导致任意代码执行
test    eax, eax
setnz   al
retn
```


经过堆喷后可使lpVtbl如下：

```
lpVtbl+1C  4A8453C3  icucnv36.4A8453C3
...
lpVtbl+3C  0C0C0C0C
...
```
