
# 盲打之友V2.5破解（包括注册算法） (11千字)

## 盲打之友V2.5破解过程

**工具：** `trw2000`、`Hview`、`W32dasm 8.93黄金中文版`
**破解：** crackjack[BCG]

未注册版本的限制：
1. 只能练习2分钟。
2. 只能运行三次，超过三次必须重新启动系统才能继续使用。

我们仍然是用两种方法来注册它：爆破和注册机。
