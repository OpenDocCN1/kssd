# [调查][危险]github下载的源码也会中标!

今天在github找了个源码,下载下来,习惯性的翻了下,感觉没啥毛病.
下载下来解压,火绒直接把\*.sln给干了.
仔细看了下,原来是文件名动了手脚.
研究一下后,我自己也搞了个大概的.
<a href="elink@0a0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6D9L8$3&6G2L8X3q4F1i4K6u0r3k6X3W2D9k6h3&6S2L8h3g2Q4y4h3k6K6M7r3!0G2k6X3g2J5">链接描述</a>
下载解压后大概是这样的,如果是仔细伪装,把正常的\*.sln隐藏好
估计不少人会中招,直接打开 \*.sln.exe程序
![图片描述](upload/attach/202205/273885\_SSQYKFM6BHRNUZ6.png)
实现原理:
右键->重命名->全选->复制->新建一个txt文件->粘贴进去.
Notepadd++打开txt,用Hex方式查看
![图片描述](upload/attach/202205/273885\_MMTXTMZGV3VJFQ3.png)
也就这三个字符实现的.
这三个字符是啥东西我也不懂.
作用就是能把在他后面的字符放到它前面去
这样就达到欺骗的目的.
以后下载源码还是小心点吧
zip下载,winrar打开,也可以看到是否异常
或者解压后,文件夹类型那看到一眼在打开吧
