# 3. 利用思路
1. 伪造freak chunk
我们可以通过edit\_heap函数覆盖fastbin中的fd指针，使其指向bss段，伪造一个chunk。
2. 修改heaparray元素使其指向free@got
因为heaparray数组存放的是chunk的数据部分，那我们可以通过修改伪造的freak chunk的数据部分，进而修改heaparray数组的元素值，比如把array[0]的内容（本来是指向chunk0的数据部分）指向free@got。
3. 使free["got"]的内容指向system@plt
我们通过edit\_heap函数可以修改array[0]的内容，也就是free@got的内容，把这个内容改成system@plt
4. 执行system("/bin/sh\x00")
我们可以设置chunk1的数据部分为/bin/sh\x00，所以在free(chunk1)时，就变成了system("/bin/sh\x00")，最终得到flag


首先我们先申请两个chunk
![图片描述](upload/attach/202511/1002337\_335NERP58KYUGMG.webp)

接着free chunk1，chunk1会被放入fastbin中，可以看到此时这个chunk的fd指针是null
![图片描述](upload/attach/202511/1002337\_4VVWASP2DS4TKJE.webp)
```
payload = b'a'\*0x68 + p64(0x71) + p64(0x6020ad)
fill(0,payload)
```
接着我们就要覆盖chunk1的fd指针，使其指向bss段，为什么fd指针要设为0x6020ad呢，我们伪造chunk的目的是为了能够修改heaparray的数组元素，那伪造的chunk自然是要在heaparray数组的低地址方向了，可以看到这里magic和heaparray两个变量的地址相差0x20
![图片描述](upload/attach/202511/1002337\_CT46WSSN32F7HJJ.webp)
因为fastbin会对chunk的size检查，我们可以把0x7f当成chunk的size，也就是0x60大小，能够覆盖heaparray的内容
![图片描述](upload/attach/202511/1002337\_S4A8CQ5KU87KUFM.webp)
这个地址是0x6020b5，但是fd指针指向的是chunk的首地址，因此还要减去0x8，也就得到了0x6020ad
![图片描述](upload/attach/202511/1002337\_33JHRXA3PJ3N3TP.webp)
把fd指针指向了我们想要的地址
![图片描述](upload/attach/202511/1002337\_SJH45TCHADFSRBB.webp)

```
allocate(0x60,b'/bin/sh\x00')

allocate(0x60,payload)
```
接着我们两个malloc，分别得到chunk1和freak chunk，数组下标分别是1和2，使得cunk1的内容是/bin/sh\x00，再修改freak chunk使得heaparray[0]的内容是free@got

接着我们就要覆盖chunk1的fd指针，使其指向bss段，为什么fd指针要设为0x6020ad呢，我们伪造chunk的目的是为了能够修改heaparray的数组元素，那伪造的chunk自然是要在heaparray数组的低地址方向了，可以看到这里magic和heaparray两个变量的地址相差0x20

这个地址是0x6020b5，但是fd指针指向的是chunk的首地址，因此还要减去0x8，也就得到了0x6020ad
