# [原创] #18周年#三年

时光荏苒，三年就这么不知不觉的过去了，三年光阴说长不长说短不短，但足以改变很多很多事情，也可以让我忘记很多事情，就连我为什么会学网络安全也差不多忘了。我只隐约记得，小时候家里没电脑，自己为了改掉一指禅的毛病用纸板把26键画上去，然后练习，但终究没那感觉，就对电脑产生了心结。

高中毕业，我就用打暑假工攒的钱买了台联想笔记本电脑。在打暑假工的空闲时间里，我觉得五笔打字很快，就把五笔口诀背熟了。我想成为黑客的这个想法的萌生，是在想查公司信息时产生的，要怪就怪那家公司时台湾的吧。那家公司用百度搜索引擎，压根就查不到什么信息，听一个人说，台湾的公司要翻墙才能查到相关信息，脑热的我就苦练翻墙。有一天的某个时刻，我灵光一闪，想为什么进不了公司内网，问及网友说这种事只有黑客才做得了。我不知道什么是黑客，在我印象里只有电视上才出现过黑客，只觉得那是对计算机操作非常厉害的人。我去图书管，书店找各种资料，那会这种资料真少，书上介绍的论坛要么似昨日黄花，要么名存实亡。时间总是匆匆的，临走之际我顺便把公司一IP抄下来了，还到卖电脑的店铺上询问什么计算机语言容易学，说PHP易学。那会不知道什么是PHP，也不知道什么是计算机语言。

专业我自己选择的是电子商务，我自己自作主张选择的，只觉得学费便宜。我爸爸觉得电商出来找不到工作，强烈要求我学建筑工程管理，还跟招生办的老师说了。我妥协地换了专业，这是想来后悔的一件事，可能我压根就没想到计算机专业。我记得军训那会，别人在草地上休息，旁边的我一人在那看PHP的电子版书籍，虽然看不懂，但我是倔强的，活生生地把那本电子书籍啃完了，就这样我从什么都不懂到学会下载phpstorm仿写代码，没人教，就这样按照书上的写。我还用节约下来的生活费买了一本apache和php的纸质书籍，只能说晦涩难懂。我过年那会都没出去玩，在家看面向对象的视频，现在看那笔记觉得蠢。我一朋友是程序员，一培训机构毕业的，会java，就跟他玩了一段时间的java，还接触了c，c#，c++，js，他只跟我说java好，其余的都是我都是自学，加各种群找资料。曾经我也想过去计算机班上跟他们一起学，我这么想也去做了，虽然进了他们班群，但后来退了，又回归自学状态。想起为什么退群，一来那会状态不好，二来自己不想放弃建筑，我问老师，说做互联网不好，施工好。我想自己不是科班生出身，天赋欠佳，出来也很大概率不做这行。

这种矛盾心理，一直在心里彳亍，大二了还在持续。我在网上看各种黑客文章也腻了，觉得心里乱七八糟的，对网络安全技术没有一个系统的认识，我也在各种地方遇到些小白问各种问题，有人问什么是黑客，我说是信仰，是对未知探索的精神。有人问怎么学黑客，我对他说，学编程，买书看，速成?脚本小子吧！有人说学网络安全从kali linux学起，实用。我插嘴说要知道原理，《深入理解计算机系统》这本书要看。培养兴趣可以看看社会工程学那一系列的书，那种书有许多小故事和相关知识。我自己在实习期买了kali linux渗透测试，黑客秘笈来看，觉得黑客秘笈告诉的是渗透思路，kali linux告诉的是一些渗透标准。比赛是学习的一种测试，虽然我什么都不太懂，但还是硬着头皮去参加了比赛。其实，我们学校专业技能比赛没有，就想体验一下那种参加大赛的感觉，可是连初赛都没通过，有点忍俊不禁。

现在准备去工地实习，学习BIM，有可能会接触BIM二次开发，我也不知道BIM是不是泡沫，都说BIM好，那就去认真地学呗。现在的生活俨然已离不开互联网，无论你是否抗拒，历史总朝着应走的路走，所以网络安全是不放弃的。此后计划，去WIKI做咨询，跟着大神做一些项目，多到github看一些项目，我想如果大一那会有此觉悟多好，可人生是一旦运行就无法改BUG的程序。我虽非大牛，没什么牛逼的经历，但也想写一稿以支持看雪，祝看雪越办越好。

如果对于明天没有要求，牵牵手就像旅游该多好，可是人生就是一次渗透测试，只不过时间是黑客，而你是系统，攻防对抗时间啊远不止三年。
