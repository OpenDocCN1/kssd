### 注入代码

![](https://bbs.kanxue.com/upload/attach/201404/48080_4sxt4rl7jgnv78p.png)

但是驱动中使用`NtQueueApcThread`，由于Zw系列函数不提供则个接口，所以需要自己写一下~

因为需求只需要32位系统所以我这里直接用了`int 0x2e`来调用。![](https://bbs.kanxue.com/view/img/face/50.gif)

```
NTSTATUS NTAPI MyNtQueueApcThread(
	__in HANDLE     ThreadHandle,
	__in PVOID      ApcRoutine,
	__in_opt PVOID  ApcArgument1,
	__in_opt PVOID  ApcArgument2,
	__in_opt PVOID  ApcArgument3
)
{
	NTSTATUS ns;
	__asm
	{
		push eax
		push ApcArgument3
		push ApcArgument2
		push ApcArgument1
		push ApcRoutine
		push ThreadHandle
		mov eax,ZwQueueApcThreadId
		mov edx,esp
		int 0x2e
		mov ns,eax
		pop eax
	}
	return ns;
}
```

## 获取 APC 分发地址

至于注入APC需要的三个参数中第一个参数，因为获取比较麻烦，直接使用符号表来解决。具体代码参看附件了~~~

```
PVOID getApcDispatchAddress()
{
	PVOID lpRet=NULL;
	if(GetModuleHandleA("kernelbase.dll"))
	{
		//高版本系统
		lpRet = SymGetProcAddress(L"ntdll.dll",L"RtlDispatchAPC");
	}
	else
	{
		lpRet = SymGetProcAddress(L"kernel32.dll",L"BaseDispatchAPC");
	}
	printf("%p",lpRet);
	return lpRet;
}
```
