# [IDA使用技巧] #166: 处理 "函数过大 "问题

偶尔您可能会遇到以下错误信息：

![](https://bbs.kanxue.com/upload/attach/202312/767964_WXK47UXV265XBG8.webp)

为确保反编译速度保持在可接受的水平，并且不会阻塞 IDA（避免处理数据过大卡死其它功能无法使用等现象），特别是在使用批量反编译时，反编译器默认拒绝反编译超过 64 千字节（kilobytes）（0x10000 字节）的函数。但在这里，我们有一个大 3 倍的函数：

![](https://bbs.kanxue.com/upload/attach/202312/767964_SCCN26PGKNP876T.webp)

在这种情况下，您可以手动增加大小，以迫使反编译器尝试反编译函数。限制可以临时或永久增加。

要只更改当前数据库的限制，请打开反编译器选项 (Edit > Plugins > Hex-Rays Decompiler, Options):

![](https://bbs.kanxue.com/upload/attach/202312/767964_6UKQS3W999W3DDA.webp)

然后在Analysis Options 3中更改设置：

![](https://bbs.kanxue.com/upload/attach/202312/767964_DZFS454PK69GGZT.webp)

要更改所有新数据库的默认值，请编辑 hexrays.cfg 中的参数 MAX\_FUNCSIZE。

![](https://bbs.kanxue.com/upload/attach/202312/767964_J89ZCG2JHQ9PMGD.webp)

请注意，配置文件中的设置仅适用于新数据库；对于现有数据库，请使用第一种方法。

提示：与其编辑 IDA 安装目录的 hexrays.cfg文件，不如在[用户目录](https://bbs.kanxue.com/elink@811K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5k6i4S2Q4x3X3c8J5j5i4W2K6i4K6u0W2j5$3!0E0i4K6u0r3j5X3I4G2k6#2)9J5c8X3W2Y4L8%4u0K6i4K6u0V1N6r3W2H3i4K6u0V1L8$3k6Q4x3X3c8@1K9r3g2Q4x3X3c8%4k6h3g2C8i4K6u0V1x3K6y4Q4x3X3c8A6k6r3q4K6i4K6u0V1N6i4y4W2M7W2)9J5k6r3c8A6M7X3g2U0N6r3!0J5P5g2)9J5k6r3W2V1j5i4g2K6M7W2)9J5c8R3`.`.)中创建一个新文件，其中只包含更改后的设置。这样，即使您升级了 IDA 版本，这些设置也会保持不变。

```
在 Windows: %APPDATA%/Hex-Rays/IDA Pro
在 Linux 和Mac: $HOME/.idapro
```
