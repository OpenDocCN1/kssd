
# [分享]kali2021-lanmp安装误区

当时在kali上安装lanmp耽误了不少时间，实际上下载一个新的kali2021可以直接避免很多麻烦，kali2021中已经为用户提前安装好了Nginx、apache2、PHP、Mysql。用户只需要在使用的时候配置一下就可以了。我在安装Kali2021之后，不停地骂自己前面做了不少无用功，这里就把怎么配置，怎么使用给大家分享一下。所有的操作都在root权限下进行，kali现在无法直接登陆root，怎样切换root自行查找。

## 1.Apache2配置

在`/etc`下有安装好的apache2，直接输入指令“`/etc/init.d/apache2 start`”即可启动，也可以输入：“`/etc/init.d/apache2 status`”查看状态

![](upload/attach/202112/922850_EHB97YYNMGPV6PN.jpg)

之后打开浏览器输入“`localhost`”查看结果就行

![](upload/attach/202112/922850_XMZT4WR4BSRZBSZ.jpg)

## 2.PHP配置

PHP是kali已经安装好的，直接在etc下键入“`php -v`”即可

![](upload/attach/202112/922850_B8E6NW5JWT5GRVY.jpg)

## 3.Mysql配置

这里需要对特权用户进行初始化，具体操作在`/etc/mysql`下键入“`mysql_secure_installation`”,之后除了修改root密码选项，其他一路Y到底

![](upload/attach/202112/922850_XFVTTADZA6T5GY3.jpg)

在特权初始化之后重启服务：“`systemctl restart mysql`”
