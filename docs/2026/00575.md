
# [原创]winxp+vpc2007+win2003sp1+windbg

以下是学习 WRK 初期整理的关于运行环境的配置。

## 一、安装 DVD-Windows

1. 解压并用虚拟镜像打开。
2. 运行 `WRK-CRK` 中的 `wrkinstall.bat`（推荐的安装方式，一些参数配置较方便）。在 `C:\WRK-v1.2` 中会默认安装 WRK 的源文件。
3. 安装 `WRK-CRK\Virtual PC 2007` 中的 Virtual PC 2007（最好默认安装）。按向导创建一个虚拟机。
4. 安装 `WRK-CRK\WinDbg` 中的 WinDbg（最好默认安装）。

## 二、配置 Virtual PC 2007 并运行 Windows 2003 SP1

1. 开始 → 所有程序 → Microsoft Virtual PC。
2. 在 Settings 中选择 Hard Disk 1 → Virtual hard disk file → Browse，设置虚拟硬盘文件为 `C:\WRK-v1.2\Win2k3SP1 Image\Win2k3 SP1 WRK Hard Disk.vhd`。
3. 将 COM1 设置为 Named Pipe：`\\.\pipe\debug`。
4. 单击 OK，退出 Settings。
5. 回到 Virtual PC Console，单击 Start，在 Command Prompt 中选择 Windows 2003 SP1 Standard。此时虚拟机上启动了 Windows 2003 SP1。

## 三、重新编译 WRK

1. 通过主机与虚拟机之间的共享磁盘 C 盘，将主机上的 `C:\WRK-v1.2` 拷贝到虚拟机上的 C 盘中。
2. 在虚拟机上，可以修改 `C:\WRK-v1.2\base\ntos` 中的相应内核程序。
3. 打开“开始”→“所有程序”→“附件”→“命令提示符”。设置编译环境文件路径并切换目录，然后执行以下命令，编译开始，大约需要几分钟时间：

   ```
   path \wrk-v1.2\tools\x86;%path%
   cd c:\WRK-v1.2\base\ntos
   nmake x86=
   ```

4. 编译完后，在 `C:\WRK-v1.2\base\ntos\BUILD\EXE` 下会生成 `wrkx86.exe` 和 `wrkx86.pdb`。将 `wrkx86.exe` 拷贝到虚拟机的 `C:\WINDOWS\system32\` 下，将 `wrkx86.pdb` 拷贝到主机的符号文件目录下。可能会有重名文件，可以重新命名，但在修改 `boot.ini` 时，要保持一致。
5. 将主机 `C:\WRK-v1.2\WS03SP1HALS` 下的 HAL 文件复制到虚拟机 `C:\WINDOWS\system32` 下。
6. 通过下述设置 `boot.ini`，可以重启 Windows 2003 SP1，运行新编译的内核。

## 四、配置 WinDbg 并调试内核

1. 在主机上打开命令提示符，切换到 `C:\Program Files\Debugging Tools for Windows\`。
2. 执行 `windbg.exe -k com:port=\\.\pipe\debug,pipe,resets=0,reconnect -y C:\Symbols\wrk`（`-y` 用于设置符号文件路径，即第三节第 4 点提到的符号文件），会打开 WinDbg 窗口，显示正在连接。

   （第 1、2 步也可以用 WinDbg 图形界面完成：打开 `File` → `Symbol Source Path` 设置符号表位置；然后 `File` → `Kernel Debug` → `COM`，设置 COM 为 `\\.\pipe\debug`，选中 `Pipe` 和 `Reconnect`，`resets=0`。）

3. 打开虚拟机，运行 Windows 2003 SP1，选择 Debugger Enabled 的启动项。然后 WinDbg 就会显示连接成功，即可进行内核调试。

## 五、在虚拟机上设置 boot.ini

1. 右键单击“My Computer”→“Properties”→“System Properties”→“Advanced”→“Startup and Recovery”→“Settings”→“Startup and Recovery”→“Edit”，在记事本中打开 `boot.ini`。
2. 编辑 `boot.ini`：在 operating system 一栏最后添加以下内容：

   ```
   multi(0)disk(0)rdisk(0)partition(1)\WINDOWS="Windows Server 2003, Enterprise" /fastdetect/DEBUG/DEBUGPORT=COM2/BAUDRATE=115200/kernel=wrkx86.exe/hal=halmacpi.dll
   ```

3. 保存并确定。

## 注

- 出现问题：运行 `.bat` 文件时出现“没有找到 `MSVCP71.dll`，因此这个应用程序未能启动。重新安装应用程序可能会修复此问题。”只需下载 `MSVCP71.dll` 放入 `windows(winnt)\system32` 下。
- 修改内核代码时，要修改文件内容，不可直接复制（copy）。否则编译系统不认为它是修改过的，不予编译。
