# [原创]发个桌面小工具（有码）

本人初学，入门级别=。=
功能说明，看了就知道代码涉及了什么。。。。
WIN + NUMPAD 1~9    切换虚拟桌面.
CTRL+ NUMPAD 1~9    关闭对应虚拟桌面.
WIN + NUMPAD 0      切换回原始桌面.
CTRL+ NUMPAD 0      关闭全部虚拟桌面.
(虚拟桌面功能不支持Vista,2008,Win7,Win8.)
------------------------------------------
CTRL+ NUMPAD +      增大音量.
CTRL+ NUMPAD -      减少音量.
CTRL+ NUMPAD \*      切换 静音/非静音.
------------------------------------------
Alt + NUMPAD 0~9    切换 0~9级暗度.
Alt + NUMPAD +      切换置顶模式.
     (0.顶级窗口不受影响,方便看电影、
             游戏等日常娱乐(默认).
      1.总是置顶,看电子书等适用.)
Alt + NUMPAD \*      刷新屏幕.
Alt + NUMPAD -      禁用/启用 屏幕亮度调节.
------------------------------------------
CTRL+ NUMPAD .      选择背景.
Alt + NUMPAD .      切换背景模式.
------------------------------------------
WIN + NUMPAD \*      设置/取消 开机自启动.
CTRL+ NUMPAD /      重载程序.
Alt + NUMPAD /      退出.

热键都是精心设计的哈
ALT主要是切换和屏幕相关
CTRL是控制功能
WIN主要是虚拟桌面
CTRL+ NUMPAD \*      切换 静音/非静音.（\*像小喇叭形状
Alt + NUMPAD \*      刷新（\*）屏幕.
Alt + NUMPAD -      禁用/启用 屏幕亮度调节.（- 是最小化按钮）
CTRL+ NUMPAD .      选择背景.（... 选择文件）
Alt + NUMPAD /      退出（谐音除 / ）.
