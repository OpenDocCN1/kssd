
# [原创]工程文件清除器

工具：工程文件清除器

描述：

可以通过资源路径获得路径，也可拖拽文件或文件夹获得路径，然后匹配要删除的文件扩展名，获取待删除的文件信息，删除文件（不删除文件夹），或删除文件和文件夹（文件夹中无文件时，可删除）。

在待删除文件信息中可查看找到的文件信息，如文件总数，大小，可删除大小，个数。

在删除文件的信息中可查看删除的文件或文件夹信息，如删除的文件个数，大小。

注：

一定确认获取到路径，再进行删除操作。
