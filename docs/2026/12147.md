# [分享]驱动模拟键鼠32位和64位，含代码，WIN10版

经过修改两位论坛中网友的代码已经实现驱动模拟键鼠了，并支持64位。上一版的是WIN7版，现在是WIN10版的。并通过测试。
这里感谢 孤山散人 和 asrn。此驱动代码是修改至他们在论坛贡献的代码，我只是做了一些简单修改，完全免费

我发的附件中有驱动和测试程序

驱动目录下面Debug和Release是32位的驱动，X64\Debug和X64\Release下的是64位驱动。

测试的时候拷贝到DLL的例子里面测试。并以管理员模式运行。

本例子是32位的lazarus写的，DLL也一样，在64位系统下面可以直接调用驱动。不需要修改，除非你完全需要64位的就自己重新编译吧。

最后要在64位系统下的驱动不开机重启进入禁用签名模式可以用下面TXT文件中的命令代码，管理员模式运行，重启后生效。

但是会在WIN10右下角显示 “测试模式"
