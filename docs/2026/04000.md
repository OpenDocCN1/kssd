## 经验总结

1. 注册码位数必须大于用户名位数

2. 循环判断用户名在字符表的位置，即`esi*2+494E20`，字符表按照`a * b * c * d * f *....`排列，`*`的位置是乱序字符，根据用户名的位置数找到乱序字符，即`esi*2+494E21`的位置，`esi`等于顺序排列字符的位置（如果用户名字符>`34h`（102）即字符表中Z的位置就填充字母P，例如用户名：`~！@#￥%……&*（）~！@#￥`，注册码：`PPPPPPPPPPPPPPPP` 就能注册成功，感谢一衰烟雨鹭影依凌版主提醒。）

3. 如果用户名不等于16位，把填充字符表从左开始补够16位

4. 比较注册码是否和算出来的注册码比较

一组可用的注册码：

```text
Name:thdzhqg
Registration Code:PkIFkdMLdQsBcmpJ
```
