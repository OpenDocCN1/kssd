### 总结算法

1. `KEY1 = rev(lwr(key))`，`key`长度6，将输入转小写，逆序
2. 反调试成功时`KEY1[0]+=1`, 其他`KEY1[i]+=i`;
3. `KEY2 = DrvMd5(KEY1)`，驱动`MD5`计算
4. `KEY3 = Md5(KEY2)`, 应用层`MD5`计算
5. `KEY4 = KEY3[2:12]`，取第3位开始的10个字符
6. `KEY4 == '888aeda4ab'`
