# 逆向流程
新建两个文件夹，`cs\_bin`里面放原版cs，`cs\_src`放之后反编译过后的cs，再将`java-decompiler.jar`放到根目录。目录结构如下：
```bash
cobaltstrike
├─cs\_bin
│ └─ cobaltstrike.jar
└─cs\_src
└─java-decompiler.jar
```
切换 java 版本到 java 11：
```bash
sudo update-alternatives --config java
```
在根目录输入以下命令将 `cs\_bin/cobaltstrike.jar` 进行反编译，反编译后的文件放到`cs\_src`文件夹中：
```bash
java -cp java-decompiler.jar org.jetbrains.java.decompiler.main.decompiler.ConsoleDecompiler -dgs=true cs\_bin/cobaltstrike.jar cs\_src/
```
