
# spycop5.5简要注册分析

对象：spycop V5.5

下载地址：http://spycop.com/spycop-free-product.htm

软件说明：SpyCop能扫瞄电脑中隐藏起来的病毒，比如特落依这种木马病毒。而电脑使用的屏幕、密码以及Email也是SpyCop的保护对象。

## 第一步：修复文件损坏

程序运行后会提示有文件损坏，所以首先得修复一下才行。使用`rtcMsgBox`下断，可以往上找到这里。

```asm
004311AA  MOV DWORD PTR SS:[EBP-4],0A2
004311B1  MOVSX ECX,WORD PTR SS:[EBP-90]
004311B8  TEST ECX,ECX
004311BA  JNZ SHORT aa.004311C1  ==>这里判断，把JNZ改为JMP就可以了
004311BC  JMP aa.00432227  ==>这里就跳往提示文件损坏
004311C1  MOV DWORD PTR SS:[EBP-4],0A6
```

## 第二步：跟踪注册码

观察一下安装目录，找到文件`reginfo.dat`，打开一看，如下内容：

```text

0
0
```

一看就知道是注册信息的文件。由于输入注册信息时正确时才写入的，现在手工填写：

```text
lordor

```
