
# [原创]修改微信余额显示

## 最终成果演示

![](https://bbs.kanxue.com/upload/attach/201809/825829_73J3VP68NC6JUZ6.png)

## 所需工具

1. `apktool`
2. `adb`
3. `FileLocator`
4. `Notepad++`
5. `dexfix`

## 步骤

1. 从网上下载微信`apk`文件

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_RNTNDAX7N4DQER9.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_YUT8EXJKFV9W4S8.png)

   由于我的电脑上安装了MoMo模拟器（打第五人格用的），所以图标会比较奇怪，不过这个无所谓。

2. 使用`apktool`反编译`apk`文件

   ```
   apktool d weixin_1320.apk -o weixin_1320
   ```

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_A3529S22GEQ665Y.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_NQE4AE2CZTYRVVT.png)

3. 打开`weixin_1320/res/values`中的`public.xml`和`strings.xml`

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_EWJAGA4RUQM688B.png)

4. 观察一下“我的零钱”页面，可以看到上面显示字符串“我的零钱”、“充值”、“提现”、“常见问题”。

   这个数字是我修改后的（我只是个poor guy）。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_N282Q5V4SP9GK8S.png)

   在`strings.xml`中查找“我的零钱”、“充值”、“提现”、“常见问题”并收集相关信息。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_PGTC8E4WXPN9ARM.png)

   可以看到，字符串的名称分别为`duu`、`dut`、`duq`、`dus`。

5. 使用`FileLocator Pro`搜索同时包含`duu`、`dut`、`duq`、`dus`的`xml`文件。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_AXPY8D3UCN52R5R.png)

   可以看到共7个`xml`文件同时包含`duu`、`dut`、`duq`、`dus`，由于只有`an8.xml`和`an9.xml`在`res/layout`文件夹中，所以只有`an8.xml`或`an9.xml`有可能是我的零钱`activity`的布局文件。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_TDUTVBTX8MWHRY6.png)

   之后会发现`an8.xml`中的`duu`是一个控件`id`，不是字符串`id`，所以排除`an8.xml`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_MTFPACDU6TNUZT5.png)

   在`an9.xml`中可以找到和我的零钱`activity`非常吻合的布局。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_3C5U2NH58K5XMHG.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_Q2RVKN3Y3X7V5BJ.png)

   所以可以肯定，`an9.xml`就是我的零钱`activity`的布局文件。

6. 我们要修改的是零钱的显示数字，而根据`an9.xml`的内容显示数字的控件则是：

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_REJZWU2X4CDVYHA.png)

   类型为`com.tencent.mm.wallet_core.ui.WalletTextView`，控件`id`为`dv3`。

7. 现在在`public.xml`找控件`id`为`dv3`的那一行。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_77GN9CGV27X6J4Q.png)

   ```
   <public type="id" name="dv3" id="0x7f101894" />
   ```

   然后用`FileLocator Pro`搜索`0x7f101894`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_9HUS5VBN5U45XRW.png)

   在`a$f.smali`文件中找到`0x7f101894`的变量名为`wallet_balance_total`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_2FP8SYM47METSBP.png)

   再用`FileLocator Pro`搜索`wallet_balance_total`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_YRCZWBD2GUMAS5M.png)

   打开`WalletBalanceManagerUI.smali`，找到`wallet_balance_total`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_54CZ394Q5CDJA4P.png)

   顺着`smali`代码向下看，会发现`wallet_balance_total`被赋值给了类成员`pan`，类型为`Landroid/widget/TextView;`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_B3ZPM3MM93B9KSP.png)

   可以肯定，`pan`就是控制着余额显示的`TextView`类型控件，每次对`pan`调用`setText`就会更新一次余额显示。

8. 似乎只要修改代码后重新编译就可以了，但一般不能这样做的，这样做可能会编译失败或者签名失败。

   （1）首先要看一下`WalletBalanceManagerUI.smali`文件的位置：

   ```
   D:\__projects__\__androidanalysis__\weixin_1320\smali_classes4\com\tencent\mm\plugin\wallet\balance\ui\WalletBalanceManagerUI.smali
   ```

   会发现`WalletBalanceManagerUI.smali`在`classes4`解析出的代码下。

   （2）回到源目录，将`weixin_1320.apk`的后缀`apk`改为`zip`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_EC8V3AK7QBKJJVV.png)

   （3）直接打开`weixin_1320.zip`（注意不要解压该文件），将里面的`classes4.dex`提取出来。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_BMVW382A4SBHTV6.png)

   （4）反编译`classes4.dex`到`classes4`文件夹。

   ```
   d2j-dex2smali classes4.dex -o classes4
   ```

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_Z374FWA68RT99DY.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_TK4MF7T3KX8VYXT.png)

   （5）进入`classes4`文件夹，并打开`classes4`文件夹内的`WalletBalanceManagerUI.smali`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_73FDQ8UWXQ2VEGT.png)

   （6）搜索每一个`pan`，然后在对成员变量`pan`进行`setText`之前的位置添加指定字符串的代码。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_BSVYFZHH9EVS98K.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_8PQVNGWFT5WUVBP.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_3ECHXVGSPJKDHDV.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_NB94RJVBAUFGF95.png)

   总共四处地方需要修改。

   （7）保存修改，然后编译`classes4`为`classes4.dex`，覆盖原`classes4.dex`文件。

   ```
   d2j-smali2dex classes4 -o classes4.dex
   ```

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_B3SK22VPPVNJPXB.png)

   （8）使用`dexfix`工具修复`classes4.dex`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_7QGQADX8BENTZW5.png)

   （9）复制`classes4.dex`，然后直接打开`weixin_1320.zip`文件，粘贴覆盖里面的`classes4.dex`文件。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_224GDN5HH8JQ3KJ.png)

   （10）再修改`weixin_1320.zip`的后缀为`apk`。

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_X4KFKR23S2Z63FW.png)

   （11）使用`signapk`工具对`weixin_1320.apk`签名为`weixinSigned.apk`。

   ```
   signapk weixin_1320.apk weixinSigned.apk
   ```

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_VP3D2M26MJ7H923.png)

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_SB25H68Y2PZZ9KC.png)

   （12）`adb`安装该`apk`文件。

   注意：安装之前需要将手机上的微信手动删除，否则即使用`adb install -r`进行覆盖安装也会失败。

   ```
   adb install -r weixinSigned.apk
   ```

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_99VMZ66QG5A3Y37.png)

9. 打开微信，重新登录，就会发现：

   ![](https://bbs.kanxue.com/upload/attach/201809/825829_UEH3TT4AE93WR3K.png)

10. 然而我的钱包页面依然显示真实的零钱余额，按照上述方法类推，也可以修改该显示。

    ![](https://bbs.kanxue.com/upload/attach/201809/825829_FXDVGS3KDHY2V68.png)
