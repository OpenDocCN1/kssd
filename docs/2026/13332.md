
# [原创]一个简单的PE病毒外壳

;主要集成了`Win32.poly.ShowTime2`，老罗的向PE文件中添加新节的办法

;编译的时候在`LINK`选项中要加上：`/section:.rew`使代码段可写

;编译器为`MASM32`

;`EnumDir`部分自己写的，功能为遍历当前目录以及子目录，故基本没有传染功能，如果改成全盘遍历就可以了

;没填加对加壳文件的识别，感染后运行会出错

;写的比较简单，而且复制的代码一部分有人注释过了，就不做详细注释了
