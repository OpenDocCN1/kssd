
# [原创][开源]EnumPE 枚举文件中的PNG

`EnumPE`是最近写的一个小工具。

它可以枚举出文件中包含的原始PNG数据。

包括PE文件中的非标准资源，不过目前只能操作PNG数据。

![](https://bbs.kanxue.com/upload/attach/201506/423318_m6g8z0x8s3q94l8.png)

下载: [`EnumPE.7z`](https://bbs.kanxue.com/attach-download-98548.htm)

源码中包含3中解决方案，一种是老外写的`std_image.c`。可以在`duilib`中找到（源码中未包含）。

另一种是使用`libpng`来转换内存中的PNG到`HBITMAP`。

不过以上两种都不理想，所以代码注释掉了。

目前是使用`CImage`来实现的。
