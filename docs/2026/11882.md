# [原创]小程序，调用7zip压缩文件

经常要用到，传上来存个档

-----------------------------
功能：
把target目录下的文件或者文件夹以默认密码加密

用法：
python main.py

其他说明:
1.如果target目录存在压缩文件，则不会压缩。
2.以zip为后缀的文件不会被压缩。
3.批量删除target目录下的zip文件，可以用ZIPdel.bat脚本。
4.在当前目录下打开命令行的技巧：Shift+右键->在此打开命令窗口
5.默认密码helloworld，可在脚本中修改。zip函数处。
