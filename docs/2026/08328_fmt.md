
# [原创] Windows 10 Android Studio 3.6.1 安装使用 OLLVM 8.0（Visual Studio 2019 编译）

GIT 下载 OLLVM 源码：3deK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6Z5k6i4u0G2K9h3#2K6i4K6u0r3L8$3u0X3N6i4y4U0j5i4c8G2M7W2)9J5c8Y4c8J5k6h3g2Q4x3V1k6D9L8s2k6E0i4K6u0V1z5q4)9J5k6e0l9。

CMake 下载：3cfK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6U0L8h3q4C8k6g2)9J5k6h3!0J5k6#2)9J5c8X3c8G2N6$3&6D9L8$3q4V1i4K6u0r3i4K6t1K6L8r3q4@1k6i4y4@1。

使用 CMake 生成 VS2019 工程。

使用 Visual Studio 2019 编译，大约 20-40 分钟（没仔细计数）。

编译成功后在构建目录的 `\Release\bin` 下拷贝 `clang++.exe`、`clang.exe`、`clang-format.exe`，替换掉 `E:\Android\android-sdk\ndk\20.1.5948944\toolchains\llvm\prebuilt\windows-x86_64\bin` 下的 `clang++.exe`、`clang.exe`、`clang-format.exe`。

在构建项目的时候会提示缺少头文件，补齐即可。以下是我缺少的头文件：

- `__stddef_max_align_t.h`
- `float.h`
- `stdarg.h`
- `stddef.h`

头文件的拷贝路径为 `Android-sdk\ndk\版本号(如20.1.5948944)\toolchains\llvm\prebuilt\windows-x86_64\sysroot\usr\include`。

在 `build.gradle` 中设置：

```
cppFlags "-mllvm -sub -mllvm -bcf -mllvm -fla"
```

至此基本可以在 Windows 10 Android Studio 3.6.1 中使用。
