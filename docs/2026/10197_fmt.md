
# [原创]为某傻妞做的玛雅谜题解密程序

某日和一傻妞去西单吃粉。大老远的去西单居然就是为了吃一碗粉。路上这傻妞BS本人的智商，然后拿出手机说要是帮她过了玛雅谜题中的一关就算我智商没问题，我看了一下这个游戏，完全的考验计算力。本人最痛恨的游戏种类之一。说实在的当时也实在懒的过了。

具体是一个`N * N`的矩阵。指定一个起点 和 一个终点。 中间的一些坐标有障碍物。 玩家需从起点开始划线把不是障碍物的格子都遍历一遍并到达终点。重点是不能重复遍历以走过的格子。

---

回家后确实心理有点不平衡，一个长期进行逻辑训练的CODER居然被一傻妞BS智商。所以顺手写了一个解谜程序，采用了深度优先的算法遍历图，但是由于是针对一个傻X游戏，所以并未涉及启发探索等。懒的写界面了。就直接用控制台表示了。
