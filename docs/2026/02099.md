已经是深夜4点多了，刚刚用了2个多小时下载了Dreamweaver Ultra Dev 4.0(29.8M)，顺便下载了几个其他程序，其中就有个ASP程序的设计软件，（身体也够大的，5M多，没办法，下载就是了），结果下载以后看到是没有注册的版本，所以就自己来算自己的注册号了。

这个软件的设计者也真“缺德”，本来我想用自己的中文名字“孙锋”来注册，可是，他不给我注册(在破解的过程中无法得到注册号)，没办法，只好用英文名字了(嘿嘿，其实也只是汉语拼音)，在破解过程中，我修改了几个`Company`名发现，注册算法程序对`Company`并不要求，只是根据输入的`Name`来计算，这是比较好搞定的。好了还是用我自己的老方法了-------用`TRW2000`跟踪拦截注册。

1、启动`TRW2000`

2、输入任意的注册姓名、公司名和注册号。(注意姓名不能是中文名字)

我在这里输入的是：

```text
Name:              sunfeng
Company:            sinling
Registeration Code: 121212
```

3、Ctrl+N呼叫出`TRW2000`。

4、执行`bpx hmemcpy`中断。

5、按F5返回程序领域，点击register。这时程序被`TRW2000`拦截。

6、执行`bd *`中断所有中断。

7、按F12共计16次。(为什么???因为如果我们按F12到17次时，程序会告诉注册错误，所以我们在拦截时只要按16次F12就可以了。)

8、在`TRW2000`的窗口中按F10，直到下面的位置：

```asm
0167:006540EC  CALL NEAR [EDX+A0]
0167:006540F2  FNCLEX
0167:006540F4  TEST EAX EAX
```

然后按F8进入`CALL`领域。

9、进入`CALL`领域后，按10几次F10到下面的位置：

```asm
0167:00654132  PUSH ECX    ------->；下 D ECX得到注册码：C3VuZmVuZw
0167:00654133  PUSH EDX
0167:00654134  CALL EDI
```

10、按`X`退出`TRW2000`领域，回到程序领域。退出`TRW2000`程序。

11、整理一下：

```text
Name:                    sunfeng
Company:                sinling
Registeration Code:      c3VuZmVuZw
```

12、再用得到的注册码重新注册，就可以看到你注册成功的界面了。

闲着没事，再算几个自己的注册号，得到下面的结果：`Company`任意

| Name | REgisteration Code |
| --- | --- |
| Sunfeng | U3VuZmVuZw |
| Sun Feng | U3VuIEZlbmc |

13、注册程序对注册表的操作是：

```text
[HKEY_CURRENT_USER\Software\VB and VBA Program Settings\EasyASP\General Options]
UserName:    sunfeng
Company:    sinling
Password:    c3VuZmVuZw
```

14、做个自己的注册机吧：用文本编辑软件把下面的内容存为`EsayASPreg.reg`即可。

```text
REGEDIT4

[HKEY_CURRENT_USER\Software\VB and VBA Program Settings\EasyASP\General Options]
"UserName"="sunfeng"
"Company"="sinling"
"Password"="c3VuZmVuZw"
```
