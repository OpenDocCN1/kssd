
# [原创] 如何调试 iOS 内核

iOS 内核调试不像 Windows 和 Linux 内核调试那么简易，操作起来比较麻烦。本文介绍如何进行 iOS 内核的调试。Word 版：[如何调试 iOS 内核.rar](https://bbs.kanxue.com/attach-download-74707.htm)

## 作者信息

作者：zhuliang

转载请保证文章完整并注明来源。

本文对如何调试 iOS（iPhone OS）内核进行简单介绍，讲述 iOS 内核调试的环境搭建、调试步骤等。

## iOS 内核简介

iOS 使用 XNU 内核。XNU for Mac 的代码可以从苹果官方下载到，当然不是最新版的。

XNU 内核由三个既相互独立又相互交互的组件构成，这三个组件是：Mach、BSD、IOKit。

## 硬件与软件准备

### 硬件准备

一台越狱的设备是必需的，建议使用 iPhone 4。

> 注：iPad 2 或 iPhone 4S 由于采用的是苹果 A5 的 CPU，其 BootROM 目前还没有公开漏洞，不能用红雪设置引导参数，不能使用它来调试。

还需要准备以下硬件：

- 内核调试数据线。该数据线含有 USB 转串口的电路，可以参考文献 1 自行焊接。本人制作好的调试线如下图所示。限于篇幅，这里不对如何制作调试线展开讨论。
- 一台电脑，可为台式机或笔记本，Mac 更佳。

![内核调试数据线](https://bbs.kanxue.com/upload/attach/201210/28365_3i9xzes47krbvj3.jpg)

### 软件准备

- 虚拟机 VMware
- Mac 操作系统，例如 Lion
- Xcode

## 环境搭建

### Mac 环境

由于 iOS 内核调试要在 Mac 操作系统平台下进行，所以首先要搭建 Mac 环境。最好使用真实的 Mac 机，也可以使用虚拟机。

本文为方便没有 Mac 的朋友，以虚拟机为例进行讲述；使用真实 Mac 机的朋友可根据具体情况随机应变。

具体步骤如下：

1. 在电脑上安装虚拟机软件，例如 VMware。
2. 在虚拟机里面安装 Mac 操作系统，例如 Lion。
3. 安装好 Mac 系统后，下载并安装 Xcode。

如果觉得这样太麻烦，也可以直接从电驴下载已经装好 Lion 的虚拟机。

### 安装 USB 转串口驱动

有了 Mac 环境后，在 Mac 操作系统里安装好 USB 转串口芯片的驱动程序。驱动安装完成后，可以使用以下命令查看串口是否被识别出来：

```bash
ls /dev/tty.usb*
```

识别出来后如下面的图所示。

然后下载本文附带的 `SerialKDPProxy_m.rar` 程序源代码。该源码是由 `Albert_liuwei` 根据参考文献 1 提供的 `SerialKDPProxy` 修改而来，特此声明。

执行 `make`：

```bash
make
```

将得到的 `SerialKDPProxy` 文件复制到 `/bin` 下，这样不用每次都切换到该目录才能执行：

```bash
cp SerialKDPProxy /bin
```

![串口识别结果](https://bbs.kanxue.com/upload/attach/201210/28365_peb5qiosf7a020l.png)

## 调试步骤

环境搭建完成后就可以进行调试了，主要有三个步骤。

### 一、运行串口代理程序

使用下面的命令行：

```bash
SerialKDPProxy /dev/tty.usbserial-A900c0xb
```

这里的 `tty.usbserial-A900c0xb` 要替换为系统上具体的设备名，即上文执行 `ls /dev/tty.usb*` 后得到的结果。

### 二、使用红雪设置引导参数

该步骤可以在物理主机 Windows 系统下进行，因为命令行涉及一个几百 MB 的文件，复制到虚拟机里比较麻烦。

可以在 Windows 下使用下面的命令行：

```bash
redsn0w.exe -i "D:\Apple\iPhone3,1_4.3.3_8J2_Restore.ipsw" -j -a "-v debug=0x09"
```

该命令输入完毕并回车后，红雪会让你按提示进入 DFU 模式。进入 DFU 后稍等一下，会看到小菠萝人在手机屏幕上。看不到的话，可能是进入 DFU 模式出错。

接下来切换到 Mac 环境工作。进入虚拟机环境之前，要确认 USB 转串口设备前面的钩已钩上，如下图所示：

![虚拟机 USB 设备设置](https://bbs.kanxue.com/upload/attach/201210/28365_apk36htlfqjt2xb.png)

### 三、使用 GDB 调试 iOS 内核

所用的命令行参数如下：

![GDB 调试命令行参数](https://bbs.kanxue.com/upload/attach/201210/28365_1kh7clp266zfyly.png)

```bash
gdb -arch armv7
(gdb) target remote-kdp
(gdb) attach 127.0.0.1
```

## Windows 环境下的配置

在 Windows 下面，串口从设备管理器里看出来是 `COM8`。代理程序使用以下命令行：

```bash
./SerialKDPProxy.exe /dev/com8
```

启动 GDB 的命令是：

```bash
./arm-apple-darwin-gdb.exe
```

其他的都是和 SE 的 PPT 上一样。

## 调试说明

至于具体怎么调试，熟悉 Linux 下使用 GDB 进行调试的朋友能相当熟练地进行调试，也可以参考本人的另一篇文章《iOS 如何利用 ARM 的 MMU 进行地址映射》。
