# 文字录入速度测试系统 V3.0 网络版
(1千字)

文字录入速度测试系统 V3.0 网络版
计算机文字录入练习、考试、比赛工作者的好帮手!
是一个集中英文打字练习、测试，五笔编码、拼音编码查询功能为一体的纯32位应用软件，她不局限于某一种输入法，您可以用任何输入法进行测试。她对于中英文各提供了三种测试方式供您选择，她还支持多用户管理，您可以在一台机器上建立若干个用户，分别进行测试，并分别查看各自的成绩；您还可以自由设定测试时间、用户权限、随时暂停测试；您也可以设定文章的载入点，这样您就可以每次都从同一地方开始测试了。

网络版：除了具有单机版的所有功能外，还增加了一些网络功能。她分为服务器版和工作站版，基于TCP/IP网络协议，可以通过局域网，甚至是Internet进行远程考核。工作站版的功能和单机版的功能基本一样，并且，当工作站版不联接服务器时，也可做单机版用；
