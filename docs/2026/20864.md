# [分享]有感而发---希望对新来的有所帮助

自我灭了第一个软件后，我一直很相信我是个cracker了，我是个逆向者。现在回头想想。可真是很傻很天真。
慢慢的接触的多了，才发现自己缺的东西太多。发现自己对软件一无所知。我接触计算机有很久了。从windows95出现就开始接触。实际上那时候的接触就是95红警。随后的n年内一直仅限于电脑游戏，到了03年才真正的可以使用计算机软件做一些东西。像flash，网页之类的...开是接触了编程.不过还是仅限于ActionScript，asp，php之类的小语言。由于所学专业的问题。那个也只是平时玩玩...学习生涯结束以后。就不在接触计算机了。
直到我注册看雪ID那天之前。我对计算机都只是感性认识。都一直相信计算机只是我们使用的工具而已(实际上也只是我们一个工具而已)，作为普通人我们没有必要像程序员一样精通计算机。即使我们使用的绿色软件。我也没有必要追究它的源头。
在注册看雪ID前后的那些日子里。我发现了linux。一个很有魅力的开源国度。我加入了magiclinux的大家庭，我甚至一度放弃使用windows了。linux下有任何我需要的软件。如果不是工作的原因。如果不是不小心来了看雪。windows我已经告别了...撇开工作原因不谈。看雪对我的吸引，是让我留在windows的最大原因。被我虐的第一软件是一个工程软件，由于是一个内部软件只有简单的序列号保护，不小心被我破解了。注册算法也很简单...当是那种窥的别人隐私的快感，相信每一个接触过的人都深有体会的。
我不鄙视那些为了破解而破解的人，也不鄙视那些为了利益不停的破解各种软件的破解者。因为每个人需要不同。尽管我很不赞同他们的做法.
我已经很久没有成功的破解过一个软件了。但是我任然快乐的每天坐在计算机前学习我的计算机知识。汇编，C语言，OPCODE，栈，堆。一点一点的学习着。COFF,ELF,一点一点的接触。我发现我没有当初的浮躁了。没有当时为了破解一个软件夜以继日的坐在电脑前读代码，绕暗桩的精神紧张了。
一天，我在看雪上看到许多和我当初一样的朋友们提的小问题。我已经不知道了，不能够回答了。我在反思我是不是退步了。难道是真的逆水行舟，不进则退？
后来我是想通了。技术在日新月异，追赶它我想是太难了，何况我的步伐远远不如别人快。到不如学习基础的，体验基础知识带来的那份快乐。看看基础，学习一下我还没有掌握的。回头再看那些新技术，搞不好，那些所谓的新技术就是变着味儿的玩弄这些基础技术呢（呵呵，实际上我也不知道的，猜想而已...）

说了好多的废话，只是有感而发。
现在好多朋友们学习crack的时候都很浮躁，想一下子就可以破解这个破解那个,自己破解不了想着法子找人破解。就算破解了又如何。得到那份偷窥者的满足感？为什么静下心来体验一下仅仅是技术领域带给你的快乐呢。那种感觉才更值的体会....
从破解软件开始接触计算机，也无可厚非。但是我想提前告诉新来的朋友们，可能破解是你来这里的目的。而想真的留下来的，应该是对技术的追求。对技术的追求也是这里存在的理由...
