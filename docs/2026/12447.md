
# [原创]网络过滤的简单wfp和tdi驱动sdk

之前自己学习windows驱动写的一个例子，由于我学驱动时间不长，初学者可以稍作参考。

环境是`vs2013+wdk8.x`

文件内容有

1. 驱动部分(`wfp+tdi`  `wfp`用于win7以上 `tdi`用于xp) -- `WFP` 和 `TDI`学习
2. `dll` sdk接口部分。用于和驱动沟通，传递数据。----驱动IO和应用层通信
3. 测试的应用层 `sample`
4. `chm`文档和`doc`

## sdk实现功能

1. 基于回调的处理方式
2. 以黑名单的模式实现   基于进程名的访问控制 基于PID的网络控制 基于IP 端口的访问控制。

## 特别注意

这不是驱动老手写的代码。而是初学者一边学习一边记录写的代码，`wpf`的相关资料较少，驱动也是自己摸索，难免有问题。众多BUG和错误，不负责处理和解答。
