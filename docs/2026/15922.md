# [原创][frida] 01_Android环境搭建

## 安装
1. 各个软件版本
- 本教程使用的是Python3.7.1的64位版本（python-3.7.1-amd64.exe）。
- frida 12.11.17
- frida-tools 8.1.3
- 夜神模拟器6.6.1.2
- adb
- Android Debug Bridge version 1.0.41
- Version 30.0.4-6686687
2. 创建一个虚拟环境
```
D:\Python\Python371\Scripts\pip.exe install virtualenv -i https://pypi.douban.com/simple
virtualenv --system-site-packages python371-venv
```
3. 安装frida-tools。
```
python371-venv\Scripts\activate.bat
python -m pip install --upgrade pip
pip install frida-tools -i https://pypi.douban.com/simple
```
4. 安装frida-server
确定手机系统的版本，参考文字<a href="elink@aaeK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1L8r3!0Y4i4K6u0W2j5%4y4V1L8W2)9J5k6h3&6W2N6q4)9J5c8Y4q4I4i4K6g2X3x3K6M7^5y4e0R3K6z5o6k6Q4x3V1k6S2M7Y4c8A6j5$3I4W2i4K6u0r3k6r3g2@1j5h3W2D9M7#2)9J5c8U0M7^5z5e0l9#2x3K6b7J5">Android系统判断CPU是32位还是64位</a>，夜神模拟器默认的系统是Android5.1.1，x86的系统，需要下载frida-server-12.11.17-android-x86（<a href="elink@817K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6X3M7X3W2V1j5g2)9J5c8X3k6J5K9h3c8S2i4K6u0r3M7X3g2D9k6h3q4K6k6i4y4Q4x3V1k6@1j5h3N6Q4x3V1j5I4x3W2)9J5k6e0p5I4i4K6u0W2x3e0M7`."><mark class="encrypted">5f9K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6X3M7X3W2V1j5g2)9J5c8X3k6J5K9h3c8S2i4K6u0r3M7X3g2D9k6h3q4K6k6i4y4Q4x3V1k6@1j5h3N6Q4x3V1j5I4x3W2)9J5k6e0p5I4i4K6u0W2x3e0M7`.</mark></a>）.
```
$ adb root # might be required
$ adb push frida-server /data/local/tmp/
$ adb shell "chmod 755 /data/local/tmp/frida-server"
$ adb shell "/data/local/tmp/frida-server &"
```
