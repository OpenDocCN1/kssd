# [原创]一个典型的游戏盗号木马逆向分析(有样本)

兵法有云:知已知彼,百战不殆。攻克敌人从了解敌人开始。
小弟新作，一个老病毒，练手用，大鸟勿喷！IDB，样本，文档随后附上。　　
------------------------------------------------------------
    病毒大小23KB左右，为游戏盗号木马，采用UPX加壳，开机自启动。运行期间监视游戏帐号和密码等信息的输入，发送到指定的URL，导致游戏帐号和密码的泄露。

一、感染环境
　　Windows xp，windows 7能感染(其它环境没有测试)
二、感染特征
1、文件行为：

在%systemroot%\system32下创建：91C7DF6D.dll和91C7DF6D.cfg，其中91C7DF6D.dll为木码盗号DLL，91C7DF6D.cfg为加密的URL内容。解密后为：
cadK9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4V1H3N6h3E0#2x3g2)9J5k6h3y4G2L8g2)9J5c8X3y4A6j5g2)9J5c8X3u0A6K9$3g2Q4x3X3g2S2M7%4l9`.

在%Temp%目录下，创建前缀为live的临时文件。

删除C:\WINDOWS\system32\VErCLSiD.exe文件。


2、进程行为：

设置全局钩子，令91C7DF6D.dll注入所有进程。
结束杀软进程，删除杀软托盘图标和结束游戏进程。

3、注册表行为：

创建键值：
hKey = HKEY\_LOCAL\_MACHINE
Subkey ＝”Software\microsoft\windows\currentversion\Explorer\shellexecutehooks”
Value name=”{91C7DF6D-AEF5-4136-9252-AF030D7A5931}”

hKey = HKEY\_CLASSES\_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Value date=”91C7DF6D.dll”

hKey = HKEY\_CLASSES\_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Value name=”ThreadingModel”
Value date=”Apartment”

4、网络行为：

访问URL：816K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4V1H3N6h3E0#2x3g2)9J5k6h3y4G2L8g2)9J5c8X3y4A6j5g2)9J5c8X3u0A6K9$3g2Q4x3X3g2S2M7%4l9`.

四、过程分析
1、创建进程同步事件对象，然后创建新线程

![](https://bbs.kanxue.com/upload/attach/201304/461323_tcc48xu8zyldcqh.png)


创建子线程是病毒核心功能，运行结束后，才释放事件对象。

2、创建91C7DF6D.cfg和写入数据

    在字符串"91C7DF6D-AEF5-4136-9252-AF030D7A5931”取出91C7DF6D，加上cfg拼成文件 名91C7DF6D.cfg，调用GetSystemDirectoryA得到系统目录，最后拼接成文件路径。%systemroot%\ststem32\91C7DF6D.cfg
    申请堆空间，加载源文件到堆空间，返回堆指针。如下图
![](https://bbs.kanxue.com/upload/attach/201304/461323_fkc6g7jlrfrewf8.png)
    在源文件offset=9fc4处读出92字节大小的数据。去掉0D 0A得到数据如下：
2DB2C93C09AD60F3BC9A2C35EDF1D148220000002200000072F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F572F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F5
    如果91C7DF6D.cfg文件存在，执行下一步；如果不存在在%systemroot%\ststem32\创建91C7DF6D.cfg文件，写入以上数据。

3、创建91C7DF6D.dll文件，然后写入数据

    在字符串"91C7DF6D-AEF5-4136-9252-AF030D7A5931”取出91C7DF6D，加上dll拼成文件 名91C7DF6D.dll，调用GetSystemDirectoryA得到系统目录，最后拼接成文件路径。%systemroot%\system32\91C7DF6D.dll
    申请堆空间，加载源文件到堆空间，返回堆指针。然后在%systemroot%\ststem32\91C7DF6D.dll创建文件，在文件offset=67C0h（脱壳后的）处，读出数据14336B大小数据写入文件。如下图：
![](https://bbs.kanxue.com/upload/attach/201304/461323_ig41qrzk9srcbff.png)
![](https://bbs.kanxue.com/upload/attach/201304/461323_jjzcwp8w8ax9x2d.png)

4、加载91C7DF6D.dll，然后运行DLL的s200函数。

    调皮LoadLibraryA加载91C7DF6D.dll，然后用GetProcAddress得到S200函数，然后调用它。如下图：
![](https://bbs.kanxue.com/upload/attach/201304/461323_a9npwsnoc00gwc4.png)

5、修改注册表
    查看
HKEY\_CLASSES\_ROO\Software\microsoft\windows\currentversion\Explorer\shellexecutehooks\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}是否存在。如不存在，下面创建键值。如下图：
![](https://bbs.kanxue.com/upload/attach/201304/461323_a1vrwa7164mq7h1.png)
    通过CreateToolhelp32Snapshot，Process32First和Process32Next查找MD5为：AF 9C 01 04 86 7E D2 84 13 89 16 7E 77 5B 83 32 的进程，找到终止它，如下图。MD5的计算通过 CryptAcquireContextA，CryptCreateHash，CryptHashData和CryptGetHashParam等系列函数计算得到。
![](https://bbs.kanxue.com/upload/attach/201304/461323_fetir07iawbu39d.png)
 删除%systemroot%\system32\verclsid.exe文件，防止自创建CLSID时verclsid.exe认证。
 调用RegOpenKeyEx，RegCreateKeyA和RegSetValueExA等API分别在注册表创建以下值：


```
hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Valve data =”91C7DF6D.dll”

hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Valve Name=”ThreadingModel”

Valve date=”Apartment”
hKey = HKEY_LOCAL_MACHINE
Subkey = "Software\microsoft\windows\currentversion\Explorer\shellexecutehooks"
Valve Name=”{91C7DF6D-AEF5-4136-9252-AF030D7A5931}”
```


![](https://bbs.kanxue.com/upload/attach/201304/461323_5dbqi843pv952yz.png)
    设置访问权限为“SeBackupPrivilege”,创建前缀为live\_开头的临时文件，调用RegSavaKeyA保存Software\microsoft\windows\currentversion\Explorer\信息。然后设置访问权限为“SeRestorePrivilege”，调用RegRestoreKeyA从临时文件中恢复注册表信息。调用RegFlushKey将修改的注册表信息实际写入磁盘，删除临时文件。重复一次相同操作，确定修改注册表成功。如下图：

![](https://bbs.kanxue.com/upload/attach/201304/461323_i25k5us6906a585.png)
![](https://bbs.kanxue.com/upload/attach/201304/461323_k9znp0828xqf0sj.png)
![](https://bbs.kanxue.com/upload/attach/201304/461323_nl7kfrlort7xh5z.png)


6、调用QueryRegKey查看
Software\microsoft\windows\currentversion\Explorer\shellexecutehooks\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}是否已存在。如不存在再次调用LoadLibraryA加载91C7DF6D.dll，运行S200函数。

7、调用GetTickCount查看系统历经时间，如果小于30分钟，继续返回第6步，直到重复三次，每次Sleep 3秒钟。为了确保dll加载运行。

8、退出子线程

9、自删除
    GetModuleFileName和GetShortPathNameA得到源文件的短形式路径，通过GetEnvironmentVariableA得到CMD.exe路径，用cmd.exe运行命令，"/c del [短路径] >> NUL"实现自删除。
**91C7DF6D.dll的行为：**
10、终止杀软进程
通过GetModuleFileNameA得到寄主路径，最后得到程序名32位MD5值，与下列MD5值对比：
  04D1C083134C2EBECA57A9724B0855D4  (360tray.exe)
  AE33A1F2459A12A09EC75D71D14B5E89
  3ABD7CD8928FE1F3EB563F43B913CA4B
  B9E9786EAC82378D3A6E05FCC1E15D2C  (smartup.exe)
  D7DB952BB0FA044F2B9A22FEADB37973
  1C085B8E02B137AA4EAFBE38CCF3D199
如果匹配成功，调用TerminateProcess中止它。如下图

![](https://bbs.kanxue.com/upload/attach/201304/461323_8tprbdyusn66vnz.png)

    MD5的计算用CryptAcquireContextA,CryptCreateHash等一系列函数。如下图

![](https://bbs.kanxue.com/upload/attach/201304/461323_o81f5hgp902gw5h.png)

11、删除杀软托盘图标和进程注入
创建无限循环子线程：
    通过CreateToolhelp32Snapshot创建快照，寻找进程名MD5为下列值的进程。然后把访问权限设为SeDebug特权，通过一套函数FindWindowA，FindWindowExA，GetWindowThreadProcessId和SendMessage等来删除托盘。
    通过GetProcAddress,WriteProcessMemory,CreateRemoteThread等系列函数，把DLL注入到游戏主进程。如下图：

![](https://bbs.kanxue.com/upload/attach/201304/461323_7w5h3v06yn1q8o1.png)

12、设立全局钩子

    调用SetWindowSHookExA设下WH\_CBT类型全局钩子，如下图，目的是把自身（91C7DF6D.dll）注入所以进程中去，得以寄生，不易被终止。

13、注册表的修改
创建限循环子线程不断监视注册表：
    首先查找%systemroot%\system32\VErCLSiD.exe，存在的话就删除它，防止验证。用RegCreateKeyEx检测是否存在
HKEY\_LOCAL\_MACHINE\Software\microsoft\windows\currentversion\Explorer\shellexecutehoos\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}键值。如果不存在，接着创建如下键值(exe主程序一样的做法)：

```
hKey = HKEY_LOCAL_MACHINE
Subkey =“Software\microsoft\windows\currentversion\Explorer\shellexecutehooks”
Value name=”{91C7DF6D-AEF5-4136-9252-AF030D7A5931}”

hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Value date=”91C7DF6D.dll”

hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Value name=”ThreadingModel”
Value date=”Apartment”
```



14、查找游戏进程，记录信息然后发送帐号与密码信息。
    查看寄主MD5值是否为：AF9C0104867ED2841389167E775B8332（猜测为游戏进程名MD5值，有谁帮我破解下），如果是就结束该游戏进程。然后通过过程，键盘，鼠标钩子监视输入的游戏帐号与密码。
    然后读取%systemroot%\system32\91C7DF6D.cfg的数据如下：

C()=72F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F5
