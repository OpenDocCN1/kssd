前    言：
             此软件功能很强，十分好用，是一个极好的FTP软件。很久没有升级，最近才升为2.7版本。
         计算和验证注册码过程比较复杂，所以用修改代码法破解。


过    程:

    只要用16进制编辑器将下5个跳转改成相对应的非跳转即可(JZ改成JNZ、JNZ改成JZ)。

    1：004871A0   offset   865A0
    2: 004871AE   offset   865AE
    3: 004871D4   offset   865D4
    4: 00495844   offset   94C44
    5: 0049571E   offset   94B1E


小   结：
             将这此跳转改过来之后就不会有任何功能限制，只是窗口的CAPTION中可能存在未注册字样。
         如果你觉得难看可以去掉（很容易）。
