
# [原创]高仿LoadPE源码

这个小东西是在学习PE文件结构时写得，也为了巩固下win32编程基础，这里已经有很多类似的demo了，但还是发出来吧，希望能对需要的人有帮助~~大牛就飘过吧。。

实现了PE头和区段信息浏览，位置计算，时间标志，数据目录中包括导入表，导出表，重定位，资源信息的浏览，界面比较刻意的模仿LoadPE。
