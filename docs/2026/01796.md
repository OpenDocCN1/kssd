## 算法

```
(M1 xor A3 xor 0) * A2 mod A1 = N1
N1 and FFFF = S1
(M2 xor B3 xor S1) * B2 mod B1 = N2
N2 and FFFF = S2
(M3 xor C3 xor S2) * C2 mod C1 = N3
N3 and FFFF = S3
(M4 xor D3 xor S3) * D3 mod D1 = N4
N4 and FFFF = S4
```
