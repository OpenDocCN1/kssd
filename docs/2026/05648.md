## 2. 修复输入表

```
006D4D25   pushad

```

运行ImportREC，选择这个进程。把OEP改为`00CC263`，点IT AutoSearch，发现完全不对。于是回到OLLYDBG，找到能正确显示API调用的代码，偶随便找到`4074a8`处，于是在ImportREC中把OEP修改为`0074a8`，点IT AutoSearch，点“Get Import”，用层次1即可修复全部无效函数数。FixDump！
