# 开心斗地主1.7S4非法注册破解 (512字)

采用用户名：/0  注册码：01  注册后重启，出现非法注册。

先用UPX将主程序脱壳后，用TRW2000调入主程序，（需加入msvbvm50.dll)
下bpx \_\_vbaFileOpen拦截，返回TRW后跟踪即可。
我跟了两回，（详情略过）发现正式画面入口在167：004f942d处，
我直接将
      167：004f7285  jz near 004f7578  (jump)
改为                jmp    004f942d

顺利完成。

另：也可用UPX脱壳后，直接用ultraedit 或 winhex等在主程序
里找 0f84ed020000 替换为  e9a3210000.
开心斗地主1.7S4 的注册文件在windows\system里：
oliver.dll和sysinfo.vxd
