
# [原创] IDA 7.0 IDAPython SetStrucAlign Bug 修复

这种问题一般不会遇到，一般通过Local Type插入自定义结构时，可以指定对齐。

当我们需要定制一些结构成员的特殊形式属性时，才需要通过IDC或IDAPython定制我们的结构，也方便脚本自动加载我们自己的类型库。

这时在IDAPython中使用`set_struc_align`或`SetStrucAlign`就会遇到这个问题。

```c
struct __unaligned __declspec(align(1)) xstru001

{

  int m_dw;

  void *m_ptr;

  __int16 m_w;

  char m_b;

};
```

在IDC中我们的原型为

```
set_struc_align（sid,shift)
```

IDAPython的原型为

```
ida_struct.set_struc_align（struct_t*,shift)
```

其重构的`SetStrucAlign`也受影响

```python
import ida_struct

ida_struct.set_struc_align(sid,2)
```

## 使用`get_struc`替代方案

```
ida_struct.set_struc_align(ida_struct.get_struc(sid),shift)
```

## 或通过`get_struc`介入修复为

```python
import ida_struct

def SetStrucAlign(sid, shift): return ida_struct.set_struc_align(ida_struct.get_struc(sid),shift)
```

## 样例

```python
from idc import *

import ida_struct

sn = 'xstru001'

if BADADDR == get_struc_id(sn):
  sid = add_struc(-1,sn,0)
  if BADADDR == sid:
    raise Exception("Couldn't add new struct {}".format(sn))

sid = get_struc_id(sn)
add_struc_member(sid,'m_dw',           0,    FF_DATA|FF_DWORD,-1,4)
```
