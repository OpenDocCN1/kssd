# [原创]使用VMP指令模拟ARM条件跳转

0.目的:

在不直接使用BEQ BNE BLE...
仅使用NAND ADD...
的前提下，

模拟CPU对BXX条件码的判断，选择出跳转的分支地址。



1.ARM条件码判断原理：

决定指令是否执行的关键，是判断CPSR/FLAG寄存器的某BIT位为0还是为1。

![](https://bbs.pediy.com/upload/attach/201901/760871_VZKEUYFPS2VMS5R.png)

以一段 ARM BLT指令为例：

---------------------------------------------------

         ...

.text:000007BC CMP R2, R3

.text:000007C0 BLT loc\_798

.text:000007C4 LDR R3, =13688

---------------------------------------------------

（1）当CPSR的N位==V位，BLT loc\_798不会执行，

程序将会执行到.text:000007C4 LDR R3, =13688。（简称分支A）

（2）当CPSR的N位!=V位，BLT loc\_798将会执行，

程序将会跳转到偏移LOC\_798处。（简称分支B）

2.模拟CPU实现BLT：

简单描述模拟的过程就是：

用ADD和AND，来手动计算出CPSR的N位和V位，

最后计算N-V根据结果，选择一个出一个分支地址。



详细过程：

（1）使用AND(CPSR,掩码)将CPSR中除N和V以外的比特位清零。

```
#define MASK_N		0x80000000			// 掩码
#define MASK_V		0x10000000			// 掩码
#define SHR_N		31-2			 	// 掩码需要右移的值(-2是因为得到数值4)
#define SHR_V		28-2		        // 掩码需要右移的值(-2是因为得到数值4)
```

（2）进一步通过右移求得N值和V值。
(可少右移2次,结果为0或4)

（3）计算N-V的结果，有三种情况，0或1或-1，只有得0时说明N==V。

（4）根据上一步结果使用加法选择出一个分支，具体做法为

在VM栈中PUSH布置A、B两个后继BLOCK的分支地址，

再PUSH布置一个指针指向0x0008处的分支地址A，结构如图。

![](https://bbs.kanxue.com/upload/attach/201901/760871_JDQ4RBS4YEF3VYQ.png)

（5）当N==V时，第三步的结果为0，

将0x0000处存储的指针加0，

指针还是指向0x0008，

所以最终计算出条件跳转结果为分支A，即.text:000007C4 LDR R3, =13688。

（6）当N!=V时，第三步的结果为1或-1

将0x0000处存储的指针+1，或+(-1)

指针会指向0x0004或0x000C,两处内容都为分支地址B

所以最终确定本次选择的分支地址B，即loc\_798.（代码66~70）

（7）使用VMP中经典的NAND或NOR运算，模拟所需的AND和SUB

3.代码实现(仅BLT,其他条件码处理方式类似)

```
		/* 伪代码描述 */
		// 求bit n
		n_value = and(flag,mask_n);
		n_value = shr(n_value,shift_n);
		
		// 求bit v
		v_value = and(flag,mask_v);
		v_value = shr(v_value,shift_v);
		
		// 根据结果0/1/-1,判断n和v是否相等,以模拟cpu对blt是否执行的判断.
		switch_num = n_value - v_value;		
		
		// 确定最终跳转地址
		pointer-4 = &addr_b					// 指针指向0x0004处
		pointer   = &addr_a					// 指针指向0x0008处
		pointer+4 = &addr_b					// 指针指向0x000C处
		pointer = pointer + switch_num		// 若switch_num不为0,说明n!=v,pointer指向变为分支地址B
		final_addr = *pointer				// ...





		/* vmp代码 */
		// V0 A分支
		// V1 B分支
		// V3 N位数值
		// V4 V位数值


		// 备份重定位值,到V0、V1（栈平衡）
		_1_PUSH_IMM4;
		_2_IMM4_A;							// <--- <重定位>
		_3_POP_V0;							// 备份A到虚拟寄存器
		_4_PUSH_IMM4;
		_5_IMM4_B;							// <--- <重定位>
		_6_POP_V1;							// 备份B到虚拟寄存器


		/****************  NV部分  ****************/
		// 1 布置分支地址（虚拟栈+4）
		_7_PUSH_V1;
		_8_PUSH_V0;
		_9_PUSH_V1;

		_10_PUSH_SP;
		_11_PUSH_IMM4;
		_12_IMM4_4;
		_13_ADD;
		_14_POP_TMP;


		// 2 求N的bit值（栈平衡）
		// AND(FLAG,掩码),P(P(a,a),P(b,b)),获取指定位的比特值
		_15_PUSH_FLAG;						// P(a,a) FLAG
		_16_PUSH_FLAG;
		_17_NAND;
		_18_POP_TMP;

		_19_PUSH_IMM4;						// P(b,b) 掩码
		_20_IMM4_MASK_N;
		_21_PUSH_IMM4;
		_22_IMM4_MASK_N;
		_23_NAND;
		_24_POP_TMP;

		_25_NAND;							// V3 == P(P(a, a), P(b, b))
		_26_POP_TMP;						// 
		_27_POP_V3;							// 结果

		// 结果右移
		_28_PUSH_IMM4;						// 次栈顶,移位位数
		_29_IMM4_COUNT_N;
		_30_PUSH_V3;						// 栈顶,要移位的目标
		_31_SHR;
		_32_POP_TMP;						// (SP栈顶保留SHR结果)
		_33_POP_V3;							// V3==N bit


		// 3 求V的bit值（栈平衡）
		// AND(FLAG,掩码),P(P(a,a),P(b,b)),获取指定位的比特值
		_34_PUSH_FLAG;						// P(a,a) FLAG
		_35_PUSH_FLAG;
		_36_NAND;
		_37_POP_TMP;

		_38_PUSH_IMM4;						// P(b,b) 掩码
		_39_IMM4_MASK_V;
		_40_PUSH_IMM4;
		_41_IMM4_MASK_V;
		_42_NAND;
		_43_POP_TMP;

		_44_NAND;							// V4 == P(P(a, a), P(b, b))
		_45_POP_TMP;						// 
		_46_POP_V4;							// 结果

		// 结果右移
		_47_PUSH_IMM4;						// 次栈顶,移位位数
		_48_IMM4_COUNT_V;
		_49_PUSH_V4;						// 栈顶,要移位的目标
		_50_SHR;
		_51_POP_TMP;						// (SP栈顶保留SHR结果)
		_52_POP_V4;							// V4==V bit


		// 4 求N-V的结果（栈平衡）
		// SUB(N-V) = P(P(N,N)+V,~)
		_53_PUSH_V4_V;						// 输入V

		_54_PUSH_V3_N;						// 输入N
		_55_PUSH_VSP;						// 
		_56_READ4;							// 
		_57_NAND;							// P(N,N)
		_58_POP_TMP;						// 

		_59_ADD;							// P(N,N)+V
		_60_POP_TMP;						// 

		_61_PUSH_VSP;						// 复制SP
		_62_READ4;							// 复制SP

		_63_NAND;							// P(P(N,N)+V,~)
		_64_POP_TMP;
		_65_POP_ADDR;						// 运算结果放在ADDR寄存器


		// 6 结果 + SP,选择出一个分支
		_66_PUSH_ADDR;
		_67_ADD;
		_68_POP_TMP;
		_69_READ4;
		_70_POP_ADDR;

		_71_POP_TMP;
		_72_POP_TMP;
		_73_POP_TMP;
		

```
