
# [原创]一款老游戏的多开!

这款游戏很老了,是一个很棒的游戏可惜被2个代理商给弄砸了.

首先,我们打开OD载入游戏的主程序.

先查找模块间的调用.粗略地看了一下.这里有一个`FindwindowA`的函数.

![](https://bbs.kanxue.com/upload/attach/201207/237564_b1ofbrcpquykswr.jpg)

由此我们可以断定,游戏是通过`FindwindowA`函数来找窗口是否存在来判断游戏能不能运行.

![](https://bbs.kanxue.com/upload/attach/201207/237564_vqa6fesb9e7y14o.jpg)

所以我们在这个`CALL`这里返回上个.来到了`00426E04`.把`JE`改成`JMP`.跳过函数判断过程.

这样游戏就会认为没有存在,可以继续运行,达到了多开的目的.

然后我们保存修改后的文件.这就可以多开了.

但是游戏的自动更新会把你修改过文件给更新掉,怎么办呢?我们要想办法跳过更新.

这款游戏的登陆过程非常简易,只需要知道游戏服务器的IP即可.

下面我给一个批处理.

```
china_login.mpr -127.0.0.1 '127.0.0.1为服务器IP
```
