
# [分享]迅雷`DownAndPlay.dll`模块溢出

/*
抱歉，没有仔细注意这个问题。这个洞的确没办法远程溢出。![](https://bbs.kanxue.com/view/img/face/16.gif)
*/

迅雷`DownAndPlay.dll`随迅雷起来后(不知道这个模块在从那个版本开始出现，我这是最新版本)，在本地绑定36897端口，等待链接。

接受的数据格式是 `XLDAP|key|value|XLDAP`, 其中的 `key` 由预定义的几个。

这里实现溢出选择的是 `savepath`, 当`value`超长时就会在 `spintf` 处发生溢出。

附件的 `11.dat` 是在临时构造的一份数据，可以使用 `nc` 看看效果，运行命令：

`C:\>nc 127.0.0.1 36897 <11.dat`

迅雷会因为异常退出。
