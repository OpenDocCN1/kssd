**NT组件概观**

如图所示，基于NT构架的操作系统包括用户模式和内核模式组件。内核模式组件拥有相对独立的功能而与其他内核模式组件相独立。

对内核模式驱动程序员来说，最令人感兴趣的执行体(Executive)组件是I/O管理器(I/O Manager)，配置管理器(Configuration Manager)，即插即用管理器(Plug and Play)，电源管理器(Power Manager)，内存管理器(Memory Manager)，执行体支持(Executive Support)，处理器结构(Process Structure)，内核(Kernel)，和硬件抽象层(Hardware Abstract Layer)。一些驱动开发人员也会对其他组件如对象管理器(Object Manager)和安全引用监视器(Security Reference Monitor)感兴趣。

在图中文件系统(File System)，中间(Intermediate)和最底层(Lowest)驱动位于I/O管理器框中，是因为，在很大程度上由I/O管理器(I/O Manager)初始化这些驱动的I/O操作。
