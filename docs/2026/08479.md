# 内核调试器的工作流程：

## 内核调试器的执行流程：

![](https://bbs.kanxue.com/upload/attach/201804/796971_DGUFA5QCW3VAE5H.jpg)

![]()

    说明：

        1.       在KiDispatchException中，如果存在内核调试器，kdpTrap会被赋值给KiDebugRoutine

        2.       KdpTrap是实际负责内核调试相关业务的函数，里面有大量的switchcase，对各种异常进行处理

        3.       KdEnterDebugger会获取一个自旋转锁，但是获取的方式的异步的，我们不能直接卡着调试器，但是可以对获取自旋锁做钩子，因为参数是固定的：DdpDebuggerLock，很好判断

        4.       KdpSendWaitContinue,主要调用KdpSendPacket和KdpReceivePack和winddbg进行交互

# 根据内核异常分发流程总结出来的反调试方法：

    1.       KernelDebuggerEnabled设置为false，有专门的函数干这个事情: KdDisableDebugger

    2.       对KdpReceivePacket和KdpSendPacket做IAT hook，这两个函数在kdcom.sys中导出

    3.       把kdpDebuggerLock，但是可以对获取自旋锁做钩子，因为参数是固定的：DdpDebuggerLock，很好判断

    4.       直接替换KiDebugRoutine

## 方法1：直接调用 KdDisableDebugger

```
#include <ntddk.h>


NTSTATUS UnloadDriver(PDRIVER_OBJECT DriverObject)
{
	DriverObject;
	return STATUS_SUCCESS;
}

NTSTATUS DriverEntry(PDRIVER_OBJECT DriverObject, PUNICODE_STRING  RegistryPath)
{
	RegistryPath;
	DriverObject->DriverUnload = UnloadDriver;
	KdDisableDebugger();
	return STATUS_SUCCESS;
}

## 方法2：如果KdDisableDebugger怕别人hook，可以自己实现下

```
#pragma warning(disable:4214)

#include <ntddk.h>

#define  DEVICE_NAME	 L"\\Device\\fakdfjadadf"


typedef struct DpcTImberExtend
{
	PDEVICE_OBJECT pDeviceObj;
	UNICODE_STRING strDeviceName;
	UNICODE_STRING strDeSymbolLinkName;
	KTIMER kTimber;
	KDPC kDpc;
}DPCTIMBER_EXTEND;
DPCTIMBER_EXTEND g_dpcExtend = { 0 };

ULONG  g_uKdEnableFlagAddr = 0;
ULONG g_uOldFlag = 0;


VOID DpcTimberCallBackProc(KDPC *Dpc, PVOID DeferredContext, PVOID SystemArgument1, PVOID SystemArgument2);
#pragma  alloc_text(NONE_PAGE, DpcTimberCallBackProc)

NTSTATUS UnloadDriver(PDRIVER_OBJECT DriverObject)
{
	KeCancelTimer(&g_dpcExtend.kTimber);
	IoDeleteDevice(DriverObject->DeviceObject);
	if (g_uKdEnableFlagAddr)
	{
		*(PULONG)g_uKdEnableFlagAddr = g_uOldFlag;
	}
	return STATUS_SUCCESS;
}

ULONG KdEnableFlagAddr()
{
	UNICODE_STRING funcName;
	RtlInitUnicodeString(&funcName, L"KdDisableDebugger");
	ULONG step = 0;
	ULONG targetFunAddr = 0;
	ULONG baseFunAddr = (ULONG)MmGetSystemRoutineAddress(&funcName);
	for (step = baseFunAddr; step < (baseFunAddr + 1024); step++)
	{
		//搜索：0x6A,0x01, 0xE8
		if (((*(PUCHAR)(UCHAR*)(step - 1)) == 0xE8) &&
			((*(PUCHAR)(UCHAR*)(step - 2)) == 0x01) &&
			((*(PUCHAR)(UCHAR*)(step - 3)) == 0x6A))
		{
			ULONG offset = *(PULONG)step;
			targetFunAddr = (ULONG)(step - 3) + offset + 5;
			break;
		}
	}
	KdPrint(("step1 addr:%08X\n", targetFunAddr));
	if (targetFunAddr != 0)
	{
		baseFunAddr = targetFunAddr;
		for (step = baseFunAddr; step < (baseFunAddr + 1024); step++)
		{
			//搜索：0x75, 0x5C,0xA0
			if (((*(PUCHAR)(UCHAR*)(step - 1)) == 0xA0) &&
				((*(PUCHAR)(UCHAR*)(step - 2)) == 0x5C) &&
				((*(PUCHAR)(UCHAR*)(step - 3)) == 0x75))
			{
				targetFunAddr = *(PULONG)step;
				break;
			}
		}
	}
	return targetFunAddr;
}


NTSTATUS DriverEntry(PDRIVER_OBJECT DriverObject, PUNICODE_STRING  RegistryPath)
{
	UNREFERENCED_PARAMETER(RegistryPath);
	DriverObject->DriverUnload = UnloadDriver;
	//
	g_uKdEnableFlagAddr = KdEnableFlagAddr();
	UNICODE_STRING temName = RTL_CONSTANT_STRING(DEVICE_NAME);
	g_dpcExtend.strDeviceName = temName;
	IoCreateDevice(DriverObject, 0, &g_dpcExtend.strDeviceName, FILE_DEVICE_UNKNOWN, 0, 0, &g_dpcExtend.pDeviceObj);

	if (g_uKdEnableFlagAddr)
	{
		g_uOldFlag = *(PULONG)g_uKdEnableFlagAddr;
	}

	//初始化DpcTimber
	KeInitializeTimer(&g_dpcExtend.kTimber);
	//初始化dpc对象
	KeInitializeDpc(&g_dpcExtend.kDpc, DpcTimberCallBackProc, NULL);
	LARGE_INTEGER timeOut;
	timeOut.QuadPart = -30000000;
	KeSetTimer(&g_dpcExtend.kTimber, timeOut, &g_dpcExtend.kDpc);

	return STATUS_SUCCESS;
}


VOID DpcTimberCallBackProc(KDPC *Dpc, PVOID DeferredContext, PVOID SystemArgument1, PVOID SystemArgument2)
{

	UNREFERENCED_PARAMETER(Dpc);
	UNREFERENCED_PARAMETER(DeferredContext);
	UNREFERENCED_PARAMETER(SystemArgument1);
	UNREFERENCED_PARAMETER(SystemArgument2);

	if (g_uKdEnableFlagAddr)
	{
		*(PULONG)g_uKdEnableFlagAddr = 0;
	}

	LARGE_INTEGER timeOut;
	timeOut.QuadPart = -30000000;
	KeSetTimer(&g_dpcExtend.kTimber, timeOut, &g_dpcExtend.kDpc);

}
