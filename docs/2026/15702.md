
# [原创]VS+VA搭建顺手的NDK集成开发环境

工欲善其事，必先利其器。

Android NDK开发环境，可选择`VIM`+插件、`Eclipse`+`CDT`等，这里介绍另一种选择：`VS`+`VA`

## 软件准备：

`Visual studio 2008` // 其他版本也行，这里以`VS2008`为例。

`Visual assist X`

`Android NDK`

## 环境变量：

将`NDK`根目录加入`%PATH%`环境变量。

打开`VS2008`，新建`Makefile`项目

![](https://bbs.kanxue.com/upload/attach/201502/305105_f0gj0z5j7uxcnmm.png)

在项目向导中填写以下内容

![](https://bbs.kanxue.com/upload/attach/201502/305105_e24z9xw5d2k355h.png)

**Build command line:** `ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=./Android.mk`

**Clean commands:** `ndk-build clean NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=./Android.mk`

**Rebuild command line:** `ndk-build -B NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=./Android.mk`

**Include search path:** `E:\Android\android-ndk-r9d\platforms\android-12\arch-arm\usr\include` // 对应到你本机的目录及版本。

点击完成。

![](https://bbs.kanxue.com/upload/attach/201502/305105_c32hbobudblifam.png)

这些设置可以在工程属性中修改；`Debug`、`Release`可以分别设置。

![](https://bbs.kanxue.com/upload/attach/201502/305105_gwnuvcti7wcp2aj.png)

写代码测试一下

![](https://bbs.kanxue.com/upload/attach/201502/305105_zj9edgmxkqkwqpt.png)

试试编译、清理、重新编译有无问题。

![](https://bbs.kanxue.com/upload/attach/201502/305105_7h1o7yf8lmtryqv.png)

搞定，开始愉快的写代码吧![](https://bbs.kanxue.com/view/img/face/1.gif)。
