## `Form` 对象信息结构

每个 `Form` 都存在可选对象信息头 `VB_OPTIONAL_OBJECT_INFO`，这个结构紧跟着 `VB_OBJECT_INFO`。

如果 `VB_OBJECT.ObjectType & 2 == 2`，即存在 `VB_OPTIONAL_OBJECT_INFO`。

可选头中重要的成员有 2 个：

- `ControlCount`：当前对象的控件计数。
- `pControlArray`：该值指向控件结构数组 `VB_CONTROL`。控件数组由 `ControlCount` 指定。

### `VB_CONTROL` 结构

`VB_CONTROL` 结构中重要的成员有 3 个：

- `EventCount`：该控件的事件计数。
- `pGUID`：指向 `GUID` 结构。结构声明在 `OleAuto.h`。这个成员是用于获取该控件的类型，被定义在 `VB6.OLB` 中。
- `pEventTable`：指向控件事件表 `VB_EVENT_TABLE` 结构的指针。

有关如何根据 `GUID` 获取控件类名、控件事件名称，见最后。

## 事件表与事件指针结构

知道了事件表的指针，就可以获取事件表了。但是请注意，这里的事件表不是数组，只有一个表。

紧跟在事件表 `VB_EVENT_TABLE` 后面的是事件指针结构数组，这个才是有关事件的。数组大小由 `EventCount` 指定。

个人分析：每种控件的事件指针结构 `VB_EVENT_POINTER` 数组的大小是固定的。

比如 `VB` 中的 `CommandButton` 的事件计数是 17 个。

不管源程序中 `CommandButton` 定义了多少事件，数组个数是固定的。

对于未使用的事件来说，其事件指针结构中的 `pEvent` 为 `NULL`。

在 `VB6.OLB` 中定义了各个基本控件事件的 `MemberID`。想获取详细信息的话，可以用类型库浏览器查看。

## 控件事件名称与 `MemberID`

现在先来说说如何知道控件的事件名称。

根据我的分析，`VB6.OLB` 中所有的控件事件的 `MemberID` 其基值都是 `0x00040000`。

以 `CommandButton` 为例，`Click` 是第一个成员，其 ID 就是 `0x00040000`。

`DragDrop` 事件是第二个成员，其 ID 就是 `0x00040001`。

这些 `MemberID` 怎么跟事件指针结构相关联呢？

比如 `CommandButton_Click` 事件，相关联的就是 `VB_EVENT_POINTER[0]`。

也就是说，第一个成员关联数组中的第一个，即数组 `[0]`。

按钮控件的事件成员有 17 个，所以也就会有事件指针结构 17 个，每个按顺序关联。

## 根据 `GUID` 和 `MemberID` 获取事件名称

最后讲下如何根据 `GUID` 和 `MemberID` 获取事件名称，直接上代码：

```
#include <SDKDDKVer.h>
#include <windows.h>
#include <locale.h>

#include <stdio.h>
#include <tchar.h>

#include <oleauto.h>

const GUID vbclsid = {0xFCFB3D2E,0xA0FA,0x1068,0xA7,0x38,0x08,0x00,0x2B,0x33,0x71,0xB5};
const CLSID cmdbtnid = {0x33AD4EF2,0x6699,0x11CF,0xB7,0x0C,0x00,0xAA,0x00,0x60,0xD3,0x93};

int _tmain(int argc, _TCHAR* argv[])
{
    ITypeLib *ITL;
    ITypeInfo *ITI;
    UINT OS;
    BSTR bStr = NULL;
    HRESULT hr;

    setlocale(LC_CTYPE, "");
    hr = LoadRegTypeLib(vbclsid,6,0,9,&ITL);
    if (hr != S_OK)
    {
        printf("载入VB6.OLB失败!\n");
        goto WaitExit;
    }
    printf("载入成功!\n");

    hr = ITL->GetTypeInfoOfGuid(cmdbtnid,&ITI);
    if (hr != S_OK)
    {
        printf("获取Command Button失败!\n");
        goto WaitExit;
    }
    printf("获取成功!\n");

    hr = ITI->GetNames(0x00040004/*Member ID*/,&bStr,1,&OS);
    wprintf(L"名称:%s\n",bStr);
    SysFreeString(bStr);

WaitExit:
    getchar();
	return 0;
}
```
