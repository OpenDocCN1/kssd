每个进程都有一个数据结构，`EPROCESS`，这个结构是在内核里面的，系统用来标识和管理每一个win进程的基本数据结构。

这个结构中包含了一个重要的字段，`DebugPort`，如果一个进程不在被调试的时候那么就是`NULL`，否则它是一个指针；win前，这个成员保存的是用于接收调试事件的`LPC`端口对象指针。发生调试时，系统会向这个端口发送调试信息。

Winxp下因为使用了专门用于调试的内核对象`DebugObject`，所以`debugport`指向的是一个`DebugObject`对象，不管是指向`LPC`端口还是指向调试对象，虽然类似不同吧~~~

但是它们的作用都是用来传递调试事件的，所以`debugport`中指向的对象，我们就叫做调试端口。

张奎银大牛告诉我们，这个端口是链接调试器进程和被调试进程的纽带~

被调试程序的事件由这个端口发送到调试器进程的。

（so，某些产品为了不被调试，就一直对这个字段写入`0`，导致调试事件无法发送，造成了调试器像傻子一样~~）

调试内核，最先想到的肯定是`windbg`，于是LZ碰到了第一个问题，那个T什么的保护禁止了双机调试。下面给出过掉防止双机调试的方法。

```
KDCOM.dll:KdReceivePacket  //这两个是COM串口的接收和发送数据
KDCOM.dll:KdSendPacket      //主要用来防止别人双机调试
```

上面两个函数几乎可以忽略掉，`VirtualKD`这个工具自己实现了COM通信，替代了上面两个函数。

然后是。。。是。。。
`KdDisableDebugger`，ok，过掉对这个函数的调用应该就可以进行双机调试了。

启动虚拟机调试模式，`windbg`对`KdDisableDebugger`下断点，然后运行游戏。

发现游戏登陆之前`windbg`就已经断下来了。`eb`指令对`KdDisableDebugger`第一行代码写入`C3(ret)`。

![](https://bbs.kanxue.com/upload/attach/201205/451812_uj4o03davn6yu1u.jpg)

然后F8单步执行，找到调用`KdDisableDebugger`处。

![](https://bbs.kanxue.com/upload/attach/201205/451812_y86kludf5n1ri3i.jpg)

仔细看代码不难发现，这是一段循环调用`KdDisableDebugger`的代码。`eb`对上图中`edcaa6d5`处写入`74`，过掉此处。

F5跑起来会再次断下来，单步执行返回到另一处调用。

![](https://bbs.kanxue.com/upload/attach/201205/451812_ts8q1lbzacwjk8r.jpg)

尾部`mov dword ptr [ecx],eax`这句很关键，不能让它执行，一旦执行，`windbg`就失去通信了。

对上图中`edcaa803`位置写入`75`，然后F5跑起来，再次断下来发现调用位置还是上面这里。

修改`CALL EAX`上面那行，也就是`edcaa7c4`位置，写入`75`，再次跑起来就不会再断下来了，游戏正常运行。

但是游戏登陆以后，保护会出现错误，重新加载一次保护，然后按照上面的方法重新过一次就可以了。

接下来，等游戏跑起来以后，用`windbg`手动断下来，命令行键入`!process 0 0`回车。

得到当前所有进程的`EPROCESS`对象地址。

![](https://bbs.kanxue.com/upload/attach/201205/451812_vu1w66o3gc2rkug.jpg)

注意这里完成后要让虚拟机尽快跑起来，中断久了游戏会和服务器断开连接。

好了，会找到两个游戏进程。接下来在虚拟机里打开任务管理器，查看当前游戏的进程ID，转换为16进制。

![](https://bbs.kanxue.com/upload/attach/201205/451812_oc49pw7eauaq6l1.jpg)

转换后就是上面获取到的`CID:0370`。

然后对`PROCESS 85f5d228`这个地址的`+BC`处下数据写入断点，`+bc`就是`DebugPort`地址了。

指令`ba w 4[85f5d228 +bc]`（`ba`指令格式：`ba Access Size [地址]`，`Access`为访问方式，`Size`为监控访问位置大小）。

然后跑起来，立马就会断下来。这里注意多跑几次，有两个地方做了清零，如下图：

第一处：

![](https://bbs.kanxue.com/upload/attach/201205/451812_n5z5hl2mlertupd.jpg)

```
xor     ecx,ecx
xchg    ecx,dword ptr [eax]
```

还有第二处：

![](https://bbs.kanxue.com/upload/attach/201205/451812_1qlwhle7afkzcu2.jpg)

```
xor     eax,eax
xchg    eax,dword ptr [edi]
```

这两个地方。

好了，位置找到了，收工。
