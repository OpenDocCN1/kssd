### Charles证书安装

- PC安装证书：帮助-->SSL代理-->安装Charles根证书

![请添加图片描述](upload/attach/202203/944393_4EAUMHWJ67RVAJ6.jpg)

- 配置SSL：代理-->SSL代理设置-->启用SSL代理-->位置： `* : *`

![在这里插入图片描述](upload/attach/202203/944393_6GQU8YR258N4EHT.jpg)

- 帮助-->SSL代理-->在移动设备或远程浏览器上安装Charles根证书

![在这里插入图片描述](upload/attach/202203/944393_3BNRSZB3DATG97B.jpg)

- 手机按照提示操作设置WiFi代理
- 下载charles证书：帮助-->SSL代理-->保存Charles根证书

![请添加图片描述](upload/attach/202203/944393_564DHXVGCVRUTBK.jpg)

- 计算证书名：`openssl x509 -subject_hash_old -in E:\download\chrales.pem`

![在这里插入图片描述](upload/attach/202203/944393_B9DXS4X2KJ3SMCV.jpg)

- 重命名：`mv charles.pem 7672ac4b.0`或直接重命名
- 上传证书文件至手机：`adb push E:\download\7672ac4b.0 /sdcard/`

![在这里插入图片描述](upload/attach/202203/944393_HUT5NGAV4933CGV.jpg)

```
adb shell
su
mount -o rw,remount /system
mv /sdcard/证书文件 /system/etc/security/cacerts/
chmod 644 /system/etc/security/cacerts/7672ac4b.0
reboot
```

![在这里插入图片描述](upload/attach/202203/944393_H26NJUD442PC5RZ.jpg)

- 检查是否安装成功：设置-->安全性和位置信息-->加密与凭证-->信任的凭据-->XK72 Ltd

![在这里插入图片描述](upload/attach/202203/944393_KPYFV7SEKUGQ59T.jpg)

### Fiddler证书安装

- PC安装证书：工具-->选项-->HTTPS-->解密HTTPS通信（安装证书）

![在这里插入图片描述](upload/attach/202203/944393_VBK7BMXA3QM4WTF.jpg)

- 连接-->允许远程计算机连接

![在这里插入图片描述](upload/attach/202203/944393_M7B8669ETQ58CDV.jpg)

- 下载证书：工具-->选项-->HTTPS-->动作-->将证书导出到桌面

![在这里插入图片描述](upload/attach/202203/944393_QRH72SD4VBBYMDX.jpg)

- 计算证书名：`openssl x509 -inform DER -subject_hash_old -in E:\download\FiddlerRoot.cer`

![在这里插入图片描述](upload/attach/202203/944393_F9FVC5JDEEFBEWC.jpg)

- 重命名：`mv FiddlerRoot.cer e5c3944b.0`或直接重命名
- 上传证书文件至手机：`adb push E:\download\e5c3944b.0 /sdcard/`

```
adb shell
su
mount -o rw,remount /system
mv /sdcard/e5c3944b.0 /system/etc/security/cacerts/
chmod 644 /system/etc/security/cacerts/e5c3944b.0
reboot
```

![在这里插入图片描述](upload/attach/202203/944393_CMH9KW6R862R85Y.jpg)

- 检查是否安装成功：设置-->安全性和位置信息-->加密与凭证-->信任的凭据-->DO_NOT_TRUST_BC

![在这里插入图片描述](upload/attach/202203/944393_5ZUXSDWBGK9NWRM.jpg)
