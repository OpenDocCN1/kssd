# 01 C语言-参数传值 ,返回值以及局部变量

前言

**该文章主要是分析了C语言函数的Debug环境下参数是如何传入以及通过函数的运算是如何将运算的结果传出。**

## 一；测试代码

```
#include <stdio.h>

int a(int x, int y)
{
	int b;
	b = x + y;
	return b;
}

int main() {
	int c;
	c = a(1, 2);
	return c;
}
```

## 二；程序分析

    首先，执行程序， 然后定位到地址"0X4417D8"。该位置就是我们"c = a(1,2)" 代码对应的汇编代码。接下来我们看到就是连续两个push指令以及一个Call指令。

![](https://bbs.kanxue.com/upload/attach/202103/911429_D6NQBYYF7B2XSJZ.jpg)

    下面，我们单步执行push指令，然后，我们关注栈空间。这个时候，我们发现1和2两个数字已经被压入栈空间。紧接的是执行一个call指令。（call指令是一个跳转指令，并且将call指令的返回地址压入栈空间）

![](https://bbs.kanxue.com/upload/attach/202103/911429_25GCYTPQ5WMQ4AR.jpg)

    然后我们执行Call指令。我们先注意一下Call指令的返回地址。

![](https://bbs.kanxue.com/upload/attach/202103/911429_X6WBC24AJ7AP8JF.jpg)

    执行Call 指令之后，发现此时栈空间已经被压入了call 指令的返回地址。

![](https://bbs.kanxue.com/upload/attach/202103/911429_U2YTBD6T9CCK593.jpg)

    这个时候，我们在代码区发现跳转到了jmp 指令，这个是一个跳转指令。不用着急，继续单步执行。

![](https://bbs.kanxue.com/upload/attach/202103/911429_D4N44R3VPRRYTJP.jpg)

    这里的jmp指令跳转之后，程序就会跳转到定义函数的位置，即如下图位置。

![](https://bbs.kanxue.com/upload/attach/202103/911429_8B35953RHUCB9MV.jpg)

    继续单步执行之后，我们跳转到了如下图位置。该位置就是函数"a(int x,int y)"的函数位置。

![](https://bbs.kanxue.com/upload/attach/202103/911429_MEZT27Z2NK89VGR.jpg)

    接下来，我们继续关注汇编代码。首先我们先看两个指令push ,mov 指令。那么这个指令有什么作用呢 ？我们先单步执行完这两个指令。

![](https://bbs.kanxue.com/upload/attach/202103/911429_BAXKYVQ3PY57687.jpg)

    这个时候，我们关注栈空间，发现EBP的值发生了变化。我们发现新的EBP值得位置当中得内容存入得是之前EBP得值。同时，将ESP的值与EBP值相等。该作用是初始化一个新的栈空间，这个栈空间就是供函数a()使用的。

![](https://bbs.kanxue.com/upload/attach/202103/911429_AF2NZMEDE28VWQA.jpg)

![](https://bbs.kanxue.com/upload/attach/202103/911429_PY95JX7PHCX27KN.jpg)

    紧接着，我们执行sub 指令。这个时候我们关注栈空间。很明显该指令的作用的给函数分别缓冲区。

![](https://bbs.kanxue.com/upload/attach/202103/911429_NWNBQ52BDDCZDBA.jpg)

    下面执行三个push 指令。执行完成，我们关注一下栈空间。此时我们发现在“EBP-D0”~"EBP-D8"位置压入了ebx,esi,edi寄存器的值。他的作用的保存环境。

![](https://bbs.kanxue.com/upload/attach/202103/911429_JDWM3TA2Z7K5HEX.jpg)  ![](https://bbs.kanxue.com/upload/attach/202103/911429_BQKYEGEKXR867TH.jpg)

    紧接着，我们继续执行“lea edi,dword ptr ss:[ebp-0xCC]”以及“mov eax,0xCCCCCCCC”，“rep stos dword ptr es:[edi]”。该指令执行结束之后。我们观察栈空间。  此时，我们发现之前生成的缓冲区现在已经填满了“CC”即int 3 断点指令。这样做的好处的当程序执行异常可以即时中断程序。

![](https://bbs.kanxue.com/upload/attach/202103/911429_25ATA2NV7DVRHG9.jpg)

![](https://bbs.kanxue.com/upload/attach/202103/911429_ZD88F6EPK79B8W6.jpg)

  直到目前为止，程序已经完成了基本的调用程序的初始化操作。接下来就是执行我看看函数主体部分的内容。

![](https://bbs.kanxue.com/upload/attach/202103/911429_U8WYRTTYP9A59NS.jpg)

    我们通过如下汇编代码发现，程序使用EBP的值作为基地址，偏移一定位置定位到之前压入栈的两个参数1和2来进行加法计算。执行完成之后，他们的计算的值被放入了寄存器EAX当中。

![](https://bbs.kanxue.com/upload/attach/202103/911429_TBJKU3MCHAEPST6.jpg)

![](https://bbs.kanxue.com/upload/attach/202103/911429_YEQFBPXXTUHTYUN.jpg)

    计算出来的值临时放入eax 当中，紧接着执行mov 指令，将值放入了一个“ss:[ebp-0x8]”的位置，该位置便是局部变量“b”的位置。

![](https://bbs.kanxue.com/upload/attach/202103/911429_5KSYAKMC8FBHHST.jpg)

    接下来，我们来看pop 指令。既然函数功能已经执行完成，接下来就是恢复环境的操作。首先使用pop 将之前保存的寄存器的值还原回去。

![](https://bbs.kanxue.com/upload/attach/202103/911429_HB8YDQYB2UN454F.jpg)

    接下来就是将之前的缓冲区，给清楚即 add 指令。

![](https://bbs.kanxue.com/upload/attach/202103/911429_9PVD6H8PS6T8FPZ.jpg)

    结束之后就是执行retn ，来返回之前的位置。然后执行"add esp,0x8"使堆栈平衡。

![](https://bbs.kanxue.com/upload/attach/202103/911429_YWVWDAU98NU6Q98.jpg)

![](https://bbs.kanxue.com/upload/attach/202103/911429_ZFAYWWR49GSNA9S.jpg)

![](https://bbs.kanxue.com/upload/attach/202103/911429_UPS54AE9G7DG7EA.jpg)

    最后，我们将这个栈空间通过一张图来展现出来。

![](https://bbs.kanxue.com/upload/attach/202103/911429_K7VEQ2VGAE3FK5F.jpg)

## 三；总结

1；首先在执行调用函数之前，先将所需要的参数通过push 指令压入栈，在之后的函数内部运行需要用到对应的参数时，可以使用EBP为基址来偏移找到对应的参数。

2；下面使用call 指令来调用对应的函数。

3；程序流跳转到对应的函数代码位置的时候，首先初始化一个新的栈针，然后划分CC空间缓冲区，保存当前环境，最后将划分的缓冲区填充为CC指令。

4；准备工作完成之后，进行函数计算，值存放在寄存器EAX当中。

5；求值结束之后，进行环境恢复。并且堆栈平衡操作。

6；局部变量即分配在缓冲区当中，文中实例局部变量b 用EBP表示，则为EBP-0X8
