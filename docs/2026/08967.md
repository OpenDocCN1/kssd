准备工具：`010editor` 、 `od` 、 `vs2012` 、 `lordpe`

自己用`VS`任意编个程序 以：

```
#include "stdafx.h"
#include "windows.h"
int _tmain(int argc, _TCHAR* argv[])
{
  MessageBox(0,L"Hello World!",L"bbs,pediy.com",MB_OK);
  return 0;
}
```

为例。

将编译好的程序拖入`lordpe` 点击“区段”-右键“添加区段”：

![](https://bbs.kanxue.com/upload/attach/201512/607869_d5re6csd9nuxh1t.png)

点击新添加的区段-右键“编辑区段” 更改：

- 虚拟大小：`00000200`
- 物理大小：`00000200`

![](https://bbs.kanxue.com/upload/attach/201512/607869_fij0t4l628s5crb.png)

保存-确定。

将文件拖入`010` 菜单栏点击“编辑”-“覆盖插入”-“插入字节” 由上图新添加区段得

- 起始地址：`7A00`
- 大小：`200`

![](https://bbs.kanxue.com/upload/attach/201512/607869_atnuqp6s43oivgc.png)

`ctrl+s` 保存。

我们拖入`od` 点击`E`可执行模块 得到基址：`00B30000`：

![](https://bbs.kanxue.com/upload/attach/201512/607869_jgyu994loruaqmt.png)

可求得新添加区段首地址为`00B4C000` `CTRL+G` -回车来到此地址处 空格修改：

```
jmp 00B41078（入口点）
```

![](https://bbs.kanxue.com/upload/attach/201512/607869_30u4ksoblvxzubd.png)

保存命名为：“`mesgbox1.exe`”。

将新保存的文件拖入`lordpe` 更改入口点为`1c000`：

![](https://bbs.kanxue.com/upload/attach/201512/607869_n7xjqwsyfy8uegd.png)

保存-确定。

为了确定是否修改成功请点击程序是否可以正常运行：

![](https://bbs.kanxue.com/upload/attach/201512/607869_ojuypk591gnyeqn.png)

增加代码段“可写入”属性：

![](https://bbs.kanxue.com/upload/attach/201512/607869_c4eha10qtodmclh.png)

拖入`010`加密：

选中代码段-十六进制的操作（加减号 如图）-二进制`xor`：

![](https://bbs.kanxue.com/upload/attach/201512/607869_lv3gwvbaa2icgaz.png)

![](https://bbs.kanxue.com/upload/attach/201512/607869_mwazea08r6p567v.png)

`ctrl+s`保存

修改后：

![](https://bbs.kanxue.com/upload/attach/201512/607869_0oyuuh9mk2i484k.png)

防止再次基址重定位 修改`dll`特征：

![](https://bbs.kanxue.com/upload/attach/201512/607869_z1nihawlfjjdx6s.png)

拖入`OD`“解密”：

```
0041C000 >  60               pushad                                   ; 保存寄存器
0041C001    B9 003C0000      mov ecx,0x3C00                           ; 循环次数
0041C006    BB 00100100      mov ebx,0x11000                          ; 代码段起始位置
0041C00B    BA 00004000      mov edx,mesgbox1.00400000
0041C010    03DA             add ebx,edx
0041C012    8033 0F          xor byte ptr ds:[ebx],0xF
0041C015    43               inc ebx
0041C016  ^ E0 FA            loopdne short mesgbox1.0041C012
0041C018    61               popad                                    ; 恢复寄存器
0041C019  - E9 5A50FFFF      jmp mesgbox1.00411078                    ; 跳转至入口点
```

重命名为“`mesgbox2.exe`”。

点击查看是否可以运行(PS:没成功继续修改 我这里已成功![](https://bbs.kanxue.com/view/img/face/28.gif) )。

拖入`OD`:

![](https://bbs.kanxue.com/upload/attach/201512/607869_jzawxrg8g4ro4fv.png)

完。
