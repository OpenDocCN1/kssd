# [原创]编译原理之词法分析简介

   我认为在工作闲暇时间多学习点原理性的知识,不仅能够使自己多沉淀一些知
识,而且能胜任更多的工作岗位。
   以下内容是在工作闲暇之余,并结合编译原理,github上某位大牛写的demo总 结出来的。若有理解错误,请指正。
