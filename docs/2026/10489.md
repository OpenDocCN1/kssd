
# [原创]关于使用高版本masm解决方案

小弟刚开始学罗云彬的《windows环境下32位汇编语言程序设计》

下载了`masm32`套装工具，发现里面的版本已经是很多年前的了，而自己本机上的`ml`已经是11（vc2012里的），而且`link`和`nmake`都是高版本的，但是如果编译例子，就会出现找不到`windows.inc`的提示

琢磨了半天，采用以下方案解决：

1.）通过vc2012的“VS2012 x86 本机工具命令提示”进入dos窗口

2.) 设置`include`，使其包含`masm32`里的`include`目录

```
set INCLUDE=%INCLUDE%;e:\masm32\Include
```

3.）运行`nmake`，成功

看了一下文件的生成时间，`masm32`里的`inc`头文件大多是2011年后更新过，应该能够支持到win7
