# 用SmartCheck破解魔装网神(NetMyth) V3.5 (2千字)

用SmartCheck破解魔装网神(NetMyth) V3.5

 作者：softs

 软件介绍：
    魔装网神是一个浏览器，主要特点如下：可以更换界面(Skins)，软件更漂亮。由于对系统缓存的最佳利用，软件的浏览速度比IE要快。魔装网神占用的内存比其他全副武装的软件要少得多。魔装网神平均每开15页占用1%系统资源，而一个IE就4%。能设置255个主页地址，方便打开你最常用的网页。一些网站在状态栏有字幕滚动效果，阻碍了用户观察当前网页读取状况、链接地址，现在你可以关闭掉这种效果。加入了黑名单功能，可以过滤掉指定的广告或不喜欢的网址。


 破解工具：SmartCheck 6.03
 开刀对象：魔装网神(NetMyth) 2001 V3.5 （目前最新版）

     运行“魔装网神”，点击注册按钮，输入用户名：zhuliang 注册码：987654321 点击确定，然后魔装网神要求重启验证，那我们就先关闭退出。

     启动SmartCheck载入NetMyth.exe后必须按要求配置好SmartCheck（在载入NetMyth.exe过程中若出现英文提示，打上对勾，不显示pcode(有时不出现)），然后点击Start按钮运行NetMyth.exe，过了较长一段时间之后，出现魔装网神界面完全时，点击End按钮暂停SmartCheck。


     首先在SmartCheck左边的窗口找到“＋\_Load”字样，它实际上是程序启动的过程，点击它，然后按Ctrl+F键，输入HEX，找到如下这么一段内容（注：如果在＋\_load下连续两次查找HEX，可直接来到10进制形式注册码出现处）：

     在上述关键“HEX”上方有一连串的“UCase”，自己点击看看吧，是黑名单出现处，包括您的注册用户名在内。


 将注册码37746866以10进制转换成16进制形式以便注册：得到23FF8B2

 整理一下，得到我的正版注册码为：

 用户名：zhuliang
 注册码：23FF8B2
