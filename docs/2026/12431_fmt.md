
# [原创]TDI防火墙框架

出于个人爱好想写一个防火墙，利用业余时间来完善这份代码，当实现了`TDI`防火墙的整体框架的时候发现`TDI`驱动居然无法捕获到`ICMP`封包（如果想捕获`ICMP`封包还必须用别的办法，比如`HOOK`某个`NDIS`的发包接口），发现这种情况觉得没有再继续写下去的必要了。。现在将该驱动源码放出来供大家参考学习，希望对一部分人有帮助![](https://bbs.kanxue.com/view/img/face/27.gif)

话说回来：拦截`TCP`、`UDP`、`RawIp`还是很好用的。![](https://bbs.kanxue.com/view/img/face/1.gif)

参考了部分科莫多防火墙的代码：）
