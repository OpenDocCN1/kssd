
# [原创分享]Flexnet Publisher V11.16及以下版本守护神加密种子点恢复方法

问题的提出：Flexnet Publisher V11.16已经做了改进，隐藏了原来恢复加密种子点的标志`3D4DA1D6`，无法利用其实现快速定位。

现提供两种方法：通用法和“`0F42400h`”标志法。

从`v11.4`之后的某个版本开始（具体哪个版本无从查起）`FlexLM`可以在链接时抛弃非ECC模式的验证，即使12位或20位都是对的也会被判定为不合法的。`V11.14` SDK的默认makefile就是用“抛弃了非ECC”的`lmgr_trl`库。未使用`lmgr_trl`库链接的守护神可以通过标志`0F42400h`来替代标志`3D4DA1D6`定位直接得到加密种子点。使用了`lmgr_trl`库链接的守护神只能采用通用法来恢复，但实际上即使恢复了加密种子点也毫无意义，因为它根本就不对非ECC进行验证，识别到该格式的模块直接认定为非法。如图，流程永远到不了左边
