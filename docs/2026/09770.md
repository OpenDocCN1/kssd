# 用NuMega SmartCheck 6.03获取魔装网神2.5的注册码（初学者请进) 
  (1千字)

用NuMega SmartCheck 6.03获取魔装网神2.5的注册码

作者：华仔

魔装网神又是一个VB的产物，未注册版本只能打开八个页面。这东西真有点
讨厌，注册时输入名字和注册码单击确定后一点反映都没有，它是在程序启
动时比对注册码的。曾想用TRW2000在它读取注册表时中断，但它读取的注册
表信息何止一两处，跳来跳去人都乏了（其实是功力不够），于是想到这位大
哥：SmartCheck。由于是初次使用该软件，不妥之处请指正。


○、运行“魔装网神”选注册，输入用户名：ZHENG HUA 注册码：1974923 再确
    定，让它将我们的注册信息写入注册表。

一、配置好 SmartCheck

二、启动SmartCheck并载入运行NetMyth.exe

三、一阵“暴风骤雨”过后一切又恢复了平静，魔装网神已进入了主界面，然后
    在SmartCheck的工具栏单击END图标以结束它的使命。现在我们可以坐下来
    “轻松轻松”了。

四、先来一段推理：一般情况下软件作者在设计软件时当读取完注册表中用户输入的注册信息

后可能要立即进行一下运算或校验，除非这个程序员是一个不怕麻繁的程序员，将这段代码放

在其它别的位置，人都有惰性，程序员也不例外。所以我们就来看一下它是在什么地方读取注

册信息的（找我们的关键字：ZHENG HUA和1974923），如果你只想获得软件注册码，你可以按

“CTRL+F”输入HEX 确定即可。

五、看一下SmartCheck左边的窗口有一个“+ \_Load”字样，它实际上是程序启动的过程，好

我们就点击它。出来很多内容，但我们更要注意在它里面还有一个“+ \_Load”字样，再点一

下，最后我们在“UCase”下找到“1974923”和“ZHENG HUA”字样，再下一点是“HEX”，这

才是我们的关键所在。“HEX”在SmartCheck右边窗口中的内容如下：

- string (variant)
  - signed lpng \* .plVal = 006CF1B4
      Long = 42672637 0x028B21FD 这就是我们要的注册码

在“HEX”下面有两个连续的“UCase”，经分析程序居然将你输入的用户名：“ZHENG HUA”

和“LiuJianYing”作比较，那么这个“LiuJianYing”应该是黑名单了吧，真是“人心不古，
世风日下”。
