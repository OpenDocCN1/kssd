
# [原创]Android 动态 so 调试

工具：IDA 6.5、Eclipse、Android SDK

1. `adb push android_server /data/`
2. `adb shell chmod 777 /data/android_server`
3. 在 `adb shell` 模式下，以 root 执行 `/data/android_server` 命令
4. 端口转发：`adb forward tcp:23946 tcp:23946`
5. 打开 Eclipse DDMS
6. 在 `adb shell` 模式下执行 `am start -D -n com.ffly.test/com.ffly.test.MainActivity` 以 debug 方式启动 app
7. 使用 IDA 附加，打开加载库，勾选 `Debugger -> Debugger setup -> Suspend on Library load/unload`，放过断点，代码执行
8. `jdb -connect com.sun.jdi.SocketAttach:port=8700,hostname=localhost`
9. 再次进入 IDA，到这里就已经是你想要的了

注：
- `android_server` 是 IDA 里面的一个执行文件
- `jdb` 是 JDK 下面的执行文件
