
# [原创]360 超级文件粉碎器 1.6 驱动分析

提前申明：本文只做技术交流，没有其他目的。

分析的是2010-08-17从官方下载的版本。

运行`360FileKiller.exe`，会释放一个文件名随机的exe，例如`FC9638FFCEFC.exe`，关闭`360FileKiller.exe`前`FC9638FFCEFC.exe`会被删除。可以在`360FileKiller.exe`关闭前将该文件复制一份，以便分析。点击“粉碎选中文件”后会释放`%SystemRoot%\system32\drivers\360IceBreaker.sys`，该驱动被加载后立即被删除。为了捕获该驱动文件，可以在`DeleteFileA`上下断即可。
