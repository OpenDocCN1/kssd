
# 企业壳反调试及hook检测分析

## 1. 写在开始
最近在学习梆梆壳加固思路，在调试的过程中遇到了反调试，很是苦恼，而且每次调试都会被中断，盆友在论坛发了篇帖子【1】介绍了其中的一个反调，学习后收获颇多，给我指明了方向，接下来再对其他反调试进行补充，仅学习目的，若有疏漏或不合理之处请各位大佬多多指教。

## 2. 反调试之时间线程检测
启动调试后是对帖子【1】的验证，过程大致如下：

运行`brpt.py`后一路`F9`,

|  |
| --- |
| #下断点  # 内存中获取模块基地址  base = FindModule('linker');  #.text:00002464     BLX        R4  addr = base + 0x2464; #该偏移值需要使用IDA静态查看linker模块的偏移值  #给linker下断点  AddBpt(addr);  #在libc.so中对库函数下断点  AddBpt(LocByName('fopen'));  AddBpt(LocByName('ptrace')); |

当`lr`为`pB54EB0CAE49198754C66F4A57BDB01DF`函数时即为第一个反调试的线程创建处，然后会调用`libDexHelper.so:pDD8ABF73B0AE99BD998BC5C954A74856`，

![](https://bbs.pediy.com/upload/attach/201801/657161_6UM9DBKK7PNDZUP.jpg)

再按一次`F9`即可断到帖子中提到的`fopen`函数处

![](https://bbs.pediy.com/upload/attach/201801/657161_2CMQZTZA2C69AX4.jpg)

执行完`fopen`后，回到调用函数`libDexHelper.so:p8878CAA1006835C9D43174C88143BA8B+A6`处，然后在如下所示处下断点，`F9`执行到此处，观察寄存器的值并做相应的修改，具体思路就是要跳过`libDexHelper.so:AEDC62A8 BLX   sub_AEDA6ECC`这个函数调用即可。

![](https://bbs.kanxue.com/upload/attach/201801/657161_FZDE575W5FUZE42.jpg)

执行完成后，会跳出调用函数，来到下图处将`r0`寄存器的值修改为`0`，或将指令`#1`改为`#0`即可。

![](https://bbs.kanxue.com/upload/attach/201801/657161_B3EQX4AEM7BWAN2.jpg)

并在`p39D6B1EED99DC7E506A9D4E07BD58D3A`处下断，

![](https://bbs.kanxue.com/upload/attach/201801/657161_YXHX6FNY3C7JASY.jpg)

执行完之后`F9`，则会跳到`p39D6B1EED99DC7E506A9D4E07BD58D3A`处，

![](https://bbs.kanxue.com/upload/attach/201801/657161_76WJN9ZP7VPESJS.jpg)

该函数功能类似`kill`，具体过程参考帖子【1】。
