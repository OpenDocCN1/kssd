### 1、常量、变量赋值

- 比如我们想定义变量`A`为整型数据：

VB：

```vb
Dim a as Integer
```

Delphi：

```pascal
a:integer;
```

VC：

```c
int a;
```

- 定义常量`B`为16进制值`75BCD15`：

VB：

```vb
b=&H75BCD15
```

Delphi：

```pascal
CONST
b=$ 75BCD15
```

VC：

```c
CONST LONG b=0X75BCD15
```

### 3、基本语句（只讲最常用的三种，更多的内容看附件）

#### ① 赋值语句

**VB：**

`变量 = 表达式`

例：

```vb
Dim a As Integer
a=100*20
```

`Set 变量 = 表达式`

例：

```vb
Dim ex As DataBase
Set ex=OpenDataBase("File.mdb")
```

**Delphi：**

赋值语句的符号是冒号＋等号即 `:=`

例：

```pascal
A:integer;
A=$ 75BCD15
```

**VC：**

变量名，后接`=`

例：

```c
a = 10
```

变量定义 = 变量名

例：

```c
long b;
```

#### ② 循环语句

**VB：**

```vb
For var = start To end [Step step]
    ...
Next var
```

例：

```vb
For I = 1 To 8
N = n + I
Next I
```

**Delphi：**

```pascal
for 循环变量 := 初值 to 终值 do
    循环体语句

for 循环变量 := 初值 downto 终值 do
    循环体语句
```

例：

```pascal
for i:=1 to 8 do
begin
n := n+i
end;
```

**VC：**

```c
for(statement1; statement2; statement3) {
    /* body */
}
```

例：

```c
for(i = 0; i <= 8; i++) {
    a[i] = i + i;
}
```

#### ③ IF语句

**VB：**

```vb
If 表达式 Then
    ...
Else
    ...
End If
```

例：

```vb
If Password=str Then
    MsgBox "true"
Else
    MsgBox "false"
End If
```

**Delphi：**

```pascal
if 表达式 then
    语句1
else
    语句2
```

例：

```pascal
If Password=str Then
begin
    ShowMessage(' True');
end
Else
begin
    ShowMessage('False');
end
```

**VC：**

```c
if ("条件") {
} else {
}
```

例：

```c
if(Password=str )MessageBox('true ',4);
else{
MessageBox('false ',4);
}
```
