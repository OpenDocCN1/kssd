
# [分享] 配置 IDA 与 x32dbg 的地址对应

## 在 IDA 中找到信息后如何在 x32dbg 中定位

下面提供方法

关键字：装载地址（`Image Base`）, `IDA`, `x32dbg`

### 1. 首先用 `x32dbg` 加载程序，打开符号菜单找到主模块，拖动代码到顶部，这样就找到 `image base` `00171000`

![图片描述](upload/attach/202212/943193\_4H269C3KNRFBCU9.png)

### 2. 然后打开 `IDA` 菜单 -> `Edit` -> `Segments` -> `Rebase program...`

打开菜单 输入 `Image base` `00171000`, 点击 `OK`

![图片描述](upload/attach/202212/943193\_KMZVV3M26NU7KHX.png)

### 验证看是否地址统一了
