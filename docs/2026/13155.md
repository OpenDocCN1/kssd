# 零、有啥用
网上大多数的微信逆向思路，是CE搜索数据得到地址，OD下访问断点，然后在堆栈里面大海捞针的找Call，效率太低了。
其实微信的界面是用Duilib做的，Duilib的界面布局写在XML文件。然后界面的消息处理，是通过控件名处理的。比如发送按钮，XML文件里面是"send\_btn"，代码里面是 if(xxx== "send\_btn")。利用这个特性，可以直接用字符串定位，省事很多。
