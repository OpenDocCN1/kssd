
# [原创]Revo Uninstaller PRO证书校验机制分析

## 1、前言

Revo Uninstaller PRO是一个比较好用的卸载工具，官网最新版本为目前4.1.5版本。

安装后会有30天的使用期限。

![](https://bbs.kanxue.com/upload/attach/202002/802790_9XNC7PK3K2XSQEK.jpg)

对现存网上的破解工具进行分析，发现其网上大部分流传的破解工具，其实现原理，皆为证书替换。

而证书替换中，证书里面的到期时间无法改变，仍然会存在到期时间。到期时间的2019/10/1。

![](https://bbs.kanxue.com/upload/attach/202002/802790_RNAG99SPYHTCK2V.jpg)

![](https://bbs.kanxue.com/upload/attach/202002/802790_8RNS5T824Z2AK52.jpg)

总结：现存网上流传的破解机制，并没有实现完全破解。

## 3 分析证书流程

### 3.1 分析`ruplp.exe`

初步想法是，看能不能找到证书有效期等关键代码，对证书进行伪造和证书验证过程中某些逻辑进行破解。

定位代码`ruplp.exe`中读取证书代码，拖入IDA。

![](https://bbs.kanxue.com/upload/attach/202002/802790_VCJEP6PYE9QJ72P.jpg)

此处时一个入口，开始创建并且读取license证书文件。

选取函数引用，走到最外层。逐层分析

![](https://bbs.kanxue.com/upload/attach/202002/802790_GF8R9DKY7MMVQY2.jpg)

找到一些字符串，开始会进入读取证书。

![](https://bbs.kanxue.com/upload/attach/202002/802790_2G45W7TY6N7RWF6.jpg)

![](https://bbs.kanxue.com/upload/attach/202002/802790_GQTU4RS3SBKZJG4.jpg)

该函数会对读取的证书各种参数和配置，下面的处理流程会根据`analysisLicense()`函数处理的证书的返回值。提示读取证书状态。

![](https://bbs.kanxue.com/upload/attach/202002/802790_PQMDJNRQ8YZT6Z7.jpg)

对读取大致是，先读取`.lic`文件`0xF000`字节，取一部字节进行校验。

在读取剩余`.lic`证书文件的剩余字节进行校验。

![](https://bbs.kanxue.com/upload/attach/202002/802790_BP2B3XKS9P9VD8P.jpg)

将解析出证书配置信息的提取出来，放进证书类文件中。

以下是证书解析后在，内存拷贝出来的数据。

![](https://bbs.kanxue.com/upload/attach/202002/802790_8AAUPQM4KX6GK8V.jpg)

![](https://bbs.kanxue.com/upload/attach/202002/802790_ZV52A88BMUTNR9Q.jpg)

发现了对证书进行网络校验的网址：`c02K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6J5k6h3N6A6M7%4c8W2M7Y4y4W2M7Y4k6W2M7W2)9J5k6h3&6W2N6q4)9J5c8U0x3%4y4o6p5&6x3e0b7#2i4K6u0r3L8s2m8%4M7#2)9J5k6h3q4K6L8i4R3`.

![](https://bbs.kanxue.com/upload/attach/202002/802790_D72EFRGWVBD27T4.jpg)

并且，`procmon`监控到有网络连接行为。

![](https://bbs.kanxue.com/upload/attach/202002/802790_M8NA43VWWNSBKPG.jpg)

对这个网络行为抓包分析。

![](https://bbs.kanxue.com/upload/attach/202002/802790_KZDQGCHWXC8D5CG.jpg)

![](https://bbs.kanxue.com/upload/attach/202002/802790_SE5QSAY6J8YUNDF.jpg)

分析发现，注册验证过程会调用证书验证的`ASReq`接口。`ruplp.exe`这个证书保护程序，会存储证书一部分信息、用户名和注册码，`RSA`加密发送至网络验证，校验注册证书的合法性，并返回一段密文。由于证书采用非对称`RSA`加密，关键信息全程以加密方式存在。`ruplp`程序中并没有找到破解口，也无法伪造证书。

### 3.2 分析`RevoUninPro.exe`

从语言选择文件中找到注册版本和未注册版本提示

![](https://bbs.kanxue.com/upload/attach/202002/802790_APJ2NQP7Y7HSPVT.jpg)

监控`.ini`可以获取`RevoUninPro.exe`的读取文件代码，找到其读取配置代码。

![](https://bbs.kanxue.com/upload/attach/202002/802790_CXUY3ZCKBBPV9F4.jpg)

继续往下跟踪代码。

找到读取证书数据中，继续进入验证证书数据函数代码。

![](https://bbs.kanxue.com/upload/attach/202002/802790_KYFDQWWEM94BT92.jpg)

校验证书数据。

![](https://bbs.kanxue.com/upload/attach/202002/802790_FTBSRZYKQFHUU3F.jpg)

取出校验返回值，根据返回值来决定是注册版本还是未注册版本。

![](https://bbs.kanxue.com/upload/attach/202002/802790_2WYSVYDPM43QPNM.jpg)

于是，第一个破解点出来了，直接爆破。

![](https://bbs.kanxue.com/upload/attach/202002/802790_QWMNFNG9P3UDHND.jpg)

继续分析，发现其输入表有`WINTRUST.DLL`和`WinVerifyTrust()`函数。

![](https://bbs.kanxue.com/upload/attach/202002/802790_GY7NHZZBYRY6D6V.jpg)

百度一下`WinVerifyTrust()`函数：微软官网解释已经很明显了，`WinVerifyTrust`的用法，是用来验证证书用的。

![](https://bbs.kanxue.com/upload/attach/202002/802790_QU8GTQYZ4CMM5M6.jpg)

第二个爆破点出现，继续爆破patch.

![](https://bbs.kanxue.com/upload/attach/202002/802790_PR54W5CFDJFKFXH.jpg)

爆破点，增加强制跳转。

![](https://bbs.kanxue.com/upload/attach/202002/802790_8HVU9NS44EF5MYR.jpg)

破解成功。时间限制完全去除。

![](https://bbs.kanxue.com/upload/attach/202002/802790_ENY6EJKE6GD7VTB.jpg)
