## 方法一

以下仅部分适用于破解“教程”。

> 注意：资源管理器的配置中选中“显示使用文件”，否则你看不见具有隐藏属性的`Y26356.exe`文件。

该软件使用`VFP&EXE`加密处理，如对其`胜新库管王.EXE`进行处理，那你就自认倒霉吧。

其实当你在启动`胜新库管王.EXE`后，再运行`TaskInfo2000 2.2`，你将发现有一个名为`W25677.exe`的文件，该文件子进程显示“胜新库管王”，可推断出`W25677.exe`可能为软件自动脱壳后的真正FOXPRO编译的`胜新库管王`主程序。

但是，该文件位于`c:\RECYCLED\ \ \ \0`目录下，如你用资源管理器查看`c:\RECYCLED`，由于WIN98保护机制你将一无所获。

同时`胜新库管王.exe`进程对该文件进行了保护，当你复制`c:\RECYCLED`时显示“文件的一部分被锁定”，这时你可用`TaskInfo2000 2.2`中止`胜新库管王.exe`进程（注意：不是中止`W25677.exe`）以去掉锁定。

到此，剩下的问题是将`W25677.exe`文件单独分离复制出来，以便进行相应处理。

### 方法如下：拷贝即可

1. 当你用`TaskInfo2000 2.2`中止`胜新库管王.exe`进程后，使用资源管理器复制`c:\RECYCLED`整个目录到`d:\1`子目录下。
2. 使用`WINZIP.EXE`对`d:\1`进行压缩，以使`W25677.exe`进入压缩包`1.zip`。（利用`winzip`的不带路径解压缩功能可将`W25677.exe`解出）
3. 打开`1.zip`，你将看见`W25677.exe`文件。
4. 选中`W25677.exe`文件对其解压缩，注意：此时将释放对话框中的“use folder name”前面的勾去掉。
5. 至此`W25677.exe`文件已被分离出来，剩下的事你就看着办吧。
