```

# 进入AFL++下的qemu_mode
cd aflplusplus/AFLplusplus/qemu_mode/
export CPU_TARGET=arm
./build_qemu_support.sh
```

afl++的qemu mode目前还不支持MIPS，找了一个arm的，不过有点问题。

下载解压到home目录下

```
cd
cd squashfs-root
./bin/busybox
```

报错 /lib/ld-uClibc.so.0: No such file or directory

原因：没有设置QEMU\_LD\_PREFIX

![](https://bbs.kanxue.com/upload/attach/202104/922479_PSEPJMFKWCQ633Y.jpg)

```
export QEMU_LD_PREFIX=$PWD
./bin/busybox
```

报错 /lib/ld-uClibc.so.0: Invalid ELF image for this architecture

链接问题

原因：原文件的问题，链接文件的格式全错了，按下面的命令把所有文件分别链接。

![](https://bbs.kanxue.com/upload/attach/202104/922479_4Y6B9A4QVNFRKXE.jpg)

以其中一个为例，如果全部链接完成，busybox就能顺利执行了。

```
cat ld-uClibc.so.0
rm ld-uClibc.so.0
ln -s ld-uClibc-0.9.33.3-git.so ld-uClibc.so.0cd
```

![](https://bbs.kanxue.com/upload/attach/202104/922479_UVMVHBTA7K773B9.jpg)

```
ls -l
../bin/busybox
```

链接全部完成，busybox就能正常执行了

![](https://bbs.kanxue.com/upload/attach/202104/922479_AARSGBYGF4D2EFR.jpg)

```
# 回到squashfs-root目录下
cd ..
rm -rf fuzz_*

afl-fuzz -i inputs -o outtt -Q -- .binbusybox awk '{print$1}'
```
