# [原创]简单分析某语音聊天软件账号&密码

注册坛子账号好长时间了，第一次发帖，没有什么技术含量，高手勿喷，如有错误欢迎指正。![](https://bbs.kanxue.com/view/img/face/16.gif)

突破点：在登录的时候用户名和密码会转为unicode。![](https://bbs.kanxue.com/view/img/face/12.gif)

打开软件，输入账号密码123456 888888。
在od中bp MultiByteToWideChar ，点击登录按钮

注意：在鼠标移动到登录按钮上时会连续断几次，这里一直f9运行，停止后点击登录按钮。
断下后 在按几次f9后在堆栈中可以看到密码明文：

![](https://bbs.kanxue.com/upload/attach/201408/227314_l8pqax1t4wcz2rn.png)

在这里取消断点，Ctrl+f9向上返回两次左右堆栈情况如下：

![](https://bbs.kanxue.com/upload/attach/201408/227314_yuhnu0zdb48is46.png)

注意这里
![](https://bbs.kanxue.com/upload/attach/201408/227314_wzq5s37mm45uvvl.png)

在这里有一个以密码作为参数的CALL，反汇编窗口中跟随到调用处。
我在再次输入密码000000，在函数头下段，点击登录按钮。单步分析这个函数
![](https://bbs.kanxue.com/upload/attach/201408/227314_vni28wecj685rs5.png)

密码解密CALL：
![](https://bbs.kanxue.com/upload/attach/201408/227314_xunwx10q5kwzxb5.png)

考虑到账号应该是与密码在相邻的位置处理的，所以再次输入账号密码 在函数头再次下断，再向上返回几层来到下面的位置
![](https://bbs.kanxue.com/upload/attach/201408/227314_yl6d2ztrfv5gzrz.png)

在这个函数头下断，在输入账号密码登录，继续单步分析应该就可以找到账号了。
分析过程是几个月前分析的。现在不知道账号这里面有没有变化，大概流程是这样的。账号就不跟踪了哈。
