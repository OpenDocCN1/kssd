# [原创]又是一个map载入工具...

这几天用ida+od分析程序，为了把ida的函数名导到od中方便分析，
先数据不多，肯吃肯吃的alt+g,ctrl+c,ctrl+v.
后数据太多，找了些插件，mapcov,map loader....
不知道是ida还是od版本还是rp问题，这些插件导入到od都有大大小小的问题。
于是自己写了个。
ollyice v1.10 汉化第二版。
ida6.1.110315 32bit

ida->file->producefile->create map file->只选demangle names+localnames,生成map文件。

od->插件->IDAMap文件载入工具->载入标签,或者载入注释。

很快，因为没用insertname,用的Quickinsertname,
标签注释都是载入后生效....

nk多个注释标签,无一丢失。

如果你用得不舒服。。。。和我学，归结为版本/rp问题。
