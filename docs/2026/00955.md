
# [原创]又是一个map载入工具...

这几天用`ida`+`od`分析程序，为了把`ida`的函数名导到`od`中方便分析，

先数据不多，肯吃肯吃的`alt+g`,`ctrl+c`,`ctrl+v`。

后数据太多，找了些插件，`mapcov`,`map loader`....

不知道是`ida`还是`od`版本还是`rp`问题，这些插件导入到`od`都有大大小小的问题。

于是自己写了个。

`ollyice v1.10` 汉化第二版。

`ida6.1.110315` 32bit

`ida`->`file`->`producefile`->`create map file`->只选`demangle names+localnames`,生成`map`文件。

`od`->插件->`IDAMap文件载入工具`->载入标签,或者载入注释。

很快，因为没用`insertname`,用的`Quickinsertname`,

标签注释都是载入后生效....

`nk`多个注释标签,无一丢失。

如果你用得不舒服。。。。和我学，归结为版本/`rp`问题。
