## 3. 反汇编VM代码

基本思路i就是将VM代码反汇编出来，然后看这个给予堆栈的虚拟机的代码（不是X86汇编了）。

void VMCode()
{
    HANDLE hVMcode;//VM code
    HANDLE hDatad;
    BYTE buf1CRC32[8419]; //8418=1020*8+258,1020/6=170
    char VMCodeLine[100];
    BOOL iread;
    int i,LineNUm=0;
    int iVMcode;
    DWORD VMdata;
    DWORD dwSize;
    DWORD BytesWritten;

    hVMcode=CreateFile("VMCode.txt",GENERIC_WRITE,0,NULL,OPEN_ALWAYS,FILE_ATTRIBUTE_NORMAL,NULL);
    hDatad=CreateFile("Datad.dat",GENERIC_READ,FILE_SHARE_READ,NULL,OPEN_EXISTING,FILE_ATTRIBUTE_READONLY,NULL);

    //LineNUm: VMcode Data
    for(i=0;i < 8419;i++)
    {
        iVMcode=buf1CRC32[i];
        switch(iVMcode)
        {
        case 1:
            VMdata=(buf1CRC32[i+4] << 24) | (buf1CRC32[i+1] << 16) | (buf1CRC32[i+2] << 8) | (buf1CRC32[i+3]);

                VMCodeLine[19]=0x0D;
                VMCodeLine[20]=0x0A;
                VMCodeLine[21]=0;

            }

            {
                VMCodeLine[20]=0x0D;
                VMCodeLine[21]=0x0A;
                VMCodeLine[22]=0;

                VMCodeLine[21]=0x0D;

# 5.注册机

检查注册码的结果保存在一个结构里面：

```c
typedef struct result
{
        unsigned short Time; //45
        //30959(1990.1),Not equal with 30E0B,
        //00030959=199001
        //0030E0B=200203,等于200203时要检验黑名单

        char  a ;           //46
        // ;<=0，设为0

        char  t  ;            //47
        //54'T'

        char  e  ;            //48
        //45'E'

        char  v  ;            //49
        //19＝25，版本号为2.5，

        char  flag ;          //4A
        //1,为1表示true

        unsigned short   c;   //4B
        //01,01F4,2,63,3E8,7CF
        //；为1时，直接去比较时间是否为200203
        //；2《＝x《＝63   good boy
        //；63《x《1F4 bad boy
        //；1F4《＝x《＝3E7 good boy
        //；3E8《＝x《＝7CF good boy
        //；》7CF bad boy
        //；为其他值时，时间必须不等于200203

        int  remainder ;           //4C
        //0001C0E0 ,必须不在黑名单内
} RESULT;
```

- `[43]`：存放序列号地址`PSerial`
- `[44]`：存放结果的地址，`pResult`，`12F5E7`
- `[45]`：`base[45]=base[5B] mod 258`
- `[46]`：`base[46]=base[5B] mod 31`
- `[4A]`：`base[4A]=sang / 7D0`，`base[4A]=base[4A] Xor (base[4D] and 3F)=1`，`sang=base[5B]/258`
- `[4B]`：`base[4B]=sang mod 7D0`
- `[4C]`：`base[4C]=a mod 常数`，`7BFC138460-989680*D003=1C0E0`，保存到`4C`，`a=base[5B]/31`的商
- `[4D]`：`CRCsum`，`base[4D]=a/常数`，`7BFC138460 /00989680=D003`，保存到`4D`
- `Result`由`base[5B]`而来
- `[4E]`：`CRCsum`，初始化为`-1`
- `[4F]`：`base[4F]=4E`，指向`4E`
- `[50]`：存放`43`，`ppSerial`
- `[51]`：计数器`i`
- `[52]`：计数器`j`
- `[53]`：`base[53]=10(8,20)`，初始化
- `[54]`：`base[54]=0(base[45])`，数据，求`CRC16`
- `[55]`：`base[55]`存放`[4E]`的`TopBit`
- `[56]`：`base[56]=16A4(即T*E)*1A(19+1)=24CA8`，切入点
- `[57]`：`base[57]=(base[51] *(base[56] and 3)) xor 0x98B2`（`0x98B2`为常量）
- `[58]`：保存余数
- `[59]`：`base[59]=base[59] *22`
- `[5A]`：`base[5A]=(base[5A]*3 +base[5C]) mod 64`
- `[5B]`：`base[5B]=base[5C] * base[59] + base[5B]`
- `[5C]`：`base[5C]`，比较的结果，`0`或`1`
- `[5D]`：保存长度
- `5D-43+1=1B(27)`
- `[5E]`：无此变量
