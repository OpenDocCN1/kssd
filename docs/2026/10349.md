
# [原创]二级指针分析

> 一级指针中存放的是普通变量的内存地址

二级指针中存放的是一级指针的地址。

二级指针的作用？

如果指针做实参，那么传实参的指针（地址），就必须使用二级指针。通俗的说，要改变指针的值，必须传指针的指针（地址）。

## 二级指针关系图分析

![图片描述](upload/attach/202203/913912_U4HBM9SFW7VCMW3.png)

```c
int a = 10;
int *p = &a;
int **pp = &p;
```

根据上面关系图，我们可以理解为`a`存在`p`里，`p`存在`pp`里，解引用一次就往右移动一次。

```text
解引用
*p为a
根据上面关系图往右移动一次
*p==a==10
p是指针类型，里面存的是a的地址，*p是解引用得到a，a就是10
*pp为p
根据上面关系图往右移动一次
*pp解引用为p，里面存放的是一级指针的地址，p就是一级指针
**pp为a
根据上面关系图往右移动两次
**pp = a
```

## 二级指针案例分析

`i`、`j`、`p1`、`p2`的值各是多少？

```c
#include <stdio.h>
#include <string.h>
#include <malloc.h>

void f(int** ptr1, int* ptr2) {
    int* tmp = ptr2;
    **ptr1 *= 10;
    *ptr2 *= 10;
    ptr2 = *ptr1;
    *ptr1 = tmp;
}

int main() {
    int i = 0, j = 20, *p1 = &i, *p2 = &j;
    f(&p1, p2);
    return 0;
}
```

我们逐行分析。

### 第一步：传参的时候

```c
f(&p1, p2);
void f(int** ptr1, int* ptr2)
```

参数1，形参二级指针，传的是`p1`的地址。

参数2，形参指针，传的是值，`p2`的值等于`j`的地址，传值不改自身。

根据调用约定从右往左依次入栈。

![图片描述](upload/attach/202203/913912_ACGBZ3UEGZMUUT7.png)

### 第二步

```c
int* tmp = ptr2;
```

`tmp`局部变量指向`p2`。

![图片描述](upload/attach/202203/913912_V3JDS48C2QXDTDK.png)

### 第三步

```c
**ptr1 *= 10;
```

参数1乘10，参数1指向`i`，`i * 10 = 0`，不变。

---

### 第四步

```c
*ptr2 *= 10;
```

`*ptr2`就是参数2，传的是`j`的地址，`j = j * 20`，`j = 200`。

![图片描述](upload/attach/202203/913912_C3HJZV9RYUW8H6H.png)

### 第五步

```c
ptr2 = *ptr1;
```

参数2指向参数`&p1`解引用一次的地址，也就是`p1`。

![图片描述](upload/attach/202203/913912_7WHVC3M69KGPY5K.png)

### 第六步

```c
*ptr1 = tmp;
```

参数1解引用一次，指向`tmp`；也就是`&p1`解引用一次等于`p1`，`p1`指向`tmp`。

![图片描述](upload/attach/202203/913912_SM5CMPPW5MVAF2R.png)

结果为：

```c
printf("%d\n", i);
printf("%d\n", j);
printf("%d\n", *p1);
printf("%d\n", *p2);
```

```text
i=0
j=200
p1=j=200
p2=j=200
```
