
# [原创]植物大战僵尸全屏秒杀

## 一、前言

此文只为记录这一修改方法。

## 二、思路

如何做到秒杀僵尸？之前的思路是找到植物攻击语句，当植物攻击后僵尸血量为0时即会跳转到僵尸死亡处理语句，修改跳转流程使植物攻击后直接跳转到僵尸死亡处理，即可实现秒杀。此处的秒杀需要植物攻击才行。

如何实现无需植物攻击，自动全屏秒杀僵尸？

在网上找到这样一份基址（全部基址以附件形式附后）：

- **怪物数上限 `+768 +94`**
- **当前怪物数 `+768 +a0`**
- **怪物: `+768 +90`**
  - `+8` x坐标(图像位置) 4字节
  - `+c` y坐标(图像位置) 4字节
  - `+18` 是否可见 0为不可见
  - `+1c` 所在行数 0~5
  - `+28` 死亡及状态 0为正常 1为消失 2为变黑 3为秒杀
  - `+2c` x坐标(真实位置) 浮点数
  - `+30` y坐标(真实位置) 浮点数
  - `+64` 换道: 1为下 2为上
  - `+ac` 冰冻时间 (减速)(倒计时)
  - `+b0` 黄油糊脸 (不动)(倒计时)
  - `+b4` 冻结时间 (不动)(倒计时)
  - `+b8` 魅惑僵尸 不等于65536时魅惑
  - `+c8` 当前血值
  - `+cc` 血值上限
  - `+ec` 神秘消失 1为消失(不可逆)
  - `+118` 隐身 为某16位值时现形(有影子)
  - `+11c` 怪物大小初始为1 浮点数
  - `+15c` 下一个怪物

上面加粗的三行为实现全屏秒杀的关键。从上面的基址表可以看到僵尸的死亡状态为`基址+768 +90 +28`，其中0为正常，1为消失，2为变黑，3为秒杀。

我们可以将死亡状态赋值为3，即可实现秒杀。此处我没有采用寻找僵尸数组，然后依次赋值的办法（僵尸并不是一次全部出现在屏幕里，我不确定未出现的僵尸在不在僵尸数组中）。从上面的基址表得知僵尸的X坐标基址为`基址+768 +90 +2c`，我们还知道出现在屏幕中的僵尸X坐标都是实时变化的，我们找到修改X坐标的语句，然后加入将僵尸的死亡状态赋值为3的语句，这样当僵尸走动时即被秒杀。

我们知道，不同版本的植物大战僵尸基址和偏移是有区别的，但是像僵尸数据这种结构体内的数据偏移一般是固定的，那么我们可以先找出僵尸血量的地址，然后推算出僵尸X坐标和死亡状态的地址。

## 三、实现

先在CE中搜索到僵尸的血量如下：

![](https://bbs.kanxue.com/upload/attach/201804/532046_TE95BNRNZJ6NYJ6.jpg)

CE中查找是什么写入了这个地址：

![](https://bbs.kanxue.com/upload/attach/201804/532046_7EANCHKRW4SC9CK.jpg)

我们看到，僵尸减血时血量地址为`edi+C8`，与上面的基址表中的相同，那么我们用`edi+2C`就是X坐标的值。我们用CE查看一下当前`edi`的值，然后在地址列表中手动填加`edi+2C`的地址，type改为`Float`，如下:

![](https://bbs.kanxue.com/upload/attach/201804/532046_STNF5MJP7CH6YMY.jpg)

现在查找是什么写入了X坐标的地址，如下：

![](https://bbs.kanxue.com/upload/attach/201804/532046_9QFUT3QPT2ED2BF.jpg)

内存中显示汇编（show disassembler按钮），如下：

![](https://bbs.kanxue.com/upload/attach/201804/532046_HYQ57KURWW6537R.jpg)

我们在此用CE的自动汇编（请原谅，此处不会截图），如下：

```asm

//code from here to '[DISABLE]' will be used to enable the cheat

//place your code here

originalcode:
fstp dword ptr [esi+2C]
jne PlantsVsZombies.exe+13B4EC

exit:
jmp returnhere

jmp newmem
nop
nop
nop
```
