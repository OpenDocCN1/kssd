# [原创]Android 7.0 framework逆向分析

Android4.4以后开启了art，apk安装后系统会提取dex优化为odex。系统应用更是将dex优化成oat文件，一个oat中可能包含了多个dex。今天就开始从oat中提取dex并转smali和jar来进行逆向分析。

以framework.jar为例。

1. 导出手机中的framework文件中的所有文件

2.下载oat2dex.jar并开始提取boot.oat中的framework.jar的dex。

![](http://bbs.pediy.com/upload/attach/201707/757146_xazxiu6d35nguh1.png)

3.将导出的dex转成jar

![](http://bbs.pediy.com/upload/attach/201707/757146_iblsctvntq8cfw9.png)
