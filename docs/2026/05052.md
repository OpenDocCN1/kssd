# [原创]利用TGP接口查数据

用过TGP的筒子都知道TGP有一个战绩查询接口，我们做为第三方也想用接口怎么办? (1.找TX谈接口开放，人家让你有多远gun多远。2.花钱用网上其它平台，三天二头出事用不了。3.自己动手，丰衣足食。)

由于楼主从分析TGP到现在间隔时间太久，这里就不描述分析过程了，只是大概讲解和源码开放。

1.TGP中有些接口是不需要cookie的，可以直接拿到数据。

3.我们再开发一个web服务器，只需要定时自动登陆TGP更新自用cookie，就可以四平八稳的拿到战绩数据了。
