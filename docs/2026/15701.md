
# [分享] Python 版本的 Dex 解析器

2 年前，为了了解 Dex 文件格式，顺手写了一个 Dex 解析器，支持 Dex 的反汇编功能。

同时也支持将 Dex 中的 Java 类导出为类似 C/C++ 语言的头文件。

类似下面的头文件：
