不知道大家是否在手机上使用天气预报软件，我以前没有用，某天碰到kaka，他在用BerryWeather，于是我也想用起来，但是碰到几个个问题，其中之一就是：
这个软件是收费的，需要根据PIN码注册（其他问题与本论坛无关，不在此讨论）

经过查阅网络资料，了解到一些新的信息：
好消息，以前叫做BerryWeather的这个软件，现在已经改名字叫BeWeather了（据说RIM不允许App World上的软件带上Berry这个关键字），以前的BerryWeahter未注册版只能体验3天，现在作者发布了BeWeather Free这个免费版本，虽说功能少点、稍有不便，但总体上够用了，界面也不错，大家可以直接下载BeWeather Free 2.2.1这个最新版本使用，具体下载方式，我是先安装了App World，再用App World搜索下载的。

既然这样，我就想安\*\*erryWeather老版本（我用的是1.5.35），并尝试在模拟器环境破解，然后用破解出来的注册码安装注册稍微新一点的版本（1.6.XX）。（不好意思，这个破解实在不厚道啊，有实力的朋友还是购买正版支持作者吧：）

这里用到的破解方法，是在网上看到资料提及的，但往往描述得比较简单（虽然过程的确简单，但是如果希望大家都能自己DIY的话，还是图文并茂比较好啊，尤其是新手）。

这里分享此文，是希望让大家看到如此熟悉的技术在其他领域的应用。（至少我有此感受）

【详细过程】
1、安装RIM开发软件中的模拟器，我是安装了完整的JDE 4.7和模拟器的，其实只需要模拟器就行了；并准备好OllyICE这个调试工具（google就行）；
2、找到你的模拟器所在位置，并修改其中的一个批处理文件，通常在这里：
C:\Program Files\Research In Motion\BlackBerry JDE 4.7.0\simulator
也有可能在这里：
C:\Program Files\Research In Motion\BlackBerry Smartphone Simulators 4.7.0\4.7.0.65 (9500-Vodafone)
由于我装了JDE（自带模拟器），又单独装了一个模拟器，所以上面两个地址都有的，我选择上面一个模拟器进行破解工作。
在上述目录中，找到\*.bat文件：
例如第一个目录中是这样的：defaultSimulator.bat、9500.bat、9530.bat（有3个）
而第二个目录中是这样的：9500-Vodafone.bat（只有1个）
你可以挑一个进行修改，例如我们修改9530.bat吧：


```
@echo off 
fledge.exe /app=Jvm.dll /handheld=9530 /session=9530 /app-param=DisableRegistration /app-param=JvmAlxConfigFile:9530.xml /data-port=0x4d44 /data-port=0x4d4e /pin=0x2100000A
```



把最后这个“/pin=0x\*\*\*\*\*\*\*\*”里面的\*\*\*\*\*\*\*\*改成你自己的BB的PIN码，然后保存。
如何知道你自己的PIN码，不用多说了吧，机器的Options-Status里面就有。
3、保存好.bat文件之后，记得看看所在目录，如果你之前启动过模拟器，这个目录中会有些文件需要删除，你可以通过查看文件最后修改时间的方式，来决定删掉哪些文件，因为我开发BB程序的时候，它会生成这些缓存等文件，所以我把这些文件剪切到其他地方去了（这样即使弄错了还能挪回来，如果直接删掉可能就不容易恢复了）：
![](https://bbs.kanxue.com/upload/attach/201003/326842_eoqb64m9fe5to0c.jpg)
（在每次破解前，我都挪走这些已经选择的文件）
4、挪走上述文件之后，就可以点击运行9530.bat文件了，这时候它会运行模拟器：
模拟器运行起来之后，是这样的：
![](https://bbs.kanxue.com/upload/attach/201003/326842_hl6ddbf49qvjwj2.jpg)
5、点击菜单“File-Load Java Program...”，选择BerryWeather 1.5.35的那个cod文件，这样，模拟器里就有BerryWeather 1.5.35了：
![](https://bbs.kanxue.com/upload/attach/201003/326842_kidl70pirokksu6.jpg)
6、运行BerryWeather 1.5.35，它会提示你注册：
![](https://bbs.kanxue.com/upload/attach/201003/326842_nsbu56kukucigql.jpg)
7、随便输入一个注册码（不要用123456这样的！因为这个在内存里会重复出现，要输个不容易重复的，比如我输入335577）：
![](https://bbs.kanxue.com/upload/attach/201003/326842_2z8aldjaipja0ig.jpg)
8、输好之后，按向下的箭头或回车，点一下“Register”按钮，程序会报错，说这个注册码不正确（废话，当然不正确）：
![](https://bbs.kanxue.com/upload/attach/201003/326842_wx5taetwvngcvyu.jpg)
9、这时候就可以打开我们的OllyICE调试工具了，打开之后，点菜单：“文件-附加”，然后选择fledge这个进程：
![](https://bbs.kanxue.com/upload/attach/201003/326842_ien4lh12x328kew.jpg)
10、确定之后，这个进程就被附加进来供我们调试了，然后按一下Alt+M，调出Memory Map窗口（把它放在最前面，或者把CPU窗口关闭也行），好了，再按一下Ctrl+B，调出查找二进制数值的窗口：
![](https://bbs.kanxue.com/upload/attach/201003/326842_8kq3lj4xv27zcq1.jpg)
在ASCII栏，输入刚才我们随便输的那个错误注册码335577，然后确定。
11、找啊找，终于找到了：
![](https://bbs.kanxue.com/upload/attach/201003/326842_wpbtynkfci1gqaa.jpg)
看到我们的335577了吧，继续往下翻，就能看到你的PIN码了（例如我的3053XXXX），继续往下翻，仔细看有没有6个数字这样的很像注册码一样的东西……
12、哈哈哈，终于找到啦：
![](https://bbs.kanxue.com/upload/attach/201003/326842_7zmy0wog219b3qx.jpg)
看到了吗，229661，哈哈哈！把它记下来，到自己的BB上去注册BerryWeather吧！（2.0以上版本不行，要1.6.XX以下的都行）
![](https://bbs.kanxue.com/upload/attach/201003/326842_rqae53npdcoafwg.jpg)
