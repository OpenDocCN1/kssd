# [原创]基于IDA Python的Dex Dump

之前写过一个基于IDA Python的dump dex脚本，但是是重新对dex文件结构进行解析，代码量大且复杂，参考了[DexHunter](https://bbs.kanxue.com/elink@2c0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6*7P5i4p5^5y4K6l9&6i4K6u0r3c8r3g2^5d9s2g2F1N6r3g2J5)之后，对代码进行了大幅修改，直接可以砍掉一半以上的代码。

同时参考[伪·MSC解题报告](http://bbs.pediy.com/showthread.php?t=197244),作者提出了一种基于gDvm获取cookie的办法。我采用的办法是通过IDA的module模块找到libdvm.so->dvminternalnatimeshutdown（保证光标停留在该函数的第一行即可），然后运行 findcookie.py，从控制台的输出中找到合适的DexFile address（通常有多个，通过name进行判断），修改dump2.py中倒数5行的address，然后运行dump2.py。具体使用方案可以见Github
