
# [原创]reversing.kr上一道很有意思的crackme replace分析

随便输入个数，发现崩溃了

![](https://bbs.kanxue.com/upload/attach/202002/742286_1es64qg4r4pe2st.png)

`PEID`查发现没壳，`IDA`找到`dialogproc`，`F5`发现`IDA`报错

![](https://bbs.kanxue.com/upload/attach/202002/742286_p7sayjft2odnoab.png)

代码逻辑前面就是`GetDlgItemInt`获取输入，（所以输入必须要是整形

看下后面，得知错误原因很简单，`sub_40466F`是个函数，但是程序在运行的时候对他进行了动态修改，所以`IDA`认为这个程序对`const`进行了修改

运行时改变代码，好，那就`OD`看下

![](https://bbs.kanxue.com/upload/attach/202002/742286_4ofjccpw1l9k2sa.png)

这里`0x4084d0`就是`input`，是个全局变量，

跟进`call`，

![](https://bbs.kanxue.com/upload/attach/202002/742286_4eo1rxvil59x5oc.png)

这里看到了`sub_404689`，功能很简单，把`input+=1`，这个函数在`dialogfunc`那里也有调用

`F7`走起，

![](https://bbs.kanxue.com/upload/attach/202002/742286_86eje9qpubvwv5s.png)

再`F7`，

![](https://bbs.kanxue.com/upload/attach/202002/742286_oqikiiqlc33tcb8.png)

注意`eip`的地址，第二张图`eip`的位置其实就在第一张`eip`的位置的后面一点

然后调用`inc input`的那个函数，返回之后又会`inc`一次，这个不好说，大家自己跟一下就知道了。。。

![](https://bbs.kanxue.com/upload/attach/202002/742286_6ws56g3y9es8efa.png)

`inc`完两次之后如图所示，注意栈上的返回地址，所以再`F7`之后，

![](https://bbs.kanxue.com/upload/attach/202002/742286_o1zktue8qnzwsk6.png)

到了这个地方，就是把`input`增加`0x601605c7`，可能会溢出，但是无所谓，取余一下就好

下面一点指令貌似没什么用，因为没对`input`有什么影响，走到下面的`call`，又会`inc input`两次，最后`retn`会返回到`dialogproc`

![](https://bbs.kanxue.com/upload/attach/202002/742286_ialxrvejogmza76.png)

所以这个函数在被后面的指令修改之前，干了一件事，把`input +2 + 0x601605c7 +2`

确认一下，我输入的是20192019，所以

```
>>> hex(20192019+2+2+0x601605c7)
'0x614a20de'
```

如数据窗口所示，数是反过来的是因为little endian

![](https://bbs.kanxue.com/upload/attach/202002/742286_m07hs99gp08eq54.png)

返回那个函数(`change_f`)之后(在`xor eax,eax`那里)，被修改过的`input`被`mov`到了`eax`中，然后又调用一次`inc_input`，然后修改`change_f`函数的函数头，在`call change_f`那里`F7`进去，发现汇编被修改成了

![](https://bbs.kanxue.com/upload/attach/202002/742286_knassaconoxbfux.png)

`[eax]=0x90`，注意此时`eax`的值，其实就是

`input +2 + 0x601605c7 +2`

，所以随便输一个数会崩溃，因为访问了无效的内存地址

返回后`inc eax`，然后再调用一次被修改后的`change_f`

`0x90`，是不是很熟悉？没错，就是`nop`，再看看`IDA`的代码，有一个疑似成功的代码段

但是没有任何`jmp`之类的跳转到这里，空格看看，上面有个`jmp short`(刚好两个字节)，

![](https://bbs.kanxue.com/upload/attach/202002/742286_yydardcfdaiaoty.png)

很明显了，这道题就是要通过这个`mov byte ds:[eax], 0x90`来`nop`掉那个`jmp short`，所以

`input + 2 + 0x601605c7 + 2 =` 那个`jmp short`的地址。

考虑到整数溢出，所以用C，

```
//input + 2 + 0x601605c7 + 2 == 0x00401071
unsigned int getinput()
{
    return 0x00401071/\*jmp short 地址\*/ - 4 - 0x601605c7;
}

int main()
{
    printf("%u\n", getinput());
    system("pause");
}//\*/
```
