# [原创]2016腾讯的游戏安全竞赛题PC第一题分析

Tencent2016A 注册过程分析

1.        查找注册函数

使用OD进行调试，发现无壳无反调试。
在 GetWindowTextW GetDlgItemTextW SetWindowTextW 设置断点无法拦截，在ctrl+n发现有SendMessage导入函数，猜测使用的消息方式，WM\_GETTEXT。
通过 SendMessage 可以顺利定位到注册函数。
