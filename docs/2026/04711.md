# 改一个字节破解星际争霸母巢之战1.08b的光盘保护 (1千字)

改一个字节破解星际争霸母巢之战1.08b的光盘保护

近来朋友将正版星际争霸母巢之战升级至1.08b版后，要放光盘才能玩，真不爽，苦于网上也找不到补丁，于是要我帮忙看看。

拿来后，要先装星际争霸老版本，忘了问朋友要CD-KEY，懒得问朋友要了，用TRW改一个跳转就过了，很简单，我就不罗嗦了。
再装母巢之战，这个游戏的光盘保护和其他的有些不太一样，但也只要改一处跳转即可，用TRW下bpx getdrivetypea，运行游戏，拦断后，BD
\*
，按数次F12和F10，来到storm.dll的领空，发现关键比较点如下：

:15018675 6681F9001F              cmp cx,
1F00
:1501867A 740B
  je 15018687      ；就是这里，改成JMP即可
:1501867C 6681F90508              cmp cx,
0805

用HIEW找：      66 81 F9 00 1F 74 0B 66 81
改为：          66 81 F9 00 1F EB 0B 66 81

另外，注册表中的CD盘付改成你的安装盘，我这里安装在D:盘下
REGEDIT4

[HKEY\_LOCAL\_MACHINE\Software\Blizzard Entertainment\Starcraft]
"StarCD"="D:"

最后将光盘上的INSTALL.EXE（540M）拷贝到安装盘的根目录下，运行游戏，动画和背景音乐和光盘版一样。
