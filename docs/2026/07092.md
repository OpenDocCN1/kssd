
# [原创]myMiniLock公钥加密小工具

受MiniLock启发，用国密sm2 ECC加密算法写了这个东西，希望能保住你的隐私文件。

[myMiniLock.rar](https://bbs.kanxue.com/attach-download-90478.htm)

## 使用

1. 输入任意字符串作为MiniLock ID，当然越长强度越高，程序自动生成公钥、私钥对；
2. 将公钥分享给你的小伙伴，让小伙伴将私密文件用此公钥加密后分享给你；
3. 输入MiniLock ID后您可以解开分享给你的文件了。
4. 支持drag & drop
