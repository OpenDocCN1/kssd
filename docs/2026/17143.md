# [原创]Ubuntu18.10 安装openvas 以及使用openvas进行简单漏洞扫描分析初学笔记

首先更新系统：

```
apt-get update
apt-get dist-upgrade
```

安装openvas：

```
apt-get install openvas
```

进行openvas设置：

```
openvas-setup
```

在设置命令执行结束时，会自动设置一个用户名和密码，用户名默认都是admin，密码为字符串User created with password之后的字符串，此时，openvas管理器、扫描器、GSAD都应该处于监听状态
