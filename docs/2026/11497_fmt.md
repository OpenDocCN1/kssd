
# [原创]禹盾2.05源码更新

禹盾hips是一款绿色的主机入侵防御系统，它从驱动层保护系统关键位置，拦截进程、注册表、驱动等危险操作，从而达到保护电脑的目标，即使是未知病毒，一样能够99%拦截。

## 2.05更新

1. 增加支持vista sp1
2. 更换ring0-ring3通信机制提高效率
3. 改善应用层如果意外崩溃，驱动层不会开死
4. 修复目前发现的拒绝服务漏洞
