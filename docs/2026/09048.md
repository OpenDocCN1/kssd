
# [原创]VxPack 开源加壳软件---0.98，20周年纪念版

VxPack是一款开源的软件保护壳，其中包括加壳软件常用的保护技术，例如代码虚拟化，代码乱序等等。作为一款学习总结以及开源科普为目的建立的。

这次时间匆忙发布的版本是为了赶上2018年最后一班车发布的20周年纪念版。

为什么是20周年？因为20年前的1998年有太多的东西值得纪念了。

`ASPack 1.0`是1998年发布的

`UPX 1.0`也是1998年发布的

还有几乎绝大部分压缩壳都会用的压缩库`Aplib`也是1998年建立的

希望在这个辞旧迎新的日子带来好运，希望在2019年博一个好的兆头，希望大家多多关注和学习交流。

`0.98`是完全逆向分析`ASPack2.42`的作品，作为我入门加密解密第一个接触的壳，`ASPack`给我留下太多的回忆。

相信许多人都对`ASPack`，`UPX`有许多回忆。于是乎作为一个Delphi风骚级玩家推出了aspack二十周年纪念版。

代码全部开源（官方仍然闭源，还收费$30），基于`Delphi7+tasm32`进行开发。

尽量还原aspack代码结构，有一些设计不合理的地方也进行了处理。

和官方的aspack最大的差别在于aspack采用自研算法`lzx`，目前只能通过各种渠道找到解压算法，压缩算法实在找不到，没办法还原给大家，实在可惜。这里使用另外一种性能和功能接近的`Aplib`压缩算法。

代码仅作为学习研究之用，界面尽量模仿aspack（纪念版嘛），由于使用了大量的aspack的资源，所以这里我也就不再声明版权了。
