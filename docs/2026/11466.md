
# [原创]x64主动防御

最近研究了一下64位系统中系统调用的相关机制，写了个主动防御玩，原理依然是跟x86下的主动防御一样，在`KiSystemServiceRepeat`中做hook（做的时候发现系统调用表的机制在64位下改动也挺大的![](https://bbs.kanxue.com/view/img/face/27.gif)）

另外附带一些程序员专用功能，例如对`c/cpp`文件的访问监控等：

![](https://bbs.kanxue.com/upload/attach/201202/161618_inj1fdhd1myt10e.png)

目前驱动的框架已经完善了，但是精力有限，监控的具体系统调用还不够多，用户界面也很残念。先放个bin让大家测试下，等把界面完善了再放源。![](https://bbs.kanxue.com/view/img/face/1.gif)
