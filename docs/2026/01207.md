
# [原创]逆向进阶——复杂分支结构逆向

熟知 `if-else` 的典型结构是逆向入门的必经路程，然而我们实际逆向时，遇到的情况远比这要复杂。

## 一、条件分支的逆向基础——典型的 `if-else` 结构

我们知道简单的 `if-else` 的跳转结构是这样的。

例如：

```
if (i1 < x1)
    ...;
else
    ...;
```

在反汇编结果中我们会看到类似下面的结果：

![](https://bbs.kanxue.com/upload/attach/201102/311352_hky4rfdaxuix2gh.jpg)

两点说明：

① `jxx AAAAAAAA` 这句由于 `false` 则跳转，因此还原为 `if` 代码时，要注意。

② `jmp BBBBBBBB` 这句在功能上属于 `if` 的部分，但是如果没有 `else`，编译器不会填写此句。

## 二、多层嵌套 `if-else`

```
if (i < x1)
{
    ...
    if (i < x2)
    {
        ...
        if (i < x3)
            ...;
        else
            ...;
    }
    else
        ...;
}
```

对应反汇编形态：（地址 A、B、C、D 从小到大分布）

Debug 版：

![](https://bbs.kanxue.com/upload/attach/201102/311352_7gzsv3aye3e4fok.jpg)

说明：

这里我们看到在 Debug 版里，多层嵌套 `if-else` 只是简单重复单层 `if-else` 的结构。另外，`jxx` 仍然是 `false` 则跳转，翻译为 `if` 时，要注意。

Release 版：

![](https://bbs.kanxue.com/upload/attach/201102/311352_zhzl9sy8liscr0d.jpg)

说明：

我们看到 Release 版对 Debug 改进，避免了 `jmp` 的多次运行。

## 三、复合条件的条件分支

### (1) 与——`&&`

```
if (i1 < x1 && i2 < x2 && i3 < x3)
    ...;
else
    ...;
```

反汇编形态：

![](https://bbs.kanxue.com/upload/attach/201102/311352_709prij9l6dr9bb.jpg)

说明：

`N` 条分支全部向 `Jmp` 后跳转。

### (2) 或——`||`

```
if (i1 < x1 || i2 < x2 || i3 < x3)
    ...;
else
    ...;
```

反汇编形态：

![](https://bbs.kanxue.com/upload/attach/201102/311352_xapuo9z1n5z0m8e.jpg)

说明：

只有 `N-1` 个分支向 `jmp` 后跳转。

### (3) 混合

```
if (i1 < x1 || i2 < x2 && i3 < x3)
    ...;
else
    ...;
```

反汇编形态：

![](https://bbs.kanxue.com/upload/attach/201102/311352_5wjua2ylj8k9rg3.jpg)

```
if (i1 < x1 && i2 < x2 || i3 < x3)

else
    ...;
```
