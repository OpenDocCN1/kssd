# [翻译]三星在线购买平台的顾客信息泄露事件

大概四个月前，我在三星的[网上商店](https://bbs.kanxue.com/elink@b28K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4y4S2L8i4y4#2L8X3N6Q4x3X3g2U0L8$3#2Q4x3V1k6#2M7#2)9J5c8R3`.`.)买了一台新电视。几天后我在邮箱里收到了一个商品跟踪链接。

416K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3q4Y4M7%4W2K6N6r3g2E0M7#2)9J5k6h3y4G2L8g2)9J5c8X3I4A6M7%4c8Z5j5i4N6T1i4K6u0W2j5i4y4H3i4K6y4r3M7$3g2S2M7X3y4Z5N6s2W2H3k6g2)9K6c8r3S2S2N6$3u0Q4x3U0k6S2L8i4m8Q4x3@1u0K6k6h3q4J5j5$3S2$3j5h3I4#2k6g2)9K6c8o6p5I4x3K6R3&6y4K6M7`.

**重复使用物流跟踪数字**

我最开始收到的这个链接，显示的订单并不是我的。我猜想可能是记录错误吧，但是我那时太忙了所以没有联系三星说这个事。

当我现在再看这个链接的时候，它竟然显示了两个订单——我的订单和一个其他人的订单。

![](https://bbs.kanxue.com/upload/attach/201703/735073_l32jf5dxk4gexsb.png)

跟踪结果显示了好几个订单，订单号码被打码是因为这些不是我的订单——这倒没什么影响（到下面你就知道了）

我有点小担心，我的跟踪链接显示了两个订单，所以我联系了三星想搞清楚到底什么情况。我收到了这样过的回复：

```
我知道您对您的商品物流跟踪信息感到担心。AGS每年都会回收他们的跟踪号码，这就是为什么您会在一个跟踪号码后面看到多个订单。您的商品跟踪信息更新后被排在第一位，我们为给您在三星购物带来的任何不便表示歉意，我们感谢您购买三星的产品 ，并真诚的希望这件事不会影响您继续购买三星的产品。如果您还有任何其他的问题或担心，请给我回复邮件。
```

**泄露订单信息**

     当我点击了HAWB(House Airway Bill)链接，它显示了我订单的细节信息。

![](https://bbs.kanxue.com/upload/attach/201703/735073_6pzjqoyn63xkpq3.png)

这里很明显有很多关于我的信息...

这确实是我的订单，一个60英寸的三星电视送到Orchard Park,纽约，POD（交货证明）：Metzger。它甚至还有我在三星网上的订单号（(11109231971 ），看起来大量的信息暴露给了未验证的用户。

等一下....那个页面上不是有两个链接么？我又返回查看了三星发送给我的那个链接，然后点击另一个HAWB链接。现在我看到了所有使用这个订单号的订单信息（我有点小嫉妒，因为他们订购了一个更大的电视）。

如果三星发给我的链接可以看到其他人的订单，那么肯定别人也能看到我的订单。

**枚举跟踪ID**

这就让人很失望了，别人只需要一个三星发送给我的那个跟踪URL，他们就可以看到很多我的订单细节信息（也可以看到其他人的订单信息）。

在某些情况下，有些应用使用机密URL来进行一些敏感操作（比如 ：通过邮箱发送的密码重置url，）。这件事还不是这样，我的跟踪URL肯定是被发送给某个有同样跟踪ID的人了——这已经没有任何保密可言了。

即使没有人收到同样跟踪链接，那这个链接依然不能被视作安全的。要注意关于这个链接唯一特别的地方就是一个相对而言安全度比较低的整数（1138977 ）。这样结合三星回复的托运人“每年都回收他们的跟踪号码 ”，就能很明显的看出来这些ID一直被继续使用。

所有需要知道的就是一个跟踪链接，然后你就可以遍历所有的ID，只需要5分钟写个脚本，就可以得到三星所有的物流信息：

\* 消费者的姓氏

\* 消费者所在的城市

\* 购买的东西

\* 订单号码

**利用数据**

让我们想想，将这四种信息泄露给有恶意企图的人会有多危险，拥有了姓氏和城市，很简单的网络搜索就可能会找到对应的手机号。

一旦找到了一些可能的手机号，我们就可以开始进行社会工程攻击，拨打这些号码了：

```
您好，我是来自三星的Bob。是Metzger先生吗？我打这个电话是因为他最近订购了一台60英寸的三星电视。
```

如果他们说他们没有购买任何东西，挂掉然后拨打下一个手机号。如果听起来他们知道我们在说什么，那就多说些信息让他们确定这个电话是合法的。

```
为了保证订单号没有错误——您介意确认下您的订单号码是1138977吗？
```

到这里我们已经把一只脚伸进门了，并且很明显我们这个电话是来自三星的合法电话，一个骗子怎么会知道他们的订单号和他们购买的东西呢？

是时候利用这个这份信任然后提供一个无法拒绝的优惠来获得支付信息了。

```
->如果他们购买了一个小电视：
我们对给您带来的不便深表歉意————我们的物流工厂出了点事故，毁坏了所有的50英寸的电视，可能两周后我们才能调运更多的50英寸的电视。为了表达歉意，只需要49美元，我们就可以将您的50英寸电视升级到60英寸（60英寸的我们还有存货）。

->如果他们买的是一个大电视：
我们队给您带来的不便表示歉意————因为我们线上商城的故障，当您购买该电视时没有显示出促销价格。您购买的这款电视只需要29美元就可以享受3年的意外破损保修服务。

->如果他们上钩了：
再次对给您带来的不便表示歉意，我们将需要您的支付信息，不用担心，鉴于支付卡行业标准，当您输入您的信息时我们是不会记录您的支付信息的。
```

你知道了吧，用得到的这四种信息进行社会工程学攻击是非常容易的。

**泄露进一步加大**

在我的电视已收货之后，我又去检查了跟踪状态——希望这只是在商品运送过程中的短暂泄露，当我收到货物后就会消失。

事实恰恰相反，不仅订单信息还在那——而且还多了一个指向TIFF文件的链接。

![](https://bbs.kanxue.com/upload/attach/201703/735073_5fjltvuoifwrbil.png)

懵逼.....他们加了一个指向TIFF文件的链接.....

那个TIFF文件是一份已签名物流票据的扫描文件。

![](https://bbs.kanxue.com/upload/attach/201703/735073_v4tasgtwq3l50w6.png)                         晕，这里有更多关于我的信息

他们本来就已经泄露足够多的信息来进行社会工程学攻击了，现在他们又泄露了更多的信息：

\* 我的全名

\* 我的完整地址

\* 我的签名（好吧，实际上是我媳妇的）

**可见性**

所有的这些信息都是从三星发送给我的一个链接里得到的——但是你不需要从三星买点东西来得到物流跟踪系统的链接。Google已经有了一些航空票据的索引了。

![](https://bbs.kanxue.com/upload/attach/201703/735073_a2uo4pppuaix56n.png)

就是这么方便！

     这个表格说的很清楚，这应该是一个7位数字。从0000001开始，它给了一个熟悉的搜索结果：

![](https://bbs.kanxue.com/upload/attach/201703/735073_tsei6psnih10sgv.png)

到这里，不容置疑——这个系统的信息一点也不安全。链接直接发送给消费者，而且链接可以被Google索引到，甚至网站还有一个公开表格来进行搜索。

三星的回应

     对这件事我感到不爽，所有的这些信息只要花几分钟就可以抓取到，所以我再次给三星反应这个问题。我告诉他们我的个人信息被他们的物流网站共享出去了。包括对每种信息的描述，还有对应的链接，我还告诉他们这些数据很容易被枚举因为他们使用了连续的ID——并且我要求他们告知他们的安全团队。

     两周后，我收到了三星的回应：

     我理解您想把这个告知我们的安全团队。您的请求需要由AGS开始处理，您需要通过AGS移除您的信息。我们对带来的任何可能影响您购物体验的不便表示歉意。我们在三星感谢您购买三星的产品，我们真诚的希望这件事不会阻止您继续购买三星的产品。

就这样，三星说我需要找物流来处理。

     我才不呢。我将我的数据委托给三星，他们就是这样保护我的信息的。如果三星的商业伙伴泄露了信息，三星需要对这种情况进行补救。

     当我写这篇文章的时候，我打算编写我的信息（至少编写我媳妇的签名），但这没有多大改变，在我将这个披露给三星四个月后，这些信息依然还在那，任何人都能获取。请不要打电话给我推销保修期服务。
