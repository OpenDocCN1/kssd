
# [原创][C#][有码]对程序中的敏感明文字符串进行简单的加密

上次我们写了个映像劫持工具类（[[C#][有码]映像劫持简析与工具类源码](https://bbs.pediy.com/thread-266140.htm)），里面有个字符串常量：

```csharp
public const string IFEO_LOCATION = "SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Image File Execution Options";
```

用IDA打开，这玩意就像灯塔一样显眼：

![](https://bbs.kanxue.com/upload/attach/202103/885443_Q3ZJKXH4XDJ8UFY.jpg)

谁都知道你小子不安好心！

所以我打算给这种敏感字符串做个简单的XOR加密脱敏，让它混杂在其他数据里，至少不会这么显眼。

```csharp
// "SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Image File Execution Options"

private static readonly uint[] _STR_IFEO_LOCATION = {★☆这里是一堆加密的uint！☆★};

public static string IFEO_LOCATION

{

    get

    {

        return Utils.Encoding.Decode(_STR_IFEO_LOCATION);

    }

}
```

再打开IDA，一眼是找不到这个字符串了。

使用方面，`IFEO_LOCATION`从常量字符串变为只读属性字符串，代码其他部分不需要改动，因为访问它的语法不变。C#真香。

现在是XOR加密工具：

```csharp
namespace Irisu.Hammer.★☆★☆

{

    /// <summary>字符串简单加密.</summary>

    public static class Encoding

    {

        /// <summary>女孩子的密钥是不可以给别人看的.</summary>

        private const int KEY = 0x★☆★☆★☆★☆;

        /// <summary>这个也算密钥! 有时间升级成数组. 在0-16之间.</summary>

        private const int OFFSET = ★☆;



        /// <summary>解密字符串.</summary>

        /// <param name="ints">密文数组.</param>

        /// <returns>明文字符串.</returns>

        public static string Decode(uint[] ints)

        {

            char[] chrs = new char[ints.Length];

            for (uint i = 0; i < ints.Length; ++i)

            {

                chrs[i] = (char)(((ints[i] ^ KEY) >> OFFSET) & 0x0000FFFF);

            }

            return new string(chrs);

        }



        /// <summary>加密字符串. 发布版本应该给你删了!</summary>

        /// <param name="str">明文字符串.</param>

        /// <returns>密文数组.</returns>

        public static uint[] Encode(string str)

        {

            char[] chrs = str.ToCharArray();

            uint[] ints = new uint[chrs.Length];

            System.Random random = new System.Random();

            for (int i = 0; i < chrs.Length; ++i)

            {

                ints[i] = ((uint)chrs[i] << OFFSET);

                // 塞入无用信息

                ints[i] += OFFSET >= 1? (uint)random.Next(0, (int)System.Math.Pow(2, OFFSET) - 1): 0;

                ints[i] += OFFSET <= 15? (uint)random.Next(0, (int)System.Math.Pow(2, 16 - OFFSET) - 1) << (16 + OFFSET): 0;

                // 加密

                ints[i] ^= KEY;

            }

            return ints;

        }



        /// <summary>把uint数组写成类C声明的格式, 方便Copy到代码.</summary>

        /// <param name="ints">Array of uint(s).</param>

        /// <returns>Array declear of C-like language.</returns>

        public static string ToArrayDeclear(uint[] ints)

        {

            System.Text.StringBuilder sb = new System.Text.StringBuilder();

            if (ints.Length > 0)

            {

                _ = sb.Append("{0x").Append(ints[0].ToString("X4"));

                for (uint i = 1; i < ints.Length; ++i)

                {

                    _ = sb.Append(", 0x").Append(ints[i].ToString("X4"));

                }

                _ = sb.Append("};");

            }

            return sb.ToString();

        }

    }

}
```
