# [原创]Windows 8 新文件系统 Protogon 印象，内部函数列表

windows 8还没有公开资料的新文件系统Protogon，现在已经可以试用了。
格式化硬盘为protogon文件系统的方法是用管理员命令行：
Format E: /fs:protogon /Q
把E:换为指定的盘符

我手里的是64位的windows 8，从C:\Windows\System32\drivers目录拿到protogon.sys看了一下，内有大量的NTFS系统函数，看来这个新文件系统还是以NTFS为基础的，不知道新推出的时候是不是直接将NTFS文件系统加高一个版本号。具体的还没有细看，猜测是增加与文件搜索有关的内容吧，或者还有增加SSD的性能支持。

特有的函数有 ProtogonFlushIndex ProtogonMoveFile ProtogonCloseIndex ProtogonIsFileOpen等等。更详细的见附件。
