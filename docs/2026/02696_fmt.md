
# morning伸请入BCG破文之二 (3千字)

目标软件：中国计算机软件水平考试测试系统2.0版(程序员)`http://www.csdn.net/cnshare/soft/7/7791.html`

工具:TRW2000 1.23

1. 启动目标软件后,启动TRW
2. 在目标软件中点"注册"
3. 出现注册对话框后,填入用户名:morning,注册号:12345678
4. CTRL+N 呼出TRW,下`BPX HMEMCPY`,F5返回目标软件
5. 按下"立即注册",被TRW拦下,`BC`清除断点,下`PMODULE`来到目标领空
6. 按F12七下(因为八下就完啦),再按F10无数直到下面:
