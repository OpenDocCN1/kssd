
# [原创]D Probe 完整开源

关于 D Probe 的介绍和请参考http://bbs.pediy.com/showthread.php?t=151338。

这里描述下整个目录结构:

+ `bin`            BUILD的输出目录

+ `btr`             核心, 一个完整的库，包括x86/x64 HOOK, STACKTRACE, IPC, STORAGE

+ `dprobe`      主程序，`btr`的控制端，包含小型GUI 库, RECORD, PDB ETC

+ `flt`              常用filter dlls的实现，方便自己定制化

+ `inc`             COMMON HEADERS

+ `kbtr`           驱动, 空的框架没实现。

+ `lib`              COMMON LIB

+ `sqlite`         SQLITE 作为配置的METADATA

`btr`的实现和很多开源的hook library不同，有自己独特的地方，也有其缺点，里面用了很多技巧，对hook感兴趣的可以看看。

`btr/dprobe`花了大量的精力在性能优化上, 可以以较小的代价，在较高的负载下获得不错的性能。有些文件是老的实现，没有包括在工程文件里，但是在文件夹下仍然存在，读代码请注意这点。

时间久了，很多细节都不记得了， so ... 碰到crash手里有代码可以自己调试，有些API不能安全的probe, 因为实现代码假设函数的调用遵守标准的规范。建了个github repository, 管理起来很方便，就不提供其他下载链接了。
