> `stegpy`是一种将编码信息隐写在图像和音频文件中的程序。使用Python编写

# `stegpy`的安装（只需三步）

一、首先输入下列命令安装依赖库

```bash
pip3 install stegpy
```

![在这里插入图片描述](upload/attach/202010/890541\_PGZKFQNM7ETGXDR.jpg)

二、然后下载[工具源码](elink@cc4K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6V1K9s2y4V1M7$3S2V1K9r3E0Q4x3V1k6K6N6r3g2Y4M7s2V1`.)解压

三、进入`stegpy-master`目录后执行下列命令，完成后就可以使用了

```bash
sudo python3 setup.py install
```

![在这里插入图片描述](upload/attach/202010/890541\_G9RDBFZJCWP4QRZ.jpg)

# `stegpy`的使用（超简单）

只需要下列命令便可实现隐写

```handlebars
stegpy 隐写内容 XXX.jpg
```

隐写完的图片会在名称前加一个下划线，默认生成png格式，可以看到图片大小有明显变化

![在这里插入图片描述](upload/attach/202010/890541\_YBQDJG7YEN4CK57.jpg)

你也可以加`-p`设置密码，解密文件时也要`-p`输入密码，不然就会报错

![在这里插入图片描述](upload/attach/202010/890541\_RC3XNFENDPCX3BC.jpg)

# 支持的格式：

- PNG
- BMP
- GIF
- Webp
- WAV
