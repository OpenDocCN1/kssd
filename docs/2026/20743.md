
# [讨论]有关支持大家出书的想法

最近看雪论坛推出的《加密与解密(第三版)》广受欢迎，形成热销。一些朋友和论坛上的高手希望我能够帮助他们自己组织出一些软件安全方面的技术书籍。首先，我非常支持他们的热情和想法。在此，我愿意把个人的一些有关组织技术书籍编写和出版方面的经验和大家分享。

论坛高手众多，很多人对技术研究已经有了很大收获，并且愿意和大家分享这些成果，进而编辑整成系列文章或教程、书籍。以我个人感觉，编书和写教程还是有不少区别，如果你的目标定位是编撰书籍，并且希望我能帮到你，那你就要考虑以下几个方面：

## 1. 市场定位
你希望出的书要给谁看？内容是不是满足市场需求，目标用户是否真是存在，且这个群体是否能够得到出版社的认同？这些问题你事先要考虑。以我个人经验，如果你定位的书的技术面过窄，内容高深，恐怕难以作为普通出版物得到出版社的技术编辑认同。

## 2. 书的定位
一本书是一个整体，主题，章节，线索一定要条理清晰。这里是有些技巧的。同样的内容如果编排不好，整体架构散乱，主题不明，层次不清，那么可能再好的内容组成的书籍也不会引起读者的兴趣。当然，这个问题最好请教出版社的技术编辑，他们会给你一些建议和忠告。如果你联系出版社有困难，我可以帮你联系。

## 3. 书的运作
要事先定好书的主题和主要内容，规划目录，写个简介。把这个文件发给我，我会帮你发给出版社技术编辑初审，然后给你回馈他们的意见。

## 4. 书的编写
如果出版社感兴趣，那你最后写出前1，2章内容，交给出版社审阅。如果他们感觉可以，和你约稿，达成合作协议以后，你就可以开始制定书的具体项目规划：组织和安排编写人员，制定时间表等。到时候有问题，可以找我们，我能帮到你的，一定尽力。

## 5. 出书感受
这些年，看雪论坛推出了几本书，从我个人角度感觉，写书和编书还是很花精力，耗时间的工作。真想推出一本广大读者欢迎，出版社支持的好书真的很不容易。可能你会觉着我们已经出版的这些书的内容，从技术角度你能独立完成并写出来；从文字功力上，你也完全可以提笔成章，写的更精彩。的确，或许你的能力都可以做到。但是写书，出书毕竟是一项与社会相关的系统性强的项目工程。在这个过程中，从立意，到规划、组织、运作、编写、审校、出版、推广，你都要亲力亲为，要同许多方面，许多人打交道，与各种事务：人际的、社会的、技术的、组织的、工作的，家庭的等等方方面面周旋。哪个环节出问题，都可能前功尽弃。所以，如你所见，《加密与解密》第三版从立意到推出经历了好几年。如果不是我的坚持、毅力和信念，恐怕今日也不会集结成册，个中艰辛，难于人言。

## 6. 发展思考
我非常理解大家看到[《看雪软件安全》系列图书](http://bbs.pediy.com/showthread.php?t=44383) 的热销，很想跃跃欲试的热情。其实好几个出版社向我约稿的书我都没有时间去写，我的精力和时间实在太有限了，无法做这么多事情。同时，有能力有精力的论坛高手又希望我帮忙他们出书。所以，我在想，如何把网站和我个人的优势与大家的优势相结合，怎么能够通过看雪论坛，组织起大家的力量，既要尽量减少不必要的风险和资源的浪费，又要能够让大家的力量汇聚起来，把软件安全系列书籍的编写当作项目有效运作下去。毕竟，我一个人的力量太有限了。如果我们能够形成一个有效的图书项目的管理和运作机制，大家积极参与进来，不要作散兵游勇，而是聚合力量，相信是对大家利益的最大保障。

如果就出书这个主题，你有什么好的想法和对论坛的建议，请跟帖发表意见。
