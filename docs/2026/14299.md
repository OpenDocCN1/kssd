## 遇到的错误
\* recipe for target 'run\_soong\_ui' failed\*解决方案一
增加swap空间
增加办法：
增加4个G的交换空间
```
cd /
sudo dd if=/dev/zero of=/swp bs=10M count=400
sudo mkswap /swp
sudo swapon /swp
```

  ```
- recipe for target 'run\_soong\_ui' failed\*解决方案一
  增加swap空间
  增加办法：
  增加4个G的交换空间

  ```
    cd /
    sudo dd if=/dev/zero of=/swp bs=10M count=400
    sudo mkswap /swp
    sudo swapon /swp
