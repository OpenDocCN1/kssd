# 原理探究
使用jadx（每个人安装位置不一样，也可以写环境变量更方便）
```
D:\program\jadx-master\jadx-gui\build\install\jadx-gui\bin>jadx-gui.bat jadx-gui
```
![图片描述](upload/attach/202205/951823\_ZDJCGCFWYXUMGMQ.png)
查看反编译源代码（去掉反混淆）
在sg.vantagepoint.uncrackble1 这个类这一hook一个js，修改器运行结果。
简单js代码讲解
```
setTimeout(function() {
Java.perform(function() {
var hook = Java.use("sg.vantagepoint.a.c");
var ahook = Java.use("sg.vantagepoint.a.a");
//console.log("[\*]: hooking target class");
hook.a.overload().implementation = function() {
return false;
}
hook.b.overload().implementation = function() {
return false;
}
hook.c.overload().implementation = function() {
var revalue = hook.c.overload().call(this);
console.log("[\*] return"+revalue);
return false;
}
});
}, 0);
//Java.perform 是frida的一个api，任何对app中java层的操作都必须包裹在这个函数中，你可以理解为frida的mian
//var hook 是定义一个变量
//Java.user 是一个api ，指定调用原来的app中的哪一个类（具体哪个类可以使用jadx反编译看看是那个类，不断调试）
//overload().implementation 重载执行指定方法
```
![图片描述](upload/attach/202205/951823\_99M92KBQM8J8DU2.png)
将三个返回状态均设置为false，软件正常使用。
