## 原理探究

使用 JADX。每个人的安装位置不一样，也可以配置环境变量以便使用。

```bat
D:\program\jadx-master\jadx-gui\build\install\jadx-gui\bin>jadx-gui.bat jadx-gui
```

![图片描述](upload/attach/202205/951823_ZDJCGCFWYXUMGMQ.png)

查看反编译源代码，去掉反混淆。

在 `sg.vantagepoint.uncrackble1` 这个类中，通过 Hook 一个 JS，修改器运行结果。

### 简单 JS 代码讲解

```javascript
setTimeout(function() {
    Java.perform(function() {
        var hook = Java.use("sg.vantagepoint.a.c");
        var ahook = Java.use("sg.vantagepoint.a.a");
        // console.log("[*]: hooking target class");

        hook.a.overload().implementation = function() {
            return false;
        };

        hook.b.overload().implementation = function() {
            return false;
        };

        hook.c.overload().implementation = function() {
            var revalue = hook.c.overload().call(this);
            console.log("[*] return" + revalue);
            return false;
        };
    });
}, 0);

// Java.perform 是 Frida 的一个 API，任何对 app 中 Java 层的操作都必须包裹在这个函数中，
// 你可以理解为 Frida 的 main。

// var hook 是定义一个变量。

// Java.use 是一个 API，用于指定调用原来的 app 中的哪一个类。
// 具体是哪个类，可以使用 JADX 反编译查看，并不断调试。

// overload().implementation 用于重载并执行指定方法。
```

![图片描述](upload/attach/202205/951823_99M92KBQM8J8DU2.png)

将三个返回状态均设置为 `false`，软件即可正常使用。
