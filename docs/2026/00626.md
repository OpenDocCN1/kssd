### 安装

进入release目录

![](https://bbs.kanxue.com/upload/attach/202301/767964_99EXGGUYSNFFGZQ.jpg)

运行x96dbg.exe 可执行文件，开始执行安装行为，以方便之后的调试

备注：因安装会进行一些系统设置操作，故会触发用户账户控制提示

在弹窗的Launcher点击Install进行安装

![](https://bbs.kanxue.com/upload/attach/202301/767964_YB2YVZRMBBCG5ED.jpg)

备注：x32dbg、x64dbg 按钮可运行相关平台的x64dbg,x64dbg与被调试程序需要统一位数才可进行调试并且x64dbg的附加调试功能只会显示相同平台的程序。

相关安装设置选项：

shell extension---选择yes会添加一个右键菜单，当用此方式右键打开被调试程序时，会识别程序的位数，并用同位数的x64dbg打开以进行调试。

![](https://bbs.kanxue.com/upload/attach/202301/767964_W8Z8Q44HDKNUUNS.jpg)

备注：Windows 11系统需右键后在点击更多选项（Shift F10),才可看到相关方式

Desktop ---选择yes,会在桌面创建两个快捷方式（不同平台的x64dbg)

![](https://bbs.kanxue.com/upload/attach/202301/767964_QSVCB498UX5VVFK.jpg)

database icon ---选择yes会对x64dbg的数据库文件(dd32、dd64)设置相关logo，以方便识别

![](https://bbs.kanxue.com/upload/attach/202301/767964_6SZ9D6XWEE43FB9.jpg)

完成安装点击OK即可

![](https://bbs.kanxue.com/upload/attach/202301/767964_ZW35SX6QUXDKYVG.jpg)
