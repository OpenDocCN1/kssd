
# [原创]CydiaSubstrate框架

Cydia Substrate是一个基于Hook的代码修改框架，可以在Android、iOS平台使用，并实现修改系统默认代码。

## 一：substrate的API介绍

Substrate具体的运行是由下图这个jar包所执行。

### 1. Substrate的代码编写实现系统文字颜色篡改

（1）创建一个空的Android工程，由于创建的工程将以插件的形式被加载，所以不需要activity，将SDK中的`substrate-api.jar`复制到`project/libs`文件夹中。配置`Manifest`文件指定权限，`cydia.permission.SUBSTRATE`，如下图所示。

![](upload/attach/202011/880306_X68NV9QER7GX45B.png)

（2）创建一个类，类名为`Main`，类中包含一个`static`方法`initialize`，当插件被加载的时候，该方法中的代码就会运行，完成一些必要的初始化工作，如下图所示。

![](upload/attach/202011/880306_JPYZXNP5XCYHU7P.png)

（3）添加meta标签，name为`cydia.permission.SUBSTRATE`，value为下一步创建的类名，例如`Main`，如下图所示。

![](upload/attach/202011/880306_VDC2WNGAFGSYQRP.png)

（4）为了实现HOOK，达到修改目标类中的代码的目的，需要得到目标类的一个实例，如下图所示。

![](upload/attach/202011/880306_B9JAYUS2VZYHHEN.png)

（5）通过`MS.MethodHook`实例实现原代码的修改。为了调用原来代码中的方法，需要创建一个`MS.MethodPointer`类的实例，它可以在任何时候运行原来的代码，如下图所示。

![](upload/attach/202011/880306_A2YJZER98AGQHY9.png)

（6）返回颜色，重启系统即可，如下图所示。

![](upload/attach/202011/880306_KVZ4FA7GYPQVWGA.png)

## 二：native层hook

1. 创建一个android程序，在android工程中新建`jni`文件夹，加入相关的头文件`substrate.h`和库文件。

例如：工程只支持arm，那就加入`cydia_substrate\lib\armeabi`下的两个so文件，如下图所示。

![](upload/attach/202011/880306_Q4QBCHBYBWWRWN3.png)

2. 在`AndroidManifest.xml`中注册cydia的自定义权限`cydia.permission.SUBSTRATE`，设置`android:hasCode`为 `"false"`，`android:installLocation`设置为 `"internalOnly"`，如下图所示。

![](upload/attach/202011/880306_XUVFR8RSC3SBYHU.png)

3. 编写Hook模块代码，即上面的`test.cpp`，如下图所示。

![](upload/attach/202011/880306_734EF7GRQVXYU4C.png)![](upload/attach/202011/880306_WKBFRVJ3HH57ZVU.png)![](upload/attach/202011/880306_UUBMQHR338WCAG2.png)

4. 编写`Android.mk`，如下图所示。

![](upload/attach/202011/880306_2E4UMW4BK9TJED9.png)

5. `ndk-build`将在android工程中生成`libs`目录，如下图所示。

![](upload/attach/202011/880306_WF9AJ3842FQFHYP.png)

6. build android工程即可生成hook模块的`apk`安装包。

7. 打开框架`apk`，点击`Link Substrate Files`，之后点击`Restart System`进行使用。

8. Hook native demo运行之后，会打印每个程序加载so的情况，如下图所示
