# [原创]iPE Src

看过《加密与解密(第三版)》和《啄石成器》PE相关章节以后，把PE结构在A4纸上梳理来梳理去，总是不踏实，于是就想编写自己的PE文件分析的工具，第一次使用MASM32编码，时常有各种乱七八糟的错误让程序或崩溃或罢工，开始无比怀念在VC下编码的日子。OD调试起程序来也很不方便，不过一路熬过来直到把程序写好确实学到不少东西，至少SDK算是复习了一遍了。界面就是照抄DiE的，连图标也是改来。MASM32写界面和使用控件都和SDK一样样的。最后，抄着Notepad.exe编了N天码的菜菜前几天突然悲催地发现RadASM这等东东，我望着我的Notepad.exe，顿时无语凝咽    T\_T
程序有几个界面方面的遗留问题。无奈英语四级和期末考试呼啸而来，该花点时间准备准备了，问题在附件中有文档描述。
[程序说明]
[1] 计算文件MD5、SHA1。
[2] 枚举区段表、导入表、导出表，界面仿照DiE。
[3] 枚举了DOS/FILE/OPTIONAL/DIRECTORY结构的所有字段，界面仿照FFI。
[4] 程序有几个界面方面的遗留问题，在附件中有文档描述。
[End]  希望这个写得很挫的程序能给予和我一样的菜菜朋友们帮助。

去年光棍节完工的，最近要换工作了，发个程序上来，圈圈叉叉什么的。呵呵。
