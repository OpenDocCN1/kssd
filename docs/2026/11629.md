### 获取全国城市列表
直接请求接口获取即可，这边使用了一个jsonpath模块用来提取json数据，很好用强烈推荐！
```
def get\_month(self):
"""
获取城市列表
"""
response = self.\_parse\_url(url).json()
# 提取json数据中所有的城市名
models = jsonpath(response, '$..city\_name')
return models
```

### 获取指定城市热销榜
```
def get\_score(self, city\_name):
"""
获取指定城市热销榜
city\_name: 城市名
"""
offset = 0
while True:
response = self.\_parse\_url(url).json()
tag\_list = response.get('data').get('list')
# 没有数据跳出
if not tag\_list:
return
for tag in tag\_list:
series\_id = tag.get('series\_id') # 车系ID
series\_name = tag.get('series\_name') # 车系名称
count = tag.get('count') # 车系销量
yield series\_id, series\_name, count
# 翻页参数
offset += 100
```
