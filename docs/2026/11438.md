# [原创]火绒剑粉碎文件的分析

## 起因
上次我已经分析了火绒是如何杀死我们进程的，可是没想到哇，客户竟然还会使用文件粉碎机粉碎我们的文件，被逼无奈，我只能继续的分析一下火绒的粉碎文件的实现，我不得不说为什么它会很多的方式去粉碎文件，一个地方注意不到文件就会被删除。难受哇！
话不多说，我们现在看看火绒粉碎机是如何粉碎的文件。
