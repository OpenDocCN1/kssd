
# [征文]慢慢走来...

一切从茫然开始、那是2002年吧，大一年级的时候。那时候的我对电脑有浓厚的兴趣，感觉什么都想学。但是，完全没有方向，因为我的专业是通信工程，搞电子电路设计的。刚开始的时候从同学那里得知`BT`下载，于是在网上找了一堆教程，有`3DMAX`，`CAD`，`PS`...具体有那些，记得不是很清楚了，在使用`BT`的过程当中，认识了`BitSpirit`的作者，学习了`BT`协议等等。

一天，在网上看到了黑客教程，遂学了起来，有一天，入侵了3家浙江的公司主机，非常开心，进去浏览了一翻，什么都没做就出来了，有一天，入侵了一家河北的机器，进去后，发现电脑里全是帐单，某某地方什么人取多少，存多少...吓了一跳就退出来了，当时，觉得似乎是某个小银行的机器...某一天，入侵了一台内网的机器，在他机器上下载了一个短片，是他的视频，正在问他朋友借钱...入侵多了，觉得非常没意思，那个时候的大学，似乎除了玩游戏之外就是看电影，我不玩游戏，那当然就是看电影了，同学们都是疯狂的在网上找免费网站，在这个过程当中，认识了某电影网站的站长，于是就学了下`Premiere`视频编辑，压制电影，配字幕等等，做了一段时间，才发现，这些都不是我的兴趣所在。

某一天，在网上下到一个英文软件，具体叫什么名字，不记得了，当时有个想法就是，能不能把它变成中文的呢？于是，接触到了汉化...汉化了几个简单的软件后，接触到了某个软件需要脱壳，于是就接触到了脱壳，再后来就接触到了破解，从此真正走上了`Crack`之路了，当时，像着了迷一样，在网上下来二哥的教程，一篇一篇的照做，尽管有很多步骤完全不知道为什么要那么做，但是，能够照样子做下来还是非常的开心。那个时候，每学完一篇，我都会按自己的记忆操作一遍，录下来，方便日后查看。开始的时候，经常上`DFCG`论坛翻帖子，有的时候，为了一个问题，从搜索结果中翻了几千张帖子，但是，仍然没有得不到结果，于是，就把问题记录下来，心想到后面可能自然而然的就明白了。

那个时候，我还不敢上看雪论坛，呵呵，因为觉得这里是高手才来的地方，相信现在有不少新手也有这样的体会，自己在下面埋头苦学了一段时间后，有一天，心血来潮的在看雪发了一篇帖子，好象是关于`Armdillo`脱壳的吧，没想到得了精华，呵呵，现在回想起来，当时的心情是无比激动的。经过一年的自学，感觉有点能力了，就经常出没看雪论坛，有时候每天早上起床去上课之前都要先浏览一翻才去上课，在自学`Crack`的过程当中，不仅仅学到了很多东西，而且锻炼了自学的能力，那个时候经常逃课，课程基本都是自学的，一本书花一周的时间就可以考高分了，呵呵。同学们以为我的XX。

后来，认识了黑鹰的站长大米，呵呵，从04年开始就在黑鹰做了讲师，在黑鹰的日子里，也接触到不少东西，呵呵，

从我走的轨迹中，可以看出来，我走了很多的弯路。在这里真心的希望大家少走弯路，所以，想给新手朋友们一点建议，高手飘过~

1、`Google`是很好的老师，请善用之
2、在论坛上，谁都没有义务去帮助你，你同样没有权利去要求别人帮助你，请善待论坛上的每一位朋友
3、论坛提问之前，请先用搜索功能，善用之
4、你有为了一个问题，而翻看几千张帖子的耐心么？
   有：继续努力，成功离你不远
   没有：请放弃吧，免得痛苦，做你适合的去，或许会有成功的机会
5、破解需要学习汇编么？
   有必要看看，可以不用学深，当然，在破解的过程中有意识的去看懂代码比看书要强
6、你说想做破解高手就要懂一门编程
   是这样的，破解不仅仅是停留下爆破、内存补丁之类的，必要的时候需要你来编写你所需要的东西，另外，有了编程的思维，破解的思路就要多很多
7、那我学什么编程呢？
   请用`VC++`吧
8、常去看雪论坛上看看吧，在那上面仍然有很多需要我去学习的东西，那么你呢？
   新手朋友，喜欢视频的话就去`PYG`看看吧，不过，你以怀疑的眼光去看`PYG`上面的一些视频，因为，有些录象的方法和思路很有问题，甚至是完全错误，如果你能看得出来，请提醒下那位楼主
9、敬告那些沉迷在挂马中的朋友，这个只能当业余娱乐。
10、先做人，再做事，做人要低调，工作要积极。
