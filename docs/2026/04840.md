# 音乐贺卡厂2000Ver2.60破解 (1千字)

音乐贺卡厂2000Ver2.60破解

    网上可以得到免费的广告版, 用它制作的贺卡是一个EXE程序, 但在结束时有广告条出现, 我们的目的就是要将其去掉.

    用fileinfo发现主程序Musicard.exe用aspack2001压缩, 故用unaspack1.091解压. 反汇编后没有发现有值得注意的地方.
后来看到安装目录下有个exe.uxe文件, 其实也是一个可执行程序, 同样是aspack2001压缩, 解压后用exescope5.0发现里面有那个nag窗口--dialog
101.

    再回到主程序Musicard.exe, 用wdasm查找其调用exe.uxe的地方, 共2处, 分别设断, 并试图将之NOP掉,
都失败, 并备告知程序组件不完整. 经过思考, 认为exe.uxe可能是制作贺卡程序的母版, 故目标应该是它.

    将exe.uxe反汇编后, 选择DIALOG REF. 中dailog:dialogID:0065, 被带到
:004041A4 833D382C410001          cmp dword ptr [00412C38],
00000001
:004041AB 7515
  jnz 004041C2
:004041AD 57
  push edi
:004041AE 68C1114000              push 004011C1

:004041B3 57
  push edi

\* Possible Reference to Dialog: DialogID\_0065  <--stop here!!!

            |
:004041B4 6A65
  push 00000065
:004041B6 FF35D8284100            push dword ptr
[004128D8]

所以是将:004041AB 7515
  jnz 004041C2
改为:  :004041AB EB15
    jmp 004041C2
保存后再用UPX压缩一下, job done.
