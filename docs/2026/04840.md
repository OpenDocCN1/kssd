
# 音乐贺卡厂2000Ver2.60破解

网上可以得到免费的广告版，用它制作的贺卡是一个`EXE`程序，但在结束时有广告条出现，我们的目的就是要将其去掉。

用`fileinfo`发现主程序`Musicard.exe`用`aspack2001`压缩，故用`unaspack1.091`解压。反汇编后没有发现有值得注意的地方。

后来看到安装目录下有个`exe.uxe`文件，其实也是一个可执行程序，同样是`aspack2001`压缩，解压后用`exescope5.0`发现里面有那个nag窗口--`dialog` `101`。

再回到主程序`Musicard.exe`，用`wdasm`查找其调用`exe.uxe`的地方，共2处，分别设断，并试图将之`NOP`掉，都失败，并备告知程序组件不完整。经过思考，认为`exe.uxe`可能是制作贺卡程序的母版，故目标应该是它。

将`exe.uxe`反汇编后，选择`DIALOG REF.`中`dailog:dialogID:0065`，被带到

```
:004041A4 833D382C410001          cmp dword ptr [00412C38],
00000001
:004041AB 7515
  jnz 004041C2
:004041AD 57
  push edi
:004041AE 68C1114000              push 004011C1
:004041B3 57
  push edi
* Possible Reference to Dialog: DialogID_0065  <--stop here!!!
            |
:004041B4 6A65
  push 00000065
:004041B6 FF35D8284100            push dword ptr
[004128D8]
```

所以是将`:004041AB 7515 jnz 004041C2`改为`:004041AB EB15 jmp 004041C2`

保存后再用`UPX`压缩一下，job done.
