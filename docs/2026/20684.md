
# 【保姆级教程】pwn题如何配置和靶机一样的环境

苦于学pwn的时候没有找到博客讲述如何配制环境，于是自己记录一下供后面学习的师傅少走一点弯路

## 二进制文件+libc篇

### 准备工作

先需要安装两个工具

#### patchelf

```git
sudo apt-get install autoconf automake libtool
git clone https://github.com/NixOS/patchelf.git
cd patchelf
./bootstrap.sh
./configure
make
make check
sudo make install cd ..
```

#### glibc-all-in-one

```git
git clone https://github.com/matrix1001/glibc-all-in-one
```

记得下下来`cd`到`glibc-master`目录的时候先运行一下`update_list`，即：

```
./update_list
```

如果发现有些时候`list`里面的版本下不了了，也可以用这个更新一下列表（然后你就发现绝版了）

### 具体操作

以文章后面给的附件`untidy_note`为例（from <a href="elink@96aK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6A6M7$3y4U0i4K6u0W2K9i4y4U0L8r3q4T1i4K6u0W2L8%4u0Y4i4K6u0W2j5$3&6Q4x3V1k6U0K9r3q4D9L8r3g2F1k6$3g2K6i4K6t1K6N6h3&6@1K9h3c8&6i4K6g2X3L8X3!0@1k6b7`.`." >iscc2022</a>）

#### (1) 先对`libc`文件来个`strings`看看版本

![img](upload/attach/202205/943085_5Z9J3BCUVFKTDVN.jpg)

```git
strings libc-2.27.so | grep ubuntu
```

#### (2) 进入`all in one` 看看有无这个版本

![img](upload/attach/202205/943085_64KEF3WRNW8UCS2.jpg)

```git
cd glibc
```

```git
cat list
```

（`glibc`是把`glibc-all-in-one`改过的名字）

发现绝版了，怎么办？

就先用1.5，先换上`all-in-one`里的`libc`试试，本地能打通远程应该没问题（有些时候会出现本地通了远程通不了的奇怪情况）

#### （3）下载`2.27-1.5_amd64`

![img](upload/attach/202205/943085_NZ6UN785CTFRKP8.jpg)

```git
./download 2.27-3ubuntu1.5_amd64
```

#### (4) 把存在`/glibc/lib`里的刚下好的文件拖到你`exp`所在的目录

（因为`./`用起来太香了，而且也不用绑定什么奇奇怪怪的东西）

#### (5) 愉快地连接`libc`和`ld`

先使用`ldd`命令看看连接前的情况：

![img](upload/attach/202205/943085_WGHKS6C2SD4MP24.jpg)

连接：

![img](upload/attach/202205/943085_UUKJSZFFSAYBG4Q.jpg)

```git
patchelf --set-interpreter ./2.27-3ubuntu1.5_amd64/ld-2.27.so ./untidy_note
```

```git
patchelf --replace-needed libc.so.6 ./2.27-3ubuntu1.5_amd64/libc-2.27.so ./untidy_note
```

再用`ldd`或者直接`vmmap`看看

![img](upload/attach/202205/943085_BFZPB6KGFRWB2P5.jpg)

![img](upload/attach/202205/943085_VQ6MGWPYMNXJRZ6.jpg)

就换好了
