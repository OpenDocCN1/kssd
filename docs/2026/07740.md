
# [翻译]翻译Load a Dll From Memory!

前一段为了脱`molebox`打包的文件，拜读了论坛上的一些关于`molbox`的文章。了解到`molebox`是把`dll`解压到硬盘临时文件后再载入的。当时考虑`molebox`这么做可能是出于平台兼容的问题或这个过程太复杂的缘故，所以避免采用从内存中加载`dll`的。前几天看到了有位兄弟推荐了这篇文章，所以看了下，了解了下内存加载`dll`的原理，顺便把它翻译了一下。文章写的相对比较简单，所以大家可以找篇介绍PE文件的文章对照着看。我也是初次翻译文章，如有错误之处，还望各位见谅并雅正。
