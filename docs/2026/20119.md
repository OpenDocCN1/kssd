函数非常简单，就是Count从0开始到5，一共有六层，然后顶和底都是固定的，就从中间的7个数值找出4个，然后得到的序列sha1之后和关键字符串比较就得到flag，keygen:

```
'''BJD hamburger competition  穷举数字的hash，然后进行判断'''
import hashlib

def fun_1(a):     #循环数组
    num=997      #初始第一层是997
    for every in a:
        if(every=='1'):
            num -=127
        elif(every=='2'):
            num *=3
        elif(every=='3'):
            num ^=18
        elif(every=='4'):
            num +=29
        elif(every=='5'):
            num -=47
        elif(every=='6'):
            num *=5
        elif(every=='7'):
            num ^=87
    num ^=127
    return str(num)

list=['1','2','3','4','5','6',"7"]
res=''

for x in list:   #num1
    for y in list: 
        for z in list:
            for w in list:
                res=x+y+z+w
                res2=fun_1(res).encode('utf-8')
                if(hashlib.sha1(res2).hexdigest().upper()=="DD01903921EA24941C26A48F2CEC24E0BB0E8CC7"):
                    print(res)
                    print(res2)
```
