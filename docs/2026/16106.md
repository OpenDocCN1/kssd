
# [原创]没有 WiFi 利用 USB 抓 HTTPS 包

> 环境：Ubuntu，其他环境请自行寻找对应的 `proxychains` 配置。

## 1. 安装 `proxychains`

```bash
sudo apt install proxychains
```

## 2. 配置 `proxychains`

```bash
sudo vim /etc/proxychains.conf
```

在最后一行改成：

```text
socks5 127.0.0.1 8889
```

## 3. 下载 `gnirehtet`

访问：

<https://github.com/Genymobile/gnirehtet>

## 4. 启动

```bash
./gnirehtet start -d 114.114.114.114
proxychains ./gnirehtet relay
```

## 5. 配置 Charles

- SOCKS Proxy 设置为 `8889`
- SSL Proxying Setting 添加 `*.*`
- Access Control Settings 添加 `0.0.0.0/0`

## 6. 证书配置

手机浏览器访问 `chls.pro/ssl`，提示安装证书。

以下操作在 `adb shell` 中执行：

```bash
su
mount -o remount,rw /system
ls -al /data/misc/user/0/cacerts-added/ # 查看有哪些用户证书
cp /data/misc/user/0/cacerts-added/* /etc/security/cacerts/ # 把安装的用户证书全部复制到系统目录
```

复制完证书后，要注意查看权限。部分手机复制后的证书权限和其他原有证书的权限不一样，需要设置为一致。
