# 字符串比较指令(Compare String Instruction)

该指令是把指针`DS:SI`和`ES:DI`所指向字节、字或双字的值相减，并用所得到的差来设置有关的标志位。与此同时，变址寄存器`SI`和`DI`也将根据标志位`DF`的值作相应增减。

指令的格式：`CMPS 地址表达式1, 地址表达式2`

```
CMPSB/CMPSW
CMPSD            ;80386+
```

受影响的标志位：`AF`、`CF`、`OF`、`PF`、`SF`和`ZF`
