# [原创]QuickSYS 开源

首先我要承认我是标题党
带驱动字眼的应该比较热门![](https://bbs.kanxue.com/view/img/face/1.gif)
因为只是几个批处理当然开源![](https://bbs.kanxue.com/view/img/face/27.gif)
既然进来了就继续看看吧

在家常看 看雪精华集 收集些代码![](https://bbs.kanxue.com/view/img/face/28.gif)
有的写驱动的大牛只贴代码或只发C文件
所以每次都要去复制
sources和makefile
或打开IDE创建工程编译
而且要手动去命令行下编译,太麻烦
所以写了些批处理文件代替烦琐劳动
QuickSYS.bat 编译用
SYSSources.bat 复制sources和makefile或新建驱动工程用
SYSSources 文件夹里是编译驱动所需的文件
SYSSources.bat会用到,版权自己打开文件修改下

先安装好WINDDK
我用的是WXP(其它版本的要自己修改下批处理文件)
设置WXPBASE环境变量到WINDDK目录
如![](https://bbs.kanxue.com/view/img/face/27.gif)\WINDDK
执行QuickSYS.cmd 就OK了

右击文件夹会有
QuickSYS CHK CHK模式编译
QuickSYS FRE FRE模式编译
SYSSources 复制sources和makefile等文件或新建驱动工程(以文件夹自动命名)
