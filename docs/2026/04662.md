
# [原创]大众etka汽车电子目录逆向1----图片解密

## 1.找到图片文件

基本上没什么难度，od载入程序，下断点`CreateFileA`，留意传进来的参数很快就找到了

在`Bilder`这个目录下面

![](https://bbs.kanxue.com/upload/attach/201812/309543_N3JAP4HMBBDFPZR.png)

后缀名来看是tif图片 但是很不幸，用系统自带图片浏览器打开查看失败

用FlexHEX 随便打开一张看下十六进制

![](https://bbs.kanxue.com/upload/attach/201812/309543_4JYJSEC6ZZ2USS4.png)

可以看到图片的文件头都是乱码，经过加密了，需要分析一下程序解密的过程

![](https://bbs.kanxue.com/upload/attach/201812/309543_Y7VM6ADY2JHH26P.png)

通过`CreateFileA`断点 在读取图片的时候返回跟踪 找到程序解密图片的函数

![](https://bbs.kanxue.com/upload/attach/201812/309543_P5ADH59HJSAP33Z.png)

祭出神器F5

在od看数据在哪里解密，发现是从第一个判断里的函数`sub_6BF03390`里面

![](https://bbs.kanxue.com/upload/attach/201812/309543_44CPC9EEW67KK6D.png)

跟进去在细致分析一下 是在箭头表明的函数里

![](https://bbs.pediy.com/upload/attach/201812/309543_AGDS3FX3MC9NXRP.png)

到了这里 就可以好好分析一下函数所做的行为了

简单说一下，这个函数先判断文件头是不是需要解密 需要解密 就进入`sub_6BF03BB0(a2, a3);`这个函数里面进行解密操作 然后返回

而解密的算法则是简单的异或 就不详细说了

![](https://bbs.kanxue.com/upload/attach/201812/309543_HD3959JTGNXZR4G.png)

用FlexHEX自带的运算异或了一下  完美把图片给解密出来。

图片解密就算结束了，大众etka汽车电子目录的账号密码是本地保存的，
