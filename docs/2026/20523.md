# \*\*题解\*\*
### 思路
通过整型溢出，在note段向上伪造结构体实现任意地址写，修改一个chunk的size，free它放入unsortedbin leak libc，再通过任意地址写修改free\_hook为system，然后free('/bin/sh')实现shell的get
有些绕过的细节其实调调就能出
