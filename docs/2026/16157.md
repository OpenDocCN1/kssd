
# [原创] Android协议分析（二）——人人视频APP协议分析

## 一、实验准备

`Fiddler`、人人视频样本

## 二、实验步骤

### （1）Fiddler环境配置

[Fiddler配置与安装](https://bbs.pediy.com/thread-268445.htm)

### （2）通过Fiddler抓登录的数据包

![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_G5YTAFYGDBT6TQA.png)

我们随意输入账号和密码，然后随意点击登录按钮，查看`Fiddler`的抓包情况。

![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_YGXSK7GP4VFJXVK.png)

![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_ERUTV6G3R4WKXW5.png)

然后我们可以查看到一些字段信息，可以看见提交的字段，和服务器返回的字段，我们一般搜索长字段，这样更好定位。

### （3）定位代码段

1. 我们使用`AndroidKiller`来搜索字段，从而来定位代码段。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_657DFURQ3YYYPVE.png)

2. 我们通过`jd-gui`来查看`java`代码，以便来分析。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_24UVJZRJDHWGUTR.png)

   我们便可以查看到定义的方法，然后我们进行简要的分析。

3. 我们通过溯源分析，查看`a`方法的调用处。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_TNC7P5Q79A59YEM.png)

   我们可以发现`a`方法的溯源，然后我们一个个的去试，查看调用的情况。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_NDTT9UHY67APU28.png)

   我们简单分析，可以发现`a`方法的调用和定义的方法和密码字段。

   我们继续溯源，发现无法溯源，可能是由于我们只导入一个`class.dex`文件或`jd-gui`问题。

   我们可以尝试动态调试或找寻新的切入点。

### （4）ddms定位代码入口段

1. 我们打开`ddms`，然后过滤应用程序包。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_YSHS3EKDCKCMWVF.png)

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_Z94WPE4DY2FW93C.png)

   通过包过滤，只查看`renren`应用程序的调用情况。

2. 我们清空窗口，重新点击登录按钮，查看`ddms`的窗口调用的情况。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_KRGTDH7EBWYCE6R.png)

   我们可以查找到点击的方法和对应的包名。

3. 我们使用`jd-gui`定位方法段，然后查看方法。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_3RAEUT2NE7WPG5P.png)

   我们定位到点击方法代码段，然后我们可以通过查看按钮的`ID`值进一步定位。

4. 打开`SDK -> Tool`工具中的布局按钮。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_GVGF957BCXCGTJV.png)

   但是打开后报错，没正确找到`adb`。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_87R92JTCZM6N9QM.png)

   解决办法：我们将`adb.exe`复制进到该文件夹下，然后替换`iautomatorviewer`用文档打开以后，把底部的`-Dcom.android.uiautomator.bindir="这里"`换成`adb`的路径就行了。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_Q6NMHDX3RWRT2MP.png)

   [参考网址1](https://bbs.kanxue.com/elink@c76K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1L8r3!0Y4i4K6u0W2j5%4y4V1L8W2)9J5k6h3&6W2N6q4)9J5c8Y4y4A6L8r3W2F1k6K6p5I4y4g2)9J5c8X3q4J5N6r3W2U0L8r3g2Q4x3V1k6V1k6i4c8S2K9h3I4K6i4K6u0r3x3e0l9#2x3K6p5@1z5o6j5%4) 和[参考网址2](https://bbs.kanxue.com/elink@a40K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2T1j5Y4y4E0j5i4S2Q4x3X3g2U0L8$3#2Q4x3V1k6m8i4K6u0r3K9#2m8*7e0%4q4^5L8U0x3#2P5q4)9J5c8R3`.`.)

   此时我们发现我们可以正确打开布局管理器：

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_N47Z8Y3X9HXFQA2.png)

   然后我们在此查找`ID`值。

5. 查找对应的`ID`值。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_FB4B7K6DG8Q6WTT.png)

   然后将其转换成十进制。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_TDCQGYWVE6NYGKR.png)

   然后我们就可以判断是从哪个接口进去。

   ![avatar](https://bbs.kanxue.com/upload/attach/202107/905443_APCMTK9PT8MXS52.png)

   再次分析此处的代码段即可，这里查找`ID`值也可以通过动态调试来判断。
