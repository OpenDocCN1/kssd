
# [翻译]IoT 渗透测试系列文章 Part 1

在本系列博文中, 我们将向你展示使用工具来进行物联网安全评估的具体步骤. 在本篇你可能需要一个设备固件`.bin`才好往下看.

## 需要用到的工具介绍

### file

`file`命令可以确定文件的类型. `file`通过检查文件属性以及读取文件起始部分数据(对普通文件而言)来猜测文件类型. `file`将命令行里的每个文件与系统维护的Magic文件中的模板进行比较, 以确定文件类型.

### xdd

该工具生成十六进制转储或做相反的操作. `xdd`可以创建给定文件或标准输入的十六进制转储, 也可以将十六进制转储转换回它本来的二进制形式.

### binwalk

这是一个固件分析工具. `binwalk`是一个用于分析嵌入式设备文件和可执行代码文件的简单Linux工具. 它主要用于提取固件映像内容.

### strings

它能打印出文件中包含可打印字符的字符串. 对于给定的每个文件, 它会打印出至少有4个字符长(或通过选项指定数量的)的可打印字符序列, 序列最末尾紧跟着的就是一个不可打印字符. 默认情况下, 它只会打印来自目标文件已初始化且已载入的区块中的字符串. 对于其他类型的文件, 它则会打印整个文件中的字符串.

### Radare2

它是一个用于逆向工程和分析二进制文件的完整框架, 由一组可以一起使用或独立使用的小型命令行实用程序组成. 它围绕着计算机软件的反汇编器(反汇编器可以从机器代码生成汇编代码)进行构建, 并支持用于不同处理器和操作系统的各种可执行文件格式.

### hexdump

该工具可以以十六进制, 十进制, 八进制或ASCII形式来显示文件内容. `hexdump`是一个实用的过滤器, 它能在用户指定文件的情况下以指定格式显示, 或在未指定文件的情况下显示标准输入.

### firmwalker

它是一个简单的bash脚本, 用于搜索提取或挂载的固件文件系统中可能感兴趣的内容, 比如`/etc/shadow`, `/etc/passwd`, `/etc/ssl`目录, SSL相关文件如`.pem`, `.crt`, 配置文件, 脚本文件, 其他`.bin`文件, admin, password, remote等关键词, 服务器, 常见二进制文件如ssh, tftp, dropbear等, URL链接, 电子邮件地址和IP地址等.

### 确定文件类型

`file myfile.bin`

### 使用 xdd 检索文件的Magic字段

| 参数 | 描述 |
| ---- | ---- |
| -l <length> | 在遇到<length>个八位字节后停止 |

`xxd -l 4 myfile.bin`

![图片描述](upload/attach/201902/93_PNHB3Q77EMN43HX.png)

### 使用 binwalk 检索文件的 Magic 字段

| 参数 | 描述 |
| ---- | ---- |
| -W | 执行文件或文件的hexdump/diff |
| -l <length> | 要扫描的字节数 |

`binwalk -W -l 100 myfile.bin`

![图片描述](upload/attach/201902/93_96X69CKQDQCDEBQ.png)

### 转储文件字符串

| 参数 | 描述 |
| ---- | ---- |
| -n <number> | 找到并打印任何以NULL结尾的, 至少[number]个字符的序列(默认为4个) |

`strings -n 10 myfile.bin > strings.out`

![图片描述](upload/attach/201902/93_ZZZQ3FJ3Q2WJ79X.png)

### 搜索非 ASCII 字符

| 参数 | 描述 |
| ---- | ---- |
| izz | 搜索整个二进制文件中的字符串 |

`r2 myfile.bin`

![图片描述](upload/attach/201902/93_DRF4PUPGQANECEX.png)

### 显示文件的十六进制内容

| 参数 | 描述 |
| ---- | ---- |
| -C | 以规范的十六进制ASCII码显示. 用十六进制来显示输入偏移量, 后隔十六个空格的两列十六进制字节, 再跟括起来的%\_p格式的十六个字节. |

`hexdump -C myfile.bin > hex.out`

![图片描述](upload/attach/201902/93_TKZWQ5YKVUNDBQV.png)

### 分析固件的架构及其文件系统

`binwalk myfile.bin`

![图片描述](upload/attach/201902/93_SMAX4QBQKR4DV9S.png)

### 自动提取固件文件

| 参数 | 描述 |
| ---- | ---- |
| -M | 对提取的文件进行递归扫描 |
| -r | 在提取结束后删除雕复的文件 |
| -e | 自动对已知文件类型进行提取 |

`binwalk -Mre myfile.bin` 或 `binwalk -Me myfile.bin`
