8. 根据判断2和判断3得出等式：

```
(x-y)<<1+(x-y)+x+z=E8F508C8
(x-y)<<1+(x-y)+x-z = C0A3C68
然后就能推倒出z=0x6E756630
```

9. 因为最终eax=0x40102F，所以带入z进行反推，得出x-y=0x2040F71

10. 得出下列等式：

```
z=0x6E756630
(x-y)<<2+x+z=EAF917E2
(x-y)<<1+(x-y)+x+z=E8F508C8
推导出：
x=0x7473754A
y=0x726F6630
```
