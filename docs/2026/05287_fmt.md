## 【详细过程】

GTA是一个非常不错的单机游戏，虽然早就玩过，但无法上网的时候翻出来玩一玩还是很不错的。这次我们要在`Cheat Engine`的帮助下打造一个“永远不挂”的悍匪。

运行游戏，然后切换出来启动CE（可以在这里下载`aa8K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4N6W2j5Y4y4A6N6r3g2%4k6h3q4@1K9r3g2J5i4K6u0W2j5$3!0E0i4K6u0r3k6r3!0%4L8X3I4G2j5h3c8K6i4K6u0W2M7r3S2H3i4@1g2r3i4@1u0o6i4K6R3&6i4@1g2r3i4@1u0o6i4K6S2o6i4@1f1$3i4K6R3&6i4K6V1K6i4@1f1#2i4@1u0o6i4K6R3H3k6%4c8S2i4K6u0V1N6X3y4Q4x3X3g2W2P5r3g2Q4c8f1k6Q4b7V1y4Q4z5p5y4Q4c8e0k6Q4z5o6S2Q4z5e0q4Q4c8e0c8Q4b7V1u0Q4b7f1y4Q4c8e0N6Q4z5f1q4Q4z5o6c8Q4c8e0N6Q4z5f1u0Q4b7f1g2Q4c8e0N6Q4z5f1q4Q4z5o6c8Q4c8e0k6Q4z5e0S2Q4b7f1j5`）。

永远活着，首先就要找到存储血量的内存地址。由于我们事先不知道存储血量的变量类型，所以`value type`选择`all`。如图所示：

![](https://bbs.kanxue.com/upload/attach/200812/169205_5b6uynoe1wrzlvw.jpg)

`first scan`结束之后，切换回到游戏，扔个炸弹在附近的地上（注意距离，不要一次把“自己”给弄死了），炸弹爆炸后残血了，记住当前血量，再切换出来进行`next scan`，然后回到游戏，给自己来个阿司匹林（密码是`aspirine`）把血加满，再切换出来进行一次`next scan`就能找到存储血量的内存单元了，在CE左边的列表框中双击该地址，将它添加到底部的列表中（在底部的列表中可以看到其类型为`float`），如图：

![](https://bbs.kanxue.com/upload/attach/200812/169205_nwe4d1lkg6ays7z.jpg)

接下来在底部的列表中右击该地址，选择`find out what writes to this address`：

![](https://bbs.kanxue.com/upload/attach/200812/169205_23rz9arhklay1lb.jpg)

此时CE会弹出一个对话框`This will attach the debugger of Cheat Engine to the current process.Continue?`大概的意思就是“这将会附加CE的调试器到当前进程，是否继续？”，选择`yes`就对了。

现在需要切换回游戏，和上面一样再丢一次炸弹，然后切换出来，是否看到有结果了？

![](https://bbs.kanxue.com/upload/attach/200812/169205_zszsedektpsvb7q.jpg)

选中上图中的地址，然后点击右边的“Show disassembler”按钮：

![](https://bbs.kanxue.com/upload/attach/200812/169205_j8xbv0lgc8yce4m.jpg)

注意这三条指令，不熟悉浮点指令的朋友（比如我）可以参考`149K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4m8W2k6r3W2&6i4K6u0W2j5$3!0E0i4K6u0r3N6s2g2@1L8%4u0A6j5h3I4Q4x3V1k6U0K9r3q4H3x3W2)9J5c8V1y4Z5j5i4l9J5i4K6u0V1y4q4)9J5k6h3S2@1L8b7`.`。

```asm
005267DE   .  D983 54030000 fld     dword ptr [ebx+354]
005267E4   .  D86424 6C     fsub    dword ptr [esp+6C]
005267E8   .  D99B 54030000 fstp    dword ptr [ebx+354]
```

这里应该就是载入血量，减去某伤害对应的血量，存储减少后的血量，在CE的`Memory Viewer`中把上面的`fsub`改为`fadd`试试。

切换回游戏，丢炸弹或者进行其他自残行为，是否发现血量不仅没有减少反而增加？

我们只需要将`005267E5`处的字节从`64`改为`44`就ok，下面就来写一个简单的`loader`：

```asm
.386
.model flat,stdcall
option casemap:none

include \masm32\include\windows.inc
include \masm32\include\user32.inc
include \masm32\include\kernel32.inc
includelib \masm32\lib\user32.lib
includelib \masm32\lib\kernel32.lib

.data?
byteswritten dd ?

.data
dbNew db 44h
szTargetName db "gta-vc.exe",0
szErrorCreate db "启动目标进程失败",0
Startup STARTUPINFO <>
processinfo PROCESS_INFORMATION <>

.code
start:
  invoke CreateProcess,offset szTargetName,NULL,NULL,NULL,NULL,CREATE_SUSPENDED,NULL,
                       NULL,offset Startup,offset processinfo
  mov ecx,eax
  jecxz @f
  invoke WriteProcessMemory,processinfo.hProcess,005267E5h,offset dbNew,1,byteswritten
  invoke ResumeThread,processinfo.hThread
  ret
  @@:
  invoke MessageBox,0,offset szErrorCreate,0,MB_OK or MB_ICONERROR
  ret
end start
```
