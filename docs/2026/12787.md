# [原创]WIN7 32位的调试API框架（不完整的水货）

我2013年以前写过的代码都存放在一个储存卡里，储存卡是插在一部手机里面，因为换手机了，那部手机就留在家里，昨天因为要找点以前代码就要家里人拿手机接下电脑，给我远程下，远程过去发现储存卡里面的东西都没了，就问了下家里人，然后得到的回答是：曾经用这台手机插过电脑，电脑上装了某数字的手机助手提示空间不足，然后就点了下那个提示按钮，我听到这里心在滴血啊，数字你是要我赞美你的功能如此简便强大吗![](https://bbs.kanxue.com/view/img/face/50.gif)
最后只有在电脑中还发现以前写的一个调试器代码过程中间的一次备份，不是完整版，干脆发上来给大家参考学习算了，因为是中间版代码写的还比较混乱~
这只是一个DLL工程
挂钩SSDT，把函数索引指向重载内核
处理了窗口函数，防止窗口提串
重写调试API，操作的调试对象自己管理
打开进程线程用到的句柄表也自己建立
完整的工程包括一个驱动工程，在里面开了一个缓冲区，重载内核也在里面，然后还有一个工程就是把这个DLL工程写入驱动文件，DLL里面导出了PatchDriverEntry函数，驱动就调用函数。
还包括一个VT引擎用来接管中断钩子的，不说了都是泪啊╮(╯\_╰)╭
