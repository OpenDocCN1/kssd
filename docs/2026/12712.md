- **总结**:

1. **上图中 使用任务门进入一环时候 esp 012 和 ss 012 不需要赋值,程序直接取得就是 esp 和 ss (经过测验得出结论, 不知道原因)**
2. **fs:三环一环都可以正常运行**
3. **cs:代码段描述符 (dpl = 1)**
4. **ss:数据段描述符就可以 (dpl = 1)**
5. **其他值都是我做测试用的,  无视掉就可以**
6. **总结下:  修改 cs ss esp 就可以成功进入一环**
7. **其他门 可以直接修改 esp 0,1,2 and ss 0,1,2 (不得原因 = = 有兴趣得大家可以测试下)**
