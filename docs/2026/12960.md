# regsnap2.8(build 638)之内存破解 (508字)

小弟初学破解，请多指教
前些天买了张电脑报二○○○年合订本配套光盘，里面有个注册表监视软件Regsnap 2.8 (build 638)
小弟水平太菜，找不到注册码，暴力破解时发现其对本身加密，只要改动就会拒绝执行，用trw2000调试时发现
只要把 1->[004249f0] 就可以解除时间限制。于是用Rpp 做了个内存补丁，其脚本文件如下：

O=Load\_regsnap.exe:

F=regsnap.exe: ; 要补丁的程序

P=4249f0/00/01:

p=40463b/74/75:

p=411401/74,5b/90,90:

$ ; 结束

用rpp.exe 生成文件Load\_regsnap.exe后将其拷到regsnap目录下执行，一切ok
