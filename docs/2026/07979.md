# [原创]VT Debugger with Open Source

本想去年发上来的，结果用的gmail邮箱，密码丢了，后果你们知道的。![](https://bbs.kanxue.com/view/img/face/11.gif)

这个是拿BluePill的代码作为Base，硬改成调试器。

构思到代码成型花掉我一年时间，幸亏公司活少，给了我充足的时间。![](https://bbs.kanxue.com/view/img/face/27.gif)

这个是摘自本人的简历内容。

XP系统的汇编级双机调试器，同时可以调试内核线程和普通线程。
Bypass 业界全部的AntiDebug系统。
Builtin with below Functions.
1. AMD VT System,
2. Internal MMU System,
3. PE Loader,
4. Kernel Socket,
5. BTS Tracer.
6. Bp without CC(int 3) code.
7. PE level Script.
8. PDB support
9. Process Memory Scan

现把Target端的代码全部共享出来，共各位皇上过目。
控制台部分基本上没有技术含量，若此帖被顶到1k页，我愿意也拿出来共各位皇上过目。![](https://bbs.kanxue.com/view/img/face/28.gif)

这个调试器不是真正意义上的调试器，核心是BTS Tracer,专门给XX项目用的。

用法简单附上，
1.WDK编译，ssmon.sys
2.安装它。
3.脚本在script\_src下，目前我做了有3个，WRHIT,XHIT,BTS-TRACE.
4.控制台发命令给target，应该是【脚本文件+参数】。
5.target返回结果，内容应该是【堆栈+IP...】。

效果很不错，AiXX,BXX,DXX 都XX过。
