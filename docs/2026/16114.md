
# [原创]Android7.0以上免xposed使用charles抓取https数据包

初入安卓逆向，先从抓包开始，其实网上有很多资料，这里做一个归类总结。

## 一、前言

目前常见的抓包工具是用fiddler和Charles，但是我已经改用了Charles，具体为什么，待会后面说一下原因；我们在抓https包的时候，会效验证书，7.0以前我们可以将证书手动导入到用户许可区抓取https数据，但是7.0以后我们可以配合xposed的模块把证书验证给设置为可信任的，但是大部分app都会做xposed检测，还是依然抓不到包，这里提供一个不需要xposed的方法，但是必须root。

## 二、刷入证书

我们先通过Charles的`Help->Prpxying->Sava Charles Root Certificate...`将证书导出来，这里我随便命名成`666.pem`，之后通过openssl提取该证书hash。具体命令是：

```
openssl x509 -inform PEM -subject_hash_old -in 666.pem
```

![image](https://bbs.kanxue.com/upload/attach/202004/885524_2P5NJ9BEHT7TKEW.jpg)

我们得到hash为：`409bf644`，将`666.pem`重新命名为`409bf644.0`（后缀是数字0）并将该文件写入到Android的系统证书列表，由于是访问了system目录，需要挂载。所以这就是需要root的原因，具体命令行：

```
adb root
adb remount
adb shell rm -f /system/etc/security/cacerts/409bf644.0
adb push 409bf644.0 /system/etc/security/cacerts/409bf644.0
pause
```

![image](https://bbs.kanxue.com/upload/attach/202004/885524_PNWKEJYGGQDMFY4.jpg)

这里提示了`Read-only File system`，我们把手机重启一遍，在执行一次这个命令即可成功，接着可以进入`/system/etc/security/cacerts/`位置查看下文件是否成功写入：

```
adb shell
cd /system
cd security
cd cacerts
ls | grep "409"
```

![image](https://bbs.kanxue.com/upload/attach/202004/885524_ZJBCSFE3YGXJWH4.jpg)
![image](https://bbs.kanxue.com/upload/attach/202004/885524_RHY2JRTKKTA5N75.jpg)

至于为什么不用fiddler，是因为即使把证书刷入系统区了，有些APP还是抓不到，具体原因不详。
