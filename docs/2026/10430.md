# [旧帖][原创]64位win7下利用debug工具！！！0.00雪花

在初学80x86的时候，由于自己使用的是win7 64位系统，所以给学习80x86汇编造成了一定的环境困难，在win7里面的DOS系统里是不可以直接使用debug工具的，不过可以利用下面的软件解决问题哦。其实，相当于利用DOS工具箱将masm 5.0中相应的程序直接加载进来，面对WIN7是直接加载的DOS工具箱，这样就解决了在win7下使用debug工具的难题。![](https://bbs.kanxue.com/view/img/face/1.gif)
下面介绍下加载使用方法：
1，先下载一个DOSBox-0.74（由于这个较大，无法上传）
2，将DOSBox-0.74解压后，打开DOSBox.exe
3，如图：![](https://bbs.kanxue.com/upload/attach/201208/537681_y1kjydw8q3qxajg.png)
4，假设masm软件放在了e盘下，那么在刚打开的DOS工具箱里面Z:\>输入mount c: e:\masm
5,输入后会弹出“Drive C is mounted as local directory e:\masm\”
6,没事，接着输入c:，然后回车就OK了
7，之后再输入debug,这样就能够使用了。
