## 创建服务

## 服务：`HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\services\SuperBackupMan`

![](https://bbs.kanxue.com/upload/attach/201912/845934_AJYTGCC2D5UVG7Z.png)

## 安全模式：`bcdedit / set {current} safeboot minimal`

这个指令执行后，在重新启动系统时，它将开始进入安全模式,每次启动时，都会获得安全模式

![](https://bbs.kanxue.com/upload/attach/201912/845934_KY5V85FWW9VAY3Q.png)

![](https://bbs.kanxue.com/upload/attach/201912/845934_87NB4P4MKDHRWD4.png)

## 最后执行关机进入安全模式之服务启动自身。
