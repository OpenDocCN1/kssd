# [原创]发几个小工具

不想玩了，github传代码又麻烦,用得到的根据fuzz需求自己改吧!

1.BSODTest是一个fuzz ssdt hook的小工具，为什么有了bsodhook还要有它呢？因为bsodhook慢，且“不支持”对Kifastcallentry hook的fuzz

2.FileBugHunter类似的工具其实也有很多，为什么还写一个呢？因为我喜欢自动化挖掘，而不是一定要用双大眼睛不停的盯着屏幕看，一觉醒来看dump即可.

3.InteractiveFuzz是什么？就是对本地的通信管道、油槽、共享内存等fuzz一下。
