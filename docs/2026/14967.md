
# [原创]【开源】Android Dex控制流平坦化混淆

## 项目介绍

本项目针对Android APK DEX控制流混淆，在不会改变应用原有逻辑的前提下，会将原始代码进行控制流混淆，使得代码难以阅读，增加反编译阅读的难度以达到保护应用。
