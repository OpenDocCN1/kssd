# 瑞星2002版本安装需软盘限制的去除。 (1千字)

首先把下载的rav.exe执行，等到出现要软盘的界面，不要关闭哦。
 然后去windows/temp/ravtemp中拷贝所有文件到自己建立的一个目录中，这些就是真正的安装文件，修改其中的setup.exe，这次的安装限制已经不是修改xetup.dll了。
