by bugvuln(bugvuln\_at\_gmail.com)

## 描述

中国游戏中心是中国一款著名的游戏平台，含棋牌，网络游戏等

8d4K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3y4Z5K9h3&6S2k6$3q4E0k6i4y4Q4x3X3g2F1k6i4c8Q4x3V1j5.

## 受影响的系统

中国游戏中心游戏大厅2009

## 细节

`clsid:75108B29-202F-493C-86C5-1C182A485C4C`

`C:\Program Files\Chinagames\iGame\CGAgent.dll`

`Sub CreateChinagames (ByVal lpszToken  As String)`

参数`lpszToken`是一个超长字符串时，发生栈溢出，利用堆填充技术，攻击者可以很轻松的利用此漏洞执行任意代码

## 解决办法

在厂商没有推出相应的补丁之前，

建议用户通过注册表对相应的`CLSID:75108B29-202F-493C-86C5-1C182A485C4C`设置Killbit

或者将以下文本保存为`.REG`文件并导入:

```text
Windows Registry Editor Version 5.00

[HKEY\_LOCAL\_MACHINE\SOFTWARE\Microsoft\Internet Explorer\ActiveX Compatibility\{75108B29-202F-493C-86C5-1C182A485C4C}]
"Compatibility Flags"=dword:00000400
```
