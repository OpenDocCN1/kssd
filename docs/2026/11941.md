# [原创]windows平台编译调试DynamoRIO和Winafl x86/x64

*不知为什么，每次尝试去编译开源项目都要踩n个坑，应该还是太菜了吧......编译成功后把方法记下来，以后回顾的时候方便看*

1.在windows系统上安装

cmake 3.18.0-rc2

Qt 5.13.0

vs2019

perl

git

everything

（这些软件的其他版本我没试过）

2.下载dynamorio项目源码，进入dynamorio文件夹并创建build\_Win32和build\_x64文件夹，打开cmake-gui

git clone [050K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6p5P5h3&6S2L8h3!0d9d9f1!0Q4x3V1k6V1P5h3&6S2L8h3!0J5K9h3!0Q4x3X3g2Y4K9i4b7`.](https://bbs.kanxue.com/elink@f59K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6p5P5h3&6S2L8h3!0d9d9f1!0Q4x3V1k6V1P5h3&6S2L8h3!0J5K9h3!0Q4x3X3g2Y4K9i4b7`.)

3.编译DynamoRIO为32位

（1）打开cmake-gui，设置源码目录和build目录，之后点击Configure；

![](https://bbs.kanxue.com/upload/attach/202008/825829_USKEHSA58Z5QKQQ.jpg)

（2）选择生成器和生成平台，点击Finish，就开始build了；

![](https://bbs.kanxue.com/upload/attach/202008/825829_55GYR4ABV4RA7MH.jpg)

（3）出现了错误，根据错误信息定位到make/cpp2asm\_support.cmake第243行；

![](https://bbs.kanxue.com/upload/attach/202008/825829_EPGGAN6DR3C9W8B.jpg)

具体原因是没有指定CMAKE\_ASM\_COMPILER；

![](https://bbs.kanxue.com/upload/attach/202008/825829_V7QRME2ACTZPK4S.jpg)

那就用everything搜索ml.exe，随便找一个就行了；

我用的是"C:\Program Files (x86)\Microsoft Visual Studio\2019\Community\VC\Tools\MSVC\14.24.28314\bin\Hostx64\x86\ml.exe"

![](https://bbs.kanxue.com/upload/attach/202008/825829_5A6Q7JTFAGX2W53.jpg)

之后填写到cmake-gui中去，点击Configure继续配置；

![](https://bbs.kanxue.com/upload/attach/202008/825829_AJA4CYNF9QKFKSJ.jpg)

（4）又出错了，这次是CMakeLists.txt的第678行；

![](https://bbs.kanxue.com/upload/attach/202008/825829_9F623BX4HQP486G.jpg)

原因是没有指定CMAKE\_MC\_COMPILER；

![](https://bbs.kanxue.com/upload/attach/202008/825829_GNQHT5MRVCHYB32.jpg)

同样地，用everything随便找一个mc.exe就行了；

我用的是"C:\Program Files (x86)\Windows Kits\10\bin\10.0.18362.0\x86\mc.exe"；

![](https://bbs.kanxue.com/upload/attach/202008/825829_EWUXJYRHNFXH5W5.jpg)

之后填写到cmake-gui中去，点击Configure继续配置；

![](https://bbs.kanxue.com/upload/attach/202008/825829_H6CZUND5D69BGWW.jpg)

（5）又出问题了，这次是没有指定uuid.lib；

![](https://bbs.kanxue.com/upload/attach/202008/825829_CS9244ZR8EYGFRP.jpg)

同样地，用everything随便找一个uuid.lib；

我用的是"C:\Program Files (x86)\Windows Kits\10\Lib\10.0.18362.0\um\x86\Uuid.Lib"；

![](https://bbs.kanxue.com/upload/attach/202008/825829_6RNHBJ279YHWRKS.jpg)

之后填写到cmake-gui中去，点击Configure继续配置；

![](https://bbs.kanxue.com/upload/attach/202008/825829_SD3C6YDCSCCS5MZ.jpg)

（6）又出问题了，这次是没有指定lib.exe；

![](https://bbs.kanxue.com/upload/attach/202008/825829_QD43CXMVC22CN9W.jpg)

同样地，用everything随便找一个lib.exe；

我用的是"C:\Program Files (x86)\Microsoft Visual Studio\2019\Community\VC\Tools\MSVC\14.24.28314\bin\Hostx64\x86\lib.exe"；

![](https://bbs.kanxue.com/upload/attach/202008/825829_PZEJAYZUNE9F25K.jpg)

5.返回dynamorio文件夹所在目录，下载winafl项目源码，创建build\_Win32和build\_x64文件夹，直接用cmake生成vs项目并编译

（1）打开git，获取winafl源码并更新

git clone [9fcK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6Y4L8$3!0Y4L8r3g2H3M7X3!0B7k6h3y4@1P5X3g2J5L8#2)9J5c8Y4N6A6L8X3q4X3L8q4)9J5k6h3N6A6N6l9`.`.](https://bbs.kanxue.com/elink@4d2K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6Y4L8$3!0Y4L8r3g2H3M7X3!0B7k6h3y4@1P5X3g2J5L8#2)9J5c8Y4N6A6L8X3q4X3L8q4)9J5k6h3N6A6N6l9`.`.)

cd winafl

git submodule update --init --recursive

（2）在winafl目录下打开cmd（使用git运行cmake会失败），生成vs项目并编译

mkdir build\_Win32

mkdir build\_x64

A、编译winafl为32位：

cd build\_Win32

cmake -G"Visual Studio 16 2019" .. -A Win32 -DDynamoRIO\_DIR=D:\\_\_workspace\_\_\fuzz\dynamorio\build\_Win32\cmake -DINTELPT=1 -DUSE\_COLOR=1

cmake --build . --config Release

B、编译winafl为64位：

cd build\_x64

cmake -G"Visual Studio 16 2019" .. -A x64 -DDynamoRIO\_DIR=D:\\_\_workspace\_\_\fuzz\dynamorio\build\_x64\cmake -DINTELPT=1 -DUSE\_COLOR=1

cmake --build . --config Release

（3）如果想要winafl在fuzz过程的界面显示彩色以及使用IntelPT的话，则打开winafl目录下的config.h文件，添加下面两个宏定义后重新编译

#define USE\_COLOR

#define INTELPT
