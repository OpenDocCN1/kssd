
# [原创]IDA动态调试启动流程

## 启动流程

在IDA目录`dbgsrv`里找到`android_server`(对应手机系统)复制到手机根目录

```
adb push d:\android_server（IDA的dbgsrv目录下） /data/local/tmp/android_server(手机根目录)
```

设置777权限并启动`android_server`

```
adb shell
#申请ROOT权限（前提手机已经获取到ROOT权限）
su(一定要有root权限)
进入到手机android_server所在目录
cd /data/local/tmp
#设置权限777
chmod 777 android_server(执行权限要给)
```

转发23946端口

```
adb forward tcp:23946 tcp:23946
```

`adb shell` 调试模式启动App

```
adb shell am start -D -n app包名/app入口
```

IDA附加勾选三项，`localhost` 端口23946
