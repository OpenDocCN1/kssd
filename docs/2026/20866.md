# 年近不惑，我第二次买了谭浩强的c语言

1985年的暑假异常炎热，小学毕业的我无所事事，碰巧我的好友要参加计算机学习班（不是每个人都能参加的，因为他是老师的孩子），我便缠着他带我一起去，从此我就被那个神奇的东西迷住了。那时的电脑是Laser 310 ，16K内存，无硬盘、光软、鼠标，看上去就是一个厚一些的键盘，连上一个单色监视器（当时叫这名），操作系统是dos3.1。到了后来，好友觉得没意思不去了，我便自己去旁听，讲课老师也不管我，呵呵。就是好多听不懂。
    等到高一，正式有了计算机班，我第一个报了名。记得第一堂科，整个一个大教室座无虚席，老师也很激动，没见过这么多人，。。。慢慢的，人越来越少，只剩下10来个。我却很高兴，终于可以一人一台机了。最高兴的就是学习完后玩游戏时间，老师拿出录音机，把耳机话筒线连接到310，把磁带里的程序放到310里，当时的“捉鬼”“上楼梯”“国际象棋”仍记忆犹新。一次老师拿出砖头大小的东西插在310上，说是640k内存，这样可以玩“星球大战”了――就是打飞机，呵呵。那段时光是我最快乐的日子，偶尔自己也编个小游戏，或是偷偷把游戏录到自己磁带上，就是参加程序设计比赛名次总是靠后。。。
    1991年高考填报志愿的时候我犯难了：是选择非常感兴趣的计算机，还是我一直梦想的医生。直到现在我都不知道自己的选择是否正确。当时的计算机还没有普及，况且计算机是工具，必须结合自己的专业才能发挥出优势――当时我就是这么想的。于是选择了后者。
等到学习那录取通知书时，看见学校买了10几台pc，发现自己连开机都不会了，因为要插入叫磁盘的一个东西才能启动（当时没有硬盘），感觉自己什么都不会了，计算机发展的好快啊。
    1992年大一寒假回家，知道父亲单位有电脑，于是晚上跑去一看，原来时康柏的386，自己乱捣鼓一阵，按了几个yes，就什么也没有了，只出现2行英文，再也不能启动。带着疑问我回到南京，一有空就步行2站路到新街口书店的计算机专柜去看书，慢慢知道我是格式化了硬盘，没有引导了。从此我养成了一个习惯，每逢周末步行到新街口书店看书，然后到商场听听音响，然后回学校。同时也见证了计算机专柜从10几平方米到上千平方米的发展。也就在这段期间接触到了破解，感觉很神秘，很有趣，于是买了很多书：《IBM/pc微机加密/解密反跟踪技术》《软盘加密与解密新技术》等，包括汇编的教材，感觉就是天书，没有老师，没有电脑，没有网络（真羡慕现在的学生，宿舍里能上网），硬啃不动，别人打球，我在看书，但还是入不了门，直到看到一本在书店看到一本《实用汇编语言入门与编程技巧》，如获至宝，虽然扉页已经脏了，售货员看出我想买就说最后一本，我省吃俭用把它买了下来。这本书最大的特点就是没有电脑你也能学会汇编，厉害吧（我打算有空再看一遍）。后来又买了谭浩强的c语言（第一版），还是看不懂，没有电脑学语言真是不可能啊。虽然有basic基础，买了本vb的书还是有很大差别，加上总是认为学了用处不大，都半途而废了。由于当时的破解都是基于dos的，加上自己没什么基础，仅仅知道些概念。
   1996大学毕业，虽然到了奔腾的年代，自己终于买了台k6－2－450，装上win98，可以跑trw2000了，也进一步学了fxp等大侠的教材，也偶尔能破几个小菜，不禁沾沾自喜，就是苦了我的显示器啊，trw真是好东西，万能断点，直奔主题，破解步骤几乎一成不变，非常适合我等菜鸟。不过我还是喜欢弟弟单位的价值10多万的”奔腾“啊，呵呵。当时注册了一个qq,6位的，可惜好长时间没用，帐户密码都忘了，55555。以后逐渐接触了od，让我头痛的很，虽然界面很友好，但感觉不如trw简单实用，感觉无从下手，直到现在我还没有完全掌握，偶尔也能破一两个简单的程序，都是无壳的，一看见壳，就找脱壳机，没想过手动脱壳，基础太差。。。
现在明显感觉学习学不动了，记忆力也不行了。我想能够支撑我学到现在的就是兴趣了，自己不会主动去学什么，只是遇到问题再去看相关的资料（主要是看雪），甚至去看vba，js编程。看到孩子（8岁）也喜欢电脑，不禁想：如果让他学编程，学什么呢？上网看看，感觉还是老谭的c语言吧，上大学买的已经找不到了，今天过年正好到书店买了第三版，自己先看看，熟悉熟悉，但愿他感兴趣，不过我还是先加强他的英语和数学，算法永远是灵魂阿。
    好了，就写这么多了，祝大家牛年更牛，共勉。
