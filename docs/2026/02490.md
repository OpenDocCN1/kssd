运行CTris 2000，又是漫长而又短暂的3秒钟，点击“Enter reg.code”按钮，
进入注册提示窗口，填写：
User name:tongxinshiwo  Registraiton code:780822
按Ctrl＋N激活TRW，
输入  bpx hmemcpy  ←…… 下断点
输入  g            ←…… 继续运行
返回注册窗口，点击 OK
又返回TRW，你会在屏幕下方看到：
Break on BP1      ←…… 拦截成功
输入  bc \*        ←…… 清除断点
输入  pmodule      ←…… 等于按F12若干次
这时，在屏幕中间你能看到绿色的那一行：
015F:0042CC6D  MOV    [EBX+0C],EAX
按7下F12一直到下面:
015F:004291AE  RET
再按22下F10到:
015F:0046DA61  MOV    EAX,[EBP-0C]      ←……下 D
EDX
看吧，注册码就在眼前。←…… 在屏幕右上方PROT32下面会有个注册码。
我的是：CT87975921
按F5返回，会提示“Invalid user name or registration code!”，
点击“确定”按钮，再点击“Enter reg.code”按钮，进入注册窗口，重
新输入User Name和Registration Code，点击“OK”按钮，你就可以看
到“Thank youfor you registering.”。怎么样，注册用户已经是你了！

破解后的思考：
这个软件到期后，会提示“Your evaluation copy has been expired.”
如果这时你点击“Continue”按钮，程序会自动退出，如果你点击右上角
“×”按钮则程序会继续运行，再点一次“×”按钮，就会看到游戏画面了。
