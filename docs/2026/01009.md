
# [原创]IDA 6.1 bool 及 默认对齐 `sizeof` 设置永久修复

F5 失败问题，各位大大给出了修复方法，但每次分析一个文件都要重做一次，感觉麻烦，找 `cfg` 文件没找到设置的地方，看文档发现用 `idc` 可以解决。

## 原方法

`Options - Compiler`

`sizeof(bool) = 4.`

`default alignment = 4`

## 新方法

```
#include <idc.idc>

#define USERLOAD_IDC

//ref 0eeK9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3S2W2P5q4)9J5k6s2u0S2P5i4y4Q4x3X3g2U0L8$3#2Q4x3V1k6H3M7X3!0V1N6h3y4@1M7#2)9J5c8X3W2V1j5g2)9J5c8Y4y4#2M7s2m8G2M7Y4c8Q4x3V1k6A6k6r3q4V1L8$3y4Q4x3V1j5J5z5o6g2Q4x3X3g2K6K9s2c8E0L8l9`.

//ref idc.idc line 2094 and line 2168
//ref onload.idc
// for x86
//#define INF_SIZEOF_BOOL 186             // uchar;  sizeof(bool)
//#define INF_SIZEOF_ALGN 188             // uchar;  default alignment

//for x64
//#define INF_SIZEOF_BOOL          270
//#define INF_SIZEOF_ALGN          272

static userload(input_file,real_file,filetype)
{
	SetCharPrm (INF_SIZEOF_BOOL,4);
	SetCharPrm (INF_SIZEOF_ALGN,4);
	Message("[default alignment] [sizeof(bool)] set to 4 \n");
}
```

将上面的代码保存为名称为 `userload.idc` 的文件，放置于 `IDA6.1` 目录里面的 `idc` 目录里，每次 `IDA` 分析文件时会自动调用此脚本。
