
# RadASM支持x64汇编

1. 从事开发工作久了想重新学习下汇编，工具必须到位！
2. 为什么要设置RadASM支持x64汇编?
   1. 明明vs已经内置支持masm的编译。
   2. vs2013高亮支持有限、汇编代码无提示。
   3. radasm配置后代码高亮、汇编代码有提示。
   4. ……反正我就是要解决下RadASM支持x64汇编的问题！
3. 下载masm64

4. 解压到指定位置
   1. `C:\masm64`
5. 菜单栏选择“Option”，选择“Make Options”

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_HMK7AZHP6XXEJDV.png)

6. Make Options窗口设置如下，调试器选择`x64dbg`

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_Y55D7HWXHRPTE9E.png)

7. RadASM创建项目，针对单独项目设置

   ```asm
   includelib kernel32.lib
   includelib user32.lib

   ExitProcess PROTO

   .data
   sum QWORD 0

   .code
   main PROC
   mov rax, 5
   add rax, 6
   mov sum, rax
   mov rax, 0
   call ExitProcess
   main ENDP
   END
   ```

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_PKS2NFQZYHZ4P8G.png)

8. 配置头文件、库文件，菜单栏选择“Option”，选择“Environment Variables”

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_HFURGP4W4KJQQNC.png)

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_7YP9RTDCHEZ8J6P.png)

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_Q4HN58UQXTZJAQJ.png)

9. 配置中文支持，菜单栏选择“Option”，选择“Code Editor”

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_7TYNRZTUSFDD7QT.png)

   选择“Code”，配置字体为“微软雅黑”，示例处显示“微软中文软件”

   ![image](https://bbs.kanxue.com/upload/attach/202206/817001_PURAU2VA38RW2HW.png)

10. 此时编译64位汇编无法链接成功。需要修改`ml.exe`为`ml64.exe`。
11. 首先确保电脑安装了Visual Studio，这里我安装的是VS2013
12. 通过Everything 查找`ml64.exe`，

    ![image](https://bbs.kanxue.com/upload/attach/202206/817001_QXAHBSU467RJNW9.png)

13. 打开`amd64`目录，复制该目录下所有文件到`masm64`的`bin64`目录，替换`masm64`目录下`bin64`目录旧的文件。
14. 打开RadAMS下的`Masm.ini`配置文件，`ml`修改为`ml64`

    ![image](https://bbs.kanxue.com/upload/attach/202206/817001_9QYUF44KWAH5B25.png)

15. 编译、链接程序。显示成功。

    ![image](https://bbs.kanxue.com/upload/attach/202206/817001_38FWHTE9JAMWUPE.png)

16.

    ```text
    ml64 /c /Cp "AddTwo.asm"
    Assembling: AddTwo.asm
    Microsoft (R) Macro Assembler (x64) Version 12.00.40629.0
    Copyright (C) Microsoft Corporation. All rights reserved.
    link /ENTRY:"main" /SUBSYSTEM:WINDOWS /RELEASE /VERSION:4.0 /OUT:"AddTwo.exe" "AddTwo.obj"
    Microsoft (R) Incremental Linker Version 12.00.40629.0
    Copyright (C) Microsoft Corporation. All rights reserved.
    Make done.
    ```

17. 为了便于使用`x64dbg`调试程序。创建windows命令行指令快捷操作。`copy2x64dbg.bat`

    ```bat
    :: copy2x64dbg.bat（copy exe to x64dbg dir）

    @echo off

    @echo "拷贝可执行程序到x64dbg目录"
    @echo "使用方法：copy "可执行程序.exe" "x64dbg所在目录" /y"

    set fileName="F:\Code\RadASM\Masm\Projects\AddTwo\AddTwo\AddTwo.exe"

    copy %fileName% "F:\Tools\x64dbg\release\x64\"

    @echo "启动x64dbg调试器调试目标程序"
    start /d "F:\Tools\x64dbg\release\x64\" x64dbg.exe %fileName%

    @echo "窗口自动退出"
    :: pause
    ```
