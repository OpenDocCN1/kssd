
# [原创] 看雪 CTF 2017 秋季第二题

## 调试过程

使用 OD 调试源程序，发现当输入大于 12 字符时有溢出。根据后面的函数发现数学运算只需要 8 个字符，果断输入 8 个字符，没有溢出，执行后面的数学处理方程如下：

```
5*(v1-v0)+v1==0x8f503a42
13*(v1-v0)+v0==0xef503a42
17*(v1-v0)+v1==0xf3a9483
7*(v1-v0)+v0==0x33a94883
```

`v1` 为输入字符高 4 个字符，`v0` 为低 4 个字符。解了很长时间发现没有结果。换个思路，猜测不是关键算法，猜测溢出是为了跳到其它地点。

打开 IDA Pro，在整个 PE 文件中浏览，发现在 `00413130` 处有未反汇编的二进制，而且 `413130` 对应于输入是 `01A`，也能正常输入，怀疑，于是开始测试输入 12 个随机字符，再输入 `01A`，发现跳转到 `exit` 函数，感觉思路对了，就把 `01A` 改成 `11A` 和 `21A` 测试，发现 `11A` 能工作，而且发现是使用跳转花指令保护算法。

## 算法分析

设输入的 12 个字符，以 4 个字符为单位，从高到低分别为 `x1`、`x2`、`x3`。

### 关键公式

1. `(x1-x2)*4+x1+x3==0xeaf917e2`
2. `x2=(x1-x2)`
3. `x1=(x2)*2+x2+x1`
4. `x1+x3==0xe8f508c8`
5. `x1-x3==0xc0a3c68`

根据以上算出 `x3` 为 `0x6e756630`，`x1` 为 `0x7473754a`，`x2` 为 `0x726f6630`。

注册码为：`Just0for0fun11A`
