
# 【征文】一只努力修行的菜鸟

03年高考分数下来了，那小子考的稀乱稀乱，本科学校把他抛弃了。当时学校有一负责招生的大学生把他们那些落了榜的“战友”号召到了一起，三分诱惑七分欺骗的，把他们哄入了自考大军。其实，当时他自己也不知自考是啥玩意，只知道考完就能拿本科证，能拿学位证，当时心里还乐呵呵的。

9月到了，他也要和那群“天之骄子”一样进入大学“深造”！

他选的是光信息科学与技术专业，（其实他也不知道那专业是干啥用的，当时他那山洼洼里还没有人见过电脑，更别说用过baidu ^\_^），没过几天,和他一起的那群学生被扔到了计算机科学技术专业，当时他们都质疑了，也反抗了,可反抗也没用，顺从吧！

其实，在大学之前他从没摸过键盘，他不想做大人们心中的坏孩子，当时计算机这玩意在他心中也是“邪恶”的。可如今他却要与这“邪恶”的专业共舞，真不敢想像他的未来会怎样。

军训结束，正式开始学习，这时他才明白所谓的自考是啥意思：自学＋考试＝自考。没办法，自学也好，考试也好，全是自己的错，苦果只能自己来吃。

努力的学习，拼命的学习。大学刚开始两年的课程很枯燥，几乎天天是和那马克思，毛泽东，邓小平同志打交道，先前他是学理的，为了考试他得每天早上疯狂的到操场上背书.。第一次考试成绩出来，他成了焦点，因为班上邓小平理论只有他一人过了，64分！(不是题目太难,而是范围太广,改卷太严)，可他明白，这并不是他想要的，随后的日子他更加努力了。

某日，终于迎来了他的第一节计算机课：“计算机应用技术”，里面似乎讲的是些WORD 97,EXCEL之类的软件的应用，他脑子一片空白，整堂课，老师讲的净是他从没听过的东西，似乎在老师的口中，高中时学过的化学，物理完全的失效了，他现在还记得老师问的最清楚的一句话是“ISA总线是多少位的？”由于是自考，老师没有申请到上机用的机房，老师吩咐他们自己去网吧实践！终于他可以明正言顺的踏入网吧了，因为他是来实践的！可网吧哪是实践的地方，黑网吧那有啥WORD的东东，当时他还不知道如何下载。总之，他对WORD当时也只有一概念："打资料要用到的东西"。"或许不实践也能考上高分"，他当时赌了一把，结果他赢了。

后来，不知听哪位学长级的高手说计算机可以用来编写程序，并且那程序运行后会出现好玩的窗口之类的东东，所以他一直期待着编程课的到来。终于迎来了第一节高级语言程序设计课，上课时老师提的第一个问题便是：“你们有没有计算机？”，当时只有两同学举手，他明白，那两学生是游戏狂，所以他很心安理得，当时老师生气了：“计算机专业的学生怎么能没有自己的计算机呢！”。没多久，他向家里人开口想买台电脑，当时家里人完全支持，因为大学生似乎都有自己的电脑。

终于他有自己的电脑了，虽然是台二手的，但是他挺满足的，AMD K7的CPU当学习机够用了，当天他捣鼓那声卡驱动就弄了一晚上，始终没有声音，后来才知道是那卖主把电脑给他时声卡驱动就不配套，神奇的东西啊，装个软件就能让它放出声音来，太神奇了。

照着书上的例子，他用TC调出他的第一个`HELLO WORLD`，随后他捣鼓着书中的例子，但他始终也没能找到一个例子可以运行出一个漂亮的窗口。它失望了，他开始怀疑了，C语言写的程序真的能运行出一个漂亮的窗口吗？而不是那黑乎乎的窗口，那时他的机器还不能上网，他对搜索引擎的使用也不太习惯，这些问题随着考试任务的加大，他也渐渐的淡忘了，他认为他的C语言能够应付基本的考试了，不用担心补考。

单调的大学生活一直持续到大二下学期，他还一直在计算机的世界外徘徊。那学期他们又开了一门编程课：“汇编语言程序设计”，大家都挺向往的，因为听说是一研究生毕业的美女老师，他也不例外的一如既往的向往，可看漂亮老师又可学编程，一举两得，上课时老师讲的手舞足蹈，其实当时大家根本不知她在讲什么，或许老师根本也不知她在讲什么，她经常在讲课后习题时卡壳，不知如何继续下去，然后下课后她跑隔壁教室问别的老师，一个字，汗！以至于当时汇编语言上机课时，调试个`HELLO WORLD`整整用了一节课，不管她教的怎么样，但是他们还得学好，因为他们得参加全省统一的汇编语言考试。在那年的时候电脑已经开始盛行了，他们寝室已经连上INTERNET了。为了考试，他验证着习题册上的每道题，programfans上陆续出现他的足迹，也就是在那时他遇到了他的第一个爱好编程的朋友dummy(随后他俩相继出现在看雪).

大二很快就过去了，传说的最难的汇编语言他通过了，大家都羡慕了，有人私下议论：“那家伙太强了，高手呢！”，其实只有他自己知道：“其实我啥不会，只会考试”。

大三，他开始担心自己的前途了，听说现在大学生就业压力很大，如果没有一技之长很难在社会立足，他慌了!

"为何不把以前学过的C和汇编语言加强一下呢，说不定以后靠它们吃饭！"突然他有了这个念头,他建了一汇编语言和C语言的QQ群，决定和大家一起交流，共同学习，其实他们当时交流的也只是为什么`MOV`指令为什么不能这么用或如何用ASM写个计算器之类的技术，他那时浑然不知WINDOWS编程是如此美好，还在整天的讨论着这个中断怎么用，那个中断如何用，孰不知罗云彬老师那时已说：“笔者发现很多高校使用的汇编教程还是停留在清华91版《IBM-PC汇编语言程序设计》之类的教材上，虽然这些教材中基础知识部分永远不会过时，但涉及操作系统的部分还是停留在DOS阶段，随着DOS操作系统的悄然引退，继续把精力花在上面是一种浪费”。

越是`MOV`越是`INT`,他觉得越来越茫然了，他开始怀疑:"C语言,ASM是不是不能写漂亮的窗体程序"，他从他的教材上没看到一个这样的例子，而他又听到一帮高手不停的重复：“语言只是工具，要解决实际的问题你还需要学习其它大量的东西，相对于这些东西，语言只相当于其中的0.00001%”，他不懂这些高手云云，似乎这一切都复杂的很，而他此时从一本JAVA的书上看到一个只有十多行的代码便能实现一个的窗口，于是他决定改学JAVA，就在那时候他遇到了黑客防线，偶然的遇到了OD,突然发现汇编原来还可以这样来玩！用16进制工具将某处修改成`90`便可将一软件变成注册版，太强悍了！他照着书上的例子，将多少软件变成了注册版，太有成就感了。好景不长，他不满足了，为什修改成`90`，`E8`，`E9`之后这些程序会变成注册版？为什么同样的软件在不同的机器上都是修改的相同地址的数据？那些地址为什么跟DOS程序中的那些地址这么大不相同？能不能不修改程序而变成注册版？这些问题充斥着他的大脑，他决定去寻找那些答案。

实践起来必然会遇到很多的麻烦，因为那时他跟本没有WINDOWS程序设计的基础，甚至连MSDN都没有听过，更没有PE文件的基础,简单的`crackme`也只能按着别人指的路线去断点，CTRL+G填入地址，然后修改成`NOP`,突然,他发现`NOP`原来就是传说的`90`，值得庆祝，疯狂修改之,后来听人说这便是传说中的爆破，暴汗!

当时,有些`crackme`会加上些压缩壳来方便交流，这无疑对他身心造成极大的伤害，他一向被宠惯了，看雪上的`crackme`一般是要求不加壳的，没办法,对着教程上录像照着学，照葫芦画瓢, F2在GetProcAddress，然后一路往下F8，对那些压缩壳是百试不爽，可他哪知那是外壳在填IAT呢，有时还独自玩得不亦乐乎。

人永远都不懂得满足，他也不例外，为什么非得在GetProcAddress下断点？脱壳时为什么非得要跳过那些往回跳的跳转？可他手上没有这些资料，生活中也没有人可以请教。计划远比不上变化，JAVA梦也因为各种原因被中断了，另外，他的用C实现窗口程序的梦想还没有实现，更迷茫了............

当为了寻找资料，他下载了不少教程，其实这些教程正是看雪学院出的，顺理成章的他成了看雪学院的一员。当时为了下载一附件，第一次登陆的他被卡住的了，因为没发过帖的人是不能下载附件的，发帖这谁都会，但是菜鸟的他来到这里不知该如何开始这个帖的主题，因为传闻这里管理很严格，弄不好会被封了ID，千金易得ID难求啊，终于找到一可以发水帖的地“休闲版块”，酝酿半天，发了一求指路的帖子，可被顶帖的水友告知休闲版的帖是不计入发帖数中的，他当时差点没晕死过去。

一日,他在网上看到“windows程序设计”这本书，其中有描述如何用C来编写一个窗体程序，兴奋之极，当即抄下源代码，成功编译运行出一像模像样的窗口程序，那种感觉是无法用语言来描述的，果真如先前的高手所说：“C语言无所不能”，如获珍宝，疯狂的上机。

一日,他看到看雪论坛软件调试版块上有一置顶帖“常见问题(FAQ)",从其中的为你指路中他看到了未来的学习方向：IBM PC汇编语言程序设计－>windows程序设计－>加密解密－>软件加密技术内幕－>windows核心编程..........

有了前面的方向，他给自己定了计划，这周windows程序设计，下周加密解密........其实这些书从前图书馆里都有，只是他以前没有注意到而已.

多少个夜晚他独自静坐于15寸CRT前疯狂的按着F8,多少个夜晚他半夜POWER ON他的爱机重新跟踪那未完工的`crackme`,多少次他对着编译器的`0 error(s), 0 warning(s)`疯子般的傻笑.

他认定这些努力一定不是白费的.

06年国庆时,他在看雪上发了自己的第一个crackme分析,骗得老大一个精华,虽然边些对那些老鸟来说还很嫩的,但是他又一次开心的笑了.

.................................................

时间过的真快,他来看雪快两年了,他也要毕业了,一切都得有个了结了.

某日,他决定用他学过的`masm`来完成他的毕业设计--------压缩壳.很顺利的完工了,他又一次开心的笑了,同时他又在看雪骗了一个精华.

某日,找工作遇到麻烦了,他被各公司以各种理由被拒绝.某日,他想到了看雪.某日,他接到面试电话,某日他去公司报到.........

................................................................

今天,他可以整天坐在电脑前投入的、合法的继续"crack".

路还长,他还很嫩,但生活很精彩.

感谢看雪,感谢那些默默帮助他,关注他的人们.
