我们关心的SystemRoot出现了，大致看了下，居然就是计算了SystemRoot字符串的hash！！！然后估计就是查表，其hash算法为：

```
    HashIndex = 0;

    while (WcharLength--) {
        Wchar = *Buffer++;
        HashIndex += (HashIndex << 1) + (HashIndex >> 1);

        if (Wchar < 'a') {
            HashIndex += Wchar;
        } else if (Wchar > 'z') {
            HashIndex += RtlUpcaseUnicodeChar( (WCHAR)Wchar );
        } else {
            HashIndex += (Wchar - ('a'-'A'));
        }
    }

    HashValue = HashIndex;
    HashIndex %= NUMBER_HASH_BUCKETS;
#define NUMBER_HASH_BUCKETS 37
```


好像大致是一个hash目录表，首先简单的通过hash快速查找，对应的37个链表之1，然后遍历链表比较名称是否为SystemRoot。
