
# [原创]Internet Explorer漏洞分析(五)——CVE-2016-0199

## 0x01 漏洞信息

### 0x01.1 漏洞简述

- 编号：`CVE-2016-0199`
- 类型：类型混淆(Type Confusion)
- 漏洞影响：远程代码执行(RCE)/拒绝服务攻击 (DoS)
- CVSS 2.0：9.3

`mshtml.dll`组件在将`CElement`—>`CAttributeCollection`—>`CAttrArray`—>`Attribute.nodeValue`复制到`CAttribute`—>`Variant`时，并未对其进行校验，以致类型混淆，进而可造成任意代码执行。

### 0x01.2 漏洞影响

Microsoft Internet Explorer 9 through 11

### 0x01.3 修复方案

<a href="elink@21cK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6V1L8$3y4K6i4K6u0W2L8h3W2U0M7X3!0K6L8$3k6@1i4K6u0W2j5$3!0E0i4K6u0r3k6h3&6Q4x3X3c8#2M7#2)9J5c8Y4y4W2j5%4g2J5K9i4c8&6i4K6u0V1N6i4m8V1j5i4c8W2M7#2)9J5c8Y4y4W2j5%4g2J5K9i4c8&6j5Y4g2D9L8r3g2@1K9h3&6K6i4K6u0r3x3U0l9I4y4W2)9J5c8X3#2K6x3e0k6Q4x3X3b7H3y4U0x3">MS16-063</a>
