
# [原创] 没什么用之——R0下不一样的SSDT Hook

## 前言

一般的，SSDT hook会采用直接修改SSDT表的方式来进行，或者采用ETW hook来做，这两种办法都不错。那么我说一种比较水的办法来HOOK，可以针对特定进程进行SSDT hook，其是利用Alt系统来做的。

## 原理

如果探究过API R3进R0过程的人，肯定会逆向`KiSystemCall64`函数，不过详细观察该函数，会发现一个奇怪的函数`PsAltSystemCallDispatch`。该函数会在进程设置某些标志位的情况下调用，并且获得TrapFrame。

### 调用

![](https://bbs.kanxue.com/upload/attach/202508/932553_ZYGTBA9ANRCM59R.webp)

通过图片上给出的汇编不难看出，该函数传入的是`TrapFrame`，我们可以转进去看一下。

![](https://bbs.kanxue.com/upload/attach/202508/932553_8PPPTDU6R6JHJWW.webp)

会发现里面竟然从`PsAltSystemCallHandlers`地址处拿指针并执行（`_guard_dispatch_icall`就是个检查一下指针然后call过去）。

此处这个ida的结构体有问题，我们可以看一下真实结构（`_KTHREAD`第一个结构是`_DISPATCHER_HEADER`）：

```C
struct _DISPATCHER_HEADER
{
.....
union
{
UCHAR DebugActive; //0x3
struct
{

};
```

这里判断4也就是（`Minimal`）。继续往后看看。

有指针，果断交叉引用一下快快会不会有什么地方写入，会发现竟然有写指针的函数，和开启该功能的函数。

![](https://bbs.kanxue.com/upload/attach/202508/932553_ZZTVY5JA2BBCJQ3.webp)

### 注册

通过该函数可以发现，`PsAltSystemCallHandlers`只有2个成员，且通过调用该函数可以直接注册回调函数。

![](https://bbs.kanxue.com/upload/attach/202508/932553_3BVBGHNE4PZUCPN.webp)

通过图片的分析我们可以看出来，如果设置的index有回调函数了，就会蓝屏，也就是意味着如果设置了就无法覆盖。

好消息是该函数是导出的函数。

![](https://bbs.kanxue.com/upload/attach/202508/932553_XNAZA6W4YY5X8HG.webp)

所以我们可以直接调用的。

## 代码实现

```C
EXTERN_C NTSYSCALLAPI NTSTATUS NTAPI NtSetInformationProcess(
_In_ HANDLE ProcessHandle,
_In_ DWORD ProcessInformationClass,
_In_reads_bytes_(ProcessInformationLength) PVOID ProcessInformation,
_In_ ULONG ProcessInformationLength
);
#define ProcessAltSystemCallInformation 100
typedef NTSTATUS(*t_PsRegisterAltSystemCallHandler)(PVOID, int);
typedef bool(*t_AltCallBack)(PKTRAP_FRAME);
NTSTATUS RegCallBack(HANDLE hPid, t_AltCallBack pCallback) {
NTSTATUS status = STATUS_UNSUCCESSFUL;
UNICODE_STRING uRegister = RTL_CONSTANT_STRING(L"PsRegisterAltSystemCallHandler");
HANDLE hProc = NULL;
OBJECT_ATTRIBUTES objectAttr;
CLIENT_ID clientId;
t_PsRegisterAltSystemCallHandler pPsRegisterAltSystemCallHandler = NULL;
InitializeObjectAttributes(&objectAttr, NULL, 0, NULL, NULL);
do
{
if (pCallback == NULL || hPid == NULL) {
status = STATUS_INVALID_PARAMETER;
break;
}
pPsRegisterAltSystemCallHandler = (t_PsRegisterAltSystemCallHandler)MmGetSystemRoutineAddress(&uRegister);
if (pPsRegisterAltSystemCallHandler == 0) {
status = STATUS_INVALID_ADDRESS;
break;
}
status = pPsRegisterAltSystemCallHandler(pCallback, 1);
if (!NT_SUCCESS(status)) {
break;
}
clientId.UniqueProcess = hPid;
clientId.UniqueThread = 0;
status = ZwOpenProcess(&hProc, PROCESS_ALL_ACCESS, &objectAttr, &clientId);
if (!NT_SUCCESS(status)) {
break;
}
status = NtSetInformationProcess(hProc, ProcessAltSystemCallInformation, &hProc, 1);
if (!NT_SUCCESS(status)) {
break;
}
} while (false);
return status;
}
```

直接调用这个函数就可以了，第一个参数传入pid，第二个是回调函数。

```C
RegCallBack(ULongToHandle(1234), [](PKTRAP_FRAME pTrapFrame)->bool {
if (pTrapFrame != NULL)
KdPrint(("[+] rax: %p\n", pTrapFrame->Rax));
return true;
});
```

## 说在最后

最重要的事情是：这个东西在**win10上可行**，**win11已经进行了修改**。~~后面有时间再分析~~。

第二重要的是：注册过回调之后无法再次注册，意味着如果对某个进程开启监控时无法停止，也不能卸载驱动，除非进程结束。
