# [原创]看雪CTF2017 第十题分析

cm没有什么校验，也没有加密，实在是我等小菜的福音。

使用x64dbg搜索字符串知道使用了gmplib。

![](https://bbs.kanxue.com/upload/attach/201706/390515_ctjxtr24820cens.png)

正好我以前也用过，还算比较熟悉，还给gmplib提交过代码呢，哈哈。

![](https://bbs.kanxue.com/upload/attach/201706/390515_zwvur537lpdq3cj.png)

然后用ida反编译，结合动态调试，猜出每个函数的意义。

[![](https://bbs.kanxue.com/upload/attach/201706/390515_a6ljs66hbd3xpcx.png)](https://bbs.kanxue.com/upload/attach/201706/390515_a6ljs66hbd3xpcx.png)

这里知道输入为70长度，然后动态调试发现前面6位存一个，后面64位存一个。
[![](https://bbs.kanxue.com/upload/attach/201706/390515_tk218e67ci01z62.png)](https://bbs.kanxue.com/upload/attach/201706/390515_tk218e67ci01z62.png)

接下来的就是标准rsa了。c1其实是N，C2是D，前6位是e，后面64位是p、q中的一个。代码里面有一句比较，这里会校验到底是p还是q。

现在我们知道了N和D，上网搜了下可以解决。

![](https://bbs.kanxue.com/upload/attach/201706/390515_gychhf8s1mczbvu.png)

但是本来是已知n,d,e求p,q的，现在e不知道，我只能暴力破解了。
