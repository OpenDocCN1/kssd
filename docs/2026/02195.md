# Micro Bridge的KeyCode生成程序 (808字)

Micro Bridge 的免光盘注册程序
        http://bridgeworld.myetang.com/soft/lang.zip[111K]

        免光盘执行 Micro Bridge 的 Key Code 防护措施相当变态，在移动软件目录或重装该软件后所申请的(10$)Key
Code 失效。

这个程序的KeyCode似乎跟机器无关，我没有那个软件，无法知道它是否还检查了KeyCode的低位。下面的程序生成的KeyCode可以通过它的lang.exe的检查：


#include <windows.h>
#include <stdio.h>

void main(void)
{
    long KeyCode;
    long Shift[ ] = { 0, 4, 8, 16, 20, 24, 28 };
    long High;
    int  i;

    KeyCode = GetTickCount( ) & 0x03FFFFFFL;
    High = 0;
    for(i = 0; i <= 6; i++)
    {
        High ^= (KeyCode >> Shift[i]) &
0x0F;
    }
    High += 0x10;
    KeyCode |=  (High << 0x1A);
    printf("Your key code is: %lu\n", KeyCode);
}
