# Hardlock加密狗破解过程-----外壳型加密狗的破解方法 (7千字)

MT unlocker 是一个手机解锁软件，它的加密方式是用hardlock加密狗加密，这种加密狗是一种外壳型加密狗，和HASP很相象。


小弟没有接触过外壳的狗，所以破解时用最原始的方法：跟踪。

工具： TRW2000
