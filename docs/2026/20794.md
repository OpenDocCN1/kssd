# [分享]菜鸟的自白

看了好多的大侠都在写自己的学习经过，也写篇来凑凑数（别笑死了才好），主要是给还没进门的
朋友看的
—————————————————————————————
现在的孩子都能很早就有自己的电脑，在我读书的阶段，电脑是一件高消费的东西（想都没想过碰）
在工作后的几年里，电脑才开始普及，那是还是 586 的年代 ，那时我还是没能碰到电脑
我的第一台电脑是在 2002 年的时候买的，开始回家一年还没能上网，但还是感觉超有意思
后来就跟着《开天辟地》学习一些基本的东西，还记得最后一张碟里有教编程的
于是就跟着学了几天 VB（很简单的东西，但还是干感觉超有成就感）
从那以后就知道了软件原来是编写出来的
也就学了几天，我就玩《杀手 2》去了
2004年我这个无所事事的人又对编程起了兴趣，就买了开天辟地学 C/C++ 的那本什么书 ，很简单的东西
但却引起我对 C 的兴趣，那时我家的宽带出了问题，导致我有几个月不能上网（幸好不能上网，不然我就
不能安下心去学了几个月的编程）就是这几个月的学习，就把我的水平固定了（现在还没有超越），原因
简单（上网后灌水啊，下电影啊，玩游戏啊），后来我买了《加密与解密》第二版，但看不懂（一天玩游戏
能看懂才是怪事），于是书就在书架上一摆就是两年。期间我有到看学注册过，但是都是灌水。
直到2006年(忘了是几月份），我又感觉要学学破解了。但汇编真的看不懂，靠。没法，我又去买书《汇编语言》
王爽的这本书还真好学（可能是有那么一点的 C 语言基础吧），我用了大约 2 个月的时间把一些基本的都搞完了
（很多例题没做＋还有部分的东西没全懂），但感觉那些对破解没关系。于是把书一甩，学破解去
于是我就对这大侠们的精华折腾去了，记得第一次看懂算法的是一个用户名累加（感谢这个作者），但同时感觉
学习汇编的两个月还真的白学了，原来那些指令都与我写 C 语言程序的时候是一样的（菜啊），只要你
F8 F8 F8 F8 的，就全明白了。好，明白这就是算法分析后，那劲可就来了，在对着大侠们的精华文章练习的同时
自己下载一些软件和一些盗版光盘里的程序练习。记得破解最多的时候一天几个（简单型的），遇到破解不了的
东西，我就使用无限体谅型的心态（我是菜鸟，破解不了是应份的），这种心里素质高啊！！！！
期间，我还学人写过几个简单的 TM 都人不出来的 CrackMe ,当然也是给菜鸟们练习的 （见不了光的东西）
偶然也去看看《加密与解密》，从来没有翻过10页的（懒惰菜鸟的典范啊）
好，后来还不自量力的去加入 DCG ，靠，还真给我蒙过去了。里面的高人太多了，但不重要，在群里，俺就用潜水
＋灌水的形式。没法，他们常聊的东西都太深了，于是我就唯有潜水。但在群里还是很高兴认识了那些不嫌我菜的大
侠，我们有空就灌灌水。
两个多月前，感觉脱壳实在式太有必要学了（不学没法在论坛灌水了）（看雪是我每天必上的网站，不学点东西，
灌水的地方就小了一个）
脱壳还真的不好搞，要学的东西真不小，需然以前都有脱过简单的，但这两年的壳越来越变态了，光看教程是没用的
基础的东西不扎实，到头也只能人云亦云（惨啊）
其实我感觉学脱壳的其中一样好方法就是学写脱壳脚本，先从简单的 UPX 等写起，慢慢变复杂一些
对着大侠们的脚本，慢慢研究一下基本 45％是可以过关的(再次安慰一下自己）
写道这里。。。。。。。。。。。。。没什么写了，不知道能不能给比我还菜的朋友什么启发呢？
