# [原创]发个我以前写的局域网小程序，有图有源码

这个我以前学C++网络编程的时候做的，看论坛里这么冷清，我就发出来玩玩，没什么技术含量，大家凑合着看吧
需要安装WinPcap，大家可以在网上下，我也上传到附件里面

如果你电脑上超过一个适配器会提示你选择适配器
![](https://bbs.kanxue.com/upload/attach/201303/443879_hgwub1irx3xbdup.png)

我选择了本地连接
![](https://bbs.kanxue.com/upload/attach/201303/443879_kfj6trh1s5wl5lh.jpg)

选择IP冲突或者ARP断网，就会弹出发送ARP窗口，你只需要填上间隔时间和次数就行了
![](https://bbs.kanxue.com/upload/attach/201303/443879_kja89fz1e44zg6g.png)

自动IP冲突和自动重命名冲突是我发明的，大家都知道，当一台电脑登录到系统就会发送一个ARP广播报，来询问是否有人使用该IP，只要你选中自动IP冲突，但程序一收到到ARP广播包，就会发个ARP包过去，说该IP已经有人使用了。
我曾经在我们学校就试过，只要我第一个打开电脑，别人都没开机，我开启软件的这项功能，其他人打开电脑会不停的提示IP冲突，就算是手动修改IP也不行，不管你修改成什么IP始终都会IP冲突。
至于自动重命名冲突就好理解了，前提是你第一个登录局域网，然后开启自动重命名冲突，这样别人一开机就会提示网络上有重名，这其实是因为计算机第一次登录时需要注册计算机名，所以它会发个广播包询问局域网里面该计算机名是否已经注册，如果注册了就会提示网络有重命名
![](https://bbs.kanxue.com/upload/attach/201303/443879_gr8cbvqqsh2711l.jpg)

貌似无线网不能ARP攻击，没什么用的软件，仅供学习
