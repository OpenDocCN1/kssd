
# 注册你的 JAMMER 1.95（4千字）

## 软件信息

- 软件名称：JAMMER 1.95
- 软件主页：http://www.Agnitum.com
- 主要功能：端口/注册表/进程监视器，能反馈扫描者的 IP 和 ISP
- 主要目的：寻找自己的注册码
- 破解难度：非常简单（适合初学者）

## 正规方法

选注册填自己的大名（长度大于等于 8），注册码 1 随便填，注册码 2 填 `78787878`。进 `s-ice` 下 `s 30:0 l ffffffff '78787878'`，下 `bpm "搜到的地址"`，按 `F5` 返回。点注册被拦到，按几次 `F12` 知道进入 JAMMER 领空，再按几次 `F10` 到这里：
