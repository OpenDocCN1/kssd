## （一）`accesscode`获取

神秘的系统，打开发现`1FEH 55AA`，这是`MBR`（系统引导）。首先分析这部分数据，主要功能就是将数据拷贝到`0x8000`处，然后会利用输入的`accesscode`去解密`200H~A00H`处。

解密算法根据输入的4个（`0~9`）循环依次解密。

![](https://bbs.kanxue.com/upload/attach/201403/457816_ayo6ufggtxrxydl.png)

第一个肯定是一个`call`或者`jmp`，根据`opcode`可以推导。

后面就是一个`E8`跳偏移，头执行哪个`E8 *** BCTF`，然后就可以推断出`1337`。

然后解密：

```c
include "stdio.h"

#include <windows.h>

#define SIZE_CODE 0x800

int main()
{
    BOOL BRet = FALSE;
    DWORD dwsize = 0;
    char buf[SIZE_CODE] = {0};
    HANDLE hFile = NULL;

    hFile = CreateFile(
        "bctfos.3bbbcae1ea13b566477c99941a5eee63",
        GENERIC_WRITE | GENERIC_READ,
        FILE_SHARE_READ | FILE_SHARE_WRITE,
        NULL,
        OPEN_EXISTING,
        0,
        NULL
    );

    if (hFile == INVALID_HANDLE_VALUE)
    {
        MessageBox(NULL, NULL, "error", MB_OK);
        return -1;
    }

    SetFilePointer(hFile, 0x200, NULL, FILE_BEGIN);
    BRet = ReadFile(hFile, buf, 0x800, &dwsize, NULL);

    if (!BRet)
    {
        printf("sdas");
        return -1;
    }

    for (int i = 0; i * 4 < 0x800; i++)
    {
        buf[i * 4] = buf[i * 4] ^ 0x31;
    }

    for (i = 0; 1 + i * 4 < 0x800; i++)
    {
        buf[1 + i * 4] = buf[i * 4 + 1] ^ 0x33;
    }

    for (i = 0; 2 + i * 4 < 0x800; i++)
    {
        buf[2 + i * 4] = buf[2 + i * 4] ^ 0x33;
    }

    for (i = 0; 3 + i * 4 < 0x800; i++)
    {
        buf[3 + i * 4] = buf[3 + i * 4] ^ 0x37;
    }

    CloseHandle(hFile);

    hFile = CreateFile(
        "1.txt",
        GENERIC_READ | GENERIC_WRITE,
        FILE_SHARE_READ,
        NULL,
        OPEN_ALWAYS,
        FILE_ATTRIBUTE_NORMAL,
        NULL
    );

    if (hFile == INVALID_HANDLE_VALUE)
    {
        MessageBox(NULL, "1.txt", "error", MB_OK);
        return -1;
    }

    SetFilePointer(hFile, NULL, NULL, FILE_BEGIN);
    BRet = WriteFile(hFile, buf, 0x800, &dwsize, NULL);

    if (!BRet)
    {
        return -1;
    }

    CloseHandle(hFile);
    return 0;
}
```

将得到的数据进行静态分析。

知道文件的创建和存储方式后，就可以还原系统中的文件了。还原步骤如下：

### （1）从1磁头、0磁道、1扇区找到文件头的信息

也就是要将`CHS`（柱面号、磁头号、扇区号）转化成`LBA`（线性地址）。

计算公式如下：

`LBA = ( C – CS ) * PH * PS + ( H – HS ) * PS + ( S – SS )`

可是不知道`PS`（每磁道有多少个扇区）、`PH`（表示每柱面多少磁道）。

想想系统在随机创建的磁头、柱面、扇区、扇区内偏移时，随机的值如果超过了最大值，写入磁盘的时候就会出错，所以我生成的随机值必须保证其在一定的范围之内。

在仔细去看看创建的磁头、柱面、扇区、扇区内偏移处的代码吧。

![](https://bbs.kanxue.com/upload/attach/201403/457816_37tyhrunwwjfrv5.png)

上图`push 4000001`相当于`push 40h; push 0001h`，进入`call sub_1b2`。

![](https://bbs.kanxue.com/upload/attach/201403/457816_d7c4ae16tury4ry.png)

还要注意，扇区是从1开始计数的，磁头是从0开始计数的。

上图可以明确`PS`（扇区数）=`3F`。

建立随机磁头时，`push 20000h`同理可以明确`PH`（最大磁头数）=`02H`。

在计算随机扇内偏移时`push 100000H`，所以将每个`sector`分割成`10H`个，即每个块大小为`20H`。

`C/H/S = 0/1/1`（1磁头、0磁道、1扇区）=`3F`。

`3F * 200 = 7E00`

![](https://bbs.kanxue.com/upload/attach/201403/457816_8kcipckhfjx3mu0.png)

文件名异或`0xcc`后，发现文件名为`key`。

### （2）获取加密的`key`及第一个文件块位置

得到加密的`key = 5252H`，以及第一个文件块存储的磁头=`1`、磁道=`1`、扇区=`3A`、扇区内偏移=`05`，定位到第一块文件，取出文件内容。

根据第一个文件块处所保存的下一块文件的磁头、磁道、扇区、扇区内偏移，找到下一块文件。

### （3）依次读取后续文件块

下一块文件以此类推，直到下一块文件的磁头、磁道、扇区、扇区内偏移均为`0xff`。

根据：

`[( C – CS ) * PH * PS + ( H – HS ) * PS + ( S – SS )] * 200H + 扇内偏移 * 20 = 1ECA0`

![](https://bbs.kanxue.com/upload/attach/201403/457816_jtunbch09e95p46.png)

上图可知：磁头=`0`，柱面=`05`，扇内偏移=`06`，扇区=`11`，计算的下一存储地址：`50CC0`。

![](https://bbs.kanxue.com/upload/attach/201403/457816_0onow8isluvcoch.png)

上图可知：磁头=`01`，柱面=`09`，扇内偏移=`07`，扇区=`27`，计算的下一存储地址：`9A6E0`。

![](https://bbs.kanxue.com/upload/attach/201403/457816_dt77xo69hq11or5.png)

上图可知：磁头=`0`，柱面=`0D`，扇内偏移=`08`，扇区=`3D`，计算的下一存储地址：`D4500`。

![](https://bbs.kanxue.com/upload/attach/201403/457816_1xsjliv0ctymj2j.png)

上图可知：磁头=`01`，柱面=`02`，扇内偏移=`09`，扇区=`14`，计算的下一存储地址：`29D20`。



![](https://bbs.kanxue.com/upload/attach/201403/457816_exun0rcyulvtyir.png)

上图可知 磁头=`01`，柱面=`09`，扇内偏移=`0b` 扇区=`30`计算的下一存储地址：`9B960`

![](https://bbs.kanxue.com/upload/attach/201403/457816_jmt91c768pukxky.png)
