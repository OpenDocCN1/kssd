
# jetcar0.91

**jetcar0.91 目前最新的版本：**

这个东西的注册检验部分一直没变，注册信息放在注册表中，每次启动时判断注册码是否正确。

在 `trw` 中

`:bpx RegQueryValueExA do "d \*(esp+8)"`

当你看到程序在读 `name` 和 `password` 时，就要用 F10 慢慢跟了，因为已经离目标不远了 `^\_^`。

```
:004132F4 MOV EAX,[ESP+0C]      //你输入的注册码
:004132F8 MOV ECX,[ESP+14]　　　//正确的注册码
:004132FC PUSH EAX
.......(注册码比较)..略
```

这个程序不能用 `W32Dasm` 来反汇编，给初手制造了一些麻烦，所以 POST 此文。最后想问问大家知道它用什么手段来防 `w32dasm`？
