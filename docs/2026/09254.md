
# 使vmp生成较干净的解释器

很长时间没上论坛了，把帖子翻了翻，看到这篇[文章](https://bbs.pediy.com/thread-271546.htm)，挺感兴趣的。

想着也很久没有调试软件了，于是花了大概大半天时间，把vmp3的加壳过程调了调。

加壳入口，读取配置，要做什么样的保护，倒是vm了。

```
0000000000269140 0F 00 00 00 00 00 00 00 C8 04 08 00 00 00 00 00 ........È.......
```

但由于作者在生成解释器过程中存在大量的`for`循环以及`stl`相关，可能考虑性能，这部分并没有vm。需要抛异常，导致有一系列比较重要的字符串方便定位（`Runtime error at xxxx`）。
