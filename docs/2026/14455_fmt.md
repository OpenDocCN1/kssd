
# [原创][原创]IDA调试so精细版

1. 复制文件，修改权限，以Root权限运行`android_server`。

```
adb push  android_server /data/local/tmp/
cd /data/local/tmp/
chmod 755 android_server
./android_server
```

2. 端口转发

```
adb forward tcp:23946 tcp:23946     //windows 控制台下转发window 到模拟器或者手机的
```

3. 启动应用

```
adb shell
su
am start –D –n com.web.crack/com.web.crack.MainActivity
```

4. debug

在`ida`中选择`Debuggger--->Attach ----> Remote ArmLinux/Android debugger`，`hostname`填上`localhost`，`port: 23946`，确定。

5. 开始调试
