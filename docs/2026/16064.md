
# [原创]Xposed 安装记录

## 前言

网上已经有很多root及Xposed安装教程，但是可能因为我的Android版本与img问题，导致折腾了几天踩了很多坑，翻了很多Android和Xposed论坛资料，前后经历了：

- 刷Android 8系统手机变砖
- 刷Android 8及以上系统，root变砖
- 安装Xposed后手机再次变砖
- 进入`recovery mode`后显示`error`
- 进入`recovery mode`后显示`no command`
- Xposed安装不上，闪退
- 无限重启
- 卡刷Xposed后卡在开机动画

提示：刷Xposed框架会修改系统文件，所以可能会导致手机变砖，系统崩溃。以及刷成功后系统变卡变慢。并且不保证每台机器都可以刷成功，请自行评估再决定是否安装。

测试手机型号：Nexus 5X Android 7.0

以下是这几天的不断试错的一个总结。

- USB调试，开启

5. 把Android SDK文件解压与 TWRP img文件放一起，运行Android SDK中的`fastboot.exe flashing unlock`解锁

如果已经解锁会提示`FAILED (remote: Already unlocked)`

解锁成功后手机fastboot状态为 `DEVICE STATE - unlocked`

6. 此时再输入以下命令刷入recovery

`fastboot.exe flash recovery twrp-3.2.1-0-bullhead.img`

7. 此时不重启直接按手机的音量键选择 `Recovery mode`，按电源确认，进入recovery后：

点击`cancel`，再点击`keep read only`，出现`team win recovery project`

选择`wipe`，拖动三个箭头的图标确认，点击recovery主图标返回主界面，此时就可以访问`sdcard`内存了。

（低版本系统升级，`wipe`最好四清后刷入）

8. 返回recovery主界面后，选择`mount`，点击两次MTP选项，第一次点击`Disable MTP`变成`Enable MTP`，再点击一次变成`Disable MTP`，就会开启手机的U盘。

## 总结

1. 请使用Android 7及以下版本的系统，不要使用Android 8及以上。

2. 刷完TWRP再刷SuperSU root后，开机进行个性化设置，接下来应该关机重新进入`Recovery mode`安装Xposed框架了，但是安装之后启动会一直卡在开机动画，进不了系统。

在其他论坛搜了很多资料，其中有个答案是：把TWRP安装完之后，再使用TWRP root手机之前，需要先卡刷Xposed，否则会停留在开机动画

在吾爱破解上看到有另一个解决办法：

1）首先在系统中卸载Xposed安装器（`XposedInstaller`）

2）然后进入第三方Recovery中，卡刷Xposed卸载包`xposed-uninstaller-xxxxxxx-arm##.zip`

然后再重新刷入recovery模式中刷入Xposed框架，这种方式测试可用。

3. 另外把TWRP安装完之后，再使用TWRP root手机之前，不root情况下卡刷Xposed，会出现重新进入`recovery mode`后显示`no command`，这就跟第2步矛盾了。

这时候进入`fastboot`，执行

`fastboot.exe flash recovery twrp-3.2.1-0-bullhead.img`

此时不重启直接按手机的音量键选择 `Recovery mode`，按电源确认，进入recovery后

使用TWRP卡刷SuperSU。



## 刷机问题：卡在开机动画的解决方法

刷完`TWRP`并在刷入`SuperSU`进行`root`后，开机进行个性化设置。接下来应关机重新进入`Recovery mode`安装`Xposed`框架，但安装之后启动会一直卡在开机动画，无法进入系统。

在其他论坛搜索了很多资料，其中有个答案是：把`TWRP`安装完之后，在使用`TWRP` root手机之前，需要先卡刷`Xposed`，否则会停留在开机动画。

在吾爱破解上看到有另一个解决办法：

1. 首先在系统中卸载`Xposed`安装器（`XposedInstaller`）
2. 然后进入第三方`Recovery`中，卡刷`Xposed`卸载包`xposed-uninstaller-xxxxxxx-arm##.zip`

然后在重新刷入`Recovery mode`中刷入`Xposed`框架，这种方式测试可用。

另外，把`TWRP`安装完之后，在使用`TWRP` root手机之前，不`root`情况下卡刷`Xposed`，会出现重新进入`Recovery mode`后显示`no command`，这就与第2步矛盾了。

这时候进入`fastboot`，执行：

```bash
fastboot.exe flash recovery twrp-3.2.1-0-bullhead.img
```

此时不重启，直接按手机的音量键选择`Recovery mode`，按电源确认，进入`Recovery`后，使用`TWRP`卡刷`SuperSU`。
