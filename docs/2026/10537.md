一道C++测试题

在这个函数前面加代码，使能工作，并输出：
　　　　<Hello> <world> <foo> <bar> <yow> <baz>


```
void test_tokenizer()
{
  std::string str = ";;Hello|world||-foo--bar;yow;baz|";
  
  boko::tokenizer tokens(str, "-;|");

  for (boko::tokenizer::iterator it = tokens.begin();
       it != tokens.end(); ++it)
    std::cout << "<" << *it << "> ";
}
```
