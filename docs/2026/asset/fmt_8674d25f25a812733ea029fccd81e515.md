
# [原创]CVE-2018-8550分析与复现

## 这个漏洞属于com组件Unmarshal类型本地权限提升漏洞

### 复现环境

1. Windows 10 1709 32位操作系统
2. 需要安装声卡或操作系统自带虚拟声卡
3. 编译环境Visual Studio 2013
