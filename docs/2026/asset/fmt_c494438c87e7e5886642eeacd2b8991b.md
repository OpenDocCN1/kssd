OK，我们再来看看如何利用程序自身作注册机，因为正假码在程序中的比对方式为字符串形式，给我们省了不少麻烦
改`00471CDE` `mov eax,dword ptr ss:[ebp-4]`处为
```
00471CDE     jmp 471D4A
00471CE0     nop
```
再把`00471D4A`处改为如下:
```
00471D4A    mov eax,edx
00471D4C    nop
00471D4D    nop
00471D4E    nop
```
