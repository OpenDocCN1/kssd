
# 开源大规模扫描、暴破、漏洞利用工具包Leviathan

![](https://github.com/leviathan-framework/leviathan/raw/master/levlogo.png)

Leviathan是一个大规模的审计工具包，具有广泛的服务发现，暴力破解，SQL注入检测和运行用户定制漏洞的能力。它包含开源工具，例如`masscan`，`ncrack`，`dsss`，并为您提供组合使用它们的灵活性。

该项目的主要目标是在全国范围内或在广泛的IP范围内审计尽可能多的系统。

## 主要特点

**服务发现**：通过Sensan，Censys发现在特定国家或IP范围内运行的FTP，SSH，Telnet，RDP，MYSQL服务。还可以通过集成的`masscan`工具手动发现IP范围上的运行服务。

简短演示：[020K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3y4U0p5%4j5Y4y4^5L8o6q4&6z5o6c8T1j5i4j5&6k6U0g2T1j5%4N6D9L8s2R3%4M7R3`.`.](https://bbs.kanxue.com/elink@85eK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3y4U0p5%4j5Y4y4^5L8o6q4&6z5o6c8T1j5i4j5&6k6U0g2T1j5%4N6D9L8s2R3%4M7R3`.`.)

**暴力破解**：您可以通过集成的`ncrack`工具暴力破解发现的服务。它具有包含最受欢迎的组合和特定服务的默认密码的单词列表。

简短演示：[d28K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3y4o6y4&6x3X3Z5K6z5s2A6#2y4$3S2T1L8Y4g2S2K9s2u0B7x3U0x3K6k6o6g2J5x3l9`.`.](https://bbs.kanxue.com/elink@6eaK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3y4o6y4&6x3X3Z5K6z5s2A6#2y4$3S2T1L8Y4g2S2K9s2u0B7x3U0x3K6k6o6g2J5x3l9`.`.)

**远程命令执行**：您可以在受感染的设备上远程运行系统命令。

简短演示：[318K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3x3s2S2U0M7X3S2V1x3e0u0X3x3X3I4H3K9$3u0C8N6r3A6D9k6s2N6@1j5h3t1I4y4R3`.`.](https://bbs.kanxue.com/elink@e89K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3x3s2S2U0M7X3S2V1x3e0u0X3x3X3I4H3K9$3u0C8N6r3A6D9k6s2N6@1j5h3t1I4y4R3`.`.)

**SQL注入扫描器**：发现具有特定国家/地区扩展或您自定义Google Dork的网站上的SQL注入漏洞。

**利用特定的漏洞**：用Shodan，Censys或`Masscan`发现易受攻击的目标，并通过提供自己的漏洞利用工具或使用预先包含的漏洞利用工具来利用这些漏洞。

简短演示：[c3fK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3z5i4g2I4M7$3A6$3L8Y4u0#2y4K6R3H3K9o6m8#2k6e0k6G2K9K6W2B7z5h3E0@1j5R3`.`.](https://bbs.kanxue.com/elink@a26K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6S2M7$3y4A6K9h3&6W2L8h3q4Q4x3X3g2G2M7X3N6Q4x3V1k6S2i4K6u0r3z5i4g2I4M7$3A6$3L8Y4u0#2y4K6R3H3K9o6m8#2k6e0k6G2K9K6W2B7z5h3E0@1j5R3`.`.)

## 集成工具

`Masscan`：这是由Robert David Graham开必的非常快速的TCP端口扫描器。Leviathan使用`masscan`来检测巨大IP范围内的服务。 [5d1K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6J5L8$3u0W2M7Y4c8V1j5i4k6A6k6r3N6J5j5h3S2S2L8g2)9J5c8X3#2S2M7%4y4U0j5h3^5`.](https://bbs.kanxue.com/elink@779K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6J5L8$3u0W2M7Y4c8V1j5i4k6A6k6r3N6J5j5h3S2S2L8g2)9J5c8X3#2S2M7%4y4U0j5h3^5`.)

`Ncrack`：`Ncrack`是一种高速网络身份验证破解工具。Leviathan使用`ncrack`来暴力破解FTP，SSH，RDP，Telnet，MYSQL等服务。[145K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6F1L8h3q4H3i4K6u0r3L8X3y4J5j5h3y4C8](https://bbs.kanxue.com/elink@436K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6F1L8h3q4H3i4K6u0r3L8X3y4J5j5h3y4C8)

`DSSS`（Damn Small SQLi Scanner）：`DSSS`是Miroslav Stampar的功能齐全而又小巧的SQL注入漏洞扫描程序。Leviathan使用`DSSS`来识别特定URL上的SQL注入漏洞。 [593K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6K6N6r3q4E0M7r3q4J5L8g2)9J5c8V1c8e0f1#2x3`.](https://bbs.kanxue.com/elink@4f0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6K6N6r3q4E0M7r3q4J5L8g2)9J5c8V1c8e0f1#2x3`.)

## 安装

有关详细的安装，请访问我们的[wiki](https://bbs.kanxue.com/elink@1b5K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6D9k6i4k6A6j5i4c8Z5j5h3&6Q4x3X3c8X3M7X3q4E0k6i4N6G2M7X3E0Q4x3V1k6D9k6i4k6A6j5i4c8Z5j5h3&6Q4x3V1k6%4K9h3E0A6)页面。

### Kali Linux：

通过克隆Git仓库下载leviathan：

`git clone 01aK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6D9k6i4k6A6j5i4c8Z5j5h3&6Q4x3X3c8X3M7X3q4E0k6i4N6G2M7X3E0Q4x3V1k6D9k6i4k6A6j5i4c8Z5j5h3&6Q4x3X3g2Y4K9i4c8Q4y4U0l9`.

进入文件夹

`cd leviathan`

安装Python库：

`pip install -r requirements.txt`

完成！

### Debian / Ubuntu：

通过克隆Git仓库下载leviathan：

`git clone 185K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6D9k6i4k6A6j5i4c8Z5j5h3&6Q4x3X3c8X3M7X3q4E0k6i4N6G2M7X3E0Q4x3V1k6D9k6i4k6A6j5i4c8Z5j5h3&6Q4x3X3g2Y4K9i4c8Q4y4U0l9`.

进入文件夹

`cd leviathan`

运行安装脚本。它将安装所需的工具（ncrack，masscan）和python库。

`bash scripts/debian_install.sh`

完成！

Python版本2.7.x是运行此程序所必需的。

**支持的平台**：Linux（Kali Linux，Debian，Ubuntu），macOS

使用以下命令运行程序：

`python leviathan.py`
