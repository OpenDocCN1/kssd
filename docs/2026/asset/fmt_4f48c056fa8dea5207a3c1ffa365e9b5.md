# 注册算法

1、取机器码 `12` 位长度的偶数位构成新的数字 `6` 位长度

`504848328369` → `088239`

2、取新数字首 `2` 位乘 `7`

`08`：`08*7 = 56`

3、取新数字末 `2` 位乘 `8`

`39`：`39*8 = 312`

4、取新数字中间 `2` 位，乘 `3`

`82`：`82*3 = 246`

5、将结果连接起来构成新数字 `56312246` 就是注册码。
