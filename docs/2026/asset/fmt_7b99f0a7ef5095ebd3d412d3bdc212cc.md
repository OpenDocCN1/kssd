
# [原创]批量检测 Android App 的 SO 中是否有 SVC 调用

## 原理

原理很容易理解：

- 对于 `ARMv7`，`svc 0` 对应的二进制数据为 `00DF`，调用号位于 `R7` 寄存器中。
- 对于 `ARMv8`，`svc 0` 对应的二进制数据为 `010000D4`，调用号位于 `X8` 寄存器中。

只要在 SO 文件的 `.text` 段中找到相关的二进制字符串，就可以确定是否存在 `svc` 调用。再向前查看，就可以分析出 `svc` 的调用号是多少。由于不同人的写法不同，分析出的调用号可能也不一样。

## 实现原理

实现原理就是遍历文件夹下的每个 SO 文件，读取 ELF 信息，找出 `.text` 代码范围，然后在这个范围内查找 `010000D4` 字符串，再向前查找 `X8` 的值。

`svc` 调用可以越过沙箱和 `libc` 的 `hook`，在一定程度上进行风控。
