# 4. 时间盲注(以第九关为例)

1）

`id=1' -- 1` 耗时大概2000毫秒

![](https://bbs.kanxue.com/upload/attach/202009/873637_M6Z7TSWT7DG72GE.png)

`id=1' and sleep(5) -- 1` 耗时大概7000毫秒

![](https://bbs.kanxue.com/upload/attach/202009/873637_8NMHBJ5R4CPQ7Z5.png)

这说明`and`后面的表达式执行了

2）

我们可以利用时间的差别，做判断

如 `id=1' and if(length(database())=1),sleep(5),null) -- 1`

`and`后为一个判断语句，如果数据库名字长度为1，那么执行`sleep`函数，那么就要等5000ms，否则不用等

这样在`if`里面填入我们待判断的信息，通过查看是否延时执行来判断`if`条件是否成立即可

3）

下方代码用于获取网页响应时间，其余代码与布尔盲注大体相似

```
import requests

r = requests.get("e37K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8U0p5J5y4#2)9J5k6e0m8Q4x3X3f1H3i4K6u0W2x3g2)9J5c8V1I4W2M7%4y4Q4x3X3b7&6i4K6u0r3")
print(r.elapsed) # 总时长，单位秒
print(r.elapsed.total_seconds()) # 以天为单位
print(r.elapsed.microseconds) # 获取微秒部分，大于0小于1秒
print(r.elapsed.days) # 秒，大于0小于1天
print(r.elapsed.max) # 最大时间
print(r.elapsed.min) # 最小时间
print(r.elapsed.resolution) # 最小时间单位
```

# 5. 双注入(以第六关为例)

1）

会用到`floor()`、`rand()`、`group by`、`count(*)`这些函数

`floor(rand(0)*2)`，意思是随机产生0或1

`group by`在sql表里就是按照这个表的某一列中的字段分组

如：有一列是单元楼号，里面有1单元，2单元等等，那么就按照1单元分为一组，二单元为一组

`count`和`group by`合起来用就是统计每组的数值和

如 输出为 所有住一单元的一组的总人数， 所有住二单元的一组的总人数

2）

`group by` 在执行时会生成一张虚拟表，这张表的主键就是`group by`后面的`key`

因为`group by`后面是一个随机值，那么如果查询表的key值为0，检测虚拟表无重复，再插入的时候有生成1，主键冲突就会报出错误。

3）

`id=1" and 0 union SELECT 1,2,COUNT(*) FROM information_schema.TABLES group by concat(version(), floor(rand(0)*2)) %23`

`%23`就是`#`，`version()`是版本信息，更改`concat()`的参数值，就可以得到想要的内容
