
# [原创]使用`VIM`查看内核代码

`VIM`配置见：<http://bbs.pediy.com/showthread.php?t=157951>

下面以WRK1.2为例，讲解下如何使用`VIM`查看大型工程源码，常见快捷键请大家参考里面文档

**注意：源码路径尽量不要含有空格和汉字**

1、首先在工程根目录随便建一个`damn.c`，如图

![](https://bbs.kanxue.com/upload/attach/201211/118994_v93b61vrtfvtca4.jpg)

2、右键菜单，使用`VIM`打开该文件，然后输入命名【`Normal`模式 `:call ProjectRefreshTags`】

当然你也可以在命令行下自行手工生成源码索引文件

![](https://bbs.kanxue.com/upload/attach/201211/118994_4diu0k62ko0wfzu.jpg)

![](https://bbs.kanxue.com/upload/attach/201211/118994_b47b6qot0sjsmf3.jpg)

3、输入命令`:cs find s NtCreatePort`

这里也可以直接到用`VIM`打开源码文件，F3可以自动交叉查找光标下面的符号。

![](https://bbs.kanxue.com/upload/attach/201211/118994_0h3dxirtzrfic41.jpg)

4、结果如下

![](https://bbs.kanxue.com/upload/attach/201211/118994_1kp6h7ymanxy0xj.jpg)

5、F4可以打开查找结果

![](https://bbs.kanxue.com/upload/attach/201211/118994_twg0ljisgprwb4k.jpg)

6、F9可以打开左侧文件栏，Ctrl+F9重置为标准布局，自行体验下

![](https://bbs.kanxue.com/upload/attach/201211/118994_p8zi6rkub6c5d6u.jpg)

![](https://bbs.kanxue.com/upload/attach/201211/118994_mgbmvswgi2n1sl9.jpg)
