## GOAD-第三部分 使用用户账号枚举

![image-20230901150432319](upload/attach/202309/986394_Z4RFVSDQB2KP962.jpg)

- 按照思维导图, 获取用户密码后 第一件事就是枚举域内完整用户.

```
GetADUsers.py -all north.sevenkingdoms.local/brandon.stark:iseedeadpeople
```

![image-20230901151202151](upload/attach/202309/986394_NE75T8F4R958ACR.jpg)

- 由于林中存在域名信任, 可以通过LDAP查询其他域信息

```
ldapsearch -x -D '<USER>@<SUB\_DOMAIN>.<TLD>' -w '' -H 'ldap://<DC\_IP>' -b 'dc=<SUB\_DOMAIN>,dc=<TLD>'
```

- 查询`north.sevenkingdoms.local`域用户信息

```
ldapsearch -H ldap://192.168.56.11 -D "brandon.stark@north.sevenkingdoms.local" -w iseedeadpeople -b 'DC=north,DC=sevenkingdoms,DC=local' "(&(objectCategory=person)(objectClass=user))" |grep 'distinguishedName:'
```
