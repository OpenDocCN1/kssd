### 方法一：清除软件使用次数限制（两种途径）

首先查壳，运行`PEID`，载入中国象棋V2.0，无壳，如下图：

![](https://bbs.kanxue.com/upload/attach/201101/304196_w3erln62av02ywy.jpg)

运行软件，启动时有注册提示窗口和30天试用信息，如下图：

![](https://bbs.kanxue.com/upload/attach/201101/304196_m11souilytubysk.jpg)

点击现在注册，注册软件，发现有错误提示窗口，如下图：

![](https://bbs.kanxue.com/upload/attach/201101/304196_cn36at6c1fwrt77.jpg)

点击开始—运行，输入`regedit`，打开注册表，点击编辑—查找，输入`chess`：

![](https://bbs.kanxue.com/upload/attach/201101/304196_1nl6dv58ytosvvn.jpg)

点击查找下一个，`F3`继续，来到下图处：

![](https://bbs.kanxue.com/upload/attach/201101/304196_gr46m2tzn0gvk3f.jpg)

观察`DayOfUsed`键的数据似乎与时间有关，将时间修改为2011.1.9试一下，在`DayOfUsed`键上单击鼠标右键—修改，2011.1.19修改为2011.1.9：

![](https://bbs.kanxue.com/upload/attach/201101/304196_f73itfnhsz3mdtg.jpg)

重新运行软件，发现软件使用天数变为11天，

![](https://bbs.kanxue.com/upload/attach/201101/304196_atvdftd4k2eoj1i.jpg)

可以肯定，该键值的数据就是计算使用天数的基准日期，将2011.1.19改为3011.1.19，可以达到永久试用的目的。

还有一种思路也可达到永久试用的目的，既然软件有计算试用天数的程序，我们只要跳过这部分不就可以达到永久试用的目的吗？

### 方法二：爆破

既然注册时有错误提示，可以通过查找字符串来查找按钮事件，`OD`载入软件

![](https://bbs.kanxue.com/upload/attach/201101/304196_4toiurmbxhmq84g.jpg)

在汇编窗口单击鼠标右键，选择Ultra字符串参考—1.查找ASCII，

![](https://bbs.kanxue.com/upload/attach/201101/304196_xxfd9q2x86m7d07.jpg)

双击“姓名和注册码不匹配，注册不成功！”这一行，来到主程序窗口，

![](https://bbs.kanxue.com/upload/attach/201101/304196_jz5cj52zzqn3hnw.jpg)

往上观察，发现了一些关键东西：

```
00430B67    E8 24E9FFFF     call ChineseC.0042F490       关键CALL
00430B6C    84C0            test al,al                    关键比较
00430B6E    6A 40           push 40
00430B70    68 90044400  push ChineseC.00440490          ; gzpower chess
00430B75    75 21           jnz short ChineseC.00430B98    关键跳
00430B77    68 9C1A4400 push ChineseC.00441A9C  ; 姓名和注册码不匹配，注册不成功!
00430B7C    8BCE            mov ecx,esi
```

在`00430B70`这行单击鼠标右键，选择汇编，将`jnz`修改为`jz`，在汇编窗口单击鼠标右键，选择复制到可执行文件—所有修改，然后选择全部复制，

![](https://bbs.kanxue.com/upload/attach/201101/304196_j0cf5qx82yqvv2b.jpg)

单击鼠标右键，选择保存文件。

重启中国象棋V2.0，仍有注册提示窗口，但可以注册成功，

![](https://bbs.kanxue.com/upload/attach/201101/304196_wmxb28c9hhfqd74.jpg)

重启后仍然是未注册版，因些必须去掉提示注册的NAG窗口中。

`OD`载入软件，用`F12`暂停法去掉NAG窗口，`F9`运行软件，然后到反汇编窗口，按`F12`键，`Alt+F9`执行到用户代码，

![](https://bbs.kanxue.com/upload/attach/201101/304196_vnsk9tr2ob2bdzm.jpg)

`00408499` 这一行是调用注册提示的NAG窗口， 往上查找，发现`00408461`这一行正好跳过调用注册提示的NAG窗口，在`00408461`这一行单击鼠标右键，选择汇编，将`jnz`改为`jmp`,

![](https://bbs.kanxue.com/upload/attach/201101/304196_audq7lejh1it7zj.jpg)

在汇编窗口单击鼠标右键，选择复制到可执行文件—所有修改，然后选择全部复制，然后单击鼠标右键，选择保存文件。

重启中国象棋V2.0，没有注册提示窗口，直接进入软件，如下图：

![](https://bbs.kanxue.com/upload/attach/201101/304196_64n48ek822fbi37.jpg)
