
# 如何破解只能在编译器的IDE中运行的控件 (4千字)

其实很简单，这类控件（VCL、ActiveX）多半是用`FindWindow`、`FindWindowEx`等来查找编译器的IDE程序的窗口，据此来判断IDE是否正在运行。当然实际上也可以通过自己的父进程名来判断（即判断自己的loader是谁）IDE是否正在运行；还可以枚举系统所有进程，从中查找IDE的进程名・・・无非是根据IDE进程的某些独有特征。比如，假定某个IDE在运行时必定会创建一个名为`XXXXMutex`的mutex，则也可以通过是否存在这个mutex来判断IDE是否正在运行。

例子：

VCLZip v2.22 for BCB5

http://www.donet.com/~vclzip/
