
`00423E11` |. `8B45 F8` mov `eax`, `dword ptr [ebp-8]` ; EAX 的返回值在这里了

`00423E14` |. `C9` leave

`00423E15` \. `C3` retn

### 总结一下关键 CALL2：

第一次：`[ESP+C]=[ESP]=0 *0A=0+1=1`

第二次：`[esp+c]=[esp]=1 *0a=0A+1=0B`

第三次：`[esp+c]=[esp]=b*0a=6E+2=70`

类似于：

```
sum=0
sum=sum*0A+注册码(i)数值本身
i++
```

描述的不是很好，但是你自己跟一遍就有感觉了。。

```vb
Dim sn2 As Long
Dim i As Integer
Dim n As Integer
Dim s As String
Dim l As Integer

Private Function call2(n As Integer)
sn2 = 0
s = Str(n)
l = Len(s)
    For i = 1 To l
        sn2 = sn2 * &HA + Val(Mid(s, i, 1))
    Next i
      call2 = sn2
End Function
```
