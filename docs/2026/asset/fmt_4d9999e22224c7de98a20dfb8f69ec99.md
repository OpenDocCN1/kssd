第一次循环完成后得到的 `ebx` 的值，放入第二次循环继续计算，每次循环最终值放入 `ecx` 中。

这个部分的注册算法为：

设 `ecx` 的值从初始到所有循环完成，分别为 `N(0)`、`N(1)`、`N(2)`、`N(3)`、`N(4)`...则：

`ecx = ((注册名字符的ASCII值) + 32) + N(n-1)`

以我填入的注册名“lovefire”为例：

`N(0) = 0`（初始的 `ecx=0`）

`N(1) = 6C + 32 + 0 = 9E`（第一次循环，所以 `N(1-1)=N(0)=0`）

`N(2) = 6F + 32 + 9E = 13F`（第二次循环，所以 `N(2-1)=N(1)=9E`）

`N(3) = 76 + 32 + 13F = 1E7`（以下类推）

`N(4) = 65 + 32 + 1E7 = 27E`

`N(5) = 66 + 32 + 27E = 316`

`N(6) = 69 + 32 + 316 = 3B1`

`N(7) = 72 + 32 + 3B1 = 455`

`N(8) = 65 + 32 + 455 = 4EC = 1260`（十进制）

这个部分的注册算法为：

设 `ecx` 的值从初始到所有循环完成，分别为 `N(0)`、`N(1)`、`N(2)`、`N(3)`、`N(4)`...则：

以我填入的注册名“lovefire”为例：
