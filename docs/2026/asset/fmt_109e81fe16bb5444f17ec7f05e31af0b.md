
# [原创]《精通UNIX下C语言编程及项目实践》学习笔记06 总结及展望

时至今日，这本书已经看完，笔记同样也已经整理完毕。至于最后的三章与项目实现相关的章节就不写笔记了，以后有机会可以写点大项目的设计及实现笔记。

相对来说，这本书不难，属于初学者可以接受的范畴；接下来的时间我准备继续学习《Linux程序设计》以及《深入理解计算机系统》。

在学习的过程中同样准备写一部分笔记，不过不同于上本书的笔记：因为《精通UNIX下C语言编程及项目实践》相对比较简单，在问题的阐述上也没有那么详尽，所以在写笔记的时候采用了以典型代码为主线；而在学习《Linux程序设计》时，将更换为以各种C编程难点为主线。下面是该书的情况：
