### 典型的用户态调试程序流程

```
CreateProcess(…)

DEBUG_EVENT DebugEv;                  
DWORD dwContinueStatus = DBG_CONTINUE; 
while(true) 
{ 
WaitForDebugEvent(&DebugEv, INFINITE); 
dwContinueStatus = DebugEventHandler(&DebugEv);
ContinueDebugEvent(DebugEv.dwProcessId, 
DebugEv.dwThreadId, dwContinueStatus); 
}
```

`CreateProcess`调试方式打开被调试程序, `WaitForDebugEvent`等待调试事件, `DebugEventHandler`处理调试事件, `ContinueDebugEvent`恢复被调试程序,继续执行

首先从`WaitForDebugEvent`下手:

`WaitForDebugEvent`调用`DbgUiWaitStateChange`

`DbgUiWaitStateChange` (`DBGUI_WAIT_STATE_CHANGE` StateChange, `PLARGE_INTEGER`)

`DbgUiWaitStateChange`第一个是返回参数为一个返回的调试对象,第二个参数为超时时间

```c
typedef struct _DBGUI_WAIT_STATE_CHANGE {
    DBG_STATE NewState; //枚举常量,代表新的调试状态
    CLIENT_ID AppClientId; //包含进程和线程句柄
    //描述详细信息的联合结构
    union {
        DBGKM_EXCEPTION Exception;
        DBGUI_CREATE_THREAD CreateThread;
        DBGUI_CREATE_PROCESS CreateProcessInfo;
        DBGKM_EXIT_THREAD ExitThread;
        DBGKM_EXIT_PROCESS ExitProcess;
        DBGKM_LOAD_DLL LoadDll;
        DBGKM_UNLOAD_DLL UnloadDll;
    } StateInfo;
} DBGUI_WAIT_STATE_CHANGE, *PDBGUI_WAIT_STATE_CHANGE;
```

`DbgUiWaitStateChange`压入返回调试信息，超时时间，1,调试对象句柄,调用内核函数`NtWaitForDebugEvent`

内核里调试对象结构:

```c
typedef struct _DEBUG_OBJECT
{
    KEVENT EventsPresent; //用于指示有调试事件发生的事件对象
    FAST_MUTEX Mutex; //用于同步的互斥对象
    LIST_ENTRY EventList; //保存调试事件的列表
    ULONG Flags; //标志
} DEBUG_OBJECT, *PDEBUG_OBJECT;
```
