
# [原创][原创]编写PE文件分析器之二  查看输入表 输出表

大家好，在写输入表这一部分的时候，主要是为了自己能更加深入的理解PE文件格式； 输入表的部分代码参考了北极星2003老兄的一部分，然而发现，在北极星2003写的那个pe文件分析器导入表部分，它用了`firstThunk`作为指针来输出Thunk rva 和函数名，由于在内存映射时改变`FirstThunk`中的数据，所以函数名就怎么都显示不出来了； 由于打算将这个PE文件分析器继续写下去，所以在完成每一部分后，我会将源代码发出；以便大家学习讨论，共同进步，也希望大家能对程序做些改进，而不是简单的复制粘贴代码，由于临近期末，所以时间不多，进度也就慢了点；大家多包涵；
