接下来，咱们就用`ollydbg`来调试看看这些数据了，记住，并没有那么神秘的。

![](https://bbs.kanxue.com/upload/attach/201201/61348_gvv00e831428g3v.jpg)

我这里写一个小程序里面就调用一个函数`GetModuleHandle`,咱们要做的就是跟进这个函数去看看

![](https://bbs.kanxue.com/upload/attach/201201/61348_yjjfptxczteq6ga.jpg)

这个就是这个函数的执行体了，咱们要关心的就是`7C80B764`这个地址的一句：

```
mov eax,dword ptr fs:[18]
```

`fs:[0]`寄存器里面存的就是指向`TEB`的地址,看看是什么地址啊,

![](https://bbs.kanxue.com/upload/attach/201201/61348_eq5vwaz7h10do33.jpg)

看到没`eax`指向的就是`TEB`的地址,接着执行，`teb`地址偏移30由上面的头文件就可以看出是`peb`的地址了，

![](https://bbs.kanxue.com/upload/attach/201201/61348_6jplb3fkmh34k1n.jpg)

此时可以确定`peb`的地址就是`0x7FFDE000`了

由上面的`PEB`结构

```
PVOID ImageBaseAddress;                          // 08h
```

再偏移08h就是基址了

```
UCHAR BeingDebugged;                             // 02h
```

偏移2字节就是表示是否被调试跟踪了

![](https://bbs.kanxue.com/upload/attach/201201/61348_el7mcj4f7almeb5.jpg)

偏移2处就是`01`了 ，呵呵 ，表示被调试跟踪了，偏移8是`00400000`，这就是基址了，可以证明了

如果自己用代码可以这么测试了：

```
mov     eax, fs:[30h]               ;指向 PEB
movzx   eax, byte ptr [eax + 2h]
or      al, al
jz      _Fine
```

如果等于`0`就是ok得了否则就被跟踪了。
