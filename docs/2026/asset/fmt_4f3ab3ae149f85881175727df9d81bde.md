
# `telock 0.85f`的一点脱壳经验

by Fpc[CCG]/6767[BCG]

研究了一下`telock 0.85f`对记事本的加壳，在已知入口点的情况下是能脱掉的 :)

由于现在我还没有通过跟踪找到入口点，所以方法还没有普遍性。下面简要介绍一下。

`Load`加壳后的记事本，下`bpm 4010cc x`，当然需要运行`super bpm`，拦下后把它`Dump`出来。在编辑dumped文件前先用16进制文件工具修改section的个数，原来是`FFFF`，根据你对目标的判断改为10个或20个。用`peditor`继续编辑，修改入口，把多余的段删除，选`dumped fixer`修复段信息，保存。

用`importREC`修复`importTable`，参见近几天的`asprotect`的精华贴。会有四个函数无法修复，记下`ptr`值。在程序(未脱壳的)运行时用`softice`的`u`命令观察相关位置，发现都是`00`，可以认为这四处是垃圾信息，因此删除。把新建的`importtable`附加到脱壳后的文件上。运行，爽!

没有问题。
