
# [原创]一个典型的游戏盗号木马逆向分析(有样本)

兵法有云:知已知彼,百战不殆。攻克敌人从了解敌人开始。

小弟新作，一个老病毒，练手用，大鸟勿喷！IDB，样本，文档随后附上。

------------------------------------------------------------

病毒大小23KB左右，为游戏盗号木马，采用UPX加壳，开机自启动。运行期间监视游戏帐号和密码等信息的输入，发送到指定的URL，导致游戏帐号和密码的泄露。

## 一、感染环境

Windows xp，windows 7能感染(其它环境没有测试)

## 二、感染特征

### 1、文件行为：

在`%systemroot%\system32`下创建：`91C7DF6D.dll`和`91C7DF6D.cfg`，其中`91C7DF6D.dll`为木码盗号DLL，`91C7DF6D.cfg`为加密的URL内容。解密后为：

`cadK9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4V1H3N6h3E0#2x3g2)9J5k6h3y4G2L8g2)9J5c8X3y4A6j5g2)9J5c8X3u0A6K9$3g2Q4x3X3g2S2M7%4l9`.

在`%Temp%`目录下，创建前缀为live的临时文件。

删除`C:\WINDOWS\system32\VErCLSiD.exe`文件。

### 2、进程行为：

设置全局钩子，令`91C7DF6D.dll`注入所有进程。

结束杀软进程，删除杀软托盘图标和结束游戏进程。

### 3、注册表行为：

创建键值：

`hKey = HKEY_LOCAL_MACHINE`

`Subkey ＝"Software\microsoft\windows\currentversion\Explorer\shellexecutehooks"`

`Value name="{91C7DF6D-AEF5-4136-9252-AF030D7A5931}"`

`hKey = HKEY_CLASSES_ROOT`

`Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"`

`Value date="91C7DF6D.dll"`

`hKey = HKEY_CLASSES_ROOT`

`Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"`

`Value name="ThreadingModel"`

`Value date="Apartment"`

### 4、网络行为：

访问URL：`816K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4V1H3N6h3E0#2x3g2)9J5k6h3y4G2L8g2)9J5c8X3y4A6j5g2)9J5c8X3u0A6K9$3g2Q4x3X3g2S2M7%4l9`.

## 四、过程分析

### 1、创建进程同步事件对象，然后创建新线程

![](https://bbs.kanxue.com/upload/attach/201304/461323_tcc48xu8zyldcqh.png)

创建子线程是病毒核心功能，运行结束后，才释放事件对象。

### 2、创建91C7DF6D.cfg和写入数据

在字符串`"91C7DF6D-AEF5-4136-9252-AF030D7A5931"`取出`91C7DF6D`，加上`cfg`拼成文件名`91C7DF6D.cfg`，调用`GetSystemDirectoryA`得到系统目录，最后拼接成文件路径。`%systemroot%\ststem32\91C7DF6D.cfg`

申请堆空间，加载源文件到堆空间，返回堆指针。如下图

![](https://bbs.kanxue.com/upload/attach/201304/461323_fkc6g7jlrfrewf8.png)

在源文件`offset=9fc4`处读出92字节大小的数据。去掉`0D 0A`得到数据如下：

`2DB2C93C09AD60F3BC9A2C35EDF1D148220000002200000072F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F572F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F5`

如果`91C7DF6D.cfg`文件存在，执行下一步；如果不存在在`%systemroot%\ststem32\`创建`91C7DF6D.cfg`文件，写入以上数据。

### 3、创建91C7DF6D.dll文件，然后写入数据

在字符串`"91C7DF6D-AEF5-4136-9252-AF030D7A5931"`取出`91C7DF6D`，加上`dll`拼成文件名`91C7DF6D.dll`，调用`GetSystemDirectoryA`得到系统目录，最后拼接成文件路径。`%systemroot%\system32\91C7DF6D.dll`

申请堆空间，加载源文件到堆空间，返回堆指针。然后在`%systemroot%\ststem32\91C7DF6D.dll`创建文件，在文件`offset=67C0h`（脱壳后的）处，读出数据14336B大小数据写入文件。如下图：

### 5、修改注册表

查看

`HKEY_CLASSES_ROOT\Software\microsoft\windows\currentversion\Explorer\shellexecutehooks\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}`是否存在。如不存在，下面创建键值。如下图：

![](https://bbs.kanxue.com/upload/attach/201304/461323_a1vrwa7164mq7h1.png)

通过`CreateToolhelp32Snapshot`，`Process32First`和`Process32Next`查找MD5为：`AF 9C 01 04 86 7E D2 84 13 89 16 7E 77 5B 83 32` 的进程，找到终止它，如下图。MD5的计算通过 `CryptAcquireContextA`，`CryptCreateHash`，`CryptHashData`和`CryptGetHashParam`等系列函数计算得到。

![](https://bbs.kanxue.com/upload/attach/201304/461323_fetir07iawbu39d.png)

删除`%systemroot%\system32\verclsid.exe`文件，防止自创建CLSID时`verclsid.exe`认证。

调用`RegOpenKeyEx`，`RegCreateKeyA`和`RegSetValueExA`等API分别在注册表创建以下值：

```
hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Valve data ="91C7DF6D.dll"

hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Valve Name="ThreadingModel"

Valve date="Apartment"
hKey = HKEY_LOCAL_MACHINE
Subkey = "Software\microsoft\windows\currentversion\Explorer\shellexecutehooks"
Valve Name="{91C7DF6D-AEF5-4136-9252-AF030D7A5931}"
```

![](https://bbs.kanxue.com/upload/attach/201304/461323_5dbqi843pv952yz.png)

设置访问权限为"`SeBackupPrivilege"`，创建前缀为`live_`开头的临时文件，调用`RegSavaKeyA`保存`Software\microsoft\windows\currentversion\Explorer\`信息。然后设置访问权限为"`SeRestorePrivilege"`，调用`RegRestoreKeyA`从临时文件中恢复注册表信息。调用`RegFlushKey`将修改的注册表信息实际写入磁盘，删除临时文件。重复一次相同操作，确定修改注册表成功。如下图：

### 11、删除杀软托盘图标和进程注入

创建无限循环子线程：

通过`CreateToolhelp32Snapshot`创建快照，寻找进程名MD5为下列值的进程。然后把访问权限设为`SeDebug`特权，通过一套函数`FindWindowA`，`FindWindowExA`，`GetWindowThreadProcessId`和`SendMessage`等来删除托盘。

通过`GetProcAddress,WriteProcessMemory,CreateRemoteThread`等系列函数，把DLL注入到游戏主进程。如下图：

![](https://bbs.kanxue.com/upload/attach/201304/461323_7w5h3v06yn1q8o1.png)

### 12、设立全局钩子

调用`SetWindowSHookExA`设下`WH_CBT`类型全局钩子，如下图，目的是把自身（`91C7DF6D.dll`）注入所以进程中去，得以寄生，不易被终止。

### 13、注册表的修改

创建限循环子线程不断监视注册表：

首先查找`%systemroot%\system32\VErCLSiD.exe`，存在的话就删除它，防止验证。用`RegCreateKeyEx`检测是否存在

`HKEY_LOCAL_MACHINE\Software\microsoft\windows\currentversion\Explorer\shellexecutehoos\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}`键值。如果不存在，接着创建如下键值(exe主程序一样的做法)：

```
hKey = HKEY_LOCAL_MACHINE
Subkey =“Software\microsoft\windows\currentversion\Explorer\shellexecutehooks”
Value name=”{91C7DF6D-AEF5-4136-9252-AF030D7A5931}”

hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Value date=”91C7DF6D.dll”

hKey = HKEY_CLASSES_ROOT
Subkey = "CLsID\{91C7DF6D-AEF5-4136-9252-AF030D7A5931}\InprocServer32"
Value name=”ThreadingModel”
Value date=”Apartment”
```

### 14、查找游戏进程，记录信息然后发送帐号与密码信息。

查看寄主MD5值是否为：`AF9C0104867ED2841389167E775B8332`（猜测为游戏进程名MD5值，有谁帮我破解下），如果是就结束该游戏进程。然后通过过程，键盘，鼠标钩子监视输入的游戏帐号与密码。

然后读取`%systemroot%\system32\91C7DF6D.cfg`的数据如下：

`2DB2C93C09AD60F3BC9A2C35EDF1D148220000002200000072F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F572F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F5`

分成两段：`Key()=2DB2C93C09AD60F3BC9A` （共10个字节）

`C()=72F18A7B04B578B3FCDA357BEAB38D0A2BAB9D6453B534ADEA82796BB1A3C81E69F5`

解密过程（如下图）：

设`i=1`;

`C(i)=Key( i%10 )  Xor  C(i)`

`C(i)= C(i)  Xor  37h`

`i++`继续第2步，直到`C()`解密结束

最后得到明文：`P()=4c4K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6i4V1H3N6h3E0#2x3g2)9J5k6h3y4G2L8g2)9J5c8X3y4A6j5g2)9J5c8X3u0A6K9$3g2Q4x3X3g2S2M7%4l9`.
