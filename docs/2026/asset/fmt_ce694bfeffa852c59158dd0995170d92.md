### 2. W11scan工具的使用

这里介绍github上一位老哥开源的框架，使用后发现效果不错，github网址：[W11scan网址](https://bbs.kanxue.com/elink@cf9K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6%4i4K6u0V1k6r3W2Y4K9i4c8S2L8q4)9J5k6s2y4U0j5h3&6F1k6i4u0Q4x3V1k6%4x3e0q4K6j5$3q4F1)

#### （1）工具介绍

`w11scan`是一款分布式的WEB指纹识别系统（包括CMS识别、js框架、组件容器、代码语言、WAF等等），管理员可以在WEB端新增/`修改指纹，建立批量的扫描任务，并且支持多种搜索语法。

#### （2）安装步骤

由于`W11scan`是作者从一个纯净的ubuntu上安装的，因此我们最好选用ubuntu系统，这里我们测试的是ubuntu18.0

##### <1> 安装python3、pip，下载软件并安装依赖

```bash
sudo apt install -y python3 python3-pip python-celery-common git
git clone https://github.com/boy-hack/w11scan
cd w11scan
pip3 install -r requirements.txt
```

我们在安装`requirements.txt`中模块时，可能会提示一些模块的版本过低，我们可以采用pip安装，或单独安装这些模块

##### <2> 安装redis、mongodb、导出指纹数据

```bash
sudo apt install -y redis-server mongodb
sudo mkdir -p /data/db # 建立Mongodb存储目录
```

我们需要让`mongodb`在`65521`端口上运行，先停止`mongodb`

```bash
service mongodb stop
```

再启动

```bash
sudo mongod --bind_ip 127.0.0.1 --port 65521
```

我们启动时可能会报错误

![image-20211120143236112](https://bbs.kanxue.com/upload/attach/202111/905443_JX4ZN26EQT6CB7F.png)

解决办法：

一、两种解决方法
（1）杀掉apt-get进程：
```bash
ps aux | grep apt-get
sudo kill PID
```
（2）强制解锁：
```bash
sudo rm /var/cache/apt/archives/lock
sudo rm /var/lib/dpkg/lock
```
经检测第二种方法会有用

![image-20211120143303883](https://bbs.kanxue.com/upload/attach/202111/905443_PDT2DBXHVRBTZ79.png)

我们可以发现此时我们的数据库已经监听在`65521`端口上了

接着导入指纹

```bash
mongorestore -h 127.0.0.1 --port 65521 -d w11scan backup/w11scan
```

接着输入`mongo --port 65521`进入`mongodb` shell
`show dbs` 查看是否有`w11scan`数据库创建，有则创建成功。
接着对结果进行全文索引。 依然在`mongodb` shell状态下

```javascript
use w11scan_config
db.result.createIndex({"$**":"text"})
```

完成后`exit`退出
