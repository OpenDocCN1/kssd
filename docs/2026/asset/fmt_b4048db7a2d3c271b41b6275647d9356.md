## 漏洞利用

我们知道 `heaparray` 的地址，可以使用 `house_storm` 实现任意地址申请 `chunk`，这样我们就能控制 `r3`、`r4` 的值，使得 `show` 可以使用。然后正常泄露 `heap` 和 `libc`，正常修改各种 `hook` 即可。

### 前置脚本

```python
from pwn import *

context.terminal = ['tmux','splitw','-h']

context.os = 'linux'

def debug(gdbscript=""):

def add(size):
    r.recvuntil(b"Command: ")

    r.recvuntil(b"Index: ")

    r.recvuntil(b"Command: ")
    r.sendline(str(4).encode())
    r.recvuntil(b"Index: ")
    r.sendline(str(index).encode())
```
