程序输入`123456`和`654321`是提示`SUCC`否则`FAIL`

我先直接贴出`test.dll`里面的代码 也方便大家下面和IL代码进行对比 至于为什么定义两个函数 因为`maxtocode`会把`private`的函数名称加密 `public`的就不会动 所以我这里定义两个函数 好有个对比

```
namespace test

{

    public class Class1

    {

         // Fields
        private static Class1 _Instance;
        private string Default_Key1;
        private string Default_Key2;

        // Methods
        public Class1()
        {
            Default_Key1 = "123456";
            Default_Key2 = "654321";
        }

        private int PassOrNot(string Key)
        {
            if (Key == Default_Key1)
            {
                return 0;
            }
            else if(Key == Default_Key2)
            {
                return 0;
            }
            else
            {
                return 1;
            }
        }

        public string KeyComp(string Key)
        {
            int iRet = PassOrNot(Key);
            if (iRet == 0)
            {
                return "pass";
            }
            else
            {
                return "nopass";
            }
        }

        // Properties
        public static Class1 Instance
        {
            get
            {
                if (_Instance == null)
                {
                    _Instance = new Class1();
                }
                return _Instance;
            }
        }
    }
}
```

## 3. Hook JIT 编译流程

上图中箭头指向的那个窗口最好放在比较好看到的位置 然后`OD`点调试-重新开始 这时候`test.exe`又运行到 要求输入注册码的地方了 这时候我们不要急着输入而是运行我们自己写的`Hook compileMethod()`函数的程序 如果`hook`成功 会出现如下界面

![](https://bbs.kanxue.com/upload/attach/201202/377721_xlum4yy0ljt6c4h.jpg)

这说明 我们已经成功把`getJit()`-`compilemethod()`-`jitNativeCode()`-`compCompile()`的流程改了 变成了`getJit()`-`compilemethod()`-`My_compileMethod()`-`jitNativeCode()`-`compCompile()` 至于我在`My_compileMethod()`做了什么 我只是判断一下如果现在`JIT`编译的是我需要的方法 就弹出一个`MFC`对话框 作用其实把他理解成为一个断点更合适 如果现在是编译我们需要的方法 那么我就先断在`compilemethod()`的后面`jitNativeCode()`的前面位置 一边来说壳都要到`compCompile()` 才会把`IL`代码还原成明文 在这之前你去取`COR_METHOD_INFO` 这个结构体里面的 `ILCODE*` 和`ILCODESIZE`的数据绝对是加密的乱码

## 4. 下断点到 compCompile

如果你理解了上面的话 那么你应该知道怎么做了 随便输入一个密钥 点击按钮 这时候肯定弹出来一个函数名对话框 如下

![](https://bbs.kanxue.com/upload/attach/201202/377721_4hlxi3drvuidtrn.jpg)

这时候再在红色箭头地址处 也就是`compCompile()`函数处下内存访问断点 点击弹出对话框上面的确定按钮 肯定会断在`[7906E997]`的位置 哈哈 这意思就是我们的`JIT`编译器要即时编译`KeyComp()`这个函数了 并且肯定都把明文参数都传给`compCompile()`这个函数了 这里要理解一下断点是段在`compCompile(){}`这个函数的左括号这个地方 也就意思是到这里的时候函数的参数都已经压栈了 但是并没有执行一行函数里面的代码 理解了这点就好了
