
![](https://bbs.kanxue.com/upload/attach/201306/546812_ly53huq4o3xyj7h.jpg)

```
004D36F7    8B46 0C         MOV EAX,DWORD PTR DS:[ESI+C]
```

此处`ESI`便是第一个`IID`的`VA`，去看看（图17）：

![](https://bbs.kanxue.com/upload/attach/201306/546812_ohiq3cdkp164yz6.jpg)

好了，就是这里`F8`跟一下发现：

```
004D3702    C746 0C 0000000>MOV DWORD PTR DS:[ESI+C],0
```

此处会将模块名称`RVA`填0，为了保持`IID`的完整，需要`NOP`掉它。

重新断到`OEP`然后`DUMP`，之后用`LordPE`打开修改入口点和`IID`（图18）：

![](https://bbs.kanxue.com/upload/attach/201306/546812_4wn68x63vmlyah6.jpg)

这样就可以了，可此时壳段还在。

直接去掉壳段是否可行，要看是否还有依赖壳段的地方。这个壳有一些资源在壳段，那么要去掉壳段必须重建资源（图19）。

![](https://bbs.kanxue.com/upload/attach/201306/546812_no2pmt4bpg6gpt4.jpg)

下面用`DT FixResource`提取资源段（图20）：

![](https://bbs.kanxue.com/upload/attach/201306/546812_o8k2mc5b3jg894y.jpg)

用`PE Tools`将壳段和资源段填0（直接清空可能导致错误）（图21）：

![](https://bbs.kanxue.com/upload/attach/201306/546812_rtpqvchtigqva19.jpg)

最后用`LordPE`清除壳段和资源段并载入之前提取的资源段并重建使`PE`有效（图22）：

![](https://bbs.kanxue.com/upload/attach/201306/546812_8t3mdfrdmegbrle.jpg)

这样便去掉壳段了。这个壳几乎没什么强度可言，这里主要演示了几种常用工具的使用。
