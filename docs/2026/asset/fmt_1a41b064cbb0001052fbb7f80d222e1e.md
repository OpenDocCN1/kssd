
# [原创].Net 反射脱壳机核心源代码

摘要: 入口函数

`void DumpAssembly(Assembly ass,string path)`

枚举所有`type`，调用

`void DumpType(Type tp, BinaryWriter sw)`

枚举所有方法，调用

`void DumpMethod(MethodBase mb, BinaryWriter sw)`

```
{
MethodBody mbd = mb.GetMethodBody();
if (mbd == null)
return;

SetOffset(sw, mb.MetadataToken);
WriteHeader(sw, mbd);
WriteILCode(sw, mbd);
WriteSEH(sw, mbd);
}
```
