## 漏洞分析与利用

1. 控制地址写的位置的主要是：`file->f_pos`（以下简称`llseek`）、以及 `*(mydata+0x10000)` 处存储的值。

2. 通过多次的 `write` 配合 `lseek`，可以实现将 `*(mydata+0x10008)` 一直增大，配合`lseek`，触发在`write` 函数中的一个溢出，可以实现对于 `*(mydata+0x10000)` 和 `*(mydata+0x10008)` 这两个关键位置的劫持。

![](https://bbs.kanxue.com/upload/attach/202011/876323_R7VKVSFEJ8XKN3X.jpg)

3. 劫持 `*(mydata+0x10000)` 和 `*(mydata+0x10008)` 后，配合`read`函数进行任意地址读，爆破 `file` 结构体的地址，读取`0x98`大小，最后8个字节即为 `file->f_cred` 指向当前进程的 `cred` 结构体。

4. 通过计算偏移，重新设置 `lseek` 和 `*(mydata+0x10000)` ，配合`write`函数做任意地址写，目标地址为我们爆破出的 `cred` 结构体的地址。

5. 将当前进程的`cred`结构体前`0x28`写成全0，达到提权的目的。
