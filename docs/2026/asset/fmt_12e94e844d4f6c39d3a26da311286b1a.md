
# [分享]关于某知名游戏公司被挂马的文件分析

来自某推的消息，某知名游戏公司网站被人恶意挂马钓鱼。

![](https://bbs.kanxue.com/upload/tmp/828999_WKCS8RUM3363VMD.jpg)

样本地址：`xxxxxxx.xxxx.com/uploads/***%E7%99%BB%E5%BD%95%E6%8E%A7%E4%BB%B6.exe`

样本伪装成 openvxx 的安装包，乘机释放后门。

![](https://bbs.kanxue.com/upload/attach/202307/828999_JDCZ8Y87FR8J5K6.jpg)

## 外壳分析

![](https://bbs.kanxue.com/upload/attach/202307/828999_U6E9MVZ8ZAAE5WZ.jpg)

逻辑十分清晰，首先使用 `AES128` 循环解密 `shellcode`，然后利用 `CreateTimerQueueTimer` 的 `CallBack` 参数来跳进 `shellcode`。

我这边选择了修改外壳 exe 然后进行内存 dump（可以看到后面跳转进 `shellcode` 的代码已经被我 `nop` 掉并修改成死循环了）。

![](https://bbs.kanxue.com/upload/attach/202307/828999_KGF4FUGB7C8NYAG.jpg)

然后我们使用工具修复导入表，再来看看 `shellcode`。

![](https://bbs.kanxue.com/upload/attach/202307/828999_TDFS3T8BPVQXAPS.jpg)

这边我发现这其实是一个 dll，这块动态计算地址 `call` 到 `dllmain` 里去了。

给 dll 分离出来以后，很明显就能看出来这是一个远控。

![](https://bbs.kanxue.com/upload/attach/202307/828999_S7EQMWJ8HXN6R2B.jpg)

这个 dll 使用 `winsocket` 和 c&c 服务器通信，使用 `xor` 加密。

![](https://bbs.kanxue.com/upload/attach/202307/828999_DEMFWNSA2QWWC78.jpg)

这边是下发指令执行部分（一个巨大的 `switch`）。

大概看了一下，功能有 `ping`、创建文件、读取文件、`powershell` 启动程序等等。

![](https://bbs.kanxue.com/upload/attach/202307/828999_Y42VWGQQR45KUWT.jpg)
