## 算法注册机

**VB代码**

```vb
Private Sub Command1_Click()
    If Len(Text1.Text) = 0 Then
        Text2.Text = "输入有误，请重新输入！"
    Else
        For I = 1 To 20
            J = ((I - 1) Mod Len(Text1.Text)) + 1
            X = Asc(Mid(Text1.Text, J, 1)) Xor Asc(Mid("How DARE you crack my software!", I, 1))
            Y = Y & Right(X, 1)
        Next
        Text2.Text = Y
    End If
End Sub
```
