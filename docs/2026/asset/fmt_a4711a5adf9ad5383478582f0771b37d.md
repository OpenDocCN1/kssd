
# [分享]Windows驱动中校验数字签名(使用`ci.dll`)

## 1. 背景

对于常规应用程序来说，校验数字签名在在应用层可以使用`WinVerifyTrust`, 在驱动层使用常规的 API无法使用，自己分析数据又太麻烦。

但在内核中`ci.dll`包装了数据签名验证相关的功能，我们可以使用该 dll 来实现我们的数字签名验证。
