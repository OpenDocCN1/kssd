根据 wp 看有几步是必须的

- `qemu-user` 的安装

  ```bash
  sudo apt install qemu-user
  which qemu-hexagon ##查看一下有没有
  ```

> 这里笔者的 Ubuntu 的版本是 22.04，但是在 20.04 的版本下载之后是找不到 `qemu-hexagon`
>
> 这块只能自己手动编译
>
> ![image-20250213144949614](upload/attach/202503/1011755_GNGVAVUDGM9MM64.png)
>
> ```bash
> sudo apt update
> sudo apt install build-essential pkg-config libglib2.0-dev libpixman-1-dev
>
> git clone <mark class="encrypted">8a2K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8D9j5h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6I4k6h3#2#2i4K6u0V1M7s2u0G2K9X3g2U0N6q4)9J5c8Y4q4W2L8i4g2Q4x3X3g2Y4K9i4b7`.</mark>
> cd qemu
>
> ./configure --target-list=hexagon-linux-user
>
> make -j$(nproc)
>
> sudo make install
> ```
>
> 安装完之后可以自己查看一下是否安装成功了
>
> **注意：** 这里安装的时候不会直接安装成功，可能会报错，拷打一下 GPT，安装一下相应的包即可
