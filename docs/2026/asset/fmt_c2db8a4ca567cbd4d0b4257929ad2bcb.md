
# [原创]一个连接到Oracle的学生成绩管理系统

这是利用`JSE`写的使用`Oracle`的小小学生成绩管理系统，是用来交任务的，能实现简单的增删改成功能，含有权限分配，普通用户只能查询，管理员用`sys`和`orcl`登录，拥有所有权限，利用经典三层架构和`DAO`设计模式，附件含有源代码和已经封装好的Jar文件，需要`Oracle`数据库，才能登录系统![](https://bbs.kanxue.com/view/img/face/1.gif)
