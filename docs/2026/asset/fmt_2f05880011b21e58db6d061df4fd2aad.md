# 5、目标3：让PVZ回调DLL的导出函数

在目标2中我们实现了对PVZ的汇编指令修改，但是这种方法只能实现小幅度修改，一些很复杂的功能召唤特定数量、特定种类的僵尸可能需要很多条汇编指令才能实现。这时就需要PVZ主动调用我们DLL的导出函数，来实现一些复杂的功能，我把这个过程称之为**回调**。

要调用导出函数，首先得有导出函数，我们写一个测试的导出函数出来：

```
#define DLL_EXPORT extern "C" __declspec(dllexport)
DLL_EXPORT void CALL_BACK() {
    MessageBox(NULL, L"call back", L"call back", MB_OK);
}
```

调用这个函数时会弹出一个对话框，我们可以把游戏暂停的窗口替换成这个对话框。

这是原效果：

![](https://bbs.kanxue.com/upload/attach/202012/910514_9TXNMD4KYADXY3D.png)

通过一些方法我们找到了打开游戏暂停窗口的地址：

![](https://bbs.kanxue.com/upload/attach/202012/910514_2YQQACY3EEKVMNX.png)

这一块有8个字节，我们调用导出函数只需要5个字节，完美。

```
DLL_EXPORT void CALL_BACK() {
    MessageBox(NULL, L"call back", L"call back", MB_OK);
}

void TestCallBack() {
    WriteBytes(0x0044F475, 3, 0x90, 0x90, 0x90); // 把前三个字节nop掉
    WriteCall(0x0044F475 + 3, (DWORD)CALL_BACK); // 写call指令
}
```

`CALL_BACK` 是函数指针，在DLL加载时已经被重定位了，因此指针的值就是函数的真实地址。

其中 `WriteCall` 的实现：

```
void WriteCall(DWORD address, DWORD func) {
    DWORD rel32 = func - (address + 5);
    WriteByte(address, 0xE8);
    WriteDword(address + 1, rel32);
}
```

`E8` 是 `call` 指令的机器码，后面接4字节的偏移量。
