
# [原创]超级Flv视频转换器算法分析

## 软件介绍
《超级FLV视频转换器》是一款功能强大的FLV视频转换工具，它可以帮助您将几乎所有流行的视频格式，如：RM、RMVB、VOB、DAT、VCD、DVD、VCD、ASF、MOV、QT、MPEG、WMV、MP4、3GP、DivX、XviD、AVI、FLV、MKV等视频文件转换为FLV/SWF网络视频格式。也可以把FLV视频文件转换成AVI、VCD、SVCD、DVD等视频格式。

具有转换简单、快速、高画质等特点，还可以支持批量添加文件转换。

## 分析步骤

1. 运行软件试注册一下发现有提示框~~~~
2. `peid`查是没有壳的。
2. 可以`F12`暂停法，`Alt+k`调用堆，调用堆栈。在堆栈中可以看到调用来自=`flv.004BCD1A`。双击可以到注册提示。
3. 找到段首下断运行软件。断下来了
