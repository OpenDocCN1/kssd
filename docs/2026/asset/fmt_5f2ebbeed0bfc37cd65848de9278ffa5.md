
# IAMixSetup: 1.34 (701字)

Happy New Year!

IAMixSetup: 1.34

很专业的多媒体制作工具，内容非常丰富，既可用于录制（从CD或麦克风）声音，也可以用于MP3或RealAudio的制作，并且有多种混音频效果，是制作音效的好工具。

类型：注册码

## 大致过程

设断点：`bpx hmemcpy`

中断後，按几次F10，可找到存放输入的注册码的地址`********`。

设断点：`bpx ********`

第二次中断後，可找到计算注册码的过程（实际上是将输入的注册码转为十六进制）。

可发现注册码形式为：`mmmmmmm-nnnnnnn`

软件判断注册码时分3步：

1. 判断`mmmmmmm`和`nnnnnnn`转为十六进制後是否大于`F4240`（即十进制的`1000000`）
2. 判断`mmmmmmm`转为十六进制後是否能除尽`12794`（即十进制的`76148`）
3. 判断`nnnnnnn`转为十六进制後是否能除尽`147BD`（即十进制的`83901`）

若以上条件满足，呵呵..注册成功！

给一个注册码：`87570200-41950500`
