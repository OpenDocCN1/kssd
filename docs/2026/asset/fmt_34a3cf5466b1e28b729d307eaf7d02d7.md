
# DirectDraw 结构体与虚表定义

## 表面描述结构体

```asm
ddckCKSrcOverlay        DDCOLORKEY                <>

ddckCKSrcBlt                DDCOLORKEY                <>

ddpfPixelFormat                DDPIXELFORMAT        <>

ddsCaps                                DDSCAPS                        <>

DDSURFACEDESC        ENDS
```

        lprSrc                        LPRECT                ?

        dwFlags                        DWORD                ?
