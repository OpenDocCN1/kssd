
Python利用`pefile`模块查询导出函数，是不是很懵逼？就两行代码？

```
import pefile

# 通过pefile模块读取PE文件
pe = pefile.PE('notepad.exe')

for exp in pe.DIRECTORY_ENTRY_EXPORT.symbols:
    print hex(pe.OPTIONAL_HEADER.ImageBase + exp.address), exp.name, exp.ordinal
```
