## 算法总结

1. 总的来说这个软件很间单~~~。因为我要这么个软件。
2. 软件第一是进行一个检查我们输入的是不是作者给定的用户名。如果不是就提示出错.
3. 作者把用户名的`ACSSII`进行一个自加。
3. 用户名自加后乘上`0X0CE53C`在加上`0X20`最后把结果算术右移1位。
4. 作用把我们输入注册码转化16进制数.
5. 就是把用户名运算出来的结果与我们输入注册码转化16进制数进行比较~~~相同就注册成功。
不相同就提示注册不成功.
6. 下面的`C++`代码就是我写的一个算法注册机~~~~~~~~~~~呵呵就多指教！！！！

## 注册机 C++ 代码

```cpp
#include <iostream>

using namespace std;

void main()

{

  char a[20];

  cout<<"请输入软件给定的用户名"<<endl;

  cin>>a;

  int i,b,c=0;

  b=strlen(a);

  for(i=0;i<b;i++)

  {

    c=c+a[i];

  }

  c=c*0X0CE53C;

  c=c+0X20;

  c=c>>1;

  cout<<c<<endl;

}
```
