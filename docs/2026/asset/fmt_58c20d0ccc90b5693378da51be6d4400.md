## 3. 计算函数 C 伪码

```c
short CalcNum(int a1, char *pszName, int nNameLen)
{
    unsigned short* psTable=(unsigned short*)g_szTable;
    int v5=0;
    char *pBuf=pszName;
    int nTemp=a1;
    for(int i=0;i<nNameLen;i++)    
    {
        v5=(*pBuf)^nTemp;
        nTemp=psTable[LOBYTE(v5)]^(nTemp>>8);
        pBuf++;
    }
    return nTemp;
}
```

算法就是根据传入的字符串和字符串长度进行某些运算后查表然后得到一个值。

## 4. 注册码校验逻辑

程序会根据用户输入的用户名通过`CalcNum`计算出一个值，然后调用`sprintf`之类的函数把值转成字符串，然后用这个字符串的前两位与用户输入的注册的3,4位分别比较，相等则继续，不相等则结束。

接着程序根据用户输入注册码的第2-最后这个字符串通过`CalcNum`计算出一个值，然后调用`sprintf`之类的函数把值转成字符串，然后用这个字符串的前两位与用户输入的注册的1,2位分别比较，相等则继续，不相等则结束。

说的可能有点绕，举个例子可能就清楚了。

假如用户名是`test` ,注册码输入的是`12345678`

用户名是`test`用`calcNum`函数算出来并转成字符串是“`F82E`”，程序接着就会拿`F8`跟`23`这两位比较，不相等就结束了。

假如他们相等了，就用`345678`这一串调用`calcNum`函数算出来并转成字符串，然后跟`12`比较是否相等。
