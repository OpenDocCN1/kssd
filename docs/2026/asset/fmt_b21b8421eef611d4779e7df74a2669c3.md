
如果终止的是当前的进程，则还会调用函数来关闭当前的线程，此时函数调用以后不会返回

```

PAGE:004B79B3                 push    edi             ; Response

PAGE:004B79B4                 call    _PspTerminateThreadByPointer@8
```

可以得出结论，所谓进程的销毁就是通过关闭进程中的所有线程来实现的。
