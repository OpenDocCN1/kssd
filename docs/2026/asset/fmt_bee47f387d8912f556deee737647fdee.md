### 触发回调

为了理解`PsSetLoadImageNotifyRoutine`的工作原理，我们需要确定它的触发条件。

假设以下代码：

```c
#include <windows.h>
#include <stdio.h>
int main()
{
HMODULE hModule = LoadLibraryA("winhttp.dll");
printf("WinHTTP: 0x%p\n", hModule);
return 0;
}
```

当调用`LoadLibraryA`时，该函数会注册一个回调函数来通知驱动程序发生了这个事件。为了在HELK中查看这个日志，我们使用[之前提到的脚本](https://bbs.kanxue.com/elink@75dK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4k6h3u0Q4x3X3g2S2M7X3y4Z5K9i4k6W2i4K6u0W2L8%4u0Y4i4K6u0r3N6$3g2T1i4K6u0r3x3U0l9J5x3U0p5I4x3U0j5I4z5o6t1#2x3K6y4Q4x3V1k6Z5N6s2c8H3M7#2)9K6b7g2)9J5c8W2)9J5c8Y4m8J5k6g2)9J5k6h3g2E0M7s2c8Q4x3X3g2V1k6i4k6Q4x3V1k6H3L8%4y4@1M7#2)9J5c8X3#2S2k6h3I4K6N6s2u0G2L8g2)9J5k6r3g2V1M7W2)9J5k6r3E0W2M7X3&6W2L8q4)9J5k6r3y4S2L8r3I4T1j5h3y4C8M7#2)9J5k6r3S2G2L8$3E0K6i4K6u0V1j5h3&6V1i4K6u0V1j5$3q4D9L8s2y4@1j5h3y4C8M7#2)9J5c8W2)9J5x3@1S2#2L8Y4c8A6L8X3N6Q4y4h3k6q4e0p5D9.)。
