
程序的虚拟地址空间如下。ELF文件被映射到图中`0x7ffff7fc9000`的区域，那么后面的内容，构造一下`gashtab`都是可以越界读的。

![image-20181226160535160](upload/attach/201901/730610\_VSREKJAJP5AUTWZ.png)

在源码中，越界读之后的数据还是保存在局部变量中的，读了之后也并不能输出，更不用说越界写和控制PC寄存器了。所以只算是一个DoS吧。

### 0x01 AFL下载和安装

AFL可以对有源码和无源码的程序进行fuzz。对有源码的程序Fuzz的原理，简单来说即是在程序编译时，向汇编代码中插入自己的指令，从而在程序运行时，计算覆盖率。当把样本喂给程序来Fuzz时，如果AFL发现程序执行了新的路径，就把当前的样本保存在Queue中，基于这个新的样本来继续Fuzz。

下载和安装AFL：

```
wget ac5K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8X3I4U0j5h3#2@1N6h3k6Q4x3X3g2U0L8%4u0W2k6s2g2E0M7q4)9J5k6h3y4^5i4K6u0r3j5h3k6D9i4K6u0r3M7X3g2D9k6h3q4K6k6i4y4Q4x3V1k6S2k6X3I4Q4x3X3c8D9j5i4c8W2M7%4c8Q4x3X3g2@1k6%4Z5`.

tar xvf afl-latest.tgz

cd afl-2.52b

# make && make install

sudo make && sudo make install

```

安装完成后，默认在`/usr/local/bin/`目录下，修改`.bashrc`加入环境变量`export PATH=/usr/local/bin:$PATH`后即可使用。
