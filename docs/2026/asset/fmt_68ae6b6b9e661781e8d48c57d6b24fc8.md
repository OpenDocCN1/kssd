
# 【经验总结】

加密算法主要是这个问题，当`e`=0时，`f(e,C)`=`2`，当`e`=1时，`f(e,C)`=`C MOD N`，当`e`>`1`时，如果`e`是奇数，`f(e,C)`=`(f(e/2,C)*f((e+1)/2,C)-C) MOD N`，否则`f(e,C)`=`(f(e/2,C)*f(e/2,C)-2) MOD N`，已知`N`,`f(e,C)`,`e`=65537，求`C`，非常像某个算式的反复平方计算，要想求`C`应该要分解`N`，知道`N`的分解后除了求多项式的根还有什么办法，这个计算量太大了，WinNTL提供的那些求多项式根的方法实在太慢了。
