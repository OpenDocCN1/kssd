# 漏洞总结

由于eps软件应该是使用了将char强制转化为int，而且将这个int参数传入`qmemcpy`的第3个参数，而`qmemcpy`会把它当做无符号数对待，导致最后复制长度过程，超越的栈顶，使攻击者可以覆盖SEH，导致任意代码执行漏洞
