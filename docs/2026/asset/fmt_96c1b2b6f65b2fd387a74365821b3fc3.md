# 四、注册机

通过上述的注册函数的逆向，我们已经知道了 `si.lic` 文件是如何生成的了。我们可以按照 `si.lic` 的检验规则写出生成 `si.lic` 的注册机。然后通过注册机生成的 `si.lic` 文件实现离线注册。

1. 按照序列号校验算法，编写序列号生成器。将生成的序列号填写 `Serial` 字段。
