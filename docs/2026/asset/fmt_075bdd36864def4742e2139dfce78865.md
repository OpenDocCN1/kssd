
# Armadillo V4.X CopyMem-II脱壳[原创]

Armadillo V4.X CopyMem-II脱壳

在ARM壳里,最麻烦的就是这种壳了,昨晚搞了带KEY的壳,把KEY的变成正常的ARM双进程的壳,没想到看了之后竟然是CopyMem-II的

所以单独发表这个CopyMem-II的脱壳教程

设置OllyDbg忽略所有其它异常选项。用IsDebug插件去掉OllyDbg的调试器标志。
