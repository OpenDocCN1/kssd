可以看出其种有译文中最重要的两个Section，`.debug_line`和`.debug_info`

- `gcc -gdwarf-2 <源码>` 编译生成 DWARF 2 版本调试格式的信息

  与上面的命令类似，只是格式版本略有不同

使用 `dwarfdump` 可以查看生成的可执行文件的调试信息

- `dwarfdump -a <程序>` 查看程序中所有debug开头的调试信息

  由于信息量比较大，就不贴图了

- `dwarfdump -l <程序>` 查看程序中调试信息的debugline信息

  ![图片描述](https://bbs.kanxue.com/upload/attach/201710/761040_d7l601uf4gebm6e.png)

- `dwarfdump -i <程序>` 查看程序中调试信息的debuginfo信息

  ![图片描述](https://bbs.kanxue.com/upload/attach/201710/761040_b3jbabh9bw8f4yb.png)

- `dwarfdump -p <程序>` 查看程序中调试信息的debug_pubnames信息

  ![图片描述](https://bbs.kanxue.com/upload/attach/201710/761040_dr4lhpq0mkz964i.png)
