## 将pass注册到clang

### 以编写ObfString为例

先创建`ObfPass`文件夹并编写`ObfString.h`，路径为`llvm/include/llvm/Transforms/ObfPass/ObfString.h`，内容如下：

```cpp
#ifndef LLVM_OBFSTRING_H
#define LLVM_OBFSTRING_H

namespace llvm{
Pass* createObfString(bool flag);
}

#endif //LLVM_OBFSTRING_H
```

编写`ObfString.cpp`，路径为`llvm/lib/Transforms/ObfPass/ObfString.cpp`，内容如下：

```cpp
#include <llvm/IR/Constants.h>
#include <llvm/IR/Instructions.h>
#include <llvm/IR/IRBuilder.h>
#include "llvm/Pass.h"
#include "llvm/Support/raw_ostream.h"
#include "llvm/IR/Module.h"

#include "llvm/IR/LegacyPassManager.h"
#include "llvm/Transforms/IPO/PassManagerBuilder.h"
#include "llvm/Transforms/ObfPass/ObfString.h"
#include "llvm/CryptoUtils.h"

using namespace llvm;
namespace {
struct ObfString : public ModulePass {
static char ID;
bool flag;

ObfString() : ModulePass(ID) {};

ObfString(bool flag) : ModulePass(ID) {
this->flag = flag;
};

bool runOnModule(Module &M) override {
return false;
};
};
}

char ObfString::ID = 0;
static RegisterPass<ObfString> X("obfstr", "String encrypt Pass",
false /* Only looks at CFG */,
false /* Analysis Pass */);

Pass *llvm::createObfString(bool flag) {
return new ObfString(flag);
}
```

在同文件夹下编写`CMakeLists.txt`与`LLVMBuild.txt`。

`CMakeLists.txt` 内容如下：

```cmake
add_llvm_library(LLVMObfPass
  CryptoUtils.cpp
  ObfString.cpp
)

add_dependencies(LLVMObfPass intrinsics_gen)
```

`LLVMBuild.txt` 内容如下：

```text
[component_0]
type = Library
name = ObfPass
parent = Transforms
library_name = ObfPass
```

然后在以下文件中添加配置：

- 在`llvm/lib/Transforms/CMakeLists.txt`中添加`add_subdirectory(ObfPass)`
- 在`llvm/lib/Transforms/LLVMBuild.txt`中添加`ObfPass`
- 在`llvm/lib/Transforms/IPO/LLVMBuild.txt`中添加`ObfPass`

在`llvm/lib/Transforms/IPO/PassManagerBuilder.cpp`中添加：

```cpp
#include "llvm/Transforms/ObfPass/ObfString.h"
......
static cl::opt<bool> ObfString("obfstr", cl::init(false),
cl::desc("Enable string obf"));
......
void PassManagerBuilder::populateModulePassManager(
    MPM.add(createObfString(ObfString));
```

对于CLion，在`Preferences -> Build, Execution, Deployment -> CMake -> Debug`的`CMake options`中填写：

```
-G Ninja -DLLVM_ENABLE_PROJECTS="clang"
```

编译通过。
