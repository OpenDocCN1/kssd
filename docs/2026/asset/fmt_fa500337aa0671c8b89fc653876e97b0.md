# 二、shellcode分析

成功加载Loader驱动后，System进程的CPU占有直接飙升至99%。

![image16.png](https://bbs.kanxue.com/./upload/attach/202404/910874_RXU322G9RP2VN55.png)

说明Shellcode应当是启动了。而Loader想在内核跑shellcode必然要写到可执行内存并获得执行时机。可执行内存的获取方式一般为：

`ExAllocatePool`/`ExAllocatePoolWithTag`/`MmAllocateIndenpendentPages`/`MmAllocateContiguousMemory`....

执行时机：`PsCreateSystemThread`/`WorkItem`/`APC`/`DPC`/`Timer`/...

延续初赛的解题代码，直接用`DetoursX`挂钩`PsCreateSystemThread`、`ExAllocatePoolWithTag`

![image17.png](https://bbs.kanxue.com/./upload/attach/202404/910874_Q7Y9MURKKCD7EZ8.png)

BSOD，看调用栈是`PsCreateSystemThread`后的双重错误。而`ExAllocatePoolWithTag`直接执行到了挂钩后面的`int3`上去了。

![image18.png](https://bbs.kanxue.com/./upload/attach/202404/910874_4B9GHR8UVR2ESTT.png)![image19.png](https://bbs.kanxue.com/./upload/attach/202404/910874_YHC9B6VGZXK67BV.png)

找到规律：
