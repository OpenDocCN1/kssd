然后再来实现第二种方法，hook 这两个函数，让它们主动执行一下。因为从刚刚的 Objection 分析中我们可以发现，那两个函数并没有被调用，所以我们要 hook 它，让它主动执行一下：

```javascript
function hook_java() {
    Java.perform(function () {
        // private static void setStatic_bool_var()
        // 这个函数是静态函数，所以可以直接 hook 调用
        Java.use("com.example.androiddemo.Activity.FridaActivity2")
            .setStatic_bool_var();

        // private void setBool_var()
        // 这个函数不是 static 修饰的，所以要通过主动调用的方式
        Java.choose("com.example.androiddemo.Activity.FridaActivity2", {
            onMatch: function (instance) {
                console.log("found instance", instance);
                instance.setBool_var(); // 调用函数，执行函数
            },
            onComplete: function () {
                console.log("instance, completed!");
            }
        });
    });
}

function main() {
    hook_java(); // 在 main 函数中调用 hook_java 函数
}

setImmediate(main);
```

通过这两种方法我们都可以实现通关。
