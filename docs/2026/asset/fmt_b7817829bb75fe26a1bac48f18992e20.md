
# 【破解总结】

## 【算法总结】

注册码长度为16，只能为0-9的数字，除此之外还得满足以下条件

将注册码每4个数字为一组，分为四组

1. 后3组的16进制的和大于等于`32h`
2. 第2组: 注册码第5-8位重新排序,为第6位第7位第5位第8位，重新排序数字的16进制必须是`17h`的倍数
3. 第3组: 注册码第9-12位重新排序,为第11位第12位第9位第10位，重新排序数字的16进制必须是`13h`的倍数
4. 第4组: 将注册码第13-16位重新排序,为第16位第15位第14位第13位，重新排序数字的16进制必须是`1Fh`的倍数
