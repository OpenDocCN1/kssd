**2.线性地址**

intel规定48位都是有效的，但微软只用了44位

- 0~47：48位是线性地址
- 48~63：16位是符号位。这16个位要么全是1要么全是0，否则为非法

**3.全局变量地址**

```
正确地址=(当前行地址+7) + (ULONG*)(当前地址+3)
```

实例

```
000000013F6017DE 48 8D 15 1B A8 00 00 lea         rdx,[x (013F60C000h)]  									

000000013F6017E5 48 8D 0D 38 84 00 00 lea         rcx,[string "%p\r\n" (013F609C24h)]
```

`000000013F6017E5` + `a81b` = `013F60C000h`

### 9.2.X64汇编

**1.在汇编里面调用c代码**

main.cpp
```
#include <stdio.h>
#include <Windows.h>
#include "1.h"

EXTERN_C int test1(int x, int y)
{
	return x + y;
}

int main()
{
	ULONG64 z = add1(1, 2);
	printf("%lld\r\n",z);

	printf("%d\r\n",test2());
	return 0;
}
```

1.h
```
#pragma once
#include <Windows.h>

EXTERN_C ULONG64 add1(ULONG64 x, ULONG64 y);

EXTERN_C int test2();
```

1.asm
```
.code

extern test1:proc

add1 proc

 add rcx,rdx
 mov rax,rcx
 ret

add1 endp

test2 proc

 mov rcx,0ch
 mov rdx,3
 sub rsp,48h    ;提升堆栈
 call test1
 add rsp,48h    ;还原堆栈
 ret

test2 endp

end
```

**2.函数参数**

- 函数有四个参数：`rcx`, `rdx`, `r8`, `r9`
- 函数有六个参数：`rcx`, `rdx`, `r8`, `r9`，`RSP+20H`, `RSP+28H`

callgateRet proc
	swapgs

### 9.5.X64分页

![](https://bbs.kanxue.com/upload/attach/202208/939298_EA5R4P4CHY5YDND.jpg)

**1.win7x64分页**

PTE基址：`FFFFF68000000000` （固定的）

&的数：`0x7FFFFFFFF8` （固定的）

**2.线性地址**

`fffff800`03ea3400
```
fffff800`03ea3400  cc              int     3

kd> !pte fffff800`03ea3400
                                           VA fffff80003ea3400
PXE at FFFFF6FB7DBEDF80    PPE at FFFFF6FB7DBF0000    PDE at FFFFF6FB7E0000F8    PTE at FFFFF6FC0001F518
contains 0000000000199063  contains 0000000000198063  contains 00000000001E3063  contains 0000000003EA3121
pfn 199       ---DA--KWEV  pfn 198       ---DA--KWEV  pfn 1e3       ---DA--KWEV  pfn 3ea3      -G--A--KREV
```

**3.算法**

先求出pte，然后用pte依次求出其它
```
//PTE = 线性地址 >> 9 & 7FFFFFFFF8 + pte基址

PTE = fffff800`03ea3400 >> 9 & 7FFFFFFFF8 + FFFFF68000000000 = FFFFF6FC0001F518

PDE = FFFFF6FC0001F518 >> 9 & 7FFFFFFFF8 + FFFFF68000000000 = FFFFF6FB7E0000F8 

PPE = FFFFF6FB7E0000F8  >> 9 & 7FFFFFFFF8 + FFFFF68000000000 = FFFFF6FB7DBF0000

PXE = FFFFF6FB7DBF0000 >> 9 & 7FFFFFFFF8 + FFFFF68000000000 = FFFFF6FB7DBEDF80
```

**4.win10的pte基址是动态的**

每次开机都会变化，所以要用函数获得
