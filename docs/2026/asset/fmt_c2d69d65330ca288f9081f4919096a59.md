## 二、算法还原

（1）输入注册码共70字节（实际只包含‘0’-‘9’、‘A’-‘F’）。

（2）前6字节转化为RSA中的`E`（24位，当然说是`D`也可以，`E`、`D`地位均等）。

（3）后64字节转化为RSA中的`P`（256位，当然说是`Q`也可以，`P`、`Q`地位均等）。

（4）对`E`和`P`进行素性检测。

（5）初始化RSA中的`N`（512位，无法直接分解，256位还可以）和`D`（与`E`互逆）。

                。。。。。。。。。。见附件

## 二、逆向过程

(1)由于`E`为素数且范围较小考虑对`E`进行枚举。

   1、用C语言，素数筛法求0xFFFFFF以内的素数，并存入文件。

```
#include <stdio.h>

char bb[0x1000000] = {0};

int main(){

      int xx = 0x1000;

      int i,j,sum;

      FILE *out;

      out = fopen("uu.txt", "wt");

      for(i=2;i<=xx;i++){

           if(bb[i]==0){

                 for(j=i+i;j<0x1000000;j=j+i){

                      bb[j]=1;

                 }

           }

      }

      sum = 0;

      for(i=2;i<0x1000000;i++){

           if(bb[i]==0) {fprintf(out,"%d\n",i);sum++;}

      }

      fclose(out);

      printf("\n%d\n",sum);

      return 0;

}
```
