# This file describes the network interfaces available on your system

 source /etc/network/interfaces.d/*

# The loopback network interface
auto lo
iface lo inet loopback
auto eth0
#inface eth0 inet dhcp

netmask 255.255.255.0

# 五、报错处理

## 5.1 WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!

```
~❯ ssh root@192.168.66.172

@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
@    WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!     @
@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@

IT IS POSSIBLE THAT SOMEONE IS DOING SOMETHING NASTY!

Someone could be eavesdropping on you right now (man-in-the-middle attack)!

It is also possible that a host key has just been changed.

The fingerprint for the ECDSA key sent by the remote host is

SHA256:/SBh0scHmmvKnRLe21DohevG3c91KKCrXo4eKb/446g.

Please contact your system administrator.

Add correct host key in /Users/wsc/.ssh/known_hosts to get rid of this message.  （根据这个路径找文件编辑即可）

Offending ECDSA key in /Users/wsc/.ssh/known_hosts:4

ECDSA host key for 192.168.66.172 has changed and you have requested strict checking.

Host key verification failed.
```

简单的讲，就是你的机器以前连过这个ip ，写入过key，如今你想连同样是这个ip，主机变了，但这个key已经变了，你这个是以前的认证，新的认证不接受你。所以，你得在你本机删掉这个key。然后把第四行的key删掉。这样就可以从新写入了。

```
vim /Users/wsc/.ssh/known_hosts
```

## 5.2 安装 firmware-b43-installer 软件包 post-installation 脚本 子进程返回错误状态 123 在处理时有错误发生： firmware-b43-installer

```
root@kali:~# vim /var/lib/dpkg/status
```

在这个文件中 找到相关的包 然后从`package`处删到它结束。 有多少错误就删多少错误的包 。这样更新软件的时候就不报错了
