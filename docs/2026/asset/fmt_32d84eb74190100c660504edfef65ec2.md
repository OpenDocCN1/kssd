```
FAB6D6CF      LEA     EAX,[EBP-24]

FAB6D6D3      PUSH   +1A          //过滤函数索引
FAB6D6D5      CALL    [EBP+08]    //出口参数检查
FAB6D6D8      MOV    [EBP+10],EAX

FAB6D6E0      JL       FAB6D6EB

FAB6D6ED      RET     0014
```

该函数首先检查传入的用户态参数，如果无需拦截则执行原始服务例程序，并根据返回的相关参数决定是否对出口参数做检查。
