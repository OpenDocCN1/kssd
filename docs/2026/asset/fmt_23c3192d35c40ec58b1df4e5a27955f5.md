漏洞在windows的NTFS文件系统驱动上（`C:\Windows\System32\drivers\ntfs.sys`）的`NtfsQueryEaUserEaList`函数中

NTFS文件系统允许为每一个文件额外存储若干个键值对属性，称之为EA(Extend Attribution)。可以通过`ZwSetEaFile`为文件创建EA，`ZwQueryEaFile`查询文件EA

```typedef struct _FILE_GET_EA_INFORMATION {
ULONG NextEntryOffset;
UCHAR EaNameLength;
CHAR EaName[1];
} FILE_GET_EA_INFORMATION, *PFILE_GET_EA_INFORMATION;
typedef struct _FILE_FULL_EA_INFORMATION {
ULONG NextEntryOffset;
UCHAR Flags;
UCHAR EaNameLength;
USHORT EaValueLength;
CHAR EaName[1];
} FILE_FULL_EA_INFORMATION, *PFILE_FULL_EA_INFORMATION;
```
