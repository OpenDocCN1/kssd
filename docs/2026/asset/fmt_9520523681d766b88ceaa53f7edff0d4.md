
# 关于C++编程的42条技巧（一）

文章作者是PVS的技术总监，他们这个项目主要是负责PVS-Studio静态代码分析器的。文中的42条建议都是他们在工作过程中发现的，算是一个总结吧。每一条建议都会用一段有bug的代码块来说明，先指出这个错误在PVS-Studio中会怎样报错。然后分析错误的原因，给出正确的代码，然后根据错误总结出经验教训，也就是他的建议。
