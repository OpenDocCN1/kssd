## unsortedbin

对于暂时未归类到 `smallbins` 或 `largebins` 的 chunk，暂时放到 `unsortedbin` 里，位于 `bin1` 位置，不需要按大小排序。

## __libc_malloc

函数原型：

```c
void *__libc_malloc (size_t bytes)
```

`bytes` 是程序实际申请的内存大小。

如果 [`__malloc_hook`](https://bbs.kanxue.com/elink@93bK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1L8h3W2F1L8%4u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5c8X3u0D9L8$3u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5k6o6u0Q4x3X3f1J5y4#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5k6h3S2Q4x3U0y4x3x3e0b7$3) 位置不是 null，则调用 [`__malloc_hook`](https://bbs.kanxue.com/elink@91bK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1L8h3W2F1L8%4u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5c8X3u0D9L8$3u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5k6o6u0Q4x3X3f1J5y4#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5k6h3S2Q4x3U0y4x3x3e0b7$3) 返回。

根据所需 chunk 大小，在 `tcachebins` 中如果已有相同大小的 chunk，则将该 chunk 从 `tcache` 链表中取出后返回。
