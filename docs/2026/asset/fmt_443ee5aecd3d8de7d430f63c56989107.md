
# [原创]某锁机APP脱壳笔记。

分析锁机样本中发现加了壳，硬着头皮撸了一遍，样本所使用加固为腾讯乐固，壳版本为2.10.3.1。

使用乐固加固后会在`Lib`文件夹下生成如下文件。

![](https://bbs.kanxue.com/upload/attach/201708/693419_htukng1oxgplbxk.png)

加固的核心功能在`libshella-2.10.3.1.so`中，`libBugly.so`主要功能为监控程序异常数据，故不关注。

修复`so`后，直接将`so`，拖入`ida`，如下图所示，`JNI_OnLoad`函数被加密，`.init`与`.init_array`也无法显示。

![](https://bbs.kanxue.com/upload/attach/201708/693419_0o0dtmzjnl1yumn.png)

修复工具地址为：<http://bbs.pediy.com/thread-192874.htm>

直接动态挂上`IDA`，在`linker`的`.init_array`调用出下好断点。

![](https://bbs.kanxue.com/upload/attach/201708/693419_xw5m1ild79n96mk.png)

关于如何定位这里简单说一下，搜索字符串`[ Calling %s @ %p for '%s' ]`，`BLX  R4`就是调用出。

![](https://bbs.kanxue.com/upload/attach/201708/693419_55r7dp44290gp9z.png)

断点触发后运行到`init_array`位置。

![](https://bbs.kanxue.com/upload/attach/201708/693419_98wey3us6k9c25t.png)

看一下流程图，应该是被`llvm`混淆过。

来到函数尾部粗略看了看代码，调用了如下图中几个函数，在`mprotect_0`处断下后，代码解密完毕。

![](https://bbs.kanxue.com/upload/attach/201708/693419_2npligx8oacc8ze.png)
