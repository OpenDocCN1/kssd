
# [原创]win10 x64双机调试处理方法

下面是我处理的方法

1. `Hook KdpTrap` 过滤 `TASLogin.exe` 制造的 r3 异常，防止 `windbg` 一直弹

    `The context is partially valid. Only x86 user-mode context is available.`

2. `SharedUserData->KdDebuggerEnabled = FALSE;` //防止安全组件加载失败

3. `HideDriver("kdcom.dll");` //断链隐藏 `kdcom`，防止 `kdcom` 内存被清空导致和 `windbg` 通讯不了

4. `ba w1 KdDebuggerEnabled` 找到某P清零 `KdDebuggerEnabled` 的位置，让它清零其他地方去，防止 `windbg` 的 break 失效

在 win10 1607 下测试正常
