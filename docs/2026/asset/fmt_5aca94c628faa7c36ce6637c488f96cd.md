
# [原创]加快ODICE鼠标滚动速度

在使用ODICE时，滚动鼠标，感觉太慢了，每次只能滚动2行，想加快一点，但在OD的设置菜单中没有找到相应的设置，只有自己动手DIY了。

使用原版OD加载ODICE，让程序执行，使用OD在ODICE的`ICPUASM`窗口下`WM_MOUSEWHEEL`消息断点，然后在ODICE中滚动鼠标轮，可惜没有中断成功。

再查手册，知道MDI窗口是使用`WM_VSCROLL`消息来滚动的，所以使用OD在ODICE的`ICPUASM`窗口下`WM_VSCROLL`消息断点，中断成功
