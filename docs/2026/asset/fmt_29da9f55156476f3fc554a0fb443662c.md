## 结构体指针

这种指针通常情况下是指向结构体变量的首地址，用的时候小心点。这个容易发生缓冲区溢出错误。

### 答案

```c
typedef struct TagPlayer
{
    int id;
    int level;
}Player;

Player* f(char* p,int a,int b,int size)
{
    if(size==0)//遍历完所有的数据
        return 0;
    if(*(int*)p==1 && *(int*)(p+4)==8) //p是char 所以先+4个字节再用int*读数据
    {
        printf("%0x\n",p);
        f(++p,a,b,size--);
    }
    //printf("%0x %0x\n",*(int*)p,*(int*)(p+4));
    f(++p,a,b,size--);
}

{
    char a[]={
```
