```DWORD CheckOrCreateSectionName( PIMAGE_SECTION_HEADER  p_sect_header,DWORD flag)

{

CHAR  *p = p_section_header;

if( flag == 1 )

{

if( p[0] != ‘.’ || p[3]+3 != p[2] || p[3]+6 != p[1] )

return 8;

if( p[4] == ‘_’ )

return 9;

else

return (p[4] << 16 ) | 7;

}

else if( flag < 3 )

{

memset( p_section_header,0,8 );//name 区域清零

p[0] = ‘.’;

p[3] = (GetTickCount() & 0xff) / 13 + ‘a’;

p[2] = p[3] + 3;

p[1] = p[3] + 6;

if( flag == 2 )

p[4] = 7;

else

p[4] = ‘_’;

}



return 0;

/*

此函数负责检查节名类型或者创建病毒的节名。参数 flag 决定此函数具体执行什么操作。

如果 flag 为 1，则只检测节名类型。返回值的含义如下：

8：不是病毒创建的节

9：病毒创建的以”_”结尾的节（猜测可能是第一版的病毒）

ver<<16 | 7：病毒创建的以版本号结尾的节，返回值的高 16 位表示当前感染的病毒版本号

如果 flag 为 2，创建以版本号为结尾的节名，返回值为 0。

如果 flag 为 0：创建以”_”结尾的的节名，返回值为 0

*/

/*

对 CheckSection 的总结：

如果正在处理的 PE 文件最后一个节的节名是病毒创建的，则检测其版本。如果版本号在 2

和 7 之间，则设置出错码为 10 并返回 0，如果版本号至少为 7，则设置出错码为 7，返回 0。

如果为被遗弃版本（节名以’_’结尾），则设置出错码为 9,并返回 0

如果病毒无法识别此节，则认为未被感染，返回 1
```
