
# [原创]CVE-2016-2345 DameWare远程代码执行漏洞分析

## 0x01 漏洞复现

DameWare是一款强大的远控软件，用于管理大量主机设备，基于Windows NT，安装完成后，`C:/WINDOWS`下会生成一个`dwsc`的文件，其中，当DameWare服务安装完成后，会开启`6129`端口，此漏洞就存在于`6129`端口的`DWSC.EXE`服务中。

`DWSC.EXE`中有一段处理接收数据的算法逻辑，逻辑中会调用`wprintf`处理接收数据，但在处理`buffer`的过程中，没有对`buffer`的长度进行有效的控制，从而导致了缓冲区溢出的发生，通过构造发送`payload`，可反控远控主机，下面对此漏洞进行详细分析。

首先Windbg附加服务，执行`payload`，程序崩溃，捕捉异常点，到达漏洞现场。
