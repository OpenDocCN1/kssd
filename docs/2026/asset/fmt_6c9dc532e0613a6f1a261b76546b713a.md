## Backup Magic 1.3.2

下断点：`bpx 0044c519`

```
015F:0044C514  MOV      EAX,[EBP-04]
015F:0044C517  MOV      EDX,ESI
015F:0044C519  CALL    00403E50
015F:0044C51E  SETZ    AL
015F:0044C521  MOV      EBX,EAX
```

分别`d eax`、`d edx`就可以得到注册码了
