
# [原创]IDA Python脚本半自动识别call dword[xxxx] jmp dword[xxxx]调用的系统函数

## 背景

平时分析静态Dump的时候容易遇到 `FF 15` `Call DWORD[xxxx]` 和 `FF 2C` `Jmp DWORD[xxxx]` 指令来调用系统函数，如果想知道调用的哪一个函数则要查具体的模块和导出函数，这个脚本就是半自动的重命名这些函数

## 用法

1、修改脚本中外挂进程加载的模块路径和模块基址 `GetCurrentExportFunction("C:\\Windows\\SysWOW64\\ntdll.dll", 0x77b00000)`

2、64位IDA还需要修改脚本 `GetCallAddr()` `GetJmpAddr()` 函数中的 `ida_bytes.get_dword` 为 `ida_bytes.get_qword`
