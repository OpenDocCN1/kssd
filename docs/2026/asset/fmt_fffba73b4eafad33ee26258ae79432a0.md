
# [分享]复习笔记第三篇：androidNDk&小壳入门

对新手来说，学习android ,环境是必须要确保的。andriodstudio一定要及时更新，还有SDkmanager里的东西，要不写起程序来你就纠结吧！不知道哪出问题了！编译不成功是常有的事！要记住，检查几遍没有语法错误后，记得重启IDE！多开几次，指不定就好了！不明觉厉！哈哈

你最好有部谷歌的原生机最好了！但也不一定就要买，里边内置模拟器也还是可以用的，就是时间上和内存上有点捉急。必备几个模拟器，要是研究病毒，还要有多开器。有些时候明明程序没问题，运行不了。可能就是模拟器的问题，这时换个模拟器试试又何妨！没准就成了！事实也正是如此，android开源，不断更新，水深的很，要是没点水准，你都不知道是哪个地方没匹配上。在没成为大师前，只能碰碰，就那几个版本，总会对上。
