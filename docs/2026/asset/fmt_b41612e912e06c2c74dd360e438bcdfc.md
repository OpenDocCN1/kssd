
```
0012FC78 0012FC88
0012FC7C 00000000
0012FC80 004046C0 ASCII "EdrLib.dll"
```

这里就是创建`EdrLib.dll`，在`0012FC3C`那句上数据窗口中跟随，使用二进制编辑把`MBX@F44@3E2510.###`改成`EdrLib.dll`，多余的填0。

3、完成后 `BP GetModuleHandleA`，断下后就可以dump这个`EdrLib.dll`了。

4、用PE Tools的从文件中删除区段功能删掉dump出来的`EdrLib.dll`的最后一个区段`\_BOX\_`。

5、用16进制工具打开dump出来的`EdrLib.dll`，用原先保存的PE头从`EdrLib.dll`的偏移0处开始覆盖，保存。

6、根据OD中看到的加载这个`EdrLib.dll`的基址，对dump出来的dll基址进行修正，否则可能重定位不正确。我这里根据OD中所看到的，基址填`00A30000`。

7、再用PE工具看一下这个dll的各个区段，看看是否有偏移及大小不正确的错误，没有的话就OK了。对于这个示例程序，这里不需修正。
