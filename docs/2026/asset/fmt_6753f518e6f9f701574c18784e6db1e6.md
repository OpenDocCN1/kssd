
# DeTitle V1.33 简单算法分析

- 软件名称：DeTitle V1.33
- 软件介绍：在很多影片的开头与结尾处都会播放标题或说明性字幕，不过一般的录放影设备是无法产生这些字幕的，必须要和其它的字幕来源合成才可以。DeTitle 是一套专业的标题字幕产生程序，可以使用各种方式与效果制作标题字幕，使影片更完美。
- 破解人：BurSH (于2003.8.6)
- 所属组织：FCG-BCG-OCN-DFCG
- 破解工具：Trw2000 1.23

## 寻找正确的注册码……

软件是分别用八个文本框来让我们输入注册码的，用一个`Label`框来提示注册失败，较有意思:P
