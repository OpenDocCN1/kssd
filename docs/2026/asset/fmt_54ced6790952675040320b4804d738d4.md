## 反调试

（说实在的，这个壳我没有一句一句从头到尾详细看，如果有漏掉的不要见怪）：

- `FUNCTION CC CHECK`（我喜欢这么叫，嘿嘿）
- `EnableWindow`
- `ZwQueryInformationProcess`
- `ZwSetInformationThread`

1. `FUNCTION CC CHECK` 会检测壳用到的函数和程序用到的函数的第一个字节是不是被下断点，形式是这样的：

```asm

003B0AB9    74 01           JE SHORT 003B0ABC
```

## 输入表加密

集合了一些壳的特征，有点像 ACP 的，不过比 ACP 的好，有点像 PESPIN 的，不过比 PESPIN 差了些。

壳在还原之前获取每个函数的地址，并检查了第一个字节是不是被下了断点。

壳把程序里的函数替换成了壳里的地址（不同函数替换成不同地址的，这里统称为 `ADDR1`），`ADDR1` 里面的指令都是这样的：

```asm
PUSH XXXXXXXX
XOR DWORD PTR SS:[ESP], XXXXXXXX
RETN     ;返回到ADDR2            (像acp)
```

在 `ADDR2` 里是这样的：

判断函数的第一个字节取的指令有没有 `PUSH` 和 `MOV`，如果有的话就把这些指令搬到壳的 `ADDR2` 地址去（像 PESPIN），然后再跳到指向函数剩下指令的地址。

来个例子：

比如调用，本来是：

```asm
CALL [XXXXX]
```

`XXXXX` 放的是 `MessageBoxA` 的地址。

原函数被替换成这样：

```asm
CALL [XXXXX]
```

`XXXXX` 里放的地址是 `ADDR1`：

```asm
PUSH XXXXXXXX
XOR DWORD PTR SS:[ESP], XXXXXXXX
RETN     ;返回到ADDR2
```

`ADDR2`：

```asm
jmp MessageBoxA
```
