
# [原创] CTF2017 第11题  ToBeBetter CrackMe 详细破解过程

## 序言

本题使用了父子进程守护、壳、SMC、反调试、DES算法、多个坑等设计，难度不低，可惜多解，现仅提交140组答案，
破解此题需要攻击者具备解壳或动态调试能力、跟踪父子进程、熟谙DES算法细节和直觉（否则栽在坑里了）。
