
# [原创]CVE-2021-40438 Apache SSRF漏洞复现

## Apache SSRF漏洞复现

### 一、环境搭建

> M1装个docker真麻烦，后来才发现是我的`/usr/local/bin`目录有问题太草了

下载`httpd`，在百度找了好久都没有找到可以编译的，只能尝试一下`docker`

```bash
docker pull httpd:2.4.48
```

![image-20211020164217588](upload/attach/202110/809626_9F6TW6WDCCZHD5M.jpg)

```bash
docker run -p 80:80 -v $PWD/www/:/usr/local/apache2/htdocs/ -d httpd
```

![image-20211020164316557](upload/attach/202110/809626_65CDCZBPR9Z9BF9.jpg)

随后进入`docker`中，改配置

![image-20211020164714549](upload/attach/202110/809626_RJM4Y9KDT9KJQW5.jpg)

> 如果没有`vim`就自己下一个

```bash
apt update
apt install vim
```

主要取消注释了五个

```bash
LoadModule proxy_html_module modules/mod_proxy_html.so
LoadModule proxy_module modules/mod_proxy.so
LoadModule proxy_connect_module modules/mod_proxy_connect.so
LoadModule proxy_ftp_module modules/mod_proxy_ftp.so
LoadModule proxy_http_module modules/mod_proxy_http.so
```

随后查看`httpd-vhost.conf`

首先需要在`httpd.conf`中将这一行给去掉`#`注释

![image-20211020171638590](upload/attach/202110/809626_EHK6VKZYF4KRKM2.jpg)

随后将`httpd-vhost.conf`中添加`ProxyPass`和`ProxyPassReverse`

![image-20211020172738673](upload/attach/202110/809626_HVPKHN8RBYQ6AZ2.jpg)

```bash
<VirtualHost *:80>
ServerAdmin webmaster@dummy-host.example.com
DocumentRoot "/usr/local/apache2/htdocs/"
ServerName localhost
ServerAlias www.dummy-host.example.com
ErrorLog "logs/dummy-host.example.com-error_log"
CustomLog "logs/dummy-host.example.com-access_log" common
ProxyPass "/" http://127.0.0.1:8000
ProxyPassReverse "/" http://127.0.0.1:8000
</VirtualHost>
```
