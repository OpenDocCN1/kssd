
# [原创]qemu 2.0与gdb连接调试内核时出现"Remote 'g' packet reply is too long"问题分析

由于`qemu 2.0`对于x86的描述没有，导致`gdb`在查询远端host寄存器时候失败。只能按照自己默认的数量接收，但是`qemu`刚好还比`gdb`默认的大，导致出现了这个问题。解决办法要么patch `gdb`，要么patch `qemu`。在此不不赘述。
