#### `type`

```
  switch(_keyType)

          keyType = 2 << 28;

          return;

      }

      break;

    case AESGID:

      keyType = 512 | (2 << 28);

      break;

    case AESUID:

      keyType = 513 | (2 << 28);

      break;

    default:

      return;

  }
```

`0x00000000` -> 128Bits

`0x20000000` -> 256Bits

`0x10000000` -> 192Bits

`0x20000200` -> `AESGID`

`0x20000201` -> `AESUID`
