
## 使用 `uEmu` 对字符串进行解密

| 序号 | 操作 |
| --- | --- |
| 1 | 下载 `uEmu`：`$ git clone https://github.com/alexhude/uEmu` |

复制 `uEmu.py` 到 `IDA_Pro_7.5/plugins/` 下，重启 `IDA`。

找到函数，设置起始与结束断点：

![image-20210105145619016](https://bbs.kanxue.com/upload/attach/202106/811222_CPFMSCUUDNTXGJW.png)

在需要执行的汇编指令起点，右键选择 `uEmu-start`。

![image-20210105145728799](https://bbs.kanxue.com/upload/attach/202106/811222_364P8ASBGMHWCEE.png)

配置寄存器。

![image-20210105150533403](https://bbs.kanxue.com/upload/attach/202106/811222_CHNES5NYTDJXKSJ.png)

使用 `Ctrl+Shift+Alt+S` 单步运行。

![image-20210105150649023](https://bbs.kanxue.com/upload/attach/202106/811222_GWJHQT6KJMWGUVT.png)

如果你需要多行执行，单击要执行到的某一行，右键选择 `uEmu-run`。

![image-20210105150820536](https://bbs.kanxue.com/upload/attach/202106/811222_SX27PBKPE663WX8.png)

会自动向下执行到你单击的那一行。

查看内存。比如我们要查看 `0x1F0AD` 处的内存，看一下解密后的字符串内容：右键选择 `uEmu-show memory range`。

![image-20210105150917607](https://bbs.kanxue.com/upload/attach/202106/811222_FBMCP4XM7W8EHSG.png)

填写地址与长度。注意长度为十进制，选择 `Add`。

![image-20210105151102965](https://bbs.kanxue.com/upload/attach/202106/811222_P8PP86H3F7ADAF7.png)

![image-20210105151159124](https://bbs.kanxue.com/upload/attach/202106/811222_HZKPFFJK5KS9V3J.png)
