# Ubuntu20

Ubuntu20的`setcontext`不再是从+53开始利用而是从+61开始

传参的寄存器变成了`rdx`不再是`rdi`，所以需要用`ropper`寻找gadget把`rdi`的内容传给`rdx`并且去`call rdx`去执行shell

其他的思路和Ubuntu18差不多，需要多获取的一个就是堆的地址。
