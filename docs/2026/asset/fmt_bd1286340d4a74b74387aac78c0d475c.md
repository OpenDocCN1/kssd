
# 一个delphi控件的破解 (12千字)

Abakus是一套Delphi的工控控件，很好的。可惜搞不到源码。

从下面这个地方可以下载到2.01版，没有源码。

URL: `http://www.torry.net/vcl/indicat/packs/abkda.zip`

大小: 1159615

表现症状：当你放一个控件到你的Form，会有一个information的对话框出现；当你编译好一个程序，在delphi没有运行的情况下，会有一个Error的对话框出现。

破解工具：`Dede250`，`Ultraedit`。

作者：sxlz

## 1. 分析

看看所有的`DCU`文件，有没有可疑的地方，发现一个`_abinfo.dcu`，好像有问题！先拿它试试，如果不成的话，最看别的。

## 2. 运行

运行`Dede.exe`，选取`DCU Dumper`，把`_abinfo.dcu`给Dumpe一下。
