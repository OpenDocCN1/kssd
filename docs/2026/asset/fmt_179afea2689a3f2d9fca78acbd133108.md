```
def viper_upload_bin(path):

"""Uploads binary file to Viper"""

         upload_url = urlparse.urljoin(VIPER_API, 'file/add')

         tags = 'enisa,bin,pe32'

         try:

                   response = requests.post(upload_url,

                   files={'file': open(path, 'rb'),

                   'filename':os.path.basename(path)},

                   data={'tags': tags})

         except IOError as e:

                   print("Error: IOError: {}".format(e))

                   exit(1)

         except requests.exceptions.ConnectionError:

                   print("Error: Connection error. Is Viper API running at {}?".format(VIPER_API))

                   exit(1)

         print response.content

def viper_upload_url(url):

         """Adds sample from URL to Viper"""

         upload_url = urlparse.urljoin(VIPER_API, 'url/add')

         tags = 'enisa,url'

         try:

                   response = requests.post(upload_url, data={'tags': tags, 'url': url})

         except requests.exceptions.ConnectionError:

                   print("Connection error. Is Viper API running at {}?".format(VIPER_API))

                   exit(1)

         print response.content

if __name__ == '__main__':

         parser.add_argument('-p', '--path', type=str, action='store', help="path to the file")

         parser.add_argument('-u', '--url', type=str, action='store', help="url to be added")

         args = parser.parse_args()

         elif args.url:
```

# 4.5 扩展Shiva蜜罐

这一步我们将扩展Shiva的功能，等扩展完成后，每当Shiva蜜罐收到新的二进制附件，自动将它上传到Viper中。

Shiva扩展将使用Viper的上传API来上传文件。Viper API 必须运行并且监听`Http://localhost:8080`。

首先为shivaAnalyzer安装python requests模块

```
$ cd /opt/shiva/shiva/shivaAnalyzer

$ source bin/activate

(shivaAnalyzer)$ pip install requests

(shivaAnalyzer)$ deactivate
```

然后扩展`shivapushtodb.py`文件。

```
$cd /opt/shiva/shiva/shivaAnalyzer/lib/python2.7/site-packages/lamson

$patch shivapushtodb.py < /home/enisa/enisa/ex2/files/shiva/shivapushtodb.patch

$ mkdir viper

$ cd viper/

$ touch __init__.py

$ $EDITOR upload.py
```

`Upload.py`内容：


# 6 总结

通过本次实践，我们学会了如何动手搭建Shiva蜜罐，作为邮件陷阱来捕获垃圾邮件。从垃圾邮件机器人的角度来看，所有发送给Shiva的邮件看上去都被成功发送，或中转了。而实际上它们会被ShivaAnalyzer扫描处理，发现各种恶意附件以及URL后保存起来。

然后我们学习了如何搭建一个基于Viper的样本仓库。Viper不仅可以存储和管理样本（添加备注，标签等）。还可以做一些初步分析。另外多亏了Viper的模块化架构才使我们可以根据自己的需求来扩展Viper的功能。

在完成安装和配置Shiva蜜罐以及Viper仓库，我们使用测试脚本生成垃圾邮件并发送它们到本地垃圾邮件陷阱。通过本次模拟垃圾邮件获取的样本可以让我们用在后面恶意代码分析的实践中。
