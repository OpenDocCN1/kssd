找到这段代码，其中主要是对输入检查的部分，重点看这两处：

```javascript
pwd = encode(loginName, pwd);
```

此处对密码进行第一次加密。

```javascript
loginName = encodeURI(loginName); //避免中文问题
var reqId = (new Date()).getTime() + "";
var str = strEnc(loginName + "\n" + pwd, reqId, validCode);
```

第一行：将用户名进行 URL 的格式编码。

第二行：取时间戳赋值给 `reqId`。

第三行：传入用户名、加密后的密码和验证码进行验证，函数返回值赋给变量 `str`，正是提交数据的 `req` 的值。

在两个加密函数入口设置断点，开发者工具设置断点，只要在这个代码的行号上点击鼠标就行了，设好断点后，再次输入用户名、密码和验证码，重新提交，程序被断下：
