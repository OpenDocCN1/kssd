## 汇编指令与内存分配

`movntps` 在 32 位程序中目标操作数是 128 位即 16 字节。

C 中的 `malloc(n)` 实际分配的堆内存是 `Header`(4 字节) + `n` 结构，即分配 `n + 4` 字节的空间。返回给用户的是 `n` 部分的首地址。且分配的堆块 8 字节对齐。

> 系统不同 `Header` 的大小可能不同，详情参考 [903K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Q4x3X3g2T1N6i4y4&6j5X3!0^5i4K6u0W2L8X3g2@1i4K6u0r3N6f1y4D9K9h3u0U0i4K6u0r3N6s2u0W2k6g2)9J5c8X3I4A6j5X3y4Q4x3V1k6K6N6r3c8D9K9h3u0Q4x3V1k6E0j5h3I4D9L8$3y4Q4x3V1k6E0j5h3I4D9L8$3y4Q4x3X3g2Z5](https://bbs.kanxue.com/elink@f07K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Q4x3X3g2T1N6i4y4&6j5X3!0^5i4K6u0W2L8X3g2@1i4K6u0r3N6f1y4D9K9h3u0U0i4K6u0r3N6s2u0W2k6g2)9J5c8X3I4A6j5X3y4Q4x3V1k6K6N6r3c8D9K9h3u0Q4x3V1k6E0j5h3I4D9L8$3y4Q4x3V1k6E0j5h3I4D9L8$3y4Q4x3X3g2Z5) 的第 104 行

程序报错的原因是因为没有做到 16 字节对齐。

## 寻找满足对齐的输入

写一个简单的代码，找出 10 个符合输入范围且可以做到 16 字节对齐的数字。

```python
while True:
    a = int(raw_input())
    if (a + 4) % 16 > 9 or (a + 4) % 16 == 0:
        print("Right")
    else:
        print("Wrong")
# 如果输出 Wrong，当前值 +8 即可
```

我们所得的一串符合预期的值为 `8 24 40 72 136 264 520 1032 2056 4104`
