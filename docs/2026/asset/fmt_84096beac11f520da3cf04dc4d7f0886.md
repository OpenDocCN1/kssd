# 注册码说明

前四次计算结果每次得2位数（余数<99），后5次计算结果每次得1位数（余数<9），一共13位注册码，再与关键字符`**`连接。

# VB 注册机

VB做的注册机（可以用Word宏运行）：

```vb
sub main()
A = 机器码
A = Right(A, 9)
B = 密钥
A1 = 0: B1 = 0
For i = 0 To 8
  A1 = A1 + Asc(Mid(A, i + 1, 1))
  B1 = B1 + Asc(Mid(B, i + 1, 1))
Next
char = ""
For i = 1 To 9
   R2 = i + 5
   R2 = R2 * Asc(Mid(B, i, 1))
   R2 = R2 + i
   R2 = R2 * Asc(Mid(A, i, 1))
   D = i * 2 * 66
   R2 = R2 + D
   C = (2 * i * i + 13) * A1
   R2 = R2 + C
   D = i * 3 + 12
   R2 = R2 + D * B1
   C = 230 - i
   D = R2 Mod C
   If i <= 4 Then
      R2 = D Mod 99
      char = char & R2
   Else
      R2 = D Mod 9
      char = char & R2
   End If
Next
InputBox "您的注册码为：", "Greet", ** & char
End Sub
```
