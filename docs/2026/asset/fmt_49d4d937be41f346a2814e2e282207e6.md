3. Android 手机一部 (root)

2. `pscp` (upload, download file)
3. `putty` (connect Ubuntu)
4. `gcc` (build arm)

## 编写测试程序

首先用标准 C 写个简单的 CM。

```
#include <stdio.h>

int IsAdd(int* pNumOne, int* pNumTwo)
{
  return *pNumOne + *pNumTwo;
}

int main()
{
  int nNumOne = 0;
  int nNumTwo = 0;
  int nNumResult = 0;

  printf("hi arm code.\r\n");

  printf("Please Input a Name:");
  scanf("%d", &nNumOne);

  printf("\r\n");

  printf("Please Input a Password:");
  scanf("%d", &nNumTwo);

  printf("\r\n");

  nNumResult = IsAdd(&nNumOne, &nNumTwo);

  printf("%d + %d = %d\r\n", nNumOne, nNumTwo, nNumResult);

  if(nNumResult != 2013)
  {
     printf("error\r\n"); 
  }
  else
  {
     printf("success\r\n");
  }

  return 1;
}
```

测试代码写得不严谨。
