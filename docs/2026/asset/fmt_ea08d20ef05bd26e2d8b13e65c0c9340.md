
# [原创]pc版微信 数据库备份（2）编译sqlite源码

首先，我使用的开发工具是 `visual studio 2019` 以下简称`vs2019`

第一步：下载 [sqlite 3.28.0的预处理过的源码](elink@f41K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2K6M7h3I4A6N6r3g2Q4x3X3g2G2M7X3N6Q4x3V1j5J5x3o6p5&6i4K6u0r3M7%4q4D9K9i4c8W2i4K6u0V1M7s2u0W2M7s2u0G2j5$3g2K6M7$3g2V1i4K6u0V1x3K6t1^5x3o6l9H3x3q4)9J5k6i4A6A6M7l9`.`.)

下载完成后，解压缩，打开文件夹，得到文件如下：

![](upload/attach/202101/36729_NGZZZHHAJH2B83Q.png)

里面都是头文件（`.h`）和c源码文件（`.c`）

为了下面方便添加头文件，和源文件，新建一个头文件夹`include`，将`.h`文件都移动到这个文件夹中。

![](upload/attach/202101/36729_NCA7GYDXU4ENS3P.png)

第二步：使用 `vs2019` 新建一个c++控制台项目

![](upload/attach/202101/36729_BV4A35KUVSHBR8D.png)

![](upload/attach/202101/36729_77AJ7XZ7CW55VRK.png)

点击下一步

![](upload/attach/202101/36729_F3SPUBHBUDWA2J2.png)

点击创建，就创建了一个控制台项目

![](upload/attach/202101/36729_DEQ38VJPTM3VVEN.png)

第三步：添加sqlite源码到控制台项目

（1）添加头文件（`.h`）

在解决方案资源管理器，右键头文件，如下图所示：

![](upload/attach/202101/36729_ZKUQANRTMFFY5W2.png)

点击 `现有项` 菜单

选中所有刚才下载的sqlite头文件（自己新建的`include`文件中的文件）

![](upload/attach/202101/36729_PJCAF7HSRHTDAFR.png)

点击添加按钮，得到

![](upload/attach/202101/36729_HTXKDBQ8U9DH752.png)

（2）添加源文件（`.c`）

和添加头文件操作一样，在源文件上右键

![](upload/attach/202101/36729_3H8AJ7BE7M76KJ8.png)

选中所有`.c`文件

![](upload/attach/202101/36729_B25Z78U96VBT5GF.png)

点击添加，得到

![](upload/attach/202101/36729_55E3DTCK6XKQY8U.png)

打开 `sqlite3ext.h`文件
