# house\_of\_botcake

`libc-2.29` 新增加 `double free` 检查，方法是在 `tcache\_entry` 结构体中新增加标志位 `key` 来检查 `chunk` 是否在 `tcache bin` 中。当 `free` 掉一个堆块进入 `tcache` 时，假如堆块的 `bk` 位存放的 `key == tcache\_key`，就会遍历这个大小的 `Tcache`，假如发现同地址的堆块，则触发 `double Free` 报错。因为 `chunk` 的 `key` 保存在 `bk` 位置，只需将其修改即可绕过 `double free` 检查。而 `house\_of\_botcake` 是另一种方法。
