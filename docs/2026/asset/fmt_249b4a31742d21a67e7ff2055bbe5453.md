
# 关于UltraEdit32 v8.1的注册校验(PJ手记).高手免看! (14千字)

软件: UltraEdit32 v8.10

下载: 随处可下.

工具: SoftIce 4.05,W32Dasm.

此软件的用途可不用我多说了吧! 网上也有很多它的注册机,新手可用它来练练手,呵呵! 今次主要来看看它的注册校验.它的注册码经过加密后放在安装路径下的`Uedit32.reg`文件里,注意这不是注册表文件.

上面的这段算法就是注册码的算法,程序的算法也不算是很复杂,有兴趣可以研究上面的算法,它主要是用用注册名的ASC码和与0-----3C(前面几位是用注册名代替)之间的ASC码值再加上查表作数学运算,每算一位得一位注册码,名字>=6个,注册码>15个(后面可见到),注册码形式:AAAAA-BBBBB-XXXXX-YYYYY.
