## phase 3

输入两个数 `num1`, `num2`

```c

.text:0000000000400F56 mov eax, 0
```

有一个长度为8的跳转表，所以会检查`num1<=7`, 之后跳转到`jpt_400F75[num1]`, 每个case都有一个数，与`num2`相等则通过

```c
.text:0000000000400F7C loc_400F7C:
```

```c
int func4(int nEdx, int nEsi, int nEdi)
{
int nRet = 0;
int nEcx = 0;
nRet = nEdx - nEsi;
nRet += nRet >> 0x1F;
nRet = nRet >> 1;
nEcx = nRet + nEsi;
// 调试到这里, nEcx==7
if (nEcx > nEdi)
{
nEdx = nEcx - 1;
nRet = func4(nEdx, nEsi, nEdi);
nRet += nRet;
}
else if (nEcx < nEdi)
{
nRet = 2 * func4(nEdx, nEsi, nEdi) + 1;
}
// 终止条件是 nEcx == nEdi
return nRet;
}
int main()
{

return 0;
```

## phase 5

输入一段字符串，要求长度为6


然后根据输入的字符串，映射为另一个字符串。

```c
.text:000000000040108B loc_40108B: ; CODE XREF: phase_5+4A↓j
.text:000000000040108B ; phase_5+75↓j
.text:000000000040108B movzx ecx, byte ptr [rbx+rax] ; rbx=input
```

映射的逻辑是，每个输入的字符的低4位，作为`0x4024B0`处字符串表（如下）的偏移。比如输入小写a（`0x61`），偏移就是`0x61 & 0x0f == 0x01`，映射为`4024B1`处的`0x61`。
