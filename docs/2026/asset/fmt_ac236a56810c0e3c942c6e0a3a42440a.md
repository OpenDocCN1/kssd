
# 【经验总结】

取固定值 `3D Image Commander` 前9位。

依次取16进制分别左移2位和右移12位，做或运算。

然后再与下一位的16进制做异或运算。

如此循环直至算完。

假码也进行相同的运算，结果与上面算完的结果相同即可
