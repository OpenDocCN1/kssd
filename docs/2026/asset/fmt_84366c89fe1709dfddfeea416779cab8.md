## 0x06 一个自问自答

Q: 为什么不直接使用android.util.Log中的Log函数来打印,即在需要插桩的位置插入这串代码

|  |  |

| --- | --- |

| 1 | `invoke-``static` `{p0, p1}, Landroid/util/Log;->d(Ljava/lang/String;Ljava/lang/String;)I` |

,而是调用另一个类中的函数来打印呢?
