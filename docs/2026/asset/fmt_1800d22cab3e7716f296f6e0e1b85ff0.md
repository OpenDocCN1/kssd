通过上面的代码,我们清晰的知道了,两部分的算法分别为:

```pascal
//第一部份外部算法

  edx := ((esi + (esi \* $5 + $C0E4) \* 2 + $2694) shl $1) mod $2710;  //6\_9

//第二部份外部算法

  edx := ((((ebx - $1A02) xor edx) - edx) \* (ebx + $8E8)) mod $2710;
```

然后,将两部分的结果,分别与`edi`和`ebp`的结果比较,相等,便注册成功了!

好，得到上面这些有用的信息后，现在我就把它具体算法的思路给理一下吧：

1. 注册名在其中没有起到任何的作用, 程序先得到注册码,然后带入到运算中；
2. 取注册码的1~4位数,带入子程序`call 0044D3A0`中运算,结果送到-> `esi`中;
3. 取注册码的6~9位数,带入子程序`call 0044D3A0`中运算,结果送到-> `edi`中;
4. 取注册码的11~14位数,带入子程序`call 0044D3A0`中运算,结果送到-> `ebx`中;
5. 取注册码的16~19位数,带入子程序`call 0044D3A0`中运算,结果送到-> `ebp`中;
6. 然后用上面的‘第一部份外部算法’，将得到的结果`edx`与第‘2’步骤中得到的结果`edi`比较，两者相等，便OK；
7. 用上面的‘第二部份外部算法’，将得到的结果`edx`与第‘5’步骤中得到的结果`ebp`比较，如若相等，便成功了。
