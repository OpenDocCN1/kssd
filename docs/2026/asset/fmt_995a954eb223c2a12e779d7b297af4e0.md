
`00C43BBC`处只是赋初值，`0x1510EB0`处的值会被后面`00C43D46`处的指令修改。

`00C43D46`那处指令函数开始位于`00C43D04`，在这个函数中，如果条件满足，后面还会改写`0x1510EB0`处的值：

```asm
00C43E76   .  C600 00       mov     byte ptr ds:[eax], 0x0

......

00C43E7E   .  C600 02       mov     byte ptr ds:[eax], 0x2

......

00C43E86   .  C600 04       mov     byte ptr ds:[eax], 0x4
```

什么条件能让它改写呢？

存在合法的注册码。

它根据注册码判断软件版本，然后重新改写`0x1510EB0`处的值。

```asm
00C43C2A  |.  BA B83CC400   mov     edx, navicat.00C43CB8            ;  UNICODE "RegNo"
00C43C2F  |.  8BC3          mov     eax, ebx
00C43C31  |.  E8 52D08CFF   call    navicat.00510C88
00C43C36  |.  84C0          test    al, al
00C43C38  |.  74 0F         je      short navicat.00C43C49
```

程序先查看注册表中是否存在`HKEY_CURRENT_USER\Software\PremiumSoft\NavicatPremium\Registration110`这个键，如果存在，则：

```asm
00C43C3A  |.  8D4D FC       lea     ecx, dword ptr ss:[ebp-0x4]
00C43C3D  |.  BA B83CC400   mov     edx, navicat.00C43CB8            ;  UNICODE "RegNo"
00C43C42  |.  8BC3          mov     eax, ebx
00C43C44  |.  E8 B3CA8CFF   call    navicat.005106FC
```

在`005106FC`中会调用`advapi32.RegQueryValueExW`来从注册表中获取软件注册码。

如果不存在，则直接跳到`00C43C49`了。

```asm
00C43C70  |.  8B45 F4       mov     eax, dword ptr ss:[ebp-0xC]        ;ASCII注册码（16个字节）
00C43C73  |.  B9 B40E5101   mov     ecx, navicat.01510EB4        ;01510EB4是过期时间？现在还不太清楚
00C43C78  |.  BA B00E5101   mov     edx, navicat.01510EB0        ;01510EB0 这个是版本类型标识变量的内存地址
00C43C7D  |.  E8 82000000   call    navicat.00C43D04
```

```asm
00C43E76   .  C600 00       mov     byte ptr ds:[eax], 0x0        ; ds:[01510EB0]=00
```

我们的`[01510EB0]`才得以重新被设置为 0。

一般，如果不存在注册码，或者注册码invalid，那么在前面就会直接跳到`navicat.00C43E92`了。

因此，暴破可以把`00C43D46`处的指令修改成

```asm
mov     byte ptr ds:[eax], 0x0
```
