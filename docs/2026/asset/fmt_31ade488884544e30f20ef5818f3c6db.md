至此算法清楚，我们写出其算法注册机：

### 算法

1、利用一个固定的串 `Str1="JmgDBWords"`
2、机器码 `Str=XXXXXXXX-XXXXXXXX` 左八位 `StrL`, 右八位 `StrR`
3、函数 `JS(CString)` 返回16进制32位值
   则注册码为 `[JS(Str1)^JS(StrL)]-[JS(Str1)^JS(StrR)]`

### 函数 `JS()`

```cpp
unsigned long CJzdc107zcjDlg::JS(CString str)
{
  unsigned long a=0;
        int i;
  unsigned long temp=0;
  for(i=0;i<str.GetLength();i++)    a+=str.GetAt(i);
  for(i=1;i<4;i++)   temp=temp*10+str.GetAt(i)%10;
  CString tt,sum="";
  temp=temp^0x3e8;
  tt.Format("%d",temp);
  sum+=tt;
  a%=1000;
  tt.Format("%d",a);
  sum.Insert(0,tt);
  temp=a^temp;
  tt.Format("%d",temp);
  sum.Insert(0,tt);

    b=b*10+(sum.GetAt(i)-'0');

}
```
