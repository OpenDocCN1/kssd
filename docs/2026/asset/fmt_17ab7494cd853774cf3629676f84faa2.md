
# [原创]Armadillo 1.xx - 2.xx 单进程手脱

## 一. 找oep

Armadillo 1.xx - 2.xx 单进程壳相对简单，高手略过。

先忽略所有异常，直接运行，发现异常非常多。最后一次异常不太可能。

改用`rsrc`断点的方法。

`alt+m` 打开内存镜像，在`.rsrc`段下断。`shift+f9`，

然后再次`alt+m`打开内存镜像，在`00401000`段下断。`shift+f9`到`oep`。

```
004D12D4     55               push ebp

004D12D5     8BEC             mov ebp,esp

004D12D7     83C4 F0          add esp,-10

004D12DA     B8 0C0E4D00      mov eax,XDeskWea.004D0E0C

004D12DF     E8 004EF3FF      call XDeskWea.004060E4
```

`loadpe`，修正镜像大小，完全脱壳。

## 二. 修复iat

`importrec`显示无效，修复级别1，2，3都试过，还是不行，看来需要手动修复。

`iat`起始地址为`4db168`，下硬件写入断点，重新加载，运行。

第一次断在

`00C2DF43     F3:A5            rep movs dword ptr es:[edi],dword ptr ds:[esi]`

数据窗口：

`004DB168  000DB93A`

还没到`iat`写入点。再`f9`。发现`iat`已经写入。
