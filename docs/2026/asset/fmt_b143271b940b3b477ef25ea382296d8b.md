## 如何修复OEP并补上Stolen bytes

用`Pe-Editor` of `ProcDump` `Lord-PE`把OEP修改为:`564BDC`

然后打开`Hex-Edit` `Hview`把OEP处的"00"修改为

```asm
Push EBP
Mov EBP,ESP
Add ESP,-010
Mov eax, 05644CC
```

到这里aspr的脱壳就完成了...
