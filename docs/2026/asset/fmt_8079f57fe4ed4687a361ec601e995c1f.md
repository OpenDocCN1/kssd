
# Gif2swf V2.1版

## 基本信息

破解软件：`Gif2swf`

`V2.1`版

下载网址：`gz2.onlinedown.net`

破解难度：易

破解工具：`TRW1.22`,`PWdasm`黄金版

软件说明：`GIF2SWF`是一个可以把`gif`文件转换`Flash`的`swf`文件的小工具，包括有`WINDOWS`及`DOS`模式两种版本，可以轻易转换大量的图形文件。
