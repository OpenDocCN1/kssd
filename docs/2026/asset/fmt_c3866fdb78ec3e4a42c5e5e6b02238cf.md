### 算法总结

1. 对`"&fp--fftxar"`进行`SHA1`转换，得到：`SHA2[20]`;
2. `Name`字符串进行变换，`str1="*" + Name + "english."`, 再转为小写。
3. 对`str1`进行`SHA1`转换，得到：`SHA1[20]`;
4. `SHA3[n]=SHA3[n]=BYTE(SHA2[n]+SHA2[n*2]+SHA1[n*2])` (n=0...10)
5. `SHA3[n]`再与上面变换的`SN`比效，相等，则注册成功。
