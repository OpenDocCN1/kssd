
# 代码逻辑清理
先根据进程名查找进程的`PID`（获取进程快照，查找进程，设置进程`PID`并返回该`PID`），然后更改权限（打开一个进程相关联的`Token`，获取我们想要的系统权限值，存放到结构体中并根据传入的第二个参数决定设置该系统权限值，最后启用该`Token`的特权），最后卸载`dll`（创建该进程的模块快照，查找要卸载的`dll`模块，根据`PID`获取进程句柄，根据`kernel32.dll`获取`FreeLibrary`函数的地址，创建线程执行`FreeLibrary`卸载`dll`）

## 备注
使用`FreeLibrary()`的方法仅使用于卸载自己强制注入的`DLL`文件。`PE`文件直接导入的`DLL`文件是无法在进程运行过程中卸载的。
