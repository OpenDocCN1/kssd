
当我们成功地抓取到 hashcat 破解 PSK 所需的 EAPOL 帧时，我们需要将输出的 `pcap` 文件转换为 hashcat 能够读取的 `hccapx` 文件。我们可以使用[这个在线服务](https://bbs.kanxue.com/elink@ab0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5j5i4y4Z5j5$3q4@1i4K6u0W2L8X3g2@1i4K6u0r3j5$3q4H3x3X3S2U0j5$3q4H3P5q4)9J5c8R3`.`.)或者我们自己安装 [hashcat-utils](https://bbs.kanxue.com/elink@8e5K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6Z5j5i4y4Z5j5$3q4@1i4K6u0r3K9r3q4K6K9r3y4S2N6q4)9J5k6s2g2@1K9h3I4K6) 本地转换文件来完成以上操作：

```
/path/to/cap2hccapx /root/bettercap-wifi-handshakes.pcap bettercap-wifi-handshakes.hccapx
```

你现在可以继续使用字典攻击或者暴力破解这些握手包了，例如尝试所有8位数字的任意组合：

```
/path/to/hashcat -m2500 -a3 -w3 bettercap-wifi-handshakes.hccapx '?d?d?d?d?d?d?d?d'
```

就是这样，经久不衰的取消验证攻击就是如此简单，仅使用了一个工具进行展示......让我们现在来看有趣的部分

## 无客户端 PMKID 攻击

### Client-less-PMKID-Attack

2018年 hachcat 的作者[揭露](https://bbs.kanxue.com/elink@042K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5j5i4y4Z5j5$3q4@1i4K6u0W2L8X3g2@1i4K6u0r3k6X3!0J5N6h3#2Q4x3V1k6@1K9s2u0W2j5h3c8Q4x3X3b7%4y4K6p5%4i4K6u0W2K9s2c8E0L8l9`.`.)了一种新的攻击方法，这种方法只需要**单个数据包**，而且也不需要任何的客户端连接到我们的目标 AP，即使有客户端已连接，也不需要我们向它们发送 deauth 帧，在攻击者和客户端之间没有交互，只存在攻击者和 AP 之间的交互。如果路由器是可被攻击的，那么是几乎可以立刻完成攻击的！

当有人正在关联时，有**大量**的现代路由器会在 AP 自己发送的EAPOL的第一帧后附加一个可选字段，也就是所谓的 `鲁棒安全网络(Robust Security Network)`，其中包括 `PMKID`：

![pmkid](https://bbs.kanxue.com/upload/attach/202001/820961_4ZKAVV9YFC2GH9B.jpg)

在原来的文章中解释过，`PMKID` 由我们已知的数据生成：

```
PMKID = HMAC-SHA1-128(PMK, "PMK Name" | MAC_AP | MAC_STA)
```

因为 `"PMK Name"` 字符串是常量，我们知道 AP 和站点的 BSSID 以及和从完整4路握手包中获取的相同的 `PMK`，这就是 hashcat 用来破解 PSK 并恢复密码的全面所需信息。这里是新的 `wifi.assoc` 命令开始起作用的地方：不同于在之前的攻击方式中展示的取消现有客户端的连接那样，我们仅开始关联目标 AP 并监听包含 RSN PKMID 数据的 EAPOL 帧。

我们仍在信道1监听（因为我们之前设置了 `wifi.recon.channel 1`），让我们向每个 AP 发送一个关联请求看看谁会相应有效的信息：

```
# wifi.assoc 支持 `all` （或者 `*`） 或是一个指定的BSSID，就像 wifi.deauth 一样

> wifi.assoc all
```

附近所有可被攻击的路由器（让我重申一遍，其中有大量是可被攻击的）会开始向你发送 PMKID，bettercap 会将它们转储成寻常的 pcap 文件：

![assoc](https://bbs.kanxue.com/upload/attach/202001/820961_ESKPFK6NEWKH6X2.jpg)

## 破解 PMKID

我们现在需要把抓取的 pcap 文件中的 PMKID 数据转换成 hashcat 能理解的哈希格式，这里我们使用 [hcxpcaptool]

(2d5K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6K9k6i4u0n7k6h3q4Q4x3V1k6Z5j5%4S2@1L8$3!0D9M7#2)9J5z5g2)9K6b7b7`.`.

```
/path/to/hcxpcaptool -z bettercap-wifi-handshakes.pmkid /root/bettercap-wifi-handshakes.pcap
```

我们现在可以继续使用 `16800` 号算法破解生成的 `bettercap-wifi.handshake.pmkid` 文件：

```
/path/to/hashcat -m16800 -a3 -w3 bettercap-wifi-handshakes.pmkid '?d?d?d?d?d?d?d?d'
```
