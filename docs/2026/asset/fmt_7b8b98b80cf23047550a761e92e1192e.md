不不清楚这一段是否可逆，可以描述为：

```
int esi=0x3D5;
char IrcA[8]="....";
char IrcB[8];
for(short i=0; i<8; i++)
{
    IrcB[i]=IrcA[i]^(esi>>8&0xFF);
    esi+=IrcA[i];
    esi*=0x3182;
    esi+=0x8C33;
}
```
