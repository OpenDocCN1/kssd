## 内存断点追踪

重新运行，断在

```
014D7F43   > \E8 5CBC76FF   call    navicat.00C43BA4
```

`F7` 跟进。

运行到

```
00C43BBC  |.  C605 B00E5101>mov     byte ptr ds:[0x1510EB0], 0x4
```

`follow in dump -> memory address`

然后对 `01510EB0` , `01510EB4` , `01510EB8` , `01510EBC` , `01510EC0` 下 `memory write` 断点。

在 `step over` 修改 `01510EB0` 处的指令后，手动修改其值为 `00`，继续 `F9`

很快，到达了修改 `01510EC0` 处：

```
00C43EEC   .  E8 A3F5FFFF   call    navicat.00C43494

00C43EF1   .  8BD8          mov     ebx, eax

00C43EF3   .  881D C00E5101 mov     byte ptr ds:[0x1510EC0], bl
```

修改 `01510EB8` 处：

```
00C4357B  |.  E8 6459B2FF   call    navicat.00768EE4

00C43580  |.  DD5D 00       fstp    qword ptr ss:[ebp] ;st=<empty>  ss:[01510EB8]=41426.00000000000 表示成16进制是： 40 E4 3A 40 00 00 00 00
```

这是一个浮点数，`41426.00000000000` 是到 `2013-06-01` 过期

我在 `OD` 中修改它为 `40F869F0 00000000` (也就是 `99999.00000000000` ), 在内存中表示则是：

`00 00 00 00 F0 69 F8 40`

然后，我们的 `Navicat` 童鞋直接显示 `Expiration date: 2172-10-13`

`2172` 年过期，呵呵，够了吧。。。

## 总结暴破方法

1. 版本选择：
自然是选择功能最强大的版本，这里我直接设定它为 `premium` 版：
`file offset: 00843146`
```
00C43D46   .  C600 00       mov     byte ptr ds:[eax], 0x0 ;
```

2. license 类型和过期时间：
可以选择 `site` 或者 `NFR`

如果选择 `Site License` 的话，
`01510EB4 = 0xFF`
`01510EC0 = 非0`

如果选择 `NFR License`：
`01510EB4 = 0xFB`
同时修改过期时间(修改方法见上面）

或者
`01510EB4 = 0xFC /  0xFD / 0xFE`
`01510EC0 = 非0`
同时修改过期时间

这样修改了，可以说是完美暴破了。
