### 安装hyper

下载地址

```
https://github.com/vercel/hyper/releases/tag/v3.1.0-canary.4
```

![avatar](./upload/attach/202102/832539_NHNBYUWP4BUWZYJ.png)

运行命令进行安装

```
sudo dpkg -i hyper_3.1.0-canary.4_amd64.deb
```

会出现报错，原因是没有安装依赖

![avatar](./upload/attach/202102/832539_BG52WJZ2F2Z3PF2.png)

手动安装需要的依赖，这里感谢寄予蓝y大佬的帮助！到下面的两个地址下载依赖

```
https://packages.debian.org/jessie/amd64/libindicator3-7/download
https://packages.debian.org/jessie/amd64/libappindicator3-1/download
```

安装下载下来的依赖

```
sudo dpkg -i libindicator3-7_0.5.0-2_amd64.deb
sudo dpkg -i libappindicator3-1_0.4.92-3.1_amd64.deb
```

再次安装hyper

```
sudo dpkg -i hyper_3.1.0-canary.4_amd64.deb
```

可以看到安装就不报错了，安装成功

![avatar](./upload/attach/202102/832539_35XDG9CHXZ796V2.png)

运行`hyper`命令发现还是无法运行，这时输入`hyper -v`命令，发现需要我们改变`chrome-sandbox`的权限

![avatar](./upload/attach/202102/832539_ABC8NVXJAK88HQC.png)

修改`chrome-sandbox`权限

```
cd /opt/Hyper
sudo chmod 4755 chrome-sandbox
```

修改完成后，输入`hyper`命令即可正常打开

![avatar](./upload/attach/202102/832539_DVVMXH94T8CH4BD.png)

### 安装hyper需要的插件

#### 使用redsocks配置全局代理

因为需要安装的插件需要科学才能上网，所以我们先使用`redsocks`对全局进行科学代理

使用`vi`打开`redsocks`的配置文件

![avatar](./upload/attach/202102/832539_6H2XEWMASEM7BYJ.png)

启动`redsocks`

```
redsocks
```

查看启动是否成功

```
ss -lntp|more
```

如果所示表示成功启动

![avatar](./upload/attach/202102/832539_ZAR8CPY5FQNKFHQ.png)

配置`iptables`

创建文件`iptables.sh`，并使用`vi`打开，配置如下

```
#不重定向目的地址为服务器的包
sudo iptables -t nat -A OUTPUT -d 172.16.238.68 -j RETURN #请用你的shadowsocks服务器的地址替换$SERVER_IP
#不重定向私有地址的流量
sudo iptables -t nat -A OUTPUT -d 10.0.0.0/8 -j RETURN
sudo iptables -t nat -A OUTPUT -d 172.16.0.0/16 -j RETURN
sudo iptables -t nat -A OUTPUT -d 192.168.0.0/16 -j RETURN
#不重定向保留地址的流量,这一步很重要
sudo iptables -t nat -A OUTPUT -d 127.0.0.0/8 -j RETURN
#重定向所有不满足以上条件的流量到redsocks监听的12345端口
sudo iptables -t nat -A OUTPUT -p tcp -j REDIRECT --to-ports 12345 #12345是你的redsocks运行的端口,请根据你的情况替换它
```

![avatar](./upload/attach/202102/832539_FTN79Z7X9XC5CHK.png)

运行命令

```
sudo sh iptables.sh
```

访问谷歌查看是否科学成功

![avatar](./upload/attach/202102/832539_PU6QZCJECWAQVM7.png)

#### 安装hyper需要的插件

运行安装命令

```
hyper i hyperinator
hyper i hyperpwn
```

![avatar](./upload/attach/202102/832539_GM4RTBS689FFCZC.png)

更新插件，会出现以下问题，原因是DNS被污染

![avatar](./upload/attach/202102/832539_RCXDRKZC5TESHKY.png)

修改`hosts`文件，解决DNS问题

```
sudo vi /etc/hosts
```

手动加入`151.101.108.133 raw.githubusercontent.com`这条解析地址

![avatar](./upload/attach/202102/832539_SZZ4G5Z35FUTN75.png)

再次更新，就不会出现报错了

![avatar](./upload/attach/202102/832539_DWJ3QZQY896CJ9R.png)

### 安装gdb-multiarch和pwndbg

#### 安装gdb-multiarch

执行安装命令

```
sudo apt install gdb-multiarch
```

输入`gdb-multiarch`命令，查看安装是否成功，如下所示表示成功安装

![avatar](./upload/attach/202102/832539_EEU846PVF7FTYJ6.png)
