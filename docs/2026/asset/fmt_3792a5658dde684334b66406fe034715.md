# 四、结论：

1、取姓名十六进制ASCII码，结束以00为标志，并用20补足128位。如姓名中
  有大写字母，先转换为小写字母再取。例如：

    | 第1位 ==>BB

华-|

    | 第2位 ==>AA

    | 第3位 ==>D7

仔-|

    | 第4位 ==>D0

    第5位 [ ==> 5B

    第6位 C ==> 43 ==> 63

    第7位 C ==> 43 ==> 63

    第8位 G ==> 47 ==> 67

    第9位 ] ==> 5D

    第10位 结束标致00

    第11位 填充20

    ......

    ......

    第128位 填充20

2、从第四位开始向前取四位，记为`SN1`，如：

  `SN1=D0D7AABB`

3、从第十六位开始每四位为一组，顺序向前取三组，并求出这三组数之和，
  记为`SN2`，如：

  `SN2=20202020+2020005D+6763635B=A7A383D8`

3、将`SN1`减去`SN2`的差再乘以7531，记为`SN`，如：

  `SN=(SN1-SN2)*7531=(D0D7AABB+A7A383D8)*7531=B8C13073`

4、取`SN`的十进制数，就是真正的注册码之一。

  `B8C13073 ==> 3099668595`

  姓  名：华仔[CCG]
