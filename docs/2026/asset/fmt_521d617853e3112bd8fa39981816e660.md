

Clutch 的源码在 GitHub 上开源，可以自行下载编译。下载源码后，可以将项目导入到 Xcode 中编译，也可以通过命令行的方式进行编译。下面将展示通过命令行的方式编译 Clutch。首先安装编译所需环境和下载工具源码，具体如下：

```bash
# 安装编译所需的 command line tools
xcode-select --install

# 下载工具源码
git clone https://github.com/KJCracks/Clutch.git
```

开始正式编译，具体命令如下：

```bash
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=../cmake/iphoneos.toolchain.cmake ..
make
```

通过 `scp` 命令将编译好的 Clutch 安装到目标设备，具体命令如下：

```bash
scp ./build/Clutch root@<your.device.ip>:/usr/bin/Clutch
```

通过 `ssh` 的方式连接目标设备，在命令行中输入 `Clutch` 即可查看该工具的所有功能，如下图所示。

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_Q997WNGWJAVCHRH.png)

查看目标设备上安装的应用清单，具体命令如下：

```text
iPhone:~ root# Clutch -i
Installed apps:
1:   TextDemo <com.test.dump>
2:   TextDemo2 <com.test2.dump>
3:   TextDemo3 <com.test3.dump>
```

对选中的目标应用进行砸壳操作，具体命令如下：

```bash
iPhone:~ root# Clutch -d 2
```

其中，数字 `2` 即上一步中应用对应的序号。

至此已经完成砸壳操作，砸壳后的应用通常会存在此目录下：

`/private/var/mobile/Documents/Dumped`

### 2.2.5 Class-dump

`Class-dump` 可以将砸壳后的 IPA 文件中的头文件导出。逆向分析 iOS 应用时，根据头文件中声明的函数名或者变量名，可极大地提高分析速度。

`Class-dump` 的官方版本因太久未维护，对 Objective-C 2.0 和 Swift 开发的应用支持得不够友好。一些开发者基于官方版本进行了修改，可以很好地支持 Objective-C 2.0 和 Swift 开发的应用。虽然 `Class-dump` 出现了许多修改版，但是使用方法、功能与官方版本依然保持一致。本章节将使用官方版本进行讲解。

在官网 `https://bbs.kanxue.com` 下载 `class-dump-3.5.dmg` 文件，双击打开后，将里面的 `class-dump` 文件复制到 `/usr/local/bin/` 目录下。这样就可以直接在终端的命令行中使用 `class-dump` 命令。

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_ENSUCKT85XTTP9D.png)

通过 `class-dump` 工具将应用的 Header 信息输出在终端，具体命令如下：

```bash
class-dump TestDemo.app
```

输出结果如下图所示：

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_EP7DASXR3Z7URW2.png)

正常情况下，目标应用中会存在大量的函数，如果将结果输出在终端，不方便查看。`Class-dump` 提供了将结果输出到指定目录的功能，具体命令如下：

```bash
class-dump -H TestDemo.app -o Headers
```

输出结果如下图所示：

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_8JF8PJ4N2T9A56J.png)

至此就可以使用目标应用中头文件中的函数信息愉快地进行分析了。
