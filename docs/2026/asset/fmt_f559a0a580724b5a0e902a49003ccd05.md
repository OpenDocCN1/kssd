
# [原创]PEID的识别机制

看雪出的软件加密一书写得不错，对程序员开发水平的提高很有帮助。

此书对软件开发环境的伪装有涉及，大致讨论了一下FI的识别机制，在此讨论基础上，我深入了解了一下一些主流识别软件的机制，对识别方法也有一些补充，很希望和大家讨论交流一下，路过高手请不吝指点一二。

我以PEID识别某个Delphi程序为例，跟踪其识别过程。

检查PE合法性和使用用户定义数据文件暂不讨论。

PEID 判断一个应用程序的开发环境主要依据3个地方：

1. 代码入口
2. PE结构中的链接器版本
   ```
   BYTE MajorLinkerVersion;
   BYTE MinorLinkerVersion;
   ```
3. 特征码，对于Delphi，把特征码定位在CODE节里，这里是Delphi的支持库代码。不同的Delphi版本，对应特征码不同。

我们来看看代码。
