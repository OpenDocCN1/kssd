//其作用就是把转换为大写的用户名的每位的ASCII值乘以一个变量EDX，然后相累加
//用C来表达如：
//这里令用户名为：`strName`;注册码为：`strCode`

```
int sum=0;
int k=1;
int len=strlen(strName);
for(int i=0;i<len;i++){
        if(strName[i]>='a' && strName[i]<='z')
                strName[i]-=32;
        sum+=(strName[i]*k);
        k++;
}
```

`sum`里面保存的就是上面循环后所得的值了，相当于上面的`dword ptr ss:[ebp-4]`
