## 漏洞利用

### CVE-2017-12615 漏洞利用

此漏洞会影响Windows上的Apache Tomcat 7.0.0至7.0.79。它可以将恶意的jsp文件上传至服务器。

该漏洞有3种使用方法，此处使用的是 `shell.jsp%20`

![](https://bbs.kanxue.com/upload/attach/202007/860119_2QHNGGY4V84QSX4.png)

解析之后，应该下载其他的攻击荷载。

![](https://bbs.kanxue.com/upload/attach/202007/860119_B5XH3FFWW7W6V8X.png)

### CVE-2017-5638 漏洞利用

此漏洞影响的是Struts 2.3.5 – Struts 2.3.31 Struts 2.5 – Struts 2.5.10。Apache Struts是一个免费的开源框架，用于构建Java Web应用程序。攻击者在“Content-Type”标头中构建恶意指令，使得恶意指令直接在服务器中运行。

![](https://bbs.kanxue.com/upload/attach/202007/860119_WC8NHMKT9RN4RCZ.png)

### CVE-2018-2628 漏洞利用

此漏洞允许未经身份验证的攻击者通过T3协议访问网络，从而破坏在端口7001上运行的Oracle WebLogic Server。

![](https://bbs.kanxue.com/upload/attach/202007/860119_TGD92SUWZNQESXQ.png)

### CNVD-2018-24942 漏洞利用

此漏洞的原因是，ThinkPHP 5框架的底层未严格过滤控制器名称，这使攻击者可以通过URL在ThinkPHP框架内调用敏感功能，从而导致下载和安装恶意程序。它试图通过从'`cmd`'运行PowerShell来下载并执行恶意程序。

![](https://bbs.kanxue.com/upload/attach/202007/860119_W25HCP8JV54S5AY.png)

### CVE-2019-2725 漏洞利用

此漏洞由于WebLogic的'wls9\_async'和'wls-wsat'组件的反序列化输入信息，攻击者可以利用它来执行任意命令。

![](https://bbs.kanxue.com/upload/attach/202007/860119_H544WNGM938DVX7.png)

### CVE-2018-7600 漏洞利用

Drupal 7.x和8.x的多个子系统中存在一个远程执行代码漏洞。它允许攻击者将恶意负载注入表单结构以执行任意代码。

![](https://bbs.kanxue.com/upload/attach/202007/860119_PSW5EZZ2352VVZT.png)

### CVE-2019-0193 漏洞利用

此漏洞存在于DataImportHandler模块中，该模块是用于从数据库或其他来源导入数据的通用模块。该模块的整个DIH配置可以来自外部请求中包含的dataConfig参数。由于DIH配置可以包含脚本，因此此参数存在安全风险。攻击者可以利用此漏洞通过包含精心设计的dataConfig参数的恶意请求来导致任意代码执行。

![](https://bbs.kanxue.com/upload/attach/202007/860119_Y6HSRHWPKGS7SSU.png)

### PHPStudy后门

BuleHero检查以下PHP模块路径（如果存在），然后将其替换为嵌入式后门，从而使攻击者可以在服务器上执行任何命令。

- `PHPTutorial \ php \ php-5.4.45 \ ext \ php_xmlrpc.dll`
- `PHPTutorial \ php \ php-5.2.17 \ ext \ php_xmlrpc.dll`

![](https://bbs.kanxue.com/upload/attach/202007/860119_6DAUTFBU3MUGHYR.png)

原本只是瞎看看，分析着就感觉很有意思，这个样本的一般行为，从火绒剑里就可以看个七八分。而样本里的漏洞利用基本都是针对web服务器的，看到的时候还在想，怎么就知道样本利用了这些漏洞呢？
