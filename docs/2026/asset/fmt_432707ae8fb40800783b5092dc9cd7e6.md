
# 随便反汇编Delphi程序段整理

**作者** 神杀中龙

用 `OllyDBG` 反 `Delphi` 写的程序，一些 `Delphi` 的函数反不出来。

引用看学 `foxabu` 说的 `Sig ... LIB` 函数。

或者可以说，`Delphi` 内有不少 `SysUtils` 的函数。

我就把这些识别不了的叫做 `Sig...Lib` 函数吧。我整理下，

并确定下各种 `Delphi` 特殊的指令序列是怎么出来的。

分下类，

1. 函数调用函数参数
2. 顺序语句
3. 分支语句
4. 循环语句
5. `Delphi` 自动添加语句，一般是添加在函数头和函数尾，已经语句指令中间。
