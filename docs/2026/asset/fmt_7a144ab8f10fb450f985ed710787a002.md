## 修复用的 Script

### 3.2) 修复用的 Script

``` 
// filename: ospr.osc

var `addr`                  // 定义变量

start:

  eob label\_break         // 中断发生时，跳到 label\_break

  run                     //  == F9

label\_break:

  cmp eip,015100A3        // 每次运行这个值都要重新修改

  jne label\_exit

  mov `addr`,esp

  sub `addr`,4

  mov [`addr`],1540210      // 回到CODE2中去

  jmp start

label\_exit:
```
