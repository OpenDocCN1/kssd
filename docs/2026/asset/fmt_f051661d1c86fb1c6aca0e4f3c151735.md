# 4. 设置通讯函数列表（`SetKeyDisFuncArray`的分析）

我们观察上面的截图，看到第一个`140010F88`(8字节)和`140010F90`(4字节)

再看看下方的截图，你发现了什么？

是吧？他就是一个8字节对齐的全局的结构体数组

```
struct _FunCallArray
{
    ULONG64 FuncAddr;
    ULONG FuncIndex;
};
```

由此我们可以知道3.2.2小节中`FuncCall`的命名由来，实际上他在根据索引确定函数的调用。

NTKERNELAPI

ObSetHandleAttributes (
    __in HANDLE Handle,
    __in POBJECT_HANDLE_FLAG_INFORMATION HandleFlags,

我们继续看一下`HandleFlags`的结构体类型

```
typedef struct _OBJECT_HANDLE_FLAG_INFORMATION {
    BOOLEAN Inherit;
    BOOLEAN ProtectFromClose;
} OBJECT_HANDLE_FLAG_INFORMATION, *POBJECT_HANDLE_FLAG_INFORMATION;
```

基本可以确定这是一个用于关闭文件的函数。如果你不是十分肯定的话，再搜索引擎确认一下。
