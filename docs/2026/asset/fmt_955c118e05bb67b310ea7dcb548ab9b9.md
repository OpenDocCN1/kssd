## 写脱壳脚本

为了复习`OD`的脚本，虽然本壳简单，写脚本也当做复习了，脚本怎么写的就不说了，注释已经很详细

```
// 1. 定义变量

VAR dwWriteIATAddr // 填充IAT地址的下一行地址

VAR dwGetAPIAddr // 获取到了API地址下一行地址

VAR dwOEP // 原始OEP

VAR dwTmp // 临时变量



// 2. 初始化变量

MOV dwOEP, 00409486

MOV dwWriteIATAddr,4385f0

MOV dwGetAPIAddr, 4385bf



// 3. 清除所有断点

BPHWC

BPMC

BC



// 4. 设置断点

BPHWS dwWriteIATAddr, "x"

BPHWS dwGetAPIAddr, "x"

BPHWS dwOEP, "x"



// 5. 循环判断

LOOP0:

RUN



CMP eip,dwGetAPIAddr

JNZ NEXT1

MOV dwTmp,eax

JMP LOOP0

NEXT1:

CMP eip,dwWriteIATAddr

JNZ NEXT3

MOV [edi],dwTmp

JMP LOOP0         

NEXT3:

CMP eip,dwOEP

JNZ LOOP0

MSG "到达OEP!"
```
