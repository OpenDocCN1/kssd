原文的思路是通过修改`backing_store`字段的值为rwx内存地址，来达到写`shellcode`的目的

<!-- 这是一张图片，ocr 内容为： -->

![图片描述](upload/attach/202609/1075564_9H6VHTPN4RYQG5A.webp)

我们发现`backing_store`那 8 字节存的不是`0x1db100000000`本身

```
真实地址
0x1db100000000
↓ 减 sandbox base
offset = 0x1db100000000 - 0x1db000000000
= 0x100000000
↓ 左移 24 bit
raw = 0x100000000 << 24
= 0x0100000000000000
```

这里还想`copy_shellcode_to_rwx` 就得打sandbox escape了
