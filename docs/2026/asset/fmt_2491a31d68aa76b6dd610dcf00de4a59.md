
将 c 文件转化为 wasm 文件：

```
../wasi-sdk-11.0/bin/clang --sysroot=../wasi-sdk-11.0/share/wasi-sysroot -O2 -D USE_JPIP=1 vuln.c -o vuln.wasm
```

![](https://bbs.kanxue.com/upload/attach/202204/932916_EMHUU9N7U5YRQYK.png)

之后进行 `insert canaries` 和 `instrument coverage` 操作，注意生成文件后使用 `chmod +x xxx.wasm` 授权：

```
afl_branch vuln.wasm vuln.instr.wasm
canaries vuln.instr.wasm vuln-cov-canaries.wasm
```

![](https://bbs.kanxue.com/upload/attach/202204/932916_CYUV22QF2CZPE5Y.png)

然后开始 fuzzing：

```
WASM_MODE=1 afl-fuzz -i testcases/ -o outputs ./vuln-cov-canaries.wasm
```

![](https://bbs.kanxue.com/upload/attach/202204/932916_74BRHNCHP5Z6XB4.png)
