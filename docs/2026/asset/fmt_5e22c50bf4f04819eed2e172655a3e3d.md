这里需要注意的是，在 XP 中新加入了一种对象，调试本身对应的调试对象（Debug Object）。这个对象的特别之处我们将在之后讨论。现在，我们先来看看`DebugSetProcessKillOnExit`函数：

第一个 API，`DbgUiGetThreadDebugObject`是另一个`DbgUi`调用，它将返回一个与当前线程关联的 Debug Object 句柄（之后我们会看到它存放在什么位置）。获得句柄后，我们调用一个直接与 Dbgk（而不是 DbgUi）通信的 Native API。该 API 将简单地改变内核 Debug Object 结构中的一个标志。正如我们之后将看到的，这个标志会在断开连接时由内核读取。

一个与此类似的函数是`CheckRemoteDebuggerPresent`，它使用相同类型的 NT 语义来获取进程信息：

```c
BOOL
WINAPI
CheckRemoteDebuggerPresent(IN HANDLE hProcess,
                           OUT PBOOL pbDebuggerPresent)
{
    HANDLE DebugPort;
    NTSTATUS Status;

    /* Make sure we have an output and process */

    if (!(pbDebuggerPresent) || !(hProcess))
    {
        /* Fail */

        SetLastError(ERROR_INVALID_PARAMETER);
        return FALSE;
    }

    /* Check if the process has a debug object/port */

    Status = NtQueryInformationProcess(hProcess,
                                       ProcessDebugPort,
                                       (PVOID)&DebugPort,
                                       sizeof(HANDLE),
                                       NULL);

    if (NT_SUCCESS(Status))
    {
        /* Return the current state */

        *pbDebuggerPresent = (DebugPort) ? TRUE : FALSE;
        return TRUE;
    }

    /* Otherwise, fail */

    SetLastErrorByStatus(Status);
    return FALSE;
}
```

正如你所看到的，这里使用了另一个`NtQuery/SetInformationXxx` API，但这次处理的是进程。虽然你可能知道，可以通过简单地检查`NtCurrentPeb()->BeingDebugged`来检测调试状态，但还有另一种方法，那就是查询内核。

由于内核需要在调试事件上与用户模式通信，因此需要某种实现方式。在 XP 之前，这通常通过 LPC 端口完成；而现在则通过 Debug Object 完成，不过二者共享同一个指针。

由于该对象位于内核模式的`EPROCESS`结构中，我们使用`DebugPort`信息类进行查询。如果`EPROCESS->DebugPort`被设置为某个值，那么该 API 将返回`TRUE`，这意味着进程正在被调试。

这个技巧同样可以用于本地进程，但直接读取 PEB 的速度更快。需要注意的是，虽然某些应用程序喜欢将`Peb->BeingDebugged`设置为`FALSE`来欺骗反调试程序，但无法将`DebugPort`设置为`NULL`，因为内核本身不会允许你进行调试，而且你也无法访问内核结构。

鉴于上面的介绍，让我们看看整个 Win32 调试基础设施的核心函数`WaitForDebugEvent`是如何实现的。在介绍更简单的`ContinueDebugEvent`/`DebugActiveProcessStop`之前，需要先展示这个函数，因为它引入了 Win32 用于封装 DbgUi 的高层内部结构。

```c
BOOL
WINAPI
WaitForDebugEvent(IN LPDEBUG_EVENT lpDebugEvent,
                  IN DWORD dwMilliseconds)
{
    LARGE_INTEGER WaitTime;
    PLARGE_INTEGER Timeout;
    DBGUI_WAIT_STATE_CHANGE WaitStateChange;
    NTSTATUS Status;

    /* Check if this is an infinite wait */

    if (dwMilliseconds == INFINITE)
    {
        /* Under NT, this means no timer argument */

        Timeout = NULL;
    }
    else
    {
        /* Otherwise, convert the time to NT Format */

        WaitTime.QuadPart = UInt32x32To64(-10000, dwMilliseconds);
        Timeout = &WaitTime;
    }

    /* Loop while we keep getting interrupted */

    do
    {
        /* Call the native API */

        Status = DbgUiWaitStateChange(&WaitStateChange, Timeout);

    } while ((Status == STATUS_ALERTED) || (Status == STATUS_USER_APC));

    /* Check if the wait failed */

    if (!(NT_SUCCESS(Status)) || (Status != DBG_UNABLE_TO_PROVIDE_HANDLE))
    {
        /* Set the error code and quit */

        SetLastErrorByStatus(Status);
        return FALSE;
    }

    /* Check if we timed out */

    if (Status == STATUS_TIMEOUT)
    {
        /* Fail with a timeout error */

        SetLastError(ERROR_SEM_TIMEOUT);
        return FALSE;
    }

    /* Convert the structure */

    Status = DbgUiConvertStateChangeStructure(&WaitStateChange, lpDebugEvent);

    if (!NT_SUCCESS(Status))
    {
        /* Set the error code and quit */

        SetLastErrorByStatus(Status);
        return FALSE;
    }

    /* Check what kind of event this was */

    switch (lpDebugEvent->dwDebugEventCode)
    {
        /* New thread was created */

        case CREATE_THREAD_DEBUG_EVENT:
            /* Setup the thread data */

            SaveThreadHandle(lpDebugEvent->dwProcessId,
                             lpDebugEvent->dwThreadId,
                             lpDebugEvent->u.CreateThread.hThread);
            break;

        /* New process was created */

        case CREATE_PROCESS_DEBUG_EVENT:
            /* Setup the process data */

            SaveProcessHandle(lpDebugEvent->dwProcessId,
                              lpDebugEvent->u.CreateProcessInfo.hProcess);

            /* Setup the thread data */

            SaveThreadHandle(lpDebugEvent->dwProcessId,
                             lpDebugEvent->dwThreadId,
                             lpDebugEvent->u.CreateThread.hThread);
            break;

        /* Process was exited */

        case EXIT_PROCESS_DEBUG_EVENT:
            /* Mark the thread data as such */

            MarkProcessHandle(lpDebugEvent->dwProcessId);
```
