
# [分享]smali语法高亮扩展包 for Sublime Text 2 & 3

《Android软件安全与逆向分析》书里作者自己写了 smali 语法高亮插件，看了颇为羡慕。但自己使用的 Sublime Text 这款性感无比的编辑器，偶尔反编译 apk，查看 smali 文件的时候，发现并没有高亮显示，即便最新的 Sublime Text 3 也没有。我想应该会有这样的插件，于是一番功夫后终于找了 `sublime-smali`。

![](https://bbs.kanxue.com/upload/attach/201309/551906_j2418glaww958lq.png)

将扩展包解压到以下目录：

- `..\SublimeText2\Data\Packages`
- `..\Sublime Text 3\Data\Cache`

启动 Sublime Text，再次打开 smali 文件的时候，已经可以高亮显示了。

如果没还是没显示，按下 `ctrl+shift+p`，选择 `set syntax：smali` 即可。

编辑器软件就不上传了，感兴趣的朋友可以自己搜一下。
