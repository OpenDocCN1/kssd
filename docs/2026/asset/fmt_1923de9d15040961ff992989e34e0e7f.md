# 3. 被骗的原因

前面的流程都是一样的，一直到达了`0x4050F8`，程序调用`CreateFileW`，试图打开`PhysicalDrive0`，结果失败了。

```c
#include <windows.h>

int main() {
HANDLE hFile = CreateFileW(L"\\\\.\\PhysicalDrive0", GENERIC_WRITE,
FILE_SHARE_WRITE, NULL, OPEN_EXISTING, 0, NULL);
if (INVALID_HANDLE_VALUE == hFile) {
printf("Error id: %d\n", GetLastError());
}
return 0;
}
```

万万没想到！由于我的虚拟机为了方便测试病毒都是打了快照的，所以确实可能出现打快照的时机出现问题，导致`PhysicalDrive0`被占用。
