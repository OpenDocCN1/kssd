# 2.动态调试

`OD`附加分析，直接跳到`rep`指令处，可以看到`edi`与`ebp +0x14`处就是返回地址

![](upload/attach/202108/912460_X3XJZSZYS2TRGG8.png)

继续跟到`ret`处，当到`ret 14`的时候，就会跳转到`jmp esp`，(我自己找的跳板)

![](upload/attach/202108/912460_V22NM5JBJEU94XT.png)

此时相隔`0X18`处，就是`shellcode`，而现在已经定位到自己找的`jmp esp`指令了，所以可以直接跳到`shellcode`

![](upload/attach/202108/912460_E7XMDR58ZA3CRX7.png)

最后成功执行`shellcode`

![](upload/attach/202108/912460_T6SM3XNW48PJV2C.png)

# 3.注意点

`0XF4CB39`处，如果跟进`30F4CE43`函数后会报以下错误，但是在`0XF4CB26`处有判断，`ZF=1`则可以让`je`跳转，跳过`30F4CE43`函数执行后面指令。

![](upload/attach/202108/912460_UXJ8UYHMGMUNH5Z.png)

如果正常进入`30F4CE43`函数，就会崩溃

![](upload/attach/202108/912460_5NABXB83NJNZQAJ.png)

解决思路：在`0xF4CB26`处 `ebp+0X10`与`ebx`进行比较，正常执行流程`ebp+0X10`为`shellcode`内容，这样当`cmp`比较之后，后续指令`je`不会进行跳转，则会进入到`30F4CE43`函数报错，那么我们只需要将`ebp+0X10`处改为`0`即可，这样`je`跳转就能跳过不执行`30F4CE43`函数。

快速定位`ebp+0X10`的位置，首先将`rtf`按照如下方法更改

![](upload/attach/202108/912460_TJH6XNDV3JTCC2K.png)

之后断点直接跑过来，`55555555`这段就是`ebp+10`的地方，所以将此地方改成`00000000`即可

![](upload/attach/202108/912460_ACNBMYTE6N77S2N.png)
