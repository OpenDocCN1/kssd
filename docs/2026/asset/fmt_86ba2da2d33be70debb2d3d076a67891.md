1、首先查壳；

![image-20210411131928308](upload/attach/202104/856790_NRJ2RXFAZHY6EPK.jpg)

+ 我们可以点进去看一下，`F5`看一下反汇编，还是比较清晰的，我就直接截图了；

```c++
int __cdecl sub_402510(int a1)
{
int result; // eax@2
char v2; // [sp+4h] [bp-4h]@5
char v3; // [sp+4h] [bp-4h]@7
if ( strlen((const char *)a1) == 4 )
{
if ( *(_BYTE *)a1 == 97 ) // a
{
v2 = *(_BYTE *)(a1 + 1) - *(_BYTE *)a1; // b
if ( v2 == 1 )
{
v3 = 99 * v2;
if ( v3 == *(_BYTE *)(a1 + 2) ) // c
result = (char)(v3 + 1) == *(_BYTE *)(a1 + 3); // d
else
result = 0;
}
else
{
result = 0;
}
}
else
{
result = 0;
}
}
else
{
result = 0;
}
return result;
}
```

很显然，这是一堆位操作，我们根据函数可以很简单的判断出这是一个密码验证函数：

```c++
*(_BYTE *)a1 = a;
*(_BYTE *)(a1 + 1) = b;
*(_BYTE *)(a1 + 2) = c;
*(_BYTE *)(a1 + 3) = d;
```

最终得到密码是`abcd`；
