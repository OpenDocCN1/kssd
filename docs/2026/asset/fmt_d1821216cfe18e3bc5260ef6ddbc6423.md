## 2. hitcontraining_playfmt（格式化利用bp链 变形题）

这个和 `SWPUCTF_2019_login` 差不多，不过有更好的办法。

上次我们拆分成3次写入很麻烦，这里实际上两次也可以，然后不一定要去利用bq链延续下去改一整条链。

我们可以把bp链上面的地址改了，没什么影响的，而且这样省去了恢复bp链。

exp

```python
#coding:utf8
from pwn import *
r = remote("node4.buuoj.cn", 28112)
elf = ELF("./playfmt")
```
