}
listen(sd, 1);
int c = sizeof(struct sockaddr_in);
cd = accept(sd, (struct sockaddr*)&caddr, (socklen_t*)&c);
if (cd < 0) {

C 的 ASCII 码为 67，所以条件 1 中第 67 个参数转换为整型后为接收端口号，我们需利用 `socket` 往该端口发送 `"\xde\xad\xbe\xef"`
