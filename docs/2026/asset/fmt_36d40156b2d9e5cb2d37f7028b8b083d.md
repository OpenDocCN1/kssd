
可以看到 `TracerPid: 0` 说明没有被别的进程附加调试（如果被调试 `TracerPid` 的值就是调试器进程 id），`pid` 是自己的 id，`ppid` 是父进程的 id。

## 0x3 反注入

### 1. 概念

程序在运行时会加载自身依赖的 so 文件，注入就是我们可以让程序加载我们自己定义的一些 so 文件，反注入检查当前加载的一些 so 文件，如果被注入，程序就结束。
