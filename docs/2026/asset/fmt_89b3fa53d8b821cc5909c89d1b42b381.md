
# Registry Crawler 4.0 注册码算法分析

（附：注册机）

**Open Cracking Group**

**CrAcKeD BY alphakk/OCG**

将用户名与固定字符串`0123456789`进行运算，以运算结果的`EDX`（余数）中的值为偏移量，取得此偏移量所指向的`0123456789`中的值并输出，共循环9次。

注册码形式为：`8267-XXXX-XXX-XX`

本例中：

- 用户名：`alphakk/OCG`
- 注册码：`8267-7626-579-75`

注册机在：`http://www.newclw.com/lllufh/cgi-bin/leoboard.cgi`
