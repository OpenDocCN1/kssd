
# [原创]记一次内存泄露检查

## 背景

一个服务器程序，基于Windows `IOCP`实现，一直稳定运行，近期加入了一个异步HTTP处理后(`WinHttp`)，出现了轻微的内存泄露情况。

## 泄露检查

首先为服务器程序配置`PageHeap`，重启服务，对程序做`FullMemoryDump`取样，间隔一定时间，拿到多个样本。

使用`gflags`做`PageHeap`配置，如下图：

![](https://bbs.kanxue.com/upload/attach/202105/906381_B5MZ7694W2BKTVA.jpg)
