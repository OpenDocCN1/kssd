
# [原创]分析实战读书笔记2_初级动态分析

# 1_基础动态分析知识点总结

- 动态分析常在尝试了可用的所有静态分析的手段无果后才会进行动态分析
- 基础动态分析常使用以下几种方式:
- 沙箱: 优点是可读性高,分析速度快,一目了然. 缺点是需要将样本提交至沙箱平台,可能会泄露客户隐私
- 通过 `rundll32` 来运行dll样本 `rundll32 xxxx.dll, ExportFunc`
- 通过手动擦除PE头中的dll标记来运行dll样本,但是只能运行DllMain中的内容,并且容易造成崩溃
- 使用行为监视器来监控样本行为, 推荐 `ProcessMonitor` 和 `火绒剑`
- 使用进程浏览器来监控样本进程情况,如内存块、模块、句柄等 推荐 `Process Explorer` 和 `火绒剑`
- ProcExp: 粉色->服务进程 蓝色->普通进程 绿色->新进程 红色->已终止进程
- 使用 `Regshot` 来比较样本运行前后注册表项值得变化
- 当需要分析样本得网络交互行为时,可以使用以下工具:
- ApateDNS 用于劫持样本发起得请求来返回虚假的响应数据
- Netcat监听样本发起的请求内容
- WireShark用于截获网络封包并加以分析, 后文将会详细讲解网络封包与wireshark使用
- INetSim用于模拟网络服务,包括dns http https smtp irc等等

# 1_基础动态分析知识点总结

- 动态分析常在尝试了可用的所有静态分析的手段无果后才会进行动态分析
- 基础动态分析常使用以下几种方式:
  - 沙箱: 优点是可读性高,分析速度快,一目了然. 缺点是需要将样本提交至沙箱平台,可能会泄露客户隐私
  - 通过 `rundll32` 来运行dll样本 `rundll32 xxxx.dll, ExportFunc`
  - 通过手动擦除PE头中的dll标记来运行dll样本,但是只能运行DllMain中的内容,并且容易造成崩溃
  - 使用行为监视器来监控样本行为, 推荐 `ProcessMonitor` 和 `火绒剑`
  - 使用进程浏览器来监控样本进程情况,如内存块、模块、句柄等 推荐 `Process Explorer` 和 `火绒剑`
    - ProcExp: 粉色->服务进程 蓝色->普通进程 绿色->新进程 红色->已终止进程
  - 使用 `Regshot` 来比较样本运行前后注册表项值得变化
  - 当需要分析样本得网络交互行为时,可以使用以下工具:
    - ApateDNS 用于劫持样本发起得请求来返回虚假的响应数据
    - Netcat监听样本发起的请求内容
    - WireShark用于截获网络封包并加以分析, 后文将会详细讲解网络封包与wireshark使用
    - INetSim用于模拟网络服务,包括dns http https smtp irc等等
