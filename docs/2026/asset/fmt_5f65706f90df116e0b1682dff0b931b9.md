
# 通过修改PE加载DLL

## 一：概述

前面的创建远程线程进行注入等都是直接向"运行中的进程"强制注入DLL。而**通过直接修改目标程序的可执行文件，使其在运行时就加载指定的dll文件。**这种方法只需要更改一次，之后每当程序运行时就会自动加载指定的dll文件。所以这其实是一种破解方法。

#### 2. InternetOpen

概况：初始化一个应用程序，以使用 WinINet 函数。

为了使网络连接生效，必须用函数`InternetOpen`函数创建一个`HINTERNET`根句柄。`InternetOpen`函数接收的参数为：用户代理信息（访问Internet函数的应用），访问网络的类型，代理主机和地址以及代理的行为动作。

`InternetOpen`的第一个参数`lpszCallerName`指定正在使用网络函数的应用程序。当HTTP协议使用时，这个名字将变成用户代理。

**函数声明：**

```cpp
HINTERNET InternetOpen(
_In_ LPCTSTR lpszAgent,
_In_ DWORD dwAccessType,
_In_ LPCTSTR lpszProxyName,
_In_ LPCTSTR lpszProxyBypass,
_In_ DWORD dwFlags
);
```

**参数**

**lpszAgent**

指向一个**空**结束的字符串，该字符串指定调用WinInet函数的应用程序或实体的名称。使用此名称作为用户代理的<a href="elink@ae3K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8V1S2f1g2q4m8Q4x3U0g2q4y4g2)9J5y4e0S2p5i4K6t1#2z5p5k6Q4x3U0g2q4z5q4)9J5y4f1q4q4i4K6t1#2b7f1g2Q4x3V1j5I4x3U0M7$3z5e0b7J5">HTTP协议</a>。

**dwAccessType**

指定访问类型，参数可以是下列值之一：

<a href="elink@e61K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2F1L8%4c8A6L8$3&6Q4x3X3g2K6L8#2)9J5c8X3k6V1z5e0b7H3j5$3j5J5j5h3c8T1j5e0b7%4k6o6t1^5z5r3t1^5x3o6c8T1x3K6q4X3y4h3x3#2z5h3p5&6">Untitled</a>

**lpszProxyName**

指针指向一个空结束的字符串，该字符串指定的代理服务器的名称，不要使用空字符串；如果`*dwAccessType*`未设置为**`INTERNET_OPEN_TYPE_PROXY`**，则此参数应该设置为NULL。

**lpszProxyBypass**

指向一个空结束的字符串，该字符串指定的可选列表的主机名或IP地址。如果`*dwAccessType*`未设置为`INTERNET_OPEN_TYPE_PROXY`的，参数省略则为NULL。

**dwFlags**

参数可以是下列值的组合：

<a href="elink@933K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2F1L8%4c8A6L8$3&6Q4x3X3g2K6L8#2)9J5c8U0l9#2j5U0R3I4k6h3c8X3x3o6j5K6x3e0c8T1x3K6u0S2j5X3q4U0y4h3t1@1x3$3f1H3x3r3x3K6j5h3j5H3">dwFlags</a>

**返回值**

成功：返回一个有效的句柄，该句柄将由应用程序传递给接下来的WinINet函数。

失败：返回NULL。

#### 3. InternetOpenUrl

通过一个完整的FTP，Gopher或HTTP网址打开一个资源。

**函数声明:**

```cpp
HINTERNET InternetOpenUrl(
HINTERNET hInternet,
LPCTSTR lpszUrl,
LPCTSTR lpszHeaders,
DWORD dwHeadersLength,
DWORD dwFlags,
DWORD_PTR dwContext)
```

**参数：**

hInternet

**当前的 Internet 会话句柄。句柄必须由前期的 InternetOpen 调用返回。**

lpszUrl

**一个空字符结束的字符串变量的指针，指定读取的网址。只有以ftp:, gopher:, http:, 或者 https: 开头的网址被支持。**

lpszHeaders

一个空字符结束的字符串变量的指针，指定发送到HTTP服务器的头信息。欲了解更多信息，请参阅<a href="elink@f14K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8V1S2@1N6s2m8e0k6h3&6V1f1X3g2I4N6h3g2K6N6q4)9J5c8U0R3J5y4e0x3K6x3K6R3`.`">HttpSendRequest</a>函数里`lpszHeaders`参数的说明。

dwHeadersLength

dwFlags

此参数可为下列值之一。

数值 说明

`INTERNET_FLAG_EXISTING_CONNECT`

如果使用相同的必须属性<a href="elink@23dK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1#2i4K6t1#2z5o6S2Q4x3U0f1&6b7W2)9J5y4f1f1#2i4K6t1#2b7V1u0Q4x3U0g2n7b7g2)9J5y4f1f1@1i4K6t1#2b7V1y4Q4x3U0f1&6b7g2)9J5y4f1f1^5i4K6t1#2b7f1k6Q4x3U0f1&6c8l9`.`." >创建会话</a>，会尝试利用现有的`InternetConnect`对象。这只对FTP操作非常有用，因为FTP是唯一在同一会话中执行多种操作的协议。WinINet API 为每个由<a href="elink@939K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8V1W2F1N6r3g2J5L8X3g2@1e0%4m8W2L8W2)9J5c8U0f1I4x3K6R3#2z5o6j5`.`">InternetOpen</a>产生的`HINTERNET`句柄缓冲一个单独链接句柄。`InternetOpenUrl`使用此标志的HTTP和FTP连接。

`INTERNET_FLAG_HYPERLINK`

当决定何时从网络<a href="elink@7e6K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1&6i4K6t1#2z5o6N6Q4x3U0f1^5c8q4)9J5y4f1f1^5i4K6t1#2b7V1c8Q4x3U0g2n7c8l9`.`." >重载</a>时，如果服务器没有返回 Expires time 和 LastModified，那么强制重载。

`INTERNET_FLAG_IGNORE_CERT_CN_INVALID`

停用检查从服务器对必须的<a href="elink@ba4K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1@1i4K6t1#2b7U0S2Q4x3U0g2n7b7W2)9J5y4f1f1$3i4K6t1#2z5f1y4Q4x3U0g2n7b7b7`.`." >主机</a>名称返回的SSL/PCT-based证书。 WinINet函数使用简单的比较匹配主机名称和<a href="elink@1e6K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1&6i4K6t1#2z5o6m8Q4x3U0f1&6b7g2)9J5y4f1f1&6i4K6t1#2z5o6g2Q4x3U0f1^5c8q4)9J5y4f1f1%4i4K6t1#2b7f1y4Q4x3U0g2m8y4R3`.`." >通配符</a>的规则检查证书。

`INTERNET_FLAG_IGNORE_CERT_DATE_INVALID`

停用检查的SSL/PCT-based的证书的适当的有效日期。

`INTERNET_FLAG_IGNORE_REDIRECT_TO_HTTP`

禁用检测这中特殊的<a href="elink@c12K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1&6i4K6t1#2z5o6N6Q4x3U0f1^5c8q4)9J5y4f1f1#2i4K6t1#2b7f1g2Q4x3U0f1&6b7g2)9J5y4f1f1#2i4K6t1#2z5e0m8Q4x3U0f1&6x3g2)9J5c8U0V1H3y4U0b7I4z5e0j5`.`">重定向</a>。当使用此标志， WinINet 透明允许从HTTPS到HTTP URL的重定向。

`INTERNET_FLAG_IGNORE_REDIRECT_TO_HTTPS`

`INTERNET_FLAG_KEEP_CONNECTION`

如果可能的话，为连接使用保活语义。这个标志要求微软网络（ MSN ），<a href="elink@92eK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8V1&6f1e0p5#2Q4x3V1j5$3x3K6M7I4x3U0V1^5">NTLM</a>和其他类型的身份验证。

`INTERNET_FLAG_NEED_FILE`

如果要创建的文件不能被<a href="elink@6ccK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1%4i4K6t1#2b7V1y4Q4x3U0f1&6x3#2)9J5y4f1f1#2i4K6t1#2b7f1c8Q4x3U0f1&6z5l9`.`." >缓存</a>，创建<a href="elink@061K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1@1i4K6t1#2b7U0S2Q4x3U0g2n7y4q4)9J5y4f1f1$3i4K6t1#2z5e0N6Q4x3U0g2n7y4W2)9J5y4f1f1$3i4K6t1#2z5e0k6Q4x3U0f1^5y4#2)9J5y4f1f1@1i4K6t1#2b7V1u0Q4x3U0g2n7y4W2)9J5c8U0x3K6y4e0V1J5x3o6V1`.`">临时文件</a>。

不自动处理<a href="elink@a86K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8V1S2@1N6s2m8e0k6h3&6V1f1X3g2I4N6h3g2K6N6q4)9J5c8U0R3J5y4e0x3K6x3K6R3`.`">HttpSendRequest</a>中的<a href="elink@be1K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1j5h3W2C8k6g2)9J5k6h3u0S2K9h3c8#2i4K6u0W2j5$3!0E0i4K6u0r3K9i4c8W2L8g2)9J5c8W2)9J5y4f1f1&6i4K6t1#2z5o6N6Q4x3U0f1^5c8q4)9J5y4f1f1#2i4K6t1#2b7f1g2Q4x3U0f1&6b7g2)9J5y4f1f1#2i4K6t1#2z5e0m8Q4x3U0f1&6x3g2)9J5c8U0V1H3y4U0b7I4z5e0j5`.`">重定向</a>。
