A——取位 `&7` 对于二进制位的设置

17、`setmem`

原型：`extern void setmem(void *buf, unsigned int count, char ch);`

用法：`#include <string.h>`

功能：把`buf`所指内存区域前`count`个字节设置成字符`ch`。

在`vc`环境中好像没有，`msdn`中也没有找到该函数。

18、`movmem`

`char`类型本身主要考虑到内存的基本单位字节而引入，因此对于字符串函数中有一些内存操作函数。
