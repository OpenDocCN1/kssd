
# [分享]对18年稍微做个总结吧

兜兜转转已经从一个小孩成长了一个大人,这一年迷茫过,焦虑过,失眠过,自卑过,爱过恨过.从一个从来不喝酒的人,到现在能喝几瓶啤酒了.从一个视金钱如粪土的愣头青,到知道金钱对于一个人其实也蛮重要的.从一个技术小白,到现在依然是小白.从前总是很害羞,到现在不是那么的害羞.从前总是急于求成,最后一事无成.

"怎么20多年到头来,还在人海里浮沉.像我这样聪明的人,早就告别了单纯.怎么还是用了一段情,去换一身伤痕 .像我这样迷茫的人,像我这样寻找的人,像我这样碌碌无为的人...."—<像我这样的人>.这是毛不易的歌,现在听起来好像挺应景的(眼角已经泛起了泪水).现在的我,对未来依然迷茫,但却不悲观.对朋友真诚以待,希望朋友也能真诚的待我.对未来依然充满了幻想,是比儿时的幻想要现实一些的幻想.这就是我吧,看起来还是那么的幼稚对吧.

今年来北京更好一年时间了,这一年里遇到了许多有趣的人.记得来北京的时候兜里只有5000块钱,这过程中遇到了许多小哥哥,小姐姐,在生活上帮我许多忙,我也一直记在心里.到现在有一份稍微稳定的工作. 一个简简单单,平平淡淡的一年吧,我想你也没有太多兴趣听我的故事.我也不太擅长向别人说我的故事,你知道的我们搞逆向的人都比较内敛.

说了那么多抒情,无病呻鸣的话.对我今年接触的逆向也稍微作一下总结吧(全靠回忆).
