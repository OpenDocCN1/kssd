
# [翻译]无需文件的UAC绕过方式：使用`eventvmr.exe`和注册表劫持

原文提供的`powershell`脚本我跑不出预期行为，由于对`powershell`不太熟悉，所以不知道什么原因。

不过，在默认账户权限下，手动构建`HKCU\Software\Classes\mscfile\shell\open\command`，将“(默认)”设为`REG_SZ`类型并将数据值修改为指定路径下的可执行文件，指定的应用程序就会以High Integrity Level启动，启动的进程具有管理员权限。这证明该方法确实可以BypassUAC
