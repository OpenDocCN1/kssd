
1. 使用上一步的 xml 文件重命名 RPC 服务器接口的某些特定部分，以便后续使用

```powershell
Get-Content "names.xml" | Set-RpcServerName $rpc
```

2. 创建基于 RPC 服务器的客户端对象，并将客户端连接到本地 RPC 服务器的 ALPC 端口

```powershell
$client = Get-RpcClient $rpc
Connect-RpcClient $client
```

3. 定义 `Start-Uac` 函数，该函数调用通过 `RAiLaunchAdminProcess` 接口返回一个 `NtProcess` 对象，该对象可用于访问已创建进程的属性，包括调试对象。默认传递 `DEBUG_PROCESS` 标志来创建进程，并使用 `RunAsAdmin` 参数来选择是否提升进程权限
