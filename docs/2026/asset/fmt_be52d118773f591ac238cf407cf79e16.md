# Python VMP

现在有了 LLTRACE 的功能，但是要实现 `ether\_v2.py` 的追踪还需要解决几个问题:

1. LLTRACE 的启用需要在当前栈帧上定义全局变量 `\_\_lltrace\_\_`；
2. LLTRACE 输出的字节码过于简略，缺乏可读性；
3. LLTRACE 输出的字节码是运行的代码，也就是循环展开后(flatten)的代码，进一步影响逆向分析；

所以我使用了一个简单粗暴的方法，即直接修改 CPython 源代码。首先在判断 `lltrace` 启用的地方修改判断从 `f->f\_globals` 改为递归搜索 `f->f\_back->f\_globals`，这样只要在我们的调用栈帧定义变量即可；对于字节码的输出，最好是可以有类似 `dis` 模块的显示效果，至于平坦化的控制流，可以根据指令 `index` 再重新进行组合。

## Dynamic Trace

在 LLTRACE 的基础上，我们可以比较简单地修改出一版具有可读性的 Trace 代码，以下面的源码为例:

```python
# test.py
\_\_pztrace\_\_ = 1
def validate(s):
if len(s) != 4:
return False
cc = 0
for i in s:
cc ^= ord(i)
if cc == 0:
return True
return False
s = raw\_input('Your input: ')
if validate(s):
print 'ok'
else:
print 'failed'
```
