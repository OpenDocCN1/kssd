解决方法很多，我说几种：

第一种是我以前用的一种比较挫的，其实最重要的是解决监控哪里：

分 2 步：
1. 在监控哪里跳走或者直接返回。
2. 注意我标的清零的 2 段代码：

```
mov     ecx, dword_100D1C0  //这里比较关键啦。
mov     edx, offset dword_100D1C0
cmp     ecx, edx
jz      short loc_10026BA // 这个是个关键比较啦
```

在函数开头钩钩一下跳到我们的函数，处理一下先查找到模块加载地址（`Modulebase`）。

伪代码：

```
ULONG D1C0 = Modulebase + 0XD1C0;

_asm {
    mov edi,edi
    push ebp
    mov ebp,esp
    mov eax,D1C0
    mov [eax],eax
    mov eax,Ret(返回地址)
    add eax,5
    jmp eax
}
```

`jz short loc_10026BA` 相等就跳啦。
