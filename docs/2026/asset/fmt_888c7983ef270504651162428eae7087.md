# 总结

在公司环境中使用VoIP的好处是巨大的。它是成本效益;规模经济可以实现，并提供更好的音质。但是，存在的风险是，安全工程师应该在启用服务器之前检查VoIP服务器的安全性，即它的开放端口。攻击你的网络，并在黑客扫描和利用它之前保护它。
