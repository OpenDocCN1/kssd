10月10日，经过这几天的分析，我终于发现实际上序列号是使用 RSA 的方法计算的。

主要是：

- 用户序列号 `S`（`BigInteger`）
- 授权信息 `I`（`BigInteger`）`toByteArray()` -> 授权数据

其中 `LicenseDecoder` 中的 `BigInteger a` 为 RSA 公钥的指数部分，`LicenseDecoder` 中的 `BigInteger b` 为 RSA 公钥的指数部分。

由于 IntelliJ 公司有 RSA 的私钥，所以只有该公司才可以生成符合格式的序列号。

对于这种方式，我们需要将 `a`、`b` 替换为我们的公钥参数，并且使用我们的私钥参数（`e`、`b`）执行序列号生成：

```java
byte [] buf = .... // 根据格式生成授权数据
```
