
# [原创]`Trojan-Spy.AndroidOS.Zitmo.a`病毒分析

- 病毒名：`Trojan-Spy.AndroidOS.Zitmo.a`
- 病毒大小：202.62K
- MD5：`2dfccca5a9cdf207fb43a54b2194e368`
- 病毒简介：这是一个伪装成“Android Security Suite Premium”安全软件的病毒，该病毒会获取被感染的手机的短信息上传至远程服务器。

![](https://bbs.kanxue.com/upload/attach/201207/302053_aa5k2nxb4qy8r1y.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_mggzeq42savx6gg.jpg)

## 详细分析

### 1. 注册消息

病毒注册并响应了3个消息，分别是：启动完成、监控拨出电话、接收短信，以便实现对应的功能。

![](https://bbs.kanxue.com/upload/attach/201207/302053_f5c0pzfemg114b1.jpg)

**注册服务：**实现服务的定时启动

![](https://bbs.kanxue.com/upload/attach/201207/302053_6klpbthzobshi04.jpg)

### 3. 代码分析

伪装成安全软件的样子，打开需要获取激活码。激活码为“1”+手机IMEI号的前7位+“3”。

![](https://bbs.kanxue.com/upload/attach/201207/302053_70mcyos1oueztis.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_mgjaql7mki1tka8.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_869dfs7gnunuy8j.jpg)

开机3分钟后自动启动服务：

![](https://bbs.kanxue.com/upload/attach/201207/302053_qgnfxdez3b0paym.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_0bzzjrf7zs7ff2t.jpg)

此后每隔1500s发送一次报告

![](https://bbs.kanxue.com/upload/attach/201207/302053_clxd2o9vz7o4c4c.jpg)

该程序能够接收控制命令，控制命令以接收到的信息的第一个字符为依据，进行相应操作：

如果接收到的短信以 `#` 开始，则获取短信信息，同时提取短信中的号码并发送报告。

![](https://bbs.kanxue.com/upload/attach/201207/302053_73o0utn49mq78c5.jpg)

如果接收到的短信以 `/` 开始，则更新号码并保存，同时提取短信中的号码并发送报告。

![](https://bbs.kanxue.com/upload/attach/201207/302053_79ii56g6faeacj6.jpg)

如果接收到的短信以 `!` 开始，则卸载软件，同时提取短信中的号码并发送报告。

![](https://bbs.kanxue.com/upload/attach/201207/302053_mq7crvimn1nf66p.jpg)

如果接收到的短信以 `,` 开始，则清除控制信息，同时提取短信中的号码并发送报告。

![](https://bbs.kanxue.com/upload/attach/201207/302053_mgqs8blbkpyk4da.jpg)

发送报告的方式有两种：`SMS`方式和`http`方式。

首先获取手机版本号，硬件制造商，版本字符串等信息，以`SMS`方式发送报告，格式为`"Model:%s AC:%s H:%d AltC:%d V:%s Mf:%s/%s"`。

![](https://bbs.kanxue.com/upload/attach/201207/302053_48mc28g16re4ncd.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_5e5wyhm76jm3l27.jpg)

以`http`方式发送，报告格式为`?to=%s&i=%s&m=%s&aid=%s&h=%s&v=%s`。

![](https://bbs.kanxue.com/upload/attach/201207/302053_aad6jm9g7bvur9a.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_kr8uzxibd5hs6gp.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_qlqawklhkh0dv7z.jpg)

![](https://bbs.kanxue.com/upload/attach/201207/302053_wskiyrlckq2fv7b.jpg)

获取收件箱中短信内容：

![](https://bbs.kanxue.com/upload/attach/201207/302053_tszx826r9euwnle.jpg)

将短信发送给远程服务器的格式为：`&from=%s&text=%s`，如果是最后一条短信，则在参数后面加上`&last=1`。

![](https://bbs.kanxue.com/upload/attach/201207/302053_7cdedyarxsm0vqd.jpg)
