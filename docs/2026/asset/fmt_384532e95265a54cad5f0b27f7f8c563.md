
# [原创]AsPack2.12分析及静态脱壳机的编写

科锐第四阶段作业题。由于去科锐才开始学的c、c++和asm，所以分析得不是很好。脱壳机的代码写得也比较幼稚，不足之处请大家多多见谅。

用asm写了个hello world，然后用AsPack2.12加壳，直接IDA载入分析。
