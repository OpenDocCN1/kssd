# 补丁分析

对比一下补丁前后的文件变化，可以看到只有 `cng!CfgAdtpFormatPropertyBlock` 函数发生了变化

![CVE-2020-17087-17.png](https://bbs.kanxue.com/upload/attach/202203/924781_PHPXJ44HRQCTVND.jpg)
