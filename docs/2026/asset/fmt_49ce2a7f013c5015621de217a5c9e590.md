
# [原创]VBScript Scripting Engine初探

近来分析Internet Explorer历史漏洞，遂对VBScript脚本解析引擎进行研究，具体环境如下：

- OS版本：Windows 7 Service Pack 1
- Internet Explorer版本：8.0.7601.17514
- `vbscript.dll`版本：5.8.7601.17514

## 0x02 数组

数组存储结构由`SAFEARRAY`定义：

```
typedef struct tagSAFEARRAY {
USHORT cDims;
USHORT fFeatures;
ULONG cbElements;
ULONG cLocks;
PVOID pvData;
SAFEARRAYBOUND rgsabound[1];
} SAFEARRAY;
```

其中各字段含义可参阅<a href="elink@09aK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6V1L8$3y4K6i4K6u0W2L8h3W2U0M7X3!0K6L8$3k6@1i4K6u0W2j5$3!0E0i4K6u0r3k6h3&6Q4x3X3c8#2M7#2)9J5c8Y4N6A6L8X3c8G2N6%4y4Q4x3V1k6%4K9h3^5K6x3W2)9J5c8X3q4H3K9g2)9J5c8X3!0S2K9h3c8D9i4K6u0r3L8Y4y4Q4x3X3c8G2j5h3W2V1L8q4)9J5k6s2y4S2k6X3g2S2M7Y4u0S2P5b7">Microsoft Docs——SAFEARRAY</a>，`SAFEARRAYBOUND`结构定义如下：

```
typedef struct tagSAFEARRAYBOUND {
ULONG cElements;
LONG lLbound;
} SAFEARRAYBOUND, *LPSAFEARRAYBOUND;
```

数组定义及赋值操作：

```
Dim stu_name(3)
stu_name(0)="Alan"
stu_name(1)="Susan"
stu_name(2)="Lisa"
stu_name(3)="Mary"
```

VBS中数组下标由0开始，数组元素个数为n+1(`Dim array_name(n)`)。另一种定义数组方法：

```
Dim stu_name
stu_name=Array("Alan","Susan","Lisa","Mary")
```

## 0x03 可用于调试时函数

`IsEmpty(var)`对应`vbscript!VbsIsEmpty`，其第三个参数对应`var`。一例：

```
<!doctype html>
<html lang="en">
<head>
</head>
<body>
<script LANGUAGE="VBScript">
dim a
a = &h1234
IsEmpty(a)
</script>
</body>
</html>
```

![](upload/attach/202103/817966_9NSGR4QNPXEJFHE.jpg)

`IsObject(var)`对应`vbscript!VbsIsObject`，同样，其第三个参数对应`var`。一例：

```
<!doctype html>
<html lang="en">
<head>
</head>
<body>
<script LANGUAGE="VBScript">
dim a
a = &h1234
IsObject(a)
</script>
</body>
</html>
```

![](upload/attach/202103/817966_AS3GQXKJMHXJNE4.jpg)

## 0x05 LenB函数

```
<!doctype html>
<html lang="en">
<head>
</head>
<body>
<script LANGUAGE="VBScript">
On Error Resume Next
Dim length,a
a=1.12345678901235
length=LenB("Hello")
length=LenB(a)
</script>
</body>
</html>
```

该函数用于返回存储字符串字节大小，其对应`vbscript!VbsLenB`。参数为字符串时，该函数先是`call VAR::BstrGetVal`，返回`pbstrVal`：

![](upload/attach/202103/817966_5C7A5ESMFF7RJF8.jpg)

参数为变量时， `VAR::BstrGetVal`函数调用`VAR::PvarConvert`，将其内容转换为字符串：

![](upload/attach/202103/817966_URAAWRGCZ5AP82C.jpg)

之后再进行计算：

![](upload/attach/202103/817966_CRB2XMPZ44C83GM.jpg)
