# 总结

在`initiallize`函数中先创建200个`HTML`对象方便后面进行内存覆盖，之后调用`spray_heap`进行堆喷射，堆喷射就是申请了200块大内存，

并在每一块内存中都填入`payload`，在处理`HTML Img` 对象的`onload`事件时调用`ev1`函数创建当前事件对象的副本，创建副本对象时会关联`CTreeNode`，当产生对象关联后又立刻清空名为`"sp1"`的`span`对象，`span`对象被释放将导致 与 `CEventObj`副本对象关联的`CTreeNode`被释放，接着重复调用`ev2`，`ev2`函数中对

200个`HTML`对象

的数据进行赋值，值的内容为`0x0A0A0A0A`，而关键是每次赋值都会申请空间，一旦申请到了被释放得`CTreeNode`就会把`0x0A0A0A0A`覆盖进去，产生覆盖后又调用副本对象的`srcElement`，执行`get_srcElement`函数时会访问与`CTreeNode`，此时

`CTreeNode`已经错误了，也就导致了`payload`的执行。
