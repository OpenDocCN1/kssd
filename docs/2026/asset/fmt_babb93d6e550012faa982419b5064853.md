# ShellExecute函数逆向

`ShellExecute`在`Shell32.dll`中，大致执行流程如下图所示，我们只关注的核心的标红函数，这三个函数是最终的问题所在，但他们不在`Shell32.dll`而是在`Shlwapi.dll`中。

![](https://bbs.kanxue.com/upload/attach/202402/967913_W5MJHH8EKBCRVR5.webp)

## PahtFileExistsDefExtAndAttributesW

路径字符串末尾为空格或"\"就会返回指向`NULL`的指针(windwos文件系统在创建文件时首部和尾部会自动把空格清除)。

![](https://bbs.kanxue.com/upload/attach/202402/967913_ZRXPJR4XNR85PNN.webp)

## PathFindExtensionw

该函数没找到符号文件,IDA解析时有问题，故用了另一位博主`B1tg`的图。通过伪代码可以看出如果路径长度超过最大长度或在最后一个点后再次出现空格或\都会返回指向`NULL`的字符串指针，即未找到后缀名。这也是为什么把最后一个字符串改成空格的原因。

![](https://bbs.kanxue.com/upload/attach/202402/967913_RSA2MP3VEE8QPFC.webp)

当未找到后缀名时会进入`sub_63192842`函数中

## sub_63192842

这个函数的主要功能是遍历当前路径下的所有文件，并将文件后缀和一个数组比较，数组中是windwos系统下常见可执行文件的后缀名

![](https://bbs.kanxue.com/upload/attach/202402/967913_V9XN4BWV4RRPFNM.webp)

对遍历到的文件进行比对，返回数组下标。

![](https://bbs.kanxue.com/upload/attach/202402/967913_EMZF8NHACXQRF5X.webp) ![](https://bbs.kanxue.com/upload/attach/202402/967913_FYTQPR6HAWWYZC2.webp)

所以`test.txt`文件因为`.`后面出现的空格返回了`Null`，导致`if`中的表达式为`False`，于是进入了`sub_63192842`函数中，搜索到了`test.txt .cmd`文件，最终该文件被返回并设置了进程创建的参数完成了代码执行。

当然如果同一路径下也没发现这6种可执行路径的后缀则会启动`rundll32`程序，加载`shell32`的`OpenAs_RunDLL`函数弹出对话框，让用户选择要执行的程序
