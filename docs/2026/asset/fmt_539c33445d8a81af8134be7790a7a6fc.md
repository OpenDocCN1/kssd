2. `prev_inuse == 1`
3. `((unsigned long) old_end & (pagesize - 1)) == 0` 页对齐
4. `(unsigned long) (old_size) < (unsigned long) (nb + MINSIZE)` 新申请的 `size` 大于 `old_size + MINSIZE`
