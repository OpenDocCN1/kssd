## 软件简介

本软件可以用来设计、打印各种类型的证件、卡片。本系统具有以下特点: 1.界面友好，操作简单。本系统采用所见即所得的排版编辑方式。无需任何培训即可上手使用 2.文档支持丰富的元素数据，包括条形码、图像、各种图形，文本等 3.强大的数据库支持，支持任意类型的关系数据库（SQLServer，FoxPro，Access等），支持从数据库读取数据（包括文本数据和图像数据）并动态显示、打印 4.灵活的打印功能。用户可以根据纸张和文档大小任意设置每页打印的行数和列数。支持条形码自动增加连续打印（特别适合于图书馆打印馆藏条码） 5.其他功能：真正所见即所得编辑方式，屏幕显示大小于打印大小真实一致；照片打印按照真实比例自动缩放，不用担心打印出来的照片变形，条码采用高质量的True Type字体。更清晰 6.更丰富的排版功能（增加了“层”的概念，卡片元素可以上下浮动，以避免被遮盖），增加了多选功能和复制粘贴功能 7.体验版本除不能保存、打开设计文档外，其他功能没有限制。

增加了注册功能，需要用户提供机器码

## 文章简介

重启验证注册码的程序，用RegMon很容易找到注册码保存的地方。

```
[HKEY_CURRENT_USER\Software\RegInfo]

"RegCode"="987654abcd"

"RegDate"="a"
```

注册码的计算过程用了浮点指令，略微增加了分析的难度。

该程序有使用10次的限制，即使注册码正确，没有过期时，程序不进行注册码的校验，所以要来到校验的地方，首先得让程序过期。
