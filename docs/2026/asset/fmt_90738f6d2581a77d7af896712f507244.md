### 前置知识

#### 格式化字符串漏洞原理

pwn题中，有形如下述代码的形式就是格式化字符串漏洞

```c
char str[100];
scanf("%s",str);
printf(str)
```

也许使用者的目的只是直接输出字符串，但是这段字符串来源于可控的输入，就造成了漏洞。

示例程序如下

```c
#include <stdio.h>
int main(){
char str[100];
scanf("%s",str);
printf(str)
}
```

编译：`gcc -m32 -o str str.c`

输入：`%2$x`
