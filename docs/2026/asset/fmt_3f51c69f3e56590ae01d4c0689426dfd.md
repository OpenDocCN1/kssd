
}

在`win32`中，我们都知道应用程序是消息驱动的，而在驱动模式中，可以把驱动理解为是IRP驱动的。驱动程序一般是分层结构，对设备的操作会转化为对HAL（硬件抽象层）的操作。IRP由I/O管理器创建，并传递给对应的驱动程序处理，而驱动程序调用我们在`DriverEnter`中注册的`pDriverObject->MajorFunction[IRP_MJ_CREATE] = HelloDDKDispatchRoutine;`函数来处理与之对应的IRP。
