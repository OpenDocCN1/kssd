## 六、补丁

只需把受影响的环境变量添加到拒绝列表中

```jsx
defaults!SUDOEDIT env\_delete+="SUDO\_EDITOR VISUAL EDITOR"
Cmnd\_Alias SUDOEDIT = sudoedit /etc/custom/service.conf
user ALL=(ALL:ALL) SUDOEDIT
```

## 一、前言

- 漏洞简介：Sudo中的`sudoedit`对处理用户提供的环境变量（如`SUDO_EDITOR`、`VISUAL`和`EDITOR`）中传递的额外参数存在缺陷。当用户指定的编辑器包含绕过`sudoers`策略的`--`参数时，拥有`sudoedit`访问权限的本地攻击者可通过将任意条目附加到要处理的文件列表中，最终在目标系统上实现权限提升（由普通用户到超级用户，即"root"）。

- 漏洞编号：CVE-2023-22809

- 漏洞等级：高危

- 漏洞评分：7.8分

- 影响版本：`sudo` 1.8.0-`sudo` 1.9.12p1 (`sudo`>=1.8.0 or `sudo` <=1.9.12p1)

- 攻击效果：本地提权
