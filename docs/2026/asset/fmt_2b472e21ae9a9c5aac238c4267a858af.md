# Limitations

1. 仅仅支持`[]byte` 和原始类型，不支持struct、slice和array
2. 在同一个pkg里不同运行多个fuzzer
3. 遇到crash会立即停止fuzz
4. 不能直接将现存的文件转换到语料库的格式

在 github上也可以在带有标签的issue上找到一些未解决和待改进的地方
