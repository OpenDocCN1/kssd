## 2. 拉取 Frida 源码

```bash
git clone --recurse-submodules https://github.com/frida/frida
git checkout 16.0.2
```

## 3. 修改配置项和部分源码

### 3.1 修改 Python 安装目录

修改 Frida 项目中的 `releng\frida.props` 文件，将以下部分修改为 Python 的安装目录。

原始内容：

```xml
<PythonLocation Condition="'$(PythonLocation)'=='' AND '$(Platform)'=='x64'">$(ProgramFiles)\Python310< / PythonLocation>
<PythonLocation Condition="'$(PythonLocation)'=='' AND '$(Platform)'=='Win32'">$(MSBuildProgramFiles32)\Python310< / PythonLocation>
```

例如修改为：

```xml
<PythonLocation Condition="'$(PythonLocation)'=='' AND '$(Platform)'=='x64'">C:\Users\29265\AppData\Local\Programs\Python\Python310< / PythonLocation>
<PythonLocation Condition="'$(PythonLocation)'=='' AND '$(Platform)'=='Win32'">C:\Users\29265\AppData\Local\Programs\Python\Python310-32< / PythonLocation>
```

### 3.2 修正 Vala 相关文件

修正 Vala 相关文件，将 `“%s”` 修改为 `\"%s\"`。

例如：

原始内容：

```vala
throw new Error.NOT_SUPPORTED ("Unsupported ABI: “%s”; please file a bug", abi);
```

修改为：

```vala
throw new Error.NOT_SUPPORTED ("Unsupported ABI: \"%s\"; please file a bug", abi);
```

> **注意：**以下步骤需要在全局代理的情况下进行，同时对 Git 设置代理，例如：

```bash
git config --global http.proxy http:127.0.0.1:1080
```

## 4. 构建 Frida 依赖

使用 Visual Studio 2020 打开 `frida.sln`，先构建 `frida-deps`：

【资源管理器】→【frida-deps】→【生成】

## 5. 编译 Frida Python 模块

编译完成后，点击 `frida-python` →【生成】→【生成解决方案】，即编译完成。

## Run

编译完成后验证是否可用，编写 Python 脚本使用它（`venv`）。

### 1. 准备验证脚本

在 `\build\frida-windows\x64-Release\lib\python3.10\site-packages` 目录下启动 `cmd`，同时放入 `test.py` 验证文件。

验证脚本 `test.py`：

```python
import sys
print(sys.path)
sys.path.append("D:\frida\_source\frida\build\frida-windows\x64-Release\lib\python3.10\site-packages")
import frida
proname = r'notepad.exe'
session = frida.attach(proname)
script = session.create\_script('''
rpc.exports.eM = function (){
return Process.enumerateModules();
};
''')
def on\_msg(msg,data):
print("[signal message] msg:", msg,"data":", data)
script.on('message',on\_msg)
script.load()
ms = script.exports.e\_m()
print([m['name'] for m in ms])
```

### 2. 打开记事本

打开一个记事本。
