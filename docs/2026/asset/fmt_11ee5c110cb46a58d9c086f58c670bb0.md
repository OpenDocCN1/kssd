00AC75F6     EB 01                   jmp short 00AC75F9

每人的机子不一样数值也不一样，我这里的 `esi` 有三个值 `96`、`77`、`89`（这几个数值好像每天都不一样），其中 `esi` 的值为 `77`、`89` 时 `00AC75F4` 处的跳转成立，但两个数中只有当 `esi=77` 时才会对 IAT 进行加密，因此只要将 `77` 改为 `89` 就可以避开 IAT 加密了。

好，就在 `00AC75F4` 进行修改，先用 OD 插件 memory manage 申请一个内存空间，lchhome 用的是 `01640000`，为了方便我也用 `01640000`，把 `00AC75F4` 改为：

```
00AC75F4  75F4  - E9 078A3500     JMP 01640000
```

然后下 F2 断点，F9 运行中断后，F7 跟进。

把修改代码写进去：

```
01640000   - 0F84 F37548FF           je 00AC75F9------这个是00AC75F6 处jmp的地址
```
