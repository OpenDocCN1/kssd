为了可持续开发，我们的目标不仅仅是本次的二次开发，我们还需要为未来的第N次开发做好规划；所以在地址空间布局上我们采用增加单独段的方式去扩展，而不是缝隙法；为此我们新增一个 `.mynpd` 数据段及 `.mynpc` 代码段，同时将来布置代码时，新增代码段中的各个代码块之间的间隔布置的大一点，以免未来扩充或者改动时发现没有空间，只好 `jmp` 来 `jmp` 去，那样不管在性能还是代码可读性上都比较差一点；

首先我们跳转到原先 `call NPInit` 的地方（`0100297B`），采用 `JMP 01016000` 指令来替换，使其跳转到我们新增的地址空间中去，然后我们在 `01016000` 地址处新增代码，具体如下：

```asm
;初始操作逻辑处理处

01016000  CALL    mynotepa.NPInit               ;先调用原先的NPInit函数

01016005  TEST    EAX, EAX

01016007  JE      mynotepa.01002980             ;如果NPInit()==FALSE,则直接返回原逻辑处

0101600D  PUSH    DWORD PTR DS:[hwndNP]         ;参数是hwndNP

01016013  CALL    mynotepa.01016401             ;InitMyNotepad：用于初始化置顶、透明度设置

01016018  PUSH    DWORD PTR DS:[hwndNP]         ;参数是hwndNP

0101601E  CALL    mynotepa.01016A00             ;调用我们插件DLL的初始化函数

01016023  JMP     mynotepa.01002980             ;处理完后再返回到原逻辑处
```

其中 `DS:[hwndNP]` 是 `Notepad` 窗口的句柄，在跟踪 `NPInit` 的时候，可以看到其创建完窗口后会把句柄保存到 `hwndNP` 中，我们在初始化的时候正好可以拿来用；
