
- `+4 CurrentThread`：当前 CPU 正在运行的线程。
- `+8 NextThread`：将要切换的线程。
- `+C IdleThread`：如果没有要切换的线程，CPU 将要运行的空闲线程。

其余字段在后续分析内核代码时再了解。

# 2. EPROCESS 结构

在 3 环下，每个进程都有一个 `PEB` 结构，用来描述这个进程的一些信息。这些信息仅是为了 3 环更好地操作进程。而在 0 环，每个进程又有一个结构体用于描述该进程的所有信息：`EPROCESS`。
