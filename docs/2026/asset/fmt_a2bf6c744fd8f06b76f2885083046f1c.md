此处还有一个坑，虽说破解成功，但使用`ida`进行调试时总是失败，仅可以附加查看信息，不可下断点进行调试。

最后找到原因时应为应用程序本身未开启`debuggable`权限，需要在`AndroidMinifest.xml`文件中添加`android:debuggable="true"`后进行重编译！

![图片描述](https://bbs.kanxue.com/upload/attach/202306/945390_2RTS6M88W3AVVQQ.png)

还有一个办法就是使用`mprop`工具修改`ro.debuggable`的值为`1`。这个方法就是有个缺点，每次手机重启都需重新操作一遍。

下载`mprop`工具：[6a6K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6%4M7s2k6K6P5h3!0#2i4K6u0r3L8i4m8J5L8%4l9`.](https://bbs.kanxue.com/elink@9a5K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6%4M7s2k6K6P5h3!0#2i4K6u0r3L8i4m8J5L8%4l9`.)，具体操作步骤如下：

| 步骤 | 操作 |
| --- | --- |
| 1 | `adb push mprop /data/local/tmp`：将下载好的`mprop`工具放入`/data/local/tmp`当中 |
| 2 | `adb shell` |
| 3 | `su` |
| 4 | `cat default.prop \| grep debug`：查看`default.prop`里面的配置值，此处是`0` |
| 5 | `getprop ro.debuggable`：获取`ro.debuggable`，此处应该是`0` |
| 6 | `cd /data/local/tmp` |
| 7 | `chmod 777 mprop`：修改权限 |
| 8 | `./mprop ro.debuggable 1`：修改`ro.debuggable`的值为`1` |
| 9 | `cat default.prop \| grep debug`：查看`default.prop`里面的配置值，此处应该还是`0` |
| 10 | `getprop ro.debuggable`：获取`ro.debuggable`，此处应该是`1` |

修改完成后，执行命令`adb shell getprop | findstr debuggable`，查看手机的`ro.debuggable`参数值。

提示：`[ro.debuggable]: [1]`即成功。
