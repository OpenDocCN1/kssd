
# DotNet2.0程序运行不起来的解决办法

今天运行一个`.net`程序，由于程序是`.net2.0`框架的，在我的电脑上运行报错。如下图：

![](upload/attach/202207/26484_D3PG7AS59CEZ6E5.png)

难道就非要安装这个框架吗？我电脑上已经有`4.0`的框架了。

那就为这个程序做做手术吧，让它变成一个`4.0`框架的程序吧。

用`CFF Explorer`打开程序，如下图：

![](upload/attach/202207/26484_AKTNT94Z352THSF.png)

把上面的字符串改为`"v4.0.30319"`，保存。

搞定收功，试了几个`dotnet2.0`的程序，都可以这样子处理。
