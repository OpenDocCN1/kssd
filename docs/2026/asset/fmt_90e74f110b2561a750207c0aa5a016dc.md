# 例题 2：LCTF2017-2ez4u（取出时攻击）

## 题目概览

1. UAF，并且 `free` 后连表中指针也不清空，可以 `edit` 和 `show`。

2. `show` 的时候从 `addr+0x18` 开始，刚好跳过了 `fd` 和 `bk` 指针，所以没法利用在 `unsortedbin` 里的 `show` 出来，而是需要拉入 `largebin` 用 `nextsize` 指针。
