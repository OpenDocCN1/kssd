
# [原创]注册多媒体开发工具 Multimedia Builder 4.9

**题目：** 注册多媒体开发工具 Multimedia Builder 4.9

**软件简介：** 使用这个多媒体开发工具，可以创建以 CDROM 为媒介的多媒体应用，教学，展示，展览，MP3 播放器等。
