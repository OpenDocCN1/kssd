
# [原创]新手从汇编语言层次结合源代码分析C语言中与指针相关的操作

首先，这次是结合源代码在反汇编下观察程序的运行过程。下面先贴出源代码，声明一下这是《C Primer Plus（第五版）中文版》中的一个例子，其中为了能更好的的观察程序的运行过程，其中我做了一点小小的改动，源程序文件名为`prt_ops.c`。以下是修改过的代码：

```
#include <stdio.h>
int main(void)
{
	int urn[5] = {100,200,300,400,500};
	int * ptr1,* ptr2,* ptr3;

	ptr1 = urn;         //把一个地址赋给指针
	ptr2 = &urn[2];     //同上
	                    //取得地址指向的值
	                    //并且得到指针的地址
	printf("pointer value,dereferenced pointer,pointer address:\n");
	printf("ptr1 = %p, *ptr1 = %d, &ptr1 = %p\n",ptr1,*ptr1,&ptr1);
	printf("ptr2 = %p\n",ptr2);
	//指针加法
	ptr3 = ptr1 + 4;
	printf("\nadding an int to a pointer:\n");
	printf("ptr1 + 4 = %p, *(ptr1 + 3) = %d\n",ptr1 + 4,*(ptr1 + 3));

	//递增指针
	ptr1++;
	printf("\nvalues after ptr1++\n");
	printf("ptr1 = %p,*ptr1 = %d,&ptr1 = %p\n",ptr1,*ptr1,&ptr1);

    //递减指针
	ptr2--;
	printf("\nvalues after --ptr2\n");
	printf("ptr2 = %p, *ptr2 = %d, &ptr2 = %p\n",ptr2,*ptr2,&ptr2);

	--ptr1;               //恢复为初始值
	++ptr2;               //恢复为初始值
	printf("\nPointers reset to original values:\n");
	printf("ptr1 = %p, ptr2 = %p\n",ptr1,ptr2);

	//一个指针减去另一个指针
	printf("\nsubtracting one pounter from another:\n");
    printf("ptr2 = %p, ptr1 = %p, ptr2 - ptr1 = %d\n",ptr2,ptr1,ptr2-ptr1);

	//一个指针减去一个整数
	printf("\nsubtracting an int from a pointer:\n");
	printf("ptr3 = %p, ptr3 - 2 = %p\n",ptr3,ptr3-2);

	getchar();
	return 0;

}
```

## 基本概念

结合原书，我们先给出3个基本的概念：

1. 指针的值（即指针指向的地址）
2. 指针指向地址中存储的内容
3. 指针本身的值（这里我说明一下：这个指针本身的值其实就是个地址，那么这个地址里面存的是什么，这里存储的其实也是个地址。它实际上存储的地址就是“指针的值”，即是该指针指向的地址。比如我们声明一个指针`int * point1;`，`point1`本身就指向一个地址，这一点很好理解。那么我们再问问自己这个地址存储在哪里，它存储在`&point1`这个地方。那么这个`&point1`就是指针本身的值）。

作为新手以上的描述可能有点云里雾里，不过没关系我们下面结合实例来看看，这样就一目了然了。

### 指针的初始赋值

首先我们看到`ptr1 = 002BFB2C`，我们源代码中有3句：

```
int urn[5] = {100,200,300,400,500};
int * ptr1,* ptr2,* ptr3;
ptr1 = urn;
```

声明了一个数组和3个整形的指针，然后将数组赋值给了`ptr1`这个指针，我们知道实际上是把数组的开始地址赋给了`ptr1`，也就是说`ptr1`现在指向`urn`这个数组的首地址。这个地址上存储的应该是100这个整形值，而且从程序的运行结果`*ptr1 = 100`也确实证实了这一点。好，我们接下来在OD中观察一下这个地址中存储的究竟是什么。在OD的数据窗口按`Ctrl+G`，如下图：

![](https://bbs.kanxue.com/upload/attach/201309/373575_p6nb1fbdzgwb5d9.png)

在32位下`int`占用四个字节，自己可以用`sizeof`测试一下。那么`002BFB2C`这个地址实际上存储的是`00000064`，也就是十六进制的`64`，即是十进制的100，这就验证了我们的猜想是正确的。好，我们再看下一句：`&ptr1 = 002BFB20`。根据我们前面的分析这个地址应该存储的是一个地址，在本次实验中应该就是`002BFB2C`。那我们再次在OD中来到`002BFB20`看看它里面存储的到底是不是`002BFB2C`。如图：

![](https://bbs.kanxue.com/upload/attach/201309/373575_4xx67vbk6ir62bp.png)

一目了然确实存储的是`002BFB2C`,关于这一块有疑问的新手请参考一下《加密与解密第三版》，看看里面关于参数的传入和调用方式以及关于大端和小端那一部分。

### 通过`&urn[2]`验证数组地址

接下来看看源代码这一句：`ptr2 = &urn[2];`我们将存储`urn`数组第三个元素的地址复制给了`ptr2`。程序的运行结果为：`ptr2 = 002BFB34`，那么我现在给自己提出2个问题，然后下面我们一起去验证。

1. `002BFB34`里面存储的应该是300这个十进制的值。
2. 数组的首地址应该是`002BFB34 - 8 = 002BFB2C`。因为这是一个`int`的数组，每个元素占4个字节，2个就是8个字节，我们现在知道第三个元素的地址，要知道第一个元素的地址只需要向回退8个字节。

好，问题提出，我们现在去OD中验证一下。先看看`002BFB34`里面的值：

![](https://bbs.kanxue.com/upload/attach/201309/373575_r9tvoba4y2drdar.png)

可以看到这个值是`0000012C`，不是应该是300吗，别着急因为这个值是十六进制的，我们现在把他转换为十进制看看：

`1*16² + 2*16¹ + C*16º = 256 + 32 + 12 = 300`。验证完毕，说明我们的推断不错。

接下来我们刚才的第二个问题说道这个数组的首地址应该是`002BFB2C`，里面存放的值应该是100，那么去看看吧。

![](https://bbs.kanxue.com/upload/attach/201309/373575_se0tyn1emwe07nf.png)

非常清楚，确实存放的是100这个值。实际上我们开始分析的时候就已经知道了`urn`这个数组的起始地址了，这里是为了通过`&urn[2]`推导一下，验证我们的想法是否正确。

### 指针加法

下来我们看看如下几句：

```
//指针加法
ptr3 = ptr1 + 4;
printf("\nadding an int to a pointer:\n");
printf("ptr1 + 4 = %p, *(ptr1 + 3) = %d\n", ptr1 + 4, *(ptr1 + 3));
```

其中`ptr3 = ptr1 + 4;`是将`ptr1`也就是数组`urn`的首地址加4，那么这里要说明的一点是：地址在内存中是以字节为单位存储的，那么加4换算成字节其实是将4和数组的类型在内存中所占的字节数相乘，在本例中数组类型为`int`，实际上是`4 * 4 = 16`，那么我们刚才知道`urn`数组的首地址为`002BFB2C`，加4以后的地址就是`002BFB3C`，请注意在加16时候把16转换成十六进制也就是十六进制的`10`，也就是`002BFB2C + 10`，同时在本例中他应该是指向`urn[5]`的地址，其值为500，那我们去验证一下：

![](https://bbs.kanxue.com/upload/attach/201309/373575_tpb0lcfte3f6lpc.png)

`002BFB3C`里面存储着`000001F4`，转换为十进制就是500，说明我们的分析是正确的。看看程序运行的结果也是如此。看下面这一句：

`printf("ptr1 + 4 = %p, *(ptr1 + 3) = %d\n", ptr1 + 4, *(ptr1 + 3));`

其中`*(ptr1 + 3)`是将`ptr1`也就是`urn`的首地址加上3，实际上也就是指向数组的第4个元素，也就是400，这里就不多做分析，程序本身的运行结果已经告诉我们了。唯一要说明的一点是：`*(ptr1 + 3)`跟`*ptr1 + 3`区别很大，新手尤其要注意，前者是地址`ptr1`偏移其数据类型大小的`3 * sizeof(type)`字节，而后者则是将`*ptr1`指向的值加3，区别很大。

### 指针的递增与递减

下面的递增和递减没什么要说的，结合前面所讲应该能够明白了，但要注意的一点是`&ptr1`，就是指针本身的地址在程序运行过程中是不变的，大家可以看看在做完递增和递减运算后`&ptr1`的地址始终没变。

### 指针减法

我们继续看下面几句：

```
//一个指针减去另一个指针
printf("\nsubtracting one pounter from another:\n");
printf("ptr2 = %p, ptr1 = %p, ptr2 - ptr1 = %d\n", ptr2, ptr1, ptr2 - ptr1);
```

运算完毕，值为2，不过我猜想地址与地址相减是没有什么意义的！

```
//一个指针减去一个整数
printf("\nsubtracting an int from a pointer:\n");
printf("ptr3 = %p, ptr3 - 2 = %p\n", ptr3, ptr3 - 2);
```

这两句就不用多说了，实际上是按照字节运算的，相信大家也都看的懂了，今天的分析就到这里了，什么技术含量，还望指正！
