# 结束语

● 本意是想在写壳的时候，初始化`IAT`的时候，将`IAT`填入自己实现的`API`调用，避免在关键`API`下断。

● 奈何`windows`版本太多，`ssdt`的序号每个版本可能变化。提供两个思路：

 ○ 从不同版本的`ntdll`文件中解析`ssdt`序号

 ○ 从不同版本的`pdb`来解析`ssdt`序号

● 思路来自张老师讲`Android`的`api`的调用。`Android`的`API`序号不变，没有版本兼容问题。
