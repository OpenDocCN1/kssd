
# 三、Windows 的线程管理

## 1. 线程的创建

最简单的线程创建函数就是`CreateThread`，该函数可以在当前进程中创建一个线程。

可以看到该函数是通过调用`CreateRemoteThread`函数，而传入的第一个进程句柄参数通过使用`-1`来表示当前进程。


在`CreateRemoteThread`中首先会对局部变量进程初始化：

| 偏移 | 名称 | 作用 |
| --- | --- | --- |
| 0x000 | `Tcb` | 内嵌的`KTHREAD`结构体 |
| 0x1D0 | `ExitStatus` | 线程退出状态 |
| 0x1EC | `Cid` | 线程ID |
| 0x220 | `ThreadsProcess` | 指向线程所属的进程 |
| 0x22C | `ThreadListEntry` | 双向链表，一个进程中的所有链表都通过该链表进行连接 |
