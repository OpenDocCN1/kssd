对照“风飘雪”的破解教程，发现可疑的关键`Call`在`004F4DE7`

打开`TRW2000`

在`ChinaZip.exe`的注册栏中填入注册名称“mazhenyu”和注册码“87654321”，但不点击“确定”

“Ctrl+N”激活`TRW2000`

在`004F4DE7`处下断点：`bpx 004F4DE7`，回车，然后按“F5”退出

点击`ChinaZip.exe`注册栏中的“确定”

程序被中断

结果在`004F4DE7`处找到真假注册码：

```
d eax=87654321
d edx=MAE4836
```

用注册码“MAE4836”进行注册，注册成功！
