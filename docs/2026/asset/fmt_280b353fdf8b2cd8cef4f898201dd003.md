
# [原创]发一个批量检测xcode ghost病毒的检测工具

发一个检测xcode ghost的检测工具

昨晚似乎安全界都无眠了，晚上大家都在不断的更新有哪些app感染了，因此为了测试到底有多少流行的app感染了xcode ghost, 写了个简单的工具，由于工具写得比较急，写得很挫，检测结果显示很二，请无视啊，目前已经新检测出了不少app.

![](https://bbs.kanxue.com/upload/attach/201509/302697_xwh8kp03n9nq6qd.png)

使用方法：

1. 将所以要检测的app的ipa文件放到`unpack`目录下，必须是越狱版的才行，因为只有越狱版的才是已经解密过的，各种助手上可下载；正式版都加密的，没法直接检测（经过测试，基本上越狱版的中存在此病毒，那么相同版本的正式版均存在此病毒）。
2. 单击`clickMeToCheck.exe`程序可直接检测，程序会将所有检测到的app写入到当前`log.txt`文件中。
