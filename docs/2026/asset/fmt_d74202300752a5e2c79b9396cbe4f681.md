## 二、ssh配置

### 2.1 切换root账号

```
kali@kali:~$ whoami 

kali

kali@kali:~$ sudo passwd root
```

新版本的kali在安装系统的时候没有设置`root`账号。首先设置`root`账号权限。在终端输入`sudo passwd root`可以设置`root`账号密码登录。当前用户账户退出后，可以用`root`+密码的方式登录系统。

### 2.3 更改ssh配置文件

```
root@kali:~# vim /etc/ssh/sshd_config
```

在使用`vim`命令时，会进入`vim`编辑模式。按`esc`是无法退出文本的。`normal`模式是方便你使用键盘的快捷键去操作或者更改文本。

进入后先按下`esc`，确保进入命令模式。把光标移动到`#Prot 22`的`#`上，就可以删掉，按一下命令`x`，就可以删除`#`。若删除错了，可以按下`u`，可以撤回删除错的。要输入文字，按`esc`后，按`i`，就可以对文字修改了。修改完后按`esc`，再输入`:wq`就可以保存退出。

## 三、IP固定

要链接`ssh`，首先要知道`ip`，若不知道`ip`，或者`ip`会变，就非常麻烦。

另外，kali虚拟机要访问办公局域网，才可以好好干活。所以，网卡需要选择桥接模式。
