
# Windows内核-内存（八）

## 八、内存

### 8.1.VAD私有内存

#### 1.`vaddemo.cpp`

```cpp
#include <stdio.h>

#include <Windows.h>

int main()
{
	system("pause");
	PVOID base = VirtualAlloc(NULL,0x1000,MEM_RESERVE,PAGE_NOACCESS);
	printf("not allocate base % p\r\n",base);
	system("pause");

	base = VirtualAlloc(base, 0x1000, MEM_COMMIT, PAGE_READWRITE);
	printf("allocate base % p\r\n", base);
	system("pause");

	return 0;
}
```
