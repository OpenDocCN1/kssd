## 简单分析

看到文件名感觉像是一个正常的设备固件，搜索一下发现是一个真实的路由器的固件，还曾出过漏洞。

![](https://bbs.kanxue.com/upload/attach/202002/725158_op5ebft9mjc70rv.png)

下载了原版固件，使用`binwalk`解包之后，对所有的文件进行了对比。

我采用的方式是针对每个文件 hash，然后比较。

```
find . -type f |xargs md5 > test.txt
diff 1.txt 2.txt
```

![](https://bbs.kanxue.com/upload/attach/202002/725158_h44eqcth5bmizct.png)

可以看到文件大概有3处修改：增加了`nc`、`passwd`和`services`文件，以及`help`目录下删掉了一些文件。

看蝶澈的 writeup 中使用了[这个工具](<https://bbs.kanxue.com/elink@54aK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1L8h3q4A6j5g2)9J5c8X3u0A6L8Y4N6S2L8r3I4&6i4@1f1^5i4@1u0r3i4K6V1&6i4@1f1@1i4@1t1^5i4@1q4m8i4@1f1#2i4@1t1%4i4@1p5#2i4@1f1#2i4K6R3#2i4@1t1%4i4@1f1#2i4K6R3I4i4K6W2m8i4@1f1@1i4@1t1^5i4@1p5@1i4@1f1@1i4@1t1^5i4@1q4m8i4@1f1%4i4K6W2n7i4@1q4q4i4@1f1#2i4@1u0p5i4K6V1#2i4@1f1%4i4K6W2m8i4K6R3@1i4@1f1$3i4K6V1$3i4K6R3%4i4@1f1@1i4@1u0n7i4@1t1$3i4@1f1$3i4@1q4r3i4K6V1@1i4@1f1^5i4@1u0q4i4K6R3K6i4@1f1K6i4K6R3H3i4K6R3J5>)做两个目录的文件比较。

## 动态调试

路由器的环境搭建可以参考[看雪](http://bbs.pediy.com/thread-212369.htm)。通常来说，搭建一个 MIPS 的调试环境还是需要花费不少时间，踩一些坑的。为了方便分析，我做了一个基于`docker`的一键测试环境[embedded-device-lab](<https://bbs.kanxue.com/elink@410K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6K6N6r3q4&6L8r3W2$3x3#2)9J5c8X3g2E0j5X3g2V1k6r3g2V1i4K6u0V1k6r3g2$3K9h3y4W2i4K6u0V1L8r3q4T1>)，可以直接使用`gdb`或者`IDA`动态调试。

经过简单的尝试，发现应该是需要输入一个密码。如果密码正确，可以获得 flag。

![](https://bbs.kanxue.com/upload/attach/202002/725158_gt8j8idaytoawla.png)

通过`getflag`、`socket`等关键字，可以定位到关键函数`400310`。通过一番调试发现，这里：

```
loc_400710:
    lw      $v1, 0x850+var_830($fp)
    li      $v0, 1
    beq     $v1, $v0, loc_40038C
    nop
```

需要`v1`不等`v0`才能进入有`getflag`相关的逻辑。而当我们随便输入密码的时候，`v1`都是等于`v0=1`的。所以，在这里把`v0`修改成其他的值，就可以继续运行到`getflag`相关的逻辑。
