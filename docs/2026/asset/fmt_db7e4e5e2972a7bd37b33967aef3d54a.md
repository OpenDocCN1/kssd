
# [原创]win32汇编的一个聊天器&网络与数据库应用

闲着翻看硬盘，发现以前学习win32汇编的时候，写的一个东东；

简单的聊天器，加了一个保存聊天记录的数据库access，操作函数都是用原始API；

关于win32汇编，自己的一点感悟：

1. 如果用来编写WIN应用程序，有着和C语言编写应用程序类似的“SDK框架”。所以，习惯用C编写WIN应用程序的来说，总是感觉特别熟悉，二者区别不大；很容易上手。
2. win32汇编完美的支持x86汇编指令，并且提供了很多的伪指令，大大简化了编写的复杂性。这也促就了很多病毒程序都是用win32汇编语言编写的。
