## ODScript 脚本

写一段`ODScript`:

////////////////////////////////////////////////////////////////////////

//fixed aspr 2.x

```
var addr

start:
  run

l1:
  cmp eip,00FF00AE ;这里的数字是上面提到的jmp [esp-4]的地址,这里是00ff00AE
  jne l2
  mov addr,esp
  sub addr,4
  mov [addr],0065110F 这个数字是上面patch2代码中jmp ebx后面那句的地址,这里是
  jmp start

l2:
  ret
```
/////////////////////////////////////////////////////////////////////////

保存成`OD`脚本.

然后把`EIP`从哦`OEP`改向我们`patch`代码的第一句，这里是：

```
00651100      60            pushad
```

然后要在上面提到的`jmp [esp-4]`的地址,这里是`00ff00AE`上面下硬件执行断点。

其次，在`patch`结束句，这里是

```
00651173      61            popad
```

上面下`F2`断点。

最后运行脚本。等待一段时间，脚本运行完毕后，清除掉所有的修改。

`dump`,修复`IAT`.

就大功告成了。
