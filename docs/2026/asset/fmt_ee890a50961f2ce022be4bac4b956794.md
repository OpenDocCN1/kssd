## 3. 其中的`TableCode`为`0x80901001`，`TableCode`字段的解释与其他系统中一样的，低 3 Bits 表示是几层表结构，低3位清0之后的值就是层表地址。

`0x80901001`低3位清零后为`0x80901000`，是一个二级表

```
lkd> dd 0x80901000
```

```

### 2. `KeVersionBlock` 指向的是 `\_DBGKD\_GET\_VERSION64` 结构体，紧跟在后面的是 `KDDEBUGGER\_DATA64`

在`wdk8.1`中以下位置可以得到这些结构体的定义：

`C:\Program Files (x86)\Windows Kits\8.1\Debuggers\inc\wdbgexts.h`

```
WINDBG>dt \_dbgkd\_get\_version64 0x81ffdd60
```
```
