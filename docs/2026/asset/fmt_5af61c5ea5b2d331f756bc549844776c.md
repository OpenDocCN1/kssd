
1. 计算 `(ecx+S xor Q) mod 3bh`，以算出的值为索引值，从 `M` 中取出相应的值，假设该值为 `t`，计算 `[(t+ecx) mod 12h] mod 4h`，将算出的值 `*4+00586C38`，从目录（见附录）中取出相应的地址 `p`，用 `{[(t+ecx) mod 12h] mod 20h}/2` 算出 `q`，然后以 `p+q` 为地址从码表取出相应的值 `AL`，计算 `[(AL xor t)+t] xor M[esi+1]*2`，将结果保存在 `M[esi]` 中。
2. 计算 `ecx mod 5h`，将算出的值保存到 `[ebp+10]` 中。如果等于 `0` 或等于 `2` 或等于 `4`，则计算 `(M[esi] mod 1Ah)+41h`；如果等于 `1` 或等于 `3`，则计算 `(M[esi] mod 1Ah)+30h`，结果放在 `[EBP+EDI+FFFFFF30]` 中，这就是注册码，当然这不是最后的注册码。
3. `ecx = ecx + 1`

重复 1、2、3 直到 `ecx > 3ch` 为止。
