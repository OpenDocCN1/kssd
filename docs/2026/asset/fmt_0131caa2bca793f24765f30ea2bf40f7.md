## 三、总结

这是一个不错的国产软件，为了防止破解扩散，只公开前面两部分的注册算法分析。

这个软件有一处反跟踪代码，是通过判断两次时间差，如发现有两次时间差超过10秒，则会直接出错。

密码表：`GFEDCBANMLKJIHTSRQPOZYXWVU`

`m1m2m3''MI''''m25m26`

注册码：`s1s2s3'''sN''s18s19s20`

1. 注册码第`N`位在密码串的位置数`I`，位置数`I`入`eax`，并计算：

   ```
   X = 0;
   for (i = 0; i < 21; i++)
   {
       X = X + (I - 1) * 注册码第N位;
   }
   ```

   注册码依次查表，并把各位相加为`X`，最后取`(X/26)`的模数，然后模数加1，得数`Y`，在密码表中取第`Y`位字母，与注册第20比较。

2. 注册码第`N`位在密码串的位置数`I`，位置数`I`入`eax`，并计算：

   ```
   X = 0;
   for (i = 0; i < 20; i++)
   {
       X = X + (I - 1);
   }
   ```

   注册码第`N`位在密码串中的位置数-1并各相加，注册码第20位不参与运算。最后取`(X/26)`的模数，然后模数加1，得数`Y`，密码表中取第`Y`位字母，与注册码第19比较。
