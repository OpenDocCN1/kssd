## 2. so 层用花指令对程序指令进行混淆

在一定程度上防止分析。

![](https://bbs.kanxue.com/upload/attach/201706/654852_6b3p43qwovm091d.png)

解题：编写去花指令脚本，`F5`就会变得很简单。去花脚本在附件里了。去花后`check`函数`F5`如下：

![](https://bbs.kanxue.com/upload/attach/201706/654852_tls50lf8o00i5zc.png)

这样就能很清楚看到注册过程了，第一个`while`循环释放存放好的字符串到`byte_20020`。`sub_19DA8`为加密函数，返回结果到`v14`，最后`v14`与`byte_20020`做比较，一样就行了。算法采用了 RC4 加密+base64 编码。

## 3. so 中藏关键字符串数据的方式

值得一提的是，so 中藏关键字符串数据的方式我自己觉得挺有意思的。不知道聪明的你有没有发现呢？

如果不会去花也不要紧，还有一个解题的思路就是找到最后的汇编`cmp`，下好断点，因为这个算法的缘故，Java 层可以遍历传入字符串进行遍历暴力破解。
