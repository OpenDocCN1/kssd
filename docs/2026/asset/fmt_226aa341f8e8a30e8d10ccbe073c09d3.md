## 注册机算法

注册机算法当然就是注册验证算法的逆算法啦！我们先来总结一下验证算法：

### 1、用户名的变化

设用户名为`char username[len];`，用户名变码为`long name;`，则有：

```
int num;
name = 0;
for (int i = 0; i < len; i++)
{
    num = username[i] - 48;
    num = num * (num + 1);
    name = name + num;
}
```
