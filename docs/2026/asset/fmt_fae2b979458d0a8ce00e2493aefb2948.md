
# [原创]反调试与反-反调试之 Java 层反调试

安卓程序动态调试需要满足两个条件。

1. 在 `AndroidMainfest.xml` 文件中，在 `application` 标签下，`Android:debuggable=true`。
2. 系统默认调式，在 `build.prop`（`boot.img`）中，`ro.debugable=1`。

## 1.1 实例演示 Java 层反调试

**以“百度加固”为例。**

1. 将样本拖入 `jdax-gui` 中，进行反编译，来到加固程序的 `onCreate` 里，如下图所示。

    ![](https://bbs.kanxue.com/upload/attach/202010/880306_UNS6PHAWHY6DYWF.png)

2. 找到 `attachBaseContext` 方法，里面有一个判断，调用这个 `Debug.isDebuggerConnected` 函数来检测程序是否被调试反调，从而执行是否加载 `so` 库的逻辑操作，如下图所示。

    ![](https://bbs.kanxue.com/upload/attach/202010/880306_YBXWDWDQ5SZAAWW.png)

## 1.2 绕过 Java 层反调试的方法

1. 使用 `androidkiller` 进行反编译，然后搜索 `isDebuggerConnected`，如下图所示。

    ![](https://bbs.kanxue.com/upload/attach/202010/880306_Z4UZQZZJCJ53KAE.png)

2. 过来后，修改判断条件，将 `nez` 改为 `eqz`，如下图所示。

    ![](https://bbs.kanxue.com/upload/attach/202010/880306_3FDHS2ARMPYG3B5.png)

3. 修改 `smali` 之后，将 `apk` 重新打包，编译，再签名即可。
