## 03-恶意代码分析

### 3.1-脱壳

- 是否有壳：`PEiD`查看`xiongmao.exe`存在FSG 2.0的壳

  ![img](upload/attach/202002/868592_84BEDGUF482V44Z.jpg)

- `x32Debug`中打开`xiongmao`，单步跟踪直到`jmp dword ptr [ebx + 0xc]`，其跳往真实OEP处，利用Scylla插件进行脱壳，最后保存为`xiongmao_dump_SCY.exe`

  ![image-20200113083033910](upload/attach/202002/868592_UPN57VMHVRYBMAR.jpg)

- `PEiD`深度扫描`xiongmao_dump_SCY.exe`显示没壳，再查看其输入表也正常，说明脱壳成功

## 04-解决方案

### 4.1-病毒特征

- 病毒文件的哈希值如下：

  ```
  MD5: 512301C535C88255C9A252FDF70B7A03
  SHA1: CA3A1070CFF311C0BA40AB60A8FE3266CFEFE870
  CRC32: E334747C
  ```

- 被感染文件中，文件最后有感染表示标识：`WhBoy` + 原文件名 + `exe` + + ascii码为1的字符 + 随机数+ ascii码为2的字符

  ![image-20200113083415753](upload/attach/202002/868592_R4GCUS3NQY6R92A.jpg)

### 4.2-手工查杀
