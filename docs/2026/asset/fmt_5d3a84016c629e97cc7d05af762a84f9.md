
# [原创]手工添加外部DLL输入表并调用添加函数

从上面的数据可以看出，输入表的地址是：`2040`，不过这是虚拟地址，要转换成文件的地址，从节的信息可以看出，输入表在`.data`节，所以这样计算一下：`2040-2000+600=640`（其中`2000`是`.data`节的起始虚拟地址，`600`是`.data`节在文件中的起始地址），这就是输入表在文件中的地址了，我们看一下这个地址下的数据：

![](https://bbs.kanxue.com/upload/attach/201812/12593_S86RGPVP5XVYQS3.jpg)

输入表的结构大家可以参照我写的另一篇文章：<https://bbs.pediy.com/thread-248111.htm>

现在的数据来看加一个输入函数是很困难的，因为要将数据整体下移才能挪出空间了，这样要改动的数据就太多了，不过来逆向思维一下，我采取了两个方法来获得空间，首先新增的 `IMAGE_IMPORT_DESCRIPTOR`结构不往后加，放到现有数据的前面，现在就是 `IMAGE_THUNK_DATA32`结构还没有空间，我采用的方法是，把 `IMAGE_IMPORT_DESCRIPTOR`结构中的 `OriginalFirstThunk`清零，这样它指向的数据空间就是放出来了，我们用这部分空间来保存新的输入表，空间都有了，现在就来增加我们需要的输入表。

![](https://bbs.kanxue.com/upload/attach/201812/12593_J4PC4EAGTK57TP9.jpg)

大家看上图，以前的输入表地址是：`640`，我们在`640`地址前面加了，大家记住A中的地址：`62C`，这是新的输入表的地址，不过要转换成虚拟地址，B中的地址指向了DLL的名称，C中的地址指向了D，D中的地址指向了函数名，将E中的数据清零，这表示函数结束，因为我们只增加了一个函数，这就构成了一组新的完整输入表，其中黑框中的地址就是 `OriginalFirstThunk`，将它清零就可以了。

现在我们来计算新的输入表地址：`62C-600+2000=202C`(是前面计算文件地址的逆过程)，我们搜索以前的地址：`40 20`，将它替换为：`2C 20`，到现在为止，输入表信息添加完成了，下面我们就要添加调用了。

![](https://bbs.kanxue.com/upload/attach/201812/12593_27UAXFHQFG99M6E.jpg)

看到地址`570`处有空间，以前的入口地址是：`401040`，我们把代码加到这里，代码如下：

```
call    DWORD PTR DS:[4020c4] //调用FlashShow的函数

jmp    401040 //跳转会原入口地址
```

`4020C4`这个地址是怎么来的呢？这就是图中D的地址转换来的，系统中加载的时候会把`FlashShow`函数的地址填写到这里，我们直接调用就可以了。

最后把新的入口地址改为`1370`即可。
