## 模拟运行

安装`qemu`模拟器`qemu-user-static`，利用Linux的`binfmt_misc`机制执行MIPS架构的`sh`，跳转到`rootfs`的根目录，执行`sudo chroot . bin/busybox sh`进入固件的`shell`。

```
sudo chroot . bin/busybox sh

Enter 'help' for a list of built-in commands.
/ # ls

```
