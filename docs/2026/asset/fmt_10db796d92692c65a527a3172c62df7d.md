## 思路

+ 利用 `unlink` 修改 `ptr[1]` 为 `&ptr[1]-0x18`。
+ 利用 `new note` 的堆溢出修改 `ptr[1]` 为 `&ptr[3]`，`ptr[2]` 为 `puts@got`，`ptr[3]` 为 `free@got`，`ptr[1]` 修改为 `&ptr[3]` 就能实现任意地址写了，我们可以通过 `ptr[1]` 修改 `ptr[3]` 为我们想写入的任意地址，编辑 `ptr[3]` 就是编辑任意地址内容
+ 利用 `edit` 功能修改 `ptr[3]` 也就是 `free@got` 为 `puts@plt`，就能够泄露 libc 基址了，也就得到了 `system` 地址。
+ 编辑 `ptr[1]` 使得 `ptr[3]` 为 `atoi@got`，编辑 `ptr[3]` 写入 `system` 地址，接着输入 `/bin/sh`，`atoi("/bin/sh")` 就变成了 `system("/bin/sh")`。

这道题和 note2 差不多，只是少了打印的功能，只需要修改 `free@got` 为 `puts@plt` 泄露地址即可，漏洞点和攻击手法一样的。
