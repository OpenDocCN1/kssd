
```cpp
class Base
{
public:
	Base(int x, int y)
	{
		this->x = x;
		this->y = y;
	}
	void operator++()
	{
		this->x++;
		this->y++;
	}
	void Show()
	{
		printf("x=%d, y=%d\n", this->x, this->y);
	}
private:
	int x;
	int y;
};
```

以上实现了对`++`的重载，我们在`main`函数中查看编译器的实现如下：


# 五.模板

模板同样作为C++的一个强大的语法工具被广泛使用，修改类定义如下。

```cpp
template <class T>
class Base
{
public:
	void InitData(T x, T y)
	{
		this->x = x;
		this->y = y;
	}
private:
	T x;
	T y;
};
```

接下来通过对`main`函数的进行反汇编查看模板的实现究竟是如何的

