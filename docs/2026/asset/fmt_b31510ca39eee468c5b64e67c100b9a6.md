## 2.2 常用命令行工具

### 2.2.1 `adb`

Android 调试桥 (`adb`) 全称为 Android Debug Bridge，是一种功能多样的命令行工具，可让使用者与目标设备进行通信。`adb` 命令还可进行各种设备操作（例如安装和调试应用），并提供对 Unix shell（可用来在设备上运行各种命令）的访问权限。

`adb` 命令语法格式如下：

```
adb [-d | -e | -s <deviceId>] <command>
```

参数具体含义如下：

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_ETKYBHG8USTUMHE.png)

当仅有一个设备连接时，命令中可以不指定`[-d|-e|-s <serial-number>]`参数，直接使用`adb <command>`的方式进行操作。连接多个设备情况时常见的方法是通过`-s <deviceId>`参数指定待连接的设备。

如果和目标设备在同一局域网，可以通过IP+端口的方式连接到目标设备。

```
adb connect host_ip[:port]
```

可以通过`adb devices`命令查看当前已经连接的设备：

```
$ adb devices
List of devices attached
rsnvs87d5dgewt   device
a38b2e8          device
emulator-5554    device
```

这种场景下如果想指定`a38b2e8`设备来运行`adb`命令，可以采用`-s <deviceId>`的方式：

```
adb -s a38b2e8 install demo.apk
```

通过`adb`查看目标设备应用列表的基本命令格式是：

```
adb shell pm list packages [-f|-d|-e|-s|-3|-i|-u] [--user USER_ID] [FILTER]
```

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_JADUZQ96727795E.png)

查看目标设备上安装的所有应用：

```
adb shell pm list packages
```

查看目标设备上安装的系统应用：

```
adb shell pm list packages -s
```

查看目标设备上用户自己安装的应用：

```
adb shell pm list packages -3
```

查看目标设备上包名中含有指定字符的应用：

```
adb shell pm list packages 'test'
```

`adb`配合`am <command>`命令可以实现与目标应用的交互，常用命令如下图所示：

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_NM5KNVCBMYNTWCX.png)

启动一个应用，命令格式如下所示：

```
adb shell am start -n com.test.demo/com.test.demo.activity
```

注意：可以用debug方式启动应用（`am start -D -n`）。特别在反编译调试应用的时候，可能需要用debug方式启动应用。

启动指定的Service服务，具体命令如下所示：

```
adb shell am startservice -n com.test.demo/com.test.demo.service
```

发送一个指定的广播，具体命令如下所示：

```
adb shell am broadcast -a android.NET.conn.CONNECTIVITY_CHANGE
```

强制停止指定包名的应用，具体命令如下所示：

```
adb shell am force-stop com.test.demo
```

`adb`除了可以和应用交互外，还可以配合`input`命令模拟更多的用户行为，例如按键行为和输入行为。模拟按键行为的命令如下：

```
adb shell input keyevent <keycode>
```

经常使用的`keycode`如下表所示：

![图片描述](https://bbs.kanxue.com/upload/attach/202306/452101_8HSDVV946ZEWNM6.png)

模拟用户滑动行为，具体命令如下：

```
adb shell input swipe 500 300 100 300
```

代码含义为模拟用户向左滑动屏幕。参数`500 300 100 300`分别表示起始点x坐标，起始点y坐标，结束点x坐标和结束点y坐标。

模拟用户点击屏幕的行为，具体命令如下：

```
adb shell input tap 100 300
```

代码含义为模拟用户单击屏幕。参数`100 300`分别表示点击位置的x坐标和y坐标。

**其他常用命令**

查看当前应用的activity组件信息：

```
adb shell dumpsys activity top
```

查看指定包名应用的详细信息：

```
adb shell dumpsys [packagename]
```

查看指定进程名或者进程id的内存信息：

```
adb shell dumpsys meminfo [packagename/pid]
```

可以查看指定包名应用的数据库存储信息：

```
adb shell dumpsys dbinfo [packagename]
```

重启进入到`bootloader`，即刷机模式：

```
adb reboot bootloader
```

重启进入`recovery`，即恢复模式：

```
adb reboot recovery
```

### 2.2.4 `Clutch`

`iOS`正常只能通过App Store下载安装应用，要想对应用进行分析只能从目标设备上导出目标应用的`IPA`包。苹果为了保护开发者的权益使用了数字版权加密技术对`IPA`包进行了保护，直接导出的`IPA`包内容是无法直接进行分析。如果要想对`IPA`文件进行分析就需要对其进行解密，也就是人们通常说的砸壳。

`Clutch`是一款便捷的解密工具，支持 iPhone、iPod Touch和iPad以及所有iOS版本、架构类型和大多数二进制文件。不管应用如何加密，运行的时候总要解密，`Clutch`就是在应用运行时，将内存数据按照一定格式导出。
