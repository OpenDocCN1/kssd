### ③、基础代码审计

#### 4、Check your source code

- 题目描述

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_DJ4HVKP8C6JT2HT.png)

- 访问网站

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_KHMPH9SW2BS2F8J.png)

- 尝试一下 `admin` / `admin`，无果后查看源代码

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_TDRUQ37ZDJ93D3Y.png)

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_6ZJ2G9K3GXEJFX5.png)

- 审计题，定义俩变量

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_99UW4PHWCCT3PJH.png)

- 检查 POST 的 `username` 和 `password`

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_EQHTHAVSR9NQ3S5.png)

- 等于

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_QD7M8CYF49VM59W.png)

- 检查 cookie 是不是 `check`

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_5675PZR2XAMG6Y4.png)

- URL 解密后的 `username` 变量全部等于（`===` 你懂的），URL 解密后的 `password` 不等于 `admin`。意思是账号 `admin`，密码不等于 `admin` 即可

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_D4DWZCACM7F5PS4.png)

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_KCJPRSF9Z9G7VQD.png)

- 然后 `setcookie` 等于 a hash，然后用 `base64` 加密 `secret` 变量，然后 `urldecode` `admin admin`，`time()` 为时间 7 天

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_9XZNSW98A9ZSYBK.png)

- 流程就是抓包把 cookie 改成 `check`，然后填入加密后的 `secret`、明文的 `admin` 与任意密码

- 抓包看到一个 base64 加密的 cookie

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_GSKQ4RPWWMAENSU.png)

- 解密后

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_8669RWRQNTUJAKF.png)

- 这个 `88` 应该就是 `secret` 这个变量，那么把它加密

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_FX2WX39ECK55RG7.png)

- 然后把包丢进 `Repeater`

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_HQ55S2XAU965HH2.png)

- 名字改为 `check`，等于加密后的 `88`

- 后面跟上 `admin` 与任意密码即可。注意：`check` 那里的密码必须与下面提交的数据 `password` 一样，不然会提示重新检查 cookie

  ![图片描述](https://bbs.kanxue.com/upload/attach/202011/809626_PUAHR7JRYDYRVZ7.png)

  `flag{welcome_to_htlab}`
