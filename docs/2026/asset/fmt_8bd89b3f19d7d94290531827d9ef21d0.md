## Tls回调函数（下）

参考上节的跟踪记录`vm_tls.txt`，可以看到第117行和第290行的`VmCALL`将代码分成3块，标记为Chunk1 - Chunk3，我们先看下`VmCALL`的实现，再分别分析这3块代码。

### `VmCALL`

```text
shrd rsi,rbx,cl
mov esi,dword ptr ss:[rbp]        ; Esi = 栈顶DWORD
clc
stc
add rbp,8
jmp vmp_userdebugger.7FF69E7403F7
bsf ax,di
sar r12d,cl
inc r12d
shl ch,5
lea r12,qword ptr ds:[7FF69E74065C] ; R12 固定取7FF69E74065C
rcl al,7
not bh
mov rax,100000000
rcr rbx,10
add rsi,rax                       ; Rsi += 100000000
xchg al,bh
bsr bx,dx
shld bx,sp,cl
rcr ebx,cl
mov rbx,rsi                       ; Rbx = Rsi
movsx cx,cl
add rsi,qword ptr ss:[rbp]        ; Rsi += 栈顶QWORD, 注意此处未调整RBP栈指针
```

可以看到，`VmCALL`取栈中DWORD作为基数计算`RBX`和`RSI`，我们第一篇分析过，`RSI`指向字节码缓冲区，`RBX`为解密Seed，也就是说每个Chunk都有自己的`RSI`和`RBX`。
