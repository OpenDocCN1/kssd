
# 联众台球圣手v4.7试用版－ARM3.60双进程非标准壳

## 一、破解目标

联众台球圣手v4.7试用版

## 二、破解工具

OllyDbg v1.10，ImportREC 1.6 Final，LordPE

## 三、破解作者

csjwaman

## 四、破解过程

### 1.寻找版本号

用PEiD扫描，提示为Armadillo 1.xx - 2.xx -> Silicon Realms Toolworks [Overlay]。这其实是误报，实际应为ARM3.60双进程非标准壳。

因为是双进程的，先用以下脚本转换为单进程：

```
//转单进程脚本
msg "请忽略所有异常，并添加忽略C000001E异常，然后运行本脚本！"
gpa "OpenMutexA","kernel32.dll"
bp $RESULT
esto
exec
pushad
pushfd
push edx
xor eax,eax
push eax
push eax
call kernel32.CreateMutexA
popfd
popad
jmp kernel32.OpenMutexA
ende
bc eip
msg "现已转换成单进程！"
ret
```

运行脚本后停在：

### 2.寻找OEP和DUMP进程

重新加载程序，下断`BP WaitForDebugEvent`，断下后堆栈如下：

```

0012DAC4    0012EB84   |pDebugEvent = 0012EB84///进数据窗口。

### 3.寻找IAT

将DUMP出来的程序`OEP`改为`97738`，然后用OD载入，跟踪几步就可以找到IAT。

```
