
# [原创]iOS手游逆向之旅-大纲

本套系列教程只为记录本人业余兴趣，记录逆向过程以及思路，未实际开发成品，不提供任何成品或代码。

该教程将会从游戏引擎`0`基础出发进行编写，教程长期更新，篇幅顺序不定，进度时间不定。

## iOS手游逆向所需具备技术学习路线

该学习路线只为本人逆向过程所需使用技术，不代表逆向其他手游或APP所需。

### 基础篇

- 砸壳（`IPA`砸壳）
- `class-dumps`（提取目标的类信息）
- `ARM64`汇编（基础必备，分析汇编指令）
- `IDA`（分析目标的可执行文件）
- `Theos`（`Hook`插件开发）
- `lldb`（动态调试）

由于基础篇过于基础，各大搜索引擎或书籍都可以找到相关资料，故不在此详解，后续有空或会编写基础教程。

### 高级篇

- [`cocos2dx`游戏引擎识别](https://bbs.pediy.com/thread-274070.htm "cocos2dx游戏引擎识别")
- [`cocos2dx`引擎的`luac`解密提取及修改](https://bbs.pediy.com/thread-274071.htm "cocos2dx引擎的luac解密提取及修改")
- `cocos2dx`引擎的`jsc`解密提取及修改
- `unity3d`（待定）

高级篇中手游所涉及到的脚本语言（如`Lua`、`JS`）不过多讲解，可以自行搜索学习。

### 进阶篇

- 非越狱插件开发
- 游戏封包协议分析
- 脱机客户端原理及开发
- 私服服务器原理及开发

进阶篇将会讲解如何分析协议及加解密算法、脱机挂的原理及实现、私服是如何产生的以及自己搭建一款简易的私服服务器。
