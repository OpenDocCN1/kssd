
# 【破解总结】

## 【算法总结】

1、注册码长度必须为16位

2、字符必须在0~9、`A`~`F`、`a`~`f`之内

3、同一数字在注册码中出现次数小于等于5

4、`1`、`2`、`3`、`4`位的值右移2位后的和等于8；`5`、`8`、`11`、`14`位的值右移2位后的和等于8；`7`、`10`、`13`、`16`位的值右移2位后的和等于8
