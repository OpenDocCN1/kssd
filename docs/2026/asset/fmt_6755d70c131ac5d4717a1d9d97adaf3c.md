下面使我对Molebox如何实现这一点做的一些猜测：

1. 首先是利用下面的字节序列做特征串。

```
  005600F1   .  90            nop

```

2. 函数修改时按修改后的代码进行编写。

3. 在生成的目标文件中搜索特征串，并计算该处指令映射到内存中后的地址，然后对地址做加密操作。
