
# Xposed 的新打开方式——Xpatch 工作流程分析

## 1. Xpatch 概述

Xpatch 是一款利用重打包的方式，使得被处理的 Apk 启动时自动加载 Xposed 模块，来实现应用内 Hook 的工具。
