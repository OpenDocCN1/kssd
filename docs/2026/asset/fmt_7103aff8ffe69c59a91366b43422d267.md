
# [分享]C语言基础八-共用体和枚举类型

## 共用体的定义

C语言中，几种不同类型的变量存放在同一段内存中，被称作共用体（Union）。共用体中可以包含结构体，结构体中也可以包含共用体。

```c
typedef union _student
{
    int nId;
    char szName[16];
}student, *pstudent;
```

- 共用体成员共享同一块大小的内存，一次只能使用其中一个成员。
- 共用体中各个成员存储的起始地址相对基地址的偏移地址都是0。
- 共用体大小由其最大成员的大小决定，并且必须是最大基本类型的整数倍。
- 对某一成员赋值，会覆盖其他成员的值。

## 共用体和结构体的区别

- 结构体的各个成员会占用不同的内存，互相之间没有影响；而共用体的所有成员占用同一段内存，修改一个成员会影响其余所有成员。
- 结构体占用的内存大于等于所有成员占用的内存的总和（成员之间可能会存在缝隙），共用体占用的内存等于最长的成员占用的内存。
- 共用体使用了内存覆盖技术，同一时刻只能保存一个成员的值，如果对新的成员赋值，就会把原来成员的值覆盖掉。
- 结构体先后存放成员数据，共用体并排存放成员数据。

## 枚举类型的定义

在实际编程中，有些数据的取值往往是有限的，只是非常少量的整数，并且每个值都有名字有意义，C语言提供了一种枚举（Enum）类型，能够列出所有可能的取值，并给它们取一个名字。

```c
typedef enum typeName
{
    valueName1,
    valueName2,
    valueName3,
};
```

`typeName`是枚举类型的名字，`valueName1`, `valueName2`, `valueName3`是每个值对应的名字，注意最后的`';'`不能少。我们仅仅给出了名字，却没有给出名字对应的值，这是因为枚举值默认从 0 开始，往后逐个加 1（递增），也可以给每个名字都指定一个值。

- 枚举类型是一种基本数据类型，不是像结构体这样的构造类型。
- 在枚举类型定义中列举出的所有可能值，说明该变量取值不能超出定义的范围。
- 当一个变量的值被限于列出来的值的范围内，可以把这个变量定义为一个枚举类型的变量。
- 枚举变量的值，在定义的时候要全部列举出来，枚举值本身是一个常量，不能被修改。
