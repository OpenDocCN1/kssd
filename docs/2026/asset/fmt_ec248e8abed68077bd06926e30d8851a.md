
# GTA2 光碟保护 暴力破解

安装完游戏，光碟先不要拿出。

`bpx GetDriveTypeA`

执行程序，弹出 sice。返回到 gta2 区域，向上的一个 `cmp XXX` 就是第一个检测点。第一步完成。

到游戏主界面，如果没有光碟，此时执行 start game，就会来到第二个陷阱：`security fail`。所以执行前 `bpx ReadFile`，按 F10 执行程序，会找到第二个检测点，很简单啦。

无壳，无反跟踪，西西，我只会做最简单的啦。

关键是开始我被迷惑了，因为我下第一个断点时，没有放光碟，这个程序上来直接读一下光碟上的东西，此时检测，如果读错误就跳走了，所以不会断到 `GetDriveTypeA` 出。

完了。算个开始吧。
