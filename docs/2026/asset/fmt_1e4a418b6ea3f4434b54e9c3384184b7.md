## 1. 工具准备

- .NET Framework SDK 1.1
- ASP.NET环境
- `ILDASM`反编译工具
- `ilasm`重新编译工具

## 2. 安装Dundas Chart For .NET,访问示例程序,发现试用版限制仍然是水印,确定打击目标

## 3. 打开`ildasm`,载入`DundasWebChart.dll`文件,如果有Reflector 4.0之类更好,看看程序架构,初步诊断特性如下:

- 控件使用.net控件`License`模型控制注册信息
- 所有字符串全部加密

使用"转储",导出IL源代码备用.
