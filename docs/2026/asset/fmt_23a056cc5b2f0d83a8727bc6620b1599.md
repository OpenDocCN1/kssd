```c

{

```

很明显最后的函数中有典型的格式化字符串漏洞：

```c
printf(s1);
```

但`buf`在`.bss`段上，所以不能用自动化工具来打：

```c
.bss:0804B0A0 s1 db ? ; DATA XREF: sub_804854B+1B↑o
```

### 思路

我们利用字符串格式化漏洞攻击`got`表，将`printf`修改成为`system`，然后之后循环中输入`/bin/sh`就可以完成利用：

```c
printf(s1);
---------after attack--------->
system('/bin/sh');
```

