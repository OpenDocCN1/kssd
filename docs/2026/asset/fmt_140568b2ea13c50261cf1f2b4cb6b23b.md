而且我还需要分配`ActiveContextStackPointer`,.

所以新线程的`eip`实际上是指向一段`stub`,

在`stub`里分配`ActiveContextStackPointer`,然后模拟的`call` 线程的起始地址,

然后调用`RtlExitUserThread`,确保在`StartAddress ret`的时候,可以自行退出.

就像系统做的那样.

```
        mov edi,API\_RtlExitUserThread

        test edi,edi

        je \_DirectRet

        ;调用用户提供的线程函数地址

        mov eax,var\_StartAddress

        mov ebx,var\_ThreadParam

        push ebx        ;线程的参数

        call eax        ;线程的起始地址

        ;是的用户线程函数返回时,我们可以让线程退出

        push eax

        call API\_RtlExitUserThread
```
