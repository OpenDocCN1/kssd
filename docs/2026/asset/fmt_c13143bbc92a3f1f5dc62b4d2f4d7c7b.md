# 前言

本篇为 CS 4.4 二开基础篇，主要对整个破解流程、漏洞修复、主题修改、新增功能进行讲解，针对CS的扫描方法及Bypass方法后续进行补充。

# 使用工具

1. Idea 2023
2. `java-decompiler.jar`
3. cs 4.4
4. CrackSleeve

# 逆向流程

新建两个文件夹，`cs_bin`里面放原版cs，`cs_src`放之后反编译过后的cs，再将`java-decompiler.jar`放到根目录。目录结构如下：

```
cobaltstrike
├─cs_bin
│   └─ cobaltstrike.jar
└─cs_src
└─java-decompiler.jar
```

切换 java 版本到 java 11：

```
sudo update-alternatives --config java
```

在根目录输入以下命令将 `cs_bin/cobaltstrike.jar` 进行反编译，反编译后的文件放到`cs_src`文件夹中：

```
java -cp java-decompiler.jar org.jetbrains.java.decompiler.main.decompiler.ConsoleDecompiler -dgs=true cs_bin/cobaltstrike.jar cs_src/
```

正常反编译如图所示：

![图片描述](https://bbs.kanxue.com/upload/attach/202309/951654_DEBDXF3CKVA5EH6.png)

新建 idea java 项目，工程命名为`cs`，在工程下面新建两个文件夹：

1. `decompiled_src`（放置反编译版cs解压后的文件）
2. `lib`（放置原版cs）

![图片描述](https://bbs.kanxue.com/upload/attach/202309/951654_TGWBU5JTKSCN3UX.png)

把反编译好的`cs_src/cobaltstrike.jar`,复制到`decompiled_src`中，然后把它解压出来，可看到一个完整的反编译后的目录：

![图片描述](https://bbs.kanxue.com/upload/attach/202309/951654_QXPRVQ87HUTSTJK.png)

接着修改`Authorization()`函数，直接用下面的代码对该函数进行覆盖：

```java
public Authorization() {
    try {
        this.watermark=999999;
        this.validto="forever";
        this.valid = true;
        final byte[] bytes = {94, -104, 25, 74, 1, -58, -76, -113, -91, -126, -90, -87, -4, -69, -110, -42};
        MudgeSanity.systemDetail("valid to", "perpetual");
        MudgeSanity.systemDetail("id", this.watermark + "");
        SleevedResource.Setup(bytes);
    } catch (Exception ex2) {
        MudgeSanity.logException("auth file parsing", ex2, false);
    }
}
```
