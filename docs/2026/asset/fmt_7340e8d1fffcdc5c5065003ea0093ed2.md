
# [原创]Protected Folder算法分析+网络注册机编写

Protected Folder,这是一款我比较喜欢的软件,保护文件挺方便的.

注册方式是本地验证后再网络验证.因此分两部分分析.`delphi2009`编译的.

## 第一部分: 本地注册算法分析.

首先应该明白`delphi`编译器的特点.参数三个之内用寄存器,多的用堆栈.即

`delphi(eax,edx,ecx,stack...)` 从右往左依次传参!参数位置使用的传参变量固定.
