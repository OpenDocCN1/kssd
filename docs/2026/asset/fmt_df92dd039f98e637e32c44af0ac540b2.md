### **新思路：将种子对应成一个大数**

今天在导师的创新实践课上突发奇想，想到python近乎无敌的大数处理，然后写了个demo简单试了试

```
a`=`1`<<`1000000`  `print`(a)
```

发现不到1s就跑出来了，果然快

再试试两个大数的按位或运算

```
a`=`1`  `b`=`11`  `c`=`((a<<`100000`)` -`1`) | (b<<`100000`)`  `print`(c)
```

也很快

那干脆直接用大数统计算了

```
a`=`1`  `b`=`11`  `c`=`((a<<`100000`)` -`1`) | (b<<`100000`)`    `def` `count_one(x):`  `s`=`0`  `while`(x):`  `if` `(x &` `1`):`  `s`+=`1`  `x`=`x>>`1`  `return` `s`    `print`(count_one(c))
```

跑2的100万次方确实有点卡，但是10万很快，而10万已经绰绰有余了
