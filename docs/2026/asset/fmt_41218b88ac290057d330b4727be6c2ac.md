
# [原创]对照Java源码学习smali语法，根据smali代码反推java代码

最近在分析一个加密应用的算法时，发现反编译出来的Java代码，有太多不完美的地方了,for循环尤其刺眼！我想要把相应的算法改成可编译的版本，这就需要对smali语法理解的比较透彻了。

public static void decodeYUV420SPQuarterRes(int[] rgb, byte[] yuv420sp, int width, int height) {
final int frameSize = width * height;
for (int j = 0, ypd = 0; j < height; j += 4) {
int uvp = frameSize + (j >> 1) * width, u = 0, v = 0;
for (int i = 0; i < width; i += 4, ypd++) {
int y = (0xff & (yuv420sp[j * width + i])) - 16;
if (y < 0) {

}
if ((i & 1) == 0) {
v = (0xff & yuv420sp[uvp++]) - 128;
u = (0xff & yuv420sp[uvp++]) - 128;
uvp += 2; // Skip the UV values for the 4 pixels skipped in between

int y1192 = 1192 * y;
int r = (y1192 + 1634 * v);
int g = (y1192 - 833 * v - 400 * u);
int b = (y1192 + 2066 * u);
if (r < 0) {
r = 0;

r = 262143;
}
if (g < 0) {
g = 0;
} else if (g > 262143) {
g = 262143;
}
if (b < 0) {
b = 0;
} else if (b > 262143) {
b = 262143;

rgb[ypd] = 0xff000000 | ((r << 6) & 0xff0000) | ((g >> 2) & 0xff00) |
((b >> 10) & 0xff);
}
}

## 参数映射

第45行这个函数有四个参数，没有返回值：

```java
public static void decodeYUV420SPQuarterRes(int[] rgb, byte[] yuv420sp, int width, int height){
......
}
```

在对应的smali代码中，四个参数分别用`p0`、`p1`、`p2`、`p3`表示：

```smali
.method public static decodeYUV420SPQuarterRes([I[BII)V
.locals 17
.param p0, "rgb" # [I
.param p1, "yuv420sp" # [B
.param p2, "width" # I
.param p3, "height" # I
......
.end method
```

## frameSize 计算

第46行代码，两个参数相乘，赋值给另一个变量：

```java
final int frameSize = width * height;
```

这个`.line 46`表示下面的代码对应的Java代码在第46行，`v2`代表变量`frameSize`：

```smali
.prologue
.line 46
mul-int v2, p2, p3
```

## for循环对应

48行，java中的一个for循环：

```java
for (int j = 0, ypd = 0; j < height; j += 4) {
......
}
```

`if-ge v5, v0, :cond_8`相当于java代码中的`j < height`，意思是如果`v5`(`j`)大于等于`v0`(`height`)则跳转到`cond_8`跳出循环。

如果不满足条件则执行下面的语句，一轮循环结束刚好到`cond_7`，执行`add-int/lit8 v5, v5, 0x4`相当于java代码中的`j += 4`，然后返回`goto_0`，继续判断`j < height`是否成立。

```smali
.line 48
.local v2, "frameSize":I
const/4 v5, 0x0
.local v5, "j":I
const/4 v13, 0x0
.local v13, "ypd":I
:goto_0
move/from16 v0, p3
if-ge v5, v0, :cond_8
......
:cond_7
add-int/lit8 v5, v5, 0x4
goto/16 :goto_0
.line 85
.end local v4 # "i":I
.end local v7, "u":I
.end local v9, "uvp":I
.end local v10, "v":I
:cond_8
return-void
```

## 多重赋值

第49行java代码，三个赋值语句

```java
int uvp = frameSize + (j >> 1) * width, u = 0, v = 0;
```

比较容易理解，其中`uvp = frameSize + (j >> 1) * width`对应smali代码前三行：

```smali
.line 49
shr-int/lit8 v14, v5, 0x1
mul-int v14, v14, p2
add-int v8, v2, v14
.local v8, "uvp":I
const/4 v7, 0x0
.local v7, "u":I
const/4 v10, 0x0
```
