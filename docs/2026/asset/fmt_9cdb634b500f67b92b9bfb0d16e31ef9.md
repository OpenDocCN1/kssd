
## 简称定义

为了描述方便，我们规定几个简称

1. `ea` - 代表一个线性地址
2. `success` - 0代表失败，1代表成功
3. `void` - 表示函数没有返回有意义的值( 可以认为返回的值为0 )
4. `anyvalue` - 表示函数的返回值可能是任意一种类型的
