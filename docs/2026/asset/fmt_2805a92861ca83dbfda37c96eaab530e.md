## CleanPC 破解过程
（简单，适用与初学者）

1. 名称：`gce` （随便）；注册代码：`516688`（随便）

2. `crtl+m`, 下 `bpx hmemcpy` 后下 `g`

3. 按 `F10` 一直到 `00407025` `call USER32!MessageBOXA` 出现错误对话框

4. 往上找找有没有可以跳到此 `call` 的区域，在 `00406f98` `jz 00406fda`
   发现可以，顾上面的 `call` 为要害，`F9`（下断点）, 再 `F8` 跟入

5. 一直 `F10` 到 `004073B5` `call 0040746F`

```
004073ba ADD ESP,BYTE + 08
```
下 `d eax` 真正的注册码
`d edx` 你输入的注册码

你也可以在 `00406f98` `jz 00406fda` 处下 `a` 命令，改为 `jnz` 就可以随便添了！

### 解释
Q: 为什么要在 `ADD` 这里下呢？？

A: 因为在上面你下 `d ecx` 可看见你输入的名字，下 `d edx` 可看见你输入的注册码，顾推测此 `call` 为计算注册码的，你可以跟入，也可以过了此行看注册码（随你啦）。

名称：`gce`

注册代码：`417-15756-339-4242`
