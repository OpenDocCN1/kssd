找脆弱性有许多方法。最广泛使用的是fuzzing。本质上，fuzzing是一种暴力方法。多数例子中，先通过畸形输入造成程序崩溃。获得一次崩溃后，下一步是理解奔溃的根本原因。合适的RCA（根本原因分析）是理解bug本质的基础。这有助于决定bug是否可利用及付出更多努力开发该脆弱性的利用是否有意义。从安全工程师的视角，适当地对脆弱性进行归类并理解bug的本质对确定修复策略很有帮助。简单说，RCA是进行利用开发和制定防护策略的起始。

# 时间回溯调试

[时间回溯调试](https://bbs.kanxue.com/elink@f7fK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6V1L8$3y4K6i4K6u0W2L8h3W2U0M7X3!0K6L8$3k6@1i4K6u0W2j5$3!0E0i4K6u0r3k6h3&6Q4x3X3c8#2M7#2)9J5c8Y4N6A6L8X3c8G2N6%4y4Q4x3X3c8Z5j5i4u0V1N6$3q4J5k6g2)9J5c8X3c8J5K9i4k6W2M7Y4y4Q4x3V1k6V1k6h3u0#2k6$3N6W2M7W2)9J5c8Y4c8A6L8h3g2Q4x3X3c8@1M7X3q4$3k6h3I4Q4x3X3c8V1k6h3u0#2k6$3N6A6L8X3N6Q4x3X3c8G2N6X3g2J5N6X3W2W2N6H3`.`.)是微软的一款记录程序执行过程并能够随时离线重现的工具。它用于从微软客户处搜集非可再现的软件bug。一旦bug在某个开启记录功能的客户环境中重现，客户可以提交记录内容到微软以便工程师分析、检查。

众所周知，理解脆弱性的本质是一个非常痛苦和乏味的过程。如果能访问源代码，可以通过重编译并调试来完全理解bug位置的上下文。如果不能，这就变成了一个试验、错误、猜测的重复游戏。

TTD（时间回溯调试）基于其记录、重现能力有助于RCA过程。TTD[建立在Nirvana和iDNA技术基础上](https://bbs.kanxue.com/elink@180K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3q4D9k6i4S2Q4x3X3c8A6L8$3&6W2M7$3y4#2i4K6u0W2j5$3!0E0i4K6u0r3c8i4y4@1L8%4c8W2M7X3W2U0i4K6t1#2x3U0m8t1L8$3!0C8M7#2)9J5k6i4m8V1k6R3`.`.)。Nirvana是一个[二进制插装技术](https://bbs.kanxue.com/elink@547K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2#2M7$3g2F1K9i4S2Q4x3X3g2G2M7X3N6Q4x3V1k6D9k6h3N6S2j5%4W2Q4x3V1k6W2N6X3g2F1N6s2y4Q4x3V1k6$3k6h3f1H3y4W2)9J5c8X3k6#2L8r3I4Q4y4h3k6H3j5i4m8W2M7Y4y4Q4x3V1k6H3x3e0f1@1i4K6u0V1j5X3S2S2L8Y4y4S2L8r3W2Q4x3X3g2H3k6r3j5`.)。程序执行过程由iDNA踪迹记录器记录并保存为踪迹文件。踪迹文件可以随后通过iDNA踪迹阅读器运行。这个和[Pin](https://bbs.kanxue.com/elink@ae9K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6K6L8$3k6@1N6$3q4J5k6g2)9J5k6h3W2F1N6r3g2D9i4K6u0W2j5$3!0E0i4K6u0r3k6h3&6Q4x3X3c8#2M7#2)9J5c8X3q4J5N6r3W2U0L8r3g2K6i4K6u0r3M7r3W2F1i4K6u0V1j5g2)9J5k6r3c8&6L8X3q4E0K9h3y4Q4x3X3c8T1K9h3&6S2M7Y4W2Q4x3X3c8A6L8Y4y4@1M7Y4g2E0k6h3&6@1j5i4c8A6L8$3&6Q4x3X3c8@1L8$3!0D9)很像，但TTD将保存执行日志和重现执行日志的功能都整合进了Windbg内，实用性更强。

## 重现并记录崩溃

## 堆破坏

可以使用`t-`（向后步过）命令来向后一步步找到发生堆检测失败的条件判定。这是堆检查发生的位置。


`RtlFreeHeap`函数内的安全检查功能的反汇编代码在[Ghidra](https://bbs.kanxue.com/elink@983K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2F1M7$3q4Q4x3X3g2Y4L8%4k6Q4x3V1k6J5k6i4y4G2N6i4u0U0k6i4y4Q4x3V1k6W2N6X3g2J5P5h3!0F1k6g2)9J5c8X3N6Z5K9h3c8J5j5g2)9J5c8R3`.`.)中如下：

![](https://bbs.kanxue.com/upload/attach/201910/827920_QS4JQQKMH4TDF6G.png)

`0x1fb1c84f`处的一字节长度空间被破坏了，我们想找到修改这个位置的代码。可以对这个地址使用`ba`命令来找到修改指令。

```
ba w1 1fb1c84f

g-
```
