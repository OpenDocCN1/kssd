## 【脱壳过程】：

`anota2.exe`是taos发布在exetools论坛上的UnPackMe。“I've working 3 months in this project. A new protection system that includes a packer,antidebugging tricks (old and new), selfmodifying code, compress code section,etc...”

`nikita@work`很快就搞定了脱壳。“`anota2.exe` was created with Thinstall v2.4.61-2.5.14。`note.exe` (YodaProtect v1.02)、`DLL45.DLL` (YodaProtect v1.02)、`steelbox inicio.bmp` (just bmp) 、`DLL2.DLL` (PECompact)”。

脱壳时注意Thinstall和yoda's Protector就行了。

```

ror al,4
```
