### 避开IAT加密

Ctrl+S 搜索命令序列：

```
mov edx,dword ptr ss:[ebp+C]
mov edx,dword ptr ds:[edx]
mov dword ptr ds:[edx],eax
```

刚开始我怎么也搜索不到，后来才发现第一次搜索时要选定整个区块，接着后面的搜索再把整个区块这里去掉，不知是否是我机子的问题。
