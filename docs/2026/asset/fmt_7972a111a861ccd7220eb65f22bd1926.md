```asm
cs:004515c1 mov edx,[ebp-0104]
cs:004515c7 lea eax,[ebp-0100]
```

3. 按数下F10到了`cs:00451513 call 00433c10`，按F8进入此副程式。

4. 再按数下F10到了`cs:00433c2f call [ecx+8]`，按F8进入此副程式。

5. 再按数下F10到了`cs:0043415b call xxxxxx`，接着：

```asm
cs:00434160  cmp [esi+10c],0
cs:00434167  jz 0043416b
```
