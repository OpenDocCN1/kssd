### 第二部分小结

第二部分分析完成，接下来做一个小结，总体行为如下：

1. 获取必要的 API 函数地址。
2. 导入私钥并申请空间。
3. 用导入的私钥解密出一个 dll。
4. 申请一块堆空间，将 dll 写入到堆内存里。
5. 在堆内存中找到 dll 的导出函数地址，并调用。

从上面的分析可以得出，病毒的主体程序实际上只做了一些初始化的操作，到目前为止并没有看到它感染或加密任何一个文件，也没有对用户进行勒索。真正的核心代码在`t.wnry`中，由于这个函数是在堆空间中调用，所以在 IDA 中并没有显示出伪 C 代码，那么接下来需要分析刚刚提取出来的 dll。
