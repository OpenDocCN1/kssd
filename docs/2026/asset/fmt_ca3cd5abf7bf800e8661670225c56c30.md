
# [原创]开源ShellCode生成引擎

潜水太久，没事也发个原创工具`(ObjToShellCode)`。之前研究VS生成ShellCode的时候做的，采用`C++`、`Delphi`两种语言开发。代码太丑陋了，暂时先不放，等我整理下放在`Github`。原理很简单：解析`COFF`格式的`Obj`文件提取需要的信息，然后自己写一个`Loader`来修复即可。支持代码中使用全局变量与多个`Obj`文件解析。做了一些简单的测试，`UI`使用`ASPACK`压缩，只为了压缩后体积比较喜欢，23333。剩下的大家自己测试吧，使用说明见附件里的`Word`。
