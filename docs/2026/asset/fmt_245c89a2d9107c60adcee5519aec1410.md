# 03-恶意代码分析

## 3.1-脱壳

- 是否有壳：`PEiD`查看`xiongmao.exe`存在`FSG 2.0`的壳

![img](https://bbs.kanxue.com/upload/attach/202002/868592_84BEDGUF482V44Z.jpg)

- `x32Debug`中打开`xiongmao`，单步跟踪直到`jmp dword ptr [ebx + 0xc]`，其跳往真实`OEP`处，利用`Scylla`插件进行脱壳，最后保存为`xiongmao_dump_SCY.exe`

![image-20200113083033910](https://bbs.kanxue.com/upload/attach/202002/868592_UPN57VMHVRYBMAR.jpg)
