### 二、处理输入表，避开加密

壳代码已经解压完毕，可以开始处理输入表了，手动`Patch`，避开输入表的加密。

`Ctrl+S` 在“整个段块”搜索命令序列：

```
add esp,44
pop ebp
pop edi
pop esi
pop ebx
retn
```

找到在`00B779F3`处。上面就是输入表的处理代码段。

下面是分析过程。可以在搜索到地址后直接修改了，免得检验出错。
