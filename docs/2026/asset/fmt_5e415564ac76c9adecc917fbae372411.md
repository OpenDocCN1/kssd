
# 验证

由于直接拿 exe 去验证的话，会有很多硬编码我们还没解析到，因此我这里将读取出来的 `codeList` 直接写死一串字节

```c
unsigned char t[50] = {0x50 ,0x5F ,0x40 ,0x4F ,0x0F ,0x84 ,0x50 ,0x5F ,0x14 ,0x7F ,0x78 ,0x0f ,0x90 ,0x95 ,0xB0 ,0x90 ,0xB8 ,0x0F ,0x80 ,0xC2 ,0xC3 ,0xC3 ,0xC2 ,0xC2 ,0xC3 ,0xE0 ,0x90 ,0xE8 ,0x12 ,0x34 ,0x56 ,0x78 ,0xE9 ,0x90 ,0x0F ,0x80 ,0x12 ,0xEB ,0x90 ,0xEA ,0xE8 ,0xE9 ,0x00 ,0x00 ,0x0F ,0x80 };
```

这串字节刚好包含了我们解析的字节，并且很多字节既可以是偏移也可以是 OpCode
