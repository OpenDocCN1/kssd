## 破解总结

这个软件的注册码与用户名无关，只是满足关系式即可（注册码长度必须为16）。

```
if eax>61
 eax=eax-3D;
else eax>41
 eax=eax-37;
else eax=eax-41;
```

前后两字符变换后的代数和等于`0x3D`，就OK了！
