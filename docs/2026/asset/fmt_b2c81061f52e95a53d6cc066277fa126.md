## 破解心得

注册码的每一位根据机器码的相应位算得

`sn[i]=sin(sn[i]*(i+1))+sn[i]+len-i`

一组注册码：

机器码：`B18165DE`

注册码：`I7=697EE`

## 注册机源码

```cpp
void CKeyDlg::OnOK()
{
        UpdateData(true);
        int i,len;
        char sn[80];
        len=m_user.GetLength ();
        strcpy(sn,m_user);
        if (len==0) MessageBox("你还没有输入机器码。","错误",MB_OK);
        for (i=0;i<len;i++){
                sn[i]=(char)(sin(sn[i]*(i+1))+sn[i]+len-i);
        }
        m_password=sn;
        UpdateData(false);
}
```
