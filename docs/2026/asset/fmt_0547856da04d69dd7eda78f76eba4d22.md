
# [原创]Warcarft III的一个MapHack的研究及一个Anti-MapHack方案

其实我是想研究`war3.exe`的自我保护方式的，但是直接从游戏下手又找不到下手的地方，于是就来分析外挂，外挂里面一定有关于游戏的保护方式的信息。

这里使用的游戏版本是`1.20e`
