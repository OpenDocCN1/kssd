最简单的选择之一是从 Google Play 商店的公共应用程序的网站下载 APK。但是，请记住，这些网站不是官方网站，并且不能保证应用程序没有被重新打包或包含恶意软件。一些托管 APK 的知名网站：

#### 从设备中提取应用程序包

从设备获取应用包是推荐的方法，因为我们可以保证应用没有被第三方修改。要从 root 或非 root 设备获取应用程序，您可以使用以下方法：

使用`adb pull`检索 APK。如果您不知道包名称，第一步是列出设备上安装的所有应用程序：

```bash
$ adb shell pm list packages
```

找到应用程序的包名称后，您需要它在系统上存储的完整路径才能下载它。

```bash
$ adb shell pm path <package name>
```

有了 APK 的完整路径，您现在可以简单地使用`adb pull`它来提取它。

```bash
$ adb pull <apk path>
```

APK 将下载到您的工作目录中。

或者，也有像<a href="elink@80fK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6H3L8r3q4&6i4K6u0W2k6$3!0G2k6$3I4W2i4K6u0W2j5$3!0E0i4K6u0r3M7%4c8G2M7X3g2Q4x3V1k6S2M7s2m8K6i4K6u0r3k6r3g2@1j5h3W2D9M7#2)9K6c8X3W2V1i4K6y4p5j5$3!0E0i4K6u0W2k6i4S2@1i4K6u0W2N6h3V1`.">APK Extractor</a>这样的应用程序不需要 root，甚至可以通过您喜欢的方法共享提取的 APK。如果您不想连接设备或通过网络设置`adb`来传输文件，这会很有用。
