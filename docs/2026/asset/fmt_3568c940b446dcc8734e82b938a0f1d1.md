
# [原创]关于SoftICE和Demon-Tools冲突的解决办法

Demon-Tools从4.0以后启用了`sptd`虚拟设备，该虚拟和`ntice`相同，很多人都是通过卸载`dt`来使用`softice`，但是我经过研究以后发现其实这是没有必要的，只要让该设备启动的时候不加载就可以了

```
Windows Registry Editor Version 5.00

[HKEY\_LOCAL_MACHINE\SYSTEM\ControlSet001\Services\sptd]

"Start"=dword:00000000
```

将`start`改成`"Start"=dword:00000001`就可以使用了![](https://bbs.kanxue.com/view/img/face/41.gif)
