
# 用`ollydbg`破《财神电话薄》（用`pcode`编的） (923字)

## 简介

本软件属于共享软件，在不注册的情况下仍然可以使用，但是使用的次数到了一定的时后就会出现提示。不用担心，这只是试用限制的生效，如果已经注册了，就不会有这个限制了。

## 级别

3级（一共十级）

## 声明

我以前破过这个软件，原来的方法和注册码，均可以用。（说实在这个软件还是可以的）。我之所以出`olldbg`破版，是因为看见看雪上有人在找`ollydbg`的中文教程。

## 工具

`ollydbg`

## 步骤

1. 用`ollydbg`加载软件。
2. `Alt+E`切换到`Executable modules`模式。
3. 选中`oleaut32`。
4. 单击右键选中`View Names`。
5. 输入`varbstrcmp`（这样能更快的找到所需要的函数）。
6. 按下`F2`，下断点。
7. 按下`F9`，启动软件。
8. 输入注册名和注册码。
9. 按下“现在注册”。
10. 被中断。
11. 在`ollydbg`的右下脚的框内，就是真假注册码的对比。

## 注

1. 有时当重复多次进行跟踪时，软件就不能运行。解决办法：删除程序和目录下未自动删除的文件。
2. 注册名只支持英文和数字，如果注册码是除了100开头的都是假的。

```
name：erwim  code：100106569
name: www.pediy.com 100895000
name:23217195  code:100469284
```
