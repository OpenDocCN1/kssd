## CPU 特性检查

`arm64_feature_init()`:

检查一下特性：

- Cache 信息
- 支持的加密算法
- 数据高速缓存的支持
- 浮点计算
- SIMD，即单指令多数据集指令，例如向量运算
- address space ID
