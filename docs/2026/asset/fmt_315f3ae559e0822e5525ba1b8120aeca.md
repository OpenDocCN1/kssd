
# [原创]闪讯客户端内存泄漏的简单分析

小菜第一次发文章，没啥技术含量，大家见谅。![](https://bbs.kanxue.com/view/img/face/12.gif)

杭州大部分地区的高校应该都用着闪讯客户端，现在是2.5.0081版本。上学也有个几年了，闪讯作为一个拨号软件搞得这么的复杂确实会让人不爽，但不管怎么说，作为一个每天必点的软件，对它多多少少有了些感情。以前写过个解除wifi限制的软件，自从有了猎豹之后也没啥用了。最近又注意到一个问题，很奇怪闪讯的内存占用一直再涨，一开始也没怎么注意，后来发现如果挂着闪讯的时间略长后，内存占有竟然会变成原来的几十倍。

刚开始连上网时的内存占有：

![](https://bbs.kanxue.com/upload/attach/201406/578829_1jktjdsz03rvwow.jpg)

一段时间后（10几个小时）

![](https://bbs.kanxue.com/upload/attach/201406/578829_iwyyq4kyoaufueg.png)

内存从10几MB升到400MB,这种情况我想基本就是哪里有内存泄露了。于是就觉得一看究竟。

用OD附加上，在`ZwAllocateVirtualMemory`处下断来线索，因为调用`ZwAllocateVirtualMemory`的地方较多，我就又下断`ZwFreeVirtualMemory`来排除有借有还的内存申请部分，最后终于锁定申请内存没释放的地方。

`IsConnectNet`从字面上就可以看出是检测网络(网线)是否连接的函数,而且是需要用来循环检测(5秒)，所以如果这里出现了内存泄露，那就会是持续新的泄露，导致内存不断增大。
