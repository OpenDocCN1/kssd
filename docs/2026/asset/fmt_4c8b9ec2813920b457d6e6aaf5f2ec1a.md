
根据参考资料2，`3942ba0`处的数据，第二列表示的就是属性的不同类型，其中`0x09`表示表示`object`，`0x08`表示`string`，这也和`selob`中对于属性的设置相符：

```
selob.w0 = alert
selob.w1 = unescape("%u1be4%u0c0c")
selob.w2 = alert
selob.w3 = alert
...
```

注意到`object`类型和`string`类型代表的数值之间相差了1，如果利用漏洞造成的增1操作，就有可能把原本的`string`类型修改为`object`类型，从而导致原本的字符串内容当作虚表指针被引用，这也是这次漏洞利用的原理。
