
# [原创]目录合并

## 功能

在一个目录显示本目录和另外一个目录及其他的功能（去除删除/改名/移动）。

## 设计思路

刚开始的思路是：

- **思路1.** 如果用户空间有剩余的空间，就在此插入数据，可是这有很多的缺点，你是知道的。
- **思路2.** 扩大用户的地址空间，或者让利用特殊的标记让用户进程重新申请更大的内存，这个也不好做。
- **思路3.** 也就是现在的这个思路，这是在搞定了注册表的键/值的合并之后，才做的这个。

别的不多说了，看代码和测试的效果图吧！不足之处，敬请指导。

注意这是测试代码，有很多不完整和需要改进的地方，重在思路。
