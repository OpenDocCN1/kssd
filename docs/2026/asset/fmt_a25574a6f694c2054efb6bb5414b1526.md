# 补丁位置

我们找块空地//我找在 `00AB1790`

在 `00A890CD` 那里 `JMP` `00AB1790`

写下如下代码:

```
pushad---------------->堆栈平衡
mov   eax, edx------>把EDX的注册码传入EAX
push  eax----------->压栈
push  0------------->压栈
call  [0AC66E8]------->显示
popad----------------->会服堆栈
add   esp, 18------->还原
mov   ecx, [ebp+C]-->还原
jmp   00A890D3------>回去
```
