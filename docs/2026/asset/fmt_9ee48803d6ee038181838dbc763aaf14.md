
# 浅谈内存监控那点事（一）：R3篇

已知的内存页面监控方式有两种：

## 1. 带有页面分配内存属性的 `MEM_WRITE_WATCH`

1. 只能知道页面被修改，不能知道修改了哪里。
2. `R0` 可以跨进程监控，`R3` 只能监控自身进程。

## 2. 性能工作集

1. 可以跨进程监控。
2. 可以监控被修改的页面大小。
3. 可以监控被修改的内存地址。
4. 可以监控被 `MmProbeAndLockPages` 调用的全部内核函数，即 `R3 ReadProcessMemory/WriteProcessMemory -> R0 MmCopyVirtualMemory`。
5. 可以监控被 `Map` 的地址。
6. 可以监控访问页面的线程。通过线程可以获取程序的 `PID`、文件路径、线程地址等信息。
