
# [原创]拼夕夕 anti-token 分析

前言：拼夕夕 charles 抓包分析发现，跟商品相关的请求头里都带了一个 `anti-token` 的字段，且每次都不一样。那么下面的操作就从分析 `anti-token` 开始了。

## 1. jadx 反编译直接搜索

![](https://bbs.kanxue.com/upload/attach/202205/884888_DT5PUXYW9PP9RB8.jpg)

选中跟 `http` 相关的类，对这个方法进行打印堆栈。

![](https://bbs.kanxue.com/upload/attach/202205/884888_UKC5WA6HA6JHHCF.jpg)

![](https://bbs.kanxue.com/upload/attach/202205/884888_ANCP6GWMUAFE6DW.jpg)

![](https://bbs.kanxue.com/upload/attach/202205/884888_3UNHUFYT5HQBXTE.jpg)

结合堆栈方法调用的情况，找到具体 `anti-token` 是由拦截器类 `f.a()` 方法调用的，在 `http.a.c()` 方法中生成，并且 `http.p.e()` 方法中加入请求头。

在 `http.a.c()` 方法中有一个判断条件，如果为 `true` 则走 `d.a().e()` 方法生成 `anti-token`。

![](https://bbs.kanxue.com/upload/attach/202205/884888_2922MVU795UA443.jpg)

如果为 `false` 则走 `j()` 方法生成 `anti-token`。

![](https://bbs.kanxue.com/upload/attach/202205/884888_H5PQ89N83MTW3SK.jpg)

hook 这个 `i()` 方法返回值，可知获取商品详情接口返回值为 `false`，所以走的是 `j()` 方法进行计算 `anti-token`。

![](https://bbs.kanxue.com/upload/attach/202205/884888_M3KDHT6J3M43MFG.jpg)

`SecureNative.deviceInfo3()` 方法生成，传入的 `str` 为 pdd 生成的固定 id，一个字符串。

![](https://bbs.kanxue.com/upload/attach/202205/884888_KWESWRKN5TNA3S7.jpg)

![](https://bbs.kanxue.com/upload/attach/202205/884888_CCU9KTAAZW5S6VM.jpg)

![](https://bbs.kanxue.com/upload/attach/202205/884888_6CZUB9VBWYZ5QGC.jpg)

根据 `hook_libart` 得到 `info3()` 方法是在 `libodd_secure.so` 中，那么 ida 打开看看这个 so 包。

![](https://bbs.kanxue.com/upload/attach/202205/884888_QJYC5G6V7JKPSG9.jpg)

## 2. 这部分我们采用 unidbg + jnitrace + frida 相结合的方式

unidbg 前期准备的代码这里就不发了，直接调用这个 `info3()` 方法。

![](https://bbs.kanxue.com/upload/attach/202205/884888_MGENH7FDXYQ684H.jpg)

这里提示调用 `gad()` 方法返回一个字符串，那么 frida hook 这个方法拿到这个值，如下图，一个固定的字符串，16 位长度，看着像 AES 的密钥。

![](https://bbs.kanxue.com/upload/attach/202205/884888_X3MA44PA8XWGBDP.jpg)

继续补环境，这里简单补环境就不发了。

![](https://bbs.kanxue.com/upload/attach/202205/884888_HHA86Q94NXJVY8X.jpg)

补完简单的环境代码后，再次运行报这个错误。看错误应该是缺少文件，那么看看日志需要补哪个文件。

继续运行，没有返回值报空指针。`execve()` 函数执行的时候程序 `exit` 了，这里我们返回对象本身。

![](https://bbs.kanxue.com/upload/attach/202205/884888_ZEY95HDEZXR58SE.jpg)

`execve()` 函数执行的时候程序 `exit` 了。

![](https://bbs.kanxue.com/upload/attach/202205/884888_A9W6FB76HJEBN4Z.jpg)

`execve` filename=`/system/bin/sh`, args=`[sh, -c, cat /proc/sys/kernel/random/boot_id]`

这个函数相当于查看 `boot_id` 这个文件信息。

![](https://bbs.kanxue.com/upload/attach/202205/884888_4ZCKQRWR6UFZW56.jpg)
