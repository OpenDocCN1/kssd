
# 解除水印地址方法

简单说一下找解除水印地址方法：查找所有命令：`call 004C7650`

找到的命令：

```text

004C544C   call    004C7650

004C7709   call    004C7650----->发现此地黄金10俩(很重要),点击进入
004C7734   call    004C7650
004C7754   call    004C7650
```

# PhotoZoomPro2 2.2.4 Photoshop插件破解

## 1. PhotoZoomPro2 2.2.4 Photoshop插件成功破解!

要把扩展名改为 DLL，用 `Aspr2.XX_unpacker_v1.0` 进行脱壳（感谢 VolX，你的脚本大强啦！）

破解过程跟破解主程序方法都差不多。

以下数据可以帮你快速定位修改：

一处：

```text
83 C4 10 84 C0 75 0C 46 3B 75 0C
```

二处：

```text
83 C4 10 84 C0
```

## 2. 目的：去掉 PhotoZoomPro2 2.2.4 Photoshop插件 Unlock 注册按钮

![](https://bbs.kanxue.com/upload/attach/200706/22282_r3d2yvsfi1het8f.jpg)

![](https://bbs.kanxue.com/upload/attach/200706/22282_56ik9s2srhpu2ol.jpg)

由于是 PS 插件，我们一般要中断 PS 加载了插件即可！
