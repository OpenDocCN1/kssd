# Pwnlib 设置

## terminal 指定

`context.terminal = ['terminator','-x','sh','-c']`

第一个参数 `terminator` 为本地可用的 terminal。

## 输出交互信息

`context.log_level = 'DEBUG'`

这样可以输入对程序的输入和程序的输出信息
