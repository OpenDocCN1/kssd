
## 条件表达式用法

**用法：** 条件必须用闭括符括起来。

```text
Operator Meaning
== Logical Equal
!= Logical Not equal
> Logical Greater than
>= Logical Greater than or equal to
< Logical Less than
<= Logical Less than or equal to
& Bit and
| Bit or
^ Bit xor
>> Bit shift right
<< Bit shift left
;not support
! Logical NOT
&& Logical AND
|| Logical OR
+ add
- sub
* mul
/ division
% mod
() parenthesis
(byte)
(word)
(dword)
* get value from point
+ positive - negative
```

示例：

```text
g if ((byte)*eip==c2)
g if (*esp==ebx)
go if (eip>401000&&eip<<10000000)
```

未注册版本，条件表达示长度有限制。

## Do statement

**用法：** `<statement>` 可以是任何有效的 TRW2000 的命令，但必须用双引号""引起来。

示例：

```text
BPX cs:401000 if (eax>200) do "d eax"
GOX 401000 if (cs!=28) do "d ss:esp"
G if (eip<1000)
```
