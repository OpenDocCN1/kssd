### 3、感染体大小的取得

我的解决方案是：
在所有的代码和数据前面放置`KGetStartAddr`函数

```
/**
*@brief 取得当前函数的地址
*
*@return 返回当前函数的地址
*/
ULONG __declspec(naked) KGetStartAddr()
{
    __asm
    {
        call lbl_Next
lbl_Next:
        pop eax
        sub eax, 5
        ret
    }
}
```

在所有的代码和数据前面放置`KGetEndAddr`函数

```
/**
*@brief 取得当前函数末的地址
*
*@return 返回前函数末的地址
*/
ULONG __declspec(naked) KGetEndAddr()
{
    __asm
    {
        call lbl_Next
lbl_Next:
        pop eax
        add eax, 5
        ret
    }
}
```

感染体大小= `KGetEndAddr()` - `KGetStartAddr()`
