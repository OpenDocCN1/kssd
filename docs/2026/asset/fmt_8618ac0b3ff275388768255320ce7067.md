## 滥用返回指针

在反汇编部分我们看不出函数有调用`_P2`就`retn`了，成功欺骗了F5。

```
void 滥用返回指针()

{

	printf("定位");

	_asm

	{

		call _P1

_P1:   

		add [esp],5

		retn

	}

_P2:

	printf("模糊函数边界！");  //这里会被执行

	return;

}
```

## 滥用结构化异常处理：成功欺骗了 F5

![](https://bbs.kanxue.com/upload/attach/202004/795357_UGB7995GCP985F4.jpg)

```
void 滥用结构化异常处理()

{

	printf("定位");

	_asm

	{

		mov eax, _PE1

		push eax

		push fs : [0]

		mov fs : [0], esp

		xor ecx, ecx

		div ecx

		retn

_PE1:

		mov esp,[esp+8] 

		mov eax, fs : [0]

		mov eax, [eax]

		mov eax, [eax]

		mov fs : [0], eax

		add esp, 8

	}

	printf("结构化异常");

	return;

}
```
