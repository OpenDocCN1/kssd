## Unity3D符号表恢复

在做这一步操作之前，机智的人已经将可执行文件脱到IDA文件中开始分析了，APP脱壳后解压ipa，然后查看app1包内容，主程序可执行文件使我们首要分析目标，一般来说是整个包中最大的那个文件。

![](https://bbs.kanxue.com/upload/attach/202006/776128_FC4VGAEKUX3GEA4.jpg)

在IDA分析的过程中，我们刚好通过`Il2CppDumper`来提取符号表，提取符号表需要两个文件，一个是上述的主程序可执行文件，另一个则是符号表文件`global-metadata.dat`，iOS下该文件位于`xxx.app/Data/Managed/Metadata`目录下

![](https://bbs.kanxue.com/upload/attach/202006/776128_AXN49B79TK765DD.jpg)

先后选择两个文件之后，程序跳出需要输入Unity version

![](https://bbs.kanxue.com/upload/attach/202006/776128_2EJT6SYCYC89SD7.jpg)

我们怎么确认到底是用了什么版本的Unity呢，只要在IDA里搜索字符串`X-Unity-Version`即可，调用的地方会出现版本号，我们要找的版本号即`2018.4.3f1`

![](https://bbs.kanxue.com/upload/attach/202006/776128_CREVP24VE75QWSJ.jpg)

在输入版本号之后，选择3即可

![](https://bbs.kanxue.com/upload/attach/202006/776128_DGB9M5ZNT5WE3UF.jpg)

同时在`Il2CppDumper`的目录下，会生成`dump.cs`和`script.py`两个文件

![](https://bbs.kanxue.com/upload/attach/202006/776128_K4KBMQQ3VN4VP67.jpg)

该脚本的主要作用是辅助IDA识别IL2CPP表函数名，在加载脚本之前IDA识别的函数形如`sub_xxxxxxx`

# 直捣黄龙

分析定位修改点之后，就可以对游戏进行修改了，原本是想通过免越狱Hook实现对游戏的修改，但是尝试了多次一直hook不成功，多次查找发现未越狱iOS并不支持`MSHookFunction`方式进行hook，同时没法对形如`sub_xxxxx`函数进行inlinehook。

这里介绍两种修改方式，一种是通过iOS越狱Hook来实现对关键函数的Hook修改，主要依赖于`MonkeyDev`，游戏修改了之后肯定不会天天抱着一个越狱手机来玩，所以这里准备的另一种种修改方式是针对未越狱手机的，通过直接修改汇编，重打包签名ipa安装到手机上，主要依赖于`IPAPatch`

## iOS越狱修改

iOS越狱插件的编写这里采用MonKeyDev，如何使用可见[官方文档](https://bbs.kanxue.com/elink@413K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6m8L8r3!0F1k6f1#2G2L8X3E0W2P5g2)9J5c8V1#2G2L8X3E0W2P5f1c8W2N6W2)9J5c8Y4N6A6K9$3W2Q4x3V1k6Q4x3U0g2q4y4g2)9J5y4f1u0o6i4K6t1#2z5o6m8Q4x3U0g2q4y4g2)9J5y4f1p5%4i4K6t1#2z5p5u0Q4x3U0g2q4y4q4)9J5y4f1u0p5i4K6t1#2b7V1k6Q4x3U0g2q4y4#2)9J5y4e0V1@1i4K6t1#2b7e0R3`.)

### 注意事项

- 在hook不同APP时将Tweak的plist中Bundles修改应用对应的Bundleid

- 在Build Settings——>User-Defined新建项`CODE_SIGNING_ALLOWED`，赋值为NO，否则编译会报错

- File——>Project Setting将Build System修改为Legacy Build System否则编译报错

- 切记安装sshpass

### 插件编写

MonKeyDev支持多种Hook框架，我这里使用Tweak插件。

具体hook代码如下：

```
#import <substrate.h>
#import <dlfcn.h>
#import <mach-o/dyld.h>
// 用于保存原函数指针
int (*old_get_Gold)();
// 新函数
int new_get_Gold()
{
return 9999;
}
%ctor{
// 执行hook
unsigned long Gold = _dyld_get_image_vmaddr_slide(0) + 0x1011aa060;
MSHookFunction((void *)Gold, (void *)&new_get_Gold, (void **)&old_get_Gold);
}
```

# 隔山打牛

iOS免越狱hook主要是通过iosOpenDev生成dylib注入目标APP实现Hook，iosOpenDev是apple官方支持的插件生成工具，可直接由Xcode生成。可生成CaptainHookTweak、Logos Tweak两种dylib。在注入dylib之后对APP进行重打包签名。

我们接下来用到的MonKeyDev是对原有iOSOpenDev的升级，更加方便于非越狱插件的编写。

### 新建项目&编译

MonKeyDev安装完成之后，打开Xcode新建项目，滑动到最下方可以看到MonKeyDev提供的模块，选择第一个。

![](https://bbs.kanxue.com/upload/attach/202006/776128_KZSF4JHSFZ8WBAW.jpg)

新建之后需要配置General——>Signing，设置自己的AppleID后续用于签名。

![](https://bbs.kanxue.com/upload/attach/202006/776128_U3Z7XM8Z8GV3A7A.jpg)

接下来将砸壳后的ipa或ipa解压后的xxx.app放入`Your_Project/TargetApp`目录下，编译整个项目，最终安装到未越狱手机上信任之后正常运行表明签名成功。
