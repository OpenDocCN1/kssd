
# [原创]刷网页访问量工具逆向分析

```asciiarmor
程序名称：刷网页访问量工具
使用工具：PEID、OD
```

先看看程序是怎么注册的吧

![1](upload/attach/201902/829513\_D6HZ62PE9ETB4SR.png)

输出错误的注册码会弹框。

不多废话，直接上程序，习惯先用`PEID`查看信息

![2](upload/attach/201902/829513\_7CGT4JNNM3TDZXD.png)

Delphi程序，直接拖入`OD`，程序出现提示框，可以搜索字符串“注册码错误”，也可以定位按钮事件，这里我选择定位按钮事件进行分析，直接上脚本下断点

![3](upload/attach/201902/829513\_VC5Y9G22R9F7UM6.png)

点击完成注册，程序断了下来

![4](upload/attach/201902/829513\_H2AKZH582K5AC8Q.png)

跟进`call`

![5](upload/attach/201902/829513\_ERCJ3C95XX34AUC.png)

果然找对了地方，下面开始分析

![6](upload/attach/201902/829513\_2BETACBFX7YHYMM.png)

先不管这些，先将程序暴力破解

将`JE`改为`JMP`，继续跟进程序

![7](upload/attach/201902/829513\_84CTN7GAY55CGAH.png)

看到注册成功了，可跳转却成立了，继续暴力，`JE`改为`JNE`，运行程序

![8](upload/attach/201902/829513\_MFQDSWQB254VDMR.png)

重启程序

![9](upload/attach/201902/829513\_XXS37ZVA7A93PEM.png)

有重启验证，暴力破解了每次弹个注册框也很烦，那么就开始追码吧

这个程序的注册还算比较简单，只有两处判断，第一处是判断输入的注册码长度是否为12位，先随意输入12位注册码`123456789ABC`

![10](upload/attach/201902/829513\_VM6AG5RUFVX2QB4.png)

成功过了第一个跳转，继续分析

![11](upload/attach/201902/829513\_YGRJFEES2J5APCB.png)

分析关键函数

![12](upload/attach/201902/829513\_7293XPFR6427XHG.png)

判断输入的前四位是否为`0871`，然后我以为程序还会判断后8位，然后，然后，我发现我想多了。。。。

在内存中要判断的数据改为`0871`

![13](upload/attach/201902/829513\_PBWNRPKJD876KJT.png)

跳转不成立，说明已经成功

前面已经知道程序有重启验证，在这里看到了一个`ini`后缀的文件，应该是配置文件，继续跟踪分析

![14](upload/attach/201902/829513\_JFN4TX49DBHDQS4.png)

找到了配置文件存放的目录，找到文件并打开

![15](upload/attach/201902/829513\_27EQ2CCZ436VTRU.png)

这是错误的注册码，重启程序发现果然需要注册，将文件中`KEY`值前四位改为`0871`，保存文件，继续重启程序，已经成功，直接进入页面

![16](upload/attach/201902/829513\_X8NBSB2NFXS9PNJ.png)

至此，分析完成
