
# CLD 汇编代码

# 经验分享

## 0x01: 哈希列表的顺序

首先，哈希列表的顺序按这种安排非常合理，尤其是在连续调用 `bind`、`listen`、`accept` 的地方，可以有效节约代码，提高效率。

## 0x02: 调试中的 `int 3` 用法

当调试代码时，如果想查看内存分布、寄存器值等信息，可以使用 `int 3` 中断。通过 OD（OllyDbg）自动附加，就能看到详细的内存和寄存器状态。

## 0x03: 构造 `STARTUPINFO` 结构

在布置 `STARTUPINFO` 结构时，如果手头没有参考资料，可以利用编译器帮我们计算。如下图所示：

![](https://bbs.kanxue.com/upload/attach/201312/396123_152170d79a5f45d6.jpg)

这样我们就获得了 `dwFlags` 的值和偏移量，进而可以布置内存构造 `SI` 结构：

![](https://bbs.kanxue.com/upload/attach/201312/396123_ac413232592384f8.jpg)

这样我们就得到了输入句柄、输出句柄、错误句柄的偏移量，继续构建关键数据。
