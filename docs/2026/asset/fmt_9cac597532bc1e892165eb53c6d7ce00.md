
# Active Messenger（恒创企业信使）v3.03跟踪

Active Messenger（恒创企业信使）是一款专为企业定制的即时消息系统，其目标是解决企业的沟通及协同的问题，提高工作。企业员工可以利用 Active Messenger 随时随地的进行即时交流、传送文件。

## 破解工具

`Ollydbg1.09` 中文版
