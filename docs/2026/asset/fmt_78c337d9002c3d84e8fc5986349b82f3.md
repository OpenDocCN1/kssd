
# [原创]WarCraft III的NnMH辅助开源

以前研究war3的时候编写的一款辅助工具， 没有修改任何代码段，全部采用修改虚函数表的方式，使用了很多小技巧。送给大家玩玩。

增加以下功能：

1.视角调整：

此功能关闭状态下直接鼠标滚轮是游戏默认视角调节，按住Ctrl+滚轮是视角远近调节

## 8.11发布

暑假做了个War3外挂，支持x86 XP, War3 1.24E(6387)

使用方法，先打开游戏，再打开外挂，最好在进入游戏之后再打开外挂

外挂开启成功的表现：屏幕左上角出现外挂窗口，游戏中出现外挂菜单

进入游戏后就会自动打开菜单，也可以输入聊天命令 NNMH 打开菜单

理论上是通用于全平台的，我测试了VS,HF可以用

功能如下：

全图去迷雾：大小地图黑雾变浅雾，可显示不可见的树木

全图显单位：大小地图显单位，显神符，小地图可恢复

锁定鼠标移动范围：智能锁定鼠标移动范围，应该够智能的了。

主机踢人功能：

1-断开连接，直接踢掉，对方显示断开连接

2-等待主机，直接踢掉，对方显示等待主机

3-虚拟在线，直接踢掉，对方显示断开连接，但是其他玩家仍然看到他在线

反检测：不可选中视野外单位，可过REP,MHCD把，貌似没有1.24E的MHCD

完美过信长的-test,看见青蛙输入-test检测也不会崩溃游戏。

过蓝宝石的-mh检测

如果你无法打开程序，确认你系统是否是XP，程序加了壳，虚拟机可能无法运行

如果提示不支持的版本，确认你用的是1.24E的魔兽进游戏

有什么问题建议什么的都可以发邮件给我Kingsdows@gmail.com

现在暑假快结束了，这只是一个demo，以后有时间我会把功能做全，版本做全，支持win7
