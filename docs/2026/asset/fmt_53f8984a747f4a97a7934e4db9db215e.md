__int64 __fastcall check(unsigned int Id, const char *s, int a3)
{

  {

      return 0LL;
  }
  else if ( !strcmp(s, "MANAGER_write") )
  {

`manager_operation`中提供了两类操作，分别是`manager_write/read`与`manager_write_usr/manager_read_usr`。

`check`复用了`usr`中的`check`，仍然是对`read`操作无检查。

对`manager_write`进行了堆块权限的检查。

对`manager_operate_usr`是根据进行的最后一次`usr`操作的`chunk`确定，还会额外调用`checkvisit`进行检查。
