### run_write.sh
模拟受害者不断使用 `docker cp` 命令将宿主机上的文件复制到容器内的场景，一旦触发漏洞，受害者指定的宿主机文件（`localpath`）将覆盖容器内恶意符号链接在宿主机文件系统解析后指向的文件（`w00t_w00t_im_a_flag`）。

`run_write.sh`内容如下：

```

# 创建flag

--build-arg "SYMSWAP_PATH=$SYMSWAP_PATH" \

```
