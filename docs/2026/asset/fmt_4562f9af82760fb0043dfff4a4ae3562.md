
# [原创]Linux kernel Exploit 内核漏洞学习(0)-环境安装

## 前言

在 Linux 上面搞事情很多东西都可能需要我们利用源码来自己编译，相对于 Windows 来讲可能会比较麻烦和耗时，这个过程中肯定会遇到很多报错，所以一定要有耐心……

## 方法步骤

### 编译内核

首先到 Linux 内核的[官网](https://bbs.kanxue.com/elink@25fK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2C8k6i4u0F1k6h3I4Q4x3X3g2G2M7X3N6Q4x3V1j5`.)下载一份内核源代码并解压：

![kernel_download](https://bbs.kanxue.com/upload/attach/201907/818602_GXTAQZU487BYJN7.png)

至于需要下载的版本，随意就好，我下载的是 5.2.1 的……

然后先安装一些依赖：

```
sudo apt-get install git fakeroot build-essential ncurses-dev xz-utils libssl-dev bc
```

这些依赖并不一定全部概况完了，在编译的过程中可能在报错信息中还要提示你安装一些依赖，具体根据报错提示再进行安装就可以……

然后进入解压目录：

```
make menuconfig
```

![linuk-kernel](https://bbs.kanxue.com/upload/attach/201907/818602_4X5BM9SWTCE54UZ.png)

这里会跳出一个设置框：

![set](https://bbs.kanxue.com/upload/attach/201907/818602_H6C3MBS247GJKRN.png)

注意下面的配置就好：

```
KernelHacking -->
选中Compile the kernel with debug info
选中Compile the kernel with frame pointers

Processor type and features-->
去掉Paravirtualized guest support
```

然后 save，保存 `.config` 就可以：

![config](https://bbs.kanxue.com/upload/attach/201907/818602_UUY395MKB6ZM8V7.png)

然后：

```
make -j4
```

虚拟机分配了 4 个核，使用 `-j4` 可以快一点……

![make -j4](https://bbs.kanxue.com/upload/attach/201907/818602_TFGUT45FDFTBB62.png)

这个过程是比较漫长的，如果你的 kernel 内核比较低或依赖不够的话，就会报比较多的错误，这需要根据你具体情况百度了，耐心……

当 `make` 结束了就可以：

```
make all
```

![make_all](https://bbs.kanxue.com/upload/attach/201907/818602_7WC6K3EHNF5NY57.png)

还是可能会报错，不过都可以百度到，最多改一下 `Makefile` 文件的，不紧张……

最后就可以：

```
make modules
```

![make modules](https://bbs.kanxue.com/upload/attach/201907/818602_R6XX966YXFQERQQ.png)

我们可以从 `./arch/x86/boot/` 拿到 `bzImage`，从源码根目录拿到 `vmlinux`……

### 编译 busybox && 构建文件系统

```
cd ..
wget https://busybox.net/downloads/busybox-1.31.0.tar.bz2
tar -jxvf busybox-1.19.4.tar.bz2
cd busybox-1.19.4
make menuconfig
make install
```

其中 `busybox-1.31.0.tar.bz2` 建议下载最新版的……

同样 `make menuconfig` 的时候需要设置：

![busybox](https://bbs.kanxue.com/upload/attach/201907/818602_VKWEG9QAKTA29S5.png)

```
Settings -> Build Options -> Build static binary (no shared libs) 编译成静态文件

关闭下面两个选项:
Linux System Utilities -> [] Support mounting NFS file system 网络文件系统
Networking Utilities -> [] inetd (Internet超级服务器)
```

编译完 `make install` 后，在 busybox 源代码的根目录下会有一个 `_install` 目录，编译后的文件会存放在下面：

![_install](https://bbs.kanxue.com/upload/attach/201907/818602_BQ9QGVBYFAVG4DA.png)

然后我们需要在里面配置一下：

```
cd _install
mkdir proc sys dev etc etc/init.d
vim etc/init.d/rcS
chmod +x etc/init.d/rcS
```

其中 `vim etc/init.d/rcS` 的内容：

```
#!/bin/sh
mount -t proc none /proc
mount -t sysfs none /sys
/sbin/mdev -s
```

然后利用命令创建文件系统：

```
find . | cpio -o --format=newc > ../rootfs.img
```

![img](https://bbs.kanxue.com/upload/attach/201907/818602_FZKXHQ4PN4N6YQC.png)

最后我们就可以使用 `qemu` 来运行内核了：

```
qemu-system-x86_64 \
-kernel ~/tools/linux-5.2.1/arch/x86_64/boot/bzImage \
-initrd ~/tools/busybox-1.31.0/rootfs.img \
-append "console=ttyS0 root=/dev/ram rdinit=/sbin/init" \
-cpu kvm64,+smep,+smap \
-nographic \
-gdb tcp::1234
```

其中：

```
-cpu kvm64,+smep,+smap 设置CPU的安全选项，这里开启了smap和smep
-kernel 设置内核bzImage文件的路径
-initrd 设置刚才利用busybox创建的rootfs.img，作为内核启动的文件系统
-gdb tcp::1234 设置gdb的调试端口为1234
```

![qemu](https://bbs.kanxue.com/upload/attach/201907/818602_5JY6WUZ5BSEUVME.png)

### 加载驱动

加载驱动很简单，只需要命令 `insmod` 就可以，然后 `rmmod` 可以卸载驱动，`lsmod` 可以查看加载了的驱动……

![insmod](https://bbs.kanxue.com/upload/attach/201907/818602_JUK6KRH55NGQ3DH.png)

### gdb 调试

我们用 qemu 运行内核的时候，加了一个 `-gdb tcp::1234` 的参数，qemu 会在 1234 端口起一个 `gdb_server`，我们直接用 `gdb` 连上去：

![gdb](https://bbs.kanxue.com/upload/attach/201907/818602_5AFUSP9P4FFRR47.png)

同时我们为了调试内核模块，利用 `add-symbol-file` 命令加载了驱动的符号文件，并且加上了系统里面驱动的加载基地址……
