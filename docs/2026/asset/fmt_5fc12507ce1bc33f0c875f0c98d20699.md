## 修改方法

修改`PackageParser`类，该类在文件`frameworks/base/core/java/android/content/pm/PackageParser.java`中。

在`PackageParser`类中添加下面的方法：

```
private void addUsersPermission(Package pkg, String usersPermission) {

    int index = pkg.requestedPermissions.indexOf(usersPermission);

    if (-1 == index) {

        pkg.requestedPermissions.add(usersPermission.intern());

        pkg.requestedPermissionsRequired.add(Boolean.TRUE);

    } else {

        pkg.requestedPermissionsRequired.set(index, Boolean.TRUE);

    }

}
```

在`PackageParser`类`parseBaseApk`方法中添加下面语句：

```
addUsersPermission(pkg, <权限字符串>);
```

添加位置：在该方法的最后一行代码前添加。

## 权限字符串

如果要添加网络权限，那么权限字符串传入：`android.permission.INTERNET`，代码见下：

```
addUsersPermission(pkg, "android.permission.INTERNET");
```

以此类推，权限字符串是`AndroidManifest.xml`中`uses-permission`标签中所能设置的权限。
