# 样本改进建议：

1. 虚假分支可以再假点，不要 `if` 可以恒为真或者假
2. 状态变量也可以拆分成常量进行计算，虽然滑块已经很慢了，但是也不差这点了
3. 状态变量可以随机穿插在 `case` 语句块里面，不要单独放在最后
4. 可以的话，就随机代码，像瑞数那样。

若对还原 `jsvmp` 感兴趣的话可以看下我写的这篇文章：[**如何使用AST还原某音的jsvmp**](https://bbs.kanxue.com/elink@7d9K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3f1#2x3Y4m8G2K9X3W2W2i4K6u0W2j5$3&6Q4x3V1k6@1K9s2u0W2j5h3c8Q4x3X3b7I4y4K6f1J5y4K6f1#2i4K6u0V1x3g2)9J5k6o6q4Q4x3X3g2Z5N6r3#2D9)
