
# 初学者(20) (1千字)

## FTP Control

软件版本：4.2.0.0 软件大小：4191KB 运行平台：Win95/98/NT 下载

软件简介：随着FTP软件技术的发展，我觉得现在好的FTP软件的起码标准配置是应该具有下面等功能：支持断点续传、拖拽、自动重拨、远程编辑文件等，但是只有这些功能是无法在FTP软件中一举夺取桂冠的，如果想脱颖而出还必须有一些自己的绝招，“江山代有人才出”，这个时候FTP Control出现了，它带给我焕然一新的惊喜。而FTP Control不仅有以上提到的所有特性，而且它还有华丽清爽界面，并支持整个子目录的拽复制、定时定位传输、后台传输、剪贴板URL监测、支持防火墙和代理服务器等功能，如果你对Getright和Netant的使用比较熟悉，你会发觉FTP Control还有一个类似Getright、Netant一样的“购物篮子”（是不是很惊喜？），在使用的时候，你只需要把选中的文件先放在篮子里（这些文件可以是不同目录或者是不同驱动器的）当选择结束后，单击“购物篮”，然后FTP Control会让你选择传输的类型--Up/Download,这个非常易用的功能是其他十一种软件所没有的，在测试过程中，我发觉在速度与稳定性上FTP Control表现得都非常优秀，可以说它是十一个软件中最为强大、完美的一个，而且它的价格也是参评软件中比较理想的一个。（因为LeechFTP和WS_FTP LE它们是免费软件，所以FTP Control 当然没法和它相比。）......
