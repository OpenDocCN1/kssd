# 六、关于流量检测

这次我们一起剖析了CobalStrike的通信协议，可见其通信协议是可靠的，`RSA`传输`AES`的密钥，`AES`的密钥加密后续通信，这也是`c2`的常规通信手法了。但为什么能被天眼所探测出呢？如果在配置好`profile`和证书的情况下，天眼还是能检测到流量通信，不妨一试删除默认的`.cobaltstrike.beacon_keys`，

![](upload/attach/202104/718877_4VVAMKXUZZKSUJ6.png)

这个文件是可以删掉的，删掉后会重新生成新的，但改文件保管着`RSA`的公私钥，所以要注意的是一旦删掉后原来的链接会丢失。同样也可以使用`ExternalC2`、`Lambda Redirector`进行流量规避。
