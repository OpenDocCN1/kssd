
# [原创]滚动的天空破解分析

滚动的天空破解

模拟器采用的是夜神模拟器。

Apk 名称：`滚动的天空_1.1.0.140_内购版`。

使用 Android Killer 打开 apk。

一种思路是从 java 层搞，参考 `c98K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3f1#2x3Y4m8G2K9X3W2W2i4K6u0W2j5$3&6Q4x3V1k6@1K9s2u0W2j5h3c8Q4x3X3b7$3x3K6t1I4y4K6S2Q4x3X3b7I4i4K6u0V1x3g2)9J5k6h3S2@1L8h3H3`，通过把支付失败的代码替换成支付成功的代码。

本文换个思路。

Android Killer 反编译后发现是基于 unity3d 的。

1. 解压 apk，找到 `Assembly-CSharp.dll`，位于路径：`滚动的天空_1.1.0.140_内购版\assets\bin\Data\Managed`。

2. 用 Dnspy 打开 `Assembly-CSharp.dll`，搜索字符串 `balls`，找到球的初始个数为 15 的 `getInitNum` 函数。Dnspy 编辑代码，将初始值修改为 1500。

    ![](https://bbs.kanxue.com/upload/attach/202002/105259_3FHXNBFRPJHCBMP.jpg)

    Dnspy 保存模块。

3. 将 Android Killer 反编译目录下 `AndroidKiller_v1.3.1\projects\滚动的天空_1.1.0.140_内购版\Project\assets\bin\Data\Managed\Assembly-CSharp.dll` 替换，编译 apk 文件。

    ![](https://bbs.kanxue.com/upload/attach/202002/105259_E6CCZUX5R6DDH4F.jpg)

    ![](https://bbs.kanxue.com/upload/attach/202002/105259_8MT3UWBH33XBU2R.jpg)

4. 购买无限球函数 `private void PayInfiniteSuccess()`，购买护盾成功函数 `public void Pay100shieldsSuccess()`。将无限球函数和加护盾的函数部分代码直接编译到 `getInitBallNum()` 中：

    ```csharp
    public static int getInitBallNum()
    {
        PlayerProfiler.OnPremiumModePurchase();
        GameHud.AddBalls(GameManager.StartingLives);
        Singleton<EventSystem>.GetSingleton().DispatchEvent(new EventObject(13, null));
        PropsShield.AddShield(65536);
        return CloudUtils.getIntValue(CloudUtils.KEY_INIT_BALL_NUM, 1500);
    }
    ```
