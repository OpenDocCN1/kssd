
# 一个代码混淆器的思路

首先，反汇编PE的`.text`节，结合重定向表的数据，分析获得指令之间的跳转、调用等引用关系。

然后，就可以进行混淆操作了。

## 混淆操作

1. 用混淆引擎，将指令变换执行方式，但意义不变。

   如：`inc xxx ==> add xxx , 1`

2. 将一个完整的指令段拆分成多个段，然后在指令结构体中建立新的引用关系。

   如：

```
a
b
c
==>
jmp tag1
tag2:
b
c
jmp tag3
tag1:
a
jmp tag2
tag3:
接下来的指令
```

3. 生成新的可执行程序。
