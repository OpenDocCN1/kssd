## 0x01 漏洞介绍

### 1. 暴露组件 AIDL 利用漏洞

AIDL 是 Android 中 IPC（Inter-Process Communication）方式中的一种，AIDL 是 Android Interface Definition Language 的缩写。AIDL 的作用是让 APP 绑定一个其他 APP 的 service，这样 APP 可以和其他 APP 交互。

```
通过 AIDL 绑定暴露的 service 进行远程访问。
```

### 2. `next_intent` 漏洞

Intent（意图）主要是用于激活组件和解决 Android 应用的各项组件之间的通信。

```
next_intent 是指在代码中出现可供透传 Intent 的代码，例如方法中出现新的 Intent，使用旧 Intent 的数据进行激活组件行为。
```
