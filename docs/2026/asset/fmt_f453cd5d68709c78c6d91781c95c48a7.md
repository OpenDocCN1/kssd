注册名须不小于两位，注册码位数为8位以上，主要思路如下：

1. 注册名第一位的 ascii 码与 `$57` 做 `or` 运算，再与 `A` 进行 `idiv` 运算，余数“7”为注册码第一位；
2. 注册名第二位的 ascii 码与 `$45` 做 `or` 运算，再与 `A` 进行 `idiv` 运算，余数“1”为注册码第二位；
3. 注册名第一位的 ascii 码与 `$42` 做 `or` 运算，再与 `A` 进行 `idiv` 运算，余数“1”为注册码第三位；
4. 注册名第二位的 ascii 码与 `$43` 做 `or` 运算，再与 `A` 进行 `idiv` 运算，余数“9”为注册码第四位；
5. 此时 `ebp=$285`（用户名的 Ascii），与 `A` 进行 `idiv` 运算，余数“5”为注册码第五位；
6. 第六位以后任意
