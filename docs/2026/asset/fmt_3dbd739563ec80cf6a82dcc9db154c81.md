简单介绍一下 `unlink`，[CTF Wiki](<elink@d03K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6U0N6r3k6Q4x3X3c8%4K9h3E0A6i4K6u0W2L8%4u0Y4i4K6u0r3M7s2N6F1i4K6u0r3L8r3W2F1N6i4S2Q4x3V1k6#2M7$3g2J5i4K6u0V1L8h3!0V1k6g2)9J5c8X3S2W2j5i4m8Q4x3V1k6H3N6r3#2S2L8r3I4G2j5K6u0Q4x3V1k6#2L8X3I4A6L8X3E0Q4x3V1j5>) 里有介绍，简单总结如下：

1. 首先找到要进行 `unlink` 的 `chunk`（这里记为 `P`）的前后堆块，`FD = P->fd, BK = P->bk`。
2. 进行安全检查，glibc2.23 的潦草判断条件如下：`FD->bk == P, BK->fd == P`。
3. 然后执行 `FD->bk = BK, BK->fd = FD`。
4. 当某个 `non-fast` 大小的 `chunk` 被释放时，就会根据 `PREV_INUSE` 位检查其前后堆块是否处于释放状态，如果是就会将前面或后面的堆块取出并与当前堆块合并。取出前面或后面的堆块 `P` 的过程就是 `unlink`。
