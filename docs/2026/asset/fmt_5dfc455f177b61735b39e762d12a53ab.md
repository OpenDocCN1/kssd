## 第一步

在系统库`Resource.h`文件里加入`"MOVEABLE  PURE"`字符串，这个文件在`\masm32\INCLUDE`目录中。

## 第二步

在工程文件中`RC`资源文件里加入：

`1 24 MOVEABLE PURE "res\Master.manifest"`

## 第三步

在工程文件中`RC`目录里新建文件`Master.manifest`，内容如下：

```
        name="Microsoft.Windows.XXXX"
       processorArchitecture="x86"
       version="5.1.0.0"
       type="win32"/>

Windows  Shell

                        type="win32"
                       name="Microsoft.Windows.Common-Controls"
                       version="6.0.0.0"
                       processorArchitecture="x86"
                       publicKeyToken="6595b64144ccf1df"
                       language="\*"

               />
```

## 第四步

添加标准控件，然后汇编，看看吧。祝大家新年快乐。

> 注：本文用到`comctl32.dll`，默认只能在xp里面使用。
