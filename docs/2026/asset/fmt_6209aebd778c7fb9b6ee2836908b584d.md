## 思路说明

说一下思想，首先我借由 <https://bbs.pediy.com/thread-263992.htm> 的思路大致定位到了 phymaps 的位置。调整 qemu 内存为 120M，增大几率。

接下来我尝试在用户态进行喷射，将喷射出的每一个堆块 `memset` 成其对应的编号。用这种方法，更进一步的，我们定位到了 `0xffff888003015000` 处的 phymaps，这里是 phymaps 最初的位置。

在定位结束后，调整参数正式进行喷射，将喷射出的空间部分初始化 `xchg\_eax\_esp` 成相关的地址，此时 `0xffff888003015000` 处的 phymaps 已经被喷满了 gadgets 的地址。

## 内核 BPF 模块

BPF 全称 *Berkeley Packet Filter*，主要涉及包过滤这一部分，分析网络流量。它在数据链路层上提供了接口。BPF 支持包过滤，允许用户态进程提供一个过滤程序，此程序指定了我们想要接收到哪种包。比如当我们使用 `tcpdump` 时可能只想收到 tcp 连接初始化的包等。BPF 只返回进程提供的能通过过滤器的包。

这种机制避免了拷贝一些不需要的包从内核态到进程，极大地提升了性能。

*For example, a [tcpdump](https://bbs.kanxue.com/elink@1b9K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6W2L8W2)9J5k6i4N6A6K9$3W2H3k6h3c8A6j5g2)9J5k6h3!0J5k6#2)9J5c8Y4N6A6K9$3W2Q4x3V1k6f1j5%4m8V1N6h3#2H3) process may want to receive only packets that initiate a TCP connection. BPF returns only packets that pass the filter that the process supplies.
