
# 如何判啾Asprotect加

如何判啾Asprotect加?我碚:

1. 先用`Procdump32`去分析,若`Section Name`除了`.data`和`.rsrc`外,]有其他的`Section Name`且有多`.data`那它有八成是`Asprotect`加的.
2. 绦`Imp_list`,看它的`Address.txt`,`RVA`是否跟件的某一`Section`的`VO`一,若一忧`Address.txt`e的函颠原的很好,那它乎可\_定是`Asprotect1.0`以上加的,且有`.idata`段.
3. 若`RVA`不符合,且`Address.txt`一\_始是`GetProcAddress`後面o接著一大堆空白函,到最後才出F一系列有系y的函盗,@就是]有`.idata`只有`.radta`段.
4. 若有`.idata`,你看它的`Address.txt`中的函,若`Shell32.dll`,`Comdlg32.dll`,`Version.dll`它的成T都是ya,那它就是`Asprotect1.06`或`1.07`

你可以⒖`Azpr3.21`,`Aw95prV.1.2`,`WinNarigatorV.1.91`等

以上只是蔚姆诸,不代表任何意x,需要你多去`Trace`,和明白`PEY`,你懈嗟恼莆.
