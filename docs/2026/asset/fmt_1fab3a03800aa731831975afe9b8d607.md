接着我们再进行区域脱壳：地址=`0180C000`，大小＝`00008000`，也就是脱出上面的部分壳处理代码段。

至此我们已经将`ASProtect 1.23RC4`壳脱出来。

现在我们来“组装”一下`dumped.exe`。先用`LordPE`打开`dumped.exe`，然后从磁盘载入刚才区域脱壳的

`Region0180C000-01814000.dmp`区段，修改其`Voffset=0140C000`（`0180C000－00400000＝0140C000`），

只保留`LordPE`的“验证PE”选项，最后重建PE。

## 四、以壳解壳：Stolen Code简便解决方案

最后我们只用`OD`加载脱壳修复后的程序,现在的OEP是`0180C000`，修改其入口代码为：

```
-------------------------------------------------------------------------------------------------------------
0180C000    BB CC050000     MOV     EBX, 5CC
0180C005    E9 3A010000     JMP     0180C144
-------------------------------------------------------------------------------------------------------------
```

这样就利用了原壳的代码来处理Stolen Code了。保存之后就可以运行了。
