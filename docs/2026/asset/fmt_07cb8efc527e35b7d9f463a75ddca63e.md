
# 永远热爱的破解――菜鸟的点滴回忆和老古董

今天整理资料的时候看见了一些小东西，自己曾经走过的路，很多的回忆和感慨。

从DOS下用debug追踪《国家基础医学试题库》、《洪老师题库（题库和文渊阁）》、《C9002原子吸收光谱》到发现softice时的惊喜，那种感觉还犹如发生在昨天。

自从1998年上网后，经常去找的资料多半是台湾或国外的破解教程。此后国内的破解网站也陆续登场，多不胜数。经过大浪淘沙之后，看雪脱颖而出，成为我心目中顶尖高手交流的园地。我是个比较沉闷的人，不爱发言，也总是觉得自己发言的水平不够资格。直到有一天看到一个觉得自己能回答的问题的时候，注册了准备回答，但还是没有发帖子，因为太小心了吧，很多论坛比较欺生，新手错误或没有礼貌的发言容易招致嘲笑或攻击。

由于家庭、工作等因素，我终于狠下心必须要忘掉破解。而去年5月父亲的去世更给了我致命的一击，愧疚、失落、孤独令我几乎失去了生命和生活的勇气。我好不容易站起来，第一次看到自己头上有了一根白头发，往年强健的体质也不再有，而工作的不顺心、至今一事无成的境况也必须让我退出破解的天堂，去寻觅自己的生活。然而或许是太习惯了，必定要定时去看雪论坛翻翻帖子，而在程序中遇到困难时，第一个反应是“反汇编看看”。

去年底，我出任了一个论坛的版主，应老大要求写篇文章挂出来招呼人气，于是写了篇调试相关的文章《我的一次debug》。觉得和破解也有点接近，终于鼓起勇气把它贴到了看雪上。立刻得到了夜月大哥的鼓励，半小时后再去看时，已经挂上精字，我呆立当场，很少有论坛这样礼贤新手的。随后还得到了景仰已久的娃娃的鼓励，确实感动。

我希望看雪论坛能够越来越好。也感谢偶像hoto把lock98的教程文件发给我，虽然懒惰的我至今还没有去研究，但谢意仍深深保留在心中。同时我也在翘首期盼看雪4月将出的新书，尽管也许我不敢再去翻它，怕破解的冲动又会在体内复活，却是一件纪念品可供收藏。

告别破解……如今的我难以回首那些须多的往事……而一个刚刚走入我生命的女孩重新燃起我对生命的眷恋和对生活的勇气，我将努力去爱她，用自己的全部……
