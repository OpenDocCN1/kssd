
![](https://bbs.kanxue.com/upload/attach/201508/686289_y46rj451h3cu9x4.png)

注意：要先把`Netfairy.rb`复制进去再`show exploits`才能看到`Netfairy`模块。

接着选中我们新添加的模块：

```
use windows/wins/Netfairy
```

![](https://bbs.kanxue.com/upload/attach/201508/686289_awttwyd3tagn6ca.png)

一般情况下我们选中一个模块后都会使用`show options`查看该模块需要设置什么，比如你选的是一个攻击远程主机的模块，可能你需要设置远程主机的IP地址和端口等信息，用：

```
show options
```

![](https://bbs.kanxue.com/upload/attach/201508/686289_q8hdayszse8gjd7.png)

从上图可以看到，我们需要设置`RHOST`地址，因为我们的服务器现在在本机测试，所以我写`127.0.0.1`：

```
set rhost 127.0.0.1  //设置远程主机IP
```

![](https://bbs.kanxue.com/upload/attach/201508/686289_m0kqi30f2osavje.png)

接下来选择我们的攻击载荷，在这里可能有的朋友会疑惑，前面选的`Netfairy`和这里选的攻击载荷是什么关系，为什么选两次？其实，前面的`Netfairy`模块是协助入侵，攻击载荷才是入侵成功后你真正想运行的代码，比如：弹一个计算器，再或者偷开摄像头……我这里为了测试，获取一个命令行：

```
set payload windows/exec
```

![](https://bbs.kanxue.com/upload/attach/201508/686289_h2l028hvrsqbypp.png)

获取命令行后，我们需要执行一些命令，这里我选择弹个计算器：

```
set cmd calc.exe
```

![](https://bbs.kanxue.com/upload/attach/201508/686289_ky2tljbh0tolgkt.png)

到这里，所有的准备工作都做好了，开始我们的`exploit`吧！！！

```
exploit
```

![](https://bbs.kanxue.com/upload/attach/201508/686289_9ilecalrt37ccz9.png)

可爱的计算器出来了……一次完整的攻击完成。其实利用`Metasploit`实现`exploit`看起来也挺简单的，无非就是做“填空题”而已。
