## 问题 4

上面没问题之后，发现 IP 开在`255.255.255.255`上。

![image-20220422102645100](upload/attach/202204/934060_N9893UCKTERY4KS.jpg)

使用`string`大法搜索`listen ip`。

![image-20220422103034994](upload/attach/202204/934060_T25WG4DAUTQ25KY.jpg)

`inet_ntoa`函数的意思是将网络地址转换成“.”点隔的字符串格式。

所以跟`sockaddr.sin_port`有关，查看引用。

![image-20220422103359077](upload/attach/202204/934060_2BUH8F8QJUE88RD.jpg)

`inte_addr`的功能是将一个点分十进制的 IP 转换成一个长整型数（`u_long`类型），等同于`inet_addr()`。

与`host`有关，再向前查看。

![image-20220422103859404](upload/attach/202204/934060_YC2H8XHGNJVV3J9.jpg)

其参数为全局变量`g_lan_ip`。设置一个`lanip`：

```bash
sudo tunctl -t br0 -u ‘用户名’
sudo ifconfig br0 192.168.5.1/24
```

`ps eth1`就是第二块网卡，第一块通常是`eth0`；`tap`是虚拟网络接口；`br`是网桥。

这个设置完之后，问题 2 直接解决了。

# 分析思路

分析其使用的 Web 服务器。常见的嵌入式 Web 服务器有以下几种：

- `httpd`
- `uhttpd`
- `gohead`
- `lighttpd`
- `boa`

还有其他的，我没咋见过，就不写了，用到的话自行查阅（懒！）。

我分析这款使用的是`httpd`，在`bin`目录下。一般服务器文件都在以下几个目录，不排除其他目录：

```text
/user/bin/
/user/sbin/
/bin/
```

在逆向分析`httpd`时，尽量关注一些自定义功能代码。`main`下调用的`initwebs`函数中，配置了前端访问方式。

![image-20220422112301584](upload/attach/202204/934060_QWYURG8FJNAQS3S.jpg)

可以看到默认页面`main`。
