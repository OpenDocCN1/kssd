## 漏洞简介

Cisco的网际操作系统`IOS`是一个网际互连优化的复杂操作系统。Cisco IOS的`Smart Install`功能在实现上存在漏洞，远程非法攻击者可利用此漏洞在受影响设备上`执行任意代码`。此漏洞源于运行`Cisco IOS Software`的`Cisco Catalyst Switches`中的`Smart Install`功能，Smart Install使用TCP端口`4786`进行通信，`要触发此漏洞需要完整的TCP三方握手的连接`。

受此漏洞影响的设备列表：

```

Catalyst 3850

```

## 复现过程

目标环境：`101.XXX.XXX.66` 某存在该漏洞的思科路由器

攻击端环境：使用公网IP地址的服务器+python环境，将<mark class="encrypted">5f9K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6e0j5h3t1H3N6r3q4Y4x3$3c8Q4x3V1k6e0d9f1g2f1</mark> 代码复制到攻击机上

![图片描述](upload/attach/201902/3_9YJ6VW4MJM98UH8.png)

进入SIET目录

![图片描述](upload/attach/201902/3_AXT4UR4GBQ8FS8B.png)

执行

```
python siet.py
```

由于模块缺失，需要安装`argparse`模块

![图片描述](upload/attach/201902/3_SSERFAG53VGR8GY.png)

安装缺失模块

```
pip install argparse
```

![图片描述](upload/attach/201902/3_WYQKVHFWD693NG2.png)

进行漏洞利用，尝试获取目标保存在`flash`内的配置文件

![图片描述](upload/attach/201902/3_JUJHMCG3TX8YVK8.png)

在利用成功后，会在程序目录下生成`tftp`的目录，进入该目录`打开以IP地址命名的文件即可`

![图片描述](upload/attach/201902/3_WB9ABSJQ5HZXTEH.png)

![图片描述](upload/attach/201902/3_MM4RABTK6STB2TQ.png)

***如无必要，不要使用`-e`参数，可能会导致原本设备配置被覆盖***
