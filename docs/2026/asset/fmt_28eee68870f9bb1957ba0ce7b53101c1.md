
# [原创]WDK编译64位汇编

之前走入一个误区，一直以为x64下要编译汇编要安装Intel的编译器![](https://bbs.kanxue.com/view/img/face/50.gif)![](https://bbs.kanxue.com/view/img/face/50.gif)，近几天看NewBluePill的源码，发现大量的x64的汇编代码，直接用WDK7600编译通过，自己试验了一下，也成功了。

汇编代码，很简单的一个`ADD`

```
.CODE 

MyAdd PROC

add rcx , rdx

mov rax , rcx

ret

MyAdd ENDP

END
```

```
NTSTATUS DriverEntry(IN PDRIVER_OBJECT DriverObject, IN PUNICODE_STRING RegistryString)

{

	ULONG_PTR Result;

	DriverObject->DriverUnload = DriverUnload;

	Result = MyAdd(3,4);

	DbgPrint("%d\r\n",Result);

	return STATUS_SUCCESS;

}

VOID DriverUnload(PDRIVER_OBJECT DriverObject)

{

}
```

上面就是代码，不过我们要在`Source`文件加入一句

```
AMD64_SOURCES = \
                        Add.asm\
```

之后用7600的命令行就可以`build`了![](https://bbs.kanxue.com/view/img/face/41.gif)
