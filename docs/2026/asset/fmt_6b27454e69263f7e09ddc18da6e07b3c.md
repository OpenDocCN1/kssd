# 背景

因为最近的项目有在内核中查找全局变量的需求，有2种方法可以实现此功能。

1. 分析搜索特征码，从某个导出函数或未公开函数中查找是否有全局变量的调用，然后提取特征码定位全局变量。

2. 使用pdb文件定位全局变量，使用pdb较为通用，可以兼容win7和win10，没有提取特征码那么繁琐，但了解到一些系统版本号可能不提供pdb，那就只能通过提取特征码的方式查找了

# 架构

本项目涉及2个主要程序，因为需要展示SSDT表，所以就使用`MFC应用`来做展示。然后`DIA2DUMP`和`dbghelp.dll`用于提供解析PDB服务。

## DIA2DUMP
