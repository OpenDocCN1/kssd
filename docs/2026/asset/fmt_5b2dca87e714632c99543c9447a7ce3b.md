+ 当然了，我们得先复习一下`memcmp`的功能吧；

```c++
// 比较两个缓冲区中的字符。
int memcmp( const void *buf1, const void *buf2, size_t count );
// Return Value
// 返回值指示缓冲区之间的关系。
// 返回buf1和buf2的第一个计数字节的值关系
// < 0 buf1 小于 buf2
// = 0 buf1 等于 buf2
// > 0 buf1 大于 buf2
```

根据题意，`memcmp`返回`0`；

+ 再复习一下`test`指令；

+ TEST 指令在两个操作数的对应位之间进行 AND 操作，并根据运算结果设置符号标志位、零标志位和奇偶标志位。

+ TEST 指令总是先清除溢出和进位标志位；

+ 所以`test eax,eax`等于`and eax , eax`也就是`and 0 , 0`，结果为`0`，ZF位置`1`。

+ 如果ZF位为`1`，`jnz`指令则不跳转；
