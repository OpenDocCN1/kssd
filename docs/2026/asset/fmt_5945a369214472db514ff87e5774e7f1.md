QT中获取`QLineEdit`中的文本用`text()`函数，该函数返回一个`QString`的对象。

`QString`对象大致上是下边的样子：

```
clsss QString

{

    Data* data;

}

struct Data

{

+0

+4

+8          //长度

+0xc        //数据地址

+0x10       //

+0x12       //数据 unicode

};
```

这个不必深究，拿到数据就行。
