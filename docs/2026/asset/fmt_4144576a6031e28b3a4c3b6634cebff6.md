
# 破解实战（三）之 WinZip8.0 (5千字)

软件名称：WinZip 8.0  
简介：一个强大并且易用的压缩实用程序（30天试用）  
解密日前：2000年7月15日  
解密工具：Trw2000 1.22  
破解目的：学习注册码的破解。

说明：

本文是在我的软件破解记录上整理出来的。所以在文中没有任何的注册码，只作技术交流。如若有纰漏，请各位大侠多指教！

首先用`Trw2000`载入`Winzip 8.0`，输入注册信息：

`name:xiA Qin`（任意输入）  
`register key:1949101`（任意输入）

下指令`bpx hmemcpy` // 下中断点

按`F5`回到程序，按确定，这时会被`Trw2000`拦截到。

下指令`bd *` // 屏障中断点

下指令`pmodule` // 直接跳到程序的领空
