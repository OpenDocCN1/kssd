
# [原创]ELF DIY For Anddroid

前几天偶然发现原来 PEDIY 是 PE 格式的 DIY，研究 ELF 格式有一段时间了，故来一发 ELFDIY。![](https://bbs.kanxue.com/view/img/face/28.gif)

也作为学习 ELF 格式的一个小结吧。限于水平有限，难免会有疏漏和错误之处，请各位大大批评指正，小弟感激不尽。

篇幅偏长，加上排版技术太烂，就直接上 PDF 吧。

主要内容分为三部分：

1. `Ehdr` DIY，针对各个 `Ehdr` 结构的各个字段。
2. section DIY，主要内容为移动 section、增删 section 内容，DIY `init` 函数和 DIY GOT 表，实现类似于基于函数 patch 的第二代 dex 加固技术等。
3. segment DIY。

文档、代码见附件。
