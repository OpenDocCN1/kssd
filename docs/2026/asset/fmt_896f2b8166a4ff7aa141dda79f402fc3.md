触发截断日志扇区功能函数，需首先设置控制元数据块（Control Record）`PCLFS_CONTROL_RECORD->cxTruncate.eTruncateState = ClfsTruncateStateModifyingStream`。在进入这个函数前，存在一个`_CLFS_TRUNCATE_CLIENT_CHANGE`结构体，用于表示需要截断的扇区个数`chg->cLength`。

`CLFS`会根据这个指定的个数分配非分页缓冲区，大小为`chg->cLength << 9`，也就是`chg->cLength * 0x200`，用于存放将要截断的扇区数据。程序从当前元数据块加上`coffClientChange`偏移量得到拷贝基址，并将数据写入缓冲区中。这里并没有对实际的`Truncate Record`元数据中指定的扇区数据数量进行校验，导致可以越界读取最后一个扇区之后的下一个扇区数据到缓冲区中，也就是说，会泄露下一个内核池中大小为`0x200`的数据。

一般情况下，非分页池相邻的数据块都包含数据，因此越界读取并不会导致`BSOD`。所有缓冲区中的数据最后都会通过`CClfsLogFcbPhysical::WriteOneRawSectorSync`写入`CLFS`容器文件，所以调用者可以读取泄露的数据。

unsigned __int8 __fastcall CClfsLogFcbPhysical::IsTruncatedRecordOffsetValid(
    CClfsLogFcbPhysical *this,
    _CLFS_TRUNCATE_RECORD_HEADER *trunhdr,
    unsigned int offset)
{
    unsigned int offOwnerPage;   // ecx
    unsigned int offClientChange; // edx
    bool chk1;                    // cf
    bool chk2;                    // zf

    offOwnerPage = trunhdr->coffOwnerPage_c;

    if (offOwnerPage < 0x10)
        return 0;

    offClientChange = trunhdr->coffClientChange_8;

    if (offClientChange < 0x10
        || offOwnerPage > offset
        || offClientChange > offset
        || offClientChange == offOwnerPage
        || offset - offOwnerPage < 0x1000
        || offset - offClientChange < 0x230)
    {
        return 0;
    }

    chk1 = offOwnerPage < offClientChange;
    chk2 = offOwnerPage == offClientChange;

    if (offOwnerPage < offClientChange)
    {
        if (offClientChange - offOwnerPage < 0x1000)
            return 0;

        chk1 = offOwnerPage < offClientChange;
        chk2 = offOwnerPage == offClientChange;
    }

    if (chk1 || chk2 || offOwnerPage - offClientChange >= 0x230)
        return 1;

    return 0;
}

__int64 __fastcall CClfsLogFcbPhysical::ValidateTruncateRecord(
    CClfsLogFcbPhysical *this,
    struct _CLFS_TRUNCATE_RECORD_HEADER *hdr)
{

    unsigned __int64 offOwnerPage;    // r9
    CLFS_TRUNCATE_CLIENT_CHANGE *chg; // r8
    __int64 chg_cLength;              // rax
    __int64 result;                   // rax

        || (offOwnerPage = hdr->coffOwnerPage_c, offOwnerPage & 7)
