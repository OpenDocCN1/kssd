
```
ebp-c                        esp                        eax (seh 指针）<-------------------------------fs:[0]
ebp-8                        esp+4                        eax (通过寄存器eax传递过来的参数进栈）
ebp-4                        esp+8                        -1
ebp                        esp+c                        ebp  ----- 注意发生变化了<------------------------ ebp
ebp +4                        esp+10                        004b5b55函数 结束时要返回的地址
```

综上所述：`0046fca0` 实现的功能为：《1》注册异常回调函数；《2》实现了和 `push ebp`、`mov ebp,esp` 查不多的功能，调用 `0046fca0` 函数的函数的第一个堆栈参数地址为 `ebp+8`。这和 `push ebp; mov ebp,esp` 是一样的，但是局部变量的寻址就不一样了。调用 `0046fca0` 函数的函数局部变量是从 `ebp-d` 开始的，而不是从 `ebp-4` 开始的。搞定……^_^

现在我们就可以很轻松的识别出参数了,开始吧
