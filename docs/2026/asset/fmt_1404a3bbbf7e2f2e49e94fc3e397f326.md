#### 5、注册信息保存在注册表

```
[HKEY\_LOCAL\_MACHINE\Software\CLASSES\CLSID\{1AE69D60-73D0-11D4-BD52-38A480C50000}]
"224951124"="224951124"
```

这个键值为1-10，是尚余的使用次数，如果是上面的数值时，就是注册版的了。删除键值，就成为未注册版本了。
