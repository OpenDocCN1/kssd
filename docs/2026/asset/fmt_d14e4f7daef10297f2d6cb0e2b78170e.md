## create_heap函数

可以看到这个函数会依次遍历`heaparray`数组，看哪个元素没有分配chunk，找到后，分配一个chunk，chunk大小可以自定义，然后写入内容，注意：**`heaparray`数组的元素存放的是chunk的数据部分的指针。**

```
unsigned __int64 create_heap()
{
  int i; // [rsp+4h] [rbp-1Ch]
  size_t size; // [rsp+8h] [rbp-18h]
  char buf[8]; // [rsp+10h] [rbp-10h] BYREF
  unsigned __int64 v4; // [rsp+18h] [rbp-8h]

  v4 = __readfsqword(0x28u);
  for ( i = 0; i <= 9; ++i )
  {
    if ( !*(&heaparray + i) )
    {
      printf("Size of Heap : ");
      read(0, buf, 8uLL);
      size = atoi(buf);
      *(&heaparray + i) = malloc(size);
      if ( !*(&heaparray + i) )
      {
        puts("Allocate Error");
        exit(2);
      }
      printf("Content of heap:");
      read_input(*(&heaparray + i), size);
      puts("SuccessFul");
      return __readfsqword(0x28u) ^ v4;
    }
  }
  return __readfsqword(0x28u) ^ v4;
}
```

## edit_heap函数

这个函数则根据用户输入的索引（从0开始），修改chunk的数据部分，特别的`read_input(*(&heaparray + v1), v2);`这里写入内容的大小竟然还是自定义的，所以这里可以覆盖其他chunk的内容

```
unsigned __int64 edit_heap()
{
  int v1; // [rsp+4h] [rbp-1Ch]
  __int64 v2; // [rsp+8h] [rbp-18h]
  char buf[8]; // [rsp+10h] [rbp-10h] BYREF
  unsigned __int64 v4; // [rsp+18h] [rbp-8h]

  v4 = __readfsqword(0x28u);
  printf("Index :");
  read(0, buf, 4uLL);
  v1 = atoi(buf);
  if ( (unsigned int)v1 >= 0xA )
  {
    puts("Out of bound!");
    _exit(0);
  }
  if ( *(&heaparray + v1) )
  {
    printf("Size of Heap : ");
    read(0, buf, 8uLL);
    v2 = atoi(buf);
    printf("Content of heap : ");

  else
  {
    puts("No such heap !");
  }
  return __readfsqword(0x28u) ^ v4;
}
```

# 3. 利用思路

1. 伪造freak chunk

   我们可以通过`edit_heap`函数覆盖`fastbin`中的`fd`指针，使其指向`bss`段，伪造一个chunk。

2. 修改`heaparray`元素使其指向`free@got`

   因为`heaparray`数组存放的是chunk的数据部分，那我们可以通过修改伪造的freak chunk的数据部分，进而修改`heaparray`数组的元素值，比如把`array[0]`的内容（本来是指向`chunk0`的数据部分）指向`free@got`。

3. 使`free["got"]`的内容指向`system@plt`

   我们通过`edit_heap`函数可以修改`array[0]`的内容，也就是`free@got`的内容，把这个内容改成`system@plt`

4. 执行`system("/bin/sh\x00")`

   我们可以设置`chunk1`的数据部分为`/bin/sh\x00`，所以在`free(chunk1)`时，就变成了`system("/bin/sh\x00")`，最终得到flag
