<a href="elink@974K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4m8Z5M7q4)9J5k6h3&6W2N6q4)9J5c8X3#2S2L8Y4g2S2L8q4)9J5c8Y4A6Z5i4K6u0r3k6Y4g2F1j5%4c8A6L8$3&6Q4x3X3g2J5k6i4q4#2K9i4u0W2i4K6u0V1L8$3&6U0k6g2)9J5k6i4m8Z5M7l9`.`.">require_once</a>函数的定义是“`require_once`语句和`require`语句完全相同，唯一区别是PHP会检查该文件是否已经被包含过，如果是则不会再次包含。”。

<a href="elink@611K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4m8Z5M7q4)9J5k6h3&6W2N6q4)9J5c8X3#2S2L8Y4g2S2L8q4)9J5c8Y4A6Z5i4K6u0r3k6Y4g2F1j5%4c8A6L8$3&6Q4x3X3g2J5k6i4q4#2K9i4u0W2i4K6u0W2M7r3S2H3">require</a>语句的作用是“`require`和`include`几乎完全一样，除了处理失败的方式不同之外。`require`在出错时产生`E_COMPILE_ERROR`级别的错误。换句话说将导致脚本中止而`include`只产生警告（`E_WARNING`），脚本会继续运行。”。

<a href="elink@fcbK9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4m8Z5M7q4)9J5k6h3&6W2N6q4)9J5c8X3#2S2L8Y4g2S2L8q4)9J5c8Y4A6Z5i4K6u0r3k6Y4g2F1j5%4c8A6L8$3&6Q4x3X3g2A6L8X3y4D9N6h3c8W2i4K6u0W2M7r3S2H3">include</a>语句“包含并运行指定文件”。

那么什么是“包含并运行”呢？你可以理解为**把要“包含”的文件原封不动地替换到`require_once`、`require`、`include`函数所在的位置，并执行其中的php语句**。以`require_once('flag.php');`为例，`flag.php`这个文件中可能存在`$flag='xxx';`，也就是我们想夺取的flag的内容。`require_once`函数的作用是在php后端执行到`require_once`时立即将`flag.php`的内容替换`require_once('flag.php');`，并在我们当前审计的php后端中执行`flag.php`中的所有内容。在php开发中，适当使用`require_once`、`require`、`include`可以提高代码复用程度，减少代码冗余。而在Web类型的CTF比赛中，将flag单独写在`flag.php`中并通过`require_once`、`require`、`include`包含进来，可以避免在主程序中暴露flag的内容。

使用URL编码还有一个好处。以[第三篇教程](https://bbs.pediy.com/thread-249088.htm)为例，如果你想给`a`参数传入`123&456=`，而不进行URL编码的话，后端接收到的HTTP请求将是

```
GET /dmsj/level0/?a=123&456= HTTP/1.1
```

就会理解为传入了两个参数：`a`和`456`，这明显与我们原来的意图不符。所以，浏览器会自动对发送的表单的数据进行URL编码。
