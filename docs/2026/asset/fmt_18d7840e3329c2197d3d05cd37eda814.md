
# [原创] Win10 1607版本开始,如果主板打开SecureBoot选项的话,就必须通过微软的仪表板认证了.

可能好多人已经知道了, 但是希望会帮助到那些还不知道的猿友们. 因为我真的是折腾了好久...

前一阵子突然发现自己写的驱动在有些电脑里不能成功安装. 安装时提示系统无确认驱动签名.... 驱动已经打过 sha1+EV认证了居然提示不行,于是各种查找资料,向微软咨询, 折腾了两周后确认:

**1. RT Win10 1607版本开始 如果是全新安装的系统在开启secureboot的时候必须通过微软仪表板服务的认证.**

**2.以前的仪表板`sysdev` 从16年11月开始会逐步移到新的仪表板服务中去(New Hardware Dashboard).**

**3.新的仪表板需要公司的Azure AD账号.**

虽然可能对个人编写驱动的人来说意义不是很大, 但是还是希望能帮助到你们,至少知道有这么回事吧
