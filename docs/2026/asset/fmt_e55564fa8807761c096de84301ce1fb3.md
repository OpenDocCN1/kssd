
# 我钟情于计算机，却没有任何收获

我钟情于计算机,却没有任何收获.为什么这么说呢.如果说我没有努力也不太对.因为我初中的时候就每个周末都往书店跑.看的全是计算机的书.当时家里穷,确实很穷(我家三个孩子,住在农村,2000年上初中的时候我一天的吃饭钱是1.5,够买三个锅贴.),所以去书店基本就是背书,连十几块钱的计算机书都没买过.我家到书店要走上一个小时的路,这我从来都没嫌累过.但当时真的是太迷茫了,不知道要看什么.什么也不懂,我就背计算机应用的一些东西.我还记得我背过当时98的开始菜单,每个菜单都是干什么用的,在桌面单击右键可以出现一个菜单,在菜单中有个属性,在属性里可以设置桌面背景......后来网上开始流行给自己建主页,也就是申请个主页,再用模板装饰一下.但我觉得模板大家都是一样的,不个性,便开始学怎么做主页.总在书店泡,看`HTML`语言.但什么都看不懂,我记得我第一本计算机书是买的<<`JavaScript`简单教程>>,花了不到10块钱,省了几天的饭钱买的,但最后好像也没学到什么东西.那时候说五笔打字快,又开始学上`五笔`,字根背的滚瓜烂熟的,但不能经常到网吧去(那时候上1小时就是1块钱,对我来说消费不起),所以总忘,后来下决心要买个学习机,我省了整整两个多月的饭钱买了个学习机,也就是那时候学会了现在一直都在用的`五笔`.

高一高二基本再没碰过计算机的东西,其实我也没有什么计算机的东西可碰,就是很少去泡书店看计算机的书了.也因为这,我当时的成绩在班里前三,全校可以排到100左右,基本可以进到好一点的大学了.但到了高三的时候我们发了一本计算机技术的教材,里面讲的是`PASCAL`语言,教材是发了,但实际上我们那的高中就没有开这门课,因为全部时间都冲击高考了,哪有心思放在这啊.但我却不一样,每天抱着看,像他一样在纸上写,却从没上机实践过,因为我都不知道要用什么工具来编这些代码.之后没有坚持看下去,感觉看了也记不住,又没地方实践,看了就全忘了,写在纸上的代码又不知道对还是不对.虽然没有再看`PASCAL`,但我喜欢计算机的兴趣又被激起了,到书店看一些乱七八糟的计算机书,到现在一本书名也没记住.后来我同学经常买黑客X档案的书,我拿来看也喜欢上了黑客,也就在那时候计算机知识长了不少,但却依旧不知道想更好的学习计算机,至少要去学习一种语言,去编程.因为高三的时候别人看的是数学语言英语高考模拟题,而我天天看的是黑客,所以我自然而然的来到了现在这个学校,一个基本没人知道,至今还年年需要降10-30分才会把招生名额招满的学校.

我现在最遗憾的就是初中高中身边没有学过计算机的人给我指条路,好让我往一条路发展下去.我原以为到了大学后就可以天天学计算机的东西,但真正进来才发现,我还要学那些自己不喜欢的东西.大一的时候本以为可以学到很高超的东西,但却开的是计算机基础操作课程,学习如何开机关机安装程序,很是伤心.混过大一,大二学习`C语言`,很是白痴的认为`C语言`过时了,基本混过了考试就算完了.而现在自己快把肠子都悔青了.

我喜欢计算机,我钟情计算机,别人问最喜欢做什么,我会毫不犹豫的说我喜欢计算机,但我却不知道我喜欢计算机的什么.直到现在我还没有完成一个自己的小程序.而身边的同学却因为我的电脑从不装杀毒软件但却基本没中过病毒而称我"厉害",因我获得了全国`ITAT`大赛`OFFICE`办公自动化二等奖而另眼相看,但我深刻的知道,我什么都不会.

就在我打这些文字之前,我还在按照<<`Windows`环境下32位汇编语言程序设计>>书上的教程来编写一个小窗口,实现什么是消息循环,什么是窗口过程.我22岁了,再过几天开学了我也就大三了.我喜欢计算机,但我很惭愧,因为我什么都不会.

我现在最后悔的是我以前总没钱也总舍不得买书,现在我认识到书有多重要了.所以我现在疯狂买书,<<`VC++`深入详解>><<Windows环境下32位汇编语言程序设计>><<`汇编语言`>><<windows核心编程>><<windows程序设计>><<C语言程序设计>><<`TCP/IP`详解1.2.3卷>><<windows应用程序捆绑核心编程>><<windows网络编程技术>>.....我知道书很乱,而且至今我只看完了<<`汇编语言`>>这么一本书,但我会按顺序继续学习的.我会在大三上半学期学完<<Windows环境下32位汇编语言程序设计>>然后再去看<<`VC++`深入详解>>,但说实话,我没有他那种超人的毅力,但我希望我能走的更远些.

我贴出来我的感想是希望更多和我一样的人看过之后别再迷茫,尽快找到自己的方向.也希望更多经历丰富的人能给像我们这些迷失方向的人一些指引,引导我们走向"正途".

在这里我想对原作者说,你给我了很大的动力,我要像你学习,我也会向你学习的.谢谢你!
