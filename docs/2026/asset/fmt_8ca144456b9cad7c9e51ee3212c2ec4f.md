## IDA 静态分析

### 1. `create`

首先刚进去就：

```text
ptr = (char *)malloc(0x20uLL);
if ( nbytes <= 0x1000 )   // 我们输入的size必须小于等于 0x1000
nbytesa = strlen(&buf);
if ( nbytesa > 0xF )  ;
```

当申请的 `size` 大于 `0xf` 的时候：

```text
dest = (char *)malloc(nbytesa);
```

为 `dest` 申请内存，然后：

```text
strncpy(dest, &buf, nbytesa);    // 直接往dest重写东西
```

之后将 `dest` 的内存地址放到 `ptr` 的第一位：

```text
*(_QWORD *)ptr = dest;
```

`ptr+3` 的位置放 `freeLong` 函数地址：

`ptr+4` 的位置来存储 `str_size`：

```text
*((_DWORD *)ptr + 4) = nbytesa;
```

接着：

```text
if ( !*((_DWORD *)&Strings + 4 * i) )
{
    *((_DWORD *)&Strings + 4 * i) = 1;
    *((_QWORD *)&Strings + 2 * i + 1) = ptr;
    printf("The string id is %d\n", (unsigned int)i);
    break;
}
```

`String` 全局变量，地址 -> `.bss:00000000002020C0`

- `String[i].inuse = 1`
- `String[i].str = ptr` <-- 存储的我们申请的 string 的写入地址空间

当申请的 `size` 小于 `0xF` 的时候：

```text
strncpy(ptr, &buf, nbytesa);
```

`ptr` 的第一位存储 `size`：

```text
*((_QWORD *)ptr + 3) = freeShort;
```

`ptr` 的第三位存储 `freeShort`。

总结：

当 `size` 大于 `0xf` 时，`string` 结构的结构：

```text
struct string{
    *buf; //1
    freeLong;  //3
    size;  //4
}
```

当 `size` <= 15 时：

```text
struct string{
    *buf;   //1
    SIZE;
    freeShort;  //4
}
```

至此我们搞懂了这个程序的数据结构。

## 溢出思路

我们先申请两个个小于 `0xf` 的堆块，然后将其释放，之后申请 `0x20` 的堆块，这样子我们就可以在原来 `string1` 的位置开始写入数据了，首先覆盖掉 `free()` 函数指针，改为我们的所需要控制的函数指针，便可以劫持程序执行流。

但是因为程序开启保护 pie，我们需先泄露程序基地址，然后才可以去的 libc 中的函数地址。

因为低三位不变得原因，我们将低三位覆盖进去就行（是 `call puts` 函数得低三位）：

```text
readelf -a pwn | grep -E "free"
```

```text
objdump -d -M intel pwn | grep puts
```

```text

```

```text
objdump -d -M intel pwn | grep printf
```
