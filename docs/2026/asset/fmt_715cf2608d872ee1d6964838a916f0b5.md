## 0x05 LenB函数

|  |  |

![](https://bbs.kanxue.com/upload/attach/202103/817966_5C7A5ESMFF7RJF8.jpg)

![](https://bbs.kanxue.com/upload/attach/202103/817966_URAAWRGCZ5AP82C.jpg)

之后再进行计算：

![](https://bbs.kanxue.com/upload/attach/202103/817966_CRB2XMPZ44C83GM.jpg)
