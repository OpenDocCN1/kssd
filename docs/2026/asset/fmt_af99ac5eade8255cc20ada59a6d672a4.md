```c
A[i] = {

    return num;
}
```

结语：

疯狂单词构造了一个巧妙的算法，要求注册码满足：

`注册码 = F(注册码，用户名)`

然后他每次验证注册码之后，只有正确的注册码可以保持不变，并通过下一次的验证。

但不足的是该作者的离散数学功底太差，他将大`F`分解成多个小`f`时仅仅采用了分段函数的形势，函数表达式本身是一样的，仅仅是作用域不同而已（验证不同的位），假如能够将大`F`分解成多个函数表达式不同的小`f`，通过跟踪小`f`分析其大`F`的算法将是非常困难的！
