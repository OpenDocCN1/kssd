
# 破解瑞星杀毒软件2001版，半字节，没搞错吧？？（破解手记）

非常棒的国产精品杀毒软件，从瑞星网站下载最新版，目前为2001版，安装时需瑞星密钥盘。

图形版`ravcpic.exe` 字符版`ravcchar.exe`

下面以图形版为例。

## 破解步骤

1. 用`winzip`等解压缩软件将`ravcpic.exe`展到一个目录下
2. 将其中的`SETUP.DLL`的`UPX1.03`壳给脱了。

脱壳可用`UPX1.06`，参数`-D`即可（`UPX SETUP.DLL -D`）

3. 用打开`w32dasm`黄金版打开`SETUP.DLL`==》串式参考

`"请插入瑞星A号盘，如果该提示仍出现请与经销商联?`

4. 运行目录下的安装主程序`setup.exe`，哇塞，省掉一百多大洋，情人节is coming,party的门票钱出来了。

6. 字符版可参考1~5，原理同。
