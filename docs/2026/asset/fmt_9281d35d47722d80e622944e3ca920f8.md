void DriverUnload(PDRIVER_OBJECT driver_object) {
}

{
    UNREFERENCED_PARAMETER(pRegistryString);

    pDriverObject->DriverUnload = DriverUnload;

    return STATUS_SUCCESS;
}

## 坑1：不支持某些intrin

用`clang`编译时会提示找不到`__writecr0`、`__readcr3`、`__readmsr`之类内核常用指令

解决方法1：修改`clang\xxx\include\intrin.h`，封装未实现的intrin，用`__asm__`让其强行支持，比如

```
static __inline__ void __DEFAULT_FN_ATTRS
__writecr3(unsigned long long __cr3_val) {
  __asm__ ("mov %0, %%cr3" : : "q"(__cr3_val) : "memory");
}
```

解决方法2：MASM写`.asm`，封装成函数让链接器去链接

比如

```
; void __stdcall AsmWriteCR2(_In_ ULONG_PTR cr2_value);

AsmWriteCR2 PROC
    mov cr2, rcx
    ret
AsmWriteCR2 ENDP
```
