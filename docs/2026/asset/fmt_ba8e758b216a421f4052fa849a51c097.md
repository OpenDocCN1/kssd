`word`版的与非门，从`EBPSTACK`的栈顶读取2个`word`作为操作数，结果存储在第二个操作数位置，`EFLAGS`标志存储在栈顶。

```
        EBP 0013F9AA

        0013F9A8   0000

        0013F9AC       0000  ....

        0013F9A8   00000286  ..

        0013F9AC       00FF  ...
```
