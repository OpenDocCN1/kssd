
# ThumbNailer (2千字)

软件名称：`ThumbNailer`

整理日期：2001.1.29

最新版本：6.6.1.1

文件大小：1324KB

软件授权：共享软件

使用平台：Win9x/Me/NT/2000

发布公司：Home Page

软件简介：

能够为一个满是图形的目录建立图片的缩略图，并建立一个HTML连接这些图片，支持JPG、BMP、PNG、PCX、TGA、AVI frame-extraction、GIF(non-LZW output)、TIFF(non LZW)、WMF(read-only)等格式。

下载地址：`http://www.newhua.com/THUMBNAILER.HTM`

破解工具：`HIEW`，`W32DASM`

这个软件没有输入注册码的地方,在左下解看到30 DAYS LEFT IN TRIAL用是我将时间跳到2002年后,再次运行它,看到YOUR 30-DAY TRAL PERIOD HAS RUN OUT.的提示,这就是入口点
