其实爆破点就是1个，就是启动那里判断是否注册的一个点，上面说了，但是修改时候有些头疼，我没有OPCODE的表，不知道NOP这个命令的OPCODE，晕了。我们换个思路，每次判断是否注册，程序都调用了`CMP_STR`这个函数，我们可以在这里做文章，这个函数返回值在`R0`里面，`R0=0`则比较结果不相同，所以，我们只要让它返回不是0就可以了

```
.text:100061B0                 BL      Compare__C7TDesC16RC7TDesC16 ; TDesC16::Compare(TDesC16 const &)
```
