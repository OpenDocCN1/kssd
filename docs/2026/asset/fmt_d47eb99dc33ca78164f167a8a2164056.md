# 解密篇

## 1. 第一层解密，以文本的形式打开，我们发现代码是加密的。

其中定义了 `x`、`y` 和 `yy` 3 个字符串和 `ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789`

脚本最后一句是 `execute x` 意思是解密执行 `x`, 这里 `x` 可以自己整理提出，也可以 `Hook_execute`, 代码如下：

```sub hook_execute(x)

'wscript.echo x

outfile="ok.txt"

set fso=createobject("Scripting.FileSystemObject")

if (fso.fileexists(outfile)) then

set objtxt=fso.opentextfile(outfile,8,true,0)

objtxt.write x&vbcrlf

objtxt.close

execute x

else

set objtxt=fso.createtextfile(outfile,True,False)

objtxt.write x&vbcrlf

objtxt.close

execute x

end if

end sub
```

这里就是执行 `excute` 之前，把 `x` 的内容写入到文本中，这样我们就得出了执行的代码。
