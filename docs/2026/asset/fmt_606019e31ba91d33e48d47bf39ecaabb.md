机器码思路：

```
eax =AC5B5AEF
ecx 右移八位 得到AC5B5A
后八位给esi＝EF
eax给ebx，edx＝AC5B5AEF
esi左移8位 ＝EF00
ecx后八位给eax＝5A
edx右移16位＝AC5B
esi与ecx相加＝EF5A
edx后八位给ecx＝5B
esi左移8位＝EF5A00
ebx右移24位＝AC
esi与ecx相加＝EF5A5B
ebx后八位给edx
esi左移八位＝EF5A5B00
esi与edx相加＝EF5A5BAC
然后对其以八进制输出就是机器码了
```

由此可以看出机器码是通过`C:\`卷标来得出来的，先进行反序，然后在以八进制输出就是机器码了！！
