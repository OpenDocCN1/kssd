### 线程 3

#### 行为分析

创建大量注册表项，类似：

`HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\avp.exe` `Debugger` `"svchost.exe"`

只要在进程黑名单中的，都会创建相应的此表项，即使用文件映像劫持来阻止黑名单中安全软件的运行。此病毒中如果运行黑名单中的安全软件进程，则会运行 `svchost.exe`，而不会运行它们。

然后判断系统是否为 XP 或 2000，如果是则提升进程权限，使用 `ZwOpenSection` 来得到 `\device\physicalmemory` 的句柄。

如果没有 `SECTION_MAP_WRITE` 权限，则此调用会失败；如果失败，则调用 `ZwOpenSection`，使用 `READ_CONTROL|WRITE_DAC` 访问标志来得到 `\device\physicalmemory` 的另一个句柄。加入新的 DACL 到 `\device\physicalmemory` 对象中，最后加入 DACL 到 `\device\physicalmemory` 中，并为管理员用户获得 `SECTION_MAP_WRITE` 访问权限。

供后面直接读取物理内存用（Vista 之后就不能在用户态直接访问了吧）。
