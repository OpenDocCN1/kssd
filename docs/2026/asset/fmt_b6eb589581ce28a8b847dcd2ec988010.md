## 扇区隐藏/保护程序

为了隐藏 MBR 和其他扇区的真实内容，rootkit 勾住了 `\Driver\Disk` 的 `IRP_MJ_READ` 请求。通常情况下，当 API 读取 0 扇区（也就是 MBR）时，Rootkit 修改磁盘 `IRP_MJ_READ` 调用并返回 62 扇区的原始 MBR 副本。第二个钩子(`IRP_MJ_WRITE`)保护自身不被删除或覆盖。
