
`.text:000100A4 LDR R2, [R1,R4]` 把 `r1+r4` 地址额值存入 `r2`，`r1` 是 `code` 变量，`r4` 表示索引，第一次值为 0。

`.text:000100A8 EOR R2, R2, R6` `r2` 与 `r6` 异或，`r6` 的值是 `0x123456`，第一次 `r2` 的值是 `0x56`。异或的值存在 `r2`，在下条指令 `.text:000100AC STR R2, [R0,R4]` 中被写入 `mmap` 分配的地址 `0x30000` 处，注意 `r0` 是 `mmap` 的返回值。

循环的作用是解密 `code` 的所有字节，在 `0x100BC` 处下断点查看 `0x30000` 的值。

```

这些就是 ARM 指令了，也可以用`idc`脚本解密：

  PatchDword(start,t);

  start=start+4;

```
