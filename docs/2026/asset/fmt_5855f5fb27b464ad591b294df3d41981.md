## 3. 关于 Stolen Code

`DUMP` 后的程序有很多被偷的代码，修复起来很麻烦，偶只好把以下4段也 `DUMP`，然后再粘贴在原程序后面，注意每个段映像地址是变化的。

`Region00EC0000-00FC0000`

`Region01380000-013DC000`

`Region01470000-01474000`

`Region0155C000-015E0000`
