
# [原创]Win8 32位中SSDT Shadow Hook的实现方法

## 一、XP 中SSDT Shadow Hook方法在win8 32中失败

SSDT Shadow hook 不是一个新话题了, 早在 XP系统时就有人对其进行了研究。目前在各大安全技术论坛公布的方法都是基于针对`KeAddSystemServiceTable`内核函数的遍历来达到找到SSDT Shadow 表地址的。

这种方法在XP中是可以实现的，因为在XP系统的`KeAddSystemServiceTable`函数中，SSDT Shadow 地址是明文记录的。但是在WIN8中这种方法却失败了！
