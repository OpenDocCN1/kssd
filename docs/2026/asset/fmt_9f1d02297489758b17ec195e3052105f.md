# 注册码整理

`3E9*7+676C=82CB=33483`（注：`82CB`的十进制）

`3+3+4+8+3=15=21`

所以由上面算出注册码前两框为`2XL13-V3246`

再`3E9*7+3091=4BF0=19440`（注：`4BF0`的十进制）

`1+9+4+4+0=18=24`

又由上两式得后两框真码为`6R80R-114IS`

所以`2XL13-V3246-6R80R-114IS`为一个可用注册码
