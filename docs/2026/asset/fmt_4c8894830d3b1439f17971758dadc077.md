异或完直接调用`sub_411B30`，然后还原`sub_411B30`。下面又看了下`sub_411B30`和`sub_411825`，这时伪代码根本没法看了，完全看不出什么，而且里面还有些堆的申请释放等函数混杂在一起，静态看起来犹如天书。有一点看出来了，没有看到明显的比较或校验，`sub_411825`中使用了`VirtualAlloc`。

把`sub_411B30`顺便也`patch`了，而且把异或函数直接`ret`了，`patch`完了，程序再也不出错了。

```
def xor1(addr,off,length,ss):  for i in range(length): 
    ch = Byte(addr+off+i)
    PatchByte( addr+off+i,ch^ord(ss[i%len(ss)]))  print "patched {:d} bytes in {:0>8x}".format(length,addr+off)

  
xor1(0x411B30,0,0x1AA,'PEDIY')
xor1(0x414422,0,200,'EB7458CCE875'.decode('hex'))
```
