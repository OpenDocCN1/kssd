# 6. 结语

`office` 有一些漏洞, 都是此类溢出. 此类的关键点, 就在于将限制文档字节个数的值放在了文档中, 导致不怀好意的人可以任意修改. 而且加上, `office` 未对读取到的漏洞 `.doc` 中限制字节的值做校验. 导致溢出.

尽量不要点击来历不明的文档, 比如 `.doc.pdf` 等. 因为可能有病毒.
