```
// 0n3代表打开文件行为属性，过滤成功后打印第二个参数指向的字符串，不支持%s格式化字符串只能通过%mu进行传递
```

```
bp kernelbase!CreateFileW ".if(poi(esp+0x14) != 0n3){.printf \"Creating File: %mu\",poi(esp+0x4);.echo};g"
```
