## 小结

`AST` 是语法分析树的简写。 `se` 是符号执行的简写。

### 为什么要用 `Claripy`？

- python中的integer几乎没有大小上限，无法很好的模拟C语言中例如`int`、`byte`的位数的限制，例如`int`中的`0XFFFFFFFF+1`会造成溢出，而python中内置的数据类型则不会溢出。所以这里，我们采用`claripy.BVS`创建符号变量或者`claripy.BVV`来创建一个含有位数限制的数值。

### `BV`是什么的缩写？

- 之前所看到的`claripy.BVS`，`s`是symbols的缩写，`claripy.BVV`中，最后一个`V`是value的缩写.

  `BV`是`Bit Vector`的缩写。

### 如何修改寄存器的值？

`state.regs.eax = state.solver.BVV(0x4,32)`

`state.regs.eax = 4`

以上两个在效果上都是一样的。

### 如何修改内存？如何获取内存

```python
state.mem[0x100000].uint8_t = state.solver.BVV(0x4,8)

state.mem[0x100000].uint16_t = 0

state.mem[0x100000].uint32_t = state.solver.BVV(0x3,32)
```

此处`mem`数组的索引就是内存地址

读取内存的两种方式

```
>> state.mem[0x100000].uint32_t.resolved

<BV32 0x3>

state.mem[0x100000].uint32_t.concrete

0x3
```

**注意**：如果使用`resolved`，获取到的是`BV`类型的值，如果是`concrete`，那么获取到的数值是采用python内置的数据类型的。
