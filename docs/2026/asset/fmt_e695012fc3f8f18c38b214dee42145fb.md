### 解密admin的账号密码

修改下启动的参数，增加两个端口，22用于`ssh`连接，1234用于`gdbserver`的调试

```bash
sudo qemu-system-arm \
-M versatilepb \
-m 256 \
-kernel vmlinuz-3.2.0-4-versatile \
-initrd initrd.img-3.2.0-4-versatile \
-hda debian\_wheezy\_armel\_standard.qcow2 \
-append "root=/dev/sda1 console=ttyAMA0" \
-net nic -net user,hostfwd=tcp::1337-:80,hostfwd=tcp::1338-:22,hostfwd=tcp::1234-:1234 \
-nographic
```

分析`auth.cgi`，发现一个存储账号密码的文件

![](upload/attach/202510/971428_WAWZK6EYPYBS2W4.png)

```bash
root@debian-armel:/var/www/cgi-bin# cat /tmp/store/users.txt
admin:dlZ4bWFsdjUDaiYCeCUqfGYUEhBvFW97dmtxcA==
```

不难看出这里的密码需要解密，跟踪下文件打开的逻辑，会发现最后有一个`sprintf`打印这一段数据，因此推断上面的逻辑是读取文件，所以这里可以尝试动调验证一下

![](upload/attach/202510/971428_EUEE989FYBAQ22Z.png)

下断点之后发现，确实是读取了admin加密后的密码，

![](upload/attach/202510/971428_XR683R5P8WCHKBP.png)

继续分析`ida`可以发现下方有一段`strcmp`的逻辑，经过分析可以发现其实是讲我们的输入密码进行加密后与admin加密后的密码进行对比

![](upload/attach/202510/971428_MANKENKUGVK3J8Y.png)

![](upload/attach/202510/971428_48Z5XGCT856VFUB.png)

加密的算法比较简单，核心逻辑如下，先进行`xor`，然后将最后的结果`base64`加密，因此可以根据加密的后的密码计算出原本admin的密码
