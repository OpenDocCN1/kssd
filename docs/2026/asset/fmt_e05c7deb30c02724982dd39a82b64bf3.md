好了 废话不多说 其实我因为没杀软 下载的东西都不大放心 先扔沙盘去试试都 上边的帖子对我唯一的帮助就是 不联网就没广告 于是扔火眼试试 报告居然木显示连接网络。。

我在沙盘设置禁止内部进程访问网络后居然奇迹般的木广告了 然后我开始考虑它是咋判断网络连接的 因为当时我联网的 肯定是打开某个网页测试 不然也不会被沙盘拦截了一次网络访问并爆出来了 不过沙盘只是拦截 也不告诉俺进程访问的是哪 突然想到先查查访问的哪个IP再查查底下的域名 于是打开了IP雷达 去掉了沙盘的禁止网络访问 IP雷达华丽丽的爆出的目标IP 再看左边 居然还有个域名:c12K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3y4G2M7X3c8&6j5X3I4G2k6#2)9J5k6h3y4F1 哇 省事了 `hosts`重定向到`127.0.0.1`之后打开了俺自己做的小型HTTP服务器 端口设80 再次运行软件 日志里直接给出了以下内容

```
10/16 16:22:34 服务器启动成功
10/16 16:22:37 127.0.0.1:17419 连接
10/16 16:22:37 127.0.0.1:17419 请求的文件不存在\flashgamemaster\solediter\
10/16 16:22:37 127.0.0.1:17419 断开
```

当然 广告当然木弹出来啦 那么 直接改`hosts`目的就达成喽

`hosts`加入以下内容

```
127.0.0.1 b21K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3y4G2M7X3c8&6j5X3I4G2k6#2)9J5k6h3y4F1
```

即可不弹出广告
