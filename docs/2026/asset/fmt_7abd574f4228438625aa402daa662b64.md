## 第8关：AES-256解密

第8关的关键代码在这里：

```
004D2601    5A             pop edx        ; KeyFile文件大小
004D2602    2BD0           sub edx, eax        ; KeyFile文件大小-4为解密长度
004D2604    8D4D D4        lea ecx, [ebp-2C]        ; MD5值作为初始密钥
```
