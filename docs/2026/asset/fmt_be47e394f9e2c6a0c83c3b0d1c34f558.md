# 可能问题

Q: 运行 `Frida` 命令行工具时, 会出现导入DLL失败  
A: 更新 `python3` 的版本, 安装 `python3.7` 以上

在安装时, 查询得到两个消息:

1. `frida` 在 12 版本时, 进行了 `frida` 和 `frida-tools` 拆分, ([https://bbs.pediy.com/thread-230138.htm](https://bbs.pediy.com/thread-230138.htm) 12以上的版本 拆分工具)
2. `frida` 最新版使用的是 `python3.7` 进行编译, 会出现导入失败状况
3. 或者使用 (`pip install frida==11.0.13`) 这条命令, 使用 `frida11` 版本
