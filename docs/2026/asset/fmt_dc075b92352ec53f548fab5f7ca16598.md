
# [原创] Windows rust使用LLVM pass

# 前言

rust的编译器`rustc`用llvm进行中间代码生成(MIR-> LLVM IR <a href="elink@357K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6J5N6i4y4@1j5#2)9J5k6r3c8W2N6W2)9J5k6r3N6#2K9h3c8W2i4K6u0W2M7Y4g2K6N6q4)9J5k6r3I4S2L8X3N6Q4x3X3g2G2M7X3N6Q4x3V1k6G2N6X3g2J5N6X3W2W2N6#2)9J5k6h3S2@1L8h3H3`.">链接</a>)，所以我想尝试下在rust编译过程加个pass进行代码混淆，进而保护生产代码。

由于rust在Windows下有两种toolchain，一种是msvc，另外一种是用mingw的`windows-gnu`。由于LLVM在Windows下的动态库编译只能使用Mingw-w64环境，具体来源：<a href="elink@716K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6D9L8s2k6E0i4K6u0W2L8%4u0Y4i4K6u0r3k6r3!0U0M7#2)9J5c8V1y4y4j5h3E0W2i4K6u0W2K9s2c8E0L8q4)9J5x3$3I4D9N6X3#2Q4x3X3c8J5k6h3I4S2N6r3g2V1i4K6u0V1N6X3q4J5K9h3q4T1L8r3g2K6">LLVM官方CMake参数</a>，并且rust自己编译的LLVM不支持动态链接。

![815418feb83ab11c46d19be273276771.png](upload/attach/202209/956011_46FQ55Y9DS3D9YR.png)

即本文使用MSYS2下的Mingw-w64环境。

# 编译LLVM

## 给LLVM添加混淆插件

1. 添加LLVM obfuscator

这里用的是<a href="elink@858K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5k6i4u0G2K9h3#2K6i4K6u0W2k6$3W2@1K9s2g2T1i4K6u0W2K9h3!0Q4x3V1j5`.">heroims</a>的patch，具体项目地址在<a href="elink@451K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6Z5k6i4u0G2K9h3#2K6i4K6u0r3L8$3u0X3N6i4y4U0j5i4c8G2M7W2)9J5c8Y4c8J5k6h3g2Q4x3V1k6H3j5i4c8U0K9r3g2K6">这里</a>。

由于LLVM14有两种pass方式，一种legacy pass一种new pass，LLVM官方正在逐渐用new pass淘汰legacy pass，所以这里使用new pass作为补丁

```sh
wget https://heroims.github.io/obfuscator/NewPass/ollvm14.patch
cd llvm-project
git apply --reject --ignore-whitespace ../ollvm14.patch
```

这里要注意，正常情况下是直接patch完毕的，如果应用patch错误有`.rej`文件出现，需要手动处理冲突。

成功应用patch截图：

![95c0b1440fff2a6929e7f4c57d4a270e.png](upload/attach/202209/956011_D8BWHWN6V4WY53Y.png)

2. 修复LLVM 14的Link错误

**无冲突**应用完patch之后，需要去`llvm-project/llvm/lib/Transforms/Obfuscation`目录，修改`CMakeLists.txt`

在 `intrinsics_gen`之后添加以下内容

```cmake
COMPONENT_NAME
Obfuscation
LINK_COMPONENTS
Analysis
Core
Support
TransformUtils
```

## 编译LLVM本体

1. 生成cmake构建项目:

在刚刚克隆的LLVM源码**同级目录**输入以下命令

`cmake -G "Ninja" -S ./llvm-project/llvm -B ./build_dyn_x64 -DCMAKE_INSTALL_PREFIX=./llvm_x64 -DCMAKE_CXX_STANDARD=17 -DCMAKE_BUILD_TYPE=Release -DLLVM_ENABLE_PROJECTS="clang;lld;" -DLLVM_TARGETS_TO_BUILD="X86" -DBUILD_SHARED_LIBS=ON -DLLVM_INSTALL_UTILS=ON -DLLVM_INCLUDE_TESTS=OFF -DLLVM_BUILD_TESTS=OFF -DLLVM_INCLUDE_BENCHMARKS=OFF -DLLVM_BUILD_BENCHMARKS=OFF`

命令解析:

```sh
-G "Ninja" 让cmake生成ninja的编译项目
-S ./llvm-project/llvm 指定源码目录
-B ./build_dyn_x64 指定编译输出目录
-DCMAKE_INSTALL_PREFIX=./llvm_x64 指定LLVM安装目录为当前目录下的llvm_x64
-DCMAKE_CXX_STANDARD=17 指定C++ 17标准， LLVM需要至少C++17以上
-DCMAKE_BUILD_TYPE=Release 指定构建类型为Release
-DLLVM_ENABLE_PROJECTS="clang;lld;" 指定LLVM启用项目
-DLLVM_TARGETS_TO_BUILD="X86" 指定编译LLVM的目标,这里只启用了x86
-DBUILD_SHARED_LIBS=ON 构建LLVM动态库
-DLLVM_INSTALL_UTILS=ON 安装LLVM的其他工具，这个是rust编译时需要的FileCheck等工具
-DLLVM_INCLUDE_TESTS=OFF -DLLVM_BUILD_TESTS=OFF 不编译测试
-DLLVM_INCLUDE_BENCHMARKS=OFF -DLLVM_BUILD_BENCHMARKS=OFF 不编译基准测试
```

具体参数可以查看LLVM的<a href="elink@e2eK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6D9L8s2k6E0i4K6u0W2L8%4u0Y4i4K6u0r3k6r3!0U0M7#2)9J5c8V1y4y4j5h3E0W2i4K6u0W2K9s2c8E0L8l9`.`.">官方文档</a>

![4a3c947a94903b6977141f104f5660cd.png](upload/attach/202209/956011_CCSUVJNY34N9WKE.png)

2. 开始编译:

`cmake --build ./build_dyn_x64 -j 22`

命令解析:

```sh
--build ./build_dyn_x64 告诉cmake从哪里开始编译
-j 22 指定多少线程同时编译
```

然后就是等待，这个时间可以刷会视频看看小说,大概20-40分钟，具体时长取决于机器配置。

![2dc7f7b403481626678ec5ced4732c88.png](upload/attach/202209/956011_MRD95KFATS7NGMJ.png)

3. 安装(生成)LLVM

`cmake --install ./build_dyn_x64`

安装编译好的LLVM到`llvm_x64`目录

这里如果不需要对LLVM进行其他修改，可以删除`build_dyn_x64`目录，节省硬盘空间。

4. 添加运行LLVM的依赖

由于是使用Mingw-w64的环境，编译出来的LLVM无法直接使用，需要去MSYS2的**mingw64的bin目录**复制下列dll到LLVM的bin目录。

需要复制的dll列表

```sh
libgcc_s_seh-1.dll
libstdc++-6.dll
libwinpthread-1.dll
zlib1.dll
```

# 编译rustc

## 配置rust编译选项

1. 进入rust源码目录，复制一份`config.toml.example`到`config.toml`

如图所示

![087d7bdded65c2f33f31828c9a9df680.png](upload/attach/202209/956011_QUJ3C6YX8MVME3K.png)

2. 修改`config.toml`

- 在`[rust]`子项，`debug = false`

这里把`debug`关闭，提升速度

![ff90f42f9abe240d0f23f640ca3543f7.png](upload/attach/202209/956011_GQ9JV6M6SXKVPMB.png)

- 在`[rust]`子项，往下的`channel`设置成`nightly`

使用`nightly` channel才能设置LLVM pass的参数

![1d253194ab2b03202290747b993bdb5a.png](upload/attach/202209/956011_F3RFVHVQJDCJDTW.png)

- 在`[target.x86_64-unknown-linux-gnu]`子项，`llvm-config`设置到刚刚我们编译的llvm目录下的`llvm-config`

修改`x86_64-unknown-linux-gnu`为`x86_64-pc-windows-gnu`

这里设置`llvm-config`选项后，就能跳过`rustc`编译的过程中编译非动态版本的LLVM

![836d0d5c5dc5d4438809118754c7549f.png](upload/attach/202209/956011_NZ3KQ35CBBDPRW9.png)

## 修改rust的源码

因为`rustc`(rust的编译器)是有几个不同的编译阶段
