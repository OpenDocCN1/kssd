### 1. Frida 安装配置与手机互通

> **安装 Frida：** `pip install frida`  
> [Frida 下载地址](https://bbs.kanxue.com/elink@ce8K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6H3P5i4m8A6i4K6u0W2L8%4u0Y4i4K6u0r3M7s2u0G2K9X3g2U0N6q4)9J5c8X3k6J5K9h3c8S2i4K6u0r3i4K6t1K6k6X3W2D9k6i4x3)

> **安装 frida-tools：** `pip install frida-tools`

> **查找模拟器或者手机的 CPU 类型：** `adb shell getprop ro.product.cpu.abi`

> **根据手机 CPU 型号下载合适的 Frida Server 并推送到手机：**  
> [Frida Server 下载地址](https://bbs.kanxue.com/elink@d1eK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6X3M7X3W2V1j5g2)9J5c8X3k6J5K9h3c8S2i4K6u0r3M7X3g2D9k6h3q4K6k6i4x3)

> **连接手机或者 MuMu 模拟器：**  
> `adb connect 127.0.0.1:7555`  
> （7555 为 MuMu 模拟器端口号，其它端口请自行查询。）

> **将文件推送到手机的指定目录：**  
> `adb push frida-server-14.0.5-android-x86 /data/local/tmp/`

> **进入手机端：** `adb shell`

> **切换并获取手机的 root 权限：** `su`

> **查找文件是否在手机中：** `cd /data/local/tmp/`

> **查看路径下的文件及权限：** `ls -l`

> **使用 root 权限将文件权限更改为 777：**  
> `chmod 777 frida-server-14.0.5-android-x86`

> **在手机中启动该文件：**  
> `./frida-server-14.0.5-android-x86 &`

> **在电脑端检查手机服务是否成功开启：** `frida-ps -U`

> **Windows 运行端口转发到 PC：**  
> `adb forward tcp:27043 tcp:27043`

### 2. Frida Hook 实现密码验证

先使用 MuMu 模拟器打开软件并随便输入密码，进入后提示**验证码校验失败**。

![验证码校验失败](upload/attach/202011/909733_BZHVFFEVE3GUWN5.png)

将软件拖入 `jadx` 分析代码执行流程，直接使用软件的搜索功能，发现只有一条数据，进入查看。

![jadx 搜索结果](upload/attach/202011/909733_74QDKVSYHUWFEJM.png)

分析软件代码执行过程，找出密码校验方法，从而确定软件 Hook 的具体位置，如下图所示：

![密码校验方法](upload/attach/202011/909733_QRXP8VYB36YTHJ3.png)

接着编写代码。打开 PyCharm，使用 Python 和 JavaScript 编写 Hook 代码，实现对软件的 Hook：

```python
import frida
import sys

jscode = '''
Java.perform(function () {
    // 这里是要 Hook 的软件具体位置：包名 + 类名
    var Testsig = Java.use('com.yaotong.crackme.MainActivity');

    // 这里写要 Hook 的方法名以及参数
    Testsig.securityCheck.implementation = function (str) {
        // 直接返回 true
        return true;
    };
});
'''

def on_message(message, data):
    print(message)

process = frida.get_usb_device().attach('com.yaotong.crackme')
script = process.create_script(jscode)
script.on('message', on_message)

print('运行完毕！！！请随便输入密码进入软件。')

script.load()
sys.stdin.read()
```

之后在 MuMu 模拟器中打开 AliCrackme 软件，并运行上面的 Hook 代码。在软件密码框中输入密码即可进入软件。

![Frida Hook 运行结果](upload/attach/202011/909733_3FFFFC2JSCWTA2J.png)

之后将 Android 视图切换为 Project。为方便添加 Xposed 开发配置，开发 Xposed 模块需要的 [jar 包下载地址](https://bbs.kanxue.com/elink@3ffK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6B7j5$3g2F1N6r3g2J5i4K6u0W2j5X3W2F1N6s2u0S2P5g2)9J5k6h3y4G2L8g2)9J5c8X3c8W2i4K6u0r3M7X3!0T1N6W2)9J5c8X3q4F1k6s2u0G2K9h3c8Q4x3V1k6^5M7r3!0K6k6h3c8Q4x3V1k6S2M7r3W2Q4x3V1j5)。

![Xposed 配置](upload/attach/202011/909733_X3UH246QF5FZ9VF.png)

将下载的 Xposed 开发所需的两个 jar 包拷贝到项目的 `libs` 目录下。

![拷贝 jar 包](upload/attach/202011/909733_T6WFX26PMKSDYC4.png)

然后在 `build.gradle` 文件的 `dependencies` 中添加以下两条信息：

```java
compileOnly 'de.robv.android.xposed:api:82'
compileOnly 'de.robv.android.xposed:api:82:sources'
```

![添加依赖](upload/attach/202011/909733_CWK4CZVK76H9XFH.png)

然后在 `AndroidManifest.xml` 中将应用标识为 Xposed 模块，将下面的代码添加到相应位置。

**用途解释：**

- `xposedmodule` 下的 `value` 为 `true` 时，表示自己是一个 Xposed 模块。
- `xposeddescription` 下的 `value` 中的文字就是对模块的描述说明。

```java
<meta-data
    android:name="xposedmodule"
    android:value="true" />
<meta-data
    android:name="xposeddescription"
    android:value="Hook AliCrackme的模块" />
<meta-data
    android:name="xposedminversion"
    android:value="53" />
```

![AndroidManifest.xml 配置](upload/attach/202011/909733_NVVTTGV46CVAKGE.png)

新建一个 Hook 类，类名为 `HookAlicrackme.java`，并编写 Hook 界面密码的相关代码。这个类实现 `IXposedHookLoadPackage` 接口，并使用接口中的 `handleLoadPackage` 方法。

```java
public class HookAlicrackme implements IXposedHookLoadPackage {
    @Override
    public void handleLoadPackage(
            final XC_LoadPackage.LoadPackageParam lpparam
    ) throws Throwable {
        // 将其它应用剔除掉
        if (!lpparam.packageName.equals("com.yaotong.crackme")) {
            return;
        }

        XposedBridge.log("软件的包名是: " + lpparam.packageName);

        findAndHookMethod(
            "com.yaotong.crackme.MainActivity",
            // 这里是 Hook 软件的包名 + 类名
            lpparam.classLoader,
            "securityCheck",
            // 这里是 Hook 的软件的方法名
            String.class,
            // 这里是所 Hook 的方法的参数类型.class
            new XC_MethodHook() {
                @Override
                protected void beforeHookedMethod(MethodHookParam param)
                        throws Throwable {
                    // Hook 函数之前执行的代码
                    // 传入参数
                    XposedBridge.log(
                        "beforeHookedMethod password: " + param.args[0]
                    );
                    // 函数返回值
                    XposedBridge.log(
                        "beforeHookedMethod result: " + param.getResult()
                    );
                }

                @Override
                protected void afterHookedMethod(MethodHookParam param)
                        throws Throwable {
                    super.afterHookedMethod(param);

                    // Hook 函数之后执行的代码
                    // 通过对 securityCheck 函数的分析发现，
                    // 只要修改函数的返回值即可实现进入软件
                    param.setResult(true);

                    // 传入参数
                    XposedBridge.log(
                        "afterHookedMethod password: " + param.args[0]
                    );
                    // 函数返回值
                    XposedBridge.log(
                        "afterHookedMethod result: " + param.getResult()
                    );
                }
            }
        );
    }
}
```

接下来在项目中为 Xposed 模块设置执行入口，让程序知道从哪里开始执行。

![设置 Xposed 执行入口](upload/attach/202011/909733_ABX3NEENWRDMNB4.png)

在 `assets` 中新建一个文件，文件名为 `xposed_init`（文件类型选 `text`），并在其中写入入口类的完整路径。

这样，Xposed 框架就能够读取 `xposed_init` 中的信息来找到 Hook 模块的入口。

![创建 xposed_init](upload/attach/202011/909733_M8HCPDWBAT9TTW4.png)

接下来将项目打包成 APK，或者直接运行在模拟器上。安装之后进入 Xposed，即可看到模块已经显示。选中模块，然后在框架主界面选择软重启即可激活并运行。

![激活 Xposed 模块](upload/attach/202011/909733_PU47FHK8XQ2CGFA.png)

启动被 Hook 的软件，在密码框中随便输入密码：**吾爱破解：佚名 RJ**。查看 Xposed 框架中的日志，最终默认返回 `true`，表示 Hook 成功。
