根据zenix大佬的汇编描述，这里有个常量`0x2705`，然后我们在IDA通过搜索立即数，立刻定位到了关键代码位置。

```asm
0058CB2A BB 0F270000 mov ebx,0x270F ; 9999 用户，也就是无限用户授权
```

看不太明白，上`Windbg`和`retsync`。

```text
!process 0 0 winchm.exe
!process ffffa10d782cd300
```

IDA启动`ret-sync`插件，然后`windbg`执行`!sync`。

![](https://bbs.kanxue.com/upload/attach/202209/770117_MNX66JJZQPG235X.png)

此时重新运行后，`windbg`需要重新下断才能断下来，而且`windbg preview`的寄存器窗口是错误的。

```text
.process /i ffffa10d782cd300
bp 0058C0E0 // 我们直接下断在小循环起始处。
```

例如`eax`寄存器

![](https://bbs.kanxue.com/upload/attach/202209/770117_H8HF4D4TAFP6HHH.png)

此时可以确定的是，我们的寄存器`eax`代表`v2`，也就是注册码的长度，`ebp-8`取出来的是注册码的地址。

![](https://bbs.kanxue.com/upload/attach/202209/770117_3QXQ5KBH92WHMUB.png)

由`dc`可以看出字符是按两个字节编码的。因此我们重命名后就是这样

![](https://bbs.kanxue.com/upload/attach/202209/770117_9Y8KQ3SGPBFEMMW.png)

用C++实现一下就是这样

```cpp
#include <iostream>
#include <string>
using namespace std;
int main(){
    std::wstring code = L"1234567890";
    int64_t licenseKey = 0;
    for (int i = 0; i < code.length(); i++) {
        licenseKey += (i+1) * code.data()[i];
    }
    printf("License key: 0x%x\n", licenseKey);
    system("pause");
}
```
