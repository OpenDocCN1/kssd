
# 一、漏洞概述

Fortinet FortiOS是美国飞塔（Fortinet）公司的一套专用于FortiGate网络安全平台上的安全操作系统。该系统为用户提供防火墙、防病毒、IPSec/SSLVPN、Web内容过滤和反垃圾邮件等多种安全功能。近日，Fortinet官方发布安全公告，修复了其多个产品中的一个身份验证绕过漏洞（CVE-2022-40684），其CVSSv3评分为9.8。该漏洞可能允许攻击者在易受攻击的设备上执行未经授权的操作，攻击者通过向易受攻击的目标发送特制的 HTTP 或 HTTPS 请求进行绕过身份认证以管理员身份在控制面板中执行任意操作。

# 二、影响版本

```text
7.0.0 <= FortiOS <= 7.0.6
7.2.0 <= FortiOS <= 7.2.1
7.0.0 <= FortiProxy <= 7.0.6

FortiSwitchManager = 7.0.0
FortiSwitchManager = 7.2.0
```

# 四、原理分析

将`forigate-vm`中的`fortios.vmdk`复制出来进行分析。

1、安装libguestfs

libguestfs 是一组 Linux 下的 C 语言的 API，用来访问虚拟机的磁盘映像文件，几乎可访问任意类型的文件系统。

```text
sudo apt install libguestfs-tools
```

2、查看磁盘分区情况

```text
sudo virt-filesystems -a fortios.vmdk
```

3、挂载

```text
sudo guestmount -a fortios.vmdk -m /dev/sda1 --ro mount_dir_name
```

（`mount_dir_name`替换成自己的目标文件夹）

4、挂载成功后，`rootfs.gz`为文件系统压缩包，我们将其复制出来。

5、解压，提取，查看文件：

```text
gunzip rootfs.gz
cpio -i 2>/dev/null < rootfs
ls
```

![图片描述](https://bbs.kanxue.com/upload/attach/202211/968133_32NB7A8VZT5N3DY.png)

6、解压所有的压缩包,发现不能正常解压：

```text
xz --decompress *.xz
```

7、尝试查找其他的解压程序：

```text
find . -name xz
./sbin/xz --decompress *.xz
```

发生错误，将其修改至主机系统的链接器路径，patch后并保存：

```text
file ./sbin/xz
patchelf --set-interpreter /lib64/ld-linux-x86-64.so.2 sbin/xz
./sbin/xz --decompress *.xz
ls *.tar
```

![图片描述](https://bbs.kanxue.com/upload/attach/202211/968133_NN98ZVM4T787XED.png)

![图片描述](https://bbs.kanxue.com/upload/attach/202211/968133_2BW5DXT37M3K3ZF.png)

接下来，解压缩文件并开始检查其内容。我们发现包含大量二进制文件，其中许多是符号链接。以及该文件夹包含管理界面的前端 Web 代码，管理界面的 NodeJs 后端，以及一个 `libaries` 文件夹和一个配置文件夹。

10、分析程序

在 IDA pro 中打开`init`程序，搜索字符串`fweb_authorize_all`进行定位，发现函数`sub_C4B590`调用了`fweb_authorize_all`函数。

![图片描述](https://bbs.kanxue.com/upload/attach/202211/968133_T52NAXBC4XUCVJR.png)

进入到函数`fweb_authorize_all`中，分析可得，在身份认证过程中，首先调用`fweb_authorize_all`判断`v2[8]`是否等于`"127.0.0.1"`，即判断是否本机访问。

![图片描述](https://bbs.kanxue.com/upload/attach/202211/968133_FVJW67RCZEQNY83.png)

如果本机访问则`sub_C50E80`函数内部继续判断接口如果是否为`vsys_fgfm`接口。

![图片描述](https://bbs.kanxue.com/upload/attach/202211/968133_ETZXTEUQ75CUHBE.png)
