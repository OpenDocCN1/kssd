# Ignition 和 TurboFan

Ignition, 是v8的解释器, 而 TurboFan 是v8最新的优化编译器。它们的关系如下图：

![](https://bbs.kanxue.com/upload/attach/202403/492418_B3W8K5DQQR35X73.webp)

JS源码经过 Parser(词法分析、语法分析) ，送入Ignition，生成字节码执行；字节码的优点是编译快，缺点是执行慢，适用于执行次数少的代码。
