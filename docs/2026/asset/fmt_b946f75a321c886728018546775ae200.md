# 十三、fuzz结果

共得到两类crash；

## 1、除零异常导致的crash

这类样本占了大多数，一般来说很难利用，意义不大；

## 2、栈溢出导致的crash

别激动，经过分析，很难利用，原因如下：

在解析torrent文件的过程中，每次文件中出现一个`d`字符，都会导致程序递归调用同一个函数，最终导致栈溢出；
