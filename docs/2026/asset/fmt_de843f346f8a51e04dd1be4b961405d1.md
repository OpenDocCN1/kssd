
# [原创]使用WinArk对抗r77Rootkit

## 0. 背景

最近发现了一个 [Rootkit](<https://bbs.kanxue.com/elink@dceK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1P5i4c8W2j5$3!0V1k6e0M7%4i4K6u0r3M7U0M7%4i4K6u0V1M7X3!0G2N6r3E0A6N6l9`.`.)>) 项目，Star 星数在 1.2K 以上。Clone 后仔细研究了一下，是一个纯 r3 的 DLL 注入 + inline hook 隐藏。

[WinArk](<https://bbs.kanxue.com/elink@127K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6n7k6h3&6W2k6X3W2U0K9h3q4D9b7$3!0V1k6g2)9J5c8W2N6A6L8V1q4J5K9H3`.`.)>) 作为一款反 Rootkit 工具，特此验证一下它的功能。

## 1. r77Rootkit 功能简介

隐藏文件、注册表、服务、网络连接、命名管道和计划任务。

![](https://bbs.kanxue.com/upload/attach/202310/958869_RWHZWH445SP9RQM.webp)

- `Install.exe` 是安装器
- `Uninstall.exe` 是卸载器
- `TestConsole.exe` 是测试控制台程序
- `$77-Example.exe` 是运行安装器后会被隐藏的文件

## 2. 运行效果

### 2.1 文件隐藏

![](https://bbs.kanxue.com/upload/attach/202310/958869_VGJY2WDM455AXCD.webp)

可以看到 `$77-Example.exe` 在资源管理器中已经看不到了。

### 2.2 进程隐藏

![](https://bbs.kanxue.com/upload/attach/202310/958869_X898WYRRPMND9DM.webp)

任务管理器中按照 PID 排序后也看不到 6056 进程。

### 2.3 服务隐藏

![](https://bbs.kanxue.com/upload/attach/202310/958869_D223BKRS3G7NM2F.webp)

服务按照 PID 排序后，也看不到 `svc64` 服务。

其他隐藏就不在此展示了。

## 3. WinArk 运行测试

### 3.1 绕过进程隐藏

在完成相关符号下载后，WinArk 成功运行起来。点击 Process ID 排序后，都没有摘除 inline hook 的前提下，我们成功找到了 `dllhost.exe` 进程。

![](https://bbs.kanxue.com/upload/attach/202310/958869_HYHZ3F7MSHD3D3B.webp)

右键属性也能看到相应的启动参数。

![](https://bbs.kanxue.com/upload/attach/202310/958869_2RCBJDF53ETT9ZT.webp)

### 3.2 绕过服务列表隐藏

按照名称排序后，未发现 `svc64`，测试失败。

![](https://bbs.kanxue.com/upload/attach/202310/958869_RPMXC98G5CN953B.webp)

如此则进行 inline hook 扫描 `WinArk.exe` 自身。

![](https://bbs.kanxue.com/upload/attach/202310/958869_YNVV3Z8HA2BN5WS.webp)

此时等待 2-3 分钟，转圈就是没扫完。扫描结果显示被 hook 了相关服务遍历函数。

![](https://bbs.kanxue.com/upload/attach/202310/958869_HU4XCXY2EVFXMJS.webp)

都右键逐个恢复后，关闭窗口。

刷新服务列表后还没有出现。

再右键重新扫描一次，钩子已经被摘除。这是为什么呢？

原来是这里我理解错误了，他是把要隐藏的项写入了注册表。通过恢复注册表的钩子，可以看到相应的注册表表项。

![](https://bbs.kanxue.com/upload/attach/202310/958869_9J3A4C9BXUDZ73T.webp)

### 3.3 绕过文件隐藏

可恢复文件钩子。

![](https://bbs.kanxue.com/upload/attach/202310/958869_ECAXJM2D4DGBY5Y.webp)

## 4. 结束语

到此我们展示了 WinArk 修复 r3 层 inline hook 的功能，成功修复了 r77-rootkit inline hook NTDLL 的：

`NtQuerySystemInformation`、`NtResumeThread`、`NtQueryDirectoryFile`、`NtQueryDirectoryFileEx`、`NtEnumerateKey`、`NtEnumerateValueKey`、`EnumServiceGroupW`、`EnumServicesStatusExW`、`NtDeviceIoControlFile`。
