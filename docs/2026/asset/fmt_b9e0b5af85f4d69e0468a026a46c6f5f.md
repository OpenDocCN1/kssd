![图片描述](upload/attach/202011/809626_5675PZR2XAMG6Y4.png)

![图片描述](upload/attach/202011/809626_D4DWZCACM7F5PS4.png)

![图片描述](upload/attach/202011/809626_9XZNSW98A9ZSYBK.png)

+ 流程就是抓包把`cookie`改成`check`然后加密后的`secret`和明文的admin与任意密码

+ 抓包看到一个base64加密的`cookie`

![图片描述](upload/attach/202011/809626_GSKQ4RPWWMAENSU.png)

+ 解密后

![图片描述](upload/attach/202011/809626_8669RWRQNTUJAKF.png)

+ 这个88应该就是`secret`这个变量 那么把它加密

![图片描述](upload/attach/202011/809626_FX2WX39ECK55RG7.png)

+ 然后把包丢进repeater

![图片描述](upload/attach/202011/809626_HQ55S2XAU965HH2.png)

+ 名字改为`check`等于加密后的88

+ 后面跟上admin与任意密码即可 注意：`check`那里的密码必须与下面提交的数据`password`一样 不然会提示重新检查`cookie`
