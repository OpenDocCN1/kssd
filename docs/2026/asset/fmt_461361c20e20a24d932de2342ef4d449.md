再罗嗦两句，扩展一下知识

`AND`   是两串数做“与”运算，只有2进制都是1的时候才＝1，例如

```
1110111010101
0001010111011
```
结果就是

```
0000010010001
```

一般来讲都是10进制化成2进制再与运算，下两个同

`OR`   “或”运算，有一个是1就＝1，例如

```
1111010100001
0001010001010
```
结果就是

```
1111010101011
```

最后“与或”（是吧？）运算，两个一个1，一个0才＝1

```
1111010101000
0010101001010
```
结果就是

```
1101111100010
```
