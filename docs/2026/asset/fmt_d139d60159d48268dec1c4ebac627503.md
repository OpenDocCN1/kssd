
`01002A1B  |.  85C0          |TEST EAX,EAX`

也就是记事本调用`GetMessage`时，系统内部已经对该消息进行了筛选，先交给IMM处理，调用`IMM32.ImmProcessKey`，所以就来到了`sogoupy.ImeProcessKey`，该函数是判断按键是否要进行输入法处理，是返回1，否返回0

第二次是中断在`ImeToAsciiEx`，堆栈回溯

`0007FECC  |77D40A82  返回到 USER32.77D40A82 来自 IMM32.ImmTranslateMessage`

`0007FEE8  |01002A08  返回到 notepad.01002A08 来自 USER32.TranslateMessage`

查看`01002A08`代码

`01002A01  |.  50            |PUSH EAX                                        ; /pMsg`

`01002A02  |.  FF15 98120001 |CALL DWORD PTR DS:[<&USER32.TranslateMessage>]  ; \TranslateMessage`

`01002A08  |.  8D45 E0       |LEA EAX,[LOCAL.8]`

`01002A0B  |.  50            |PUSH EAX                                        ; /pMsg`

`01002A0C  |.  FF15 94120001 |CALL DWORD PTR DS:[<&USER32.DispatchMessageW>]  ; \DispatchMessageW`

就是记事本建立消息循环的地方，在这里，`TranslateMessage`--`ImmTranslateMessage`--`ImeToAsciiEx`，完成输入法对按键的转换处理，变成中文编码

最后中断在条件断点，这里才把消息交给用户程序，看看是否需要对按键进行特殊处理

`0007FE10   77D18816  返回到 USER32.77D18816 来自 USER32.77D1870C`

`0007FE14   771A3DDA  COMCTL32.771A3DDA`

`0007FE18   000809A0`

`0007FE1C   00000100               ;WM_KEYDOWN`

`0007FE20   000000E5               ;虚拟键码为VK_PROCESSKEY`

`0007FE24   001E0001               ；`

当切换`sogou`为英文输入，按下”A"键，直接由`ImeProcessKey`到条件断点（因为`ImeProcessKey`返回为0），

`0007FE10   77D18816  返回到 USER32.77D18816 来自 USER32.77D1870C`

`0007FE14   771A3DDA  COMCTL32.771A3DDA`

`0007FE18   000809A0`

`0007FE1C   00000100          ;WM_KEYDOWN`

`0007FE20   00000041          ;原始键码，对应A`

`0007FE24   001E0001          ；key data`

现在让我们看看中文是如何出来拼出来的，这里需要用到三个重要的消息`WM_IME_STARTCOMPOSITION(10Dh)`、`WM_IME_COMPOSITION(10Fh)`和`WM_IME_ENDCOMPOSITION(10Eh)`

首先在`77D1870C`下条件断点`[ESP+C]==10dh`，切到记事本窗口，随便输入个字符，过程为`ImeProcessKey`---`ImeToAsciiEx`--`WM_IME_STARTCOMPOSITION`

然后在`77D1870C`下条件断点`[ESP+C]==10Fh`，切到记事本窗口，输入字符，会发现每输入一个字符，都经历过程`ImeProcessKey`---`ImeToAsciiEx`--`WM_IME_COMPOSITION`，

最后在`77D1870C`下条件断点`[ESP+C]==10Eh`，切到记事本窗口，输入回车或空格，过程为`ImeProcessKey`---`ImeToAsciiEx`--`WM_IME_ENDCOMPOSITION`, 完成中文

拼出的中文放在哪儿？可以查看`ImeToAsciiEx`函数的倒数第三个参数`lpdwTransBuf`

`Address of a double word buffer to receive the translated result. The format is [Length of the pass in translated message buffer] [Message1] [wParam1] [lParam1] {[Message2] [wParam2] [lParam2]{...{...{...}}}}.`

翻翻缓冲区就能找到刚刚拼出的中文了，呵呵！
