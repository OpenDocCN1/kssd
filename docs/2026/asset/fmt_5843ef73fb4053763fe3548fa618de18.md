其中的`object`就是上方的通用类型的header，对于复杂类型会使用到`ecma_extended_object_t`，其中的`union u`会根据不同的类型选择不同的字段，以此定义不同对象的属性字段

      } u2;

      {

    } cls;

      uint32_t length_prop_and_hole_count;
    } array;
