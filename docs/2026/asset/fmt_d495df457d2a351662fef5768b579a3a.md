到此,整理一下思路.首先把用户名用`2CH`(`2CH`就是逗号)补齐为`32H`长,比如用户名`WAKU`,就在后面补`32H-4`个逗号,设为字符串B.然后用了两个常量,`0D04323E`和`9014FB17`,分别把它们转换成`$0D0432E3`和`$9014FB17`的字符串形式,设为字符串A和C,然后把A、B和C连接起来成为`ABC`.

要注意的是Delphi的字符串有一个特点,就是在字符串前面会用一个字节表示字符串的长度,向上面的`WAKU`前面就有一个`04`,`$0D04323E`和`$9014FB17`前面分别有一个`09`.这样`ABC`的全貌就是这样的:

```
(09)$0D04323E(04)WAKU,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,(09)$9014FB17
```

括号内是由于ASCII表示不出来,所以我用数字表示了.
