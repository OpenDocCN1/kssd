## 4、Android Studio + smalidea 插件动态调试 smali 代码

### 调试模式启动

```bash
adb shell am start -D -n com.renren.mobile.android/.ui.WelcomeScreen
```

### 进行端口转发

```bash
adb forward tcp:8700 jdwp:957
```

### 端口占用错误

出现以下错误说明 `8700` 端口被占用：

```text
error: cannot bind listener: cannot bind to 127.0.0.1:8700: 通常每个套接字地址(协议/网络地址/端口)只允许使用一次。 (10048)
```

### 解决办法

```bash
netstat -nao | findstr "8700"
```

根据 PID 找到该进程，结束进程。

打开任务管理器，依次选择“查看”→“选项列（S）”→勾选 PID，确定。

配置好调试环境后就开始调试了。先在 `ServiceProvider.smali` 文件里面的 `a(Ljava/lang/String;Ljava/lang/String;ILjava/lang/String;Ljava/lang/String;Landroid/content/Context;Lcom/renren/mobile/android/loginfree/LoginStatusListener;)V` 方法函数头下段，按 `Shift+F8` 往上回溯，就来到图下所在位置。

![](upload/attach/202012/880306_T4HEMWTG85HJJFE.png)

在 `LoginFromQuickRegisterFragment.smali` 文件里面找到 `onClick(Landroid/view/View;)V` 方法，找到登录逻辑核心实现如下图。

![](upload/attach/202012/880306_UXT9HSY2CSV395Z.png)

## 小结

1. 使用抓包工具抓取人 X 的数据，通过对比工具分析哪些数据发生了改变，着重分析改变的字段及加密算法。
2. 反编译 APP，搜索协议中的关键字段信息进行定位。
3. 分析相关字段的加密算法。
4. 动态调试分析字段拼接流程。
