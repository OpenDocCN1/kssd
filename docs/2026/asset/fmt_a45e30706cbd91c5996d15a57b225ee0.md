
# [原创]对一个QQ木马的分析

## 程序流程

首先注册自己程序的窗口以及类等一系列窗口操作，安装了一个定时器，间隔为100ms，功能搜索QQ的类名，如果找到就利用`FindWindow("5B3838F5-0C81-46D9-A4C0-6EA28CA3E942", NULL)`找到当前运行的QQ号，之后隐藏QQ主界面，弹出自己的界面，利用socket发送输入的密码到指定的IP、端口，达到窃取用户的QQ密码。

程序很简单不过，不过代码确实有点多，不过很多都是多是对字符串的操作，动态就直接无视吧。
