# 攻击思路

由于`create`和`edit`操作中都有置零操作,所以不存在泄露`libc`/`heap`信息的机会

想要泄露信息只能通过`uaf`后的`show`,那么我们就无法利用`uaf`中的`overflow`函数

之后无论是劫持`IO`结构体还是劫持栈上的返回值都是可以`getshell`/`orw`的
