
# [原创]漏洞挖掘(APP逻辑漏洞,登录页面) 的完整流程思路 分享

获得一个域名渗透思路

# 信息收集

首先进行信息收集,主站的防护一般做的比较好,可以尝试从边缘资产下手

通过`多地ping`判断是否启用了`CDN` (`多地ping`显示多个`IP`启用了`CDN`,通过国外`IP`地址进行`ping`域名,备案信息查注册地,通过网站图标的来源`IP`)

通过`whois`查询得到注入人电话和邮件同时通过`whois`反查是否会得到新域名

通过备案查询看是否得到新域名

通过企查查,小蓝本等都是为搜集到更多域名

通过`oneforall`子域名挖掘`layer`得到更多的资产

鹰图`鹰图`(很不错,每天免费500积分,白嫖党)`fafo`(也可以)`shado`信息收集网站

然后对得到的资产进行依次渗透

# 网站

## 公开漏洞

判断网站是否使用了`CMS`公开的框架,中间件类型版本,搜寻公开的漏洞

## 基本漏洞

在页面中一切数据交互的地方搜索框,留言板,`url`中变换的参数值,尝试`sql`注入和`xss`,在功能点,根据功能的不同尝试不同的漏洞如寻找文件上传,通过`URL`分享和在`url`地址中获取资源的地方尝试`SSRF`.

### 逻辑漏洞

注册和登录,短信轰炸,邮件轰炸(`src`也会收的)

(`验证码失效,抓包修改电话后加%00,可以多次给手机号发送验证消息.`)

找回密码步骤可以跳过

#### app端漏洞挖掘(存在最多)

`app`端通过逍遥模拟器,将`app`的流量转到`burp`中,转为`web`端的渗透,在大多少`APP`中存在以下问题`app`程序中的完成一个如签到任务,会发送一个包,抓包,修改任务`ID`,通过`burp`的`intruder`模块,进行批量`id`1-999的修改发送,控制速度,会完成各种任务,兑换礼品.(`虽然可以兑换,但最好还是不要,交漏洞就好`)

### 尝试其它思路

`nmap`去扫描端口

潮汐指纹去寻找旁站和`C`段信息

通过目录扫描`dirsearch`,获取网站的备份文件,或得到后台的登录页面,

# 转到后台页面

转到登录页面进行进一步渗透测试

### .git .svn 目录

在进行目录扫描`(工具dirsearch)`,看是否会有`/.git/` `/.svn/`目录.有的话可以躺平了,通过`gitHack` `svnHack`工具直接拉取网站后台源码.`(出现原因是,管理者,直接copy代码到网站中,没有使用git,svn导出功能)`

### disearch暴露出来的其它目录

目录扫描是否有未授权访问的页面暴露出来,都点开看一看,会有好东西.
