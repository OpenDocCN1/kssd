
# 调试`KeyHook.dll`

![](https://bbs.kanxue.com/upload/attach/202207/890008_ANM3SXA9MUREG5B.jpg)

使用`OD`打开`notepad.exe`，F9运行

![](https://bbs.kanxue.com/upload/attach/202207/890008_PPVB9RXJ4ZQZD4C.jpg)

在`OD`中设置如下的选项

![](https://bbs.kanxue.com/upload/attach/202207/890008_Z8KF8WMAXTNMW2Y.jpg)

运行`HookMain.exe`

![](https://bbs.kanxue.com/upload/attach/202207/890008_TAS5H96D2Y5GFRV.jpg)

随后在`notepad`中随意输入一个字母，此时dll被加载到10000000处

![](https://bbs.kanxue.com/upload/attach/202207/890008_VZBS5WAVXRBQ7J3.jpg)

```
根据系统环境不同，有时不会先显示 KeyHook.dll，而是先加載其他 DLL 库。

此时按（F9）运行键，直到KeyHook.dll加载完成。

有些系统无法正常运行该功能，此时使用OllyDbg2.0即可保证运行顺畅。
```

点击dll跳转到`KeyHook.dll`的EP地址处。并且由于之前在调试`HookMain.exe`时候已经知道钩子的地址是10001020，所以直接在此处下断点。

![](https://bbs.kanxue.com/upload/attach/202207/890008_JT5HWEDKBCCJJU4.jpg)

下好断点好，再重新运行一下程序。然后在记事本当中尝试输入数据，记事本无接收数据的意向，并且`OD`已经跳转到断点处。

![](https://bbs.kanxue.com/upload/attach/202207/890008_74KRJMMEQ52NM3E.jpg)

```
1、OD运行notepad.exe

2、开启Break on new module(中断于新模块)选项

3、运行HookMain.exe

4、进行键盘输入，触发键盘消息事件

5、dll被注入

6、OD中设置钩子进程（KeyboardProc）断点
```
