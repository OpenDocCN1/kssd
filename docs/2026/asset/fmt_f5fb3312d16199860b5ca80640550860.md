## 二、算法小结

1. Email字符位数要大于10位，如果不足16位尾部加8个`'a'`。

2. 预处理Email字符串，在`[a..f] [A..F]`范围内的，先与`'CE'`逻辑与运算，再减42。其余的减32。处理后的字符串长度为16。

3. 设处理后Email的字符串为`S=(s0,s1,s2 ……s13,s14,s15)`。

4. `C=(c0,c1,c2 ……c13,c14,c15)`，`i [0..15]`，`S`下标大于等于16-16(循环)。

```
C(i)=(   (si+i)*s(i+2)    + (s(i+3)+i)*s(i+6)  +  s(i+1)*s(i+5)  + s(i+4)*s(i+7)   )  *
       ( (s(i+9)+i)*s(i+13) + (s(i+8)+i)*s(i+10) + s(i+14)*s(i+12) + s(i+15)*s(i+11) )
```

5. 4.式运算结果`C(i)`算术右移(`SAR 3`)、与运算(`AND 1F`)，再根据运算结果的大小选择不同的加数：

```
       if      c(i) < A     +50
           A=< c(i) <12     +28
          12=< c(i)         +2F
```
