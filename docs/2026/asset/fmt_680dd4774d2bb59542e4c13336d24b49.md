
## 6.借鉴的技巧

这个病毒写的确实非常好。作者的构思，以及编码技巧都值得我们借鉴到自己的壳中。

这个病毒最实际的是给出了几个很不错函数例如`BPE32`变形引擎、`BCE32`压缩引擎这些，都可以直
接拖到我们自己的壳中使用，或者在其上进行山寨。做到青出于蓝而胜于蓝的山寨效果。还有像多线程
通讯这种技巧非常值得在壳中得到应用。

这个病毒整体用的最多是一个自修改的编码技巧，例如：

```
mov eax, 0
_xx_ = dword ptr $ - 4
```

接下来是

```
call eax
```

或者

```
stosd
```

这些操作`eax`寄存器的技巧，都值得我们借鉴。
