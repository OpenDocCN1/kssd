
## 编译为 so 文件

```bash
gcc -shared -fPIC libhook.c -o libhook.so -ldl -lcapstone
```

## 新建一个 sample.c 文件

文件内容：

```c
#include<stdio.h>

int main()
{
getchar();

for(size_t i = 0; i < 10; i++)
{
FILE* file = fopen("sample.txt","r");
if(file != NULL)
{
fclose(file);
}
}
}
```

## 编译并运行 sample

```bash
gcc sample.c -o sample
./sample
```
