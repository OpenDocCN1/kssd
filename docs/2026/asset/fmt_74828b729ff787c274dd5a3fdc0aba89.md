## 破解总结

该软件通过一定算法得到一个机器码，这个机器码的算法就不用研究了。注册码通过机器码进行二次运算得到：

- 第一次把机器码的 ASCII 值从左到右取出，乘以十并相加，得出一个值。
- 然后进行第二次计算，把刚才算出来的值的 ASCII 值从右到左取出，乘以十并相加。此时计算出来的值为十六进制。
- 最后把这个十六进制转换为十进制，就是我们想要的注册码了。

## 注册机制作

现在我们可以来制作注册机了，呵呵，我只会用 Delphi 哟！好了开始开工了，先来写三个函数吧！

### 第一个函数模仿第一次计算

```delphi
function strtointex(s:String):integer;
var i,n:integer;
begin
  n:=0;
  if length(s)-1>0 then
    for i:=1 to length(s) do
      n:=(n+ord(s[i]))*10;
  result:=n;
end;
```

### 第二个函数模仿第二次计算

```delphi
function strtointex0(s:String):string;
var i:integer;
    n:int64;
    x:string;
begin
  n:=0;
  result:='';
  if length(s)>0 then
  begin
    for i:=length(s) downto 1 do
      n:=(n+ord(s[i]))*10;
    x:=inttohex(n,16);
    result:=copy(x,length(x)-7,8);
  end;
end;
```

第三个函数就是把十六进制转为十进制。不知道为什么 Delphi 中没有内置这个函数，还是不知道！管他了，我们写一个！
