# 安全解决方案

1、由于`Phobos`家族会利用`RDP`（远程桌面协议），建议关闭`3389`等远`RDP`相关端口，如果确实有工作业务需要，建议进行白名单配置，只允许白名单内的`IP`连接登陆。
2、尽量关闭不必要的文件共享，或使用强密码对文件共享加密保护。
3、定期更换帐户密码，采用高强度的密码，避免使用弱口令密码，同时避免使用统一的密码。
4、对重要文件和数据进行定期异地备份。
