# KeyGen

讲讲思路吧。那就是对原授权解密的`buffer`中的`buffer[50]`做修改大小`0x10`的数据，然后用原密钥`"ShouJiErShiSiShi"`以 AES ECB 模式进行加密。最后逆向第一轮解密的算法，生成符合要求的序列号就可以了。
