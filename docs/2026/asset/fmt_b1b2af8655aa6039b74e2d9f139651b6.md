
# [原创]拿来就用,浅谈代码抽取技术在汇编中的应用

在用WIN32汇编做软件开发的过程中不免要遇到一些麻烦,如想写个远程控制,写到远程屏幕传输的时候就看到DELPHI里面有人用库转换抓取的BMP图片为JPG,这下可难到我了,自己写个JPEG处理模块,我做不到,到网上找了下,有C语言的,想了想,我可不可以把它弄到汇编中呢?我在实例包中有人用C++写了实例,这下好办了,

在VC中新建LIB工程,导出3个函数,`bmp2jpg24`,`bmp2jgp`,`jpg2bmp`,在函数定义中直接调用实例中的代码,返回值中加上`__stdcall`,这样就能在汇编中调用了,带着激动的心情来到RADASM中,编译,链接,晕,抱错了,无法找到`LIBCD.LIB`,找到`VC98lib`目录,`COPY`过来,接下来又是几个,以`COPY`过来,再后来搞不下去了,RADASM干脆CRASH了,这个问题一直没解决,希望高手能给予解答,后来我直接把它做成了dll,TMD这样又可以!!

第一次的成功让我高兴不已,马上对一个免费的界面库进行"抽取"工作,现献上完整品!!
