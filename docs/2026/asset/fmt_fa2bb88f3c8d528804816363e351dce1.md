## 详细过程

刚拿到这个软件时，一看是 Java…… 蛋疼啊，又要装虚拟机把 Java 环境配上，然后 `XJad` 反编译、看源码、重新编译一个放回去。没办法，慢慢来吧。

`jar` 包直接解压，傻眼了，全是 `A`、`a`、`ab`、`b`、`ba`。我勒个去，这还咋编译？没办法，只能看看能不能写算法搞注册机了。

先定位一下算法在哪个 `class` 里。用 `XJad` 把包里面的所有 `class` 反编译成 `.Java`，用 `Uedit` 在文件夹内搜索字符串 `"注册失败"`，找到关键类、关键函数。

函数找到了，直接照着先写一份解码的吧。了解下解码流程，看看解密函数，什么 `Base64`、`md5`、`Des` 加密的，还有一些需要的数据和其他类的一些函数。没法动态调试，没办法只能宣布失败了。

那怎么办？也不能放弃啊，另寻思路吧。网上 Look 一下别人都咋弄的，看看能不能爆破撒。

把神器 `IDA` 祭出来，把 `.class` 拖进去。很好很强大，直接定位到关键函数。

函数里面第一个判断 `ifne met008_12`，直接爆破它，跳到正确的函数地址就可以了。

先看一下 `ifne met008_12` 这条指令的地址：`56D3`。

再看一下跳到的 `new java/io/FileReader` 指令的地址：`56D8`。

打开 Hex View，执行 `Jump` 到 `56D3` 这个偏移量，显示 `9A 00 05`。`9A` 代表的是 `ifne` 这个指令，`05` 是跳转多少个相对地址。

`56D8 - 56D3 = 05`

这样，只要找到需要跳转的地址，修改一下就可以了。

正确地址：`5CDC`

`5CDC - 56D3 = 609`

OK！打开 Hex，执行 `Jump` 到偏移 `56D3`。

现在：
```
9A 00 05
```
改成：
```
9A 06 09
```

保存 `.class`，打开 `jar` 包，把刚才修改的 `class` 拖进去覆盖一下。

好了，大功告成！启动一下，`Success!`
