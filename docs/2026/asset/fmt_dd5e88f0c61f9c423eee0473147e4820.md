
# 流程
释放文件 `Identities.dat`、`Licence.Dll`、`pexo261.dll`、`pexo261.exe`、`ruei.dll` 文件到 `C:\Documents and Settings\Administrator\Application Data\Macromedia` 目录，然后给 `pexo261.exe` 创建快捷方式到启动项（xp,W7通用，UAC造成的结果），伪装成 `explorer.lnk`。检测是否存在杀毒软件，如果存在那么重启运行（这里面又全局hook，所有这样可以过主动），不存在写注册表 `SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows`，`AppInit_DLLs`=`“dll的全路径”`，`LoadAppInit_DLLs`。

# 特点
注入到 `explorer`，hook 函数 `NtQueryDirectoryFile` 隐藏快捷方式文件（这个时候你用 explorer 是看不到这个启动项的）。
