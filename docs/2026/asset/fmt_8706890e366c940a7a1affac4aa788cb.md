TTP以`PUSH IMM32/jmp VMINIT`对进入虚拟机，并把寄存器和`key`按顺序入栈

```text
/*
key
edi
esi
ebp
esp
ebx
edx
ecx
eax
eflag
keydata
*/
```

其中`eax`,`ecx`,`edx`作为虚拟机的寄存器用于运算

`edi`指向`VMCONTEXT`

`ESI`指向`VMDATA`

`EBP`指向真实堆栈

`EBX`作为`key`参与运算
