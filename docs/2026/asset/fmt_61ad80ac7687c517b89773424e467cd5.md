# 小结

这种方法提供了一种别样的思路，相对于傀儡进程技术，它可以少启动一个进程，相对于`smc`技术或者原作者介绍的技术，不需要复杂的页面属性修改，适合执行精简的`shellcode`，但对于内存加载`exe`/`dll`，这种拓展思路就显得吃力了，根据原作者的思路，结合`PE`文件结构，更胜一筹。

至于这种技术的免杀，在此不做讨论。
