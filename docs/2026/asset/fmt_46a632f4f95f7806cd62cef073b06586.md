frida hook代码

```js
//1494C4
var arg2;

onLeave: function (retval) {

}
});
```

由比对结果可知，第一个参数是输入的不知名参数，第二个参数是不知名参数的长度，第三个是出参结果二进制，即定义成：`sub_1494C4(input, inputlen, &output)`
