### 编译选项

这一节我会介绍三个选项，并附带例子。

这是用到的[源码](https://bbs.kanxue.com/elink@955K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6A6L8Y4k6A6j5%4c8#2M7K6p5K6x3o6k6Q4x3V1k6m8f1V1#2Q4x3X3c8W2M7r3W2K6L8$3c8W2M7#2)9J5c8X3u0D9L8$3u0Q4x3V1k6E0j5i4y4@1k6i4u0Q4x3V1k6q4M7r3W2K6L8$3c8W2x3g2)9J5c8X3y4G2L8i4m8A6L8r3g2J5i4K6g2X3L8%4m8@1K9h3!0F1M7#2)9J5k6h3x3`.):

```
#include <stdio.h>
#include <string.h>

static char password[] = "compiler_options";

int main()
{
  char input_pwd[20]={0};

  fgets(input_pwd, sizeof(input_pwd), stdin);

  int size = sizeof(password);

  if(input_pwd[size] != 0)
  {
    printf("The password is not correct! \n");
    return 0;
  }

  int ret = strncmp(password, input_pwd, size-1);

  if (ret==0)
  {
    printf("Good done! \n");
  }
  else
  {
    printf("The password is not correct! \n");
  }

  return 0;
}
```

#### 调试符号

`-g` 选项会在编译时向可执行文件中加入调试信息（符号表）。

编译带 `-g` 和不带 `-g` 选项的两个 ELF 文件，比较大小：

