### 服务启动`StartService`

主要逻辑：首先查看是否是沙盒化服务，如果是调用`SbieDll_StartBoxedService`，向`SbieSvc`进程发送`MSGID_SERVICE_RUN`请求；否则调用`SbieDll_CallServer`函数，向`SbieSvc`进程发送`MSGID_SERVICE_START`请求，启动服务。

// specify WithAdd to add the service to the sandbox

//

SetLastError(ERROR\_SERVICE\_LOGON\_FAILED);
