# 5 总结

这是我分析的第二个病毒样本，还是花了一段时间的。对于自己的分析下来之后做一些总结：

1. 样本在分析时候，尤其是原始样本分析时带出表和代码中的API函数很少，以此怀疑会释放 `shellcode` 或 `PE` 文件；
2. 抓住代码执行流程，不要过于抠细节，知道莫个函数的功能就可；
3. 内存中释放的文件要及时 `dump` 下来。
