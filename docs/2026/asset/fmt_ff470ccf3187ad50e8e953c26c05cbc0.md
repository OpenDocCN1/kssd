## `_int_malloc`

函数原型：

```cpp

_int_malloc (mstate av, size_t bytes)
```

`av` 为线程对应的 arena，`bytes` 为程序实际申请的内存大小。

使用 <a href="elink@82eK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1L8h3W2F1L8%4u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5c8X3u0D9L8$3u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5k6o6u0Q4x3X3f1J5y4#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5k6h3y4Q4x3U0y4x3x3e0t1I4z5b7`.`.">`request2size`</a> 将 `bytes` 参数转换为所需 chunk 的大小 `nb`，chunk 头占用 `0x10` 的空间，剩下的用来存储用户数据。

如果 `av` 是空的，表示还没有可用的 arena，直接调用 <a href="elink@6ccK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1L8h3W2F1L8%4u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5c8X3u0D9L8$3u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5k6o6u0Q4x3X3f1J5y4#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5k6h3y4Q4x3U0y4x3x3U0t1%4x3H3`.`.">`sysmalloc`</a> 申请 `mmap` 映射内存并生成 chunk，此 chunk 会被标记为 <a href="elink@9a0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1L8h3W2F1L8%4u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5c8X3u0D9L8$3u0Q4x3V1j5J5x3K6p5#2z5r3t1H3z5r3p5H3z5e0l9^5k6U0x3^5x3e0b7#2z5h3j5J5y4K6y4S2z5e0R3@1j5K6k6X3k6o6x3J5z5o6x3$3x3$3y4T1i4K6u0r3L8h3q4D9L8r3!0U0i4K6u0r3L8h3q4D9L8r3!0U0i4K6u0W2j5#2)9J5x3@1H3I4x3U0f1K6">`IS_MMAPPED`</a>。

如果 arena 可用且 `nb` 大小在 fastbins 范围内，则找到合适大小的 fastbin，取出一个 chunk 后将其他相同大小的 chunk 转移到 tcache 中，达到 tcachebin 上限（7个 chunk）后停止转移。

在 fastbins 中没找到合适的，再判断 `nb` 是 smallbin 范围还是 largebin 范围。

如果在 smallbins 范围，找到合适大小的 smallbin，取出一个 chunk 后将其他相同大小的 chunk 转移到 tcache 中，达到 tcachebin 上限（7个 chunk）后停止转移。

如果在 largebins 范围则调用 <a href="elink@bf0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6T1L8h3W2F1L8%4u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5c8X3u0D9L8$3u0Q4x3V1k6Y4L8r3W2T1j5#2)9J5k6o6u0Q4x3X3f1J5y4#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5c8X3#2S2L8r3I4G2j5#2)9J5k6h3y4Q4x3U0y4x3y4o6b7H3x3R3`.`.">`malloc_consolidate`</a> 合并 fastbins 中的 chunk 避免免空间碎片化。
