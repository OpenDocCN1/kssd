
# 破解总结

## 算法总结

注册算法主要采用置换的方法

用户名以`tianxj`为例

1. 取用户名第1位`"t"`，转成大写`"T"`，对应第1个置换表的`"84"`
2. 取用户名右边第1位`"j"`，转成大写`"J"`，对应第2个置换表的`"2"`
3. 取用户名第2位`"i"`，转成大写`"I"`，对应第3个置换表的`"T3R"`
4. 取用户名第4位`"n"`，转成大写`"N"`，对应第4个置换表的`"414"`
5. 将上面所得到的4个字符串相连为`"842T3R414"`
6. 根据相连字符串`"842T3R414"`的第3个字符`"2"`，对应第5个置换表的`"4TGFDERN"`
7. 将相连字符串`"842T3R414"`再与`"84"`、`"414"`、`"2"`、`"414"`相连，得到字符串`"842T3R414844142414"`
8. 取`"842T3R414844142414"`的第4、2、7位相连得`"T44"`
9. 取`"842T3R414"`的第4位`"T"`，`"4TGFDERN"`的第2位`"T"`，`"842T3R414844142414"`的第7位`"4"`相连得`"TT4"`
10. 取`"T44"`的第1位`"T"`，`"TT4"`的第2-3位`"T4"`，`"842T3R414844142414"`的第7-10位`"4"`相连得`"4148"`相连得`"TT44148"`
11. 取`"TT44148"`的第1-4位`"TT44"`，`"842T3R414844142414"`的第1-3位`"842"`相连得`"TT44842"`
12. 在`"TT44842"`之前加上固定字母`"M"`，即得到注册码`"MTT44842"`
