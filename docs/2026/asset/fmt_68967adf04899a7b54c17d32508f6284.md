## 跳转类型

`1F` 是 `jmp` ->`11111`  
`1B` 是 `jne` ->`11011`  
`04` 是 `je` ->`00100`  
`14` 是 `jbe` ->`10100` //这个不太肯定，CF也可以作用，不过它上面是这条指令：`test eax, eax`
