
# 瑞星个人防火墙及瑞星2002杀毒通用破解

瑞星个人防火墙及2002杀毒通用破解。2002仍然没有改掉2001的老毛病，在`setup.dll`上捣鬼。

## 1. 瑞星个人防火墙

下载地址：http://211.101.232.6/pcver/UpdatePad\_wnxio01sdghgyrising/rfw.exe

`rfw.exe`用`winrar`等解压缩软件解开，研究`setup.dll`。

脱`setup.dll`的`upx`壳：`upx -d setup.dll`。

用`w32dasm`反汇编`setup.dll`，选“函数”=>“输出”，双击第一项`checkkey`。

修改`eax=1`就不用密钥盘了，下面是改后的：
