## 3.1 avi格式

AVI文件采用RIFF文件格式，这种文件格式的基本单元是块(CHUNK)：

```c
struct chunk {
uint32_t ID; //块标识符
uint32_t Size; //块数据大小
uint8_t Data[Size]; //块数据
};
```

## 3.2 cvid压缩格式

*以下格式的理解参考[cinepak文档](elink@68bK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6E0N6h3I4@1K9h3#2W2k6r3W2S2i4K6u0W2j5%4S2Q4x3V1k6E0K9i4u0J5L8%4u0Q4x3V1k6U0K9h3&6W2M7r3q4C8i4K6u0W2N6s2S2@1)，可能有错误，与《漏洞战争》中的分析也有不同，后面调试的时候会尝试进行验证。*

根据[文档](elink@995K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6E0N6h3I4@1K9h3#2W2k6r3W2S2i4K6u0W2j5%4S2Q4x3V1k6E0K9i4u0J5L8%4u0Q4x3V1k6U0K9h3&6W2M7r3q4C8i4K6u0W2N6s2S2@1)，Cinepak视频流通常由如下几个部分组成：

