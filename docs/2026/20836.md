# [原创]读《哪来的天才》有感

读《哪来的天才》有感

　　推荐一本好书，《哪来的天才》。现在的励志书很多，告诉大家“要努力，努力就会成功，不要放弃”什么的，一点意思都没有。这本书不同。它讲了一些我们未注意到的方面。
        ＊高成就并不需要天才。
        ＊即使是一些比如下棋等大家公认需要天才的领域，一般人通过努力也能达到高成就
        ＊很多大家以为的天才，其实只是很努力的普通人。
        ＊高成就是“刻意训练”的结果。
　　引用书中的一个例子。波尔加三姐妹的故事。一个匈牙利人 Polgar 在20世纪60年代提出来“伟大人物是后天培育而非天生”的观点。他为此写了一本书《造就天才》，并公开寻找愿意与他结婚生子的女士，以便能协助他一起完成这个实验。结果居然真的有一位来自乌克兰的女教师肯嫁给他。后来他们有了一个女儿，在女儿四岁的时候开始教她国际象棋。后来他们又生了两个女儿，三个女儿都学国际象棋。“家里堆了上万本国际象棋书籍”，“她们每天几个小时几个小时地练习”。后来，“当苏珊19岁，索菲亚14岁，朱迪12岁时，她们组队参加了女子奥林匹克国际象棋赛并打败了前苏联队，赢得了匈牙利历史上第一次胜利而成为国家英雄”后来她们都成为了国际象棋大师。
　　既然下棋都不需要天才，做程序员就更不需要了。一下子转变了我多年的一个观念：程序员一定要够聪明。我现在明白，其实只要不是太傻，肯努力，普通人也可以成为一名好的程序员。
　　书中讲到，“多年的经验”常常没有什么用处。要“刻意训练”。如果不用心，多年的经验只是多次的重复。
　　通过读这本书，我明白了很多道理。有些行业，比如音乐和体操，是可以从小训练的。比如５岁就可以开始了。如果你现在１５岁了，就不要再想成为音乐家或体操运动员了。因为你已经比有些人落后１０年了。你觉得你还年轻，其实因为你父母的原因，已经有很多机会与你无缘了。有多道门，已经对你永远地关闭了。
　　有些行业，则不可能很早入门。比如金融。不可能有人训练一个５岁的孩子去搞金融。你３０岁开始研究金融，一点也不晚。你的人生经历会对你的专业有帮助。
　　书中讲到，在很多行业，如象棋、数学、音乐、游泳、网球、文学等，没有１０年艰苦努力，是无法出类拔萃的。
　　我也有我自己的思考。以下内容超出了这书。
　　那三姐妹为什么选象棋？为什么不选唱歌呢？我想很大程度上是因为，象棋容易分胜负，而唱得好不好，一般人听不出来。当外行要想在一个领域取得高成就，最好选一个能胜负立判的方向。很多家长让孩子练音乐，自己又不懂。即使他唱得再好，或弹得再好，能上CCTV吗？难。
　　再举一个极端的例子，电影演员。做一个好的电影演员显然不需要10年苦练。甚至有很多例子，随意抓来的没经过任何演艺教育的孩子，就可以演得很好，成为明星。于是，在电影演员这个领域，出现了一个很奇怪的现象。一方面，成功不需要苦练。另一方面，一旦成功，有名有利。赚很多钱，世界闻名，比其它行业的成功人士赚多了。既然当演员这么好，为什么不大家都当演员呢？这里有个问题。即使你长得再漂亮，演得再好，导演不用你，你也上不了银幕。所以，这个行业，要成功不需要苦练，只需要导演！
　　所以，成龙的儿子当要演员，我不怀疑他会成功。潘长江的女儿要唱歌，我不怀疑她会成功。那些没有名人爸爸的，想进这个圈子，那可难了。怪不得很多美女想睡导演都要排队。

　　再回到程序员。程序员这个职业，对年轻人来说，还是不错的。做得好的，工资上万也不是难事。办公环境也不错，风吹不着雨淋不着。而且一个聪明的孩子，只要学习两三年就可以上岗了，相比其它行业的十年苦练算是好的了。
　　要当程序员，也需要一个锻炼的过程。单纯看书，为了学习而学习是不行的。年轻人需要有人给机会锻炼学习，而ＩＴ公司却往往不想花时间培养人，只想找有经验的。这是个矛盾。
　　很幸运我现在达到了一个可以给别人机会的位置。招一批新人，指导他们，培训成才。在给别人机会的同时，自己也达到极大的满足。我甚至羡慕他们，当初我都没有这种机会。
　　不过比导演还是差太远了。都是男的，培养还要倒贴钱发工资。
