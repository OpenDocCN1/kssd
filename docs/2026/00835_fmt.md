
# [原创]调试服务方法整理

方法：

1. 增加服务启动超时时间

    ```
    [HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control]        ServicesPipeTimeout                60*60*24*1000=86400000
    ```

    重启系统，使之生效。

2. 修改文件：`EP`设置无限循环

    `EP`修改后的二机制：`0xEB 0xFE`(`JMP` 目前指令）

3. 启动服务，附加至调试器

4. 修改进程，删除无限循环(恢复`EP`指令)

5. 调试分析
