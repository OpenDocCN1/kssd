## ida
好几年前，工具没有那么丰富，只用ida进行慢速的trace来分析算法。速度非常慢，曾经分析某个vmp算法，trace了大半个月。
使用方法可以看我的课程 [https://www.kanxue.com/book-53-900.htm](https://www.kanxue.com/book-53-900.htm)
## unidbg
<a href="elink@9e1K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6\*7K9r3E0D9x3o6t1J5z5q4)9J5c8Y4g2F1K9h3c8T1k6H3`.`.">unidbg</a> 出来后，大大的提升了分析算法的速度。trace速度比ida trace快了非常多。
在unidbg的测试用例中，先补全环境，然后调用算法函数前加一下三行代码，即可开启trace
```
emulator.traceRead();
emulator.traceWrite();
emulator.traceCode();
```
