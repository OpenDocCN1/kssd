# [原创]分析运行过的反汇编代码

## 先总结
一、 阅读一个函数的反汇编代码，我将其归纳为四个角度:
1. 局部变量的走向.
以变量为线索，串起所有对该变量进行读写的操作。相关的业务功能被串起后，以此为上下文推测变量的实际功能。
2. 参数或成员变量的读写
a. 一般函数的输入参数，是该函数承接上下文的重要数据。
b. 类对象的成员变量，其实也可以理解为参数，观察成员变量的读写，可以猜测该对象在内存中受不同上下文作用后的状态。
3. 未知的函数调用
对于非本模块的第三放导入表函数，就只能观察其输入和输出了。输出不一定是某种返回值，也可能是系统的全局参数，又或者是某个元器件的功能表现，比如输出控制的是一个IO开关。
4. 调试监视内存变化
一般同一对象，或者关系紧密的对象，大概率是分配在同一块内存的，尤其是栈内存。即使是堆内存，如果是其含义又相关性，其引用一般也是存放在一起的。所以即使堆地址是离散的，但是通过回溯其基址，很大概率是同一个基址偏移可以得到的。
