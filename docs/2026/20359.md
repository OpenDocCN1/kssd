## bof

os： kali 64 &&win7 64

 toos：gdb—peda插件  ida64 登陆pwbalble.kr 打开`bof` 根据英文提示：

> Nana told me that buffer overflow is one of the most common software vulnerability.  Is that true?

根据提示可获得信息：此题可能跟缓冲区溢出有关：

 此时进行查看源代码获取更多信息：`bof.c`

```c
#include <stdio.h>  

#include <string.h>  

#include <stdlib.h>  

void func(int key){  

    char overflowme[32];  

    printf("overflow me : ");  

    gets(overflowme);   // smash me!  

    if(key == 0xcafebabe){  

        system("/bin/sh");  

    }  

    else{  

        printf("Nah..\n");  

    }  

}  

int main(int argc, char* argv[]){  

    func(0xdeadbeef);  

    return 0;  

}
```

### 从`bof.c`中可以提取到的知识点

1. `main()`函数调用`func()`函数传递参数`0xdeadbeef`
2. `func()`函数中包含对数组`overflowme[]`数组的输入，接下来就是`if(key == 0xcafebabe)`判断是否读取flag文件
3. 由此根据英文提示可以进行猜测就是，利用`overflowme[]`的溢出输入进行覆盖`key`的值为`0xcafebabe`进行正确的`if`判断读取flag文件

### 计算需要覆盖的字节数

由此我们可以进行比较出来：`a1`的地址为`[ebp+8]`，`s`的首地址是`[ebp - 0x2c]`

因此`0x8 + 0x2c = 0x34 = 52d`，因为栈区是从高向低生长的，所以此时想覆盖掉`key`的值为`0xcafebabe`就需要先进行覆盖前面的52个字节。下面通过调试`bof`文件进行验证此想法。

### 分析方法二
