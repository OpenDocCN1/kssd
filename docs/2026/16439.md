# Linux内核Makefile执行流程

## 1. 必备知识
### 1.1. Makefile基础语法
&emsp;&emsp;如果还不熟悉Makefile语法，建议先系统的学习一下，特别是以下几点：
&emsp;&emsp;(1) Makefile哪些部分包含的是shell语句：
&emsp;&emsp;&emsp;编译规则中的指令部分
&emsp;&emsp;&emsp;${shell XX}，var != XX中的XX部分
&emsp;&emsp;&emsp;$(if …, XX, XX)中的XX部分
&emsp;&emsp;(2) 变量展开：
&emsp;&emsp;&emsp;=（延迟赋值）、:=（立即赋值）、!=（值为shell命令）、?=（条件赋值）、+=（追加）
&emsp;&emsp;(3) include：将指定的其它Makefile内容，展开到当前Makefile
&emsp;&emsp;&emsp;-f/-C：嵌套执行指定（目录中的）Makefile
&emsp;&emsp;&emsp;执行一个Makefile，并不是从第一行开始执行，而是从指定或默认的编译目标开始执行（位置目标编译规则之前的赋值语句，只在相应变量需要被使用时才会执行），其中，Makefile（包括include内容）中的第一个目标，为默认目标，如果make命令行中没有指定编译目标，则执行默认目标。
&emsp;&emsp;(4) 自动推导依赖文件
&emsp;&emsp;(5) 根据文件时间戳、中间文件（.d、.cmd），判断依赖更新，决定是否需要重新编译
&emsp;&emsp;(6) 重要的内置函数：
&emsp;&emsp;&emsp;$(wildcard pattern)
&emsp;&emsp;&emsp;$(patsubst pattern, replacement, text)
&emsp;&emsp;&emsp;$(strip string)
&emsp;&emsp;&emsp;$(filter pattern, text)
&emsp;&emsp;&emsp;$(filter-out pattern, text)
&emsp;&emsp;&emsp;$(call func, args..)
&emsp;&emsp;&emsp;…
&emsp;&emsp;(7) 自动推导变量：
&emsp;&emsp;&emsp;$@：编译目标
&emsp;&emsp;&emsp;$<：依赖列表中的第一个依赖对象
&emsp;&emsp;&emsp;$^：依赖列表中的所有对象
&emsp;&emsp;&emsp;$?：依赖文件列表中所有有更新的文件

### 1.2. Kbuild内置函数
&emsp;&emsp;Linux内核源码包含一套Makefile程序，本文基于Linux-5.2.5内核源码分析，其中包括top Makefile，scripts/目录下的Makefile、Makefile.build、Makefile.lib、Kbuild.include、Makefile.modpost、kconfig/Makefile等,以及其它目录下的很多子Makefile，统称为Kbuild。Kbuild是按照框架设计思路实现的，使得内核自身包含或外部提供的大量驱动模块，只需要按照Kbuild框架的约定，各自提供一个简单的Makefile即可编译。
&emsp;&emsp;所以，理解内核或驱动文件的编译过程，其实就是要理解Kbuild这套Makefile程序的实现逻辑，既然是程序，就免不了会定义一些函数，由于很多关键的流程，都使用了$(build)和$(if\_changed)，所以以下先单独介绍（本文分析的Makefile内容，来自Linux-5.2.5内核源码）：
