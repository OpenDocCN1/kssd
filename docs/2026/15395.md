# [原创] JEB2插件，导出APK资源文件

JEB2没有直接提供导出APK内资源文件（AndroidManifests.xml、各种resources等）的功能。

因此实现了一个JEB的插件，可以导出资源文件。一个挺简单的小python脚本，需要的看看 :-)
