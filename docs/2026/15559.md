## 4. 注册机思路

我们这里梳理下流程逻辑和思路

### 1. 逻辑流程

> `s[]` <-- 用户名`name`
> 
> `v15[]` <-- 密码`pwd`
> 
> `v12[]` <-- `s[]`
> 
> `v13[]` <-- `v15[]`
> 
> `v13[]` <-- `v12[]`

1. 我们的注册机是已知`name`求`pwd`

# 3. 注册机

![图片描述](upload/attach/201904/768906\_NPC6Z8M9R4MZ6CW.png)

## 1. 流程

写注册机前再梳理一遍

1. `name`得到一个数组`s[]`，可以由ida得到

```cpp
do
{
v6 = (char \*)s + v5;
v7 = v11[v5 % v3] \* (v5 + 20160126) \* v3;
++v5;
\*(\_DWORD \*)v6 += v7;
}
```

2. 由`s[]`可以得到`v12[]`

3. `v12[]`可以得到`v13[]`

> `v13[0]=2*v12[2]+v12[3]`
> 
> `v13[1] <= 3 * v12[2]-v12[4]`
> 
> `v13[2]=2*v12[0]+v12[1]`
> 
> `v13[3]=v12[2] + v12[3]`
> 
> `v13[4]=v12[0]+v12[1]`

4. `v13[]`得到`v15[]`

5. `v15[]`通过`encodebase64`得到密码
