# [旧帖][原创]初遇看雪，相见恨晚，勤奋执着，十年一剑0.00雪花

重剑无锋，大巧不工，20岁前持之横行天下。20岁后草木竹石，皆可为剑。
  一年前，仰慕安全界牛人，希望某一天自己也可以做到。
  大一辍学，一个人北上漂泊，北京的冬天很冷，我的房子没有暖气。
  现在坐在北京某信息安全公司的研发办公室里，一个低调的我，在别人的眼里那样的卑微和不值得一提，初遇看雪，回忆着一年来自己付出和变化，我流下了泪水。
  我的表达不好，朴实的文字实在表达不出此时此刻的心情，一切都是那样的巧合，我的学习历程和看雪上的学习过程惊人的相似，和riijj一样。
  初遇看雪，相见恨晚。沉浸在看雪论坛，心静了下来，前方道路的尽头是甚么也许我们都不知道，但是与世无争的心态更加坚定了我的信念：一万年太久，只争朝夕。身边的事情对我来说已经不在重要，也许已经与我无关，从身边的同事身上看到了什么叫生活，什么叫被生活磨平了棱角，我想这不是我想要的。
  生活的波折锻炼了我吃苦的精神，无数次的打击磨练了我的意志，我悟性敏锐，执着吃苦，看雪为我提供了知识的源泉。抱十年一剑的态度，三年后，一试锋芒。

                                             与看雪初学者共勉之
                                                         泽天
