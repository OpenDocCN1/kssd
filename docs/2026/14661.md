
# [原创] TrafficStats 去图片去限制

**标 题**: 【原创】TrafficStats 去图片去限制  
**作 者**: arsusanh  
**时 间**: 2012-11-24, 18:50  

声明：本文章仅做技术研究，请勿用于非法用途。

这个看流量的软件还是不错，没有怪怪的让人不爽的权限，而且很小，比我 `4.04` 自带的好些，但是有广告，而且有限制，这个很不爽，但是作者不错，这个广告也就是点击图片，提示你去市场下载而已，软件本身没有后台流量，图就不截了。

有两个目的：

1. 去掉图片
2. 去掉限制

---

## 一、去掉图片

反编译 APK，进入`\res\layout`目录，查看`main.xml`文件，搜索 `ad`，直接把后面 2 个值固定为 `0px`。

## 二、去掉限制

解压出`classes.dex`，并转化成 JAVA 源码（提示使用全功能版本对话框的文字在 JAVA 源码里面，smali 没有），搜索该文件夹下所有包含 `full` 的文件，查看`Graph.java`文件：

```

{
    super.onResume();
    android.app.AlertDialog.Builder builder = new android.app.AlertDialog.Builder(this);
    android.app.AlertDialog.Builder builder1 = builder.setTitle("Full version only").setIcon(0x108009b).setMessage("Sorry, Traffic Graph is available only in full version.\nPlease, buy it in Android Market.");
```

这个就是提示叫你去市场购买的对话框，定义了个`onResume()`，就从这个入手，搜索 smali 文件夹下所有包含 `onResume` 的文件，然后删除这个函数，记得有好几个文件都有，最后重建 APK 就可以了。
