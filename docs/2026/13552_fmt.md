
# [原创][分享]PC样本"勒索软件分析"

这是一款比较简单的PC勒索病毒,当然样本时间应该也比较久远了.

简单样本,简单分析,最后提供一个手动查杀的小方案吧,大牛略过→\_→

## 一．病毒概况

病毒名称：`华夏联盟.exe`

软件图标:![](https://bbs.kanxue.com/upload/attach/201703/711707_a77tficl1ykaybc.png)

所属家族：W32.Malware.Blackmail

文件大小: 1536 byte

编译时间: 2013-11-11 12:09:38

MD5值: 0b1972462ec0041bf9711561ca1a1b45

SHA1值: 700b448e07738cb82937983ca86c61a82f4e060d

CRC32： 5bad5d4c

病毒行为:

1. 添加管理员权限
2. 添加新用户
3. 修改用户密码
4. 关机重启
5. 主机迹象:无
6. 网络迹象:无

病毒目的:

1. 添加,锁定受害人主机 留下联系方式勒索用户

## 二．具体行为分析

获取本机用户名

![](https://bbs.kanxue.com/upload/attach/201703/711707_61cypgquagif8vm.png)

根据获取到的用户名拼接字符串

![](https://bbs.kanxue.com/upload/attach/201703/711707_qv9ygdvl15tr421.png)

以隐藏方式运行`cmd`,为当前用户添加登录密码

![](https://bbs.kanxue.com/upload/attach/201703/711707_vi4v27q76pqbzuk.png)

为管理员账号追加密码:107289

![](https://bbs.kanxue.com/upload/attach/201703/711707_bqmhyhyog07u002.png)

添加新用户,密码

![](https://bbs.kanxue.com/upload/attach/201703/711707_9dhst7l96uduhv3.png)

将新添加的用户,追加到administrator

![](https://bbs.kanxue.com/upload/attach/201703/711707_6viv9pvd1tavlcp.png)

处理完以上事情后就该关闭用户机器,等待重启然后锁定主机勒索用户了

![](https://bbs.kanxue.com/upload/attach/201703/711707_ik1p8zskq8fud2u.png)

## 三．解决方案

提取病毒特征码:

![](https://bbs.kanxue.com/upload/attach/201703/711707_wh63eksnd7r498z.png)

手工查杀思路:

1. 使用分析得出的锁机密码(107289),登录任一帐号
2. 在控制面板->用户帐号->管理帐号 中清除被锁定用户的密码,并且删除恶意添加的用户帐号
