### 脱壳
这个方法应该能脱掉近2年的所有乐固壳
hook libc的strstr
```C
int new\_strstr(char \*str1, char \*str2) {
if (strcmp("xposed", str2) == 0) {
return 1;
}
return old\_strstr(str1, str2);
}
```
然后再hook libart的DefineClassNative对dex进行整体dump.
这种情况，dump出的dex全部是完整的。
