# [原创]wak的成长

转眼已经是快24的人了,回头看看自己走过来的路,心中有说不出的感慨,写此
文章算是给曾经帮助过我,给过我鼓励的人说声谢谢了,也希望此文对于那些对
IT感兴趣但对将来有迷惑的朋友们有点用.

在我高中的时候,只有学校机房有计算机,虽然每周有微机课,但大部分是被别的
课占用.偶尔能去机房,也是望着电脑发呆,好玩的是扑克牌游戏,还有就是dos
界面的字母输入.那时感觉计算机是个神奇的东西.我只知道我喜欢...
所以,在我报考大学自愿的时候,我所报的第一专业都是计算机专业.然而,可以说是
"命运不济",虽然高考考得不错,但是在我所报考的那所学校,我还是没能达到计算
机专业的分数线.只好被调剂到一个飞机方面的专业.但是:我对计算机仍然是非常
非常的喜爱!...

也许是大学时时间非常的空,也许是对自己专业的非常不喜欢,也许是我始终放不下
那种敲键盘的感觉...呵呵. 大一的时候,我们没玩过计算机的人学的是C, 懂点的学
的是C++, 一个学期下来,感觉什么都懂,但考试成绩又不是很好.大大体上感觉会了点
编程语言了,现在想想那时候的学的跟以后的金工实习时学的数控编程差不多,会皮毛
而已,但有成就感,也正因为有了这么一点微妙的感觉,才促使我常常使用Trub c编两个
存取文件的小程序.学完了C,不知道该干什么了.学校没别的课安排,但对学C++的,
好像有个晚上上的辅导课,偷偷过去听了一节课,汗啊,那时感觉真的是在做贼啊.也就
是那次,我第一次听说了MFC,但听了半天一点不懂.我是那种对自己不知道的东西有强
烈的求知欲的人.第二天我去图书馆借回了七本关于MFC的书,为什么是七本,因为我们
学校规定本科生只可以借七本,呵呵.那时看书很快的,不过说实话,我可能真的在计算
机方面有点天赋,一看就懂,也许是喜欢它的原因吧.想想也真是的,一个人如果不喜欢
做某件事情,那他因该不会把这件事情做得很好,后来很多事情都验证了这一点,昨天
msn上一个偶像的个人签名就是:做自己想做的事情!也就是那时我又体会到了MFC的强
大,以及很多有趣的东西,抽象的,面向对象的,以及一些杂七杂八的东东.那时我很喜欢
看书,看编程方面的书,时常编一些小程序,看了网络编程方面的书就写个Socket聊天等
的小程序,看了数据库的书就写个操作access数据库的程序.总之那时候没有目标,借到
什么书看什么.自己也不知道该学什么.大二的时候我们有一门选修课叫数据结构,在那
时我终于对链啊,栈的印象深刻了.但也被一些算法问题搞得头大了(呵呵,不要怕,只要
学会stl,这些复杂的东西不要考虑啦),甚至让我感觉到原来这才是搞计算机的呀,难啊,
是不是非要去计算机专业学习才可能学好呢?有点泄气.

现在想想那时候是我最迷茫的时候,人生嘛,难免有低落的时候,有想不开的时候,也许过
了那段时期就好了.是这样的.没过多久我对木马感兴趣了.为什么呢?一个人做事情总是
有原因的呀,呵呵,而那次的原因我都不好意思说,是因为我们那边别的班上的人电脑里
面有很多电影,租碟好贵的哦,为什么不跟我共享?老借不好意思啊.于是写了个远程列举
文件和传输文件的程序,亲自放到别人的电脑里运行了一下,呵呵,效果还不错,能在我机
器上看到他的文件,但传回来时老把人家的电脑搞得不能动^\_^.现在想想那时编的什么
玩意啊,不过:有意思.

曾经我考虑过如果我可以进入计算机行业,我做什么方面的呢?看了半天,我感觉开发3D
游戏很有前途,于是苦学了几个月的DX,自己编了个手枪打鱼的2D小游戏,当开始写3D程序
的时候发现:谁来给我做3D的实物模型呢?我艺术细胞不好啊,很泄气,后来终于放弃了...

每一次学一个东西,都是很累人的,那时我们学校宿舍不让联网,很多资料要到机房去上网
查,而每次到机房都是要排很长的队.还有就是心疼的钱啊,不过有个好处就是,学这些东西
很多都是英文的资料,如果看多了对你将来的阅读文献的能力是个很大的提高.

2006年7月毕业后,我在上海找了份工作,在虹桥机场做机务.因为对工作的不喜欢,偶然的机会
跟kanxue说了一下想法.想找份计算机相关工作,由于自己不是计算机专业,心里还是很虚.
kanxue说我两篇精华文章就是资本,己证明有这方面能力.经过kanxue介绍,我成功进入IT
行业的第一家公司,公司老板是TRW2000的作者刘涛涛,一时我晕了.运气太好了,同时不知
道的是别人能看上你吗?呵呵.跟着刘涛涛,你会学到很多很多的东西.这里举个例子,也算是
我对他的感谢吧.我们两个人逆一个软件,他分析,我写代码.最后调试时,有个地方我老调不过去.
折腾了几天.是这样的,有个驱动里的函数里面很复杂,传进去的数据和原来的程序都是一
样的,就是返回不对,而且是第一次对,第二次错,晕的,我真是不想跟进去,代码没错,汇编
已经看了好多遍了,检查过没错.我说我实在不行了,他说他来,我坐旁边看.他把两个程序
同时调试,比较每次修改的内存的值,那里面还有个md5的运算,每一轮的值都进行了比较.终
于找到了bug,原来一个结构大小定义错了(已知域填好了,未知的要占位,给忘了).搞计算
机的一个字节不对程序都不会正常的跑起来,刘涛涛是个很优秀的程序员,也是一个很执
着,很认真的,很细心的人.从那次我学会了耐心,学会了要心细.呵呵,同时,他还是个很会
赚钱的老板,想学的跟着他吧^\_^.在那里,我还认识张玉林,他是我们公司的军师,技术很好,
人也很不错,写过虚拟机,在工作中给了我很多的帮助.还有就是技术很牛的doskey了,用他
的名言我想说:你是个好人,dos!赶快结婚吧(他的心愿)...
