=======================分割================================
又想到了一个办法：

```
for (int i = 0; i < wcslen(_Text); i++)
		_Text[i] -=10 ;
```


把\_TEXT中的数据挨个加或减固定的数，这样中文字符的话就会变成乱码，在VS调试的时候把这些乱码保存下来，然后赋给字符串作初值，这样就算OD或IDA查到字符串，那么也是乱码。

```
WCHAR _Text[100] = L"砾觭旃泟Ｄ\x14;》叅陮朶xkq窡叭\x14<》侉寐砋辝兯桐叢乄叹甲\x14=》抈刄管泟";
```


用到的时候在把它还原，用完了再给他加或减固定的数。

```
for (int i = 0; i < wcslen(_Text); i++)
		_Text[i] -=10 ;
	for (int i = 0; i < wcslen(_Caption); i++)
		_Caption[i] += 10;
	MessageBox(_Text, _Caption);
	for (int i = 0; i < wcslen(_Caption); i++)
		_Caption[i] -= 10;
	for (int i = 0; i < wcslen(_Text); i++)
		_Text[i] += 10;
```
