## 2. 先安装 postgresql-10.20-1-windows-x64.exe，设置数据库端口、密码等信息

`username:postgres`

`password:sa`

`port:5432`

运行 PostgreSQL 10 的 SQL Shell (`psql`)，将 `schema.sql` 复制到 D 盘，导入 `schema.sql`，初始化数据库。

![](https://bbs.kanxue.com/upload/attach/202203/87758_ZRF3B4ESGSNBPUU.png)

![](https://bbs.kanxue.com/upload/attach/202203/87758_G8MC4Q2FNWCDXJB.png)

### 注意：导入 sql 文件的路径用 `/`，不是 `\`。

![](https://bbs.kanxue.com/upload/attach/202203/87758_UQCGHEY349NVNNP.png)

## 3. 解压 `lumen-v0.1.0-x86_64-pc-windows-gnu.zip` 到任意目录，修改 `config-example.toml` 中数据库连接信息，填入正确的数据库端口号 `5432` 和数据库密码

![](https://bbs.kanxue.com/upload/attach/202203/87758_U9USDYA795FNZ4N.png)

## 4. 修改 IDA 的 `ida.cfg`，填入 lumen 服务器信息，lumen 端口 `1234` 在上面 `config-example.toml` 中配置的

![](https://bbs.kanxue.com/upload/attach/202203/87758_VY459TA233TAKBY.png)

## 5. 运行 lumen 服务器，可创建一个批处理来运行

启动 `lumen.cmd`：

```
@echo off
lumen -c config-example.toml
```

## 6. 运行 IDA，开始分析程序，通过菜单 lumen 提交签名或者检出签名

![](https://bbs.kanxue.com/upload/attach/202203/87758_S54NR74HR7BHSDY.png)

配合 PostgreSQL 10 的 pgAdmin 查看数据库存放了啥数据。
