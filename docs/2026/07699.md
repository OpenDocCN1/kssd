# [原创]对目标程序自带DLL输出表加密[开源]

初学C++用MFC写的第一个小程序,源码写的可能不太好看,有什么地方写的不好,请一定要指出,在此感谢帮助过我的朋友![](https://bbs.kanxue.com/view/img/face/41.gif)

程序虽然比较简单,不过第一次用C++写程序,也花了不少时间,支持下哈![](https://bbs.kanxue.com/view/img/face/41.gif)

本程序是单向加密,如果你加密的目标程序中,有一个DLL调用另一个DLL,或者有另一个应用程序调用某DLL,本程序加密后必定会导致另一程序无法载入DLL函数!所以在加密前要确认,你的DLL只被该目标程序调用!
