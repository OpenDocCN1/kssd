# 『深圳腾讯2010安全技术竞赛』（第二阶段将在 2010-10-28 12:00开始）

**赛事目的**

1. 增进安全领域交流，活跃论坛气氛；

2. 发掘优秀的软件安全人才，并给予鼓励和嘉奖。

**赛事时间**：10月18日至11月18日

**赛事地点**：看雪软件安全论坛线上举办

**主办单位**：腾讯公司

**协办单位**：看雪软件安全论坛

**参赛资格**

所有在看雪论坛注册的有效ID号（包括临时用户）均可以参加此次比赛，但以下人员不得参加此次比赛：

1. 所有腾讯公司的工作人员

2. 此次比赛评判委员会成员

**注意事项**

1. 禁止同一人用两个或两个以上会员ID参与此次比赛，一经发现，立即取消其参赛资格，并ban掉相关ID。

2. 比赛结束前，请勿在论坛、QQ群或其他公共场所讨论试题相关信息，否则取消参赛资格，并ban掉相关ID。

3. 如发现有抄袭行为，抄袭与被抄袭者均视为作弊，取消参赛资格并ban掉相关ID。

**报名方式**

本赛事无须报名，只要拥有看雪论坛有效ID（包括临时用户），就可以参加第一阶段的比赛。比赛只以单人形式参与，不接收团队形式报名。

**比赛形式**

本赛事分三个阶段，采用分阶段淘汰的方式，选择出优胜者。

第一阶段比赛

调试逆向相关的题目。大致范围：PE文件格式；逆向分析；漏洞分析等。

本阶段共四道题目，每题计分，每题的计分方法，将在题目放出时公布。

第二阶段比赛

编程相关题目。大致范围：驱动相关功能设计；算法题目解答；虚拟机相关功能设计等。

本阶段共二道题目，每题计分，每题的计分方法，将在题目放出时公布。

第三阶段比赛

综合性的题目。

注意：所有题目以最终公布的为准。

**评分标准**

1. 此次比赛为分阶段淘汰赛，采用分阶段淘汰的方式，选出最终优胜者。

   每阶段根据选手得到分数，选出若干名优胜者进入下一轮。若有比分相同者，则上一轮所得分数较高者胜出；若还无法确定，大赛组委会可能酌情增加附加题或再次评审同分答

   案，最终确定优胜者；

2. 题目可能存在多种不同解法，答出多种解法者，根据答案优劣，酌情加分；

3. 如题目挑战失败，但提供了解题思路及分析过程，也可酌情得分。
