前言

我为了方便逆向分析自定义了一个ROM，下面是自定义ROM过程中写的技术分享文章。

目前我自定义的ROM有以下功能：

●
[\*]记录特定应用特定方法所执行过的指令
[\*]获得方法的调用堆栈
[\*]进行方法的执行跟踪
[\*]APK安装时不校验签名

上面的功能均可控（即：功能开启和关闭、指定特定应用和特定方法）。

随着我给自定义ROM添加新特性，可能会有新的技术文章，本帖会持续更新。

未来展望：


[\*]想把qemu user mode移植到Android上，这样就可以记录和跟踪本地程序的执行。
[\*]全方位监控应用行为。



我的自定义ROM不会放出，因为放出以后就会有对应的检测办法，有想自定义ROM的朋友可以参考下面的文章自行修改ROM。
