通过分析，发现 `set` 方法是没有调用的，第一反应就是通过反射赋值的？

![](https://bbs.kanxue.com/upload/attach/202004/880781_Z98PMSUUGKNA7PR.jpg)

原来如此，查看了一下 `JsonTools` 源码，它的主要作用就是把 `JsonElement` 对象转成 `class` 对象，但是 JSON 数据和 `class` 成员必须要一一对应。

查看一下此方法调用情况。（如果本地所有有关数据的对象都是通过这类方法来的，那么数据就是直接从服务器上下发到客户端，然后直接转成了对象。这样前面不会去走给对象赋值的方法也就说得通了。）

![](https://bbs.kanxue.com/upload/attach/202004/880781_36FWHXA2U9MVAFG.jpg)

还挺多，那就简单了，直接勾住它，查看本地有哪些对象实例化了。

![](https://bbs.kanxue.com/upload/attach/202004/880781_7Y28TBX7N7SPKQR.jpg)

通过逐一分析，找到了嫌疑很大的类：

![](https://bbs.kanxue.com/upload/attach/202004/880781_DYP8T6DYHQV4TMA.jpg)

![](https://bbs.kanxue.com/upload/attach/202004/880781_235V8PZ3326BCHM.jpg)

为什么是它而不是其他类？

- 购买状态如果是 0，没有购买（修改）。
- 是否免费如果是 1，则不是免费（修改）。

```java
if (作品没有购买 && 作品不是免费) {
    //.....
}
```

以上就是原因。

# 胆儿肥而美

我们重打包了一个 App，并取消了它的一些限制，我们还能做些什么？

有人会说，我们还能继续改，加金币，加能力。或许吧。

但是据我所知，一些人是可以让它产生一定收入的，这个就需要胆儿肥了。但是的确是有人正在这样做（反正我是不敢的）。往后本系列就分析这样做需要哪些要求（仅在技术层面），并可能加以实现。

## 1. 广告方式

添加广告接口到重打包的应用，通过千展和点击盈利。

![](https://bbs.kanxue.com/upload/attach/202004/880781_2F6VFTJGS943MQB.jpg)

往往重打包的 APK 已经有广告了，如本 APK 就是 Facebook 的广告。如果需添加自己的广告，最好的方式就是破解对应的广告 SDK，让广告 SDK 认为我是源 APK，还能拿给别人用，爽歪歪。（本 APK 就是使用的这种方式，不过它所破解的 Facebook 广告现在已经无效了，已经不能使用。一些原因，非本系列重点。）

## 2. 内容付费

什么内容可以让我付费观看？反正我也不知道。

用上面的 App 举例，因为已经去除了它本身的限制，或许可以添加一些我们自己定义的玩法。

如：每天免费播放 `n` 次，第 `n` 次开始需要付费才能继续播放。本系列往后就以此为模板，进行相关 App 的分析工作。

总的来说，按目前使用习惯会牵涉以下接口：

1. 两个大厂指定金额收款二维码即时生成。
2. 交易记录的获取。
3. 转账。

以上功能所涉及的 APK 比较特殊，后续的分析也只会列出分析过程，并不会牵涉具体的代码。
