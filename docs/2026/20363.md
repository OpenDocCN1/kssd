# 劫持exit\_hook
exit调用流程如下：
```
exit()->\_\_run\_exit\_handlers->\_dl\_fini->\_\_rtld\_lock\_unlock\_recursive
```
我们劫持```\_\_rtld\_lock\_unlock\_recursive``` 而这个函数是在```\_rtld\_global```结构体中的一个函数。
