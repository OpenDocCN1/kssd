## 5.常见问题

* **链接错误：找不到文件"crt.lib"。如下图所示：**

![](https://bbs.kanxue.com/upload/attach/201308/139470_tpb0p8neydxedzd.png)

此时打开工程属性，设置如下图即可：

![](https://bbs.kanxue.com/upload/attach/201308/139470_ivdhf80jbkc1y56.png)

* **还是链接错误，这次是找不到符号，如下图：**

![](https://bbs.kanxue.com/upload/attach/201308/139470_ozn6dffd121yabz.png)

这个错误很常见，但一不小心就会出错。这个错误主要是因为在C++ Project中使用C Library，C和C++编译出的符号格式是不一样的，在这里只需要在使用`BeaEngine.h`头文件的外面包一个extern "C"即可。如下图：

![](https://bbs.kanxue.com/upload/attach/201308/139470_tfpa09e6p34d4k0.png)

* **以下两个宏，使用的时候要注意，我开发的时候是用的静态库**

```
#define BEA_ENGINE_STATIC   // 指明使用静态Lib库
#define BEA_USE_STDCALL     // 指明使用stdcall调用约定
```

NOTE：以上问题在使用64位`BeaEngine`的时候也会出现，解决方法类似。
