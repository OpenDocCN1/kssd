
# [原创]android木马Phone_spy分析报告

## 一、样本特征

### 1.基本信息

病毒类型：木马

样本长度：328,138 字节

### 2.特征描述

该样本启动后无界面，后台服务运行，监听短信和电话。被控端接收控制端发来的短信指令后，会静音并删除该指令短信，其它短信正常接收，读取其中的配制信息（邮箱地址），根据控制端所发出的指令可发送短信内容和将通话录音通过邮箱发送到该邮箱。危害隐私较大。
