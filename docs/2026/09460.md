过程：
   官方说明限制是有水印广告，ok，我们开始旅程吧
   Load Lassalle.Silverlight.Flow.DLL 在Reflector 使用查找工具：我们就查找 Evaluation
   ![](https://bbs.kanxue.com/upload/attach/200905/38112_54h5yzzfn2h06dd.jpg)

  我们双击找到的值，跟踪到这里：

  ![](https://bbs.kanxue.com/upload/attach/200905/38112_3tbgz8yju6dtz4n.jpg)

  接下来我们要分析这里由哪里CALL

   ![](https://bbs.kanxue.com/upload/attach/200905/38112_twe46pnx29q0moz.jpg)

   我们按照下图一路展开，

   ![](https://bbs.kanxue.com/upload/attach/200905/38112_06lcrrmvs11pj6w.jpg)

   ok，我们只要将下图的License.ᜀ ＝True就ok

    ![](https://bbs.kanxue.com/upload/attach/200905/38112_p20j5er8ajvhiw5.jpg)

   我们怎样修改它，先要修改public key 或去掉命名，这个控件不能使用 “StrongNameRemove” 去掉强命名，我只有2种方法，1，是使用CFF去掉强命名，2，是使用SN提取public key ，再建立一个新public key ，再提取public key ，根据就的public key 的值，使用新key替换它，这里我是用第一种方法，有需要2种方法试验。如果你有更好方法请共享，谢谢。ok，闲话少说。。

【1】先去掉 Lassalle.Silverlight.Flow.DLL 强命名，load dll in CFF
      ![](https://bbs.kanxue.com/upload/attach/200905/38112_i48gcummayddsg7.jpg)

【2】去掉Lassalle.Silverlight.Flow.Layout.dll 自身的命名及对 Lassalle.Silverlight.Flow.DLL 命名引用。

![](https://bbs.kanxue.com/upload/attach/200905/38112_2gx0sxwh6bylnth.jpg)

![](https://bbs.kanxue.com/upload/attach/200905/38112_bc554dvc9iis59k.jpg)

现在我们开始修改代码了；

   记住刚才 的  License.ᜀ ＝True
   我们load  Lassalle.Silverlight.Flow.DLL 到 ildasm，不要忘记选择 “Show Bytes”选项
   找到我们刚才的License.ᜀ 类，如下图，然后双击：
   ![](https://bbs.kanxue.com/upload/attach/200905/38112_i3ebzq8c1j2n5e5.jpg)

   复制RVA
   ![](https://bbs.kanxue.com/upload/attach/200905/38112_kjxilt12iiyek9q.jpg)

  打开CFF转换偏移值
   ![](https://bbs.kanxue.com/upload/attach/200905/38112_bls2mfeowwd9qso.jpg)

  最后将 Lassalle.Silverlight.Flow.DLL 载入 winhex，使用Alt＋G组合键，输入刚才你复制的RVA 偏移值。
   ![](https://bbs.kanxue.com/upload/attach/200905/38112_lxjz21qo5arq86l.jpg)

关键一步，修改 7E 03 00 00 04 = 17 2A 00 00 00
![](https://bbs.kanxue.com/upload/attach/200905/38112_u16ev4yivl9q5tv.jpg)
