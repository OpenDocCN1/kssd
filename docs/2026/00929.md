## 创建段

要在数据库中添加额外地址，请通过如下步骤：`Edit > Segments > Create segment…`操作。

![](https://bbs.kanxue.com/upload/attach/202312/767964_Y97UBJQX85PSP5D.webp)

输入段名、起始/结束地址和可选类别。类通常只是提供信息，但可能会影响[反编译器](https://bbs.kanxue.com/elink@0e8K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2Z5k6i4S2Q4x3X3c8J5j5i4W2K6i4K6u0W2j5$3!0E0i4K6u0r3M7s2u0G2k6s2g2U0N6s2y4Q4x3V1k6V1k6h3y4G2L8i4m8A6L8r3g2J5i4K6u0r3L8h3q4F1N6h3q4D9i4K6u0r3N6s2u0A6j5$3E0K6i4K6u0W2M7$3S2@1L8h3H3`.)的行为。`Use sparse storage option`适用于大部分为空且数据项相对较少的数据段（如 BSS 或 MMIO）。启用该选项后，IDA 将使用针对此类情况优化的存储空间，因此即使新的数据段非常大，IDB 也不会增长太多。

注意：段的结束地址是排他的，即段的最后一个字节的地址为 `end_ea-1`。

段创建后，最好重新[分析数据库](https://bbs.kanxue.com/elink@e33K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5k6i4S2Q4x3X3c8J5j5i4W2K6i4K6u0W2j5$3!0E0i4K6u0r3j5X3I4G2k6#2)9J5c8X3W2Y4L8%4u0Q4x3X3c8@1K9i4m8Q4x3X3c8G2k6W2)9J5k6s2c8Z5k6g2)9J5k6s2N6W2k6h3E0Q4x3X3b7H3z5g2)9J5k6s2u0W2j5h3&6S2L8s2W2K6K9i4y4Q4x3V1j5`.)，以便发现对新可用地址的引用。

## 分割段

如果您指定的地址范围与现有段有部分交叉，IDA 将自动截断该段，为新段腾出空间。例如，假设你有一个从 0 到 `0x80000` 的 ROM 固件段，但后来发现代码区域似乎在 `0x60000` 处结束。若要将最后一部分分割为只读数据，可创建一个边界为 `0x60000` 至 `0x80000` 的新段（如命名为 `.rodata`），ROM 段将自动截断为 `0x60000` 结尾。

## 移动段边界

比方说，在进一步分析二进制文件后，你发现 `.rodata` 实际上应该从 `0x70000` 开始。你可以通过以下步骤快速移动分割点：

1. 导航到新的分割点 (e.g. `0x70000`);
2. Invoke `Edit > Segments > Edit segment` (或使用快捷键 `Alt–S`);
3. 在起始地址（或终止地址，取决于移动的方向）中，在此处输入。
4. 确保“Move adjacent segments” 已启用，然后单击 OK.

![](https://bbs.kanxue.com/upload/attach/202312/767964_TUG649GM8U2PHDT.webp)

由于 IDA 中的大多数数字输入字段都接受[IDC 表达式](https://bbs.kanxue.com/elink@80fK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5k6i4S2Q4x3X3c8J5j5i4W2K6i4K6u0W2j5$3!0E0i4K6u0r3j5X3I4G2k6#2)9J5c8X3W2Y4L8%4u0K6i4K6u0V1N6r3W2H3i4K6u0V1L8$3k6Q4x3X3c8@1K9r3g2Q4x3X3c8%4k6h3g2C8i4K6u0V1x3U0q4Q4x3X3c8U0j5h3I4U0N6h3I4S2N6r3!0J5i4K6u0V1j5h3&6V1i4K6u0V1k6i4S2H3M7X3g2K6M7$3W2G2L8W2)9J5k6r3g2$3j5h3I4#2j5i4c8A6L8$3&6Q4x3X3c8X3k6h3q4@1N6i4u0W2i4K6u0V1K9h3&6Q4x3X3c8A6k6r3q4Q4x3V1j5`.)，此处将转换为当前地址（`0x70000`），因此 `.rodata` 段边界将调整为 `0x70000-0x80000`，相邻 ROM 段扩展为 `0-0x70000`。

## 知识扩展（非原文内容）

`segments`单词解析：

一个"节"或"段"通常是指一个具有特定属性或用途的数据或代码的集合。例如，在某些操作系统中，内存可以被划分为不同的段，每个段用于不同的目的（例如，一个段用于执行程序代码，另一个段用于存储数据等）。在病毒分析中，"segments"可能指的是被病毒恶意利用的计算机资源的部分。
