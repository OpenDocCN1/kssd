
# [原创]Win32 ASM全功能系列注册机模板一个

程序说明：

1. Win32 Asm编程，工程文件Radasm，原版主程序未加壳7K
2. 通过本程序你可以参考：
   - 汇编编程中生成及使用随机长度字符的方法
   - 进度条、组合框、文本框、保存对话框等控件的使用参考
   - 线程的简单使用（主程序消息处理和注册码生成分开两个线程，以保证在配置较低的电脑上程序不会假死）

程序简介：

1. 组合框点选任一软件名，点击`Generate`按钮会调用不同算法生成对应注册码
2. 创建新线程负责进度条、文本框同步，同时保证程序不会假死
3. `Ctrl+Alt+"X"` 结束程序
   - `Ctrl+"P"` 中断注册码生成过程
   - `Ctrl+"S"` 保存文本框内容
   - `Ctrl+"*"` 相当于点击`Generate`按钮
   - `Ctrl+"-"` 清空文本框
