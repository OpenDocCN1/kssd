
# 破解flash32（抓图软件）实站录 (2千字)

## 破解flash32 2.18a

这是一个屏幕抓图软件，比较老了（最新的可能是3.0版）。记得刚用的时候，用了一个月之后，出现了过期提示，我就再也没有办法了，只好删除。但学了这么长的时间的Cracking，今天突然想到了这个软件，把这个软件又找了出来，以试身手。结果一试成功，原来软件的破解竟是如此的容易！

下面我们开始破解吧：

安装软件后，将时间调过后一个月，后出现过期提示！记下提示字符串`"period is finished"`，

然后用`W32dasm`反汇编，查找字符串`"period is finished"`，找到如下：

```
* Referenced by a (U)nconditional or (C)onditional Jump at Address:
|:0040EE27(C)　　<==这个跳转哟！:)
|
* Possible StringData Ref from Data Obj ->"The evaluation period is finished."
            |
:0040EE41 6878FB4400              push 0044FB78
```

根据以上代码，可以看出过期提示框是由 `:0040EE27` 处跳来的，向上看(tKC的绝招)，于是找到如下代码：

```
:0040EDFB C7051004470000010000    mov dword ptr [00470410], 00000100
:0040EE05 C70570014700FFFFFFFF    mov dword ptr [00470170], FFFFFFFF
:0040EE0F A384014700              mov dword ptr [00470184], eax
:0040EE14 8915DC044700            mov dword ptr [004704DC], edx
:0040EE1A E841350200              call 00432360
:0040EE1F 83C434                  add esp, 00000034
:0040EE22 48                      dec eax
:0040EE23 5F                      pop edi
:0040EE24 744E                    je 0040EE74
:0040EE26 48                      dec eax
:0040EE27 7418                    je 0040EE41    <===将此处je nop nop掉则可继续。:)
:0040EE29 6A00                    push 00000000
:0040EE2B 6890C44000              push 0040C490
:0040EE30 6A00                    push 00000000
```

2、用`ice`载入`flash32.exe`，在`0040EE24`设断，修改标记，使其不跳转，程序继续运行，没了时间限制。

3、修改程序：

用`hiew`打开`flash.exe`找到`744e74186A00`，将其中`7418`改为`9090`即可削除时间限制。
