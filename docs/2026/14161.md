
# [原创]AndroidMainfest文件反编译工具

这两天看起了Mainfest文件的二进制格式，写了反编译工具。

个人测试我写的apk,还有QQ的二进制Mainfest文件都能正常反编译。

基于控制台，源码在附件的压缩包里。

反编译的时候会输出二进制文件的分析结果，如果文件太大在控制台输出会很费时间，而且分析结果也不能完全显示，所有可以重定向至文本，速度会非常快

由于是c语言写的，所以输出的文件不是utf-8编码，不过也就是用来看一下，不需要编码转换。
