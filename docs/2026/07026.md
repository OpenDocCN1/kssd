# Awave Studio v7.0的破解

Awave Studio v7.0的破解
工具:TRW2000和Wdasm 8.93 Gold版(http://go.163.com/~wuhuashang/gold.exe)
目标说明:一个能转换几乎所有音频格式的工具，用于聆听不同平台音频文件的最好工具之一，
        你可以以各种方式使用它：音频文件格式转换器、音频编辑器、音频播放器、以及作
        为一个通用波表合成器格式的转换器和编辑器。Awave可以读取差不多所有的音频文
        件格式，同时它可以输出大部分流行的音频文件格式。
难度:中级?
下载地址:http://www.fmjsoft.com
==================================================================================

Awave Studio v7.0是用Asprotect加的壳，无法直接用Wdasm反汇编，只有先找到它的OEP，再从内存
中Dump出脱离壳后的文件映像(无需重建Import Table)，具体过程可参看《论坛精华 II》中的教程！
运行Wdasm 8.93(Gold版)反汇编Dump出来的文件，在String Data References中会看到"Registered to:%s"

的字样。通过RegMon监测，该软件启动时会校验注册表中的Username和Usercode两个键值，已确定是否已注册。
为了便于跟踪，可手动建立下列两个键及键值：
[HKEY\_CURRENT\_USER\Software\FMJ-Software\Awave Studio]
"Username"="sUpErbOss"
"Usercode"="1122334455"
启动TRW2000，加载Awave Studio，点击"Load"按钮。进入到TRW2000环境，下指令"faults off"，
再打"G 0046E22C",即可！

此软件的注册码的计算好像用到了RSA算法，要算出注册码是很困难的。但很明显，用暴力
法破解它是非常容易的，只需将004A486C处的jne 004A48AE改为jne 004A48A1，即可！
当然，改法不止这一种！由于Awave Studio被Asprotect加了壳，而最新的Asprotect的
脱壳软件Caspr v0.952对它脱壳不完整，造成脱壳后，Awave Studio运行出错！所以，无法
在脱壳后修改，只有写一个Loader搞定它！Loader源码如下：(已经调试通过）

; tasm32 /ml loader.asm
; tlink32 /Tpe /aa /c loader,loader,, <path to> import32.lib
; 以上两行是编译命令，需用到TASM 5.0！

.386P
model flat,stdcall
locals
