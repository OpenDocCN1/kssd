
# 跟兄弟们一起复习一下IEEE浮点数的存放格式 (818字)

对于大小为32-bit的浮点数（32-bit为单精度，64-bit浮点数为双精度，80-bit为扩展精度浮点数），

1、其第31 bit为符号位，为0则表示正数，反之为复数，其读数值用`s`表示；

2、第30～23 bit为幂数，其读数值用`e`表示；

3、第22～0 bit共23 bit作为系数，视为二进制纯小数，假定该小数的十进制值为`x`；

则按照规定，该浮点数的值用十进制表示为：

`(-1)^s * (1 + x) * 2^(e - 127)`

对于`49E48E68`来说，

1、其第31 bit为0，即`s = 0`

2、第30～23 bit依次为`100 1001 1`，读成十进制就是147，即`e = 147`。

3、第22～0 bit依次为`110 0100 1000 1110 0110 1000`，也就是二进制的纯小数`0.110 0100 1000 1110 0110 1000`，其十进制形式为0.78559589385986328125，即`x = 0.78559589385986328125`。

这样，该浮点数的十进制表示

=　`(-1)^s * (1 + x) * 2^(e - 127)`

=　`(-1)^0 * (1 + 0.78559589385986328125) * 2^(147 - 127)`

= 1872333

你可以用windows自带的计算器算一下。
