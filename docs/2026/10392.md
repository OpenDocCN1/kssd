# [原创]Asm Wizard for vs2008

用于 vs2008 的汇编向导.

1. 使用记事本打开 Install.bat 。
2. 把 VCInstall 设置为你本机上的VC路径，保存。
3. 运行 Install.bat 进行安装，以后在新建VC项目时就能看到 AsmWizard 选项了。
4. 接下来看图进行操作。
5. 只需要把 MASM32 中的 include 和 lib 两个目录包含进搜索路径中，就可以编写汇编程序了。
6. 我个人觉得VS编写汇编的优势在于可以使用VS强大的调功能。
7. 在VS中写汇编是没有代码提示的。
