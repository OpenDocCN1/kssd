{
	BYTE buf[0x100];

这样再看就非常清晰了，过程如下：
<1>算出序列号中每个字母的编号，存在buf中，编号范围是0-31，共32个符号，2进制就是00000-11111共5个bit
<2>然后把变换后的bit拼接起来，序列号共32位，故拼接后32\*5=160bit=20字节

故：
设a1-a8是序列号前8位，d1-d5是散列值，则有如下关系：

	sha1_init (&ctx);
