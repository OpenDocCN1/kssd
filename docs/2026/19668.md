# [原创]研究4阶幻方找到的部分规律

先说明下,本人是数学小白,所以有错误的地方请见谅!看到这道题时,我还不知道幻方是何物,所以百度上查了一下,发现原来[洛书](https://bbs.kanxue.com/elink@db9K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8X3u0S2K9h3E0W2i4K6u0W2j5X3q4A6k6s2g2Q4x3X3g2U0L8$3#2Q4x3V1k6$3K9h3g2%4i4K6u0r3y4o6p5%4x3q4)9J5k6h3S2@1L8b7`.`.)就是一个3阶幻方,易经的后天八卦这是按照这个顺序排的,神奇的东西!然后找了一些4阶幻方的例子,开始找规律,一晚上下来,总算有点头绪了!现在分享给大家,本人愚钝,还没有完全参透![](https://bbs.kanxue.com/view/img/face/50.gif)

随便拿几个例子:
![](https://bbs.kanxue.com/upload/attach/201010/155970_34ghttozjckyxg9.jpg)

奇数(阴)背景加了颜色,你可能会惊奇的发现,这个图案,对折刚好是可以重合的,下面我们重合下:
![](https://bbs.kanxue.com/upload/attach/201010/155970_9u2ss3uojsgbi84.jpg)
重合后看不出他有什么规律,但是我们可以发现,他是一半奇数,一半偶数,然后在瓜分一半到另一边去,我们试着手动写一个:

![](https://bbs.kanxue.com/upload/attach/201010/155970_rc3gy4ejlcaoxc6.jpg)
这个很简单, 很有规律性,竖和斜都是34,除了横排,现在我们要把4个奇数放到偶数那边,因为竖和斜都是34,所以,4个角和中间4个不能动,动了斜面的和就要变了,所以只能动5,3,9,15和2,14,12,8,把他们对应交换后,得到:
![](https://bbs.kanxue.com/upload/attach/201010/155970_1rk0vcakxd5ly2m.jpg)

一个简单的幻方就完成了,这时候把他们从分成4块, 7,14,2,11为一块,12,1,13,8为一块,9,4,16,5和6,15,3,10,然后顺时针旋转一格:
![](https://bbs.kanxue.com/upload/attach/201010/155970_v6rfr1in8j2mzrm.jpg)
还是一个幻方,这样可以旋转4次!

下面来试试用另一种方法:
![](https://bbs.kanxue.com/upload/attach/201010/155970_knk457vu989j94o.jpg)

第一行从右到左,依次写1,2,3,4,然后第3行左往写5,6,7,8

第2行从左往右写9,10,11,12,第4行从右到左,13,14,15,16,这里你会发现一个规律,第一行和第3行相对,和都为9,第2行和第4行相对,和都为25,所以竖排和都会一样!

用上面的方法,4边和中间不动,得到:
![](https://bbs.kanxue.com/upload/attach/201010/155970_858v1x0v8c30n0r.jpg)
