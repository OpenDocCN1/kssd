## 下载后如何安装

1. 运行命令行安装 openai 的运行库：`pip install -r ./requirements.txt`。

2. 下载脚本 `WPeChatGPT.py` 后，将自己 ChatGPT 的 API-key 填入脚本中的变量 `openai.api_key`。

3. 将 `WPeChatGPT.py` 复制到 IDA 的 `plugins` 文件夹中，重启 IDA 即可。
