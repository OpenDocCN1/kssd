# [原创]android 简单实现Bitmap和Drawable的切换，ImageView中得到Bitmap

![](https://bbs.kanxue.com/view/img/face/16.gif)照顾下新人，我只会android,可想学其他，发帖也只能在这发了。。。

很多人实现图片功能时都会遇到的问题，图片很多功能都只有Bitmap可以实现，但是读取图片一般都是Drawable的，下面说说简单的实现方法~~

一般很多人使用的方法是
view.buildDrawingCache(true);
view.getDrawingCache();
Bitmap bt=viewg.etDrawingCache();

这方法其实是对的，不过呢，这方法经常返回的图BT都是NULL，这是因为View是new出来的,因为没有cache可以获得，所有返回空。
如果是使用在有展示的ImageView这方法并没有太大的问题。

这开始就讲讲简单的方法，这方法不管是new不new都没有太大的问题。

Bitmap image = ((BitmapDrawable)view.getDrawable()).getBitmap();

很简单的一段代码，这是将ImageView中得到的图片以Drawable格式出来后再强制转换的.

同理将Bitmap转为Drawable就是

view.setImageBitmap(image);
view.getDrawable();

简单高效快捷。
