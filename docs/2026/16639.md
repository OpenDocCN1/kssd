# [原创]开源Console版iOS APP内存修改器

开源自己一直在用的小工具，算法全部在内存中完成，速度比bmsq，igg快，直接搜索0也是无压力。使用c++编写，有一定的扩展能力，可以自己扩展value type和comparator。

32bits
0x00000000-0x7FFFFFFF
64bits

uint8\16\32\64
int8\16\32\64
float\double

支持模糊搜索
eq\ne\lt\gt
