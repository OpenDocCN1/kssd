
# [原创]进程管理dll注入综合小工具[附源码]

最近看完Windows核心编程，想检测一下自己所学的东西就写了这个进程管理小工具。

主要功能有：
- 进程枚举
- 进程的模块枚举
- 结束进程
- 模块的卸载
- 进程虚拟地址空间的查看
- DLL的注入
- 系统WIN32服务的枚举和驱动模块的枚举（这两个功能可以无视）

源代码和可执行程序在附件里，代码用MFC编写，代码风格不是很好，代码内有附有详细注释，用的方法都是些老方法，觉得有帮助的朋友看看吧。另外Windows核心编程确实是本好书，希望更多人去看。
