## 【算法总结】

将用户名变形，分成两部分计算，最后将计算结果1-5位，6-10位，11-15位用"-"相连即是注册码

## 【算法注册机】

〖VB代码〗

```
Private Sub Command1_Click()

If Len(Text1.Text) = 0 Then

   Text2.Text = "请输入用户名！"

Else

  A = Text1.Text

  B = "Lb)a6Fcw9K9"

  C = A & B

  D = Len(C) \ 2

  X1 = Left(C, D)

  X2 = Right(C, Len(C) - D)

  X3 = X2 & X1

  X4 = Left(X3, 10)

  X5 = Mid(X3, 6, Len(C) - 5)

  E = 256

  Y = Hex(E)

  j = 0

   For i = 1 To (Len(X4))

   F = Asc(Mid(X4, i, 1))

   F = F + E

   F = F Mod 255

   If j >= Len(X5) Then

   j = 1

   Else

   j = j + 1

   End If

   G = Asc(Mid(X5, j, 1))

   E = F Xor G

   H = Hex(E)

   For k = 1 To (2 - Len(H))

   H = "0" & H

   Next

   Y = Y & H

   Next

   Text2.Text = Mid(Y, 1, 5) & "-" & Mid(Y, 6, 5) & "-" & Mid(Y, 11, 5)

End If

End Sub
```
