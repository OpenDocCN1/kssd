
# 让金山词霸在Acrobat Reader最新版中取词 (491字)

小弟用Crack软件同样的方法知道了Acrobat Read不让词霸在其4.05版本中取词的地方, 因此patch了它并专门做了一个网站供大家下载,

有兴趣的朋友可去看看:

`http://acropat.home.chinaren.com`

方法简单的不好意思说:

1. 在运行Acrobat Reader前下断 `bpx CreateFileA do "d esp->4"`
   直到显示出正在打开`xdict32.api`.

2. 再下断:
   `bpx ReadFile`
   `bpx ReadFileEx`

经几次`F12`后 发现有

```
or eax, eax
jnz xxxxx
```

就在这儿改!

其实ICE除了破解, 用它来发现并改变软件的行为是大有可为的. 我类似使用ICE的例子绝不只这一个.
