好了，废话少说，我们上路吧！
运行WinZIP7.0（SR-1)，点击“Enter Registration Code“按钮，
进入注册提示窗口，填写： Name:tongxinshiwo  Registration :1234567890
按Ctrl＋N激活TRW，
输入  bpx hmemcpy  ←…… 下断点
输入  g            ←…… 继续运行
返回注册窗口，点击 OK
又返回TRW，你会在屏幕下方看到：
Break on BP1      ←…… 拦截成功
输入  bc \*        ←…… 清除断点
输入  pmodule      ←…… 等于按F12若干次
这时，在屏幕中间你能看到绿色的那一行：
015F:0040801A  PUSH  EBX
接下来你需要做的就是一直按F10到
015F:0040805C  CALL  00407B4B
再按F8进入CALL，出现
015F:00407B4B  PUSH  EBP
按F10（好长时间的，注意不要按过了。）到
015F:00407C53  PUSH  EAX
好了，找到注册码了。
输入  d eax      ←…… 察看注册码
屏幕右上方PROT32下面会有一个8位数字，赶快记下来吧！我的是：62657298
按F5回到WinZIP7.0（SR-1)注册窗口，重新输入你看到的注册码，就可以看到注册
成功了。

Name:          tongxinshiwo
Registration : 62657298

在这儿我想提醒一下各位，不论你在Name中输入什么样的中文注册名，得到的注册码始终
都是： 00990000 （不要问我为什么，我是初学者，我也不知道，请问Crack中的高手
高手高高手吧！）

Name：        只要里面没有英文字母就行了！
Registration : 00990000
注意：有一个英文字母都不行，注册名可以是汉字、数字、各种标点符号、还有其他符号，
或者是这几种的组合。比如注册名可以是：看雪学院、00990000、“”《》、＋－×÷、
ⅢΓγ、←→↑↓、★■◆●▲等等只要注册名里没有英文字母就行了。


WinZIP7.0（SR-1)的注册名和注册码在WinZIP8.0中也适用。行了，现在，你也可以把
WinZIP用自己的中文名字注册了，要不用些稀奇古怪的符号来当注册名也行，怎么样它
是不是已经属于你的了。
