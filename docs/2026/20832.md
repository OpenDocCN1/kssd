
# [旧帖][分享]`看雪10周年.chm`激励着我0.00雪花

最近很迷茫，或者说自己不自信，所以又来到了看雪，很久没来了，甚至忘记了密码，最后还是用邮箱找回的，对于这段时间我感觉很惭愧。在07年因为没考上高中，就来到这个城市上技校，在初中没时间去多接触计算机，有点时间就是去网吧打游戏，那个时候对计算机的爱好完全就是因为游戏，然后到这来之后想都没想直接就报的计算机专业，但是进学校过后我完全后悔了(学的东西很杂，都有了解，但是都不通)，因为是学的计算机专业，因此父母就给我买了电脑，主要是用来学习用的，但是我用这个没做好事，经常中病毒，当时对这安全一点知识没有，中病毒之后还得拉去修电脑，修一次就100多，自己受不了，父母也受不了，后来了解到只是重装系统，惭愧，自从那个时候就对自己说不能再拿去修了，然后qq加了几个关于电脑的几个群，刚开始在群里边问一些低级问题，很多人都直接说"自己百度!"，没办法，从那个时候开始就对计算机安全方面有着极强的兴趣，杀毒软件下载\安装\扫描\处理\卸载，重复了很多不同的软件，放假每天的忙碌也只是做这些事，当时真的是很充实，发现自己已经喜欢计算机了，但是我什么也不会，接触到了几个论坛 天天就泡在论坛上学习，然后接触了看雪，当时给我给我的感觉就是非常专业，对于大神们发的帖，很有兴趣，在0基础的时候就想学习脱壳、解密之类的，当时我大哥就先让我学习汇编，然后再学这类的，但是我没有听他的，依然按着我的性子来，不过大哥也给我基础的文章，没有多看，直接就上手了脱壳了，当时按照教程成功了一个，心情非常激动，相信大家如果有第一次成功心里当然是非常高兴的，不过在接下来的时候，发现自己根本什么也不会，想了想还是得把基础打好，但是自己完全看不懂，也有点心灰意冷了，有放弃的念头。在学校的一天，有同学建议跳墙出去刷夜(之前在小学和中学我是乖乖男，可就是学习不好)，当时我自己就问我自己能否跳过墙，心里还是害怕的，在同学们的忽悠假骗过后，我还是跳出去了，虽然落地的一瞬间很狼狈，心里还是很高兴的(跳过墙了)，第一次刷夜，就跟着同学们一起玩着游戏，从那个时候开始就一发不可收拾，中途有段时间想过这个问题:我在游戏可以得到什么?答案是没有，有曾想过从0开始，继续到看雪，看到完全看不懂的天书，又伤心了，继续回到游戏中，甚至在外实习的几个月当中(干的都是没技术含量的活)，下班抽点时间也得去网吧打会游戏，堕落中生活，几个月之后公司的部门解散，不想去公司安排的其他部门干活，毅然决定辞职，这段时间又迷茫了，不知道自己何去何从，最近发现自己很没用，母亲也在为我的以后生活操心，然后经朋友介绍了一个IT补习班，母亲问我的意见，我说没问题，就报了，要学4个月，15000就这样没了，心里就想，这下必须得好好学习了，不然自己都不能原谅自己，突然想到了看雪，就过来看看(很久没来了)，发现了一个看雪论坛成立10周年的精华帖(祝福看雪10周年快乐，偶来晚了~~~)，下载了，也好好看了看"成长的故事"，发现那些大鸟们刚开始也只是从菜鸟起步的，心有感触，自己不努力肯定是没有成绩的，所以就想到在这里发一篇文章，以此来激励自己，迎接4个月的培训，为了以后的好工作而努力，为了父母以后的生活而努力。论坛如果有与我差不多情况的同学，我们真的得努力了，就算不为自己，也得为了父母想想。再见了，网游，不敢说永别，但这4个月，真的得告别!迷茫的生活也在这几天找到了目标，看雪的同学们，为了以后的生活，大家一起努力!~~
