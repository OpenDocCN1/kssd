
# [原创]分析个性感小马

昨天发了一篇被判定为YJ贴了。。![](https://bbs.kanxue.com/view/img/face/16.gif)，希望这篇不会。。。

马比较简单，适合新手。

先说一下行为：`exe`文件会释放`Pcix32.sys` `amd32_.sys` `atax32.sys`三个文件，但是后两个其实只是地一个的拷贝。`sys`文件负责监控各种杀毒软件和安全工具的启动，一旦发现，马上kill。

## 1。`exe`行为。

这里只写思路，详细请参考`idb`文件和自己跟，嘎嘎。

首先获取系统`drivers`目录，然后释放`Pcix32.sys`到这个目录下，期间拷贝各种副本。

还有，`exe`会检测是否有还原精灵，有的话会做相应处理，不过本人太懒。。懒得搭环境，这部分有兴趣的跟一下吧：）

如果没有还原精灵的话，就加载驱动。

最后有一个注入的行为，也没仔细跟：D
