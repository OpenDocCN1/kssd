# [原创]极路由远程命令执行漏洞-漏洞分析

## 简介
本篇主要介绍cloud\_token的计算方式和远程命令执行漏洞的代码分析。cloud\_token是开启远程ssh的token，如果知道cloud\_token就可以远程开启ssh服务。

## 漏洞分析
远程命令执行的漏洞分析比较简单，漏洞代码就位于以上的local\_ssh.lua中。漏洞代码如下:
```
local cmd\_result = utils.exec\_cmd("sudo /usr/lib/lua/luci/local\_ssh/local\_ssh\_util.lua valid " .. tostring(request.data))
```
在method=valid时，对于传来的data参数没有做任何的过滤就直接传进了exec\_cmd进行了执行。
