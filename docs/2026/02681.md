1,运行程序，即弹出提示框，呵呵……就从这里入手好啦。输入用户名，注册码嘛，随便啦，"11111111"。

2,不要急着按注册，先用`TRW`下断点。`CTRL+N`叫出`TRW`，下`bpx hmemcpy`。`F5`退出。

3，按下注册，`TRW`马上拦下来了。来到这里：

```
0177:00490F73  CALL    004312BC ----------光标在这一行上。
0177:00490F78  MOV      EAX,[EBP-20]
```

4，下`PMODULE`，按8下`F12`出错，SO只要按7下就行啦。

5，接着要一步步来了，按`F10`，来到……

```
0177:00490EA2  CMP      DWORD [EBP-08],BYTE +00 --------是否输入用户名
0177:00490EA6  JNZ      00490EB7 -----------没有则出错。
0177:00490EA8  MOV      EAX,004910AC
0177:00490EAD  CALL    004587E4
0177:00490EB2  JMP      00491016
……
0177:00490F73  CALL    004312BC
0177:00490F78  MOV      EAX,[EBP-20]
0177:00490F7B  MOV      EDX,[EBP-04]
0177:00490F7E  CALL    00403E70 -------在这里下D edx您猜会怎样啊？当然，您想要的东东出来啦！
0177:00490F83  JNZ      00490FEC
0177:00490F85  LEA      EDX,[EBP-28]
```
