# [讨论]爆破算法优化

算法如下：
v1 = 0
v2 = k1
v3 = k2
{
v1 += const1

v2 += v3<<4
v2 += v3^const2
v2 += (v3>>5)^v1
v2 += const3

v3 += v2<<4
v3 += v2^const4
v3 += (v2>>5)^v1
v3 += const5
}循环32次

k1,k2,const2~5全为0x20-0x7e中任意字符的任意组合，const1为任意非0十六进制数。

目前通过取消循环体，速度为15s算完一个k1k2(0x20202020)到(k1+1)k2(0x7f7f7f7f)区间。

求更快的算法。

另外，const1~5不便透露……
