# [原创]多态混淆器 [开源]

前言:

这个东西是2013年完成的，在硬盘里放了快1年了,现放出来献丑,祝大家中秋快乐 :)

工作: 在编译后，link前对中间文件进行处理，让最终生成的代码增加复杂性，来增加人工/机器分析的难度

特点: 1. 支持intel x86指令集，支持 纯代码段 和 coff obj (vc6,vs2010,...)格式
      2. 变形混淆公式采用开放接口形式,可自行添加
      3. php源码，支持命令行格式，很容易做成批处理形式做批量操作

待改进:
      0. 界面没做，输入命令行，输出没啥意义...
      1. 提供支持64位
      2. 建立集中的变形混淆库，方便交流,共享变形混淆公式
      3. 除目前支持的native 2进制代码(如shellcode) 或 vc的obj/lib 格式外，支持更多文件格式
      4. 支持更多指令集，如mmx,sse，等...
      5. 填充代码前后文语法关联弱，会生成不合理的语法，如: mov eax,1; xor eax,eax;
      6. 代码外的特征，如输入，输出表，重定位表，资源表，等

...anyway,现在是个可以工作的版本，我会继续改进，希望有人喜欢。
