
# [原创]最全Windbg 指令总结

写内核代码期间慢慢积累整理的东西，发出来大家可以快乐地做CV战士。

## 1.基础指令

`.reload`

`.reload /f` 重新装载模块

`.reload /i` 强制加载mismatched symbol

`u`：主要用于反汇编某个地址，后面可以跟函数名和地址

`L [nLength]` 查看指定行数，不指定则显示8行

`u nt!DbgPrint`

`uf`

反汇编整个函数（从函数头部开始反汇编）

`db`/`dw`/`dd`/`dq`/`dD`/`df`

```
db 显示一字节的长度
dw 显示两字节的长度
dd 显示四字节的长度
dq 显示八字节的长度
显示double实数(8字节的长度)
df 显示float实数(4字节的长度)
dh 显示pe头信息
```

`!dd`/`!dq`/`!d?...`

```
查看物理地址
```

`da`/`du`/`ds`/`dS`命令

```
da 显示asscii值
du 显示unicode值
ds 显示ANI_STRING值
dS显示UNICODE_STRING的值
```

`eb`/`ew`/`ed`/`eq`

```
eb address value 在address 这个地址写入一个字节value
ew address value 在address 这个地址写入两字节value
ed address value 在address 这个地址写入四字节字节value
eq address value 在address 这个地址写入八字节字节value
```

`dt`命令

```
dt主要用于查看结构体
```

## 2.对象相关指令

`dt 结构体 地址`

```
查看地址所在结构体上的数值
kd> dt 0x873123b0 Irp -r1
-r 参数 指定深度 ，r1代表只看往下一层
```

`lm`命令

```
lm 列出模块
lm vm 模块名 查看模块详细信息
```

`!process` 命令

```
!process 0 0 //列出系统进程信息
!process 0 0 进程名 //列出该进程信息
!process 0 1 进程名 //列出该进程详细信息
!process 0 7 进程名 //列出该进程包括线程在内的详细信息
```

`.process` 命令

```
.process EPROCESS //切入该进程中
.process /i EPROCESS //切入该进程中再附加，如果不加i的话上下文环境没有切换。
```

`!object` 命令

```
!object 地址 //显示改地址的对象信息
```

## 3.读取寄存器指令

`r` 命令

```
查看所有寄存器的值（通用寄存器、段寄存器、eflag，看不到控制寄存器）
```

`r 寄存器`

```
查看某一个寄存器的值
```

`rdmsr [索引]`

```
rdmsr 174
读取msr寄存器中174位置的值
```

## 4.断点命令

`bp`指令

```
bp 命令是通过向指定地址插入int3 指令来完成的
bp address 在地址address插入断点
```

`ba`指令

```
ba指令是硬件断点命令，通过设置cpu的dx寄存器来拦截线程
ba access size 地址 //access是访问的方式，比如 e (执行)，r (读/写)，w (写)， size是监控访问的位置的大小，以字节为单位。值为 1、2或4，在64位机器上还可以是8
```

`bd`指令

```
bd 断点号 //此命令是禁止断点号所对应的断点 。
```

`be`指令

```
be断点号 //此命令是开启断点号所对应的断点。
```

`bc *` 指令

```
去除所有断点
```

## 5.其他命令

`x`命令

```
X命令用来模糊查询。例如可以这样查看SSDT表的地址:
x nt!kes*des*table*
0: kd> x nt!kes*des*table*
8055d6c0 nt!KeServiceDescriptorTableShadow = <no type information>
8055d700 nt!KeServiceDescriptorTable = <no type information>
```

`dds`命令

```
dds 地址 //此命令用来解析某连续地址的函数名。
0: kd> dd nt!KeServiceDescriptorTable L1
8055d700 80505450 00000000 0000011c 805058c4
0: kd> dds 80505450 l3
80505450 805a5614 nt!NtAcceptConnectPort
80505454 805f1adc nt!NtAccessCheck
80505458 805f5312 nt!NtAccessCheckAndAuditAlarm
补充：dqs 等同于64位下的dds
```

`dg [tr]` 命令

```
查看段属性
0: kd> r tr
tr=00000028
0: kd> dg tr=00000028
P Si Gr Pr Lo
Sel Base Limit Type l ze an es ng Flags
---- -------- -------- ---------- - -- -- -- -- --------
0001 00000000 00000000 <Reserved> 0 Nb By Np Nl 00000000
```

`.cls`

```
清-屏
```

`.reboot`

```
重-启
```

`!irql`

```
查看当前irql
```
