
# [原创]Ghost Bird OS

呵...这是一个已经有了简单GUI的操作系统。

开发者是我的一个朋友，高中生。他的梦想就是开发操作系统。我认识他有一年多了吧，那时我在学汇编时认识的。

我认识他很久了，这人特别爱钻研技术，非常佩服。[我也做过系统](http://bbs.pediy.com/showthread.php?t=195743)，但是太枯燥无味了，有些资料又不好找，所以停工了，没想到他却突破了重重困难进入到了”GUI时代“
