# [原创]AIDA64去广告分析(入门版)

AIDA64是个非常好用的软件，是我必装的工具软件之一，但不知从哪个版本开始，有了烦人的广告，于是决定从它开始研究下如何去除，顺便熟悉下破解的流程。广告界面如图所示

![](https://bbs.kanxue.com/upload/attach/202305/975816_2UT4NBXGT6DVYSH.jpg)

过程其实很简单，这个软件没有加壳没有做代码混淆，几乎没什么门槛。

将下载的apk拖到jadx里面，从AndroidManifest.xml里面得知主MainActivity为com.finalwire.aida64.HHMainActivity，

![](https://bbs.kanxue.com/upload/attach/202305/975816_E5AF8A95HQPRKBE.jpg)

于是打开HHMainActivity的源码，一眼就看到了几个跟广告相关的字段，好吧，老外就是实诚...

![](https://bbs.kanxue.com/upload/attach/202305/975816_A6AYGJ8A2E4FGH2.jpg)

看上去那个adMode比较关键，应该是用于判断是否显示广告的，顺藤摸瓜找到以下引用的地方

![](https://bbs.kanxue.com/upload/attach/202305/975816_9PCUKS52HJSJG9H.jpg)

这段代码的含义是查找用户是否交钱了，如果没有交钱，那么就调用showHideAds来展示广告，这个函数名倒是起的挺直白。破解也很简单，只要将showHideAds nop掉就可以不显示广告了。

确定位置后，用apktool将该apk反编译

![](https://bbs.kanxue.com/upload/attach/202305/975816_6EJ9NHSRASQZAUK.jpg)

然后定位到HHMainActivity.smali, 将showHideAds直接跳过

![](https://bbs.kanxue.com/upload/attach/202305/975816_DBMGDCFHNP2RQGT.jpg)

然后重打包

![](https://bbs.kanxue.com/upload/attach/202305/975816_89KWPWHWZ27UYKY.jpg)

然后需要用zipalign做一下对齐

![](https://bbs.kanxue.com/upload/attach/202305/975816_GKYUWNV6GCJVUBT.jpg)

验证一下没问题

![](https://bbs.kanxue.com/upload/attach/202305/975816_H4M9KU3BJ4BPNAJ.jpg)

最后就可以签名了

![](https://bbs.kanxue.com/upload/attach/202305/975816_RN7RK43D9G74W6B.jpg)

安装后再启动，没有任何广告了。

传到附件了，有需要自取～
