
# 逆向技术之寻找Main入口点

## 一、识别各个程序的入口点

入门知识，识别各个应用程序的入口点（举例识别VC编译器生成，以及VS编译生成的Debug版本以及Release版本）

### 1. 识别VC6.0 Debug版本

1.1 首先，新建一个VC debug版本的程序，然后F5运行，可以看到栈回溯窗口

![](https://bbs.kanxue.com/upload/attach/201902/3_JZB4PCEZBKVQXT2.jpg)

1.2 而后通过栈回溯窗口，点击`mainCRTStarup`，查看`main`函数之前会调用什么API

![](https://bbs.kanxue.com/upload/attach/201902/3_BEQSDQSA9K4BGZH.jpg)

确定之后，OD打开查看。

![](https://bbs.kanxue.com/upload/attach/201902/3_NPDMPBB8CE3XBQR.jpg)

可以看到调用API的位置，但是怎么确定那个是入口点，我们知道，VC中的`main`函数是3个参数，那么我们只需要找到三个`push`然后一个`Call`的位置，则可以确定，（确定也是要你F7跟进去，看看代码是不是`main`函数的代码，或者参数传参是什么）

1.3 确定`main`入口点

![](https://bbs.kanxue.com/upload/attach/201902/3_2KYJX8B8GPX7ZHH.jpg)

在上图可以看到，三个`push`，然后一个`Call`，那么我们跟进去查看，因为是Debug版本，所以已经提示出来参数是什么了，所以直接可以确定了。

1.4 F7跟进去查看。

![](https://bbs.kanxue.com/upload/attach/201902/3_QYNV8YWRSTCUEZW.jpg)

可以直接确定使我们的入口点

IDA查看一次

步骤和前边一样，先看入口点特征，Debug版本特征是调用API `GetVersion`

所以IDA中查看。

1. 查看文本视图

![](https://bbs.kanxue.com/upload/attach/201902/3_V7TSA8W2VYVWGB7.jpg)

2. 展开文本视图

![](https://bbs.kanxue.com/upload/attach/201902/3_VF73F5S76B4PYU6.jpg)

这里提示你要CTRL + 加号展开

展开查看

![](https://bbs.kanxue.com/upload/attach/201902/3_P4MYX799XFGXW2G.jpg)

3. 根据特征，读取代码，确定`main`位置

![](https://bbs.kanxue.com/upload/attach/201902/3_QZZQ4SBG2C8NUWH.jpg)

因为是Debug所以有符号显示 下面直接看Release版本

### 2. 查看VC6.0 Release版本

首先，特征是一样的，都是调用`GetVersion`

那么现在直接OD打开去分析。（当然IDA也可以，都是工具）

1. 都是一样的，先找特征

![](https://bbs.kanxue.com/upload/attach/201902/3_MVTJRDZJ8MCJH4J.jpg)

2. 找到之后，因为我们写的是`main`，所以判断是`main`，只要找到三个`push`一个`Call`即可

![](https://bbs.kanxue.com/upload/attach/201902/3_HADSM6UETSTWZHF.jpg)

已经找到了 F7 跟进去查看。

3. 确认是不是。

![](https://bbs.kanxue.com/upload/attach/201902/3_89U9NBYDWR2HYNT.jpg)

可以看出，因为是Release版本，所以都给优化没了。确实是我们写的代码

### 3. 查看VS系列 Debug版本（每个版本不一样，所以先看下特征这里 VS 2015）

1. 栈回溯，确定入口点特征

首先第一步，还是编写一段代码

然后通过栈回溯，查看入口的特征。

![](https://bbs.kanxue.com/upload/attach/201902/3_R5RXD3T329YPQR4.jpg)

那么我觉着，这个是入口点的特征，而在`tmainCRTStartup`里面调用的`wmain`

那么此时OD打开的时候可以分析遇到的第二个`call`，然后在第二个`call`里面跟进去。

通过栈回溯，可以看到会调用这种API，而下方的截图则会调用`wmain`，所以OD打开，不断的跟，也是三个`push`一个`Call`

![](https://bbs.kanxue.com/upload/attach/201902/3_9UAH54ZAU5CNVNY.jpg)

2. OD分析

因为是Debug版本，有跳转表，也可以看到符号信息，所以直接跳转过来

![](https://bbs.kanxue.com/upload/attach/201902/3_J394HBGCXVRSTH9.jpg)

可以看到确实是两个`Call`，也就是我们上面分析的，然后进入第二个`Call`

3. 确定入口点位置

F7跟进去，查找三个`push`一个`Call`

![](https://bbs.kanxue.com/upload/attach/201902/3_PFKRNG4FUUHFVER.jpg)

找到了，我们跟进去查看，看看是否是入口点，

![](https://bbs.kanxue.com/upload/attach/201902/3_RVGA6HUZZS9K7BW.jpg)

跟进去之后发现又有一层跳转表，没关系，F8 走过去

![](https://bbs.kanxue.com/upload/attach/201902/3_DPA2DSMSHPJMFUM.jpg)

跟过来之后则会发现确实使我们入口点写的代码了

### 4. VS系列，查看Release版本

Release版本是一样的，直接IDA打开查看（换着工具看）

1. 进去IDA，打开入口点，CTRL + 加号展开

![](https://bbs.kanxue.com/upload/attach/201902/3_4VV8XZ5U3VF9SEE.jpg)

CTRL + 加号展开不做演示，同上面分析一样。

查看反汇编

![](https://bbs.kanxue.com/upload/attach/201902/3_DZWKRCDGSZG6BPZ.jpg)

发现IDA直接跟过来的就是这个，那么此时好办了，我们知道`main`在它的下面，那么直接寻找三个`push`一个`Call`即可。

![](https://bbs.kanxue.com/upload/attach/201902/3_WE7SNMUTFND4E9D.jpg)

找到了，双击`_main`确认一下。

![](https://bbs.kanxue.com/upload/attach/201902/3_PCECQERFRZ8X8TQ.jpg)

我们刚才写的代码已经出来了
