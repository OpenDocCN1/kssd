# [原创]PointerTraversal 指针遍历器

最近在写游戏辅助，经常需要用CE来定位指针，但有的时候CE也不是很管用。
就上网找了个名叫CE之父指针扫描专家，VB写的，光一个EXE就10MB，不晓得到底装了些啥。还有一大堆组件。
而且不支持Win8，就寻思自己写个指针扫描器。
于是就有了PointerTraversal。PT用VS2012 C++开发的。完全支持Win XP ~ Win 8.1。
写这个花了差不多半个月时间吧。%70的时间浪费在对话框消息处理上了(不太会用MFC![](https://bbs.kanxue.com/view/img/face/50.gif))。
目前只测试过遍历DWORD、WCHAR[]型的变量。欢迎反馈BUG。
