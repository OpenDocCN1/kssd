# [原创]集成xposed到安卓源码

准备 `Xposed` 的编译环境，官方给的方法是使用 `Xposed Tools` ，其他大部分教程也是 `Xposed Tools`，这种方法不方便的地方就是集成 `Xposed` 后，我对 `art` 部分代码还有其他修改时会不生效。
# 环境
1. 安卓源码版本
android-7.1.2\_r8
2. 编译环境
docker ubuntu:16.04
3. 测试机
pixel
# 准备
下载安装源码，并成功编译，刷到手机，能正常启动运行
# 集成xposed
## XposedBridge
1. 下载 `XposedBridge` 源码，切到 `art` 分支
`git clone git@github.com:rovo89/XposedBridge.git -b art`
2. 用 `Android Studio` 打开，选择 `build -> build apks`，生成 `apk` ，修改文件名为 `XposedBridge.jar`
3. 拷贝 `XposedBridge.jar` 到 `out/target/product/sailfish/system/framework` 下
## Xposed
1. 下载 `Xposed` 源码
`git clone git@github.com:rovo89/Xposed.git`
2. 使用 `Xposed` 替换源码中的 `app\_process`，替换前记得备份下 `app\_process`
`mv Xposed frameworks/base/cmds/app\_process`
3. 替换 `Android.mk`
![图片描述](upload/attach/202006/778739\_DG6P8H9WXQTPY5M.png)
![图片描述](upload/attach/202006/778739\_RQNBPMZS5YGANN8.png)
## xposed\_art
1. 下载 `xposed\_art`
`git clone git@github.com:rovo89/android\_art.git -b xposed-nougat-mr2`
2. 使用 `xposed\_art` 替换源码中的 `art`，替换前记得备份下 `art`
`mv xposed\_art art`
## xposed.prop
放置 xposed.prop 在 `out/target/product/sailfish/system/` 下
## 编译与刷机
`make -j2`
`fastboot flash system system.img`
`fastboot flash boot boot.img`
`fastboot reboot`
系统正常启动后，安装 `Xposed Installer`
