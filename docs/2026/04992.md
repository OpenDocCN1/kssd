# Oicq 99c Build 0820版破解 (1千字)

这是目前(2000.10.12)最新的Oicq,本以为加密会很好,可破起来只用了十几分钟。不禁为腾讯公司感到悲哀。


在Oicq\dat下有Oicq2000.cfg文件，偏移0009为号码个数，后面有08000000隔开每个号码，保证你的Oicq号码的目录在Oicq\下,将Oicq2000.cfg中的号码改为你想要破的号.然后启动Oicq,在列表中选择你要破的号码,密码任意。在trw2000中下bpx
hmemcpy，F5切换到Oicq，点确定， 被拦下，经过N行，到449234显示出密码错误的对话框，向上看

:449210 cmp eax,ebx
:449212 jnz near 449446;此处可跳过

在49210下断点，再运行一次，光标停在cmp eax，ebx，此时eax=0,ebx=0,修改eax为1，跳到449446，按F5运行，竟成功了，连我都不敢相信，检查一下聊天纪录、个人信息，全对！又试了几个，都没问题。不禁有些愕然，如果直接跳到449446不就不用密码了吗？将449212改为jmp
449446，果然可以，不过程序开始时会提示程序被修改，过几次后Oicq会自动恢复，已很累不想继续追了，但应可以找到CRC比对处的。

我没对此前的版本测试过，相信应更容易。

以前用过一个Oicq密码终结者,用穷举法破译密码,遇到8位9位的密码不知要多少时候,没多大意义。破它的注册码倒有些意思。

特别提醒大家在公用机房上过机后，将Oicq下和你的号码一样的目录彻底删除，否则很容易被别人偷看聊天纪录，修改密码、个人信息，后果不堪设想。
