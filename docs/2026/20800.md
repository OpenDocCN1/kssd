
# [旧帖]分享我的经历0.00雪花

最开始接触C语言的时候是在我上高2的时候，有一次和朋友去网吧在网上看到的；当时，觉得很是新奇（学习都是从好奇开始的），回去以后决定去买本书看看。

还记得那时候在书店里《C语言程序设计》要68元一本，我省吃俭用攒了半个多月才买回来，当时我的心情非常的激动；从那以后就开始废寝忘食的学习，我不是很聪明学C完全是靠死记硬背，那时候哥们很穷，买不起电脑；学习C语言完全是靠用写的来熟悉代码，现在家里还保存有一纸箱的练习纸；现在想想当时是多么的有毅力啊。

我的C语言就是这样入门的，深入学习C语言是在我上职业学校的第一个学期（家里经济条件不好，上不起大学，这辈子连大学是什么样的都不清楚，真是遗憾啊！有些时候看都网吧里那些通宵的男男女女们我总是为他们感到不值，身在福中不知福啊，有点跑题了！），在学校的第二个星期我就进了学校的学生会，于是我的晚自习可以有大把的时间用来学习，回到宿舍我一般都是12点睡觉，宿舍楼是8点熄灯，我们7：30下自习；为了看书我很恨心买了个用电瓶的台灯，冲一次电可以用4个小时；那时候对C语言有一种偏执的、近乎疯狂的热爱，一本书都快翻撕了。第二个学期的时候我有了自己的第一台电脑AMD 3200+的处理器、512M的内存、80G的硬盘，这台电脑现在我还留着；有了电脑以后马上装上编译器开始练习，双休日的时候宿舍的朋友们都是出去玩、陪女朋友，只有我一个人在哪里敲键盘，就这样我学会了C、C++、VB。

当时，我喜欢的女孩是我的老师，教《金属工艺学》的，那个时候除了学习编程以外就是想她，于是我终于鼓足勇气向她表白，可惜被拒绝了。那时候做什么都没精神，干什么都没劲；仿佛天都塌下来了。后来，慢慢的恢复过来。我的电脑技术也是在那个时候学会的，为了能看看她、我入侵了学校的局域网在文件服务器上，上传了个木马（灰鸽子）；我把它该成一个文档，叫做“工资明细”，于是第二天晚上我就得到了很多的电脑；经过一个一个的筛选最终我找到IP：`192.168.4.13`这个地址，我想这辈子我都会记住这个地址。从那以后每天有多出一件让我开心的事。

现在想想当时的自己是多么的傻；唉，她在上个星期已经结婚了！我想这辈子我都没办法忘记她了。

现在，我在一家公司做网络维护也就是大家熟悉的企业网管，闲暇的时候还是会想想她，想想关于她的一切。

写这篇文章不是说明我有都么的厉害，只是想告诉大家什么事 都是靠自己的努力去换取的，而机会却要好好把握。
