# [原创]Ida7.0修改默认端口

### # 在逆向某款 APP的过程中发现只要Ida动态调试附加App进程就会出现连接断开的情况，打开android:debugger="true" 也不行 猜测可能是做了Ida检测,修改默认端口后发现可以正常调试。记录下修改默认端口的过程
## 用Ida打开 android\_server文件
![图片描述](upload/attach/202202/941861\_46XBCKQZVA6RQ7P.png)
字符串搜索 shift+F12搜索
![图片描述](upload/attach/202202/941861\_82BNH38C3A5DJNC.png)
X键找到引用位置
![图片描述](upload/attach/202202/941861\_CCTMA6CX3498U42.png)
![图片描述](upload/attach/202202/941861\_44EFS53VZHVZZKF.png)
默认端口为2394616 16进制就是0x5D8A
只要修改这个值就可以达到修改默认端口的目的
LDR R1 ,=0x5D8A是伪指令 值为97 4A
所以真实地址为
![图片描述](upload/attach/202202/941861\_J3UGNBQWKRH7S58.png)
ida输入 hex(0xafe4+0x25c) = 0xB240
![图片描述](upload/attach/202202/941861\_H32GWW96W9R5WMY.png)
记住位置 010Editor打开跳转到0xB240位置
修改8A 5D 为自己想要的端口 我这边修改为 6666 16进制为 1A 0A 倒过来为0A 1A 修改 保存 即可
![图片描述](upload/attach/202202/941861\_PEEZUPWC777W4D7.png)
![图片描述](upload/attach/202202/941861\_GN84QY5HYMZDG7K.png)
好的 收工 记录一下
