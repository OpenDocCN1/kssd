## depot_tools 安装配置

`depot_tools` 谷歌的包管理工具，可以管理多个git项目。重点就是可以断点续传，避免拉一半消失。

```
git clone https://chromium.googlesource.com/chromium/tools/depot_tools.git
```

配置环境变量使`gclient`命令生效

```
gedit /etc/profile
```

底部新增一行

```
export PATH="$PATH:/home/nizz/work_space/flutter/depot_tools"
```

配置生效

```
source /etc/profile
```

## 下拉flutter engine仓库

这一步我们使用`gclient`来拉取仓库

新建文件夹

```
mkdir engine_compile
cd engine_compile
```

新建配置文件填写`gclient`配置

```
touch .gclient
gedit .gclient
```

写入配置

```
solutions = [
{
"managed": False,
"name": "src/flutter",
"url": "git@github.com:flutter/engine.git",
"custom_deps": {},
"deps_file": "DEPS",
"safesync_url": "",
},]
```

方便同步 可以fork一份到自己仓库 配置ssh密钥

参考 341K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6T1L8r3!0Y4i4K6u0W2j5%4y4V1L8W2)9J5k6h3&6W2N6q4)9J5c8Y4q4I4i4K6g2X3x3K6j5J5y4K6f1%4x3K6c8Q4x3V1k6S2M7Y4c8A6j5$3I4W2i4K6u0r3k6r3g2@1j5h3W2D9M7#2)9J5c8U0M7^5z5o6M7%4z5o6f1I4

修改前面的git仓库路径为自己的

开始同步

```
gclient sync
```

需要等很久 打开网络流量监控看下

![](https://bbs.kanxue.com/upload/attach/202205/832784_AB2AUUEA5HP3REY.png)

## 切换源码分支

同步完成切换分支 先去看本地的flutter版本

你的flutter环境下的`/flutter/bin/internal/engine.version`可以找到

比如我的 `57d3bac3dd5cb5b0e464ab70e7bc8a0d8cf083ab`

757K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6X3L8s2g2@1N6r3g2J5i4K6u0r3k6h3&6Y4K9h3&6W2i4K6u0r3N6s2u0W2k6g2)9J5c8U0f1%4k6o6y4T1j5h3x3K6k6r3b7#2j5$3t1#2j5U0m8W2y4o6j5@1j5h3t1%4x3r3f1%4j5X3x3^5j5e0m8V1z5r3y4X3x3o6R3K6j5h3t1`.

```
cd src/flutter
```

```
git reset --hard 57d3bac3dd5cb5b0e464ab70e7bc8a0d8cf083ab
```

```
nizz@ubuntu:~/work_space/flutter/engine_compile/src/flutter$ git reset --hard 57d3bac3dd5cb5b0e464ab70e7bc8a0d8cf083ab
Checking out files: 100% (1993/1993), done.

查看当前commitid

```

确认开始同步

gclient sync --with_branch_heads --with_tags --verbose

## 如何切换源码版本

```

```

先 进行 `git pull` 操作 更新 `git log` 找到该版本信息

```
git reset --hard 857bd6b74c5eb56151bfafe91e7fa6a82b6fee25

```

开始同步

```
gclient sync --with_branch_heads --with_tags --verbose
```
