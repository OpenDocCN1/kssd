# [原创]使用010Editor对AndroidManifset二进制文件进行修复

说明

做Android ctf的时候遇到了个AndroidManifest修复的问题，记录一下修复过程，大佬勿喷(#^.^#)

0x01 现象

安装apk提示错误

```
Failure [INSTALL_PARSE_FAILED_UNEXPECTED_EXCEPTION: Failed to parse /data/app/vmdl891914658.tmp/base.apk: Corrupt XML binary file]
```

![](https://bbs.kanxue.com/upload/attach/202002/590753_X46ZSV5XP35W2FK.jpg)

AndroidManifset应该是解析失败了

使用 010Editor 进行查看

![](https://bbs.kanxue.com/upload/attach/202002/590753_ESK28NV5G5TYNTE.jpg)

直接打开文件，如果没有配置套用模板是无法分析二进制格式的

可以在 7ccK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2K6N6$3g2W2N6s2y4U0j5i4m8W2i4K6u0W2j5$3!0E0i4K6u0r3x3o6p5H3k6h3c8A6N6r3!0J5i4K6u0r3M7X3g2H3L8%4y4A6N6r3!0J5P5g2)9J5c8Y4c8W2L8i4m8D9j5i4c8W2M7#2)9J5c8R3`.`. 上下载AndroidManifest的模板

![](https://bbs.kanxue.com/upload/attach/202002/590753_SFQEBC35NU9FZTV.jpg)

或者直接在 010Editor上进行模板配置

![](https://bbs.kanxue.com/upload/attach/202002/590753_RFTXVR2YG8SMT2D.jpg)

![](https://bbs.kanxue.com/upload/attach/202002/590753_96N5FVVGFNE6E97.jpg)

然后套用模板

![](https://bbs.kanxue.com/upload/attach/202002/590753_H78CVSQMXT6T8SE.jpg)

![](https://bbs.kanxue.com/upload/attach/202002/590753_NX7FAYVJ7VCKTWD.jpg)

这样010Editor套用AndroidManifset模板就成功了

0x02 AndroidManifset 二进制文件格式

参照大神发过的格式图 https://bbs.pediy.com/thread-194206.htm

![](https://bbs.kanxue.com/upload/attach/202002/590753_5BNRVWTVVXZK3AM.jpg)

然后和010Editor中模板中分析出来的节点进行对应发现

![](https://bbs.kanxue.com/upload/attach/202002/590753_JZU4U6HCT2C78XY.jpg)

Chunk Type 固定值 0x0001C0001 对应的是 scSignature

![](https://bbs.kanxue.com/upload/attach/202002/590753_3VFE2PNED8EA5WC.jpg)

Style Pool Offset 样式池的偏移量 相对于StringChunk开始处 应该是 0

![](https://bbs.kanxue.com/upload/attach/202002/590753_Q3C5VX7UEXGRG8H.jpg)
