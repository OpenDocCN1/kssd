
# [翻译]mona插件帮助命令汉化

因为 `mona.py` 这个插件很棒 (`windbg` (需要 `pykd`) 和 `IMD` 都可以使用)

但是因为英文命令帮助不利于一目十行，所以翻译了一下。

陆陆续续居然花了两天 (除去上课时间, 虽然现在已经没几节课了)

翻译完后又配合着官方文档手册仔细校对了，增加了很多东西，比如例子说明

可以把 `mona` 原插件命名为 `mona_en.py` (运行 `!mona_en` 就是英文插件)

把这个汉化插件命名为 `mona.py` (运行 `!mona` 就是中文插件)

插件目录: `Immunity Debugger\PyCommands\`

这样就可以两个版本同时使用 (英文版升级到最新版，翻译版拿来看帮助命令)

当然也可以直接帮翻译版的帮助复制到最新版帮助 -> 最新版就汉化了

## 其他提醒

每个命令都可以使用全局选项

设置工作目录:

```
!mona config -set workingfolder xxxxxx
```
