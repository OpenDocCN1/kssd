# [原创]Python编写的网站组件指纹扫描工具

之前在其它地方发表过,都是我;13年写的,我也不知道当时写了些啥,现在只是想留个记录在pediy,万一哪天发疯不干了......

这是一个使用Python语言编写的开源网站组件指纹扫描工具,该工具运行在Python2.73环境下,Windows平台,它支持如下功能:

> 1.自动提取互联网URL，根据GoDumpDomainSelect.py模块里面的配置启动URL，自动提取URL模块包含在aSearchDomain.py里边;这里包含了广度搜索URL的大小(for index in range(2000):)在aSearchDomain.py中间搜索这句Python代码.
>
> 2.根据aSearchDomain.py得到的结果自动提取URL相关的顶级域名和二级域名;该模块包含在(aExtractDomain.py).
>
> 3.网站组件指纹分析模块(aAnalyizeDomain.py, GoDumpAnalyize.py)，这部分参考了网站组件扫描信息站点这里的扫描方式.4.增加了自动对fofa上面已有结果的二次过滤扫描.5.以上所有功能都做了去重处理，并且过滤掉了图标、工作文档、压缩文档、PE等等这一系列的文件格式.
