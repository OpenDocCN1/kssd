# [原创]给任意EXE加皮肤，封装为单文件（含源码）

使用流程 - loaddll.exe+需要挂皮肤的exe 生成->1.txt 根据需要编辑txt ->build.bat 生成skin,exe

基本上可以给所有EXE添加！
========================================================================
     导入表修改: LoadDll 项目概况 C
========================================================================
loadDll.c -> laoddll.exe
------------------------------------------------------------------------
Usage = loaddll [Executable file] Or into
------------------------------------------------------------------------
用法= loaddll [可执行文件] 或者拖入可执行文件
========================================================================
    动态链接库 : LoadSkin 项目概况 Vc++
========================================================================
LoadSkin.cpp -> loadSkin.dll
主函数：TUFU
Skinh.h -> 你懂的！
========================================================================
    应用目录 : bin  外部说明
========================================================================
makeisn.exe//ISN脚本文件制作文件

icon.ico  //isn封装图标

Skinh.she //必要的皮肤文件

1.txt //执行loaddll.exe 后自动生成的isn脚本文件方便自己添加需要一起打包的文件

build.bat //制作isn单文件
