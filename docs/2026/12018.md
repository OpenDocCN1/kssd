# [原创]VS2012 ddk驱动编译与虚拟机联机调试设置（已更新）

一．安装Windows Driver Kit 8
1首先在计算机上安装VS2012 (12很容易安装，安装步骤略),然后到官网上下载Windows Driver Kit 8 下载地址：
550K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8X3#2K6k6r3&6Q4x3X3g2E0K9h3y4J5L8%4y4G2k6Y4c8Q4x3X3g2U0L8$3#2Q4x3V1k6\*7K9q4)9J5k6r3y4F1i4K6u0r3N6$3W2F1k6r3!0%4M7#2)9J5c8X3S2S2M7X3c8%4j5i4u0W2i4K6u0r3K9r3R3^5y4e0t1K6y4U0u0Q4x3V1j5`.

下载完毕点击 ![](https://bbs.kanxue.com/upload/attach/201303/475718_4p6twpj9j2zaq67.jpg)进行安装。安装模式有两种，一种是在线直接安装，一种是下载安装包到本地，之后再进行安装 (如果网速够快建议直接在线安装。下载安装包安装，会多一步操作，由于刚开始不知道那一步操作，运行2012报一个错误，也无法进行调试设置，所以搞得我头大了好几天！！！)
1.  在线安装，直接默认路径即可，安装完应该没有问题的，本人没试过。
2.  说下下载安装包安装吧：下载完全部文件307M，打开文件夹点击其中的![](https://bbs.kanxue.com/upload/attach/201303/475718_lrnzx4w18icqt7t.jpg) 文件安装，一路OK，最后点击finish完成安装。安装完别急着打开2012，再次点![](https://bbs.kanxue.com/upload/attach/201303/475718_73lyg8u202hk2tf.jpg) 这次选择在线安装，过程中会有两个选项，一个yes...,一个no，我选了yes,具体什么意思，不清楚，嘿嘿。然后next,进度条很快读完。到此Windows Driver Kit 8就已经安装成功了，这时打开2012，会发现新建项目中多了一些Driver项目，菜单栏上也多出了一个菜单选项DRIVER。
二 驱动项目与虚拟机com串口联机调设置
  怎样在2012下直接生成DDK驱动项目我目前还没搞出来，不过可以通过2012把我们写的驱动加载转换成2012可以运行的项目
  就让我们用最简单的Hello级DDK驱动演示下吧，写好Hello.c  makefile和sources文件。
然后运行2012
 ![](https://bbs.kanxue.com/upload/attach/201303/475718_5hfvmp7hhz9a724.jpg)
选择 文件打开Convert Sources/Dirs...
找到驱动所在的文件夹，选中sources文件
![](https://bbs.kanxue.com/upload/attach/201303/475718_42ls6vdxxx489ex.jpg)
这时2012就会对我们的驱动项目进行自动转换了，转换完成后还会弹出对话框询问你是否查看有关转换细节的记录，这里随意。

然后在上边工具栏中
![](https://bbs.kanxue.com/upload/attach/201303/475718_k35lhsrk3400phs.jpg)

选中驱动程序所要运行的系统环境，可惜，不支持XP系统平台！！！
按F7快捷键编译连接即可生成我们想要的.sys文件了。另编译Vista以上版本系统平台驱动文件时makefile文件是可有可无的，没有此文件编译器会自动为我们加上相关定义！(Starting with the Windows Driver Kit (WDK) for Windows Vista, it is no longer required for the Makefile file to be in every project. By default, the Build utility includes the Makefile.def if the Makefile file is not found in the project. Any custom tasks that are required in a project should be moved to Makefile.inc as appropriate.)

![](https://bbs.kanxue.com/upload/attach/201303/475718_5qemn5gg0c4hly2.jpg)
驱动文件生成完成，现在开始进行虚拟机连接设置：
![](https://bbs.kanxue.com/upload/attach/201303/475718_2arjdghpr2xzl2z.jpg)
点击菜单选项 DRIVERTestConfigure Computers
 ![](https://bbs.kanxue.com/upload/attach/201303/475718_miz7wrqojxm1rqk.jpg)
点击“Add New Computer”
![](https://bbs.kanxue.com/upload/attach/201303/475718_xz7ypzs6wt13kfy.jpg)
在Computer name:中输入你真实的计算机的名字(不是虚拟机中计算机的名字)
下边三个选项选择最后一项”Manually configure debuggers and...”，手动配置调试
![](https://bbs.kanxue.com/upload/attach/201303/475718_0ydftkd36xflzku.jpg)
按上图配置即可，Connection Type选为Serial (串口)
(波特率)Baud Rate 115200
(管道)Pipe勾选
(重连接)Reconnect勾选
(管道名)Pipe name  \\.\pipe\com\_1
这几个选项根据你虚拟机设置来设置
最后点击完成。

打开虚拟机进入系统后（调试模式）(按我以前的步骤是先在虚拟机中运行驱动，然后附加下断点，会导致2012卡死掉，后来摸索发现在没有加载驱动之前就让2012把系统断一下，这样就连接成功了！驱动运行之前设置断点也会成功！)

再在vs2012中选择菜单栏中的  工具附加到进程
 ![](https://bbs.kanxue.com/upload/attach/201303/475718_b9soay89qnkmje5.jpg)
![](https://bbs.kanxue.com/upload/attach/201303/475718_jle2rrcowl239xg.jpg)
传输:Windows Kernel Mode Debugger
限定符:就是我们添加的计算机名

点击附加 2012会自动进入调试状态，
此时显示Waiting to reconnect...;
![](https://bbs.kanxue.com/upload/attach/201303/475718_551myau6339zv88.jpg)
点![](https://bbs.kanxue.com/upload/attach/201303/475718_iqmhz2bpryekjaf.jpg) 把虚拟机断下，这时在源代码中就可以下断点了！完成断点设置输入g命令或F5，让虚拟机走起。当你运行虚拟机中驱动程序到相应代码位置就是会被2012断下。(经过这几天摸索，2012不用关闭重新打开也是可以地！)
 ![](https://bbs.kanxue.com/upload/attach/201303/475718_vf554e789ut4tjj.jpg)

把我们生成的hello.sys
![](https://bbs.kanxue.com/upload/attach/201303/475718_mgxxilnpiwtscot.jpg)
文件放到虚拟机中，用INSTDRV工具安装启动
 ![](https://bbs.kanxue.com/upload/attach/201303/475718_csqs2oiuwwsk8hg.jpg)

 ![](https://bbs.kanxue.com/upload/attach/201303/475718_h5ajh0f9ofavqc5.jpg)
 ![](https://bbs.kanxue.com/upload/attach/201303/475718_szvut72ogkip8o3.jpg)

在2012中驱动项目的符号文件是不用特殊指定的，编译器会自动找到符号文件所在位置。

系统符号我知道的其中一个方法是用命令的形式来加载或下载符号文件
如果系统中没有单独安装符号文件，在Debugger Immediate Windows窗口中输入命令
.sympath srv\*c:\MyServerSymbols\*
\*c:\MyServerSymbols\*之间的路径就是你要保存的符号文件的路径

如果你已经下载并单独安装了符号文件可以用如下形式的命令来指定：
.sympath c:\MyRegularSymbols 回车后显示
![](https://bbs.kanxue.com/upload/attach/201303/475718_mp6eu0k7kwb55ut.jpg)
我们再   .reaload一下(重新加载符号文件)
![](https://bbs.kanxue.com/upload/attach/201303/475718_r8w8gy9xrb4edni.jpg)
哈哈，这里输入命令还有智能提示哦！
![](https://bbs.kanxue.com/upload/attach/201303/475718_2f5xhe0mkeblqgy.jpg)
部分符号文件没有找到也属于正常情况，指定目录下没有这些驱动的符号文件！可以指定到官方网站去下载符号文件
