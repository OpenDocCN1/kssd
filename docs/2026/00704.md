
# 在VMWare虚拟机中实现`trw2000`的调试功能

现在的电脑配置越来越高,一般都只装2K或XP,很少装个又占地方又不稳定的98.可是98对咱们广大cracker,unpacker以及汉化爱好者却是一个必须的系统,它的万能断点`hmemcpy`的确给偶等破解菜鸟带来极大方便.因此,如果能利用虚拟机来进行破解,不仅安全,方便,而且也不占地方,用不着划出一两个G专门装98,费用实报实销,真是不错.

第一步,安装VMWare虚拟机

第二步,安装98虚拟系统

第三步,安装虚拟机的自带工具

第四步,修改配置文件,用记事本等文本编辑工具打开扩展名为`vmx`的文件,大小是1K左右.在文件尾加上

```
vmmouse.present = "FALSE"
svga.maxFullscreenRefreshTick = "5"
```

第五步,把`trw2000`的所有文件拷到根目录下,双击运行`trw2000`

这时一般机器会呈死机样,但其实没有死,连续按`ctrl+m`,直到弹出`trw2000`的运行界面.这样就OK了,

在测试中发现,每次系统第一次启动时,只有先按`CTRL+M`才能调出`trw2000`,之后按`CTRL+N`也能调出.

在VMWare4.5.1中通过测试.
