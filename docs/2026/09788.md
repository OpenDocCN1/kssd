【经验总结】
  1、注册码必须有“－”号，长度大于3
  2、这给个源码，不然说还真不好写
  l=左边注册码的长度
  a = Asc(Mid(Text1.Text, l, 1))
  b = Asc(Mid(Text1.Text, l - 1, 1))
  zc = ""
  For i = 1 To l
    s = Mid(Text1.Text, i, 1)
    a = a And Asc(s)
    b = b Or Asc(s)
    If b > 128 Then
      b = 256 - b
    End If
    k = ((a \* b) Mod 52) + 65
    zc = zc + Chr(k)
    c = b
    b = a + b
    a = c
  Next
  这样就可算出注册码的右边
  3、如果注册码的右边字符＝计算所得的字符，注册成功
  4、可以有N组注册码，呵呵
