核心思想：当程序开启DEP后，可以通过VirtualProtect函数修改内存属性，达到绕过DEP的目的
VirtualProtect函数：
```
BOOL VirtualProtect(
LPVOID lpAddress, // 要更改属性的内存地址
DWORD dwSize, // 要更改属性的内存大小
DWORD flNewProtect, // 内存的新的属性，设置为0x40时为可读可写可执行
PDWORD lpflOldProtect ); // 内存原始属性的保存地址
因此如果栈如下布置的话，就可以将shellcode所在内存区域设为可执行模式。
VirtualProtect(
shellcode所在内存空间起始地址，
shellcode大小，
0x40,
某个可写地址)
```
注意：
参数中包含0x00，因此漏洞函数改为memcpy函数
