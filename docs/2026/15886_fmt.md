
# [原创] 在 Windows 搭建 Frida Hook 环境碰到问题

## 1. 安装 Python

安装 Python（最新的版本就可以），看看 `pip` 是否是内部指令，如果不是则安装 `pip`。我在百度上找的安装教程：[d89K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6B7K9h3&6Y4P5h3q4F1i4K6u0W2j5X3q4A6k6s2g2Q4x3X3g2U0L8$3#2Q4x3V1k6S2M7Y4c8A6j5$3I4W2i4K6u0r3x3K6f1^5y4e0M7H3k6U0k6S2z5o6t1^5k6e0W2U0k6e0b7$3x3U0c8X3j5K6f1$3i4K6u0W2K9s2c8E0L8l9`.`.](https://bbs.kanxue.com/elink@1f0K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6B7K9h3&6Y4P5h3q4F1i4K6u0W2j5X3q4A6k6s2g2Q4x3X3g2U0L8$3#2Q4x3V1k6S2M7Y4c8A6j5$3I4W2i4K6u0r3x3K6f1^5y4e0M7H3k6U0k6S2z5o6t1^5k6e0W2U0k6e0b7$3x3U0c8X3j5K6f1$3i4K6u0W2K9s2c8E0L8l9`.`.)

## 2. 安装 Frida

安装 `frida`，需要安装两部分，分别是：`frida`、`frida-tools`。

### 2.1 安装 frida

在 `cmd` 中输入指令 `pip install frida`，成功后会有提示，我就不多说了。

针对安装不成功的情况，我们进行手工安装。方法是这样的：下载 [`frida-12.0.7.tar.gz`](https://bbs.kanxue.com/elink@96fK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6X3K9h3I4W2M7#2)9J5k6i4m8&6N6r3S2G2L8X3S2G2M7%4c8W2k6q4)9J5k6h3!0J5k6#2)9J5c8Y4m8S2j5$3E0S2k6$3g2K6i4K6u0r3y4U0c8Q4x3V1j5J5y4W2)9J5c8X3y4S2x3o6M7K6x3K6c8S2z5e0R3&6y4U0p5&6x3o6p5K6j5$3p5K6k6o6y4V1y4o6x3I4z5o6R3H3k6U0c8S2x3h3p5K6x3X3f1&6k6h3p5$3k6X3q4X3z5o6N6X3j5U0c8W2y4X3u0X3y4U0u0T1y4o6l9H3k6W2)9J5c8X3k6J5K9h3c8S2i4K6u0V1x3e0u0Q4x3X3f1H3i4K6u0W2y4#2)9J5k6i4c8S2M7W2)9J5k6h3N6*7)，解压该文件，会看到 `setup.py` 文件，在 `cmd` 中输入指令 `python setup.py install`。然后去你安装的 `python->lib->set-packages` 路径下查找是否有 [`frida-12.0.7-py3.6-win-amd64.egg`](https://bbs.kanxue.com/elink@b7aK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6X3K9h3I4W2M7#2)9J5k6i4m8&6N6r3S2G2L8X3S2G2M7%4c8W2k6q4)9J5k6h3!0J5k6#2)9J5c8Y4m8S2j5$3E0S2k6$3g2K6i4K6u0r3k6o6N6Q4x3V1j5J5j5#2)9J5c8X3f1K6y4r3t1H3z5o6y4X3k6U0f1I4x3h3b7K6x3e0t1K6k6o6m8S2x3$3f1&6k6e0S2U0y4$3g2T1k6h3p5&6y4o6M7&6x3U0N6V1j5U0b7I4y4K6m8V1x3U0k6V1y4o6u0U0y4e0c8V1k6U0R3$3y4e0N6T1y4W2)9J5c8X3k6J5K9h3c8S2i4K6u0V1x3e0u0Q4x3X3f1H3i4K6u0W2y4#2)9J5k6s2m8&6x3#2)9J5k6e0k6Q4x3X3c8%4K9h3&6Q4x3X3c8S2L8h3b7$3y4q4)9J5k6h3g2Y4k6H3`.`.) 文件（我的版本是 `python3.6`，其他版本请自行查找下载）。如果没有该文件，下载该文件到 `python->lib->set-packages` 路径下。然后在 `cmd` 中输入指令 `pip install frida`，如果出现以 `Requirement already satisfied` 开头的提示，说明就成功了，第一步工作完成。

### 2.2 安装 frida-tools

在 `cmd` 中输入指令 `pip install frida-tools`，该操作可能会卡在某个位置不能向下进行，不要紧，关闭程序多操作几次就可以了。该条指令主要是安装这几个文件包，分别是 `frida-tools-1.1.0.tar.gz`、`frida-12.0.7-py3.6-win-amd64.egg`、`prompt_toolkit-1.0.15-py3-none-any.whl`、`Pygments-2.2.0-py2.py3-none-any.whl`，成功后就会提示 `Successfully installed frida-tools-1.1.0 prompt-toolkit-1.0.15 pygments-2.2.0`。
