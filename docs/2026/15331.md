# [分享]发布个java反编译软件jda

作者是搞android开发和逆向安全的，逆向安全是主业，用jeb2.2.7用的很不爽，特别是分析某稍微大一点的软件后卡和老报OOM，后面又没有更好的破解版jeb，刚好去年年底辞掉工作后有空就开始编了个反编译软件，加上疫情期间没出去找工作，所以就在这段时间内写了个反编译工具jda。
搞这个东西花了作者挺多时间的，宁愿分析X梆的vmp也不愿搞这个软件，搞vmp花不了很多时间，而这个软件的算法让我很头疼，发布了这个软件后就要去找工作了，很久没有收入都没钱买米了...，以后更新可能不在这里发布了，在头条我的帐号“月影湖心”发布，包括怎么使用、有什么功能和更新...都在我的头条帐号发布。
#### 一、主要功能
1、支持apk、dex、jar文件反编译。
2、支持apk包含多个dex。
3、支持直接重命名类、方法、属性、本地变量。
4、支持基本的反混淆。
...
由于作者技术比较菜，软件界面做的丑，且反编译时某些方法还有一定的问题，以后再慢慢更新修复。
