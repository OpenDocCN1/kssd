# [原创][征文]一路走来

好几年了...
   2000年什么季节我已经想不起来了,那时我正在度过小学最后一个暑假,我到乐山小叔那里第一次认识了电脑这玩意儿,那时候的电脑大多都还是爬在地上工作的,不像现在个个都是亭亭玉立,当时那里正在搞培训,我也自然是为着这个奔去的,遗憾的是我已想不起来第一眼见到那玩意儿的心情了,因为当时我的心情正为眼前所见的很多东西而激动颤抖着,所有一切我在农村不知道且看不到的东西,那是我第二次进城,激动得我当天下午就骑着单车跑了很多地方,大概折腾了4个多小时,我才终于跟着公车找到回去的路.暑假很快就过去了,快得让我现在都已经想不起来是怎么过的.
   初中2年级时,我到了一个小城市走读,那一年发生了一件很大的事情,我老爸咬咬牙终于狠心给我买了一台电脑,那台电脑至今都还好的,只不过内脏都被我换下来当古董保存着,机箱和键盘至今都还在用,且键盘上的字母那么多年了都还没有消失,这是现在一般键盘无法比拟的,至少我现在打出的每一个字都是在默写.那是的我很激动的,很多人是无法体会那种农村家的孩子突然拥有了自己梦寐以求的东西的感受的,那是一种很不寻常的感觉,那是一种没有夹杂着一丝攀比炫耀的真正甜美的感觉,因为对于一个家境不算好的农村家庭来说那并不自然。电脑买回来的第一天我就连夜玩了一通宵的剑侠情缘，第一次知道，原来通宵玩游戏会头晕的。很多事情在那以后就开始改变了，至少我大多休息时间都改为做在电脑前。
   初中3年级的时候，我回到家乡念初中最后一个年级，当时我是自作主张的，因为虽然我们那里山清水绣，但是其实初中教学别人都说很差的，所以我们那里好多人家都把孩子往外放，即使这样会增加非常多的家庭负担，望子成龙。我的决定很是让家里人恼火，我们那个大家族还没有过本科大学生，就我小叔念过专科，大家都把目光和希望聚集在我们几个身上，我的决定自然会让家里人恼火，也一定会恼火。那学期，我花了非常多的时间在电脑上，导火线就是看雪出的一个crackme集和一个入门教程还是什么的，我想我已经把那些名字留在岁月里了。 当时都是不能上网的，有一次机会我到现在这个小城里，逛便了所有电脑铺子，终于找到了几张中意的光盘买了下来，因为上面有softice for win9x,还有很多其他软件工具类。回家后我便开始照着教程里面的做，很久以后我才基本上能按按F10什么的，对那个黑白镶嵌的屏幕，熟悉而陌生，更不要提壳这样的东西了，绝对不知道是个什么概念，一下子那么多的无知，终于激发了我想深入学习的志气。从而解决难题。人的一生都是在制造难题和解决难题中度过的，能解决比别人多的难题就比别人成功。在努力很久后，我终于追出了一个明码比较的软件的注册码，很激动的，那也是我最后一个追注册码的软件，因为不久后我就习惯了爆破，而又不久后我就不破解了，因为我在学习VB和汇编，当时我写过一个软件，那软件直到很久以后我才整理了一下放到了网上再也没有过问之后，但是想起来都是很兴奋的，那时什么都不容易，什么都很困难，什么都不懂。还好当时的我并不能了解这些，并不会多想，只是一味的做。所以才会没有那么多的精神负担。很快我也将这年花光了，花得比以往都大手笔，都充实。那一年还有影响我一生的小事，那就是上帝给我开的一个玩笑，本来我会以优异成绩进入高中而进入很好的重点班级的，结果中考的时候数学机读卡没填，导致白白丢了36分，结果最后终于还是因为差3分没进入好的班级，事后上帝笑着对我说，东西是要分三六九等的。
  高中一年纪由于住校，我终究还是不能没完没了的玩电脑了，也正式在那一年我正式接触网络了，我在网吧里做过网页，在网吧里开过传奇私服，在网吧里帮别人申请QQ号码，在网吧了熬了通宵，在网吧里修过电脑。也因此我在网吧里可以免费上网。农村孩子是不会有多少钱去挥霍的，况且也不忍心用那钱去挥霍，阔在眼前，疼在心间。那一年我知道了好多以前不知道的事情，也开始认识了delphi,慢慢的由于头脑里的很多问题都在突然之间被我看穿了，所以那一年认识提高了非常多，且认识了一个和我一样爱好的朋友。然后对于破解我实在几乎要忘记了。
   高中二年纪了，我转校到了乐山，在那里我对事物的看法由于来自各方面的影响有些变化，尤其是对学校里正在常识教会我的东西，我想我这头脑毕竟是不太灵活了，老师成天到晚的教课，早上7点多奔赴现场，晚上10点往回走，对于这样的时间开支我实在不太好忍受，再加上小叔那里还有一台电脑弄得我心痒痒，于是我开始没天理的熬夜，每天晚上都要到晚上2点，很快我的整个人疲惫了，我开始在课堂上睡觉，我在课堂上构思，那时我认识了壳，且在写我的第一款壳，且好多时候就在课堂上构思。终于我的成绩直线下降。我开始考虑除上大学之外的路子，并写过一篇长达7页的关于这个问题的凌乱文字，结果让老师看了之后庭下大怒，且让我小叔也跟着到了办公室埋头认错般的做了好一阵子。那一年也过的相当艰难，时间上的不足让我失去了好多东西，同学，朋友。后来我终于还是决定退学了。。。
   高中三年纪。。。没有高三了，我又回到了家乡无所事事，但依旧玩电脑，网络有了，突然觉得这个社会进步了好多，这一年我依旧是在电脑面前度过的。这一年家境终于开始有了一点转机。所以我并不需要疲于生计。所以学到了不少东西。且知道一个道理，那就是在应用中学习才是王道。所以我便在写很多不同的小工具其中包括我的第二款第三款壳中学习，我渐渐的渐渐的最后终于有了自己的理想。我在网络上开始看很多的资料，开始潜深水，开始穿梭于不同的路由路径之间。就这样又过了一年，时间就是奔去的水啊，一去就不回来了。
   又是一年，很多事情之后，我终于又明白了一个道理，那就是需要有长远一点的眼光，需要有更长远一点的打算，毕竟一辈子很长，于是我便开始学习C++,由于已经习惯了自学，所以我便一开始便装了一个vc2005开始摸索，也不知道这个是好是坏，反正看到是最新的，我不断的看别人的代码，不断的写代码，连蒙带猜终于没过多久就基本上能写点小程序。这一年在电脑上过得很平淡，因为我在考虑人生的问题，考虑生计问题，在确立我的人生观。
   一直到如今，多少岁月了，我像我也记不清了吧，所有的都是个模糊的记忆，童年也就这样消失了，我不在乎过去的日子是对还是错，因为已经没有意义了。我也不在乎对于别人来说我这几年学习的是否太少了，因为也已经过去了，还有好多辛酸的难忘的事就都不要说了吧，一路走来。

   菜鸟依旧是菜鸟。。。
