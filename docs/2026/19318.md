# [原创]说说我的嵌入式学习经历，给后来的同仁们一点参考

本人以前非计算机专业，纯属个人兴趣爱好，在看雪潜水了几年，一直想写点东西，可是在各位大虾面前拿不出什么像样的东西。在嵌入式 加百力 版主的带领下，我也写点自己的经历给需要的朋友。
08年介入嵌入式领域，说说我的学习经验。
第一步，08年上半年，系统学习了ARM，以S3C2440为ARM9例，用的是三星公司原装开发板,包括ARM汇编指令，BOOTLOADER(类似BIOS)的编写。从事硬件开发的朋友一定要学好BOOTLOADER的编写，从事软件开发的朋友一定要学好ARM汇编,C。
第二步，08年下半年，学习了UCOS-II以及在S3C2440上的移植和开发。实时嵌入式操作系统是一个方向。VXWORKS太贵,非民用,也没机会接触,放弃.相信UCOS—II一定可以赶上VXWORKS的.
第三步，08年下半年，学习了LINUX在S3C2440上的移植和开发，驱动的开发，应用程序的开发。
09年至今，准备玩WINDOWS CE或WINDOWS MOBILE。
刚把VC++6.0和MFC学完（以前从事硬件，未曾做过软件开发，所以恶补了一下计算机系统知识、汇编，C、VC++、高级WEIDONGS编程和软件工程），感觉真的很累。
总结一下，需要掌握的东西太多了 。特别是C，汇编。

各位要介入的朋友们，要做好受苦受累的准备。
