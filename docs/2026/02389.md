# 彩票快车破解手记(copyyour兄要的，来看看吧） (1千字)

彩票快车破解手记

作者：孙锋
主页：http://sffs.533.net

我今天在网上得到的copyyour（黑狐）老兄的一个问题，是关于“彩票快车”的破解，从学校回来后就在机器上跟踪起来了，但是我没想到作者在进行注册码的判断时加了好多的陷阱，本来我以为追到的数字就是注册码呢，谁知道，他还把得到的注册码的顺序又另排了一下，最后才给你正确的注册码。下面我写写追踪的过程，希望可以给copyyour兄一个答复。


这个软件是根据机器硬件生成注册号，然后算注册码，如果你注册成功了，除了修改lotteryrapido.ini外，还生成一个注册数据文件cpkcreg.dat文件，里面存的就是注册信息，因为我用的是bpx
hmemcpy来跟踪的，所以跟踪的过程麻烦了些。

工具：    TRW2000 1.23注册版

步骤：
1、执行“彩票快车”后选择“软件注册”，然后输入自己的用户名，电话，email后，点生成用户码，我使用的是默认，直接用生成用户码，得到的是11723152，然后填入注册码12344321（程序的注册码要求是8个数字，其他的不对）。

2、启动TRW2000，下BPX HMEMCPY，然后用F5返回程序空间，点注册被TRW2000拦截到。
3、按F12共计14次（因为按5次弹出注册失败的对话框），然后一直F10到下面的地址，这个时间和按键次数很长和多，直到：

0167：004A8C1A CALL 004086EB处，下 D EAX得到注册码，为11558461。
4、说明：在跟踪的过程中得到的35217864 和55111684都不是正确的注册码，只有在弹出对话框之前不远处，才得到正确的注册码，这也许就是程序的陷阱所在吧。

5、如果要直接得到注册码，可以直接下BPX 4A8C1A，然后直接D EAX即可。
6、收工。
7、黑狐兄可以把cpkcreg.dat和lotteryrapido.ini拷贝到别的机器上试试，看看能不能在别的机器上用。
