
# 请帮我做一个“EldoS Thumbnailer”的注册机，好吗？

(425字)

这是一个用来查看图标和图像的30天试用软件，程序每次启动时首先取得注册表中的`HKEY_CURRENT_USER\Software\EldoS\Thumbnailer\AppData`这一项的值，然后判断是否已过试用期限。如果把注册表中的该项键值删除的话，则程序会重新计算试用时间。但是我比较烦它每次启动时都弹出一个对话框，所以想请各位高手予以破解。

另外，需要告诉各位的是，该程序如果检测到`SoftICE`存在则不运行。
