# 如何判啾Asprotect加

如何判啾Asprotect加?我碚:
(1)先用Procdump32去分析,若Section Name除了.data和.rsrc外,]有其他的Section Name且有多.data那它有八成是Asprotect加的.

(2)绦Imp\_list,看它的Address.txt,RVA是否跟件的某一Section的VO一,若一忧Address.txte的函颠原的很好,那它乎可\_定是Asprotect1.0以上加的,且有.idata段.

(3)若RVA不符合,且Address.txt一\_始是GetProcAddress後面o接著一大堆空白函,到最後才出F一系列有系y的函盗,@就是]有.idata只有.radta段.

(4)若有.idata,你看它的Address.txt中的函,若Shell32.dll,Comdlg32.dll,Version.dll它的成T都是ya,那它就是Asprotect1.06或1.07

(你可以⒖Azpr3.21,Aw95prV.1.2,WinNarigatorV.1.91等)
