c0000ba::m0001b6 函数有问题，将其中的
fixed (int\* pInt = &(this.f00034d[num5]))
{
      p10[(int)(pInt + 1)] = num2;
}

Reflector 反出来的是 p10[(int) &(this.f00034d[num5])++] = num2;
要改为
int num10 = f00034d[num5];
f00034d[num5] = f00034d[num5] + 1;
p10[num10] = num2;
