## 简介

Style XP 是更改 Windows XP“皮肤”的工具。通过使用皮肤，它可以改变 Windows 的外观界面，而且还提供了皮肤制作软件。下载安装的过程非常简便，在机器重启后便可令你的 Win XP 外观焕然一新，整体感觉要比 Winblinds 看上去要轻盈淡雅。未注册只能用 30 天。

Style XP 的反跟踪代码做得很有特色，虽然比不上 aspr 等“大牌”程序，但只花费了很小的代价，就基本达到了 anti-debug 的效果。

## 反跟踪分析

### SEH 反调试

原来是用 SEH 来实现 anti-debug 的，那好办，下命令 `SXD *`。这条命令是让 `WinDbg` 忽略所有的异常，只在 debug 窗口输出信息，类似于 soft-ice 中的 `faults off` 命令。再下命令 `GN`，即“Go Unhandled Exception”（执行，但不处理异常情况）。满以为搞定了，谁知程序居然自动退出了！看来还有暗桩。

### 反跟踪逻辑总结

将上面代码总结一下：

1. 记录一个时间点。
2. 产生一个子线程，并且再将本身的主线程挂起，直到子线程结束。
3. 在子线程中计算是否注册以及是否过期，并且使用 SEH 技术，用 `int3` 断点指令触发 debugger（如果有的话），这时会有时间上的延迟。
4. 当子线程退出，比较第一步的时间点，如果大于 15 秒，就说明本身被调试。（因为调试时要下断点，会有时间延迟）

要去掉暗桩也容易，将 `cmp eax, 00003A98` 改为 `xor eax, eax` 即可。这样就可以调试子线程了。
