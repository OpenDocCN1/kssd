# [原创]windows2003 VPN服务组件调试跟踪

应该算是一个很好的逆向分析教材了，花了我差不多一个星期时间，希望对大家有用
windows 2003 命令行启动vpn服务如下：

```

sc config RemoteAccess start= demand
net start RemoteAccess

:netsh ras set user test_user permit
:netsh ras ip  add  range 192.168.111.1 192.168.111.10

netsh routing ip nat install
netsh routing ip nat add interface "本地连接" full
```
