# [原创]Linux下的VScode的Rust开发调试环境搭建

### **六、设置debug调试环境**

需要让vscode重新选择项目区域，就是刚建好的项目kanxue ，重复如下图的步骤，找到kanxue文件夹。

![](https://bbs.kanxue.com/upload/attach/202105/754744_XV47GTWUDQZ9ZAF.jpg)

![](https://bbs.kanxue.com/upload/attach/202105/754744_E2JS5VZH46SB5C4.jpg)

点击创建launch.json文件

![](https://bbs.kanxue.com/upload/attach/202105/754744_H389EDTM22NHTJJ.jpg)

把如下代码替换默认的：

```
{
    // 使用 IntelliSense 了解相关属性。 
    // 悬停以查看现有属性的描述。
    // 欲了解更多信息，请访问: a6bK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4L8#2)9J5k6h3#2A6j5%4u0G2M7$3!0X3N6q4)9J5k6h3y4G2L8g2)9J5c8X3k6%4L8r3W2F1K9#2)9J5c8W2)9K6c8X3I4A6L8X3E0A6k6q4)9K6c8o6R3K6x3o6x3^5y4H3`.`.
    "version": "0.2.0",
    "configurations": [
        {
            "type": "lldb",
            "request": "launch",
            "name": "Debug",
            "program":  "${workspaceFolder}/target/debug/${workspaceFolderBasename}",
            "args": [],
            "cwd": "${workspaceFolder}"
        }
    ]
}
```

点击debug测试下看是否正确

![](https://bbs.kanxue.com/upload/attach/202105/754744_YH54TDXFDVHZH35.jpg)

那debug就设置好了，后续按F5就有用了。重要说明下，设置debug的时候会生成一个.vscode的文件夹，这个文件夹就是控制debug的，需要在项目内，这个就是在kanxue的项目内。若脱离这个项目，debug就运行不了。所以新建的项目也需要重新添加debug。

![](https://bbs.kanxue.com/upload/attach/202105/754744_SNFTYXEH749FNFY.jpg)
