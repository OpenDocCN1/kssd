换思路后，我们得到这个公式：

```
#!/usr/bin/python
# -*- coding: utf-8 -*-
from sympy import *

x=Symbol('x')
y=Symbol('y')

#((x - y) << 2) + x + z = 0xEAF917E2
#((x - y) << 1) + (x - y) + x + z = 0xE8F508C8
#((x - y) << 1) + (x - y) + x - z = 0x0C0A3C68

#化简，先从后两个公式相减得到z.
#z=1853187632=0x6e756630

#4x-3y==3908372680-1853187632=0x7A7FA298
#4(x-y)+x=0x7C83B1B2

print (solve([4*x-3*y-0x7A7FA298,4*(x-y)+x-0x7C83B1B2],[x,y]))
```
