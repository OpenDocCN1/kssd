
# 羊了个羊通关修改思路

## 抓包配置

最近几天一款 WX 小游戏火爆出圈，"无良"开发商故意设置游戏难度，让大家对此上头，疯狂刷广告。自己尝试通关 40 多次，蹲马桶蹲的痔疮都快犯了，无奈最后还是选择走捷径。

这里主角当然是 Fiddler（Windows 下方便截图展示），手机端可以使用 HTTP catcher/Stream 抓包，原理思路相同。

首先下载 Fiddler（不做过多描述），一路正常安装就行，安装完成后进入设置：`Tools->Options`。

![](https://bbs.kanxue.com/upload/attach/202209/676504_V4SMPUKNAT7V7QU.jpg)

![](https://bbs.kanxue.com/upload/attach/202209/676504_DG7W7X24BMH3QNT.jpg)

下面一步是重点，这里一定要勾选后安装下证书：

![](https://bbs.kanxue.com/upload/attach/202209/676504_HU3EKSB7WJ7PDR8.jpg)

![](https://bbs.kanxue.com/upload/attach/202209/676504_P3G3QVYNU6223GV.jpg)

我们这里不需要设置模拟器，或者使用代理参数代理到手机。

这些设置完成后，就可以进入 WX 小程序进行操作了。

注：这里还有一个坑，就是如果你使用最新版本的 WX，你会发现无法抓包小程序数据，这里需要回滚下 WX 版本，我这里是把 WX 设置成 3.5.X.XX 版本。

## 修改思路

打开 Fiddler 后进入游戏，然后开始：

![](https://bbs.kanxue.com/upload/attach/202209/676504_UDEAUESJ7SPAD2U.jpg)

这里可以看到 2 个 `map_id`，不难理解这个其实就是关卡的编号。

初始第一关 `id` 为 80001，一直不变；第二关后 `id` 变为 90015，顾名思义 9 月 15 号……

拿到 2 个 `map_id` 后，就可以直接上手撸 FiddlerScript 了：

![](https://bbs.kanxue.com/upload/attach/202209/676504_566S8TT89476Q29.jpg)

找到 `OnBeforeRequest` 类直接进行判断，如果 `map_id` 为 90015，则把 `id` 强制设置为 80001，这样就可以实现进入第二关卡后，其实还是第一关卡，随便点一点即可通关。

![](https://bbs.kanxue.com/upload/attach/202209/676504_GTR88RAKMCS7TF6.jpg)

```
if (oSession.url=="cat-match.easygame2021.com/sheep/v1/game/map_info?map_id=90015") {
    oSession.url = "cat-match.easygame2021.com/sheep/v1/game/map_info?map_id=80001";
}
```

或者粗暴设置为通过（00分00秒会不会太假？），设置完成后，则直接加入羊群成功。

![](https://bbs.kanxue.com/upload/attach/202209/676504_QTDYJCUS94WCFKB.jpg)

```
if (oSession.url=="cat-match.easygame2021.com/sheep/v1/game/map_info?map_id=90015") {
    oSession.url = "cat-match.easygame2021.com/sheep/v1/game/game_over?rank_score=1&rank_state=1&rank_time=0&rank_role=1&skin=1"
    //oSession.url = "cat-match.easygame2021.com/sheep/v1/game/map_info?map_id=80001";
}
```

其中 `rank_time` 后面填写即是时间（以秒为单位）。

最后 `Save Script` 后，重新进入小程序即可。

![](https://bbs.kanxue.com/upload/attach/202209/676504_QCQY5BWCVTVZVE9.png)

![](https://bbs.kanxue.com/upload/attach/202209/676504_DYTNNAPR6GSXKHJ.jpg)

大致通关思路就是这样，手机实现方法一样，通过软件抓到包后设置下相应改变的数据即可。

昨日维护后，此方法还是有效。
