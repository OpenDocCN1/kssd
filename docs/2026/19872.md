## 2. 计算

`(md2 * ep1 + epInput) * md0 mod n == (md2 * ep2 + epInput) * md1 mod n`

`=>`

`epInput = (md2 * md1 * ep2 - md2 * md0 * ep1) * (((md0 - md1)^-1) mod n)`

得到 `(02D23461BA71B50AF182DC76E5A7C726F5, 07BE013AF19BD185BCD20BB341EA31298B)`
