### 一 查看自己设备支持的ABI
不同的 Android 设备使用不同的 CPU，而不同的 CPU 支持不同的指令集。CPU 与指令集的每种组合都有专属的应用二进制接口 (ABI)。
那么我们自己手上的设备支持什么ABI呢？
<a href="elink@5bbK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6V1k6i4k6W2L8r3!0H3k6i4u0Q4x3X3g2S2L8X3c8J5L8$3W2V1i4K6u0W2j5$3!0E0i4K6u0r3L8X3c8C8i4K6u0r3k6%4g2A6k6r3g2K6i4K6u0r3j5h3u0A6M7H3`.`.">ABI官方文档</a>
#### 1.查看Android设备的CPU信息
uname -a 或者 getprop ro.product.cpu.abi
```shell

4329 ◯ adb shell

Linux localhost 4.4.88-g3acf2d53921d #1 SMP PREEMPT Thu May 17 20:37:50 UTC 2018 aarch64

/system/bin/sh: adb: not found
127|walleye:/ $ getprop ro.product.cpu.abi
arm64-v8a
walleye:/ $
```
AArch64是ARMv8 架构的一种执行状态。这说明我手机架构是arm64-v8a

### 二 让android项目编译出指定架构的.so文件
我们已经知道了自己的手机的CPU架构、所能支持的ABI。那么如何让我们创建的Android项目编译出指定架构的.so文件呢？
从<a href="elink@244K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6V1k6i4k6W2L8r3!0H3k6i4u0Q4x3X3g2S2L8X3c8J5L8$3W2V1i4K6u0W2j5$3!0E0i4K6u0r3L8X3c8C8i4K6u0r3k6%4g2A6k6r3g2K6i4K6u0r3j5h3u0A6M7H3`.`.">ABI官方文档</a>中可以看到，可以通过以下方式，指定abi构建
![图片描述](upload/attach/202104/907919\_59KWTX9E3PAS6XV.png)
```
android {
compileSdkVersion 30
buildToolsVersion "30.0.3"
defaultConfig {
applicationId "com.example.myeasymd5"
minSdkVersion 16
targetSdkVersion 30
versionCode 1
versionName "1.0"
testInstrumentationRunner "androidx.test.runner.AndroidJUnitRunner"
externalNativeBuild {
cmake {
cppFlags ""
}
}
ndk {
abiFilters 'arm64-v8a','armeabi-v7a','x86','x86\_64'
}
}
```
