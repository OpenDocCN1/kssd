IDA 支持不同的[指令操作数](https://bbs.kanxue.com/elink@912K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5k6i4S2Q4x3X3c8J5j5i4W2K6i4K6u0W2j5$3!0E0i4K6u0r3j5X3I4G2k6#2)9J5c8X3W2Y4L8%4u0K6i4K6u0V1N6r3W2H3i4K6u0V1L8$3k6Q4x3X3c8@1K9r3g2Q4x3X3c8%4k6h3g2C8i4K6u0V1y4o6k6Q4x3X3c8V1K9i4y4S2M7%4y4W2L8h3u0D9P5g2)9J5k6r3!0H3k6i4u0S2L8X3c8Q4x3X3c8J5k6i4m8J5k6i4y4W2L8Y4c8S2N6r3W2G2L8W2)9J5c8R3`.`.)和数据项表示法。不过，只有最常用的才会在右键菜单中列出或分配热键。想象一下，你在固件二进制文件中发现了一个看起来像浮点数值表的区域：

![](https://bbs.kanxue.com/upload/attach/202312/767964_PMG5H3K7F3Z8FJ6.webp)

您可以通过切换[十六进制视图](https://bbs.kanxue.com/elink@6fbK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5k6i4S2Q4x3X3c8J5j5i4W2K6i4K6u0W2j5$3!0E0i4K6u0r3j5X3I4G2k6#2)9J5c8X3W2Y4L8%4u0K6i4K6u0V1N6r3W2H3i4K6u0V1L8$3k6Q4x3X3c8@1K9r3g2Q4x3X3c8%4k6h3g2C8i4K6u0V1x3K6S2Q4x3X3c8Z5k6i4S2Q4x3X3c8$3K9h3g2%4i4K6u0r3)中的表示来确认它看起来是否合理：

![](https://bbs.kanxue.com/upload/attach/202312/767964_6777YETHMZED2FP.webp)

但在反汇编中，它只是普通的十六进制字节：

![](https://bbs.kanxue.com/upload/attach/202312/767964_5Q6QF5D58G6Y6Q9.webp)

如何制作精美的浮点数值表？您有两种选择：

1. 创建整数项或整数[数组](https://bbs.kanxue.com/elink@c7dK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Z5k6i4S2Q4x3X3c8J5j5i4W2K6i4K6u0W2j5$3!0E0i4K6u0r3j5X3I4G2k6#2)9J5c8X3W2Y4L8%4u0Q4x3X3c8@1K9i4m8Q4x3X3c8G2k6W2)9J5k6s2c8Z5k6g2)9J5k6s2N6W2k6h3E0Q4x3X3b7I4x3q4)9J5k6s2N6G2M7X3E0A6L8X3N6Q4x3X3c8%4K9i4c8Z5i4K6u0V1j5i4u0J5j5i4W2K6i4K6u0r3) (本例中为 dwords) 然后将其表示法更改为 floating-point（浮点数） (Edit > Operand type > Number > Floating point):
   ![](https://bbs.kanxue.com/upload/attach/202312/767964_PK6W8P6V3746RTH.webp)
2. 使用Options > Setup data types… 对话框(快捷键 Alt–D)可直接创建浮点数据. 按住Alt键位，按钮对应的字符串相应字母会出现下划线，此时按相应的字母，则相当于按下对应的按钮（如 F 表示Float(浮点)或 U 表示Double(双精度浮点数)），可以快速选择要创建的数据项：
   ![](https://bbs.kanxue.com/upload/attach/202312/767964_53MK9AE4JQBQQHN.webp)
   像往常一样，创建一个项目后，可以使用 \* 来创建一个数组

![](https://bbs.kanxue.com/upload/attach/202312/767964_AQSGWWMN7RW5CX3.webp)

注：Tbyte（又称 ten-byte）对应于原始 8087 浮点协处理器及其后继者中使用的传统 80 位[扩展精度](https://bbs.kanxue.com/elink@466K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6W2L8W2)9J5k6i4N6A6K9$3W2H3k6h3c8A6j5g2)9J5k6h3!0J5k6#2)9J5c8Y4N6A6K9$3W2Q4x3V1k6q4P5s2c8W2L8X3c8W2k6q4)9#2k6Y4m8J5k6h3y4A6M7$3W2G2L8R3`.`.)格式。除了传统的 DOS 或 Windows 软件外，很少使用这种格式。
