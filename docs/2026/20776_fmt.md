
# 20周年征文 | 纪念逝去的青春岁月--做看雪学生二十年

## 做看雪学生二十年

在疾驰的高铁上，我正翻着手机，无意中看到看雪论坛群里的二十周年征文令，突然意识到认识看雪也快二十年了，思绪难平，十年前为生计奔波没有参加十年征文，这又过了十年，是应该写点儿什么来纪念过往的青春岁月，也算是对看雪的感谢，因为一直到现在还在受着看雪的“恩惠”，知恩图报，君子之道。

说是写征文，也算是对自己成长历程的一个回顾吧。废话少说，言归正传。

我从小就算是一个特立独行的孩子，特别爱看书，但一般农村家里穷，买不起书，所以就借书看，如果上学路上碰到地上有张带字的纸，也会捡起来看看什么内容，印象最深的是在一家屋后的垃圾堆里，经常能捡到一张一张的日历，每张都有一个名人故事，于是我就基本每天都会过去翻一下垃圾堆，若能发现新的日历就如获至宝的收藏起来好好看，一年下来攒了两百多张名人故事，订成一本书。说到现在好像跟看雪还没关系？别急，等我长大点儿了就有联系了。

上了初中以后社会上开始流行街机游戏，慢慢的有了俄罗斯方块掌机，最后初三看到了带键盘的小霸王游戏机，这就是我接触的第一个电脑了――因为有键盘！初步印象那里面好像就有`BASIC`语言编程，可惜不懂，只知道练习键盘打字，因为自己没有这么昂贵的游戏机，为了练习打字，自己画个键盘天天放在桌子上敲桌子，我想有不少朋友都跟我一样吧？

就这样开始朦胧地迷恋上了“电脑”，上了县城的高中以后，已经是96年了，慢慢地街上开始出现电脑游戏厅，不过价格很贵，每小时十块，若上网就三十块，当然是拨号上网了。平时就利用省下来的零花钱买《电脑爱好者》杂志看，跟看小说一样精彩，然后看到一些电脑操作就去电脑游戏厅练习，主要是修改注册表，更改系统配置等等，玩得不亦乐乎。

慢慢地因为接受书本报纸上的新思想以及自己的特立独行，加上学校中发生的各种事件，产生了对当时教育的反叛心理，以至于决定放弃高考，准备开始自学之路，刚开始因为对电子感兴趣，所以看电工学，后来在旧书堆里淘到一本周明德老师的《微型计算机原理》，这个是以`Z80`处理器来讲解的，看了一年多才懂了点儿基本的逻辑电路和程序指令，很可惜这本书后来被我遗弃在珠江边上了，因为太重，背不动了，为了活命，只得忍痛割爱，就如红军过草地，丢掉轴重一样。

然而我就这样看书看了三年竟然都看不懂一个小程序，直到有一天，在《电爱》上看到一个用Dos的`Debug`编程的小工具，一下豁然开朗，如同打通任督二脉一样，回过头再看那些程序（都是汇编语言）都看懂了！然后就在Dos里编程实现，真的应该感谢微软，Dos独有的开放性，可以很方便的学习编程，特别是汇编语言，Dos真的是最好的平台，几乎可以完全控制所有硬件，而且简单的一个`Debug`命令行就可以用来学习编程，多么方便啊。很多人估计还记得用`Debug`命令清除CMOS密码的指令吧：

```
－ O 70 10
－ O 71 00
```

简单两条指令就可以破解掉BIOS密码，真的很神奇耶！所以能出现CIH病毒也就不奇怪了，他可以清除BIOS的程序。而正因为这好奇和兴趣，让我挺过了迷茫的三年，正式入门汇编语言，也深深地爱上了汇编语言，为了锻炼自己，我还用汇编写了一个俄罗斯方块游戏，源代码直到现在还保存着我的硬盘里。

后来参加工作了，在网吧里就是去逛论坛，大概是03年，知道有个看雪网站，挺多有意思的资料和帖子，也会下载来上夜班时候看（那时候的工作是生产线维修不良显卡，所以有电脑，也就是简单的一块主板、一颗CPU、一个内存条、一个显示器，没有机箱），那时候大部分业余时间都在练习编程了。软件反向工程（为避险以此代称，你懂得）仅仅是在欣赏阶段。

又由于自己会点儿汇编，后来为了转入程序员行业，入职了单片机开发工程师，这单片机算是软硬结合的完美产物了，可以得到极大的成就感和满足感，因为经过自己开发的产品可以送到千家万户使用（说穿了就是电视机和空调的遥控器），直到有一天，有位美女同事学习英语，她告诉我这个软件比较贵，试用版试用几下就过期了，问我能不能研究研究，我当时拿出英雄救美的姿态接下了这个“大活”，于是乎，此水帖终于开始不是灌水，也让我真的叩开了看雪的大门。这时候才记起来竟然没有注册会员，好在是开放注册，会员名还借鉴了“CCDebuger”大牛的ID，起了个“AsmDebuger”，倒也符合我热爱汇编语言的特性。接下来的一个月里，自己几乎每天都是泡在论坛里，几乎从零开始系统学习反汇编知识。所有能下载到的工具都下载到硬盘里（在这里特别要感谢我们伟大的linhanshi林版，他的辛勤劳动为我们收集了很多有用的工具），也阅读了大量的帖子，学习了思路，最后终于完美解决问题，这也一下让我在女同事眼里的形象瞬间高大起来，那一段时间每位女同事见面都好像在行注目礼一般，幸福感爆棚，这就要感谢看雪！于是乎趁热打铁就有了第一篇帖子，也是唯一的一个精华贴。仍然记得第一个留言鼓励的sessiondiy，我都称他是S大，还有combojiang等等大牛，让我真的受宠若惊啊，兴奋了几天没睡好觉。后来心血来潮做了一个`Crackme`小程序，引来yingyue大牛的一顿狠批，我是诚惶诚恐地虚心接受，好在有“小子贼野”、“NBA2005”、“不问年少”、“netwind”、“menting”，特别是神鬼莫测的S大的鼓励和参与，让我感到万分荣幸，也越来越喜欢看雪的如此热烈开放无私的氛围了，在这里跟在少林寺学武功一样，大家可以互相切磋，有时候我们菜鸟就在旁边观战，也会让自己的功力也跟着有所长进。

逛的久了就记住了论坛的大牛“ccfer”、“海风月影”、“forgot”等等等等，如同看武侠小说一样，看他们每个主题和回帖就如同一场精彩纷呈的比武斗法，如痴如醉，在后来也遇到了Shoooo、Nooby被Ban ID的事件，那段时间好像争论的比较热烈，突然就失去几位高手，如同被逐出师门的师兄，心里也酸酸的。渐渐地就慢慢释怀了，“国有国法、院有院规”，只有这样看雪才一直走到今天，也让大家学会容忍，学会收敛。

话说回来，我也慢慢地接到一些软件研究课题，既锻炼了自己又补贴一下穷困的生活，也就更离不开看雪了，虽然鉴于你懂得的原因，没有再发研究文章，但却一直在默默支持论坛，因为浏览学习回帖也是一种奉献啊（^\_^）。平日里印象最深的还是对林版那勤劳的发帖感到佩服，真的值得尊敬的一位版主，然而有一天听看雪发帖说林版身体出了状况，这才体会到林版的辛苦，直到现在，一直都把林版当作自己的偶像，为了技术可以无私奉献数十载，不求回报，得林版实乃看雪之幸啊！最近林版身体又有点儿不舒服，我又不好意思打扰他（他甚至把住址和电话都发给我了！），只能借此征文，来祝福林版早日恢复健康，让我们能很快看到一个每天都在发帖子和朋友圈的辛勤园丁，也希望等您恢复健康之后，我们能约个时间，过去拜访一下您，让您接受一位看雪会员的朴实的当面的感谢。我觉得看雪大哥是不是应该为二十年来论坛里贡献最大的几位版主或会员颁发纪念金牌，以资鼓励呢？

时过境迁，安全问题也上升到了国家层面，而基于对产权的保护，讨论技术也似乎越来越多的禁忌，各个论坛随着时间推移慢慢地消失不见了，曾经的百花齐放已然不再，唯独已经开始商业化运作的看雪还保持初心，勇敢前行。我想，看雪一定会成功，也一定会一直为广大会员和安全界服务，因为这无私的共享精神，因为那些大牛们的持续活跃，因为广大普通会员的默默支持。

希望在下一个二十年里有机会面对面的拜会各位心目中的大牛，聊聊“武林”的奇闻轶事，而看雪也应该出一本书，书名就叫做《看雪论剑》，内容就是二十年来的武林各路高手的“争斗”，演绎的“爱恨情仇”，满足我们这些菜鸟的“追星”心理。

最后，祝看雪越办越好！
