
# [原创]od逆向分析栈溢出shellcode

## 概述

逆向一个栈溢出实例，正向开发一个可以实现同样功能的项目。

主要功能：利用栈溢出产生的 SEH 异常处理，运行传入的参数里面的字符串化的 shellcode，进而加载 dll 并运行。

仅供用于学习研究栈溢出实现原理，严禁用于其他用途。

原来没有 shellcode 这方面经验，通过 `od` 逆向分析具体实例，再结合 github 找一些资料。最终完成了利用栈溢出加载指定文件 shellcode 化的 dll 文件。

### 4. 具体分析上图 `3.010018A0` 函数

![](https://bbs.kanxue.com/upload/attach/201805/652409_YMBPVQKEXRBNUX9.png)

```asm
010018B8  |> /880C02        /mov byte ptr ds:[edx+eax],cl
010018BB  |. |8A48 01       |mov cl,byte ptr ds:[eax+0x1]
010018BE  |. |46            |inc esi
010018BF  |. |40            |inc eax
010018C0  |. |84C9          |test cl,cl
010018C2  |.^\75 F4         \jnz X3.010018B8
```

这里是实现栈溢出的关键所在，由于传入的 `-r xxxx` 参数长度太大覆盖栈空间正常数据，使 `3.exe` 程序运行出现 SEH 异常，主要观察下面 2 图栈溢出前后对比：

![](https://bbs.kanxue.com/upload/attach/201805/652409_79GWTX4XRTU48PT.png)![](https://bbs.kanxue.com/upload/attach/201805/652409_5RSJDS6R3M7XHVM.png)
