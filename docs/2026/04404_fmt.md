## 《电脑报2001年配套光盘软件》-ACDSee 4.0 Trial Version和FotoCanvas Lite Trial Version时间限制破解

《电脑报2001年配套光盘》附带了不少好软件，但有不少都是未注册版本，有一定限制，前面破了其中一个DART Karaoke Studio，今天有又破了ACDSee 4.0 Trial Version。

【软件版本】4.0  
【文件大小】11.3M  
【适用平台】Win9x/Me/NT/2000  
【软件简介】高性能的看图程序，支持 BMP,GIF,JPG,TGA,TIF 等各种常见的图形文件格式，图片打开速度极快。你还可以直接用它查看动画 GIF。它还可以为你的每一个目录建立一个相册。

### （一）ACDSee 4.0 Trial Version时间限制破解

### （二）FotoCanvas Lite Trial Version破解

破解完`ACDsee.exe`，发现FotoCanvas Lite Trial Version的运行也有时间限制，索性一块破掉！

运行程序`FotoCanvasLite.exe`，参照上面的方法先找到那个出现提示过期的`CALL`：

```
:0041AAF3 3BC3
  cmp eax, ebx（这里比较，改为cmp eax, eax会怎样，呵呵）
 :0041AAF5 7414
                je 0041AB0B（这里跳则可绕过过期提示）
 :0041AAF7 8B4574
mov eax, dword ptr [ebp+74]
 :0041AAFA 50
            push eax
 :0041AAFB E860C00100

00000004
 :0041AB03 85C0

 :0041AB05 0F84C4020000

```

这里有两种改法，要么将`:0041AAF3 3BC3 cmp eax, ebx`改为`:0041AAF3 3BC0 cmp eax, eax`。使用UltraEdit打开`FotoCanvasLite.exe`文件，查找：`3BC374148B4574`，修改：`3BC074148B4574`。要么将`:0041AAF5 7414 je 0041AB0B`改为`:0041AAF5 E911000000 jmp 0041AB0B`。使用UltraEdit打开`FotoCanvasLite.exe`文件，查找：`3BC374148B4574`，修改：`3BC3E911000000`。推荐使用第一种改法！
