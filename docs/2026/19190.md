# [原创]我自己几年的心得对RFID一些看法

首先写我自己的心得先来致敬RadioWar 因为是他们让我懂一点 这方面知识
先来普及一下基础知识：
RFID即为射频识别。NFC近场通信。很多人把NFC和RFID混为一谈，但实际上NFC你可以把他可以理解为以RFID技术为基础的一种产品，
当然我今天先说下NFC吧
可能我说RFID ，有这个范围可能扯大了，那我们就说下平时用的公交卡，银行卡，当然你没有用也没有关系。就读书的时候所用的饭卡，水卡之类的，基本都属于NFC近场通信的范围。我陪伴着各种卡走了2年多，至于普及的知识我也不多说了，首先你单纯的觉得，可以学习，心里有想歪了，靠在这一门去做违法的事情赚钱，那你绕道吧。举个列子吧：比如XX团伙盗刷银行卡，都最多，银行卡里不会存太多数据，当然我也不知道，我也不想去做，但是我的猜想银行卡里面就只有2组数据（名字+卡号）所有的数据都存在银行内部的服务器上，所有你知道卡号和名字，就可以复制他人的银行卡，知道卡还不行，还要知道密码，后面的都大家应该知道了，也不用我说了。
当然你想要去做违法的事情不可缺少很多基础。
NFC这个词离我们很近，非常近，触手可及。他让我们跟方便了，所有的捷径都有一定的风险，就要看你是否敢去承担这个风险，过高的安全技术只是可以让你降低风险，也不能能完全让你避免，比如你电脑装卡卡巴X，36X，XXX，你装了这么多有什么用的，还不是中毒，假如你不装就会天天中毒， 大概就是这个意思了。
入门基础：软件免费送百度下就可以了，不用去某宝上花个2.30元去买，源码人家都公开了，做一个道德的人，既然拿别人的软件起码也要被别人以个署名吧，别把所有的版权改成自己的就以为是自己的。硬件：ACR122U(122U有好几种我也不解释了 去某宝上买吧最正常的价格都是165到180这个之间)  进阶了 可以用下其他的比如PM3（价格是分2中定制版和国产版所谓的山寨货定制版价格可以说固定在2300元 国产版的500到800元）其他设备我也不多说了 种类太多 当然你有钱也可以去买一套发卡设备。
