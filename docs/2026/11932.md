
# [原创]CSGO透视自瞄各种C++姿势

首先说一下，我这个源码我不知道能不能达到商业辅助的台阶，但是希望一些不良份子不要拿出去卖，我开源只是想分享一下这一方面的东西，因为我百度了一下CSGO对于这块的资料，基本是没有的，或者是少之又少。另外，我这份代码是基于`imgui`画的菜单，然后功能是`HOOKD3D`画的，网上基本上是没有的。所以你们懂得。废话我也不多说。。。

对于我这份源码说一下：首先是透视用的是矩阵透视，绝非那种烂大街的反三角函数。骨骼的话，CT和T的骨骼点不一样，所以画出来的骨骼T正常，CT不正常。像完善的话就自己去写一个阵营判断，然后根据阵营去话骨骼。最后，本人不是什么大佬，兴趣研究而已，所以代码写得并不是很叼炸，很多东西都是为了实现而去临时写，没有优化。。
