## (2) `Hook`

め岬的某淌竭是不能用因ASProtect有留下`Hook`,如何移除它呢?那你得感xASProtect,因樗晟频`SEH`系统嬖V你,重_始的SEH `MessageBox`中得知它留下的`Hook`位址`00C1C6D8`,用HexWorkshop打_已さ奈募,查找`D8C6C100`你lF在`RVA 64FAC,64FB0`中各有一,用W32Dasm去反Mg,查找`0064FAC`,你lF有如下的程式:

```asm
CALL [0064FAC]
```

等r於

```asm
CALL 00C1C6D8  <-- 在我已さ奈募惺遣羞@位址的程式a
```

比^原程式lF原`00C1C6D8`只是一`RET`,真是o聊!好了!那你 知道如何移除@`Hook`吧!我的方法是找位址放`RET`,再`RVA 64FAC,64FB0`指向@位址,我x在隔壁即`RVA 64FB4`改:

```asm

RVA 64FB0 00C1C6D8 --> 00464FB4
RVA 64FB4 00 --> C3
```
