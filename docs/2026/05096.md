# [原创]VirtualBox无法正常退出分析

现象：
每次VirtualBox启动后，然后关闭，进程管理器里面居然还有，死活退不出去！！！
你知道，向我这种经常搞windbg调试的人，怎么受得了啊~~每次都去进程管理器杀VirtualBox进程
搞得我对VirtualBox印象很差啊！！！

今天我实在受不了了，我决定看一下，到底发生什么原因了：

3、~\*kv ,打印出所有的堆栈信息，根据堆栈信息找到发生死锁的线程。
