# [分享]antiVM ida pro插件-快速识别anti-vm行为

- 基本描述：

ida pro 插件，安装之后快速识别代码中的anti操作。以防万一，使用前可以先保存idb快照。目的是减少分析人员对抗时间。

- 基于Yara-Rules项目，扩充yara规则。
- 使用al-khaser做测试和丰富特征，项目提供编译版本供大家测试。
- 可以通过快捷键 Ctrl + atl + A 执行，也可以在plugins目录下允许。
