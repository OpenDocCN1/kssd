0x01.安装Textobot.deb

前置申明，下文TBROOT是指本产品的根目录。
Textobot.deb就是一个普通的Cydia插件安装包，需要注意的是它依赖RocketBootstrap这个插件。所以如果你的手机还没有安装RocketBootstrap这个插件，就把TBROOT/iOS/RocketBootstrap-1.0.7.deb和TBROOT/iOS/Textobot.deb一并拷贝至手机/tmp目录，然后依次执行下述命令：

- dpkg -i /tmp/RocketBootstrap-1.0.7.deb # 可选，如果还未安装才需要；
- dpkg -i --force-overwrite /tmp/Textobot.deb

等安装过程出现“finished, press CTRL+C to exit...”时，就表明Textobot正确安装至手机了。我们可以通过如下命令验证Textobot的后台服务是否正在运行:

- iPhone:~ root# ps -ef|grep server
- 0  5068     1 ... /usr/libexec/hybrage-iserver
- 0  5070  5068 ... /usr/libexec/frida-server -l 0.0.0.0

另外，如果你的iOS版本低于10.0，则还需要安装TBROOT/iOS/Util/SimulateTouch-iOS8\_9.deb才可以使用点击、滑动等操作的API。

至此，iPhone手机端的环境就部署好了。如果你对Textobot手机端的组件也感兴趣，那就接着往下看吧。不感兴趣可以忽略下面的内容直接跳到0x07.下篇再见。Textobot手机端一共分为5大部分，如下图：

![](https://bbs.kanxue.com/upload/attach/202001/461021_YF8QB8996D8QF8S.jpg)

1. 管理器Textobot.app负责TB插件的状态切换，比如start、stop、uninstall等，同时也提供一个简易的shell工具；
2. 注入库textobot.dylib负责获取进程的状态数据并生成事件汇报给调度器；
3. 启动器textobot-server负责启动Textobot后台服务，用于重启手机重新越狱之后使用；
4. 注入器frida-server负责发送TB插件的JavaScript代码至指定的进程运行；
5. 调度器hybrage-iserver负责整个TB插件体系的驱动工作，它自身集成了Frida、Python等核心模块；

0x02.管理器Textobot.app

![](https://bbs.kanxue.com/upload/attach/202001/461021_27SWH4Q5FDA9KV3.jpg)

管理器提供执行/保存/加载shell命令、启动/停止/卸载TB插件、检查Textobot后台服务是否正常运行等功能。
虽然管理器App目前还非常原始和不完善，但是在设计理念和功能上，我们是将它对标CydiaApp的。

0x03.调度器hybrage-iserver

![](https://bbs.kanxue.com/upload/attach/202001/461021_V6V277FKKQBST5Y.jpg)

调度器是Textobot的核心驱动，它接受VSCode和管理器的HTTP请求、注入库的IPC事件、控制frida-server执行命令等核心任务。
TB插件的Python代码就执行在调度器中，TB插件的JavaScript代码由frida-server负责发送至textobot.dylib所在的进程执行。

0x04.注入器frida-server

![](https://bbs.kanxue.com/upload/attach/202001/461021_6D4DBK5P7GXVR6S.jpg)

Frida是2015年面世的一个跨平台开源逆向框架，经过将近5年的发展，现在已经非常强大。包括JavaScritp代码远程注入、Native调用封装等等非常重要的功能，这也是我们选择它作为核心执行引擎的关键原因。
通常的用法是Frida客户端跑在电脑端、frida-server跑在手机端，Textobot为了简化电脑端的部署，我们把完整的Frida统一编译进手机端了，这样脱离电脑端一样可以使用Frida的完整功能，方便进行TB插件管理。关于Frida更详尽的信息，请参考它的github项目文档和源码。

0x05.注入库textobot.dylib

注入库textobot.dylib就是一个普通的deb tweak插件，它是调度器事件源发送者，包括进程启动、退出、UI更新等事件都会汇报给调度器，然后由调度器发送给TB插件处理。同时注入库还导出了一些实用API方便JavaScritp调用，比如点击、滑动等API。这样一来，我们就可以真正做到只用动态型脚本语言开发具有deb一样功能的插件，并且维护、更新方便许多。

0x06.启动器textobot-server

最开始是没有设计启动器这个工具的，而是采用了iOS Daemon的机制，这样越狱后可以重新自动激活，使用起来更方便。但是，从iOS 11开始，系统对后台进程的资源使用限制非常严格，这对于集成了Frida、Python这样庞大模块的进程而言，进程会因为资源限制而被系统Terminated Due to Resource。而通过root用户手动启动就没有这个限制，所以为了更稳定的使用Textobot服务端，采取了手动启动的模式。如果手机重启重新越狱之后，就需要通过textobot-server命令重新启动服务。如果嫌每次连接ssh麻烦，推荐使用TBROOT/iOS/Util/MTerminal-1.4.5.deb，这样在手机端就可以输入命令，记得装完之后执行uicache刷新主界面图标，否则MTerminal的图标不会出现在SpringBoard界面。
