# [原创]为你的Notepad打上只属于你的烙印

**制作目的：**
1、看完了《加密与解密》二次开发那一章，需要练手巩固一下
2、毕竟是第一次二次开发，总得留下什么做纪念，不是嘛(⊙\_⊙)？

**选择缘由：**
1、上家公司有一位BOSS逆向很牛，当时他向我们介绍逆向这门学问时，曾举过自己改造Notepad的事情（给其增加置顶与半透明功能），让人好生羡慕，所以二次开发Notepad也有纪念的意味；
2、在Ollydbg调试时，用记事本记东西比较方便，不过没有置顶、半透明功能，导致经常需要切换来切换去，比较麻烦，所以给记事本增加这些功能还是比较有意义的；

**补充说明：**
下面讲述时假设你已经比较熟悉PE结构，最好还看过“二次开发”那一章节；

**言归正传：**
我们知道二次开发有2种方式，第一种是直接修改可执行文件，在上面添加功能；第二种是为可执行文件导出扩展接口，调用我们用高级语言写的程序来实现需要的功能；因为有练手的目的，所以我们打算二者都采用；

相对于原先记事本的具体改变是：
1、在菜单栏中增加了“高级”菜单
2、其中“置顶”、“透明度”及“说明”三个子菜单功能，我们是通过直接修改可执行文件完成的；
3、同时为记事本增加了DLL调用接口（插件式），方便采用高级语言二次开发，DEMO中的DLL为“高级”菜单增加一个“计算器”菜单项，点击后打开系统计算器；
4、所有需要保存的设置信息我们均采用注册表保存（如置顶及透明度配置）；

要实现上述的功能，我们必须先找到合适的点能够插入我们的代码，比如调用CreateWindow的地方，又或者消息循环处理WM\_COMMAND的地方，不然一切都是白搭；

从中我们发现NPInit调用结束后会判断返回值是否为TRUE，如果是FALSE则表示失败，并直接退出；

因而我们可以在这里进行第一步的截获操作，使其jmp到我们指定的地方去，在那里先调用NPInit，随后判断返回值是否为TRUE；若TRUE则接着调用我们额外添加的初始化函数，用于初始化用户的置顶及透明度设置；

因为我们的主要功能是通过菜单点击调用的，所以我们还需要继续查找消息循环中WM\_COMMAND消息的处理逻辑；对刚刚找到的消息循环处理过程入口下条件断点（[ebp+0x0C]==WM\_COMMAND）并单步跟踪，不难发现，Notepad对于WM\_COMMAND的消息处理专门封装了一个名为NPCommand（01002B87）的函数来处理，同时发现该函数对于未知命令ID的处理逻辑位于地址010032ED处，具体如下：

为了可持续开发，我们的目标不仅仅是本次的二次开发，我们还需要为未来的第N次开发做好规划；所以在地址空间布局上我们采用增加单独段的方式去扩展，而不是缝隙法；为此我们新增一个.mynpd数据段及.mynpc代码段，同时将来布置代码时，新增代码段中的各个代码块之间的间隔布置的大一点，以免未来扩充或者改动时发现没有空间，只好jmp来jmp去，那样不管在性能还是代码可读性上都比较差一点；

最后就是完成上述功能的全部代码改动及分析：
首先我们跳转到原先call NPInit的地方（0100297B），采用JMP 01016000指令来替换，使其跳转到我们新增的地址空间中去，然后我们在01016000地址处新增代码，具体如下：
;初始操作逻辑处理处
01016000  CALL    mynotepa.NPInit               ;先调用原先的NPInit函数
01016005  TEST    EAX, EAX
01016007  JE      mynotepa.01002980             ;如果NPInit()==FALSE,则直接返回原逻辑处

0101600D  PUSH    DWORD PTR DS:[hwndNP]         ;参数是hwndNP
01016013  CALL    mynotepa.01016401             ;InitMyNotepad：用于初始化置顶、透明度设置

01016018  PUSH    DWORD PTR DS:[hwndNP]         ;参数是hwndNP
0101601E  CALL    mynotepa.01016A00             ;调用我们插件DLL的初始化函数

01016023  JMP     mynotepa.01002980             ;处理完后再返回到原逻辑处
其中DS:[hwndNP]是Notepad窗口的句柄，在跟踪NPInit的时候，可以看到其创建完窗口后会把句柄保存到hwndNP中，我们在初始化的时候正好可以拿来用；

接下来我们修改原地址010032ED处的指令为JMP 01016050，使其跳转到我们扩展的命令处理逻辑处，具体如下：

0101605F  PUSH    DWORD PTR SS:[EBP+8]                  ;接下来所以命令处理函数，我们均以hwndNP为参数，所以直接在开头调用下，免去每次调用的麻烦

;目前demo中实现了打开计算器的功能，具体见DLL实现代码
0101615D  PUSH    DWORD PTR SS:[EBP+10]                 ;lParam
01016160  PUSH    DWORD PTR SS:[EBP+C]                  ;wParam
