
# [原创] IDA 动态调试 Android 应用

这里使用的是 macOS 系统，当然 Windows、Linux 也是一样的，具体问题具体分析。

## 把 IDA 中的 `android_server` 复制到手机并启动 Android Server

1. 上传 IDA 调试服务器，路径为：`IDAPro70\dbgsrv\android_server`
2. 使用命令行进入该目录：`IDAPro70\dbgsrv`
3. 导入 IDA 调试服务器：

   ```bash
   adb push android_server /data/local/tmp
   ```

4. 使用 `adb shell` 以 `su` 身份启动，手机需要获取 root 权限。
5. 进入 `/data/local/tmp` 目录并修改权限：

   ```bash
   chmod 777 android_server
   ```

6. 启动 `android_server`。如果启动失败，请重启手机：

   ```bash
   ./android_server
   ```

启动之后，可以看到：

`IDA Android 32-bit remote debug server(ST) v1.22. Hex-Rays (c) 2004-2017`

注意：如果是 32 位程序，打开 IDA 时也要使用 32 位版本，否则就使用 64 位版本。

## 设置 `ro.debuggable` 为 `1`

### 1. 使用 `mprop`

```bash
adb push xxx/mprop /data/local/tmp/mprop
adb shell
su
chmod 755 /data/local/tmp/mprop
data/local/tmp/mprop setprop ro.debuggable 1 /data/local/tmp/mprop -r
```

### 2. 在 Magisk 中安装并开启 MagiskHidePropsConfig 模块

```bash
adb shell
props
```

## 转发 IDA 端口并开启 ADB 应用调试

```bash
adb forward tcp:23946 tcp:23946
adb shell am start -D -n 包名/包名对应启动Activity
```

端口转发之后，可以使用 `lsof -i:23946` 查看。如果有 `Listen`，则说明转发成功。接着调用 ADB 调试命令，填好对应包名和启动的 Activity，注入调试。

![图片描述](upload/attach/202211/961239_GESJ28W5EEZ824D.png)

## 在 IDA 中附加到应用进程并设置断点

打开 IDA，设置好 process options，地址为 `127.0.0.1`，端口为 `23946`。

依次选择 `IDA` → `debugger` → `attach process`，选择对应的应用进程。选择 `libdvm.so`，找到 `dvmDexFileOpenPartial` 并计算偏移量。

## 动态调试步骤总结

1. 安装 Android APK。注意手机的 Android 版本，高版本系统默认为 64 位。如果使用 32 位调试，肯定无法正常工作。

   ```bash
   adb install --abi armeabi-v7a 七xxx小说.apk
   adb install --abi arm64-v8a <path to apk> 运行64位的
   ```

2. 开启 `android_server`：

   > `adb shell` → `tmp` → `./android_server`

3. 开启本地转发端口：

   ```bash
   adb forward tcp:23946 tcp:23946
   ```

4. 打开 APK，找到包名和启动页面：

   ```bash
   adb shell dumpsys window | grep mCurrentFocus
   ```

5. 开启 APK 调试附加模式：

   ```bash
   adb shell am start -D -n com.kmxs.reader/com.kmxs.reader.home.ui.HomeActivity
   ```
