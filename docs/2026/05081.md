# [原创][.net]修復不能使用的115网盘地址解析工具

最近经常去下载MTV的网站换成优蛋下载，要下载他自带的下载器（其实就是一个跟迅雷一样的下载器…..），非常麻烦。试过用JDownloader，下载速度只有100kb/s，所以在网上找了一个115 网盘地址解析工具1.0.0.0，可惜该版本已经不能解析，又没找到其他可用的工具。刚巧看完.net加密解密第一章，所以决定自己试试修改，学以致用。

软件版本：115 网盘地址解析工具 V.1.0.0.0
工具：NotePad++，ILASM，ILDASM，ExEinfo PE
目的：修改解析部分，令其能下载新版本资源

打开程序，贴上下载网址，程序报错
![](https://bbs.kanxue.com/upload/attach/201106/16322_4aa9b3wc08yfxa8.jpg)
一看错误框就知道是用.net写的，在提取真实下载地址时出错，估计是服务器更换了解析地址。上网搜寻了一下，发现旧版本提取地址是在

```
df3K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4g2Q4x3X3f1I4x3e0g2Q4x3X3g2U0L8$3#2Q4x3V1k6Q4x3@1k6U0N6q4)9K6c8s2g2H3L8r3!0S2k6q4)9#2k6X3q4H3K9g2)9J5y4X3q4U0i4K6y4p5k6$3g2@1i4K6g2X3M7r3W2U0K9#2)9#2k6X3y4G2k6r3g2Q4y4h3k6A6L8X3k6G2i4K6t1$3N6X3g2J5M7$3W2G2L8W2)9K6c8o6p5I4y4U0m8Q4x3U0k6H3K9h3y4C8j5$3!0V1k6g2)9K6c8q4!0q4y4W2)9^5c8W2)9&6x3q4!0q4y4g2)9^5c8W2)9&6y4W2!0q4y4#2!0m8x3q4)9^5x3b7`.`.
```


然后用JSON解析出真实下载地址，直接浏览器输入地址，出现一堆乱码，用Json Parser online转换一下，出现[请升级至新版本优蛋使用最新上传功能。]提示。
用沙盒安装优蛋下载器，然后用Wireshark截取封包。打开优蛋下载，贴上下载地址，优蛋会自动显示档案名称。这时观察wireshark的数据包就会发现跟上面旧地址相似的地址：
![](https://bbs.kanxue.com/upload/attach/201106/16322_mx1jpfgigyaj1fk.jpg)
打开ILDASM，选择115 网盘地址解析工具，输出IL代码，档名115
有4个文件
![](https://bbs.kanxue.com/upload/attach/201106/16322_xhiqpjslnu3jt1q.jpg)
用NotePad++(也可以用笔记本)打开115.il
找到下面这句(p.s.搜寻最快)
![](https://bbs.kanxue.com/upload/attach/201106/16322_e4fb1qym35glsw7.jpg)
然后根据wireshark的封包资料修改一下
![](https://bbs.kanxue.com/upload/attach/201106/16322_drntb23a5nc8x4q.jpg)
原文是两行的，我不想麻烦，一行过算了，反正没什么影响。要注意的是，问号前一定要加[\]，要不会出错的。
存档，然后打开【Visual Studio 2008 命令提示字元】，
输入：
