
# [分享]-使用phantOm 1.2插件注意了

目前该问题只发现在1.20版本，系统为WIN2003才有这个问题，XP就没有~~！

问题存在为Hook `GetTickCount` 这个选项：

`phantOm` Hook之后会是如下：

7C8219DF   .  838B 152003FE>or      dword ptr [ebx+FE032015], 7F

修改方法为：

`winxp`就不用管了，`win2003`的话，需要修正，因为这个是代码上要调整，建议大家到资源下载区下载`HideOD v0.1.9.6`这个版本，之前的版本存在和`phantOm`一样的问题，`0.1.9.6`这个版本之后加了版本校验，`win2003`和`XP`都就可以用哪~~！
