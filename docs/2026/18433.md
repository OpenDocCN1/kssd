## PNG 文件格式概述

简单地总结一下文档中关于 PNG 文件格式的描述。

![](https://bbs.kanxue.com/upload/attach/200810/41673_x0byua0epltiymy.png)

如上图所示，PNG 文件可以简单地理解成一个文件头和一系列数据块。具体来说：

### 文件头

由八个字节组成：

```text
0x89504e470d0a1a0a
```

### 数据块

每个数据块由四部分构成，描述如下：

- **Length**：占四字节，表示数据块 `Data` 域占多少个字节。（注意这里不包括 `Length` 自身。）
- **Type**：占四字节，表示当前块的类型。一般是英文字母大小写字符的 ASCII 码（65～90 或 97～122）。
- **Data**：数据区，大小可以是 0 字节。
- **CRC**：占四个字节，是整个 `chunk` 的 CRC 校验码（`Length + Type + Data`）。
