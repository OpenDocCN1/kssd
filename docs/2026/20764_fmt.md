
# #18周年# 逆向的天马行空

作者：爱琴海

值此看雪18周年之际，我想写点关乎逆向与人生哲理的天马行空感悟。我有故事，你有好酒么？

人生无根蒂，飘如陌上尘。  
分散逐风转，此已非常身。  
得欢当作乐，斗酒聚比邻。  
盛年不重来，一日难再晨。  
及时当勉励，岁月不待人。  

陪伴看雪走过了十多年光阴，世事变迁，沧海桑田，我认识了很多密界好友，也一起经历了风风雨雨。

前几个月路过上海中环路，离看雪公司仅仅几公里，阳光透过车窗很迷人，一直觉得我跟看雪有段缘分，由于事急匆忙，遗憾没能见个面。

逆向是件很花费时间和精力的事情，有些人像烟花那么绚烂，却又消失在了虚无，生命无常。

如果仅仅是追求逆向本身的技巧，你我能有多少汗水可以挥洒，又有多少岁月可以消磨？

古人有格物致知的说法，去体会、探究事物蕴含的道理，思考和总结万事万物的本质，升华到人生哲理，指引内心，达到超凡入圣的境界。

如果说大千宇宙是包罗万象的系统，你我便是那系统中的程序，每个人仅能运行一次。

如果人生可以重新运行，你想做点啥？

小区里面有个叫马云的人，小时候鬼头鬼脑，没有跟他拜把子。有个手下工作不卖力被我训话了，不留情面，后来他成了我的甲方。家里有好大一块良田，土地肥沃，在我小时候几百元一亩卖掉了，高兴了好一阵子。十多年前，北京、上海房价还是挺便宜的，真不贵，但是我没有买。曾经接到电话说中奖了，欣喜若狂，后来打了五万块钱出去。

对过往事物的审视、思考、总结，从中吸取到经验和教训显得愈加重要。

如果人生可以下断点，你想做点啥？

赤壁之战，曹操若看到败于如履平地的铁索连舟、火烧连营，众将士死于烈火和马蹄之下，他会不会及时果断改掉BUG，来日方长、从长计议？牢狱之灾，华佗若看到焚毁《青囊书》以致一身绝学失传、后世痛惜，他会不会留有备份或者及时把一身所学传授他人？大理寺狱，岳飞若看到断头铡刀斩下，会不会重新审视十二道金字牌和他所寄希望的南宋？流浪街头，退役运动员若看到满身的伤痛和病残、毫无尊严活着，这表面镀金的金牌对他又有何用？

对人生下断点，把握当下、理清头绪，越是重要的选择越是要审时度势、审慎考虑。

逆向对于人生的启发是对过往事物的审视、思考、总结，从中吸取到经验和教训，预测将来的事物，在当下审慎选择，使人生运行得更加圆满。

把人生当做程序，逆向永无止境。
