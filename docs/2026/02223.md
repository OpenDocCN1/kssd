# OicqSend (Oicq消息发布） Ver 2.01.903 
破解 (1千字)

OicqSend (Oicq消息发布） Ver 2.01.903 破解实录

工具：trw2000

由于在某一天早上，本人的oicq受到了不知是谁的消息攻击，发现这个工具挺不错的，于是也载了一个下了，虽说这个工具是免费注册的，可是要发E，又不知何时有回音，（最主要的就是看着要注册不舒服，加上手痒而已，呵呵）就想到了破解它，好了，费话小说
Go

首先打开trw2000按下OK后，运行oicqsend，点注册的图标（一个大锁）写上自己的Q号，注册码先写456456456吧，Ctrl+N由trw2000接管，写进bpx
hmemcpy回车后，输入G回到注册的画面，点击确定，TRW2000自动跳出来到了
        0043491B    MOV    [EBX+0C],EAX
一直按F10执行
    0043491E    MOV    EAX,[EBX]

    00434920    CMP    EAX;BYTE+0C

    00434923    JNZ    00434940

    00434925    MOV    EDX,[EBX+08]

    00434928    PUSH    EDX
    00434929    MOV    ECX,[EBX+04]

    0043492C    MOV    EDX,EAX

    004919BF    MOV    EAX,[00497FC4]

    004919C4    MOV    EAX,[EAX]

    004919C6    CALL    00493084

    004919CB    LEA    EDX,[EBP-14]

    004919CE    MOV    EAX,[EBX+02DC]

    004919D4    CALL    00430BFC

    004919D9    MOV    EAX,[EBP-14]

    004919DC    MOV    EDX,[EBP-08]

    004919DF    CALL    00403FE4
  <=可疑吧，按F8跟进
    004919E4    JNZ    NEAR

    00403FE5    PUSH    ESI

<=关键时刻到了
我们来D EDX 吧，注册码出来了，赶快抄下，注册去吧。（总共用时12分钟）
