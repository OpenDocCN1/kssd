
# [原创]索然无味的勒索病毒

## 前言

感觉自己最近没有分析过勒索类的病毒了，就冲浪的时候随手找了一个blocky的勒索病毒来分析分析。

## 过程分析

先拷贝自身，算出随机密钥，对特定目录下的文件进行加密，发送密钥至恶意样本作者。
