## 程序说明

`mypower` 是我用 C++ 仿制 [`scanmem`](elink@21eK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6K6j5$3q4F1L8h3g2E0i4K6u0r3M7$3y4S2L8X3#2W2L8b7`.`.) 而来的。但是 `mypower` 包含了更多高级功能：

1. 支持指针引用扫描。这个算是核心功能了，可以分析指针的引用路径。例如，我们扫描出了堆里的血量的指针，然后就可以用这个功能扫描出某个内存区域（通常是 `.bss` 或者 `.data`）到血量的一系列指针和偏移量。假如是手机大型游戏，扫描起来会比较慢，这时则可以抓镜像到电脑端，用多核心电脑搭配内置的 OpenMP 支持进行多线程扫描。
2. 支持导出内存镜像。这个可以在手机导出镜像然后拖到电脑上加载做静态分析。
3. 命令交互支持数学表达式。这样方便做简单的计算，不需要计算器来回倒腾。
4. 可扫描 Unity3D 对象，也可以一键分析指针的类和实例名，也支持字符串内容解析。

## 简单使用教程

### 目标进程源码

```cpp
#include <iostream>
#include <memory>
#include <vector>

struct Actor {
    int32_t hp;
};

struct World {
    std::vector<Actor> actors;
};

std::unique_ptr<World> world;

int main(int argc, char *argv[])
{
    world.reset(new World);
    std::cout << ".bss " << (void *)&world << std::endl;
    world->actors.push_back({});
    world->actors.at(0).hp = 300;

    while (1) {
        std::cout << "hp " << world->actors.at(0).hp << std::endl;
        getchar();
        world->actors.at(0).hp -= 1;
    }

    return 0;
}
```

首先运行目标进程，输出如下：

```text
$ ./dummy
.bss 0x563db339b128
hp 300
```

接着运行 `mypower`，用 `findps` 命令查找目标进程。

![a](upload/attach/202305/978503_MC85FBZN69JMDCA.png)

接着在搜索到的进程列表界面按 `ESC` 进入列表模式，选中进程后按 Enter 即可附加这个进程。也可以用命令 `attach -p pid` 手动附加。

![b](upload/attach/202305/978503_AVA8QGVXHSTWGCP.png)

附加进程后，就可以用扫描命令扫描内存了。这里作为例子，我们扫描 32 位整数 `scan -i =300`。这行命令的意思是扫描精确的 32 位整数 `300`。如果要扫描大于 `300` 的 32 位整数，可以运行 `scan -i >300`。

![c](upload/attach/202305/978503_QSNPVHC45H4F4CR.png)

运行扫描命令的结果：

![d](upload/attach/202305/978503_7YN4TMCZYD5WMBZ.png)

很多结果明显是不对的，我们可以过滤一下。因为这时目标进程的内容 `300` 变成 `299` 了，所以我们输入命令 `filter <300`，把小于 `300` 的找出来。

![e](upload/attach/202305/978503_7VM66HG27TDUSXU.png)

这时结果很显然，`[heap]` 这一行就是我们要找的东西。

![f](upload/attach/202305/978503_YW3FX7VERWNFZNC.png)

最后我们尝试一下搜索 `world` 变量的地址：

```text
ptr --mask 0xFFFFFFFFFFFFFC00 --depth-max 4 --offset-max 512 --result-max 512 0x563db339b000 0x563db339c000 0x563db53396d0
```

`--mask` 是内存块掩码。比如我们要搜索 `0x563db53396d0`，那么这个指针所处的内存块就是 `0x563db5339400`（`0x563db53396d0 & 0xFFFFFFFFFFFFFC00`）。然后内存里每 8 个字节当作一个指针，当（`指针 & 0xFFFFFFFFFFFFFC00`）== `0x563db5339400` 时，程序就认为找到了对地址 `0x563db53396d0` 的引用。接着这个引用指针就会作为下一个目标地址进行下一轮搜索，直到这个指针落在指定的范围内。

`--depth-max` 意思是最多搜索多少级指针。

`--offset-max` 意思是每级指针的最大偏移量。

`--result-max` 是结构达到这个数量后停止扫描。

`0x563db339b000 0x563db339c000` 是内存区域范围。比如给的是 `exe` 的 `bss` 段或 `data` 段，就是搜索全局变量到目标指针的引用路径。当搜索到落在这个区域的结果时，视为成功。

`0x563db53396d0` 是目标地址。

![g](upload/attach/202305/978503_AC6SAHWUMNAJ893.png)

就这样我们找到了全局变量 `world` 的地址。

```text
From: 0x563db339b000-0x563db339c000 To: 0x563db53396d0
0x563db339b128 Value: 0x563db53392a0 Offset: 0
0x563db53392a0 Value: 0x563db53396d0 Offset: 0
0x563db53396d0
Time: 0s
```
