# [原创] C和Win32編的GUI, 彩色計時器1.8.0 (2012-10-14) (有源代碼)

![](https://bbs.kanxue.com/upload/attach/201212/294723_93dfz2dt9lm7a7m.png)

**特點**
1. 用 CreateTimerQueueTimer 和 timeGetTime 準確計時, 時間不會有任何誤差.
2. 倒計時&順計時
3. 提供秒錶精度選項, 可以選擇 1/100秒, 1/10秒 , 1秒
4. 「順計時」 和 「倒計時」 在計時過程中也可以自由切換
5. 有8種顏色:『紅綠藍白黃青紫橙』
6. 可以自由調整窗口大小
7. 命令行參數, 可以選擇模式 ,顏色, 精度,是否立刻計時
8. 在我的CPU上佔用為0, 無論界面放大到多大

RC 資源文件也是我手寫的，
用的IDE是CodeBlocks。

**使用方法：**
1.鼠標左鍵：拖動
2.鼠標左鍵雙擊： 在Mini模式和完整模式切換
3.鼠標右鍵： 菜單
4.鼠標中鍵, Space鍵：開始計時, 暫停計時

**高級功能: 命令行參數**

-mode=timer:90 (倒計時90秒)
-precision=centi (精度為1/100秒)
-precision=sec (精度為秒)
-color=blue(藍色)
-start (立即計時)
