
# [原创]某 电子白板 软件逆向分析 记要

特点如下:

1) 试用次数记录在 0 号物理驱动器第 62 扇区,即使重装系统,也不会被覆盖

2) 启动进程 `A.exe`,伪装进程 `B.exe`,实际进程 `C.dat`, `B` 和 `C` 同名

`A` ---> 读取 `C`,在内存中解密[`C` 其实是个 加`UPX`壳 的 `exe`]

---> 创建 `B`,挂起,得到`B`的主线程环境

|

|_> 在 `B` 的空间里,写入 `C`,随后,修改 `B` 的主线程环境,使得 `EIP` 为 `C` 的入口

|_> 启动 `B` 的主线程(实际上是运行 `C`)

===============================================================================

## 总结陈述

1) `rsRSWBSW.exe` :

加载 `RSWBSW.dat`,解密; 启动 `RSWBSW.exe` 进程并挂起;

将解密后的 `RSWBSW.dat`(实质是加 UPX 壳的 exe 文件)写入 `RSWBSW.exe` 进程空间,替换掉 `RSWBSW.exe` 的内容,随后,启动替换后的 `RSWBSW.exe` 主线程

2) `RSWBSW.dat` :



被解密后，可以从 `rsRSWBSW.exe` 进程中复制出来，另存为一个 exe 文件，比如 `ppx.exe`，随后 `UPX` 脱壳，然后修改指令，爆破。

3) `RSWBSW.exe`：启动 `rsRSWBSW.exe`，完成 1) 2) 动作，随后自己退出。

4) 试用次数写在 0号物理驱动器第 62 扇区（`512字节/扇区 x 62 = 7C00h`）偏移 `100h` 处，格式是 `52 53 57 42 00 1C => R S W B . .`。
