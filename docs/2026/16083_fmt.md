
# [原创][Android] 记一次艰难的 Android 11 抓包过程

## 前言

最近开始学习 App 渗透，抓包是必不可少的过程，接下来记录一下我遇到的一些小麻烦。

## 设备环境

![file](https://bbs.kanxue.com/upload/attach/202403/979679_RNT7Z248CJTXSXW.jpg)

## 问题

首先，由于 Android 版本大于等于 7.0 之后，系统不再信任用户的 CA 证书（应用 `targetSdkVersion >= 24` 时生效，如果 `targetSdkVersion < 24`，即使系统是 7.0+，依然会信任）。简而言之，如果只是用户 CA 证书，那么 HTTPS 包就抓不到了。

### 方法一：手动将证书移动至 `/system/etc/security/cacerts/`（未解决）

由于我们采用的抓包工具是 Burp Suite，这里就以 Burp Suite 的抓包方式举例。

首先下载 Burp Suite 的证书（访问 Burp Suite 的监听端口即可）。

![file](https://bbs.kanxue.com/upload/attach/202403/979679_2UWGQHD8E5UKJFX.jpg)

下载好之后，首先需要计算 `cacert.der` 的哈希值，命令如下：

```bash
openssl x509 -inform der -subject_hash_old -in cacert.der -noout
```

得到的应该都是 `9a5ba575`。

那么将文件名称更改为 `9a5ba575.0`，传入到手机中。

如果直接一步到位，大概率会出现如下情况：

![file](https://bbs.kanxue.com/upload/attach/202403/979679_WJRJ4YC49ET8HBP.jpg)

出现这种情况的原因很多，有可能是没有使用 `adb root`，导致 `adb` 终端的默认权限不是 root。如果 `adb root` 无法使用，可能是因为 `ro.debuggable` 不为 1 导致的。可以使用如下命令查询：

```shell
adb shell getprop ro.debuggable
```

既然不能这样，那么我们不妨先 `push` 到 `/data/local/tmp` 中，再移动到 `/system/etc/security/cacerts/`。按理说，这就是系统默认信任证书的文件夹，我们移动过去应该就可以成功装上证书了，但是奇怪的一幕发生了。

![file](https://bbs.kanxue.com/upload/attach/202403/979679_QV6CB2MHGS3CHDJ.jpg)

（崩溃……）

---

后经检查发现，是我的 `system` 分区没有解锁。

别的版本解锁请看如下文章：

### 方法二：Magisk 模块大法

到了 Android 11 和 Android 12 机型，已经不能通过 TWRP 或 `syslock` 软件暴力解锁 `system` 分区了。已知目前解锁 `system` 的方法，都是对系统分区进行二次打包改造，实现解锁 `system` 分区的效果。

唉，不会，本文到此结束！

当然，结束是不可能结束的。正所谓柳暗花明又一村，Magisk 有一个模块可以完美解决我们的问题！

项目地址分享如下：

[0c4K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6n7L8r3!0G2k6s2W2Q4x3X3c8n7j5h3c8T1L8%4W2Q4x3V1k6y4L8%4k6W2i4K6u0V1g2i4y4W2M7W2)9J5k6p5y4W2M7Y4c8A6k6X3W2U0j5i4c8W2M7H3`.`.](https://bbs.kanxue.com/elink@3c1K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6n7L8r3!0G2k6s2W2Q4x3X3c8n7j5h3c8T1L8%4W2Q4x3V1k6y4L8%4k6W2i4K6u0V1g2i4y4W2M7W2)9J5k6p5y4W2M7Y4c8A6k6X3W2U0j5i4c8W2M7H3`.`.)

刷上该模块之后，我们将 `cacert.der` 改成 `cacert.cer`。

![file](https://bbs.kanxue.com/upload/attach/202403/979679_XPJRYTK6JUBPB4E.jpg)

直接安装证书就可以了，模块会自动帮我们加载成系统证书。
