# regsnap2.80破解小记 (1千字)

RegSnap2.80注册表比较工具。
该工具功能非常不错，本身也属于Crack软件,但它要注册并有三十天的时间
限制，真令人讨厌。

    网上已有不少Crack高手，破解了它，但我不知他们有没有试过这软件，
它还隐含了一个陷阱，破解过它的人都知道，首先是把文件位置0x41F9处7409
改为EB09，即原有的条件跳转语句改为无条件跳转语句，以及0x421b处74DE
改为9090，同时把程序检查完整性的地方改掉。

  但不知这些高手们是否测试过程序，或者说他们也太忙了，经过这样改过的
程序，RegSnap会在做比较时始终会说Broken Source file.然后就停止工作。

  我曾试过找到此处也进行修改，但发现又有问题，于是我干脆对程序不作修改，
而采用ppatcher来处理，我把ppatcher.ppc文件进行一下配置：

#Process Patcher Configuration File
Version=3.93

DisplayName=My Test Program
Filename=regsnap.exe
Filesize=299008
Arguments=/quiet
Address=0x4041f9:0x74:0xEB
Address=0x40421b:0x74:0x90
Address=0x40421c:0xde:0x90


#End of Configuration File

然后把ppatcher.exe和ppatcher.ppc拷贝到Regsnap执行目录下，然后运行
ppatcher.exe，^\_^，一切正常，运行比较功能，也正常。

当然这时显示的注册信息好恐怖哦。。。。
