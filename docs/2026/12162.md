# [原创]浅述 KdPrint 在checked 和free版本的不同

在checked版本中，Kdprint,会被DbgPrint所代替
我们编个简单的程序：

NTSTATUS DriverEntry( PDRIVER\_OBJECT pObj , PUNICODE\_STRING path)
{
pObj->DriverUnload = DriverUnload;

KdPrint(("123"));
return STATUS\_SUCCESS;
}

可以用IDA简单的看一下：
![](https://bbs.kanxue.com/upload/attach/201308/597880_2ie6qitvujsmpis.jpg)
显然Kdprint,被DbgPrint所代替了。

在free版本中，Kdprint无效，不做任何事情。
可看IDA分析结果：可见不做任何事情
