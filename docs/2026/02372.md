
# 破解YATS32 v8.1 build 6 (2千字)

软件名称：`YATS32`

版本：`v8.1 build 6`

下载地址：`http://www.dillobits.com/bin/yats3281.exe`

`http://newhua.21f.net/down/yats3281.exe`

保护类型：注册码

破解类型：`patch`

难度级别：`easy`

软件描述：时间同步工具

该软件用`UPX`压缩过，解压后反汇编，利用`W32Dasm`的`reference`功能，找到如下的地方。很明显`DS:[00456970]`中存放的是注册的标志，非零值表示已注册。
