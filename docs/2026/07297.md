# [原创]ZwQuerySystemInformation函数在驱动中的用法

最近研究驱动 因为要枚举出内核模块 所以要用到ZwQuerySystemInformation函数 网上对这个函数的介绍也是比较多的 但是有一些错误 这里我详细的介绍一下  转帖请注明作者和网站



ZwQuerySystemInformation是一个未公开的函数 所以必须定义他 定义如下

extern "C" NTKERNELAPI  NTSTATUS ZwQuerySystemInformation( IN ULONG SystemInformationClass, IN OUT PVOID SystemInformation, IN ULONG SystemInformationLength, OUT PULONG ReturnLength OPTIONAL );

网上有些文章并没有 使用extern "C"来修饰 可能是由于我编译器的问题 如果我不加extern "C" 编译器会报错  如果有同学在定义这个函数的时候报错 可以加上extern "C" 试试

第二个参数与第一个参数是有关联的 如果第一个参数是SystemModuleInformation 那么第二个参数的结构就是

```
typedef struct _SYSTEM_MODULE_INFORMATION {
ULONG Count;
SYSTEM_MODULE_INFORMATION_ENTRY Module[1];
} SYSTEM_MODULE_INFORMATION, *PSYSTEM_MODULE_INFORMATION;
```

这个参数是我要重点提醒的 第二个参数必须是非分页内存 如果你定义一个变量 比如  PVOID pBuffer = NULL; 这样 你加载驱动运行函数的时候就会蓝屏 这时候ZwQuerySystemInformation 会返回一个 错误 错误代码是0XC0000005

所以 当我们申请这个第三个参数的变量的时候要这样做

PVOID pBuffer = NULL; //第二个参数
ULONG cbBuffer = 0x8000; //第三个参数
pBuffer = ExAllocatePool (NonPagedPool, cbBuffer);// //开辟非分页内存

第三个参数是输入缓冲区的长度   一般是用一个循环来确认其长度

第四个参数是函数调用后返回所需缓冲区的长度 如果我们不想用循环来确认长度 那么我们可以先调用ZwQuerySystemInformation 把第二参数设置为NULL 把第三个参数设置为0  调用成功后 会返回所需缓冲区的长度 代码如下
PULONG retureSize=0; //缓冲区所需的长度
ZwQuerySystemInformation(SystemModuleInformation, NULL, 0, ULONG retureSize; );
