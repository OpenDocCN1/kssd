
# WinME 小故事 (从网上来)

MS 在ME上将real mode清除，改动`io.sys`的功能。不运行`config.sys`、`command.com`与`win.com`，直接跟`vmm32.vxd`连通，因此没有`autoexec.bat`与`INT68` (real debugger debugger) interface，而S-ICE需要在real mode装载自已，但因`win.com`不运行（`win.com`会找寻并装载real mode debugger），又没有`autoexec.bat`，Numega没法运行`winice.exe`。

不知是Numega找到或MS通知，在debug build的`io.sys`会运行一个叫`debugger.exe`的程序，故在Numega站有`debugger.exe`下载。（跟MS提供的有异，会装载`winice.exe`）另Win98MEDDK裹有debug用的`io.sys`（checked `io.sys` or `winboot.sys`），以上是原厂方法。

但另外有人发现原`io.sys`会装载另一各字的debugger，（`loader.exe`），象`wmeldr.zip`裹便是，有源码可参考。此为土法，但比原厂的方便，0.3版可选装或不装`winice.exe`，现已有人说`hmemcpy`这断点不能在ME上工作，我没用它debug，only安装。
