# WinME 小故事 (从网上来) (748字)

MS 在ME上将real mode 清除,改动io.sys的工能.不运行config.sys,command.com与win.com
,直接跟vmm32.vxd连通,因
此没有autoexec.bat与INT68 (real debugger debugger) interface,
而S-ICE 需要在real mode装载自已,但因win.com不运行
(win.com会找寻并装载real mode debugger),又没有autoexec.bat,Numega没法运行winice.exe.
不知是Numega找到或MS通知,在debug build的io.sys 会
运行一个叫 debugger.exe的程序,故在Numega 站有debugger.exe下载.(跟MS提供的有异,会装载winice.exe)
另Win98MEDDK裹有debug用的io.sys(checked io.sys or winboot.sys),以上是原厂方法.
但另外有人发现原io.sys会装载另一各字的debugger,
(loader.exe),象wmeldr.zip裹便是,有源码可参考.此为
土法,但比原厂的方便,0.3 版可选装或不装winice.exe,现
已有人说hmemcpy这断点不能在ME上工作,我没用它debug,
only安装.
