
# GalaxyAP 过游戏反调试框架

这个工程我以前用来在XP上跑过DNF，DN，只为好玩目的，还没写过外挂。

声明：用这套代码干了什么坏事与我无关

[`BypassAntiDebug.rar`](https://bbs.kanxue.com/attach-download-61988.htm)

## 工程说明

1. `GalaxyAP` 应用程序
2. `HookPortBypass` 重加载内核（包括 `nt` 和 `win32k`）
3. `TEST_KIDISPAT` 自分发异常（朋友帮忙实现了部分，代码主要来源 WRK）

PS：`hookport` 代码抄网上的，来源 `a92K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3@1#2K9r3!0E0k6g2)9J5k6h3y4G2L8g2)9J5c8X3u0T1M7#2)9J5c8X3k6G2M7Y4g2E0i4K6u0W2M7r3S2H3`

这套 `GalaxyAP` 工程主要实现了：

- 重加载内核（借助 `hookport` 思路配合 `peloader`）
- 自实现异常分发的几个主要函数
- 自创建 `debugobject`，使用另一个 `object`
- 也使用了另一个 `fastmute`
- 自己发现吧……

PS：驱动的加载有时候在游戏前好使，有时候在启动游戏后好使  
PPS：这货也只能在 XP 上跑了
