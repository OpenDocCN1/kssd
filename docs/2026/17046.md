
# [原创]msf学习第二帖

## 常见的网络服务扫描

### 1. Telnet服务扫描

```
use auxiliary/scanner/telnet/telnet_version
set rhosts 192.168.1.0/24
set threads 100
```

![](https://bbs.kanxue.com/upload/attach/201908/862556_CS43RA97BNR7XAV.png)

### 2. ssh服务扫描与查点

```
use auxiliary/scanner/ssh/ssh_version
set rhosts 192.168.1.31
set tereads 100
```

![](https://bbs.kanxue.com/upload/attach/201908/862556_2ZKYD5H2QFHDZVE.png)

### 3. Oracle服务查点模块

```
use auxiliary/scanner/oracle/tnslsnr_version
set rhosts 192.168.1.0/24
set threads 50
show options
run
```

![](https://bbs.kanxue.com/upload/attach/201908/862556_ET4ZXDZTS27QGBQ.png)

