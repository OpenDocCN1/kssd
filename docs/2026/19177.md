
# [翻译]Hacking 101 to mobile data

这篇文章主要介绍如何创建`MitM`（中间人攻击），用于嗅探`SIM`卡和后端服务器之间的流量。虽然这不是什么新的研究，但我还是希望这篇文章可以帮助到那些没有技术背景的人，如何使用移动数据嗅探和伪基站。如今我们有很多带有`SIM`卡的物联网设备可以连接到后端，适用场景广。

本文先以`SIM`使用`2G`和`GPRS`的最简单的场景举例，以后或许还有关于`3G`、`4G`的文章。

## 动机

如今，大多数`IoT`设备都是通过`SIM`卡与后端相连。这些`IoT`设备可以是任何简单的小东西，比如：咖啡机、智能手表、智能眼镜，或是大一点的物品，汽车、医疗设备等等。如果你想监听这些`IoT`设备与后端之间的流量通信，这篇文章就再合适不过了。

## 目标

为了实现移动数据流量的`MitM`攻击，首先要使用`USRP`硬件制作一个简单的伪基站。

## 要求

这是本次实验所用到的设备。

**硬件**

1. `USRP B210`（带天线和电缆（`USB 3`）连接到`PC`）
2. 智能手机或旧`GSM`手机，本次实验使用`IoT`设备
3. `SIM`卡
4. 笔记本电脑

**软件**

1. `OpenBTS`
2. `SipauthServ`
3. `Smqueue`（可选——如果你想发短信）
4. `Asterisk`（可选——如果你想打电话）
6. `OS – Ubuntu 16.04`

**Human ability**

使用`Google`搜索、阅读、写作和耐心。开始，停止，踢球，重新开始，停止，暂停，喝咖啡，开始，停止...... ..循环。

## 什么是OpenBTS

![图1：OpenBTS概述](https://bbs.kanxue.com/upload/attach/201804/776575_X986N98R49GNRYE.png)

`OpenBTS.org`是一个开源软件项目，致力于通过互联网协议和灵活的软件架构来制作电信协议和传统复杂的专有硬件系统。`OpenBTS`软件是一种`Linux`应用程序，它使用软件定义的无线电向用户设备呈现标准的`3GPP`空中接口，同时将这些设备作为`SIP`端点呈现给互联网。这构成了新型无线网络的基础，该网络承诺将覆盖范围扩大至未服务和服务不足的市场，同时释放创新平台，包括为新兴网络技术提供支持，例如针对物联网的新兴网络技术。[参考]

### 运行OpenBTS

- 使用`USB 3`电缆将`USRP`设备连接到电脑
- 我搭建了一台虚拟机，里面构建了所有必需的软件，以便轻松移植。如果你也使用虚拟机，请确保它具有`USB 3`转发的可能性。在`VirtualBox`中，你可以启动`USB > Devices > Ettus Research USRP B210`（或类似的名字）。
- `uhd_usrp_probe`：此命令用于`Linux`的`USRP`硬件驱动程序外设报告实用程序，一旦它检测到设备，它将下载`B210`的固件
- 运行`SipauthServe`

```
home/dev/subscriberRegistry/apps$ sudo ./sipauthserve
```

- 运行`OpenBTS`

```
home/dev/openbts/apps$ sudo ./OpenBTS
```

- 运行`OpenBTSCLI`

```
home/dev/openbts/apps$ sudo ./OpenBTSCLI
```

### 配置伪基站

在上面的步骤中，运行了`OpenBTSCLI`，这主要是为了配置我们的`OpenBTS`。

以下是`OpenBTSCLI`为我们获得功能模型所做的主要配置：

- 允许任何电话连接到基站而无需身份验证。这允许任何电话注册，不管他们的提供者是谁。

```
OpenBTS> config Control.LUR.OpenRegistration .*
```

- 启动`GPRS`

```
OpenBTS> config GPRS.Enable 1
```

- 启动`IP`转发

```
echo 1 > /proc/sys/net/ipv4/ip_forward
```

- 安装`iptables`：整个`GPRS`和`IPtables`设置在这里可以找到。

### 让手机连接上基站

如果您有智能手机，则必须更改一些设置才能使手机连接到基站。当物联网设备就位时，这会变得更具挑战性，因为几乎没有任何选项可以在物联网设备中配置“移动网络”。但我们会在稍后讨论。

**配置安卓手机（其余手机类似）：**

- 启动`2G`。这是从`4G`网络降到`2G`网络：`设置 > 蜂窝网络 > 首选网络类型 > 2G`
- 添加`APN`：`设置 > 蜂窝网络 > 接入点名称`。添加时，确保`MCC`和`MNC`设置为与`SIM`卡相同值。在德国，`MCC`为`262`，它会根据提供商的不同而改变，这个链接可供参考。除此之外，`APN`和名称可以是任何东西，身份验证为无。

![图3：设置APN](https://bbs.kanxue.com/upload/attach/201804/776575_R9UFYMBX8RXSBSY.jpg)

- 搜索伪基站并且手动的连接：`设置 > 蜂窝网络 > 搜索网络`。通常显示为包含`MCC`和`MNC`值的数字。

![图4：注册到基站](https://bbs.kanxue.com/upload/attach/201804/776575_VPHYX5FPVRVUHYC.jpg)

如果您看到该消息，说明您的电话已在网络上注册，则可以通过查看`OpenBTSCLI`来确认。

```
OpenBTS> tmsis
```

这将显示注册到基站的`SIM`卡的`IMSI`。如果你做到了这里，你已经有了第一个发现，那就是`SIM`卡的`IMSI`。`IMSI`是您`SIM`卡的私有标识符。具有`IMSI`的攻击者可以识别并跟踪用户的网络，甚至可以尝试模仿用户行为。

## 关于物联网的思考

正如我们所知，今天没有任何设备会使用`GPRS`连接其后端。它要么是`LTE`，要么是`3G`。如果物联网设备足够小，将其连接到我们的基站的最佳想法是将其放置在法拉第笼中。在这种情况下，没有其他信号可用，并且`SIM`卡逐渐连接到我们的基站。但是当设备像汽车一样大时，这是不可能的。（除非你有一个带法拉第笼的车库）。一种可能的技术是使用干扰器，以使`SIM`卡实际上与其原始供应商断开连接。同时，只要我们关闭干扰器，我们就会在设备旁边准备好`OpenBTS`。然后祈祷并等待`SIM`实际连接到我们。这需要反复试错。干扰器允许选择性地只打破`LTE`和`3G`可能导致降级攻击，当使得`SIM`卡连接到我们的`2G`基站。无论如何，我必须说这些在实践中并不那么容易。

注意：许多地方禁止使用干扰器。确保你可以控制干扰器干扰的范围和频率。它必须仅限于您正在测试的设备。

对于那些想尝试嗅探`4G`网络的人，可以看看`srsLTE`。

如果你对`IoT`设备或者通信安全感兴趣，你可以看看`Troopers18`，点击“Next Generation Internet”和`TelcoSecDay`获得更多详情。
