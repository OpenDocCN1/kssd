# [翻译]Hacking 101 to mobile data

这篇文章主要介绍如何创建MitM（中间人攻击），用于嗅探SIM卡和后端服务器之间的流量。虽然这不是什么新的研究，但我还是希望这篇文章可以帮助到那些没有技术背景的人，如何使用移动数据嗅探和伪基站。如今我们有很多带有SIM卡的物联网设备可以连接到后端，适用场景广。

本文先以SIM使用2G和GPRS的最简单的场景举例，以后或许还有关于3G,4G的文章。

# 动机

如今，大多数 LoT设备都是通过SIM卡与后端相连。这些LoT设备可以是任何简单的小东西，比如：咖啡机、智能手表、智能眼镜，或是大一点的物品，汽车、医疗设备等等。如果你想监听这些loT设备与后端之间的流量通信，这篇文章就再合适不过了。

# 目标

为了实现移动数据流量的MitM攻击，首先要使用USRP硬件制作一个简单的伪基站。

这是本次实验所用到的设备。

硬件

2、 智能手机或旧GSM手机，本次实验使用loT设备

3、 SIM卡

4、 笔记本电脑

OpenBTS.org是一个开源软件项目，致力于通过互联网协议和灵活的软件架构来制作电信协议和传统复杂的专有硬件系统。OpenBTS软件是一种Linux应用程序，它使用软件定义的无线电向用户设备呈现标准的3GPP空中接口，同时将这些设备作为SIP端点呈现给互联网。这构成了新型无线网络的基础，该网络承诺将覆盖范围扩大至未服务和服务不足的市场，同时释放创新平台，包括为新兴网络技术提供支持，例如针对物联网的新兴网络技术。[参考]

运行OpenBTS

- 使用USB 3电缆将USRP设备连接到电脑
- 我搭建了一台虚拟机，里面构建了所有必需的软件，以便轻松移植。如果你也使用虚拟机，请确保它具有USB 3转发的可能性。在virtualbox中，你可以启动USB > Devices > Ettus Research USRP B210（或类似的名字）。
- uhd\_usrp\_probe：此命令用于linux的USRP硬件驱动程序外设报告实用程序，一旦它检测到设备，它将下载B210的固件
- 运行SipauthServe

```
   home/dev/subscriberRegistry/apps$ sudo ./sipauthserve
```

- 运行 OpenBTS

```
 home/dev/openbts/apps$ sudo ./OpenBTS
```

- 运行OpenBTSCLI

```
   home/dev/openbts/apps$ sudo ./OpenBTSCLI
```

配置伪基站

在上面的步骤中，运行了OpenBTSCLI，这主要是为了配置我们的OpenBTS。

以下是OpenBTSCLI为我们获得功能模型所做的主要配置：

- 允许任何电话连接到基站而无需身份验证。这允许任何电话注册，不管他们的提供者是谁。

```
OpenBTS> config Control.LUR.OpenRegistration .*
```

- 启动gprs

```
OpenBTS> config GPRS.Enable 1
```

- 启动IP转发

```
echo 1 > /proc/sys/net/ipv4/ip_forward
```

- 安装iptables：整个GPRS和IPtables设置在这里可以找到。

让手机连接上基站

如果您有智能手机，则必须更改一些设置才能使手机连接到基站。当物联网设备就位时，这会变得更具挑战性，因为几乎没有任何选项可以在物联网设备中配置“移动网络”。但我们会在稍后讨论。

配置安卓手机（其余手机类似）：

- 启动2G。这是从4G网络降到2G网络：设置>蜂窝网络>首选网络类型>2G

- 添加APN：设置>蜂窝网络>接入点名称。添加时，确保MCC和MNC设置为与SIM卡相同值。在德国，MCC为262，它会根据提供商的不同而改变，这个链接可供参考。除此之外，APN和名称可以是任何东西，身份验证为无。

![](https://bbs.kanxue.com/upload/attach/201804/776575_R9UFYMBX8RXSBSY.jpg)

图3：设置APN

- 搜索伪基站并且手动的连接：设置 >蜂窝网络>搜索网络。通常显示为包含MCC和MNC值的数字。

![](https://bbs.kanxue.com/upload/attach/201804/776575_VPHYX5FPVRVUHYC.jpg)

图4：注册到基站

如果您看到该消息，说明您的电话已在网络上注册，则可以通过查看OpenBTSCLI来确认。

```
OpenBTS> tmsis
```

这将显示注册到基站的SIM卡的IMSI。如果你做到了这里，你已经有了第一个发现，那就是SIM卡的IMSI。IMSI是您SIM卡的私有标识符。具有IMSI的攻击者可以识别并跟踪用户的网络，甚至可以尝试模仿用户行为。

关于物联网的思考

正如我们所知，今天没有任何设备会使用GPRS连接其后端。它要么是LTE，要么是3G。如果物联网设备足够小，将其连接到我们的基站的最佳想法是将其放置在法拉第笼中。在这种情况下，没有其他信号可用，并且SIM卡逐渐连接到我们的基站。但是当设备像汽车一样大时，这是不可能的。（除非你有一个带法拉第笼的车库）。一种可能的技术是使用干扰器，以使SIM卡实际上与其原始供应商断开连接。同时，只要我们关闭干扰器，我们就会在设备旁边准备好OpenBTS。然后祈祷并等待SIM实际连接到我们。这需要反复试错。干扰器允许选择性地只打破LTE和3G可能导致降级攻击，当使得SIM卡连接到我们的2G基站。无论如何，我必须说这些在实践中并不那么容易。

注意：许多地方禁止使用干扰器。确保你可以控制干扰器干扰的范围和频率。它必须仅限于您正在测试的设备。
