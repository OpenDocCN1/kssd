
# [原创]`msf`学习系列第一帖！（我是新手，不喜勿喷）`msf`的主机探测模块

## `msf`中的`arp_sweep`模块探测子网中的活跃主机

```
use auxiliary/scanner/discovery/arp_sweep
set rhosts 192.168.1.0/24
set threads 50
run
```

## 使用`nmap`进行活跃主探测

```
nmap -sn 192.168.1.0/24
```

![](https://bbs.kanxue.com/upload/attach/201908/862556_3E92MXNQQHB7UQT.png)

## `nmap`中使用udp ping进行主机测试

```
nmap -PU -sn 192.168.1.0/24
```

![](https://bbs.kanxue.com/upload/attach/201908/862556_22GJQV25QBM7MFV.png)

## 使用`nmap`探测目标主机的操作系统版本

```
nmap -O 192.168.1.19
```

![](https://bbs.kanxue.com/upload/attach/201908/862556_3Z2WXFVK9DCJ7T9.png)

## `msf`中的`syn`端口扫描的使用模块过程

```
use auxiliary/scanner/portscan/syn

run
```
