## 脱壳方法总结

1 载入程序

2 设置硬件访问断点，改变这里的跳转使它跳：

```asm
0041912A   74 09                  JE SHORT crackme4.00419135
```

3 设置硬件访问断点，使它跳：

```asm
004193FC   0F84 D8000000          JE crackme4.004194DA
```

这里也可以设硬件断点，可以看得`IAT`：

```asm
00419A8E   8902                   MOV DWORD PTR DS:[EDX],EAX
DS:[004120F8]=17CE3053
```

4 设置硬件断点 SHIFT+F9：

```asm
00419B86   EB 01                  JMP SHORT crackme4.00419B89
```

5 设置内存访问断点 SHIFT+F9：

```asm
00407C2E   55                     PUSH EBP
```

停在这里后，就可以`dump`程序了。
