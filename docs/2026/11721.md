# 给PEiD添加换肤功能（易语言源码）

某一天，见到一个0.96版本的peid，我用的还是0.94版本的，为不至于太落后就下载吧，看了一下，界面被“好事者”改得不太美观，还加上了自己的logo，于是就用刚学的“易语言”写了个dll，然后修改主文件，调用这个dll达到给PEiD换皮肤的目的，共有10种皮肤可以设置。

    如不想使用或更换皮肤，删除PEID目录中的skin.ini文件即可。

    如何修改软件调用我们写的这个dll，这个比较简单，就略去了。
