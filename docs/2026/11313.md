+0x000 Pcb : \_KPROCESS

+0x070 CreateTime : \_LARGE\_INTEGER
+0x078 ExitTime : \_LARGE\_INTEGER

这只是其中的一部分,UniqueProcessId参数是进程的ID,ActiveProcessLinks这个是一个双向链表分别指向了前一个进程和后一个进程的ActiveProcessLinks.这样就把所有的进程连成一个双向的链表,可以方便的查询进程的任何信息.

+0x000 Flink : Ptr32 \_LIST\_ENTRY
+0x004 Blink : Ptr32 \_LIST\_ENTRY
