
# [原创]WinDbg+IDA 五步分析内存泄漏

重点是为了分析内存泄漏，建议分析时，泄漏大小越大越好。

目标：通过`WinDbg`分析内存泄漏处的调用堆栈。使用`IDA`分析处堆栈处的代码特征，从而达到定位源码泄漏位置的目的。

## 分析步骤

1. 找到大量分配内存的堆块。

![](upload/attach/202203/940598_MAVFJFKFSTWZET7.png)

2. 分析堆块的大小以及提交的次数。

![结构大小统计分析](upload/attach/202203/940598_NGG5VRNX4JDZP6R.png)

3. 分析所有大小为4的堆块内存。

![结构大小统计分析](upload/attach/202203/940598_G87CHY4MZ4EAE5D.png)

4. 查看分配指定堆块的调用堆栈。

![结构大小统计分析](upload/attach/202203/940598_GNWJ5PGZ4SB2B28.png)

5. 通过调用堆栈，使用`IDA`来分析代码特征。

![结构大小统计分析](upload/attach/202203/940598_Q7E9ZUGMFZW8JED.png)
