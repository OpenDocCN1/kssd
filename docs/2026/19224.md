# [原创]初玩树莓派B基础系列

这个小系列主要介绍了树莓派的一些基本玩法，从系统安装到实用配置再到GPIO最后接入物联网。

我初学树莓派也主要是玩GPIO，其他的玩法不用树莓派也可以做到。当然作为初学者，有错误也是难免的。如果文中有错误还请指出,我好做出相应修改。

其他的一些玩法可能还有做一些下载机或者爬虫之类的，这些就和树莓派本身硬件没有太多关系了，任何一台机器都可以做，所以也就不学习使用了。希望以后有时间能够学习更多硬件上的玩法，学习更多的知识。
