
# [原创]SlimHook预告 - 全新安卓ART的Hook框架

由于某些原因，此前的SandHook更新较为缓慢，并且因为工程量较大，修改核心部分较为麻烦（使用了较多Native Hook），因此造了个新的轮子：SlimHook

其实此前SlimHook已经应用于多个项目，但是因为稳定性以及易用性原因一直处于备胎位置。

新的SlimHook将会取代SandHook，成为安卓12下默认的Hook框架，并首选运行于SandVXposed、SPatch、SlimXposed、VirtualApp等项目当中。

SlimHook支持安卓11、12下DEBUG应用的Hook，支持安卓2.1 - 12的Java、Native层钩子，在Dalvik VM 1.x环境下将会默认使用类似手淘DeXposed的方案，保证稳定性和兼容性。

SlimHook将会是你的下一个轻量+稳定的ART Java层Hook框架，拥有相当优秀的稳定性和兼容性，并且提供Xposed API以及SPatch Plugin API。
