
# [原创]MS08-011 Microsoft Works 文件转换器中的漏洞分析

**漏洞描述：** Microsoft Works 或 Microsoft Works Suite 版本打开特制的 Works (`.wps`) 文件，则这些漏洞可能允许远程执行代码。成功利用此漏洞的攻击者可以完全控制受影响的系统。攻击者可随后安装程序；查看、更改或删除数据；或者创建拥有完全用户权限的新帐户。

一如既往，是没有公布漏洞细节的，我以前也没有关注过，最近网上传有很多exploit，于是拿来练练手，看看是如何触发漏洞的，分析一下漏洞细节。
