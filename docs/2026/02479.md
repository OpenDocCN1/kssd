运行B-Puzzle，接下来又是漫长而又短暂的3秒钟，点击“Enter reg.code”按钮，
进入注册提示窗口，填写：
User name:tongxinshiwo  Registraiton code:780822
按Ctrl＋N激活TRW，
输入  bpx hmemcpy  ←…… 下断点
输入  g            ←…… 继续运行
返回注册窗口，点击 OK
又返回TRW，你会在屏幕下方看到：
Break on BP1      ←…… 拦截成功
输入  bc \*        ←…… 清除断点
输入  pmodule      ←…… 等于按F12若干次
这时，在屏幕中间你能看到绿色的那一行：
015F:00458AD5  MOV    [EBX+0C],EAX
直接按62下F10到:
015F:0040B9CF  MOV    EDX,02
输入  d eax
输入  e            ←……光标跳至屏幕上部的内存窗口，按↑键向上查看。

一直到 0030:0070EC5C处，
看吧，注册码就在眼前。←…… 在屏幕右上方PROT32下面会有个注册码。
我的是：63259863
按F5返回，会提示“Invalid user name or registration code.”，
点击“确定”按钮，再点击“Enter reg.code”按钮，进入注册窗口，重
新输入User Name和Registration Code，点击“OK”按钮，你就可以看
到“Thank youfor you registering!”。哈哈，我已经是注册用户了！

破解后的思考：
(1)这个软件到期后，会提示“Your evaluation copy has been expired.”
如果这时你点击“Register Later”按钮，程序会自动退出，如果你点击右上角
“×”按钮就会看到游戏画面了。看来10天的限制还是不彻底。下个版本作者
要继续努力哟，嘻嘻……
(2)英文名字的注册码是8个数字，中文的是4个数字，在内存中找到1470这个
注册码后，我还想这是个假注册码呢，没想到一注册到也成功了。在破解以前
未曾想到两个注册码的位数竟相差4位。
