# [原创]【很有时间系列】如何优雅地在内核做dll加载拦截

拦截dll加载有两种思路，一种是从文件入手：minifilter、sfilter...反正都是对LdrLoadDll过程中可能出现的IRP进行拦截

比如

![](https://bbs.kanxue.com/upload/attach/201805/619065_33XU4WPH9ZX98EN.png)

还有一种是从dll本身入手，比如把dll的入口点给patch了，这个等下再讲

先讲第一种，最简单的方法当然是拦截CreateFileMapping/CreateSection，它对应的IRP是IRP\_MJ\_ACQUIRE\_FOR\_SECTION\_SYNCHRONIZATION

注册minifilter就不提了

```
	{
		IRP_MJ_ACQUIRE_FOR_SECTION_SYNCHRONIZATION,
		FLTFL_OPERATION_REGISTRATION_SKIP_PAGING_IO,
		PreCreateSection,
		NULL
	},
```

这时候你已经有了dll路径和FileObject。你可以根据具体需要判断是否需要拦截这个dll

```
if(需要拦截DLL( ProcessId, Data->Iopb->TargetFileObject, pNameInfo)){
  Data->IoStatus.Status = STATUS_ACCESS_DENIED;
  result = FLT_PREOP_COMPLETE;
}
。。。。

```

你以为这样就完事了？

然鹅每次dll被拦截都会提示这个![](https://bbs.kanxue.com/upload/attach/201805/619065_J4MG2BYWCDD98ZT.png)

那么怎么去掉这个提示呢

你需要来自BattlEye的神秘力量，返回值给INSUFFICIENT RESOURCES才能没有错误提示

![](https://bbs.kanxue.com/upload/attach/201805/619065_NZ8WHFNVZRA57EU.png)

```
if(需要拦截DLL( ProcessId, Data->Iopb->TargetFileObject, pNameInfo)){
  Data->IoStatus.Status = STATUS_INSUFFICIENT_RESOURCES;//←这样才能没有错误提示
  result = FLT_PREOP_COMPLETE;
}
。。。。
return result;
```

你以为这样就完事了？

NO，你会发现很多不是dll的文件也进到这个IRP的回调了

那么你需要把非dll的FileObject都过滤掉

怎么判断FileObject是不是dll呢？我的方法还是借助BattlEye神力，ReadFile啊ReadFile

