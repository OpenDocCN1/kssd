
# 管家婆8.2单机版加密狗破解过程 (3千字)

小弟两天不吃狗肉，心里发慌得要命，正好有个朋友叫我破解管家婆，所以就下载了管家婆8.2单机版，看一下它的保护方式，呵呵，谁知它的保护很简单的。

## 工具

`TRW2000`

`W32dasm 8.93` 黄金版

`Hview`

好了，我们找到出错的地方了，往上看看什么地方可以跳过去，地址`005C1223`是一个关键的`CALL`，我们把代码修改一下：

`je 005C1268`改为`jmps 005C1268`
