# [原创]泉行之路

泉行之路

攀蟾折桂摄寰宇，摘星揽月御乾坤。
踏云踩雾骋宵壤，驱风逐日闯天地。
                               ------泉哥

      光阴似箭，岁月如梭，从第一次与电脑的亲密接触到现在已经走过了六个春秋。提到电脑，不得不先说下我与传说中的“小霸王”电脑学习机结下的不解之缘。
     记得初三刚毕业的那个暑假，由于闲时无聊，我就跑到我姨妈家去借了“小霸王”电脑学习机来玩，说实话，当时是为了玩游戏，而并不是为了学电脑之类的“正事”，但是借的时候，我姨妈没有给玩游戏用的手柄，邻居也没得借，因此那个暑假也就没游戏玩了！但是那无聊的日子总得打发吧，于是，我就开始真的办起了“正事”——练打字。当时小霸王上面有一种打字游戏：26个字母每次一个从上至下落下来，你在点相应字母的按键，下面就会发子弹将其打掉，整个游戏共分九关，字母下落的速度一关比一关快。就这样，每天都在键盘上玩“突击”。从早上八点多起床一直到玩到十一点多，再从十二点多一直玩到傍晚五六点，然后吃完饭再玩到晚上八点多，然后去看电视（当时在看卫斯理电视剧），这样下来，差不多每天练习十个小时，这样下来想打字想不快都不行了！最后自然是过关斩将，直至通关，最后一关的速度相当快，我几乎花了一周时间才过关，真不容易啊！这样前后差不多就过了一个月的暑假。
      接下来就是学五笔了，也是差不多重复着之前的节奏，每天在键盘上打字。而这时就在某一天（因年代久远，具体时间已无从考证），学校打来了一个电话说，中考成绩上600分，并且选择就读本校的同学一律免费进行电脑培训，就因为这样，我终于第一次接触了电脑。当时教开机的时候，我都不敢按开机键，怕弄坏了电脑，呵呵……其实那次培训就教了点五笔的知识，其它时间都是要求练打字。由于我有了之前“小霸王”的经历，因此打字速度突飞猛进，十天里面从每分钟五六个字上升到60几个字每分钟。这项经历是我一直引以为自豪的事，直至高一，我一直都是班上的打字冠军。而在高一的打字考试上，我自然也都是得满分，也正因此获得了班上第一个可以上网的人，就这样我第一次接触到了传说中的神秘网络。
在高一暑假的时候，我第一次进入网吧，但当时还只是看看电影，浏览网页之类的无聊事，在高中的网络生活也差不多都是如此，没有什么技术上进一步学习。一直到考上大学，才真正地开始自己的IT学习生涯。但我考上的是省内的医学院校，之前本打算不干医生和教师这两个职业，没想到还是走到这一步了！
      刚进入大学的时候，每天都是用手机看小说，我看的第一部小说就是《黑客传说》，后来又看了《禁区之门》（又名《地狱黑客》）和《指间的黑客》，也正是因为这些小说，我开始了我的黑客学习生涯！
      刚开始学习的时候，都是在手机上看文章学习的，经常去的一个手机网站就是“黑客契约”，当时玩的是都是一些手机上收费服务破解，比如修改手机书签来下载收费的图铃……而关于电脑黑客技术，一般都是从图书馆借书看，偶而到网吧看文章或者电子书。我看的第一本黑客书籍是一本红皮的《黑客入门》，里面有一张中国黑客在中美黑客大战中黑掉白宫的黑页照片，这就更增加我学黑的激情，因此拼命地看完此书，但发现里面的html看不懂，于是又在网吧学html。慢慢地，又开始学C。
      后来在某一天，在图书馆看到了《黑客防线》这本杂志，当时有听过这本杂志，但一直没看过。看了之后，发现上面的脚本入侵文章根本看不懂，因此又开始学asp，php，javascript等脚本语言。
      又后来在某一天，我在图书馆的书架上发现了一本“秘笈”——《深入理解计算机系统》，这本书带领我开始了系统底层的学习，强烈推荐大家有空去看一下这书。我第一次接触的汇编就是在这上面的AT&T汇编，这也导致后来刚接触intel汇编的时候一直没弄懂代码的含义，比如mov指令，一个是左边赋予右边，一个是右边赋予左边，立即数前一个有%，一个没有，当时头脑全乱套了，直至后来学了80x86汇编，才算弄明白了。
      后来的某一天，我无意中来到了“看雪学院”，就这样开始了我的破解生涯。之后我就开始到网上下载电子书来看，当时下了《黑客反汇编揭秘》来看，就这样认识了OD，IDA，SoftIce等工具。由于之前看过《深入理解计算机系统》，还看了两遍，就自认为自己已经会汇编了，于是就开始找CM来破解，但是不玩不知道，一玩吓一跳，上面的反汇编代码，我根本就看不懂，更别说破解了。当时，还是跟着看雪精华集上面的CM破文来学习的，但是文章我根本看不懂。上面的注释，作者又是如何知道的呢？那些代码的真正含义又是什么呢？当时有很多疑问出现在脑海中，自己又没法解决。那一次，我失望地离开了网吧！
之后，我一直在思考：我该如何去学习破解呢，为什么我看不懂文章呢，问题到底出在哪了？经过苦思冥想之后，我得出一个结果：重新学习汇编。于是我下载了中山大学的汇编视频教程来学习，后来才知道，为什么《深入理解计算机系统》一书的汇编其实跟平常我们见到的汇编是不一样。接下来的那几天我都是在网吧渡过的，每天都是在网吧看教程。这样下来，看来这套教程，就花掉了我五六十块钱。虽然比买书贵了点，但学习的效果还不错，比单纯看书学得快，学得牢，是套不错的视频教程。
      后来，我又在网吧看了《加密与解密II》，由于自己一直没有电脑，因此看这些PDF的电子书，都只能在网吧看。之后，新建的图书馆有提供检索机，我又在检索机上看完了加解密一书中尚未看完的剩余部分内容。
      再后来，我看到了罗云彬那书《windows环境下32位汇编语言程序设计》一书，由于当时网上刚好有提供这本书的在线阅读，因此在手机看完这本书，当时连走路都在看。由于经常在走路时看手机，以致后来同学碰到了，如果手机没在手上，都会问我手机呢？由于缺乏实践操作，win32asm学得自然不怎样，只是知道了win32asm原来长这样啊！后来我干脆就到当当网购了这本书，当时是第2版的，然后又认真地把这本书看了一遍。之后，我又网购了很多IT书籍。平时我没有什么花钱的嗜好，现在除了买书，其它依旧如初。
      由于一直都是在玩黑，因此在学习的过程中，一直没有向他人透露这方面的信息，以致同宿舍三年的舍友也无法知晓，直至目前也没人知道，除了我哥，其他现实中的人还没人知道。记得暑假回家的时候，我一高中同学还问我会不会电脑。我现在还幻想着出现这样一幕：“舍友拿着《黑客防线》上面的文章，称他看得懂上面的文章和代码，然后在我面前炫耀，我拿过来一看，发现上面写着作者：riusksk！”可能这现象不会出现了，因为2010.1.11我们都要下临床实习了，舍友都去了不同的地方的医院。
      从08年10月开始我就开始给黑防投稿，骗点稿费买糖糖嘛，呵呵。到目前为止也发表了不少文章，今年暑假就用其中的1500元稿费，再加上我哥的亲情赞助，终于拿下了一台联想笔记本，也就近四千的档次，配置一般，但对我这不玩网游的人来说，足矣！自从有了电脑，一切都不一样了！我开始拼命写稿，拼命学逆向，拼命学编程，一切都沉浸在学习之中！在09年中，从黑防03期到06期，10期到12期均有我发表的文章。而逆向方面的文章以及几篇翻译文章，我大多直接发在看雪论坛上了，赚了几帖精华，哈哈。似乎一切都在有序地进行着，慢慢地成为了某些组织的成员。但这些只是一些虚名而已，这里就不提了！
      由于电脑今年暑假才买，而编程又都要在键盘上练出来，因此编程一直是我的弱项，之前没条件，一直都是停留在看书上面，看的IT书的数量也许已经超过我的专业书籍，至少有一米多高吧。如果之前我每天都去网吧敲代码，光从经济上不说，时间上更是个问题，因此这两三年来，能够在电脑上编程的时间很少。现在终于实现了自己的一台本本，因此近来都是在弥补编程这块内容，VC，win32asm ……由于这段时间经常都是在敲键盘，舍友看见了总是说，这个土人又在聊Q了（由于宿舍没有桌椅，我都是把笔记本搬到床上，因此舍友都是看不到屏幕内容的），而实际上，我还没连网呢！！！
      最后特别祝贺看雪建站十周年：
独领密界整十载，振兴软安扬猷绩。
黉园施教兴华夏，嘉木擎天誉九州。
