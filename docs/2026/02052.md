# ollydbg的一种使用方法（无需任何汇编知识） (1千字)

软件名称：Clipmate 5.3.05 Build 268
下载地址：www.thornsoft.com
破解工具：ollydbg 1.06
破解方法：快速暴破法

破解过程：
1.打开ollydbg，open clipmate,按F9运行
1.进入软件注册画面，输入用户名和任意注册码，这儿设为name：Slimboy，s/n：77777777777777。
3.按F12暂停，进入CPU窗口
4.在右下角Stack窗处，右键单击最顶端的一行数字，选Follow in Dump,进入相应的内存段。
5.在Dump窗（即内存段）右键单击，选Search，在ascii处填Slimboy，然后search
6.在高亮显示的Slimboy处，右键单击选breakpoint－on memory access
7.按F9继续运行clipmate，然后重复第一步
8.你会发现ollydbg自动暂停了程序，查看Stack窗，你见到了什么？你的注册码，应该是G013668254526
9.remove all breakpoint，然后按ALT＋F12退出，这很关键，否则你会死机的，不过即使是ALT＋F12在某些机器上也会死机
破解总结：
依靠ollydbg的强大功能，这样简单的破解不到半分钟，而且简单地甚至不知道什么叫汇编的人也能快速掌握。特别适合newbie用，不过不是所有的软件都可以这样解决，我在这儿也是提供了一种方法而已。
