
# [原创]开源一个自用的云手机方案 `xenoid`

> 仓库地址：[c1bK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6g2L8h3W2S2k6r3g2Q4x3V1k6^5k6h3&6G2K9h3b7`.](https://bbs.kanxue.com/elink@9d3K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6g2L8h3W2S2k6r3g2Q4x3V1k6^5k6h3&6G2K9h3b7`.) （GPL-3.0）

## 功能简述

- 原生支持 Apple silicon MacOS 以及 ARM ECS
- 支持多实例、OTA（OTA功能尚未测试）
- 一键改机、位置与 SIM 模拟
- 理论上无法被检测的全局代理
- ROOT 管理与隐藏
- 抹了一些特征的 Frida 和 eBPF Hook 支持
- 驱动层模拟点击
- 支持服务式启动
- 支持 GMS 与 TEE （keybox 需要额外提供）
- 支持 CLI 与 MCP

测试了市面上做得比较好的若干检测器，和某些头部 APP，目前基本可以认为到了一个初步可用的阶段。

使用也很简单，举个在 Mac 上直接启动的例子：

```
# 先安装环境

./xenoid install-runtime

./xenoid init --config PATH/TO/CONFIG

# 后续一条命令启动即可

./xenoid up
```

具体原理和实现细节大家直接看代码就成，这里就不展开了
