
# [原创]lua助手

最近写了个小工具：lua代码输入助手。

现在很多人在写手机游戏，而手机游戏几乎都是在用lua来写，因为避免app审核太久，而影响app更新速度。

但是lua，居然没有输入助手(也许有，我没发现而已。)，写代码，需要不停的查vc的头文件，很是麻烦。

于是，用Hook方式，写了一个lua输入助手。

功能还不是很完善，希望大家多多给意见，我会持续修改中。。。。。。。。。。。。
