# 破解vfp&amp;exe v1.85 demo加密文件的简单方法 (498字)

vfp&exe v1.85 demo 又一简单破解法
1、运行加密的VFP文件，最小化该进程
2、运行filemon.exe找出VFP最小化进程文件名（在一些特殊目录中）
  （或者开始就运行trw2000调入加密后的vfp文件，BPX 401760后F5，
  中间横线上出现新的进程名后记下该文件名，退出trw2000和vfp加密文件）
3、重新运行vfp加密文件，最小化后用win98下的查找文件找到先记下的那一
  文件后，按右键将该文件复制出来的文件即是去壳后的文件
4、改入口点为401760
5、删除第二次找到的FEF2后的所有字节，存盘后的文件即是可用unfoxall反编译的文件了
