
# [原创] ubuntu 1604下 `one_gadget` 出现 undefined method `unpack1` 问题的解决方案

`one_gadget`是用Ruby编写的，可以用`gem`直接安装，当我使用默认的`apt`安装`ruby`和`gem`，是这样的流程

```bash
sudo apt install ruby gem
sudo gem install one_gadget
```

此时`ruby`的版本：

```bash
# ruby --version
ruby 2.3.1p112 (2016-04-26) [x86_64-linux-gnu]
```

然后用的时候就会报错:

![-w818](upload/attach/202101/757977_ZJXNAR8ZYCFNP4D.jpg)

```bash
/var/lib/gems/2.3.0/gems/elftools-1.1.3/lib/elftools/elf_file.rb:59:in `build_id': undefined method `unpack1' for "\xC4\xFD\x86\xEC\x1E\xEDW\xA0\x9Cy\xCE`\x1Fln7\x96\xF5t\xDF":String (NoMethodError)
```

## 解决方案

1. 卸载已经安装的`ruby`、`gem`、`one_gadget`

```bash
sudo gem uninstall one_gadget
sudo apt remove gem ruby
```

2. 我在`one_gadget`的Github repo中的 Github workflow 中看到,开发者使用的`ruby`版本是2.6

![-w1218](upload/attach/202101/757977_VQFZEDU5CQKQG9Y.jpg)

接下来装个2.6的`ruby`,使用`ruby-install`脚本进行安装，该脚本的安装方式参考README。

配置好脚本后,安装 `ruby` 2.6：

```bash
# ruby-install ruby 2.6
```

等亿会，安装完成。

![-w813](upload/attach/202101/757977_DH2KAEF3VRY63SB.jpg)

把路径加到`PATH`中：

```bash
export PATH="/home/lushan/.rubies/ruby-2.6.6/bin:$PATH"
```

检查`ruby`版本：

```bash
## ruby --version
ruby 2.6.6p146 (2020-03-31 revision 67876) [x86_64-linux]
```

安装`one_gadget`：

```bash
gem install one_gadget
```

正常使用：

![-w536](upload/attach/202101/757977_5ZNX25WQDVGC2NZ.jpg)
