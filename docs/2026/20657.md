# [原创] ubuntu 1604下 one_gadget 出现undefined method `unpack1'问题的解决方案

one\_gadget是用Ruby编写的，可以用gem直接安装，当我使用默认的apt安装ruby和gem，是这样的流程
```bash
sudo apt install ruby gem
sudo gem install one\_gadget
```
此时ruby的版本：
```bash
#ruby --version
ruby 2.3.1p112 (2016-04-26) [x86\_64-linux-gnu]
```
然后用的时候就会报错:
![-w818](upload/attach/202101/757977\_ZJXNAR8ZYCFNP4D.jpg)
```bash
/var/lib/gems/2.3.0/gems/elftools-1.1.3/lib/elftools/elf\_file.rb:59:in `build\_id': undefined method `unpack1' for "\xC4\xFD\x86\xEC\x1E\xEDW\xA0\x9Cy\xCE`\x1Fln7\x96\xF5t\xDF":String (NoMethodError)
```
## 解决方案
1.卸载已经安装的ruby、gem、one\_gadget
```bash
sudo gem uninstall one\_gadget
sudo apt remove gem ruby
```
2.我在one\_gadget的Github repo中的 Github workflow 中看到,开发者使用的ruby 版本是2.6
![-w1218](upload/attach/202101/757977\_VQFZEDU5CQKQG9Y.jpg)
接下来装个2.6的ruby,使用<a href="elink@f4dK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6H3L8%4y4@1L8h3!0V1k6i4u0F1i4K6u0r3M7Y4g2T1P5g2)9J5k6r3W2F1M7%4c8S2L8r3H3`.">ruby-install</a>脚本进行安装，该脚本的安装方式参考README。
配置好脚本后,安装 ruby 2.6：
```bash
#ruby-install ruby 2.6
```
等亿会，安装完成。
![-w813](upload/attach/202101/757977\_DH2KAEF3VRY63SB.jpg)
把路径加到path中：
```bash
export PATH="/home/lushan/.rubies/ruby-2.6.6/bin:$PATH"
```
检查ruby版本：
```bash
##ruby --version
ruby 2.6.6p146 (2020-03-31 revision 67876) [x86\_64-linux]
```
安装one\_gadget：
```bash
gem install one\_gadget
```
正常使用：
![-w536](upload/attach/202101/757977\_5ZNX25WQDVGC2NZ.jpg)
