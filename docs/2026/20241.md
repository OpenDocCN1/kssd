```
int main(){
    int (*ret)();

    if(getenv("EGG")==NULL){
        printf("Give me something to execute at the env-variable EGG\n");
        exit(1);
    }

    printf("Trying to execute EGG!\n");
    ret = getenv("EGG");
    ret();

    return 0;
}
```

很明显，如果能修改EGG环境变量直接执行’/bin/sh’，就能拿到root，而之前的[番外篇](https://bbs.pediy.com/thread-252790.htm)里已经介绍过如何写一个能得到root权限的shellcode了，解题过程如下
