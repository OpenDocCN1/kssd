记得几年前我开始学Arduino的时候，发现Arduino编程语法，很多书籍和教程都是不讲的。为什么呢？大家看完这篇贴子也就明白了。

那么，今天我们就来谈谈Arduino的语法，其实我认为语法最重要的东西应该来讲不是很多。基本的了解了，其他查一下资料应该是没有问题的。

大概有主要有两个部分，一个是程序结构，另一个是循环语句，最后多了一点宏和函数

## 一、程序结构

首先，来说说最基本的程序结构：

![](https://bbs.kanxue.com/upload/attach/201609/70743_j6ulttbmp83oav4.png)

现在，我们给程序增加点代码：

![](https://bbs.kanxue.com/upload/attach/201609/70743_m9rtata9d1x6599.png)

```
int ledpin=13;//定义数字接口13
void setup()
{
  Serial.begin(9600);//设置波特率为9600，这里要跟软件设置相一致。当接入特定设备（如：蓝牙）时，我们也要跟其他设备的波特率达到一致。
  pinMode(ledpin,OUTPUT);//设置数字13 口为输出接口，Arduino 上我们用到的I/O 口都要进行类似这样的定义。
}
void loop()
{
    digitalWrite(ledpin,HIGH);//点亮数字13 口LED。
}
```

## 二、控制语句

不用多说，当然是`if` `else` `for` `while` `switch` `case`等，这些关键字，只要略懂编程应该是没有问题的。

### 1、先来用一下`if`

![](https://bbs.kanxue.com/upload/attach/201609/70743_wc1yd30z4vpc9po.png)

```
int val;//定义变量val
void setup()
{
Serial.begin(9600);//设置波特率为9600，这里要跟软件设置相一致。当接入特定设备（如：蓝牙）时，我们也要跟其他设备的波特率达到一致。
}
void loop()
{
val=Serial.read();//读取PC 机发送给Arduino 的指令或字符，并将该指令或字符赋给val
if(val == 'r')//判断接收到的指令或字符是否是“r”。
{
Serial.println("Hello World!");//显示“Hello World！”字符串
}
}
```

### 接下来 `switch` `case`

![](https://bbs.kanxue.com/upload/attach/201609/70743_fmoemymccw0vin5.png)

```
int val;//定义变量val
void setup()
{
Serial.begin(9600);//设置波特率为9600，这里要跟软件设置相一致。当接入特定设备（如：蓝牙）时，我们也要跟其他设备的波特率达到一致。
}
void loop()
{
val=Serial.read();//读取PC 机发送给Arduino 的指令或字符，并将该指令或字符赋给val
switch (val)
{
case '1':
Serial.println("Hello 1");//显示字符串
break;
case '2':
Serial.println("Hello 2");//显示字符串
break;
case '3':
Serial.println("Hello 3");//显示字符串
break;
default:
break;
}
}
```

## 三、宏和函数

在宏和函数上，我还是非常喜欢的。这样代码写得多的时候，就很方便了。

下面是一个求最小值的宏（宏的名字，我一般会大写）

```
#define MIN(a, b) ((a)<(b)?(a):(b))
```

![](https://bbs.kanxue.com/upload/attach/201609/70743_ut913gzbffwrlpb.png)

![](https://bbs.kanxue.com/upload/attach/201609/70743_s9smnnpaf2j66p3.png)

```
#define MIN(a, b) ((a)<(b)?(a):(b))
int val;
void setup()
{
Serial.begin(9600);//设置波特率为9600，这里要跟软件设置相一致。当接入特定设备（如：蓝牙）时，我们也要跟其他设备的波特率达到一致。
}
void loop()
{
val=Serial.read();//读取PC 机发送给Arduino 的指令或字符，并将该指令或字符赋给val
while(val=='1')
{
Serial.println(MIN(1, 3));//显示较小值
delay(1000);
}
}
```

再来一个求区间的宏

```
#define CONSTRAIN(amt, low, high) ((amt)<(low)?(low):((amt)>(high)?(high):(amt)))
```

![](https://bbs.kanxue.com/upload/attach/201609/70743_ibfk630u2tp13si.png)

![](https://bbs.kanxue.com/upload/attach/201609/70743_vx59rywe4nb5b8i.png)

```
#define CONSTRAIN(amt, low, high) ((amt)<(low)?(low):((amt)>(high)?(high):(amt)))
int val;
int nRet;
void setup()
{
Serial.begin(9600);//设置波特率为9600，这里要跟软件设置相一致。当接入特定设备（如：蓝牙）时，我们也要跟其他设备的波特率达到一致。
}
void loop()
{
val = Serial.read();//读取PC 机发送给Arduino 的指令或字符，并将该指令或字符赋给val
delay(2000);
nRet = CONSTRAIN(val, '1', '10');
Serial.println(nRet);//显示较小值
}
```
