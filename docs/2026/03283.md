
# xplorer2之破解和注册机

## 对象

xplorer2 V1.1.0.2，http://www2.skycn.com/soft/21143.html

## 软件简介

xplorer2是2xExplorer的后续版本，xplorer2拥有全新、非常友好的界面，和Windows的资源管理器一模一样的操作，让你不用学习即迅速上手。

■>>>> xplorer2体积小巧，却提供相当前卫、个性、丰富的功能：

①很有创意的“临时碎片容器”，用过了才知道爽不爽！

②拥有一个目录窗口，两个浏览窗口，可以大图标、详细信息等方式查看文件(跟Windows的完全一样！用过Total Commander、EF Commander吗，也是双窗口，但它们显示的图标较小，用xplorer2就好啦！)

③支持快速书签，批量重命名，方便的快捷键。

④强大的文件搜索功能，直观地统计目录信息让你看个明明白白，提供文件的分割/合并/永久删除等功能。

⑤可即时预览文本及众多类型的多媒体文件（需要相应系统插件支持，建议安装暴风影音，等）。

⑥极好的命令行运行功能，内置DOS控制台，跑DOS命令再无需启动黑窗口！

⑦随时随地的提示信息，上手极快。

⑧附带有一个不错的文本编辑器，比Windows记事本强多了。

⑨没有FTP等鸡肋型功能(怎么说还是FlashFXP专业！)，等等...

总之，这是一款功能丰富、界面简洁、操作简单、身材相当苗条的增强型文件管理器！

key符合下列条件

1.第8位=1

2.从第4位开始的4个char组成一个int在0x1C42F0F和0x1D2D9A0之间并且不等于给定字符串的前4个char组成的int（0x98989898）

3.从0A开始取出值p[a]，再以该值为偏移量得到零一个值p[b]，p[b]^m[i] ==p[b+1],a = b+2,继续进入循环

4.上面的每个p[a]的值之间的距离大于2，并且在0xA-0x62之间

下面给出注册机的代码：在这个代码中我只算出了一组key。当然你可以改一下算出所有key

```c
#include <stdio.h>

void main()

{

  char p[100];

  char q[201] = {0};

  char t[20];

  int a = 0x0a;//a的初始值

  char b = 0x1f;//我把它从0x1f开始，0x1f在0xA-0x62之间

  char m[] = "\xA5\x5D\x12\xE4\x37";\\这时程序初始化的值

  for(int i = 0; i < 100; i ++)

    p[i] = (char)0x88;//没事就用88来填

  for (i = 0; i < 5; i ++)

  {

    p[a] = b;

    p[b + 1] = p[b] ^ m[i];//上面的第三的条件

    a = b + 2;

    b = b + 8;//第四个条件，我让他们相差8〉2

  }

  p[4] = 0x11;

  p[5] = 0x11;

  p[6] = 0x0D1;

  p[7] = 0x01;//这4个值组成0x1d11111在0x1C42F0F和0x1D2D9A0

  p[8] = 1;//这个值必须为1

  //下面是hentostr转化，方法很土，其实可以仿照他的程序中strtohen

  for(i = 0; i < 100; i ++)

  {

    sprintf(t,"%02X",p[i]);

    if((unsigned int)p[i] >= 0x80)

    {

      q[2 \* i] = t[6];

      q[2 \* i + 1] = t[7];

    }

    else

    {

      q[2 \* i] = t[0];

      q[2 \* i + 1] = t[1];

    }

  }

  //存放在文件中

  FILE \*fp = fopen("C:\\key.dat","w");

  if(NULL == fp) return ;

  fprintf(fp,"%s",q);

  fclose(fp);

}
```
