
# [原创]xx助手主体实现简单分析

前段时间写了关于天天酷跑游戏外挂的实现原理。文章链接：http://bbs.pediy.com/showthread.php?t=187948

这几天正好有时间看了下xx助手主体的实现原理，大致如下：

1. `/assets/injectso` 首先跑起来，然后判断目标进程，即要注入的游戏进程中是否有 `libxxghost.so` 文件，如果没有，那么就关闭 `selinux`，往目标进程中注入 `libxxghost.so`，然后执行 `libxxghost` 的 `loadResAndPlugin` 函数。

2. `libxxghost.so` 注入到目标进程后，`loadResAndPlugin` 函数开始加载 `libsubstrate.so`，`libxxdvm.so`，`libxxAndroidLoader.so`，调用 `libxxAndroidLoader` 的 `loadXXPlugin`。其中，`libsubstrate.so` 和 `libxxdvm.so` 都是和 `hook` 相关的。

3. `loadXXPlugin` 的功能就是把 `xxUI.apk` 注入到游戏进程，然后实现具体外挂的功能。详见此文：http://bbs.pediy.com/showthread.php?t=187948
