# [原创]APIMonitor源码

很久没正式来看雪论坛了，看到2年前发布APIMonitor有不少的同学求源码，同时由于后续工作较忙，也没有继续更新，有不少的bug也没去修复，有负大家的期待。同时，那时候代码还写得比较烂，也不敢献丑，有时间的话再重新用C++写一遍，这里先分享一下那时丑陋的源码，基本原理就是采用Inline Hook的方式Hook进程中的任意Dll的导出函数，截取相关信息后汇总统计。

![](https://bbs.kanxue.com/upload/attach/201909/93_V49JFRJNEUZDRAF.jpg)
注意：
1、APIMonitor对64位程序无效，个人自测XP，win7 32位均没问题，64位进程的Inline Hook需要改写Hook代码和反汇编引擎

2、反汇编引擎用的是玩命版主的反汇编引擎（http://bbs.pediy.com/showthread.php?t=74414）

3、APIMonitor的使用介绍和说明见<http://bbs.pediy.com/showthread.php?t=180997>

4、代码用VC6编译
