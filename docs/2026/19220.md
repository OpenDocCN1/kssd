
# [原创]Arduino与Teensy

这篇说一下Teensy，平时我们用Arduino或者单片机的时候，要装驱动和相关软件，有时候就有点不方便，当然大部分时间还好。

对于我来说Teensy的好处是：可以很简单就完成模拟鼠标和键盘操作。

我购买的Teensy 2.0++的芯片是`AT90USB1286`，要在板子上做其他扩展只能自己焊了。

再来个鼠标的例子吧

代码：

``` 
void setup() { } // no setup needed

void loop() {

  int i;

  for (i=0; i<40; i++) {

    Mouse.move(2, -1);

    delay(25);

  }

  for (i=0; i<40; i++) {

    Mouse.move(2, 2);

    delay(25);

  }

  for (i=0; i<40; i++) {

    Mouse.move(-4, -1);

    delay(25);

  }

}
```

这里一定注意，选择USB类型
