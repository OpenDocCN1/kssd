
# [原创]发一个我用C语言编写的PEInfo（附源码，基于win32 sdk）

本人大三学生，在学校主要用的是C和Java进行开发和学习，没学过C++，但是本人也对Windows平台的逆向分析很感兴趣，会学习一些相关知识，也做过一些Crackme之类的（我连菜鸟都不算），但是PE结构可以说是必须要了解的知识，最近一段时间读了《加密与解密》上关于PE格式的内容，但总感觉记不住，于是就想自己做一个PEInfo工具帮助自己巩固学习，参考了PEditor和LordPE等工具的风格（个人感觉LordPE真的是一个伟大的工具），可以解析PE格式基本信息，数据目录表，输出表，输入表，资源结构，区块信息，任务管理器，相对虚拟地址转换器。

虽然学过一些Windows编程，但是感觉使用c语言编写这样的gui程序真的是很麻烦的事情，查了不少msdn文档，看来还是要去学一下c++。。

这个程序的功能比较基本，但对我而言能完成已经是一个成功了，接下去有时间我会继续完善这个工具，增加更多功能，再扩展成支持x64版本

IDE: Visual Studio 2017 Community
