在进程中利用以下代码调用函数,可以达到稳定

```
	  00000000  55                push ebp
	  00000001  89E5              mov ebp, esp
	  00000003  C9                leave
	  00000004  58                pop eax
	  00000005  870424            xchg eax, [esp]
	  00000008  FFE0              jmp eax
	  0000000A  89EC              mov esp, ebp
	  0000000C  5D                pop ebp
	  0000000D  C3                ret
```

构建的远程调用函数有最大支持15个参数的传递,只支持int类型
