## 过程

### 一、尝试注册

这个软件每次启动都要提示注册，输入：

```
email：ratarice@sina.com
regsiter code: 01234567890123456789
```

点`register`按钮，当然了，结果是弹出一个对话框`Invalid register code!`

### 二、用 PEiD 检查软件

用`PEiD`检查软件，发现没有加壳，报告是`Microsoft Visual C++ 7.0`，正和我意。
