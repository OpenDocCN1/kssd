# 俺来写写“超级光盘管理员1.注册码的获取方法”的破解点吧。 (1021字)

超级光盘管理员1.注册码的获取方法

下载地址：URL http://go.163.com/~cdmanager/cdm.zip

本软件可以使用通用的万能中断bpx hmemcpy来中断并得到注册码。
使用中要注意首先判断按F12的次数。下面开始。

1、首先载入vcdrom.exe，然后选择注册。随便输入注册码和其他信息了，我输入的是用户名：CrackerABC[BCG]邮件地址随便，注册码：31415926。

2、然后启动TRW2000（防止有些软件检测TRW2000）点确定，然后用热键
Ctrl+N 呼叫出trw2000，下断点bpx hmemcpy。
3、F5返回程序空间后点注册，被TRW2000拦截到。
4、在TRW2000窗口中下BD \*终止断点。开始按F12，当按下第15次时，出现错误提示。
5、BC \*清除断点然后X返回程序空间，重复1，2，3，4步，在4中，按F12的次数是15-1=14次（这就是一般程序按F12的次数的规则，出错前的为最后一次）这里呢就当然是14次了。

6、下面就开始按F10了，呵呵，有时候是几次，有时候是几十或者几百次啊，当然有时候要跟进一些CALL关键子程序中去的。这里呢只按F10几次就可以了。

7、按F10一直使光标到下面的地址：
0167：0049990F POP EAX ；------> 下D EDX 得到注册码：9910
8、呵呵，就这么简单。整理注册，一切都变的清净了。俺喜欢！！！
