## 2. 定位
### 2.1. 关键字定位
IDA 载入 WechatWin.dll
#### 2.1.1. IDA 操作
宽字符关键字搜索
```
打开设置: Options -> General -> String -> Default string literal type
把 C-style 下拉选项改为 Unicode C-style (16 bits)
打开 String 窗口: View -> Open subviews -> Strings
快捷键: Shift + F12
搜索关键字 "Duilib"
得到数据:
.rdata:11478C84 ; const WCHAR aDuilib
.rdata:11478C84 aDuilib: ; DATA XREF: sub\_1080F1A1+267↑o
.rdata:11478C84 ; sub\_1080F1A1+294↑o
.rdata:11478C84 text "UTF-16LE", 'Duilib',0
然后双击跟入 sub\_1080F1A1 函数
```
#### 2.1.2. CE 操作
如果 IDA 搜索不到，也可以尝试 CE 搜索
```
CE 打开 Wechat.exe
选择 UTF-16、不可写
搜索关键字 "Duilib"
搜索得到地址: WeChatWin.dll + 1478C84
那么在 IDA 中的地址为: WeChatWin.dll + 1478C84 = 10000000 + 1478C84 = 11478C84
IDA 快捷键 G 跳转地址: 11478C84
然后还是按照 2.1.1 后面的步骤操作找到函数
```
