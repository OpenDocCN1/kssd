
# [分享]win7下<0day安全>栈溢出

最简单的栈溢出，大佬请直接跳过。

在win7下使用编译器编译下面的代码：

![](https://bbs.kanxue.com/upload/attach/201809/798964_FF39E5P87XDXUBA.jpg)

首先使用ollydbg打开程序，在`strcpy`处下断点，停留在图一位置：

![](https://bbs.kanxue.com/upload/attach/201809/798964_7BAZNWEKGH84HZN.jpg)

继续f8，可以看到栈的返回地址已经被我们覆盖为我们`shellcode`处的地址：

![](https://bbs.kanxue.com/upload/attach/201809/798964_4UKJF4PDHZ5QH2V.jpg)

继续单步，成功跳转到我们代码：

![](https://bbs.kanxue.com/upload/attach/201809/798964_HPQ9NFHX5TTBZF6.jpg)

可是此时程序却不能执行就结束了，由于是刚开始学，我也不知道为什么，后来查资料发现是微软的数据程序分离的技术，我们无法在win7执行这段程序，但是为了成功在win7上执行，所以我们可以把它关掉，具体方法是下图：

![](https://bbs.kanxue.com/upload/attach/201809/798964_S4A5RK93NMDNBXP.jpg)

重启后我们就可以执行了：

![](https://bbs.kanxue.com/upload/attach/201809/798964_DZGZNZV25EWF6C5.jpg)

继续单步，成功执行代码：

![](https://bbs.kanxue.com/upload/attach/201809/798964_V4D56H88Y7BW58X.jpg)

希望能帮到刚开始学习的你。
