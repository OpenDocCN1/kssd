
# [原创][WM系统开发]枚举当前可用SD卡目录[MASSADA0012]

在WM中SD卡是重要的存储设备相当于PC系统的硬盘。用户有大量数据和程序保存在其中。SD卡一般以目录形式出现在根目录下，用户可以方便的访问比如模拟器上一般为`\Storage Card`目录。但是在真实系统中SD卡对应的目录名不是固定的。比如我见过`\SDMMC`或者`\存储卡`等等。

甚至在模拟器上如果在设置SD卡共享目录前已经存在`\Storage Card`目录则系统会将SD卡目录自动设置为`\Storage Card2`。因此我们的程序不能固定使用`\Storage Card`作为SD卡的目录名。WM中有一组特殊的API可以解决这个问题。

## 相关头文件与库

头文件：`projects.h`

Lib库：`note_prj.lib`

## API说明

`FindFirstFlashCard()`：获取第一个可用的SD卡信息，使用`WIN32_FIND_DATA`结构体保存这些信息。

返回查找句柄。

`FindNextFlashCard()`：使用查找句柄和`WIN32_FIND_DATA`查找下一个可用的SD卡信息，返回`BOOL`类型的查找结果。

`FindClose()`：关闭查找句柄。
