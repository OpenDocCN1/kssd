
# [原创]VMPStudio-1.0正式版，再也不用找IDA泄漏版了

## VMPStudio

VMPStudio核心功能`LightIDA`的目标是覆盖`IDA` 80%的能力，且永久免费。这样，咱们就不用苦苦寻找`IDA`泄漏版了。况且，有时候我们只是想简单看一看目标文件，用不上`IDA`那么笨重漫长的分析，此时，`LightIDA`刚刚好。

希望各位朋友能喜欢这个产品，么么哒～

### Description

An arm/arm64/x86/x64 IDA for UnicornVM/Decompiler/PhoneVMP, it's free to use as a LightIDA tool.

* GUI Runtime is based on `Qt`;
* GUI Controls is based on `X64Dbg`;
* Assembler/Disassembler is based on `LLVM`;
* Script is based on `Python`;
* AnalyzeEngine is developed by `YunYoo`;

VMPStudio:

* Windows user: download from `VMPStudio-Win`;
* Intel macOS user: download from `VMPStudio-Mac`;
* ARM macOS user: download from `VMPStudio-iOS`;

Plugin DevTool:

* Windows user: download from `ADPluginDev-Win`;
* Intel macOS user: download from `ADPluginDev-Mac`;
* ARM macOS user: download from `ADPluginDev-iOS`;
* The `vspsdk` and demo, look into `include/plugin` for more information.
