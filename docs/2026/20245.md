```
#include <string.h>
#include <stdlib.h>
#include <stdio.h>
#include <ctype.h>

extern char **environ;

int main(int argc,char **argv){
    int i;
    char buffer[256];

    for(i = 0; environ[i] != NULL; i++)
        memset(environ[i], '\0', strlen(environ[i]));

    if(argc>1)
        strcpy(buffer,argv[1]);

    return 0;
}
```

我死活没看懂这个for循环存在的意义在哪儿，因为这题和这个for循环一点儿关系都没有，这题的解法和[narnia2的解法](https://bbs.pediy.com/thread-252827.htm)相同，也是利用nop滑板原理（因为没开NX），不过是对narnia2的复习罢了，不过还是要注意之前说的每16字节对齐的问题，调试结果如下
