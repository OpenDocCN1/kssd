
# 请高手试试这个软件的破解，它的保护非常的好，要破它实在是有点难度。

软件名称：BrainsBreaker 版本：2.5 大小：953KB

软件介绍：一款拼图游戏，实在是精品中的精品！

下载地址：`http://www.brainsbreaker.com`

## 破解时请注意以下几点：

1. 该软件没有用任何软件加壳，修改代码后运行程序会发现自己被修改过，但不影响运行。

2. 进入界面后直接按 `CTRL+F8` 来呼出“注册信息框”，形式如下：

```
PACK: Full
NAME: The GodFader
YOUR ID: PZCRACKTEAM
KEY: 77473408754
```

3. 我参考了国外一个 2.3 版本破解的补丁，他是先将主程序打个补丁，再在“注册信息框”中输入相应的注册信息，如上所示。大家可按这个思路来考虑。
