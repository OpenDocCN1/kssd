# 一、程序基本分析

程序名称`1.ab`，不知道什么文件格式

文件目录下通过`file`分析文件结构

```
file *
```

![图片描述](upload/attach/202207/941979_6AUP37A9TMZV55T.png)

【droid Backup】安卓备份文件，可以用`ade.jer`提取

下载`ade.jer`，输入命令：

```
java -jar ade.jar unpack 1.ab 1.tar
```

将`1.ab`文件解释成`1.tar`文件

解压`tar`文件：

```
tar xvf 1.tar
```

解压`tar`文件成`apps`文件夹

文件夹内存在`apk`和数据库相关`db`文件等

# 三、objection hook获取密码

启动`objection`

```
objection -g com.xxx.xxx.xxx
```

`hook getWritableDatabase`方法（静态分析中知道该方法来自哪个类）

```
android hooking watch class_method net.sqlcipher.database.SQLiteOpenHelper.getWritableDatabase --dump-args --dump-backtrace --dump-return
```

![图片描述](upload/attach/202207/941979_PV5T63T5VDGXXQH.png)

堆中搜索`MainActivity`类实例（因为调用他类中的`a`方法）

```
android heap search instances com.example.yaphetshan.tencentwelcome.MainActivity
```

![图片描述](upload/attach/202207/941979_S4Y3RNNEE4738Q8.png)

调用`a`方法

```
android heap execute 0x60042a a
```

![图片描述](upload/attach/202207/941979_UDGEBHQ2Y96MX77.png)
