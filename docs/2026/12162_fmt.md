
# [原创]浅述 `KdPrint` 在 checked 和 free 版本的不同

## checked 版本

在 checked 版本中，`KdPrint` 会被 `DbgPrint` 所代替。

我们编个简单的程序：

```
NTSTATUS DriverEntry(PDRIVER_OBJECT pObj, PUNICODE_STRING path)
{
    pObj->DriverUnload = DriverUnload;
    KdPrint(("123"));
    return STATUS_SUCCESS;
}
```

可以用 IDA 简单地看一下：

![](https://bbs.kanxue.com/upload/attach/201308/597880_2ie6qitvujsmpis.jpg)

显然，`KdPrint` 被 `DbgPrint` 所代替了。

## free 版本

在 free 版本中，`KdPrint` 无效，不做任何事情。

可看 IDA 分析结果：可见不做任何事情。
