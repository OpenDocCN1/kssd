这个题目既然出自C语言里面。那么自然就使用C语言来回答。汇编以及其他语言就不用了。

循环有 `for（；；）` `while（）` `do while（）`

不使用循环，不使用If，将其逆序输出。

例如：

输入：`124578ABc` （长度限制为100吧，无限输入还是不现实）

输出：`cBA875421`

下面是我的作答。我采用递归算法，加`switch`结束。总共代码21行。

不过，不知道还有没有更简单的，希望大家能给出更简单的。

语言的话都整C语言吧。

```c
#include<stdio.h>

#include<string.h>

char c[100];

void daoxu(int n)

{

printf("%c",c[n]);

switch(n)

{

case 0:break;

default:daoxu(n-1);

}

}

int main()

{

scanf("%s",&c);

int i;

i=strlen(c);

}
```
