# [原创]projectoz编译

高手飘过...
前几天下了个WRK,编译后想再编译projectoz学习下,本人比较懒,直接GOOGLE了下,只找到了readme中的下面几行帮助,
    set  wrk=the WRK directory
    set  projectoz=the ProjectOZ directory
    path %wrk%\tools\x86;%path%
    nmake -nologo x86=
刚开始做了个批处理,把这几行放进去,编译时报没有找到"nt.h",又到网上一顿好找,只找到2条,也没有什么帮助,书店也转了下,最后没办法,觉得还是自己尝试解决吧.
打开projectoz目录下的makefile文件,一开始就发现wrk目录设置与自己机器不符,马上备份一份原文件,修改为正确路径。我最后编译做的工作为：
在环境变量里添加了2个变量：
wrk=E:\WRK-v1.2
projectoz=E:\ProjectOZ
在path路径前面加上path %wrk%\tools\x86;%path%；
做了个批处理文件，内容就2行：
    path %wrk%\tools\x86;%path%
    nmake -nologo x86=
然后运行这个批处理，没想到编译成功，而且可以使用。![](https://bbs.kanxue.com/view/img/face/27.gif)
