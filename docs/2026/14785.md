# [原创] 微信群聊闹鬼，自动乱发东西,定位原因

今天上午 ，多个微信群里突然好多人@我,说 微信群聊闹鬼了：自己的微信一直乱发广告还不能撤回.
![图片描述](upload/attach/201904/630232\_REF5DJPKEVUPT4D.png)
我自己也赶紧把所有的模块都关闭.但是关闭完.发现我自己的微信还是发广告了.
![图片描述](upload/attach/201904/630232\_2RDQ757TQPGAC6W.png)
很是奇怪啊 .同时另外一个朋友告诉我.他的手机没有root没有装插件还是发广告了. 20个微信群隔几分钟 自己的微信就会一直发广告.难道真是闹鬼吗?
作为开发者我感觉这个事肯定是微信的一个漏洞把.我赶紧拉自己的小号建了一个群.发这个广告转发到群里.从小号那里却发现 是小号自己的发的消息.这下确定了.肯定是微信识别参数的时候识别错了

构造完毕 发送消息
