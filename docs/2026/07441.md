# Ntoskrnl\_Viewer X64
## 本项目含三个模块
1.驱动模块（编译后的驱动需要和EXE放在同一文件夹）
2.用户模块
3.成品模块（驱动已签名）
## 功能 function：
可在不开启测试模式和WinDbg本地调试的情况下，以符号化的形式浏览本地内存！
不管是否为导出函数、未导出函数、系统内核变量、标志，只要在PDB文件中的符号，都能浏览其内存。
只支持X64系统，理论上支持任何版本（只要微软公开了此版本的PDB）
