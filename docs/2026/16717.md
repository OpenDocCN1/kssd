# [原创] 从Mach-O中导出swift对象定义的小工具：SwiftDump

#### SwiftDump
项目地址 <a href="elink@630K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6F1k6h3W2D9i4K6u0V1N6%4g2Q4x3V1k6e0N6$3W2X3N6p5c8#2L8i4l9`."><mark class="encrypted">f4bK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6F1k6h3W2D9i4K6u0V1N6%4g2Q4x3V1k6e0N6$3W2X3N6p5c8#2L8i4l9`.</mark></a>
SwiftDump是从Mach-O文件中获取swift对象定义的命令行工具，类似大家都用过的OC类dump工具<a href="elink@b27K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6F1P5h3N6S2M7X3c8Q4x3V1k6U0L8r3q4K6M7#2)9J5k6r3c8#2L8i4m8Q4x3V1j5`.">class-dump</a>，SwiftDump专注于处理swift对象(当前只支持swift 5)。对于采用OC/Swift混编的Mach-O文件，你可以将 class-dump 和 SwiftDump结合起来使用。
同时，我在<a href="elink@1b6K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6%4N6%4N6Q4x3X3g2X3M7X3W2V1j5g2)9J5k6i4u0W2i4K6u0r3">Frida</a>中实现了一个简单版本 <a href="elink@0edK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6F1k6h3W2D9i4K6u0V1N6%4g2Q4x3V1k6r3M7X3W2V1j5g2y4%4K9h3k6@1c8s2g2E0M7q4)9J5c8R3`.`.">FridaSwiftDump</a>。
你可以根据需要选择使用， `SwiftDump` 可以解析处理Mach-O文件，而 `FridaSwiftDump` 可以对一个前台运行的app进行解析。
\*\*如果你对解析Mach-O的过程感兴趣，请查看该文档最后的配图。\*\*
效果演示：
![](upload/attach/202007/736021\_YVKJU7NBW3AQAX8.jpg)
#### 用法
```
USAGE: SwiftDump [--debug] [--arch <arch>] <file> [--version]
ARGUMENTS:
<file> MachO File
OPTIONS:
-d, --debug Show debug log.
-a, --arch <arch> Choose architecture from a fat binary (only support x86\_64/arm64).
(default: arm64)
-v, --version Version
-h, --help Show help information.
```
\* SwiftDump ./TestMachO > result.txt
\* SwiftDump -a x86\_64 ./TestMachO > result.txt
#### 特点
\* 完全使用swift编写，项目小巧
\* 支持 dump swift 5 的 struct/class/enum/protocol
\* 支持解析 enum with payload case
\* 支持解析 swift类继承 和 protocol
\* 由于采用swift编写，所以借助于swift的运行时函数来还原修饰符(demangle) 比如， `swift\_getTypeByMangledNameInContext`  和  `swift\_demangle\_getDemangledName`
受益于swift运行时函数, SwiftDump可以还原复杂的数据类型, 比如某个使用RxSwift声明的变量类型能达到如下的解析效果：  `RxSwift.Queue<(eventTime: Foundation.Date, event: RxSwift.Event<A.RxSwift.ObserverType.Element>)>`

```
ARGUMENTS:

                          (default: arm64)
  -v, --version           Version
  -h, --help              Show help information.
```
