## 0x00 前言

这几天清理硬盘，整理资料发现一份两年前分析SanforBotScan的分析笔记，本身没多大技术含量，思路上可能有点借鉴意义，留着没有意义，没准哪儿天就删了，分享出来，留给有需要的人，大牛轻拍。

## 0x01 背景

当时应该是有需求分析一下友商产品中的规则(rule)。

### 3) 从规则格式入手

看样子像是解密之后的规则信息，猜想是不是可以直接从这个地方dump规则呢？经验证是可以的。

具体调试分析过程比较繁琐，我写了一个python脚本从通过windbg直接将全部解密后的规则dump到相应文件。代码如下：

dump\_rules.py

```
#coding:utf-8
#!/usr/bin/python

try:
    import immlib as dbglib
    from immlib import LogBpHook
    __DEBUGGERAPP__ = "Immunity Debugger"
except:     
    try:
        from pykd import *
        import windbglib as dbglib
        from windbglib import LogBpHook
        dbglib.checkVersion()
        arch = dbglib.getArchitecture()
        __DEBUGGERAPP__ = "WinDBG"
    except SystemExit, e:
        print "-Exit."
        import sys
        sys.exit(e)
    except Exception:
        import sys
        exit(1)

from pykd import *

dbg = dbglib.Debugger()

# 获取msvcr90.dll基地址
modules=dbgCommand('lm m msvcr90').split('\n')
msvcr90_base_addr = modules[1][:8]
# 获取fsopen函数地址
fsopen_addr = int(msvcr90_base_addr,16) + 0x301af
##dbg.log("fsopen_addr: " + str(hex(fsopen_addr)))
# 对fsopen下断
setBp(fsopen_addr)

yr_compiler_add_string = 0

go()

flag = flag1 = 0
timer = 0
bp_flag = 1000
temp = 0
while 1:
    # 获取fsopen打开的文件路径及名称
    ebp = reg("ebp")
    ptr_path = ptrPtr(ebp+8)
    file_path = loadCStr(ptr_path)
    ##dbg.log(file_path)
    file_name = file_path.split('\\')[-1]
    ##dbg.log(file_name)
    
    # 判断是否为enc文件
    if file_path[-4:] == ".enc":
        if bp_flag == 1000:
            # 获取yara基地址
            modules = dbgCommand('lm m yara').split('\n')
            yara_base_addr = modules[1][:8]
            # 获取yr_compiler_add_string函数地址并下断
            yr_compiler_add_string = int(yara_base_addr,16) + 0x5ea0
            bp_flag = setBp(yr_compiler_add_string)
            go()
        else:
            go()
        
        # 获取规则信息并保存到相应文件
        eip = reg("eip")
        while eip != yr_compiler_add_string:
            go()
        
        esp = reg("esp")
        begin_addr = ptrPtr(esp+8)
        ptr_rule = begin_addr

        while 1:
            test = loadBytes(ptr_rule,0x1)
            if test[0] == 0:
                break
            
            ptr_rule = ptr_rule + 1
        length = ptr_rule - begin_addr + 1
        rules = loadBytes(begin_addr, length)
        
        rule_lines = []
        line = ""
        for byte in rules:
            if byte == 10:
                rule_lines.append(line)
                line = ""
            if byte == 0:
                break
            line += chr(byte)
        output = open('d:\\rules\\'+file_name, 'w')
        for line in rule_lines:
            output.write(line)
        output.close()
        go()
    go()
    if flag == flag1 and timer == 500:
        break
    if flag == flag1:
        timer = timer+1
    flag1 = flag
```

上面的脚本需要按如下步骤运行：

(1) windbg运行SangforBotScan.exe，勾选debug child process also

(2) 输入命令.childdbg，F5运行断在子进程

(3) 设置如下断点：bp MSVCR90!fopen+0xd

(4) F5运行，断下来后清除断点bc \*

(5) 加载pykd插件:.load pykd.pyd

(7) 运行脚本:!py dump\_rules.py

之后规则文件会保存在脚本中指定的目录下。
