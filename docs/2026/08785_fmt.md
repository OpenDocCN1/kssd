
# [原创]加密狗检测工具源代码

此源代码绝对原创，检测机制是利用USB设备的VID和PID，准确率99%，为什么说99%呢，因为针对HASP的狗还不是能很准确的判断，因为HASP的狗全部是一样的VID和PID，判断型号需要从狗里读出狗的参数才能准确判断。

本人发出来，是希望有人帮完善一下，做成能扩充狗型号，免除了每增加一种狗就要重新编译程序，本人实在是没什么时间去完善了。

源码用Delphi 7编写，如果没有安装D7，自行去找找下载了。
