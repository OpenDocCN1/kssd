## 0x1 包的命名
&emsp;&emsp;1.什么是包名
在安卓中，包名是app唯一标识符， 同一个系统不能有两个相同包名的app.
&emsp;&emsp;2.命名规范
域名后缀.公司名.项目名称
例如: com.kanxue.app
&emsp;&emsp;3.包名的位置
```
androidManifest.xml
package= "com.metasploit.stage"
```
