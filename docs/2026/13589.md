# 基础分析

## 基础静态分析

就是在程序不运行的情况下尽可能多的使用工具对进行病毒行为信息的搜集和整理和猜测的过程。PS:最后需要通过IDA和OD对这些病毒行为猜测进行验证。

### 资源信息分析

有些病毒会利用资源表对自己进行隐藏，所以需要利用资源工具对资源信息进行分析检测。

![图片描述](upload/attach/202002/784955\_CC62R7CRKK63P99.png)

### 查看导入表

将病毒文件拖入Load PE查看每个DLL导入的API，对病毒具体行为进行初步的猜测。为了方便大家观看，我利用Load PE的文本显示功能将导入表信息复制到了txt文件中并进行了整理。PS:这一步只是对病毒行为进行简单的猜测，目的是为了给详细分析时提供思路。具体病毒行为还是要通过IDA和OD双剑合璧为准。

静态字符串检索方法：

2. 使用IDA进行字符串筛选（推荐）

# 手杀方法

1. 结束`spo0lsv.exe`
2. 通过注册表管理器将隐藏属性`svcshare`修改为1
3. 注册表中`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`下的自启子键删除
4. 将隐藏的`Setup.exe`和`autorun.inf`删除
5. 删除`Desktop_.ini`

## 手杀方法

2、通过注册表管理器将隐藏属性`svcshare`修改为1

4、将隐藏的`Setup.exe`和`autorun.inf`删除
5、删除`Desktop*.ini`
