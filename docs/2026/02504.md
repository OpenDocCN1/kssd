
# 破解心得之eXeScope篇

使用工具：`Fileinfo v2.43`、`W32DSM`白金版汉化版、`TRW2000 v1.22`

由于这个软件没有加壳，因此破解相对容易一些，且注册算法也不复杂，很适合初学者破解。

先执行`TRW2000`，然后运行该软件，填好`Your Name`和`ID`后，按`Ctrl+N`激活`TRW2000`，然后键入"`BPX HMEMCPY`"，按`F5`跳回程序，然后点`OK`就会被拦下，再键入"`pmodule`"，继续按`F10`。
