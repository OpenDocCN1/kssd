# [原创]一个虚拟桌面程序（源码）

使用说明：刚开始只有默认桌面，你可以点击新建按钮来添加，添加以后对应的按钮就会启用。然后随便选中一个桌面，包括默认桌面，这时如果有最后的快照会显示出来。选中桌面以后点击切换，这时应用程序会跟着跳到你要切换的桌面，但这时是没有任务栏的，点击在当前桌面新建Shell，任务栏就出来了。
