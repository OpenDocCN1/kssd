
# 关于自学逆向的疑问，年龄和学历是否会成为一大障碍？

先说一下我自己，83年出生的，眼看也马上奔3了，有时候是真感觉自己老了。

只有初中文化，96年以后就出来闯荡社会了，到02年中间的几年了，学了很多行业，厨师、驾驶、装潢、汽车维修都跟过一段时间师傅，最后实在不感兴趣跑路了。（工资只有1000出头，包食宿）

2000年的时候镇上有了网吧，开始接触到计算机，记得2000到02年这2年，只会玩QQ，泡聊天室。03年的时候无意中看到一本《黑客防线》，被书里的一些内容吸引住，买了回去研究，但是完全看不懂。只有个别简单的针对QQ之类的文章能看个大概。

后来经常去2个黑客论坛，记得那会为了回答别人一个注册表的问题，把书上关于注册表的一段内容死记硬背下来再去回答，自家没电脑，所以只能这样。

03年到05年2年，在家里常去的那个网吧的技术员介绍下，去了南京某网吧做网管。网吧里大家都了解，技术含量有限，平时遇到问题我也喜欢自己先想办法解决，最后没招了再去求助baidu，GG，2年下来对`windows`系统管理和网络管理以及故障方面算了多少有了些了解。（工资1100，管住不管吃）

06回到老家接了几家中小型网吧做维护工作，内容就是（系统安装，网络布线，路由器和一些收费系统制作），平时闲着无聊捣鼓捣鼓网站，学会了简单的`HTML`网页制作。（工资2500-3000之间，吃饭住宿自己解决）。

07年底进了市里一家专业的网络维护公司（就是做做网吧，学校，宾馆这些地方的网络组建和维护）后来被分配到一个县城里专门负责那一块的6-7家网吧。（工资给了2800到3000，住公司宿舍，吃饭基本都是BOSS请客，然后自己钱哪去了？都拿去泡妞了。）

这一年多的生活感觉是逍遥自在，每天闲着没事没想着学点东西，就顾着泡MM了，一年多可能比一些纯情少年一辈子泡的妞都多。

08年因为公司BOSS招了一些只拿钱不做事的人，这些人来了直接把我们几个做技术员的（汗，虽然技术含量有限，但称呼都这样）工资分流了，本来我3000+的工资直线下降到1800，最后一怒之下，辞职不干了。

辞职后和当时在公司里出来的另外2个同事一起自己做，做了2个月还算行。后来和家里有些矛盾从小就有一直化解，在08年下半年出来外地。在这边一个还算不错的网吧做技术（名义上的，其实每天都闲着无聊，除了偶尔修下打印机或者某个电脑硬件故障网管不会弄再去整下，其他时间都没事做），一直到今年前半年都这样恍恍惚惚的过来了。网吧技术上也实在没什么值得继续去深入的了，再深入都涉及到程序方面，自己也不懂。

前几个月一直在自己做网站，利用以前自学到那点有限的`HTML`知识做了个简单页面，然后和其他人交流，一致认为学`PHP`编程很有前途，于是买了书，又查了一些资料，学`PHP`同时要学会`MYSQL`等数据库，要学会`linux`下的`APACHE`，要会`HTML`、`AJAX`、`CSS`等等，我傻了。

又去咨询了一些朋友，结果是`PHP`一般程序员拿的工资和我现在差不多，最高级的也就相当于一个中级的逆向工程师的工资（当然有一些能力突出的算例外，以我现在基础，我没觉得自己2年内能成为一个能力突出的`PHP`高级程序员）。

于是认真的想了想，反正都要从头开始，干脆就从最难的学，因为现在工作的原因，所以时间很充足，从前几天买了王爽老师的《汇编语言》、罗云彬老师的《WIN32汇编》、谭浩强老师的《C程序设计》和看雪段老大的《加解密第三版》，就一直在看书，一天差不多从早上8点看到晚上11点。

目前看的王爽老师的《汇编语言》看过的部分已经基本理解了，还有一些是脑子没记住的，因为一点基础没有，完全记住实在费劲（我不知道这个算不算是懒惰的借口？）。

从我的前几年看，已经是一个废人了。（和父母关系特差，因为我只对计算机有兴趣，他们却总是想让我去做别的；女朋友和别人结婚了；唯一的一点好处是前几年被好朋友骗过，后来懂得了为人处世的一点道理，做人圆滑，虽然不拍马屁但也基本不得罪人。工作的一些地方，两个性格再不合的人都能和我成为朋友，PS：当然是普通朋友，交心这年头太难了。比如在之前网络公司的时候，公司分为两派，所以员工无一例外也分为了两派，我成了唯一例外，哪边都不是却也和哪边的关系都不错。）

一直崇拜的一个人是王江民老师（虽然说和很多成功的人比较，他算不上什么，但对于我来说，意义却不一般），我觉得以他那样的年龄和当时的身体状况都能坚持学习下去，我为什么不可以？

但是现在唯一的疑虑是，假设我自学两年，两年以后已经高达28岁“高龄”了，那个时候去找工作会有人要吗？现在的公司门槛都相当高，正常都来个大学本科，英语XX级，最差也得一个大专，这些我是样样都缺。

在我看来做什么都是很难的，再加上实在是除了计算机对其他的都提不起兴趣来。期待各位老大来指点下，尤其期待笨笨雄老大，看过他的《职场123》，感觉很值得参考。

1. 年龄是否会成为将来找工作的障碍？
2. 学历对将来的工作影响大不大？
3. 我现在这个年龄这个基础开始学，还有希望吗？
4. 自学有一定的基础后，报一个如科锐这样的专业培训学校学习，会不会事半功倍？

补充一个问题：学过汇编以后，下一步到底是学`C`（我没选`VB`，`D`之类的语言，就买了本`C`）还是学`WIN32`环境下的汇编？加解密肯定要留到最后学了。

我现在唯一的优势是工作时间多、耐心和坚持还是能做到的，虽然自制力差点（对MM无法克制^\_^）

其实上面写了那么多无非就是一个人生经历，我的意思是以前的经历会对以后的学习和工作有所帮助吗？
