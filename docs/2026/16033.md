
# [原创] 通用的 Xposed 模块

## 用途

Xposed 模块 `hook` 目标函数，获取参数以及返回值。

## 优势

更改 `hook` 的函数时，不需要重新编译 Xposed 模块，系统也不需要重启。

## 工作量

有一点。

## 技术含量

无。

## 使用方法

配置 `config.txt`，然后放到 `sdcard` 目录下。

## 原理

Xposed 动态读取 `config.txt`，获得包名、类名、函数名、参数签名等信息。
