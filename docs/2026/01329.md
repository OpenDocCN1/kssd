　　这个初始化过程（实际是个函数）的流程还是非常清楚的。但是这个参数到底是什么？从上面来看，如果参数为0，那么就枚举当前线程的窗口。看来应该是某窗口的句柄。通过查看sub\_406A1F，发现00406A53处有对GetWindowLong的调用，而且传过去的ebx作为首个参数。这样，可以判断它是个窗口句柄。这里给出该过程的Pascal形式

```

Var
  CurrentHook:HHOOK;

Function Init(Window:HWND):HHOOK;
Begin
  Result:=0;
  If Window=0 Then
    Begin
      If CurrentHook=0 Then
        Begin
          EnumThreadWindows(GetCurrentThreadId,,1);
          CurrentHook:=SetWindowsHookEx(WH_CALLWNDPROC,sub_406D4A,0,GetCurrentThreadId);
          Result:=CurrentHook;
        End;
    End
  Else
    Begin
      sub_406A1F(Window);
    End;
End;
```


　　CurrentHook又是什么呢？从上面看，应该是起类似于标志的作用。初始值为0，Hook过以后就是
Hook函数的句柄。所以修改一下定义

```

Const
  CurrentHook:HHOOK=0;
```


    首先看看sub\_406D4A，这是一个CallWndProc函数。MSDN中有关定义如下：

```

LRESULT CALLBACK CallWndProc(
    int nCode,
    WPARAM wParam,
    LPARAM lParam
);
```
