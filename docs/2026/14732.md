
# [分享]利用Cheat Engine查找APP签名校验算法

首先我们拿到apk的时候先查壳(只限技术交流)

![](https://bbs.kanxue.com/upload/attach/201909/681174_WXSX4QDS74KUH2V.jpg)

原理:一般的签名校验大部分都是MD5  很多签名算法都会带时间戳进行组合加密,以时间戳为入口点突破

## 0x1:

设置好FD抓包以及过滤规则，减少抓到无用包 打开CE，附加模拟器进程，一定要附加模拟器主进程，以雷电为例，

附加`LdBoxHeadless.exe`;

![](https://bbs.kanxue.com/upload/attach/201909/681174_PAJS3PEDB22HRX6.jpg)

![](https://bbs.kanxue.com/upload/attach/201909/681174_3UR8MZM4RHQNYBU.jpg)

大概看了下参数 我们发现`secretKey`应该是MD5加密 还发现`answerTime`；

![](https://bbs.kanxue.com/upload/attach/201909/681174_TTN2DZJWAETVVFK.jpg)

## 0x2：选择搜索字符串 首次搜索 以`answerTime`关键点

![](https://bbs.kanxue.com/upload/attach/201909/681174_M7ARPQAXX7MKYBG.jpg)

## 0x3:操作一定要快 抓到包以后就要立即操作 否则人生只是个杯具； 重新抓包中ing；

![](https://bbs.kanxue.com/upload/attach/201909/681174_5AJ9E52G9EMJ4MY.jpg)

## 0x4: 快捷键`Ctrl+B` 查看附近内存 定位到加密的明文 然后通过计算得到结果和抓包的数据一样；

`stuId + cellId + answerTime + 123456789` 进行取数据摘要计算得到的结果
