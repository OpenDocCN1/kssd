# [原创]说说一名cracker应有的态度

我为什么想要学习破解技术呢?原因有很多，其中有一个就是受当时几个国产黑客电影的影响，我想当时这部电影的目的是想告诉大家不要误入歧途，可是我学到的确是,这群人真酷，我要是能够这样就好了。在当时我的心里就埋下了一颗小小的种子，只是有很多其他种子抢他的水分，一直都没有发芽。如今这颗种子开始成长了，我开始思考，1.怎样才算一名出色的cracker，2.怎样才能成为一名出色的cracker。
1.怎样才算一名出色的cracker？
  我觉的一名出色的cracker不仅仅是很有实力的人，而且是一个有态度的人。所以这个问题应该是一名cracker应该又怎样的态度？
      1[3].兴趣，目标，持之以恒。这三点是也是10000个小时天才理论的精华，刻意的做一件事情10000小时。3个是连在一起的，缺少一个都会失败，没有兴趣你无法坚持10000个小时，缺少目标即使有10000个小时，其效果顶多1000个小时。持之以恒就不用说了，你要是能够学10000个小时就算是持之以恒了。至于如何做到这三点，简单说几句，兴趣是培养出来的，不是天生的，具体技巧可以看一看行为心理学，行为是如何强化的？目标越细越好，这样就越专注，效率就越高，至于如何知道目标是什么，自己的目标对不对？实践是检验真理的唯一标准。关于持之以恒，参见培养兴趣的那一段

      2.放大镜，由以上3点是不够的，作为一名出色的cracker，要是需要一块放大镜把以上三点无限放大。放大到什么程度呢，程安之有句话是“要成功，先发疯”，没错，“疯”了，你就成为一名出色的cracker。

为了简洁：就列这两点就够了，当然还有很多态度是很重要的，认真，好学，多动......可是谨记以上几点，其他的自然就回来了。
