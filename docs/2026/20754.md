
# [原创]看雪是一盏灯！

来到看雪的时间不长 感觉到的却是特别的温暖 运气好，注册了就直接成为了初级会员 但我依然喜欢现在的临时会员模式 要依靠努力才能够真正融入看雪 融入了就不想离开

看雪为每个人提供了提高自己的机会 看雪的大牛们毫不吝啬自己的知识财富 挥金如土的洒向新人

我 离开IT行业半年 也就在2009的年中 才真正在看雪里穿梭 因此我并没有太多的经历 我就是一个小草 但 真的很少有论坛让我这么喜欢

看雪 吸引了一个个大牛 而一个个大牛正是我们的一盏盏灯塔 指引我们向前 向前 向前

长时间的别吸把我们吸引在看雪 也有一个个求知的灵魂 如滔滔江水般涌向看雪 给看雪注入新的活了

我并不十分清楚看雪支持到现在的原因 对看雪的老大的了解也仅仅停留在：他姓段 但是我佩服他 因为他周围有道光环 吸引了和他志同道合的人在他身边

看雪 加油！ 相信你会越来越好！

这不是征文的稿件 我没有资格写 只是酒后的乱言 借此一书 盼看雪人气鼎盛百年千年万年 看雪也一定会鼎盛百年千年万年
