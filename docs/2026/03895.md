### 破解总结

算法超级简单

逐位取用户名ASCII码 再首尾串起来 结果设为`A`

与固定值`CMW201118`串起来 格式为`CMW201118-A` 即为真码

E语言注册机源码：

```
.版本 2

.局部变量 name, 文本型

.局部变量 len, 整数型

.局部变量 sn, 文本型

.局部变量 i, 整数型

.局部变量 C, 文本型

.局部变量 sum, 文本型

name ＝ 编辑框1.内容

len ＝ 取文本长度 (name)

.计次循环首 (len, i)

    C ＝ 取十六进制文本 (取代码 (name, i))

    sum ＝ sum ＋ C

.计次循环尾 ()

sn ＝ “CMW201118” ＋ “-” ＋ sum

编辑框2.内容 ＝ sn
```
