# 漏洞成因

以该参数为例：

当form[0] == ‘\\’时，from++ 当前字符串的结束符 ，\*to++ = \*from++ ，form指向下个字符串的起始位置（此时为A），while 循环内，将第二个字符串又写入to中，实际写入长度会超过堆块大小。
可利用点：
1. 分配的堆块大小可控，由所有命令行参数的长度来决定。
2. 可控制堆溢出的数据， 溢出为’\\’的下一个字符串决定，可利用环境变量。
3. 可写入null数据，from == ‘\\’ 时，\*to = \* from++ 将null字符写入。
