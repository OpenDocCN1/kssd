
# [原创]发个从VC头文件中提取函数并分析参数的源码及个人用的汇编函数库

这个东西是我的API调用监控软件APIMonitor中用来从VC头文件中提取转换API参数的一个小工具，可以提取VC头文件中函数的名称、参数数量、参数名称、参数类型等信息，供APIMonitor显示API调用参数之用，当然如果大家需要提取一些API或者VC函数信息也可以在此基础上修改，代码用汇编写的，编译平台为:MASMPlus。

APIMonitor的网址：<http://bbs.pediy.com/showthread.php?t=180997>

为了方便大家使用，把我个人写的汇编函数库也附上，用了2年多了，感觉还算顺手。比如如果要弹出一个消息框，使用`invoke VK_MsbBox, CTXT("显示消息")`，再比如要打开一个“打开文件”对话框，如果调用API可能要处理`GetOpenFileName`的一堆结构，使用个人的汇编函数库`invoke VK_OpenFile, _pszFileName:DWORD, _pszFileType:DWORD, _pszOpenFilePath:DWORD`，一个函数即可免去所有问题，喜欢汇编的朋友欢迎下载。
