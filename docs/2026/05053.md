# [原创]cydia Impactor安装未签名IPA的协议抓取。

cydia Impactor是使用Curl来与通过通信进行签名，因此一般的中间人代理工具如fidder之类的是抓取不到协议的。

本工程可抓取3中类型的协议，抓取后的协议写入文件。

第一种，hook curl的Curl\_ossl\_send与Curl\_ossl\_recv可对curl的协议进行抓取。

第二种，支持对itunes的协议进行抓取，苹果公司的itunes一般重要的协议使用了HSTS协议的，因此中间人代理是抓取不到的。
