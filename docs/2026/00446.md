# [原创]OD自定义工具插件源码

该插件是OD调试器的辅助插件，给OD增加了,工具菜单、工具栏、计算器、脚本编辑器、记事本，ASCII等功能。

工具栏图标说明：
   图标说明：
   第一个：左键单击：向上，右键单击：向下
   第二个：左键打开脚本编辑器，右键 执行脚本
   第三个：计算器（算术、逻辑、进制转换等）
   第四个：记事本，可以在调试的时候记录东西，默认保存到调试软件的目录，文件名默认为：调试文件的名称后加.txt
   第五个：显示当前OEP处的信息
   第六个：打开硬件断点管理窗口
   第六个：打开调试软件的目录
   后面按钮可自定义，最大支持20个

记事本，可在配置中指定保存的路径，以后才自动保存到该目录下。
