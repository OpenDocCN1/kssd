
# [原创]分析一个简单的 `.dex` 文件 —— `Hello.dex`

最近在学习 `dex` 的文件格式，阅读非虫大大的《Android软件安全与逆向分析》里 `dex` 的章节内容，其实信息量蛮大的。读过一遍后，觉得对 `dex` 的文件格式的学习还少点什么。下一章 `odex` 内容看了几行后，这种不安全的感觉愈发变得强烈起来，会想起“空中楼阁”的寓言。决定自己写一个可执行的小程序，编译成 `.dex` 格式，分析过一遍后再往下进行书的内容。觉得这东西总归是基础功，属于必须熟悉的那一类。

分析的过程尽量不去翻书，尽量模拟原生的分析过程。一些结构的定义，多有参考 Android Open Source Project 上的在线文档。
