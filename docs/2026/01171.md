源代码:

```c
#include<stdio.h>
#include <string.h>
void main()
{
  char str1[30]="People's Republic of ";
  char str2[]="China";
  if(strcmp(str1,str2))
    printf("yes\n");
  printf(strcat(str1,str2));
}
```
