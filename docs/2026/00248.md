# [原创]浮点数基础概念

# 一、存储方式
## 1.定点小数存储法：
• 固定小数点的位置及整、小数各自占用的空间大小。
• 优点：易于表达，运算方便。
• 缺点：难以扩展，因为整数部分的取值范围在-32768~32767之间。
## 2.小数点移位存储法(IEEE)：
• 'S'1位(符号位)+'E'8位（指数位）+'D'23位（数据位）。
\*\*• 2.1 'S' 符号位：0表正，1表负。\*\*
\*\*• 2.2 'E' 指数位：小数点左移正指数，右移负指数。\*\*
#### 小数点移位必须移到“整数只有一个个位数，且此个位=1”的情况。
• 0值例外，0值不移，且所有值都为0。
• 10111.101 = 1.0111101 \* 10⁴ （指数位值即为4（⁴=^4），
• 0.00101011 = 1.01001 \* 10⁻³（指数位值即为-3（⁻³=^3）。
#### 简便计算指数值法：已知2⁷=128=10000000，127+4(位移值)=128+3=10000000+101(3)=10000011.
![](upload/attach/202104/919233\_6UNERU5BY8GJU2J.png)
\*\*• 2.3 'D' 数据位：整数部分1舍去，从小数部分开始正序排列，小数右补0。\*\*
• 如 1.0111101 的D数据位：01111010...0。
# 二、还原步骤
• 1.符号位正0负1；
• 2.（个位数1+小数点.+小数值）\* 基数ⁿ。

#### 第一题：已知地址0013FF74内容为：00 68 45 44，系统字节顺序为小尾方式，如果这个地址是存放float变量，那么其10进制真值为多少？
```
1.答案：789.625。
2.步骤：
//1.小尾转换00 68 45 44为实际十六进制
4 4 4 5 6 8 0 0
//2.十六进制转二进制
0100 0100 0100 0101 0110 1000 0000 0000
//3.重新排列
S EEEEEEEE DDDDDDDDDDDDDDDDDDDDDDD
0 10001000 10001010110100000000000
//4.0=正；128+8 == 127+9 == 指数为9
+ 9 1.100010101101
//5.1.100010101101 \* 10^9
1100010101.101
//6.二进制转十进制（将各位权值相加）
789.625
```
#### 第二题：将895.75转换为float类型的16进制形式，已知895 = 1101111111(B)。
```
1.答案：00 F0 5F 44。
2.步骤：
//1.将0.75由十进制转换为二进制
1101111111.11
//2.小数点移位
1.10111111111 \* 10⁹
//3.E 9转二进制 == 127+9 == 128+8；
S EEEEEEEE DDDDDDDDDDDDDDDDDDDDDDD
0 10001000 10111111111000000000000
//4.重新以4位/组分布排列
0100 0100 0101 1111 1111 0000 0000 0000
//5.二进制转十六进制
4 4 5 F F 0 0 0
//6.小尾排序
00 F0 5F 44
```
