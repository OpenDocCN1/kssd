# [原创]HW前期之分析一款远控木马

每年的活动又要开始了呀，无意在网上冲浪的时候发现了这个马，估计是攻击队留下的痕迹，前期做准备的，感觉这样很有趣，在攻防中不断成长呢！

![相关图片](https://bbs.kanxue.com/upload/attach/202006/678001_DENBG9TJECY86MB.jpg)

猜测是采用常规的钓鱼邮件的方式，图标伪装。

![](https://bbs.kanxue.com/upload/attach/202006/678001_8UA7XDSGT34N9UP.jpg)

刚开始免杀效果还可以，如下。

![](https://bbs.kanxue.com/upload/attach/202006/678001_9ZUWWZP7USUCH6J.jpg)

![](https://bbs.kanxue.com/upload/attach/202006/678001_5TGRSZ3GD9N69AP.jpg)

![](https://bbs.kanxue.com/upload/attach/202006/678001_7NCS88P5YYRGKAX.jpg)

原始文件名为“增量更新包”，程序里方法很少。

![](https://bbs.kanxue.com/upload/attach/202006/678001_3G7CQ9HBDEKD3PV.jpg)

进入入口点，原始文件名为“壳程序”，说明很大概率这个只是个下载器或者外壳程序，变量text有点特殊，感觉类似base64编码过。

![](https://bbs.kanxue.com/upload/attach/202006/678001_RX3FETK38MVFUN6.jpg)

大致看了下程序流程，会反转text变量的值，然后解码之后调用invoke加载执行。

![](https://bbs.kanxue.com/upload/attach/202006/678001_NX35862J3EATXZ6.jpg)

![](https://bbs.kanxue.com/upload/attach/202006/678001_8GX4AMAXSYGSQEN.jpg)

![](https://bbs.kanxue.com/upload/attach/202006/678001_SQ4SCT8YZEK6ADS.jpg)

提取出来，查询如下。

![](https://bbs.kanxue.com/upload/attach/202006/678001_3YAPN3CPQYZ93DR.jpg)

依然还是.NET程序，没有加壳没有混淆，文件名果然很直接......哈哈，是“免杀”，看到VritualAlloc很大概率会是内存执行恶意代码。

![](https://bbs.kanxue.com/upload/attach/202006/678001_CR96DU5M8UXM3BR.jpg)

![](https://bbs.kanxue.com/upload/attach/202006/678001_V8UR39A7W8WY6JV.jpg)
