# CS V.J破解实录

用了几个星期来跟踪INSTSCS.EXE始终没有结果,突然想到在用ICE跟踪的时候,按F12键
时第11次就死机了,会不会......
于是我就在读完密盘以后按CTRL+D调入ICE,"大约在10%处
<S DS:0 L FFFFFFFF '9090'>
搜出在0E24:F79B处出现了我的密码，先碰碰运气再说,向下找可疑代码,
< 0805YYZIP >
这个0805会不会就是密码呢? 我们知道,SCS40.DAT的压缩是用YYZIP作的,"鬼才知道YYZIP
是什么压缩软件,不管它.这一定就是了,因为在解压缩这前一定会验证密码的.
重新运行INSTSCS.EXE 输入0805 直到安装完成,哈哈 ^\_^ 成功了。原来这么简单，
大家都上当了。
