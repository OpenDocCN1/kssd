
# 新的SD卡烧录工具Etcher，支持全平台

# 1. Etcher

## 1.1 发现新的大陆

今天给被雷劈了的树莓派烧录新的系统的时候，发现树莓派的官方推荐不再是`dd`了，而是一个叫做`Etcher`的烧录软件，支持`Win/Linux/Mac`三大平台。

## 1.2 果然叼叼叼

- 开源
- 支持烧录硬盘
- 界面美观友好
- 跨平台
- 协议优化，比`dd`更快的烧录速度

## 1.3 尝试一下

### 1.3.1 本机环境：

```cmd
$ uname -a
Linux roysue-desktop 4.10.0-33-generic #37~16.04.1-Ubuntu SMP Fri Aug 11 14:07:24 UTC 2017 x86_64 x86_64 x86_64 GNU/Linux
```

### 1.4 下载下来是ELF文件，64位的App打包文件。

```cmd
$ file *| grep etcher
etcher-1.1.2-linux-x86_64 (1).zip: Zip archive data, at least v2.0 to extract
etcher-1.1.2-x86_64.AppImage: ELF 64-bit LSB executable, x86-64, version 1, dynamically linked, interpreter /lib64/ld-linux-x86-64.so.2, for GNU/Linux 2.6.18, BuildID[sha1]=d629f6099d2344ad82818172add1d38c5e11bc6d, stripped
```

### 1.5 在Ubuntu下双击直接Run！界面果然美观！比Win32DiskImager好看多了

左边选择`img`、`iso`、`zip`等格式，右边选择SD卡，然后直接`Flash`！

![图片描述](upload/attach/201709/581423_zsb2rvmhayvda9t.png)

选择完成之后，是需要`root`权限的，输入密码即可。

![图片描述](upload/attach/201709/581423_4sck9d5oovu6rbs.png)

然后进度开始读，SD读卡器开始一闪一闪亮晶晶。用`iotop`可以看到三个线程一起在写 ~~（SD卡速度太慢请无视...）~~

![图片描述](upload/attach/201709/581423_ijqojtij36da98l.png)
