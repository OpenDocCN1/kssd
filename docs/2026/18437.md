
# [原创]BisonFTP Server v3.5 Remote Buffer Overflow 漏洞分析

第一次分析漏洞可能会让大牛笑话，只有在Exploit找到软杮子捏了。

## 漏洞描述

BisonFTP Server v3.5在处理接收数据时未判断缓冲区大小造成堆溢出。

## 漏洞样本来源

[841K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3g2^5M7r3I4G2K9i4c8Q4x3X3c8V1j5W2)9J5k6h3y4G2L8g2)9J5c8X3g2^5M7r3I4G2K9i4c8K6i4K6u0r3x3e0M7$3y4o6W2Q4x3V1j5`.](<https://bbs.kanxue.com/elink@6f4K9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3g2^5M7r3I4G2K9i4c8Q4x3X3c8V1j5W2)9J5k6h3y4G2L8g2)9J5c8X3g2^5M7r3I4G2K9i4c8K6i4K6u0r3x3e0M7$3y4o6W2Q4x3V1j5`.>)
