# [原创]新手爆破 Sandboxie 4.08 全过程

前记
偶一直在用Team Eat 的3.54, 心想都是时候更新一下, 于是搜寻当时的最新版本4.08
在找到[uuk 大的破解](http://bbs.pediy.com/showthread.php?t=124357)前, 所试过的国外破解全都是有名无实的. 失望之际, 瞥见一留言:
> 先安装3.46, 注册后再安装4.08, 长时间享有注册版功能
> 3.46注册码:
> Name: DigitalConduct3
> Serial: JR37NV1


尝试后大致如是, 遂萌生破解念头.

重要发现
1. 使用Total Uninstall6 监控, 安装+注册3.46后, Registry 新增了:
[HKLM\SOFTWARE\Classes\CLSID\{98E6BD24-2D93-41A5-BC6D-CB7C1507318B}]
"I"=hex:b2,8e,3d,43,c4,6c,cf,01 ;初次执行时间
"K"="KS48OW2" ;之后有用
"N"="EjhjubmDpoevdu4" ;可无视

2a. 4.08 机子每次重启后都会有一小时注册版试用期, 而试用期过后, 只要将系统时间调前, 即回复注册版功能.
2b. 将Sandboxie Service 及 SbieCtrl.exe 改为手动执行, 重启机子, 登入, 将系统时间调前一年, 启动 Sandboxie, 还原系统时间,
按Help->Register Sandboxie, 提示注册有效期尚余365日.

3. 使用IDA Pro 6.1, SbieDrv.sys 内取得系统时间的import 只有KeQuerySystemTime, 尽管调用此API的函数为数不少
![](https://bbs.kanxue.com/upload/attach/201405/633211_3802z5if54a8e3b.png)

大胆尝试
推测与注册期相关的KeQuerySystemTime 是DriverEntry 里起初调用的几个, 由于仍没信心逐一解读, 于是来个逐步偷天换日,
将IAT的KeQuerySystemTime 改成自己的函数, 好便缩窄目标范围.

使用Ollydbg 1.1 + holyshit 0.3.3 + Multiline Ultimate Assembler 2.2.4, 并inject于sub\_33580(红箭头所示)

```

;SbieDrv.sys of Sandboxie x86 v4.0.8

<00993580>
@OEP2: ;这儿是sub_33580的开头
call @inject ;偷天换日
db 90 90 90
;原来的代码
push ebx
push esi
push 65
pop esi
push 5C
pop eax
push 69
pop ebx
push 73
pop edx
;call Table_KeQuerySystemTime somewhere later
;return

<00995C6A>
@inject:
;EAX is unbound!
call @setQST
add ESP, 4
pop [@tmp1+1]
call [ESP-8]
call @restoreQST
@tmp1:
push DADADADA
ret

@realQST: db DA DA DA DA
@pQST: db [COLOR="Red"]2C E1 03 00 ; point to KeQuerySystemTime

@setQST:
mov EAX, [@pQST]
push [EAX]
pop [@realQST]
push @myQST
pop [EAX] ;蓝屏三解说 ;SbieDrv.sys+25ca1
;[EAX] was 0xa55ba12c = 0xa559c000 (当时的基址) + [COLOR="Red"]1e12c (RVA)
;此RVA 就是import table 里的KeQuerySystemTime 指针, 而IAT属于 section .rdata
ret

@restoreQST:
push EAX
mov EAX, [@pQST]
push [@realQST]
pop [EAX]
mov word [@OEP2], 06EB ;skip injection shall sub_33580 be called again
pop EAX
ret

@myQST:
pop [@tmp2+1]
call [@realQST]
add dword [EAX+4], 001B0000 ;around 24 years
@tmp2:
push DADADADA
ret
```


每次改动后要 editbin /release SbieDrv.sys, 任何device driver CheckSum 不吻合就不能被加载.
(没editbin 的话可以用[CFF Explorer](https://bbs.kanxue.com/elink@3ddK9s2c8@1M7q4)9K6b7g2)9J5c8W2)9J5c8Y4N6%4N6#2)9J5k6h3&6@1j5$3!0J5k6g2)9J5k6h3y4G2L8g2)9J5c8X3k6A6L8r3g2K6i4K6u0r3c8i4S2H3L8r3!0J5k6i4u0e0N6h3W2@1k6g2)9J5k6h3g2^5k6b7`.`.), 按左边的Rebuilder=>只勾选Update Checksum=>按Rebuild)

其后遭遇三大蓝屏:
其一:代码逻辑错误 (详情略去=\_=)
其二:缺少 Relocation Entries (需人手加入和更改 Optional Header->Data Directories->Relocation Directory Size)
![](https://bbs.kanxue.com/upload/attach/201405/633211_4nxorm1x5z0b45a.png)

其三:缺少 section .rdata 的可写入标记 (Section Headers->tab Characteristics of .rdata, right click, check "Is writeable" box)
