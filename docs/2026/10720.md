# [原创 WinRar 安装程序集成密钥文件的方法

这个方法是通用的。而且能一直用下去。

WinRar 本身的安装程序是使用使用 WinRar 自己制作的自解压文件。
集成密钥的思路是：
1. 解开自压缩包。
2. 加入密钥文件。
3. 重新打包。

前提条件：
需要本机上已安装有 winrar。
winrar.exe - 主程序
wrar400.exe - 官方网站上下载的安装包
操作步骤：
1. 提取安装脚本。winrar.exe cw wrar400.exe setup.txt
2. 提取自解压模块并放到本机上已安装的 winrar 目录下。重命名为 setup.sfx
3. 解压安装程序到 wrar400 目录下。
4. 按照一般的步骤对 wrar400 目录制作rar自压缩程序，记得把 key 放进去。
5. 模块选择 setup.sfx，添加注释文件为 setup.txt。

如果你要制作 64 位的。方法也一样。

附件中提供：
KillOverlay 用来提取sfx。包含它的源代码。
setup.sfx 32 位的安装模块。
setup64.sfx 64 位的安装模块。
setup.txt 安装脚本。

BTW：
类似于烈火的美化版或者某些论坛的专用版，集成的方法都是一样的。
美化就是替换主程序中的资源。
