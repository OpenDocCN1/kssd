
# [原创]Windows7 x86/64 WIFI WPA1/2 登录嗅探程序

好久没在看雪论坛上发贴，把最近写的一个小工具共享给大家玩玩，**请在WIN7 系统WIFI网卡情况下测试**，希望大家顺便帮忙测试下，无花无壳无代码。

**需要管理员权限，如果驱动无法自动安装的话，自行去wifi网卡适配器属性界面安装服务。**

## 1、命令行参数

- `/Install`：安装卸载wifi过滤驱动，未指定情况下，程序会自动检测并安装驱动
- `/Uninstall`：卸载wifi过滤驱动
- `/NoDeauth`：不发起deauth攻击，默认会自动发起Deauth攻击
- `/Scan`：对整个wifi频道1-14进行扫描，每个驻留2s，该模式会禁用deauth
- `/Dump`：将原始数据dump到`dump.pcap`文件
- `/Channel 1-14`：指定wifi频道

## 2、常用场景

- `/Scan`：首先对整个wifi情况进行初步扫描
- `/Channel x`：对指定的频道自动进行wifi攻击，并抓取EAPOL握手包，容易被用户察觉
- `/NoDeauth /Channel x`：对指定频道进行嗅探，抓取EAPOL握手包，适合长时间运行

## 3、注意事项

- 运行前最好手动断开wifi，以免抓包时，windows自动连接wifi，导致模式切换
- 程序退出后，部分wifi硬件（Ralink）可能会出现无法切换正常模式，需要用户手工重置wifi网卡
- **Deauth攻击发包需要wifi网卡驱动支持，可以通过自行给网卡驱动打补丁解决**
- X64需要手动安装wifi过滤驱动，安装好驱动后，使用x86的exe就可以使用了
