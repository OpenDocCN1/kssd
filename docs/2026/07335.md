迷糊中突然想到花指令，之前看过但从来没用过，也忘记了目的。

只知道是在代码中插入数据来混淆反汇编引擎解析的代码。反汇编多数都是顺序解析的，在指令中插入其他数据后，导致将数据当Opcode解析导致后面的不对齐。

`_asm _emit 0xEB` 编译后数据就混在代码里，执行是怎么分辨呢？(唉，自己想多了)

其实是类似如下的方式，花指令是不可达的。(学了不用==没学)

```
_asm
{
    JMP MyCode
    _emit xxx
MyCode:
}
```
