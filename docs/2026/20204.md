
# [原创]pwnable.kr passcode

前几天我看到看雪的pwn板块，发现比较感兴趣，而且从这其中看到了一个练题的网站`pwnable.kr`，于是我就去练了一下，虽然很简单，但是想和刚入门的新手们分享一下。

说一下此次的主要利用思路：

通过`welcome()`函数写`login()`函数的`passcode1`的内容，修改`printf`的指针使函数调用`printf`时就会跳到我们想要的地址去执行程序，绕过判断语句，拿到flag。

进入网站打开`passcode`；

![](https://bbs.kanxue.com/upload/attach/201811/798964_RZB3KMVPS9A5SVV.jpg)

于是我们进入Linux，输入`ssh passcode@pwnable.kr -p2222`

输入密码后我们查看下这里面的文件

![](https://bbs.kanxue.com/upload/attach/201811/798964_WTPNKAYPZ2CK9GF.png)

我们看到以`guest`身份对`flag`没有任何权限，所以我们查看`passcode.c`

![](https://bbs.kanxue.com/upload/attach/201811/798964_DG55VCM8CF3KQ2N.png)

我们看到`scanf`处没有加取地址符号（`&`），而且程序没有对`passcode1`和`passcode2`进行初始化；但此时`main`函数中对`welcome()`和`login()`连续调用，这就隐含了它们的`ebp`是相同的；所以或许我们可以从这里利用。

我们用`objdump -d passcode`查看`passcode`这个可执行文件的汇编代码，这里我们主要看`welcome()`函数和`login()`函数的汇编

![](https://bbs.kanxue.com/upload/attach/201811/798964_YTZQAN9KW7JUTRA.png)

我们看到`welcome()`函数处的`0x8048643`处的代码`lea -0x70(%ebp),%edx`；相当于`edx=[ebp-0x70]`；从这里我们知道`name`的地址是保存在`ebp-0x70`处；而在下图中`0x8048586`处的前3行处有`mov -0x10(%ebp),%edx`；可知`passcode1`在`ebp-0x10`处，因此在调用`welcome`处的字符串处我们输入`(0x70-0x10)=96`个字节，再覆盖四个字节就是`passcode1`的值，这里如果我们把`passcode1`的值覆盖为任意地址就可以实现任意地址写了。

![](https://bbs.kanxue.com/upload/attach/201811/798964_66GUVCF7GJ6GQVY.png)

这里我们将`passcode1`处的值写什么我们才能读到flag呢？

我们再看源代码

![](https://bbs.kanxue.com/upload/attach/201811/798964_HTB6J3KHAW37EJR.png)

`scanf("%d",passcode1)`处的后两句又对`printf`调用，因此我们想能不能覆盖`printf`的地址呢，把`printf`的地址覆盖为`printf("login ok!\n")`处的地址就直接绕过了判断语句；我们看`login()`函数的反汇编可以看到这里的地址为`0x80485d7`。

接下来我们用`objdump -R passcode`查看`printf`的地址

![](https://bbs.kanxue.com/upload/attach/201811/798964_2J5YHG88B39762E.png)

我们看到`printf`的指针保存在`0x804a000`处，因此我们把这里的指针覆盖为`0x80485d7`（10进制为134514135）就可以绕过了那个判断语句执行里面的代码了

![](https://bbs.kanxue.com/upload/attach/201811/798964_WP5J5X79524B899.jpg)

接下来我们构造数据如下图，最后就能得到flag了；（由于`scanf`要的是`%d`，所以我们要输入10进制的134514135）

![](https://bbs.kanxue.com/upload/attach/201811/798964_5AK678ZAJY4BTHP.png)
