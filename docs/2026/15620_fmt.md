## 破解过程

1、用`APKTOOL`反编译该APK程序，并用`dex2jar`工具将classes文件转化成jar文件。

2、在`AndroidManifest.xml`文件中找到主Activity：`picview.meitui.type`

```
        <activity android:name="picview.meitui.type" android:screenOrientation="portrait">

            <intent-filter>

                <action android:name="android.intent.action.MAIN" />

                <category android:name="android.intent.category.LAUNCHER" />

            </intent-filter>

        </activity>
```

3、用`JR-GUI`来查看JAR文件，可以发现一个`VIP`类

![](https://bbs.kanxue.com/upload/attach/201308/150432_bqisamq7f9731f7.jpg)

4、展开`VIP`，里面有一个`VipMgr`类，很明显是对`VIP`的管理类，展开之：

![](https://bbs.kanxue.com/upload/attach/201308/150432_q96d9xy70ks7c5e.jpg)

5、再观察里面的成员变量和成员方法，不难发现一个成员函数`getVipType`

![](https://bbs.kanxue.com/upload/attach/201308/150432_chxrdka77s98g66.jpg)

6、`getVipType`的返回值决定了VIP的类型。

```

7、而在`VipMgr`类中的成员变量里有对VIP类型的定义：

```
  public static final int VIP_NEED_LOGIN = -2;

  public static final int VIP_NOAD = 100;

  public static final int VIP_NOAD_1YUAN = 130;

  public static final int VIP_NOAD_MONEY = 200;

  public static final int VIP_NOAD_SMS_10YUAN = 135;

  public static final int VIP_OUTDATE = -1;

  public static final int VIP_VIP = 300;

其中`VIP_VIP`是最高级别的VIP，是没有任何限制的。
