## 2.反调试之时间线程检测

启动调试后是对帖子【1】的验证，过程大致如下：

运行brpt.py后一路F9,

|  |
| --- |
| #下断点  # 内存中获取模块基地址  base = FindModule('linker');  #.text:00002464     BLX        R4  addr = base + 0x2464; #该偏移值需要使用IDA静态查看linker模块的偏移值  #给linker下断点  AddBpt(addr);  #在libc.so中对库函数下断点  AddBpt(LocByName('fopen'));  AddBpt(LocByName('ptrace')); |

当lr为pB54EB0CAE49198754C66F4A57BDB01DF函数时即为第一个反调试的线程创建处，然后会调用libDexHelper.so:pDD8ABF73B0AE99BD998BC5C954A74856，

![](https://bbs.pediy.com/upload/attach/201801/657161_6UM9DBKK7PNDZUP.jpg)

再按一次F9即可断到帖子中提到的fopen函数处

![](https://bbs.pediy.com/upload/attach/201801/657161_2CMQZTZA2C69AX4.jpg)

执行完fopen后，回到调用函数libDexHelper.so:p8878CAA1006835C9D43174C88143BA8B+A6处，然后在如下所示处下断点，F9执行到此处，观察寄存器的值并做相应的修改，具体思路就是要跳过libDexHelper.so:AEDC62A8 BLX   sub\_AEDA6ECC 这个函数调用即可。

![](https://bbs.kanxue.com/upload/attach/201801/657161_FZDE575W5FUZE42.jpg)

执行完成后，会跳出调用函数，来到下图处将r0寄存器的值修改为0，或将指令#1改为#0即可。

![](https://bbs.kanxue.com/upload/attach/201801/657161_B3EQX4AEM7BWAN2.jpg)

并在p39D6B1EED99DC7E506A9D4E07BD58D3A处下断，

![](https://bbs.kanxue.com/upload/attach/201801/657161_YXHX6FNY3C7JASY.jpg)

执行完之后F9，则会跳到p39D6B1EED99DC7E506A9D4E07BD58D3A处，

![](https://bbs.kanxue.com/upload/attach/201801/657161_76WJN9ZP7VPESJS.jpg)

该函数功能类似kill，具体过程参考帖子【1】。

接下来通过静态分析知道了时间线程的创建点，如下所示：

![](https://bbs.kanxue.com/upload/attach/201801/657161_3GH5FVDDQWYNHT7.jpg)

具体的时间检测函数如下：

![](https://bbs.kanxue.com/upload/attach/201801/657161_WMEVWU4XQ32XVCK.jpg)

其中主要就是调用了gettimeofday函数，获取时间，然后再做比较，

![](https://bbs.pediy.com/upload/attach/201801/657161_KJFEM4Q35CWNFCF.jpg)

不满足条件则kill掉
![](https://bbs.kanxue.com/upload/attach/201801/657161_JXWT86WA5ZUDKED.jpg)

以上便是时间检测的功能了。
