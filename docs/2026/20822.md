
# [原创]是坚强了还是虚弱了

小时候因为看到父母生活的艰苦，我在学校发奋读书，目的就是为了改变乡村中的生活状况，以后不走父母的老路，可后来发现苦难不仅仅源于生活资源的匮乏，还来自人们内心的心灵枷锁，嫉妒、贪婪、虚伪，如果不能除去人心灵上的枷锁再好的生活也没什么意思。

我没有强壮的身体，也没有大把的钞票，想要改变乡村人的思想无异于蚂蚁憾树，无法改变别人只能改变自己了，慢慢的，我可以不太在意生活上的得失，一心追求技艺也使我在很长一段时间里心平如水，虽然走了很多弯路但也过的充实，大学四年参加了大量的公益活动，认识了很多热情善良的社会人士，专业知识的学习也没有怠慢，如果不是学校发了毕业离校通知书的话我相信我会一直留在学校里，至今还怀念学校的图书馆和阅览室。

离开学校之后我并没有像其它大学生那样到处发简历找工作，我有篇关于人工智能论文一直没有完成，本来那篇论文是想用来做毕业设计的，后来因为时间来不及就用另一篇论文顶替了，可在我的心里我的毕业论文还没完成，就这样我在离学校不远的地方租了间房子默默的研究,一台电脑，把图书城当图书馆用，偶尔出门给人修修电脑赚点外快，生活简单清苦，如果不是后来发生的一些事情我也许会一直这样下去。

我哥哥放弃广州的工作来武汉见他的女朋友，可相处没多久就分手了，身心疲惫的哥哥在武汉也做过几份工作，由于人太老实，高中毕业的他没学历又没技术总是做些吃力不讨好的事情。虽然在外面混了很多年可并没有学到可以养家糊口的技术，我不能再袖手旁观了，08春节过后就教我哥哥修电脑方面的技术，出门修电脑也带着他，几个月之后他就可以自己出去修了，挣钱不多但不管怎么样他再无须看别人的脸色，走出去心里塌实，他也慢慢有了自己的想法，毕竟在外面混了这么多年还是懂得一些营销策略，竟渐渐的走出路子来，这也反过来感染了我，我也把越来越多的精力花在修电脑上，同时积累了大量的软件破解和网络数据分析的经验。

在中间一段时间里我接到北京一个游戏设计公司的笔试通知，那是冬天，我在北京经历了北京的第一场大雪，笔试，再面试经历了一个月之久，最后还是不了了之，北京之行让我知道学校的知识和外面需求之间的差距。

后来又被朋友介绍到一个政府部门上班，专门搞电脑维修和网络维护，正是我喜欢的工作，在里面也算是得心应手吧，可是里面的人事关系复杂，我这个不喜欢奉承巴结，竟莫名其妙的被辞退了，（说什么技术不行，后来我才知道都是些污蔑的话，是某个领导的亲戚要坐我的位子）如果说有什么遗憾的话那就是没有到中心机房看一下，我只是在书上见过核心路由器的样子，上班那几天我已经把整个部门的网络结构和一般性问题都了解清楚了，这些对我以后做网络工程很有帮助。

今年八月我和我哥终于开了家电脑维修的店子，没有任何开店子的经验完全是硬着头皮一步一步往前走，偶尔会想起以前那未完成的论文，可经历了这么多的事情之后我已经不是以前的我了，再也没有勇气去挑战那些高深的东西，也不愿意回到以前清苦的生活，不分昼夜的修电脑，烦躁、空虚、失落、怨恨所有这些以前被我抛弃的情绪现在都像蚊子一样越来越多的萦绕在我周围，有时候我感觉我真的变了，是坚强了还是虚弱了自己也说不清楚。
