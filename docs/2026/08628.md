# Mirage

> 驱动已签名，由于使用泄露签名，使用前请关闭杀毒软件。

## 说明

1. 基于`intel vtx` && `ept` 技术
2. 不与其它反反调试插件冲突

![image](upload/attach/202001/607869_QGRH7WRXJ3UCFN5.jpg)

## 系统支持

1. `win7 x64` ( *`6.1.7600`* )
2. `win10 19h1 x64` (*`10.0.18362.XXXX`*)

## 使用

0. 使用<a href="elink@9fcK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6J5j5h3A6C8N6h3#2S2M7W2)9J5k6s2u0S2L8X3N6S2M7X3q4B7i4K6u0r3f1p5c8n7i4K6u0V1c8r3!0%4L8X3I4G2j5h3c8W2M7R3`.`.">`PDBDownloader.exe`</a>下载`ntoskrnl.exe`文件 (默认在下载在C盘

![image](upload/attach/202001/607869_FW8Y46RH7PSUSFZ.jpg)

1. 使用`MVConfigBuild.exe`生成`config.mv`配置文件 并将之移动到c盘根目录`C:\`

> `MVConfigBuild.exe` `C:\symbols\ntkrnlmp.pdb\hashxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx\ntkrnlmp.pdb`

![image](upload/attach/202001/607869_S48DJE4VQXT87RP.jpg)

2. 将`Mirage.sys`、`MirageV.dp32`、`MirageV.dp64`移动到`\plugins\`目录下

![image](upload/attach/202001/607869_RX68A47URCFD2NF.jpg)

3. 菜单栏-插件-幻境-进入

![image](upload/attach/202001/607869_A9WCQZWK6HZGW95.jpg)

- 附加

> 输入进程id - 点击`附加进程` - 点击`开启`

![image](upload/attach/202001/607869_VWK43X94ZTEBU7R.jpg)

- 启动调试

> 直接点击开启

![image](upload/attach/202001/607869_6P4VN2SAQHKE2BM.jpg)
