
# [原创]看雪CTF2017 readyu crackme 解题方法
学习了一下这个椭圆曲线的运算规则
主要用到了`readyu`的3个工具`ECCTOOL v1.04`、`BigInt v1.14`、`RDLP v1.12`
主要就是4张图
先初始化椭圆曲线方程
[![](https://bbs.kanxue.com/upload/attach/201706/TSTW7M449GEQQ5K.jpg)](https://bbs.kanxue.com/upload/attach/201706/TSTW7M449GEQQ5K.jpg)
然后设置参数
[![](https://bbs.kanxue.com/upload/attach/201706/752_8k4z26ob0hgt5qc.png)](https://bbs.kanxue.com/upload/attach/201706/752_8k4z26ob0hgt5qc.png)
还有2个参数比较复杂
最终比较
`(Px + m3*G)*m1 = (Px + m3*R)*m2 (mod Q)`
其中`G`, `R`, `Px`是椭圆曲线上面的点，`m1`, `m2`, `m3`, `Q` 已知
求`Px`
化简一下（看了作者的帖子）
`Px = (m1*m3/(m2-m1) mod Q) * G + (m2*m3/(m1-m2) mod Q) * R`
这里设
`L = m1*m3/(m2-m1) MOD Q`
`H = m2*m3/-(m2-m1) MOD Q`
`m1*m3 = 34A53EFAD29408CAABD29CCE116F2D2BF0D1E0C9055F6631E907AB900198255B`
`m2*m3 = 93F10EEB724DE4C311EFB2ACE64AA8E3E64310FE24299CE560D4A4E24A75341`
`m2-m1 = -436A672EDB74BAF67DD5E43647C5EB62`
计算得出
`L = B0F488CAD8CCD07AD4D6842C9B80540`
`H = 150239A0F0A087516E1BE5BCFF3DF190C`
