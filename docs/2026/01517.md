
# [原创]ISCC2014宝藏探秘

![](https://bbs.kanxue.com/upload/attach/201406/236638_tpoxh2wwa246199.png)

这道题目很有挑战性，简单讲一下,欢迎论坛兄弟交流。

下载程序，`peid`检查发现是`ASProtect 1.2x - 1.3x [Registered] -> Alexey Solodovnikov`，加密壳直接在论坛找脚本脱掉，再次检查发现是`Microsoft Visual Studio .NET 2005 -- 2008 -> Microsoft Corporation`。注意程序会用函数`kernel32.GetVersionExW`检查你的操作系统，`xp`的话会直接结束，`win7`则正常出现`flag`输入窗口。

大致原理：内存中有一块加密数据，解密后是`bmp`像素信息，从图像信息得到一串数字；而我们输入的字符串经过某种加密也得到一串数字，如果相同的话，输入的字符串就是`flag`。

## 图像的解密算法

```c
#include <stdio.h>
#include <stdlib.h>
#define SIZE 0x1800

int main(int argc, char *argv[])
{
    FILE * fp;
    unsigned char buf[SIZE*4];
    fp = fopen("enc.dat", "rb");
    fread(buf, sizeof(unsigned char), 0x6000,fp);
    fclose(fp);
    unsigned int i = 0;
    unsigned int n = 0;
    unsigned int m;
    do
    {
      m = (*(unsigned int *)(buf + 4 *i + 1)) ^ n ^ (0x1800 - i) ;
      n = n + (*(unsigned int *)(buf + 4 *i + 1));
      *(unsigned int *)(buf + 4 *i + 1) = (m >> 17)+ (m << 15);
       i++;
    }
    while ( i < (unsigned int)(0x1800 - 1) );
    fp = fopen("enc.dat", "wb");
    fwrite( buf, sizeof( unsigned char ), 0x6000,fp);
    fclose(fp);
    system("PAUSE");
}
```
