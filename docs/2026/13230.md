
# 实现 `W32dsm.exe` 在 2000 下的命令行功能，老调重弹啦 (6千字)

## 一、问题的提出：

我在`SendTo`文件夹下放了很多常用的软件的快捷方式。但是其生效的基本条件是必须支持命令行参数。`W32DSM`的KILLER版说明支持此参数，而且在WIN98下也通过了。但在2000下用`SENDTO`会自动退出。
