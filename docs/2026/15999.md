## 编译安装

### 编译

文档说明 直接实操

![](https://bbs.kanxue.com/upload/attach/202204/832784_WHRM58H9PU9A9D7.png)

先设置NDK环境变量进行编译

![](https://bbs.kanxue.com/upload/attach/202204/832784_D8KZ3YP2N3RTQS2.png)

没法进行编译，看来是缺少了依赖

`Module example depends on undefined modules: cxx`

我发现确实有`libcxx`文件夹但是是空的

`mk`的链接文件表示这里需要放静态库

```
LOCAL_PATH := $(call my-dir)
include $(CLEAR_VARS)
LOCAL_MODULE := example
LOCAL_SRC_FILES := example.cpp
LOCAL_STATIC_LIBRARIES := libcxx
LOCAL_LDLIBS := -llog
include $(BUILD_SHARED_LIBRARY)
include jni/libcxx/Android.mk
```

找了半天发现这个`libcxx`的文件地址在

[`9a5K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6@1L8%4m8B7L8$3S2F1N6%4g2Q4x3V1k6D9K9h3u0U0P5s2S2Q4x3X3g2Y4K9i4b7`](<https://bbs.kanxue.com/elink@8efK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6@1L8%4m8B7L8$3S2F1N6%4g2Q4x3V1k6D9K9h3u0U0P5s2S2Q4x3X3g2Y4K9i4b7>).

### 安装

这个模板只是生成了hook的链接`so`，但是他不生成可安装的magisk模块。所以我们还有将这个`so`文件移植到一个magisk module中。

`so`放置文件如下:

![](https://bbs.kanxue.com/upload/attach/202204/832784_92V5J9X88N5KR97.png)

再打包压缩成一个`.zip`安装包。如果你的面具开启了zygisk就会进行链接。
