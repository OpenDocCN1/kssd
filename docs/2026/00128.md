# [原创]手工添加单击文件右键二级菜单项

1.假设你想要在单击文件右键时增加三个二级菜单，第一级为”破解（加载文件）“、”破解（加载进程）“、其他工具，三个项目的第二级菜单项是你想要添加的工具，以便更为方便的启动工具，不需要再在各个文件下下面找了，目前网上这方面的资料貌似不太多，而且看得我非常凌乱,所以我花了一天时间整理出这个，供大家参考，欢迎转载^\_^

2.根据以上假设如果想实现它，应该如何做呢？？？软媒魔方其实有这个功能，而且很好用，但是它的缺点是只能增设一个二级菜单，如果像我刚才假设的那样就无法实现了，必须手动添加，我就是根据软媒添加二级菜单的方法实现的手动添加二级菜单~~~~

3.开始，运行，输入regedit，回车

4. 找到[HKEY\_CLASSES\_ROOT\\*\shell]，右键添加一个项目，这里我是用的RuanMeiMenu（实际上你可以设置任何你想喜欢的名字），然后再RuanMeiMenu项下增加三个键，第一个键为icon="D:\Program Files\TweakCube3\winmaster.exe,3"，MUIVerb="破解（加载文件）"，SubCommands="RuanMeiMenu.0;RuanMeiMenu.1;RuanMeiMenu.2;RuanMeiMenu.3;RuanMeiMenu.4;RuanMeiMenu.5;RuanMeiMenu.6"，解释一下，第一个是设置不表，第二项是菜单项名称，不用我多说，第三项要注意，分号分隔的是你要添加在二级菜单下的程序，这里有7个，MS规定二级菜单下最多只能添加16个项目，这里的二级菜单项如何设置，稍后解释。"icon"="<图标所在绝对地址>"，MUIVerb="<一级菜单显示名称>"，SubCommands="<二级菜单项一;二级菜单项二;二级菜单项三;二级菜单项四;二级菜单项五;...>"

5. 这时就应该来设置第二级的项目了，首先定位到[HKEY\_LOCAL\_MACHINE\Software\Classes\Microsoft\Windows\CurrentVersion\Explorer\CommandStore\shell]
 根据刚才添加的SubCommands的键值，每个分号分割的项目在这里以其名字新建项目，注意，名字一定要相同，否则不会成功！！
 将其默认键值设为二级项目的显示名字，新建一个键命名icon，值为图标所在绝对地址，例如一级菜单项SubCommands第一个分号前的名字为RuanMeiMenu.0,那么在[HKEY\_LOCAL\_MACHINE\Software\Classes\Microsoft\Windows\CurrentVersion\Explorer\CommandStore\shell]下新建RuanMeiMenu.0项，@="LordPE",icon="D:\Program Files\TweakCube3\winmaster.exe,3"，然后在[HKEY\_LOCAL\_MACHINE\Software\Classes\Microsoft\Windows\CurrentVersion\Explorer\CommandStore\shell\RuanMeiMenu.0]下新建command项，@="G:\破解\LPE-DLX\LordPE\_hh.EXE",到此就添加了一个二级菜单项，依次添加n个项目（n<=16）

6.至此完成了 一个二级菜单的添加，其实到这里和软媒添加二级菜单的功能一样，但是我们可以用同样的方法再添加两个二级菜单，至此就完成了刚才假设要添加的三个菜单项。截图如下

![](https://bbs.kanxue.com/upload/attach/201304/544552_ceue5v6yhi1h26p.png)

7.至于最多能添加几个二级菜单，这个本人木有试过，若果你有兴趣可以试试^\_^
