# [原创]360加固VMP问题小结

##### **通过对比360加固的VMP实现，发现以下几点问题：**

###### **一、VMP虚拟机引擎变化很小，指令执行代码没有变化，两次版本之间的指令代码基本一样 二、VMP引擎中变化的只是指令码与指令执行代码的对应关系**

###### 三、指令执行码可以通过功能比对分析出真实指令码

**例如最简单的nop指令就可以一眼看出：**

debug071:76227C28 02 36       ADDS            R6, #2                  ; jumptable 76227828 case 183
debug071:76227C2A ED E5       B               loc\_76227808

###### 总结

**可以通过分析vmp指令执行代码的功能进行指令的还原，配合上针对对照表的算法的分析就可以实现指令码的还原**
