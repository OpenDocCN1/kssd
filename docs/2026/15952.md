# [原创]【开源】Qujing曲境 | 在PC浏览器上进行安卓的监控hook

## 曲境是什么

曲境是一个xposed模块，可实现在PC浏览器上动态监控（hook）函数调用和查看堆栈信息，及反射调用（invoke）等功能。避免了频繁写hook代码的麻烦，提供了可视化的界面，对新手更友好。

Github地址：[184K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6y4L8$3y4Z5j5g2)9J5k6p5I4Q4x3V1k6c8N6f1A6A6L8X3M7`.](https://bbs.kanxue.com/elink@077K9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6y4L8$3y4Z5j5g2)9J5k6p5I4Q4x3V1k6c8N6f1A6A6L8X3M7`.)

项目依据xserver优化而来，感谢原作者[@Monkeylord](https://bbs.pediy.com/user-776971.htm)。

## 曲境能做什么

1. 枚举安卓设备所有APP

2. 根据类名和方法名搜索方法

3. 方法监控，打印调用栈和出入参

4. 对目标方法强制执行
