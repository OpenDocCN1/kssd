
# CCproxy最新版破解,有个小小的玩笑 (17千字)

目标软件: `CCProxy 4.11`

保护方式: 注册码

破解人: `TAE`!`CCG`!`BCG`!`FCG`

破解方式: 算注册码

运行软件发现程序自动生成一个机器码,需要让用户输入序列号和注册码,你可以随便输入一些,我输入的是:

序列号: `12345678`

注册码: `78787878`

跟踪到这里我就发现这个程序很奇怪,一般来说程序注册的过程应该是这样的,即判断注册码的合法性,如果正确那么写入注册表或者是文件中,错误的话应该不写入的,而这个程序还没有判断正误就将注册信息写入了文件,奇怪!另外如你仔细观察机器码,你会发现每次注册,机器码都会改变,奇怪!可能会有陷阱!无论如何我们还是继续跟踪吧!
