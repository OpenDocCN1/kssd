
# [原创]开机adb默认Root权限修改方法 [android4.4、android5.1、android8.1]

## android 4.4.4_r1 修改方法

修改 `/system/core/adb/adb.c` 处 `should_drop_Privileges()` 函数

![](upload/attach/202007/778210_QUA5B5UP65UCJ6S.png)

## Android 5.1 版本修改方法

```
1.直接修改函数should_drop_privileges() 函数, 清空这个函数，直接返回 0 即可。返回0 即开启root 权限。
2.修改 alps/external/sepolicy/Android.mk 文件， 将-D target_build_variant=$(TARGET_BUILD_VARIANT) 改成 -D target_build_variant=eng
```

## Android 8.1 版本修改方法

1. 路径为 `/system/core/adb/daemon/main.cpp` 文件中寻找 `should_drop_privileges` 函数

![](upload/attach/202007/778210_5KFJCF92RAESBY3.png)

2. 将 `should_drop_privileges` 函数所有返回值都修改为 `false` 即可。

注释说明只有调试模式和root权限下不会运行 `drop_capabilities_bounding_set_if_needed` 函数。
