# [原创]开机adb默认Root权限修改方法 [android4.4、android5.1、android8.1]

\*\*android 4.4.4\_r1\*\* 修改 /system/core/adb/adb.c 处 should\_drop\_Privileges()函数
![](upload/attach/202007/778210\_QUA5B5UP65UCJ6S.png)
\*\*Android 5.1版本修改方法\*\*
```
1.直接修改函数should\_drop\_privileges() 函数, 清空这个函数，直接返回 0 即可。返回0 即开启root 权限。
2.修改 alps/external/sepolicy/Android.mk 文件， 将-D target\_build\_variant=$(TARGET\_BUILD\_VARIANT) 改成 -D target\_build\_variant=eng
```
\*\*Android 8.1版本修改方法\*\*
1.路径为 /system/core/adb/daemon/main.cpp 文件中 寻找 should\_drop\_privileges函数
![](upload/attach/202007/778210\_5KFJCF92RAESBY3.png)
2.将should\_drop\_privileges 函数所有返回值都修改为 false 即可。
注释说明只有调试模式和root权限下不会运行drop\_capabilities\_bounding\_set\_if\_needed 函数。
修改后刷机 adb链接如下图默认root权限：
![](upload/attach/202007/778210\_9YNFZ44CXZYNZMQ.png)
