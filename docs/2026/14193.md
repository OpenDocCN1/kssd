
# [原创]二.Android ELF系列:实现一个so文件加载器

项目我已经上传到附件里面,先下载对照着看比较好理解.

对于`gradle`由于不同版本可能在不同的`sdk`中会存在不同,可能会导致编译失败.解决方法就是

新建一个`NDK`项目.复制所有`cpp`目录下的源文件放到新项目下的`cpp`文件夹.

复制`libs`下的所有文件.修改`app`目录下的`build.gradle`目录添加如下配置

```
defaultConfig {
......
externalNativeBuild {
cmake {
cppFlags ""
abiFilters 'armeabi-v7a'//添加这个
}
}
}
```

即可.

这个加载器我是直接通过下载`Android 4.4`系统源码把里面的`linker`源码抽取出来放到一个新建的`ndk`项目里面的.

里面的代码没有作任何修改.只是简单的把一些不能跑起来的代码给注释掉了.和增加一些函数.

先上自己写的一个加载`so`文件的入口函数:

```
extern "C"
JNIEXPORT void JNICALL
Java_com_example_mi_ndktest_MainActivity_openlib(JNIEnv *env, jobject instance) {
soinfo *sostart = nullptr;
soinfo *soend = nullptr;
long long base;
GetModuleBase(base,getpid(),"linker");
if(base != 0)
sostart = (soinfo *)(base+0x100a8);
soinfo *si;
soinfo *so_n = (soinfo *)dlopen(nullptr,0);
getgSoInfoPools((void *)((uint32_t)so_n- sizeof(void *)));//获取全局变量gSoInfoPools的地址
for(si = sostart ; si != NULL ; si= si->next)
{
soend = si;//定位最后一个so文件
LOGD("lib:%s",si->name);
}
initSome(sostart,soend);
soinfo *substrate = do_dlopen("/data/data/com.example.mi.ndktest/lib/libsubstrate.so",0);
}
```

注意到其中有两个变量`sostart`和`soend`这两个变量.在`linker`用于记录已经加载的`so`文件.所以我们需要把它们给获取到.

还有在调用`do_dlopen`完成时会调用一个保护函数设置`soinfo`的内存区域为只读.由于我们加载`so`文件时对应的`soinfo`信息的引用(`soinfo.ref_count`)会加`1`,所以会涉及到写入的操作.

```
soinfo* do_dlopen(const char* name, int flags) {
if ((flags & ~(RTLD_NOW|RTLD_LAZY|RTLD_LOCAL|RTLD_GLOBAL)) != 0) {
DL_ERR("invalid flags to dlopen: %x", flags);
return NULL;
}
set_soinfo_pool_protection(PROT_READ | PROT_WRITE);//设置为可读可写
soinfo* si = find_library(name);
if (si != NULL) {
si->CallConstructors();
}
set_soinfo_pool_protection(PROT_READ);//设置为只读
return si;
}
static void set_soinfo_pool_protection(int protection) {
for (soinfo_pool_t* p = gSoInfoPools; p != NULL; p = p->next) {
if (mprotect(p, sizeof(*p), protection) == -1) {
abort(); // Can't happen.
}
}
}
```

这个内存区域的信息是通过全局变量`gSoInfoPools`获取的,所以这个变量我们也需要把其获取到.

`gSoInfoPools` 的结构为

```
#define SOINFO_PER_POOL ((PAGE_SIZE - sizeof(soinfo_pool_t*)) / sizeof(soinfo)) //14
struct soinfo_pool_t {
soinfo_pool_t* next;
soinfo info[SOINFO_PER_POOL];
};
```

那么怎么获取那,通过结构可以知道`next`的下一个结构是`soinfo`数组.通过分析可以发现`somain`模块就是在`soinfo`数组的第`0`个元素.那么我们通过`somain`的`soinfo`信息地址`-4`就是`soinfo_pool_t* next;`而且该数组的最后一个元素又指向下一个`soinfo_pool_t`的`soinfo`数组的第`0`个元素.

![](upload/attach/201902/793792_YSGEMHVYKA52NB8.jpg)

![](upload/attach/201902/793792_QASBDXSR4B8DXQ6.jpg)

```
void getgSoInfoPools(void *addr)
{
soinfo_pool_t *pt = (soinfo_pool_t *)addr;
do{
void *next = (void *)((uint32_t)pt->info[13].next - sizeof(void *));
pt = (soinfo_pool_t *)next;
}while(pt->info[13].next);
gSoInfoPools = pt;
}
```

到这里我们就可以正常调用自己的`do_dlopen`加载`so`文件了.
