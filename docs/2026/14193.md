# [原创]二.Android ELF系列:实现一个so文件加载器

项目我已经上传到附件里面,先下载对照着看比较好理解.
对于gradle由于不同版本可能在不同的sdk中会存在不同,可能会导致编译失败.解决方法就是
新建一个NDK项目.复制所有cpp目录下的源文件放到新项目下的cpp文件夹.
复制libs下的所有文件.修改app目录下的build.gradle目录添加如下配置
```
defaultConfig {
......
externalNativeBuild {
cmake {
cppFlags ""
abiFilters 'armeabi-v7a'//添加这个
}
}
}
```
即可.
这个加载器我是直接通过下载Android 4.4系统源码把里面的linker源码抽取出来放到一个新建的ndk项目里面的.
里面的代码没有作任何修改.只是简单的把一些不能跑起来的代码给注释掉了.和增加一些函数.

先上自己写的一个加载so文件的入口函数:
```
extern "C"
JNIEXPORT void JNICALL
Java\_com\_example\_mi\_ndktest\_MainActivity\_openlib(JNIEnv \*env, jobject instance) {
soinfo \*sostart = nullptr;
soinfo \*soend = nullptr;
long long base;
GetModuleBase(base,getpid(),"linker");
if(base != 0)
sostart = (soinfo \*)(base+0x100a8);
soinfo \*si;
soinfo \*so\_n = (soinfo \*)dlopen(nullptr,0);
getgSoInfoPools((void \*)((uint32\_t)so\_n- sizeof(void \*)));//获取全局变量gSoInfoPools的地址
for(si = sostart ; si != NULL ; si= si->next)
{
soend = si;//定位最后一个so文件
LOGD("lib:%s",si->name);
}
initSome(sostart,soend);
soinfo \*substrate = do\_dlopen("/data/data/com.example.mi.ndktest/lib/libsubstrate.so",0);
}
```
注意到其中有两个变量sostart和soend这两个变量.在linker用于记录已经加载的so文件.所以我们需要把它们给获取到.
还有在调用do\_dlopen完成时会调用一个保护函数设置soinfo的内存区域为只读.由于我们加载so文件时对应的soinfo信息的引用(soinfo.ref\_count)会加1,所以会涉及到写入的操作.
```
soinfo\* do\_dlopen(const char\* name, int flags) {
if ((flags & ~(RTLD\_NOW|RTLD\_LAZY|RTLD\_LOCAL|RTLD\_GLOBAL)) != 0) {
DL\_ERR("invalid flags to dlopen: %x", flags);
return NULL;
}
set\_soinfo\_pool\_protection(PROT\_READ | PROT\_WRITE);//设置为可读可写
soinfo\* si = find\_library(name);
if (si != NULL) {
si->CallConstructors();
}
set\_soinfo\_pool\_protection(PROT\_READ);//设置为只读
return si;
}
static void set\_soinfo\_pool\_protection(int protection) {
for (soinfo\_pool\_t\* p = gSoInfoPools; p != NULL; p = p->next) {
if (mprotect(p, sizeof(\*p), protection) == -1) {
abort(); // Can't happen.
}
}
}
```
这个内存区域的信息是通过全局变量gSoInfoPools获取的,所以这个变量我们也需要把其获取到.
gSoInfoPools 的结构为
```
#define SOINFO\_PER\_POOL ((PAGE\_SIZE - sizeof(soinfo\_pool\_t\*)) / sizeof(soinfo)) //14
struct soinfo\_pool\_t {
soinfo\_pool\_t\* next;
soinfo info[SOINFO\_PER\_POOL];
};
```
那么怎么获取那,通过结构可以知道next的下一个结构是soinfo数组.通过分析可以发现somain模块就是在soinfo数组的第0个元素.那么我们通过somain的soinfo信息地址-4就是soinfo\_pool\_t\* next;而且该数组的最后一个元素又指向下一个soinfo\_pool\_t的soinfo数组的第0个元素.
![](upload/attach/201902/793792\_YSGEMHVYKA52NB8.jpg)
![](upload/attach/201902/793792\_QASBDXSR4B8DXQ6.jpg)
```
void getgSoInfoPools(void \*addr)
{
soinfo\_pool\_t \*pt = (soinfo\_pool\_t \*)addr;
do{
void \*next = (void \*)((uint32\_t)pt->info[13].next - sizeof(void \*));
pt = (soinfo\_pool\_t \*)next;
}while(pt->info[13].next);
gSoInfoPools = pt;
}
```
到这里我们就可以正常调用自己的do\_dlopen加载so文件了.
