# 一.前言

HEVD作为一个优秀的内核漏洞靶场受到大家的喜欢，靶场地址 [**HackSysExtremeVulnerableDriver**](https://bbs.kanxue.com/elink@4daK9s2c8@1M7s2y4Q4x3@1q4Q4x3V1k6Q4x3V1k6Y4K9i4c8Z5N6h3u0Q4x3X3g2U0L8$3#2Q4x3V1k6Z5j5h3y4C8M7%4W2K6N6r3g2S2L8g2)9J5c8V1S2S2j5$3E0e0P5i4y4q4P5s2c8J5k6h3#2W2g2Y4g2D9L8X3g2J5j5h3u0D9k6f1c8J5K9i4k6W2M7R3`.`.)。这里选择x86的驱动来进行黑盒测试学习内核漏洞，作为学习笔记记录下来。

实验环境:

|  |  |
| --- | --- |

| **调试器** | WinDbg，IDA Pro |
| **编译器** | Visual Studio 2017 |
