该软件是够变态的了.

1.先20/20出品的SoftSentry对FOX编译的EXE文件进行加密;
2.然后采用VFP&EXE对FOX编译的EXE文件加壳.
3.因此你用"方法一(见下)",虽然可突破VFP&EXE解出Y26356.exe文件(该文件名在你的微机上可能不同),但你使用市面所有反编译FOX文件的程序

都会告诉你"该文件不是FOX系列文件"因此无法反编译得到PRG,SCX等源代码(其实由于该软件未采用编制源程序的方法产生注册画面,故即使你本领超人破出源代码,也是无用)-需加密源代码可用该方法.

4.使用FileInfo.exe检查Y26356.exe文件,未发现是经过SoftSentry加过壳的.
5.到此,我只好调出TRW进行跟踪,胡乱下了几个 r fl z后发现程序中出现20/20字样,马上想到可能是经过softSentry处理过的.(说道这,还要谢谢wjx,要不是他提出破解MINIDVD,我是从未见过采用softSentry软件来进行加壳的)

6.至此,调出上午刚下载的desoft05.zip对Y26356.exe进行逆向工程(运行Desoft9x.exe后有三个按钮,选最下面的进行脱壳,文本框中的"1000"不要改),破出Y26356.exe纯净程序.运行,一切OK.


注:
1. TaskInfo2000下载地址:http://www.newhua.com/TASKINFO.HTM
2.desoft05.zip下载地址:http://mud.sz.jsinfo.net/per/aaron/files/unpackers/win/desoft05.zip



方法一: <<<<<<以下仅部分适用于破解"教程">>>>>>>>
<<<<<>>>>>>
<<<<<<注意: 资源管理器的配置中选中"显示使用文件"否则你看不见具有隐藏属性的Y26356.exe文件>>>>>>>>>>>



该软件使用VFP&EXE加密处理,如对其胜新库管王.EXE进行处理,那你就自认倒霉吧.
其实当你在启动胜新库管王.EXE后,再运行TaskInfo2000 2.2,你将发现有一个名为W25677.exe的文件,该文件子进程显示"胜新库管王",可推断出W25677.exe可能为软件自动脱壳后的真正FOXPRO编译的胜新库管王主程序.


但是,该文件位于c:\RECYCLED\ \ \ \0目录下,如你用资源管理器查看c:\RECYCLED,由于WIN98保护机制你将一无所获.

同时胜新库管王.exe进程对该文件进行了保护,当你复制c:\RECYCLED时显示"文件的一部分被锁定",这时你可用TaskInfo2000 2.2中止胜新库管王.exe进程(注意:不是中止W25677.exe)以去掉锁定.


到此,剩下的问题是将W25677.exe文件单独分离复制出来,以便进行相应处理.
方法如下:

<<<<<<<<<<< 拷贝即可>>>>>>>>


1.当你用TaskInfo2000 2.2中止胜新库管王.exe进程后,使用资源管理器复制c:\RECYCLED整个目录到d:\1子目录下
2.使用WINZIP.EXE对d:\1进行压缩,以使W25677.exe进入压缩包1.zip.(利用winzip的不带路径解压缩功能可将W25677.exe解出)

3.打开1.zip,你将看见W25677.exe文件.
4.选中W25677.exe文件对其解压缩,注意:此时将释放对话框中的"use folder name"前面的勾去掉.
5.至此W25677.exe文件已被分离出来,剩下的事你就看着办吧.
