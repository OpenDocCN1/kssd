# [原创]注册“豪杰超级音乐工作室 V1.1”

题目：注册“豪杰超级音乐工作室 V1.1”
功能简介：
万能音频播放，支持CD、MP3、AC3、VOB、MID、WAV等多种音频格式，支持VCD、DVD的音频播放；支持多种音频文件的相互转换，DVD、VCD、CD、MID、WAV转WAV、MP3；支持磁带与音频的外部录音，轻松把磁带转换到电脑及MP3播放器上；轻松制作自己的电子音乐相册；轻松玩转音乐数字CD抓轨。

工具：SOFTICE，PEID。
