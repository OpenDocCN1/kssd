
# [原创]聊一下！

在看雪里混的都有一身不错的武功造诣，我却是真真正正的小菜一个，学过一点外家功夫还没入门。在这十周年这个神圣的地方本来还轮不到我发表的，但是不吐又不快，在此厚着脸皮发一下偶的经历。![](https://bbs.kanxue.com/view/img/face/50.gif)![](https://bbs.kanxue.com/view/img/face/15.gif)

83的我在看雪里算是大龄人了，虽说学无前后达者为先，每每看到有惊人武功的少年侠士行走于江湖之中，只能暗暗努力！

自我介绍下吧，其实什么条件之类的并不是重点，重点的是有没有明确的目标，我就是因为没什么目标而且还没耐心及坚持，从而到现在还是没入门。

第一次接触电脑是从2002年开始的，那时是在高三下学期，附近开了一间网吧，说来也真是的，比我大一届的及小一届的学生都有电脑课开设，就是我那一届没开电脑课，对于拥有电脑一直觉得都是认为是有钱人才有资格，当有网吧后，就常常去看他们玩CS。那时也自己上机玩，还记得在吊桥那个地图对着天花板上的灯管拼命用ak扫射的情景，也记得用QQ自己说旁边的朋友边我打字同MM聊天的事，因为拼间不行，所以只能选五笔了，学打字的目的在那时很简单。就是为了能同女网友聊天，就去借了高二的电脑书背字根，在画在纸上的键盘拼命练，也亏得那时有努力学过打字，从而使我之后不管玩游戏同人对骂或者同时同几个MM吹水都能快速打出一行行方方正正的方块字。

我读的是一所不入流的大专，我想同我这个时代出生的大部分也是在大学里混过去的，很少人有明确的目标[指的上大专的同胞-\_-!]，不幸的是我也是其中一员，02年，传奇，还很火，我宿舍有一个是城里人，高中就玩传奇的了，所以在他的带领下，宿舍的全体成员都在网吧的传奇中度过，升级，PK，跟着他们行会战，玩过的就知什么叫热血了，真的是热血沸腾啊。。。

大学的课程很杂，我读的是计算机网络,就计算机方面的也很多，图形设计、网络基础、C语言、CISCO路由器、布线等，不过呢。基本上同没学过的差不多，因为那时只知道玩，根本没目的，也没想想未来，就这样迷迷糊糊过了三年，其实我对电脑程序很感兴趣的，也或许大学教程序的老师不会引导学生的兴趣吧，学c语言的时候，到了大学结束我还一直以为只能写dos下运行的，只能简单加减乘除之类的，所以C的课程基本上给我无视了，没兴趣所以不会深入，根本没去百度之类的。

毕业之后大学的一个同学开电脑店叫我过去帮手，其实就是装机维护之类的，也接网吧，因为做广告嘛所以会在软件里用修改资源的软件修改并打上广告[是不是很无耻？![](https://bbs.kanxue.com/view/img/face/50.gif)]，有些加壳的改不了，就百度，给我找到了看雪，呵那时的目的也简单，只要把壳脱了就行了，也看过了下教程，不过最后还是用脱壳机脱掉，那时看过 脱衣大侠 fly大牛的文章，就想学脱壳，这里搞下那里搞下太难了所以就放手了。

06-08学过很多东东，不过都是猫头鼠尾，入门了就放手，比如精简系统[及安装包]，封装，`au3`[用来写封装工具]，`delphi`,`ros`，`asp`等，无一精通。学得比较久的算是`delphi`，不过到现在也只会写操作下注册表及数据库的小软件而已。反正学没多久就去起点看小说，偶也曾经构思过两种题材的小说，全局剧情及大约的故事情节基本上写好..![](https://bbs.kanxue.com/view/img/face/1.gif)

到现在我认为只要有个目标，能静下心，再用用一万个别定律，那肯定会有所成。。

09年同学的店做不下去了，所以就到深圳打工，找了一份什么都不多，就是时间多的工作，在一个小工厂里做网管，也就四五十台电脑。

期间也开过一个网站，`www/520os/com`[写到这里我还记得有个网站就打开看下，进不了？问了下客服，她说机房80端口给封了，晕，] [今年合计: 2346 IP 10471 PV ]不过现在基本放弃，本打算搞几个广告费花花的，开始时拼命采集[`dedecms`系统]， 一直没流量就不了了之，反观我同学的网站现在一个月也能搞到几百美元，哎，

8月，开始学王爽第二版语言，9-11月都在看罗大侠的那本书，期间在`bccn.net`混得久点。

本来以为会一点点汇编就能破解了。那知，，，，，到现在一个软件也没破过。哎。。。。

11月之后调整目标，觉得要破解，或者写sdk的软件，了解了底层机理，熟悉内核，这样才能知其所以然。所以一直没买过书的我在这个月一口气买了四本书。

每每看到MJ，教主这些大牛带剑行江湖，指点江山。就羡慕不已。暗暗下决心努力学习，希望有一天能看到他们的背影。

我相信，只要真的有恒心，铁棒是能磨成针的。人不能活在对过去的追悔中，要看前方。呵呵，真的有个个美女在坐在我前面，我同事。^\_^!![](https://bbs.kanxue.com/view/img/face/12.gif)

希望还没找到目的，还在看到那个好就想学那个的朋友们，赶紧下定目标，不要让时间无目的流逝。

我很菜，希望有学内核的朋友加我153785587[希望钓个大牛指点下，哈]一起讨论，本菜常用ID：`onepc`，`zerostudy` 这二个，请大家多多指教。

写此文的目的是为了让自己有明确的目标，虽然起步晚了点，不过我感觉我现在很有兴趣学这个了。
