# [原创]沫、D开源内核小工具

大概在2013年写的,当时只考虑了XP系统,驱动层面只兼容了XP,不过内核层的SSDT表枚举全是在应用层实现的,所以很是有参考价值,有兴趣的朋友可以扩展下或者跟我一起完善![](https://bbs.kanxue.com/view/img/face/1.gif)

由于驱动层的代码在经历过一次硬盘格式化,提供不了,无非就是当时很流行的重载内核,没什么价值,还好关键的R3层面代码还在.

这个小工具参考了很多前辈的代码,过去2年了,已经回想不起来了,感谢这些前辈提供的帮助。![](https://bbs.kanxue.com/view/img/face/1.gif)
