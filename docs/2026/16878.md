# 0x04 虚拟机项目开启调试
先新建一个网站，网站目录是刚刚映射的共享磁盘目录
![图片描述](upload/attach/202207/861996\_4UJ86TMYA8EA8BU.png)
给网站添加xdebug扩展
![图片描述](upload/attach/202207/861996\_QE4VPMRPA43YVMQ.png)
编辑网站中选择的php版本对应的php.ini
![图片描述](upload/attach/202207/861996\_NJG6DAEQWR7NUUM.png)
在[Xdebug]中修改内容：
xdebug.collect\_params=1
xdebug.collect\_return=1
xdebug.auto\_trace=1
xdebug.remote\_enable=On
xdebug.remote\_host=192.168.0.102
xdebug.remote\_connect\_back = 1
xdebug.remote\_port=9001
xdebug.remote\_handler=dbgp
xdebug.idekey = PHPSTORM
![图片描述](upload/attach/202207/861996\_8PV9KKTDKA9GDCP.png)
其中remote\_host是PC机的ip
remote\_port是phpstorm的监听调试端口
idekey是phpstorm中设置的idekey
保存重启网站
