## 0x04 虚拟机项目开启调试

先新建一个网站，网站目录是刚刚映射的共享磁盘目录

![图片描述](upload/attach/202207/861996_4UJ86TMYA8EA8BU.png)

给网站添加`xdebug`扩展

![图片描述](upload/attach/202207/861996_QE4VPMRPA43YVMQ.png)

编辑网站中选择的`php`版本对应的`php.ini`

![图片描述](upload/attach/202207/861996_NJG6DAEQWR7NUUM.png)

在`[Xdebug]`中修改内容：

```
xdebug.collect_params=1
xdebug.collect_return=1
xdebug.auto_trace=1
xdebug.remote_enable=On
xdebug.remote_host=192.168.0.102
xdebug.remote_connect_back = 1
xdebug.remote_port=9001
xdebug.remote_handler=dbgp
xdebug.idekey = PHPSTORM
```

![图片描述](upload/attach/202207/861996_8PV9KKTDKA9GDCP.png)

其中`remote_host`是PC机的ip

`remote_port`是`phpstorm`的监听调试端口

`idekey`是`phpstorm`中设置的`idekey`

保存重启网站
