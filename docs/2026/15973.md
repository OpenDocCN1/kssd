# 一款基于Xposed自动化框架[XposedAppium]

## 简介:
基于Xposed做的一款自动化点击，滑动框架（基于安卓原生的事件分发）。可以模拟手指的一切操作，基于Xpath表达式获取View。此框架在virjar大佬的框架基础上进行的修改的，修复了部分Bug，添加常用方法等。
