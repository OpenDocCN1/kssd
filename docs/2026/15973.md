
# 一款基于 Xposed 自动化框架 [XposedAppium]

## 简介

基于 Xposed 做的一款自动化点击、滑动框架（基于安卓原生的事件分发）。可以模拟手指的一切操作，基于 `XPath` 表达式获取 `View`。此框架在 virjar 大佬的框架基础上进行了修改，修复了部分 Bug，添加了常用方法等。

## 实现原理

通过 Hook `Application->dispatchActivityResumed()`（也可以 Hook `Activity` 的 `onResume()`），包括 `Fragment` 里面的 `onResume()` 等来监听页面的切换。

![dispatchActivityResumed](https://bbs.kanxue.com/upload/attach/202007/819934_65793VY5BHF6BK5.png)

切换以后，遍历已实现的 `PageManager.ActivityFocusHandler` 或者需要处理的 `Fragment`。

![图片描述](https://bbs.kanxue.com/upload/attach/202007/819934_PC5NMVZZ72BHRVG.png)

根据设置的延迟时间，调用对应的回调。
