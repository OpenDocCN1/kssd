# [原创]另类关机之UPS大法

实在是闲的DAN疼，看看驱动编程，研究UPS例程时，发一个另类关机的办法![](https://bbs.kanxue.com/view/img/face/41.gif)
大概原理我猜是UPS服务如果监测到低电池量就会延时关机吧。懂的可以讲讲啊![](https://bbs.kanxue.com/view/img/face/1.gif)

测试方法如下：
解压后两个文件，右键安装demoups.inf
![](https://bbs.kanxue.com/upload/attach/201604/4656_kkt0w3ytci7q9yy.png)
然后在控制面板中打开电源选项的UPS页
![](https://bbs.kanxue.com/upload/attach/201604/4656_0w7u15foprht50u.png)
选择DDK Demo UPS 完成
![](https://bbs.kanxue.com/upload/attach/201604/4656_ppai75ioj92iak9.png)
返回UPS应用驱动，然后就等着机子被关闭吧，大概5分钟的样子
![](https://bbs.kanxue.com/upload/attach/201604/4656_zud5w97fdk1g2ck.png)

取消办法：
进入系统后马上修改UPS属性，选择无，并应用
![](https://bbs.kanxue.com/upload/attach/201604/4656_enghz6owdfg6qr8.png)
