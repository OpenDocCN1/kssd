**方法一：清除软件使用次数限制（两种途径）**

**方法二：爆破**
既然注册时有错误提示，可以通过查找字符串来查找按钮事件，OD载入软件
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_4toiurmbxhmq84g.jpg)
在汇编窗口单击鼠标右键，选择Ultra字符串参考—1.查找ASCII，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_xxfd9q2x86m7d07.jpg)
双击“姓名和注册码不匹配，注册不成功！”这一行，来到主程序窗口，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_jz5cj52zzqn3hnw.jpg)
往上观察，发现了一些关键东西：
00430B67    E8 24E9FFFF     call ChineseC.0042F490       关键CALL
00430B6C    84C0            test al,al                    关键比较
00430B6E    6A 40           push 40
00430B70    68 90044400  push ChineseC.00440490          ; gzpower chess
00430B75    75 21           jnz short ChineseC.00430B98    关键跳
00430B77    68 9C1A4400 push ChineseC.00441A9C  ; 姓名和注册码不匹配，注册不成功!
00430B7C    8BCE            mov ecx,esi

在00430B70这行单击鼠标右键，选择汇编，将jnz修改为jz，在汇编窗口单击鼠标右键，选择复制到可执行文件—所有修改，然后选择全部复制，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_j0cf5qx82yqvv2b.jpg)

单击鼠标右键，选择保存文件。
重启中国象棋V2.0，仍有注册提示窗口，但可以注册成功，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_wmxb28c9hhfqd74.jpg)
重启后仍然是未注册版，因些必须去掉提示注册的NAG窗口中。
OD载入软件，用F12暂停法去掉NAG窗口，F9运行软件，然后到反汇编窗口，按F12键，Alt+F9执行到用户代码，
![](https://bbs.kanxue.com/upload/attach/201101/304196_vnsk9tr2ob2bdzm.jpg)

00408499 这一行是调用注册提示的NAG窗口， 往上查找，发现00408461这一行正好跳过调用注册提示的NAG窗口，在00408461这一行单击鼠标右键，选择汇编，将jnz改为jmp,
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_audq7lejh1it7zj.jpg)
在汇编窗口单击鼠标右键，选择复制到可执行文件—所有修改，然后选择全部复制，然后单击鼠标右键，选择保存文件。
重启中国象棋V2.0，没有注册提示窗口，直接进入软件，如下图：
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_64n48ek822fbi37.jpg)

仍然有未注册字样，但不影响使用，也可将未注册字样去掉，OD重新载入修改后中国象棋V2.0，在汇编窗口单击鼠标右键，选择Ultra字符串参考—1.查找ASCII，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_apuu92lgjibnvyh.jpg)
双击“（未注册）”这一行，来到主程序窗口，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_rb4q4yje05az4qd.jpg)
从004086C6这一行往上观察，发现004086C4这一行跳转正好跳过“未注册”字样这一行，在004086C4这一行单击鼠标右键，选择汇编，将jnz改为jmp,
![](https://bbs.kanxue.com/upload/attach/201101/304196_72uc8rbu2dkvnqc.jpg)

在汇编窗口单击鼠标右键，选择复制到可执行文件—所有修改，然后选择全部复制，然后单击鼠标右键，选择保存文件。
重启中国象棋V2.0，直接进入软件，且没有“未注册”字样。OK！现在就是正式用户了！

**方法三：追踪注册码，制作内存注册机**
根据前文分析，00430B67这一行是关键CALL，用OD载入中国象棋V2.0，Ctrl+G输入00430B67
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_4790nmujzxmxza3.jpg)
点击确定，来到00430B67这一行，F2下断点，
![](https://bbs.kanxue.com/upload/attach/201101/304196_hv8nbxe4qpsrofj.jpg)

F9运行软件，输入注册名和注册码，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_r3pcgapxvq546a6.jpg)
点击“注册”，软件被OD断下来， F8单步，观察堆栈窗口，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_oxl5lkaexf5mzob.jpg)
正在进行真假码对照，复制"9eb9a33259ad034db8b0a8462dac9aee"字符串进行注册，注册成功。
下面制作内存注册机，见上面分析，软件被OD断在00430B67这一行，F7单步进入，F8单步走，来到0042F4A0这一行，观察寄存器窗口，
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_nt05oxuveey37a2.jpg)
EAX寄存器中就是真的注册码，打开keymake注册机，选择其它—内存注册机，浏览选择中国象棋ChineseChess应用程序，点击添加，在是中断位置填写0042F4A0，中断次数位置填写1,第一字节位置填写FF，指令长度位置填写6,
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_0wd6pkl5t1dn3rz.jpg)
选中“保存下列信息为注册码”，选中内存方式，寄存器方式选择EAX，然后点击添加，关闭添加窗口，点击生成按钮，
![](https://bbs.kanxue.com/upload/attach/201101/304196_bf61wzqsuumtwz8.jpg)
选择界面三，点击确定，保存注册机。运行内存注册机，注册码会自动出现，OK！
 ![](https://bbs.kanxue.com/upload/attach/201101/304196_a6teiu6r4lt4s19.jpg)
