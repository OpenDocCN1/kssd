
# 破解微信数据库2.0需要root或Xposed

把三年前的项目更新了下，就多了个支持Xp读取微信db，只有核心读取功能，想要什么数据自己写SQL。用Xp可能会被封号，没有定制xp的话，可以根据xp代码改一版frida的。

## 微信相关功能（微信存活在后台即可）

- **IM消息**——给指定好友发文本、图片、链接、视频、文件、小程序
- **SNS朋友圈**——发文本、图文、链接、视频、删除指定朋友圈、点赞、评论
- **社群**——创建群聊、拉人进群、发布群公告、获取群详情、二维码、群名称
- **修改类**——修改指定好友备注名、描述、标签、图片、自动设定时间通过好友请求、好友导入企业微信
- **监听类**——实时监控聊天记录文本、图片、视频、红包、转账、添加好友请求、朋友圈是否被点赞评论
- **数据库**——获取微信好友数量、群历史聊天记录、个人信息`wxid`手机号、头像、二维码图片、性别、省市区、个性签名、好友个人信息、添加方式、历史朋友圈

以上只是部分，做微信的朋友可以交流下。
