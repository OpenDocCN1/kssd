
# [原创]多核 32位VT，支持XP win7 (win10没测试)

这几天看代码，调试代码，脑子很乱，可能突然想到一个思路，然后用几天的时间，调试好了代码，但是到最后感觉有bug，就一分钟的时间全删掉，再重写 (虽然我对编程感兴趣，但是遇到这种情况，真的忍不住想摔电脑)，上次的VT不支持win 7 ，我今天调试了下，发现是`FS`寄存器的问题，具体细节可以看intel手册chapter 26那里，这个`EPT`初始化支持2M页，而不是4KB(可以自己修改)，最主要的原因就是用2M页的话，不怎么占用内存，我算了下，好像才10K 不到，而4KB的话，却需要2M页，这个代码可以让部分跟我一样菜的朋友，少走很多弯路，具体细节，直接看代码吧
