
# [原创] LLDB 使用方法（学习笔记）

## 一、加载调试

### 调试本地文件

常规：`lldb FilePath`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-1.png)

带启动参数的调试：`lldb FilePath Arg1 Arg2 ArgN`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-2.png)

### 附加进程

通过进程 ID 附加：

`ps aux | grep UserName | grep ProcName`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-3.png)

`(lldb) process attach --pid PidNum`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-4.png)

通过进程名附加：

`(lldb) process attach -name ProcName`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-5.png)

## 三、辅助命令

### 存在调试信息时查看代码

默认：`(lldb) l`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-14.png)

BTW：编译时需要以`gcc(cc) FileName –g`的方式输出，并且发现调试信息居然会带有注释。

查看函数代码：`(lldb) list FunName`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-15.png)

查看文件代码：`(lldb) list FileName`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-16.png)

### 查看反汇编

`disassemble -a 虚拟地址`（`dis -a $pc`）

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-17.png)

### 寄存器读写

`register read`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-18.png)

`register write RegisterName Value(hex)`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-19.png)

### 单步步入、单步步过、执行到返回和执行到下一个断点

- `step(si)` → 单步步入 == F7
- `next(ni)` → 单步步过 == F8
- `finish` → 执行到返回 == `ctrl+F9`
- `continue` → 执行到下一个断点

### 查看调用堆栈、执行到任意调用堆栈和查看线程

`bt`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-20.png)

`frame select FRAMENUM`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-21.png)

`thread list`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-22.png)

### 查看内存和修改内存

`memory read [起始地址 结束地址]/寄存器 -outfile 输出路径`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-23.png)

BTW：`memory read` 只能读取 1024 字节数据，超出将报错。

解决方法：加`－force`参数。

`memory read 0x10001000 0x10003000 -force`

或者：

`memory read 0x10001000 -count 0x2000 -force`

`memory read $x0`（寄存器）` -count 0x2000 -force`

`--binary` // 二进制输出参数

`memory write 虚拟地址 Values`

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-25.png)

### 查看变量

`print`（指定类型）寄存器/虚拟地址

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-26.png)

`po`（指定类型）寄存器/虚拟地址

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-27.png)

`expression $r6 = 1` // 设置`r6`寄存器的值

`expression $r6` // 查看`r6`寄存器的值

`expression username`（源代码中变量）` = @"11111"`

`expression [self btnTest]` // 调用某类某方法

![](http://www.expshell.com/wp-content/uploads/2016/05/lldb-28.png)

BTW：

1. 加参数可以更改显示方式，如`/x`十六进制方式打印。
2. `po`一般用作看对象信息。
3. `po`命令是“`expression -O —`”命令的别名，`expression`功能很强大。
