   听说超级魔法兔子设置有内部版和共享版之分，内部版3.97可到自由鸟汉化找到，我看了半天也不知有什么不同。反正都可以注册成功就行，我就只要它这个功能，:)。

   在网上找了好多超级兔子的注册码，可不是进了兔子的黑名单,如：Sun Bird [CCG] Sn: CX-AYYABBPDOLG
（完全不能用），就是不完全注册码。如 天若有情 sn:CXMSR-ZPZWTJWBCDZ(可以注册，不过你怎么改都没反应)   即然大虾们都找出了注册码，我这菜鸟就自己碰碰运气，找一找

   开始我试过用兔子组件里的ms98.exe破。发现找到的注册码就是不能注册winspeed.exe组件，所以干脆就用winspeed.exe.

   首先在超级魔法兔子的目录下找到winspeed.exe(我用的是超级兔子4.0中的winspeed.exe 3.4)，打开会出来注册对话框,名字随便填，注册码我为了省事就按照正确注册码的形式CXMS-xxxxxxxxxx（CXMSR-
是必需的,后面乱填11个字母），其它填法行不行，我没试过.点确定，然后点退出，因为兔子要在下一次起动时校验注册码.
    Ctrl+D  呼出softice （注意:要记得在winice.dat包含VB5的运行库，如没有，一定要添加）

   下Bpx \_\_vbaStrComp("\_\_"就是按下划线2下）,按F5返回，再点winspeed.exe,程序立刻被中断后

   下bc \*，这时按F10几下来到下面这里:( \*\*\*\*\*\* 代表你在softice下看到的数字，因为每台机器看到的不相同，只好用\*\*\*\*\*\*代替了)


             \*\*\*\*\*\*9f    PUSH EAX

             \*\*\*\*\*\*A0    PUSH DWORD
PTR [EBP+0C]
             \*\*\*\*\*\*a3    PUSH DWORD
PTR [EBP+10]

   CALL \*\*\*\*\*\*\*

   TEST EAX,EAX

   然后下bpx \*\*\*\*\*\*9f do "d ecx"  （下中断时,不是bpx \*\*\*\*\*\*9f
然后d ecx,而是完整的）

 (不下bpx \*\*\*\*\*\*9f，一直按F10你会看到兔子在不断拿你的名字和黑名单比较.比到最后一个时d ecx就出真码)

然后要做的事就是狂按F5。按十几下可看见黑名单，里面的名字是不是很眼熟,:)



        E.G.I.S........


        LI....HAO......
                     SOFTICE的内存窗口
 ====>       ...S.W.N.E.T.C.




这时你可按AIL+PageDown往下看，看最后一个黑注册码是什么
WINSPEED3.4版的看见的是JGMGRCTCWVK


        J.G.M.G.R.C.T.C


        W.V.K.......5..
                     SOFTICE的内存窗口
 ====>       ....6.......7..


        ....8.......9..

当你按F5几十下窗口出现JGMGRCTCWVK这个数据时,再按一下f5就可得正确的11位注码.
(如版本不同可能不是JGMGRCTCWVK,反正就是最后一个黑名单就行)
(正确的注册码出现后,再按一下F5,softice的内存窗口这时就是空的啦，所以也可以记下按的次数找)
(最好用超级兔子4.0中的winspeed3.4来找,4.15中的不行.找到的注册码所有版本都是可用的)
把得到的11位注册码加上前缀CXMS-,就搞定收工了，再启动ms98.exe，填上，所有的组件都应注册了.
