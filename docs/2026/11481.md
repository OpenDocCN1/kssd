# [原创]某安全卫士的内核hook

思路：
1、自己分配一块内存，存放需要hook的函数地址。
2、从内核模块中读取相应内核函数的地址，然后存放在自己分配的内存中。
3、修改nt!KiFastCallEntry函数中的代码，使跳入自己的驱动模块中。

优点：坚决不修改ssdt和内核模块中的数据，使得一般的工具软件无法检查出hook信息，也避免了和其他软件的不兼容性。
