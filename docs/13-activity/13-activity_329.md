

# 借看雪十年畅谈

> 原文：[`www.pediy.com/kssd/pediy10/103628.html`](https://www.pediy.com/kssd/pediy10/103628.html)

**借看雪十年畅谈** 看雪，十年了。想想网络也应该就是这十年发展起来的。十年前该是 1999 年。腾讯 QQ 刚出来吧，当时应该叫 OICQ，不记的了。隐约记得在 163 网易聊天室的情景。  
第一次接触网络这个东西是很兴奋的。和很多不相识的朋友在网络上聊天。不过多数是找和自己相差不多的女孩子们了聊（鬼知道是男是女）。想某年我在网络游戏里也曾经是个“人妖”。呵呵，不过这些都无关紧要了。毕竟我从来没有像如今认真的对待网络中的人和事。在网络上我始终会有自己的原则。不欺骗别人也不会轻易相信人。  
很多原则是随着时间会变化的，“忠君”在老祖宗那会儿是原则，现在就是愚昧了。来到看雪以后发生的事我讲过很多。不管是我的 linux 时期，还是 windows 时期。反正计算机在几年前算是真正的进入了我的生命。注意不是生活，是生命。我总是喜欢描述的详详细细的，因为我觉的这个词很重要。再次确认是生命，不是生活。  
真正的去了解计算机，了解网络以后。我开始相信，相信网络上的人，网络上的事。无论如何至少可以相信我可以获得真正是知识。就像来到看雪，几年的看雪生涯我学到的东西很多，也认识了一些朋友，这也是最重要的。  
看雪十年，谈谈和看雪相关的吧。刚来论坛时，一直没有什么突破。总想在看雪能够得到些什么，比如质的飞跃。但是发现。想突然的提高不是件很容易的事，虽然拜读了很多大牛的文章。但是大多数都是看不懂的，少数的还只能是一知半解。一次在论坛提问，很多人都给出了建议或者方法。但是自己基础太弱，如何也不能理解网友给予的答案。在发贴的言语间，还把笨笨雄版主搞的很无奈（后来我把自己的大部分惹人不开心的话都删除了，毕竟我是个好孩子）。实际上那次给我的触动很大。也就是那次的冲击我才静静下来学习自己开始不削的基础，认为自己已经掌握的基础。  
偶然间被 kanxue 给予了肯定，兴奋不已。慢慢的渐渐的成长起来。其间给予我帮助的朋友很多。我这边不能一一提及。我最为感谢的还是 kanxue 和笨笨雄。kanxue 在技术上给予的肯定和支持，是激励我前进的动力，而笨笨雄则是诲人不倦的人生哲理是前进的指南针。我实际经常会想如果现实工作中他们能够合作，一定很强大。我试图谈及此事，但是有人告诉我我想想的太过理想。呵呵，无意间讲十年畅谈变成了感谢信。能在这里畅谈无论如何是要感谢他们，感谢给予过我帮助的人。以及经常在论坛上帮助别人的人的。  
看雪十年，说点对看雪，对自己的一些期望。希望是看雪成长的一个转折点，不久成为安全界最具有影响力的论坛社区。同样希望也是我的一个转折点。套用保尔柯察金的名言，人生只有一次，不要碌碌无为。人生是曼妙的舞台。我们不是父辈的续集，也不是后辈的前言。我们是自己的主角。
