

# 感悟我的编程经历

> 原文：[`www.pediy.com/kssd/pediy09/pediy09-706.htm`](https://www.pediy.com/kssd/pediy09/pediy09-706.htm)

> 在看雪论坛上我用的是“红火蚁”的名字，实际中，我经常以“关中刀客“自居.可能有的朋友对“关中刀客”这个名字熟悉吧  
>   
> 看到大家在发表自己的编程路程，我也来说说自己的经历吧，也算是对自己大学生活的总结   
> 高中时期的我，根本就不知道计算机编程这个概念，高三以前没见过电脑（除了电视上看到过）。  
> 到高三的时候，同学把握拉进了网把，才知道了什么是电脑，那个时候，我连开机都不会，QQ 都不会用，更不要说打字了，经常就是一个指头在键盘上找字符。报考大学的时候，我根本就不知道计算机专业，软件工程专业是干什么的，就这样，被调剂进了软件学院，学软件工程.  
> 没上大学的时候，总是美好的憧憬者，奖学金，纯真的爱情..........  
> 大一开学了，开始学什么 pascal,c,c++，汇编都在大一学的，说实话，哪个时候的我们，根本对这些编程不以为然，整天在学高数，英语＝＝，这个阶段的我，对 c,c++,汇编可以说就不会，连指针都是我最大的难点，考试都是 6２，６３看来多亏老师留情了。  
> 大一暑假回家，在家没什么意思，然后就来学校，无疑见发现了“编程爱好者”这个网站，发现里面很多的“高手”，同志们也很热情地回家你的问题，然后我就整天泡论坛，暑假的时候，我开始学在 TC 下面做一些图形化的编程，基本都是那些论坛上的朋友帮助我的。  
> 大二开始了，第一个学期，照样的整天泡论坛，然后这个时期对 c 语言还算理解的更多了一些，然后到了大二寒假，我们试训，老师给我们教 MFC 程序设计，以下子震住我，太神奇了，居然能简单的实现一个窗口，还能显示图片，然后我着了魔，那个寒假，我没有回家，在学院实验室一个人默默地学习着 MFC,然后到了大二第二学期了，感觉 MFC 就是那么回事，就那样子做就可以做很不错的窗口==，这个时候，自己发现回 MFC 不算牛，要是全部都是从 win32 开始做的话，那才牛，然后我就开始学 wn32 程序设计，这个时期，我认识了 dummy,robin＝＝的好朋友，很多的不会，他们都帮助了我，再次写写了，无意见发现了 hook 这个东西，太神了啊，然后就整天用 hook 做东西，屏幕截图，消息群发，＝＝，就这样子一直在学，大二的暑假我也没有回家，一个人在实验市学习这些技术，大三开学了，我选的＂游戏开发的专业＂，就开始学那些 directx＝＝,这个时期，是我人生的一个重大的转变时期，因为我们一个教室那么多的人都主要学的 3D 场景的渲染技术，所以我感觉自己没有必要在专注这个方向，学一些比较特殊的，然后就开始专注学 socket 编程，这个时候的我，能找着例子写一些程序，但是因为没有老师指点，都是自己自学的，所以很多的东西不知道，大三的寒假，我照样没有回家，一个人在实验市学这些，我记的很清楚，大年初七的那天晚上，我一个人在实验市通宵的学习，看着那些 socket 编程的书籍，我突然之间茅塞顿开，全部的理解了那些到底是怎么回师，那种感觉，在我的编程经历中，经常出现，几天都没有成功的程序，突然之间就成了，找到了问题所在，所以我内心知道：上天还是很照顾我的．然后就是大三的第二学期了，我才真正的认识到，一个成功的开发者，不是回什么 MFC,回什么 win32,回什么 socket 就可以的，而是对 c++本质的把握，所以我这个学期，那些什么＂游戏引擎＂＝＝，我都没有主要的学，而是在学习很多 c++本质，一些＂设计＂上的东西，那些都是表面而已，最核心的还是＂设计＂，我见过很多写程序牛的人，说实话，他们的设计思维很菜，只回写程序谁都回，关键看谁的设计好，看谁的框架好，在这个方面，现在的我，重申我 MFC，MFC 在消息的处理上很有技巧的，至少大多数的人都做不料的，在大三的第二学期，我也学到了很多关于网络程序设计的东西，这些对我来说，都是很宝贵的财富，回顾我身边的同学，虽然他们回只用 DirectX，回做简单的 3D demo,但是在我的眼里，他们的程序都是拼出来的，逻辑设计，物理设计很混乱的，说实话，在老外那些高手的眼里，这样子的代码就是二个字＂　垃圾＂．大三暑假我没有回家，因为要工作，现在的我，大四了，感悟了．感觉大学的时间我失去了很多的东西，爱情，欢乐＝＝，但是我学会了“忍受寂寞”，人都说“像学技术就要耐得住寂寞”，没错的，我没有看到那些整天陪美女朋友的同学，技术上很牛的（或许真的有这种牛人存在）。我的大学挂课很多，但是我感觉在大学期间我要得到的东西我已经得到，其他的对我来说已经不重要了，所以我现在考虑“退学”，虽然我的大学也是一个全国重点的大学，但是这些对我来说，已经不重要了，对我最宝贵的东西“忍受寂寞”“自学能力”我已经有了，所以没有必要再像其他人一样的生活。  
> 看着初中，高中的照片，英俊潇洒，文采风流，在看看现在的我，白发苍苍，胡子长长，慢性咽喉炎，身体消瘦，都是因为我对技术一颗执着的心。我不曾后悔我这样做。
