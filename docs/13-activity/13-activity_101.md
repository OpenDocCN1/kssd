

# 今天下雪了，可是不冷，因为可以看雪

> 原文：[`www.pediy.com/kssd/pediy12/128466.html`](https://www.pediy.com/kssd/pediy12/128466.html)

今天我想在看雪这片神圣的地方写下我的很短的成长经历，并以此激励自己不断努力。     
     我是一名毕业于一个三流学校的的大专生，大学的时光很多，当年在大学里，念了两年书就出去实习了，靠了那点对 javaee 肤浅的理解，居然找到我人生第一份实习工作，那是 09 年的 9 月，那时我只会 java,会用时髦的框架 ssh 做些系统，说白了那只是网站，我知道它还是能做好多事情的，不过外包的项目用她来开发会更快点，更灵活，稳定些。09 年 9 月份我参与一个小网站的开发，主要是小孩在幼儿园，家长在家可以通过网站看到，大概开发到 11 月份，结束了，之后就是维护的事情了。之后公司就没项目可做，领导让我跟着网管做些维护的事情，哎，没办法，那段时间天天装系统，做网线，说起做网线，最多的一天要做 200 跟吧，那时候一有空我就坐下来学习，多学点东西，在找份工作，那时坐我后头的同事很友好，有一次她跟我聊了会，问我会不会 flex,她有同事会来这个地方开公司，想推荐给我去，我当时那个冲劲，刚好我的毕业设计就是用的 flex+java，于是就答应了，这里我再次谢谢这位大恩人，呵呵。当个星期我就去买了本厚的书再次巩固下，等 12 月份，新的公司领导过来很和聊了会，决的还行，于是在 10 年 3 月份进入了一个新的公司了。3 月份我们做的一个医疗的项目，跟医疗方面的吧，用的是 flex 渲染界面，amf 的协议和 java 通信，大概到 10 月份差不多做完，之后又在一个月的时间做完了手机版本，windows mobile 的开发，那时候还不太熟悉 c#,于是花了一个星期熟悉 c#,勉勉强强带点新手的感觉把手机版本做完了。之后就是装机的事情了，得跟医院里头的人交流，郁闷的了，无锡话还听不懂，不过之后我就做其他东西了。从 3 月份到 11 月份这一阶段，我又要提到我的迷茫了，空余时间不是看 java,flex，c#和工作相关的，而是去学习其他东西了，而且还接二连三的变，看了 ruby,觉得好厉害，自从电脑装了苹果系统之后，又开始决心学习 python 了，而且 google 一直力推 python 的，再加上 googleappengine 先有 python 版本的，那时候决得 ruby 版本太多，不太唯一，语法变化多端，而且 gui 设计很弱，学习 python 主要看到之前上海的同事他就会 python,最重要的是他的也是苹果系统，在苹果的终端下，敲着 python 脚本酷酷的，于是日日夜夜的看 python，那时候是夏天，每天看到 12 点，大概两个星期之后，一本看完了，突然发现自己又不感兴趣了，发现 python 功能并不是那么强大，完全解释性的语言还是脱离操作系统很远，于是我又放弃了，不看了。那时又一次迷茫了，我该学什么呢？那时候得知一个网友很牛逼，他说经常把他们的网吧里电脑搞死，我很佩服他，他说他才 16 岁，吓了我一大跳，原来他还是个初中生，他说他英文不会，主要还是用易语言搞，听了之后，又有冲动了，当初在大学里的时候我在学校电子阅览室的时候那位老师就是用的易语言，做些小外挂，很方便，于是又开始学习易语言了，下了几个 G 的视频教程看，看了 1/3 不错，还做了一些小外挂，其实也不算了，照猫画虎，不过易语言对其 winapi 的封装真好，真方便，简单易懂，看了之后，过些天，工作又忙了，就没看，过些天再看时候又不想看了，发现易语言功能强大，其实也少不了一些付费或者不付费的模块，而且易语言还不是免费的，外挂海的模块还要钱啊！！最后我还是放弃了，那几天，还搞了些 googleapp engine 的东西，没坚持多久。记得 2 年前，百度被黑的事情，我就想起了一个论坛，看雪，恩，这个论坛给我了很大的帮助，当初在电子阅览室那个位老师的指导下，我走进了软件破解的大门，不过我有些日子没来了，如今我又来了，看了看雪几篇成长的故事，我很有动力，我知道论坛里面大都是一等一的高手，他们给我们讲解了他们曾经的成长的故事，给了我们很大的鼓舞，我记得北极星 2003 的那篇文章我感触很深，其中有句话。这里复制下：  
  
“在学校常有听说某公司需要某类技术的人才，然后就有一些人蜂拥过去，我不喜欢这个样子。货物公司需要的是骡，征战沙场需要的是马。现实社会中各类人才都是需要的，我们所要做的只需要让自己成为千里马，我们的伯乐总会出现的，总有能让我们展示自己的舞台。又何必去盲目追随瞬息万变的社会，在学校里这需要按照自己的轨迹成长即可”  
  
当时我很激动，不过我也很清晰自己，其实之前走的一些弯路就是我的兴趣和人云亦云的思想在作怪，我觉得我还是不太喜欢做些窗体，依赖.netframework 做些好看的自定义控件，还是反复的一张一张的 jsp 页面，还是数据库的增删改查，还是遇到相关的功能，比如说一个 struts2 上传，一段 xls 解析，一段酷的效果，就去网上搜段代码，复制改一下就好了，期间虽然积累了一些经验，不是说这些东西没技术含量，不过我还是觉得很乏味，缺少激情，也许是因人而异吧，感觉这些好像都不是我要的，那段时间我一直潜水于看雪论坛，看到不会的东西就 google 下，慢慢的找回原来的大学时候对破解的激情，期间我还在猪八戒网成功了帮人家脱了个壳，说来简单，是个变异的 upx 壳，输入表和资源修复下居然好了，主要人家还是想 diy 那个软件，想改资源的。那时候我很兴奋，当晚我从 10 点搞到凌晨 3 点半，兴奋我一晚没睡着，最后我还认识了替他脱壳的网友，得知他是做免杀的，而且还是业余的，本来是铁道部 ，他也是业余时候学习下，听他说他为学这个免杀，闭关了两年，期间他还上传了自己的免杀视频教程，也特地传到了网盘推荐我学习，他说你想学的话就把心思放在上面其他的就先放一放吧，不然你什么都学不成的，当时我心头一怔，觉得好惭愧，不过 他的教程我还真没怎么看懂，用的是 Delphi，反省了自己，原来自己这些年来一直徘徊应用层的开发，一直没有关系底层实现的细节部分，在大学里我借书记录是 223 本，其中两本是数学的，一本是我同学借的小说，其他的都是 java,jsp,单片机什么的，从来还没关心过 windows 原理方面的东西，问起 dos 还以为 windows 下的 cmd.exe 就是，好惭愧.....。于是我立刻从 vc++开始补，12 月份看了孙鑫的 vc++深入详解，才觉得 windows 的消息机制，才明白为何有时候在破解的时候要下消息断点，当初看得 看雪记事本 DIY,才明白消息处理函数的意思，顿时恍然了许多，又看了那本红皮的<<Visual C++ 2005 入门经典中文版>>，理解了托管和非托管的代码的区别，加密与解密那本书里提到的 dll 导出函数又更深刻理解了。不过现在工作的需要，我又有了新的开发任务，做游戏，用 XNA 这个框架，不过用了 ICECREAM 这个 2D 游戏引擎开发更快了，我才有空看其他书，(\*^\_\_^\*) 嘻嘻……。我这里可以推荐下哦。之后也就是现在又看了老罗的那本经典的 windows 汇编的书，更是才发觉自己以前是多么的无知，不过也很开心，感觉我心中有个很大的 bug 被修复一样，如今我已经在看雪这里找到了自己的方向，正向《O+DAY 安全：软件漏洞分析技术》那本书的作者提到那句话（所有漂亮的 exploits 背后后隐藏着无数个对着寄存器发呆的不眠之夜）一样，我会义无反顾，永不回头，不管前面的路有多难......  
    今天我们这下雪了，呵呵~     
    感谢看雪~
