
# 两年的梦

> 原文：[`www.pediy.com/kssd/pediy10/65015.html`](https://www.pediy.com/kssd/pediy10/65015.html)

看着大家都这么热情的交流自己的成长故事  
小菜我也来热闹哈子  
本小菜于去年（2007.6）高考惨败，哎！当时心里是有一个想法就是学肯定是还要上的，当然大学就不用想了。去学什么了？于是就先在附近找了份工作做了起来，可是这人要是没个目标，这小日子不好过呀，总要想点什么吧！没多久就不在去上班了，开始在为自己的以后着想了，其实一直一来我都对电脑都很是感兴趣，在高二的时候开始接触的 C 语言，不过当时没下决心只是一个兴趣而已，当然不用说，没学咋的。

在家里的那个时间心里特别的虚，最后才决定去学电脑。其实在高二的那段时间还因为想去学电脑还和家里搞得不愉快。爸妈一定要让我毕业了在说，可毕业了，家里并不想让我去学电脑。家总是说现在学这个的人太多了，就以后不好找工作。我就说啦，我说：“不错！现在学电脑的人是多，但是真正学好的人多不多呢？我想信我一定能把电脑学好的。”

反正也没上班了，于是从去年的 10 月份开始一直都在家里看书，在那段时间里我的 C 语言开始真正的入了门，家里电脑也是才买的，没有连网，手上资料又不多。这时就是隔四五天就带着手机去上网，手机里面也就 256 的内存，就这样从网上下了很多东东，看着可好了！那种对知识的欲望是无法形容的。当时也没个体系，只要是电脑的都看，看不懂的就硬着头皮去看。由于自己的基础问题，有太多的不明白，又没有人可以交流！不过想起来那时候还是很开心的，反正天天坐在电脑旁边，就这样慢慢的积累了不少的知识。记得当时过年三十的晚上我对着电脑看书看到了两点多。晚上就没看放礼花~呵呵。今年就好了，二月中旬我来到了武汉开始了我学习，我相信这是一个新的开始，我很是珍惜这个学习的机会。不过来到了这里到现在就学校讲的来说没学到什么东东。不过我们以后要学的编程语言是 C#，所以就把别的同学的书借来了看了，有 C 的基础，学起 C#来感觉还好，没什么困难。

然后就是对看雪的钟情，说起来还得说说去年在家自学的那段时间。那是无意中下载的看雪精华，有种如获珍宝的感觉，可以让我喜又让我忧。看天书的感觉可能就是那样吧！为此我又买了一本汇编语言的书，死看了几天，指令的意思是还可以了，就代码放一块是在做什么那就是 CPU 的事了，实在搞不明白。现在好多了，正在看《加密与解密》（二）---》图书室借的，期待着第三版  
要收藏呀

正是因为看雪让我扩大了知识面，从而让很多同学对我另眼相看。甚至许多在这里学了很久的同学斗不相信这知道的这么多。感觉特别好的就是每当和那些学哥学姐们交流的时候，看着他们那眼神，呵呵。不过我从没有自大和自懑过，因为看雪就是我的一面镜子，他让我不时的告诉自己要努力，要学的东西很多，而且这个世界上的牛人很多，要有一颗虚心，要不断的去学习来充实自己

看看时间！哇！1：06
