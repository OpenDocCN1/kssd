

# 坚持就是胜利,送给所有看雪的新手和自己

> 原文：[`www.pediy.com/kssd/pediy11/116944.html`](https://www.pediy.com/kssd/pediy11/116944.html)

坚持就是胜利     很多人都想学习解密，也许是解密能满足人们的猎奇心里，因为这东西刚入门时会让人沉迷进去，可以饭不吃、觉不睡，很神奇，但是，慢慢地，随着学习的深入，你会发现某些东西越来越难，甚至是毫无头绪，这时候就是回过头温习这篇文章的时候的了![](img/cda69129882b40377a87144c782680e1.jpg "微笑")  
      下面以《格兰特船长的儿女》一书为例讲述坚持的重要性。  
　　格兰特船长求救的漂流瓶。在英国政府拒绝营救的情况下，格里那凡爵士毅然组织格兰特船长的儿女等一行人乘坐“邓肯号”去寻找船长。虽然他们多次遭受土著人的袭击，但是他们并没有放弃寻找；他们找遍了南纬 37°的所有陆地，登高山，爬冰川，过沼泽；他们遇到过地震，洪水和野兽，最后还跟匪徒进行殊死搏斗……经过了无数的艰难困苦，他们终于成功地在荒岛上找到了格兰特船长。这就意味着坚持就是胜利。 　   
　　“坚持就是胜利，”这句话用在我身上是最适合不过了。这个暑假，我喜欢上了破解，我喜欢破解成功后的那种胜利的喜悦感，但同时我又惧怕面对那复杂的程序，这时我就会想到格里那凡爵士的毅力和罗伯特的勇敢，坚持不懈地走着，尽管我已经筋疲力尽，尽管我已经受不了，但我仍会凭着那不服输的精神继续走下去，因为我知道我心中有一个不倒的信念一直在默默的支撑着我，那便是坚持就是胜利。 　   
　　坚持就是胜利。俗话说：“世上无事难，只怕有心人”。就算是再难办的事情，只要人们用心去做，总是有可能成功的。无论做什么事情，如果不坚持到底，而选择半途而废，那么再简单的事情也会办不成。想想看，如果格里那凡爵士等人在落入土著人手中时，要是不克服重重困难，想方设法逃走，那不就永远成了土著人的俘虏了吗？如果他们在冰川、洪水的降临时畏缩不前，一心想着放弃，那么格兰特船长不就要永远流落在荒岛上了吗？因此，只有抱着锲而不舍、持之以恒的心态，困难才能迎刃而解。 　   
　　所以，坚持就是胜利！我们应该有所感悟，我们应该学习书中人物那勇敢和大无畏精神，我门应该领悟那钢铁一般的毅力，我们应该懂得坚持就是胜利，坚持一定能胜利！  
    最后，附上 kanxue 先生的一句话作为结尾：“学习解密其实很累的，需花费大量的时间，而且经常会碰壁，三五天毫无进展是极为平常的事情。这时你可能有点想退却，其实你不要着急，只要你认真学习，成功就在眼前。没有人是生来就什么都会的，如果你有问题，就大胆的去问你周围的人。学解密的秘诀就是勤奋＋执着！记住并能做到这两点，你会变得很优秀的。”
