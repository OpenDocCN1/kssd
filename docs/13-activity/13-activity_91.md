

# 认为一个真正的 Cracker 必须熟练掌握以下几点

> 原文：[`www.pediy.com/kssd/pediy05/pediy50612.htm`](https://www.pediy.com/kssd/pediy05/pediy50612.htm)

  
一个真正的 Cracker 必须熟练掌握以下几点：  
1.德； 要有社会道德意识，必须遵守一些规范！  
2.数学； 要尽可能的多学一些数学知识，必须具备扎实的数学基础！  
3.外语； 最起码要有一定的英语阅读能力，当然掌握得越多越好！  
4.计算机知识； 必须熟练掌握 8088 系列 x86 汇编语言和一门高级程序语言！  
5.悟性； 必须具有一些触类旁通的本领，死记死背定律以及公式是不行的！
