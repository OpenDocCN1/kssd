

# 分析幼年菜鸟们的玩具对其日后发展的影响

> 原文：[`www.pediy.com/kssd/pediy05/pediy50468.htm`](https://www.pediy.com/kssd/pediy05/pediy50468.htm)

一个人幼年的玩具对他日后人生发展的方向是有着巨大的影响，所以孟母三迁的故事一直被写在启蒙书中。同样对于刚接触加密和解密的菜鸟们，最初选择的"玩具"也将影响今后他们在这个领域的发展，因此我今天谈一谈"玩具"与发展方向的客观联系。  
  计算机诞生在第二次世界大战中，最初的应用是参加盟军对德军的情报解密工作，正是它的参加扭转了整个世界的格局，同时也加快了加密和解密这一矛一盾的发展速度。  
  A. 最初接触的四个玩具  
   a. 汇编语言玩具。 这是一个枯燥的玩具，很多菜鸟都不太重是它。  
   b. 程序流程图玩具。 这是一个有趣的玩具，但菜鸟们极少有人碰它，因为想把它画出来非常困难。  
   c. 工具型玩具。 这个玩具入门简单但精通不容易办到，不过菜鸟们很喜欢它，因为它可以很快的带来成就感。  
   d. API 类玩具。 因为 Windows 的普及使得这个玩具变得容易理解，虽然菜鸟们不了解它，但都能举一反三，触类旁通，有人说"嗨，不就是个积木吗，地球人都知道！"   
  B. 逐一分析对发展方向的影响  
  由于人的大脑使用的不是 INTER 至强 CPU，所以不能进行多进程同步运算，这就决定了菜鸟在最初接触这一领域时玩具选择上的侧重，这个选择也将直接影响他日后的发展方向。  
   a. 选择汇编语言玩具。这是一个需要较高数学基础的玩具；同时还需要较强的逻辑思维能力和忍受寂寞的能力，由此就可以看出这类人的日后发展情况及方向，程序员尤其是系统底层程序员占大多数，还有小部分是黑客或是系统调试员...因为这类人大多都能做住凳子，长时间的使用电脑以及黑白颠倒昼伏夜出，缺乏有规律的生活。  
   b. 选择程序流程图玩具。这是一个有强烈权利欲望人玩的玩具；稍不留神就变成一个公司老总，他们有较长的潜伏期，一有机会立即发作。他们纵观全局，喜欢宏观管理，精通各种力量，资源和人力的分配，意志力极强；这类人大多都有很好的生活规律，语言逻辑能力高，对新生事物异常明感。  
   c. 选择工具型玩具。这类人大多爱慕虚荣，对寂寞的忍受能力极差，善变，一定时间的无所作为会使他们改变发展方向，懂的知识极广，但都不精，缺乏耐性，买书一般选择"\*\*\*快速入门";"\*\*\*一月通"；"\*\*\*速成教材"...等等，很难在业界有所作为，大多从事非技术类工作，公务员较多。  
   d. 选择 API 类玩具。 microsoft 忠实信徒，一般都会一种以上的高级计算机语言，接受新事物快，生活休闲化，浪漫，是好的大众情人 :))（玩笑），穿着整洁，多是外语水平强，一般都有较高的学历，有志向。这类人大多能成为应用程序程序员，大城市较为集中，生活稳定，经济收入上好，很少的人能成为黑客，因为多数对底层系统一知半解。
