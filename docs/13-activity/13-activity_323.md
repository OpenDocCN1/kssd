

# 一起去看雪

正文  
    第一次摸电脑应该是在初中吧，在学校的机房里，那鼠标还是滚轮的。至于老师到底教什么了，忘了。值得一提的是就在那时候，我会了神奇的一招：搜索，本地全盘搜索（那机子还没接互联网）音频视频文件，还不是什么音乐和电影，那机子中还没有这些的，老师上课的时候，我就在下边偷偷的把自带的耳机插上去乱听，第一次听到计算机的声音，应该是有激动的吧！那时我还并没有就此迷上了计算机，由于环境以及条件的关系，我们那些小地方，欠发展，也没什么见识，所以并没觉得这东西的到底会有多重要。自此，和计算机之间的接触也就搁浅了。  
    一直到了高二，可能是需要放松的关系吧。第一次和朋友去了网吧，是通宵，我记得，啥也不会，在朋友的指导下开始乱点了。最郁闷的是开了一款游戏，却不知道怎么退出，因为是全屏模式的，没办法，直接叫管理员了。令我兴奋的是，发现可以在线听歌，喜欢啥就听啥，无论何时，都觉得音乐是个好东西，家里还收藏着以前买的一两箱磁带呢，不知道拿它怎么办了。通宵到了早上 8 点，该回去了，可我还没觉过瘾，就谎称要买些东西，让他们先回去睡觉。自己就随便吃了点早点，就又钻进了网吧，继续想发现新奇的东西和弄明白那啥“神奇”的东西是怎么回事，我总是这样，没弄明白会老想起它。直到自己认为明白了才好，对有兴趣的事物，先放一放对我来说有些困难了!一直到下午两三点。真困了，实在是对它无力了，才回家补睡眠了的。  
    从此，我是对计算机上了兴趣了，有时间没时间，开始经常跑网吧了，当然是去玩和乱点的。还记得第一次玩 CS 的时候，在地图中瞎跑几圈，头就开始晕了，还不适应这个虚拟的空间能动来动去！慢慢头不晕了，可也没多少兴趣玩了。不知是性格关系还是自我控制，我对游戏都没什么激情可言的。  
    必然的，我就渴望了解隐藏在计算机背后的东西了，事实上也就是想知道那些程序是咋出来的的而已，因为这是当时我直接可以看到的东西了。我就开始学习 Java 了，为什么是 java 呢？通过了解，我认为这个语言是很强大的，啥跨平台啊等等。我就想啊，既然要学就学最好的最新的最多人用的！尽管当时我不知道我用过那些程序都不是 java 弄出来的，尽管现在看来它那跨平台啥的和当时想象的完全不是一回事。所以我的第一个“hello world!”就是 java 弄出来的，尽管这和那些漂亮的程序根本没法比，但还是很高兴的，至少它来之不易啊。可惜的是到目前为止这个 hello world 竟成了我 java 语言历程的绝唱。  
    黑客，我不得不感谢这个概念。自由的，共享的，最吸引我的还是那份神秘感，不太懂事啊就是。当了解了传统的黑客精神后，我冲动的就认定这就是我想要的了。接着买了一本黑客攻防实站详解和一期的黑客手册学习，当然很多东西都看不懂，而且书中基本上也就讲讲工具的使用。第一次用啊 D 工具“全自动”的进了一个不知名小站的后台管理，什么都没干，就出来了，其实也不知道要干什么。现在我就是黑客了？后来了解到这样的叫“脚本小子”，而且现在讲的黑客已经不是那么回事了，更多的是为人所不耻的东西！显然这不是我想要的结果。梦想和现实总是有差距的，这个差距常常给我们带来了烦恼，但同时也是进步之源。在高考报志愿的时候，我报了信息安全专业。  
    开始上大学了，大学里什么东西是最好的，那肯定是图书馆了。为了了解更多的计算机知识，开始从图书馆借阅过不少计算机相关的书籍，因为大一还没自己的计算机，到了大二上学期才买了电脑的。跑网吧和学校的机房都不是很方便，所以很多东西，也就是看看，而没有动手去实际下，因此也就只能是了解下了的，而且很多看过就忘了。渐渐的看到了 C 和汇编的强大，于是就多看了些这两个语言的入门书籍。期间从网上下载资料而下载到的看雪论坛精华集，虽然没看多少，但是在碰到问题的时候，在从中找下学习，还是很有用的。就是这个精华集，让我从此进入了看雪的世界中。事实上，我印象中早在高三的时候，我就碰到过看雪大哥那个早期的 crack 教程，也就知道了看雪，可惜的是那时候可能只是来逛了下主页，都还没进到论坛的，然后就离开了。  
   2008-12-03 是值得纪念的一天，也就是在大二上学期差不多到期末的时候，这一天我在看雪有了自己的号，下面是我在论坛发的第一贴，由于是发到了《生活心情》版，所以并没有记入我的发贴数中：

现在看来当时是多么的浮躁了，现在的我还是很多都不懂，别说两年了，就是五年也不一定做到的 powerful 的，再说，世事无常啊！事实上，学习是需要贯穿始终的，应该是一生的计划！  
    接着马上在当当网买了《加密与解密第三版》，寒假带回家学习，现在书背后的封面都已经掉了。收假回来写了第一篇简单的 crackme 破文并发到了论坛上，这是我在论坛的第一篇精华，对我有着极大的鼓舞。尽管有时候批评比鼓励更能使人进步，但我还是希望多一些鼓励，少一些批评，也许是人的本性使然吧。下面是这篇文中开篇的一小段话，也记录下（我很希望可以借这次看雪十周年征文的机会把这篇记录我历程的文章写好，这样的机会不是很多，而且我也不是很会写文章的）：

这是我写的第一个 creakme 分析文章，也是我第一次在看雪发表文章，在这里我还想谈一下我的感受，还请多多忍耐了！我接触这个加密与解密差不多有一年了吧，但都仅仅只是停留在了解这么一个层次上，没有发生过什么亲密接触了。真正开始学是近一两个月的事，但我以前有学过 c，asm 的一些知识，但都是浅薄的一点了，感觉人还是浮躁了一点.今年一月份买了 kanxue 大哥以及诸位大虾的出的《加密与解密》，用春晚老毕的话说是：内容很不错，写得很不错！不过对我来说是有点难了！春节放假回去鼓捣了一阵，今天终于写了第一篇破文，我的心情是从多云转晴了!不说了，不说了，什么时候把感想重写一篇把，还扯不完了还，都快跑偏了！最后我要感谢 pediy,感谢 cctv,mtv............还是 F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7F7.....................实际~@~

2009 的春晚《不差钱》我很喜欢，所以就模仿下了，呵呵！  
  
    后来很幸运的认识了 kanxue 大哥，带着自己不成熟的想法和 kanxue 大哥聊了不少次。让我有机会对看雪论坛有了进一步的了解，并深深的感受到看雪论坛走过了艰辛的十年并得到越来越多的朋友的支持和欢迎是多么不容易的事。我是在看雪论坛陪伴下成长的，饮水思源，我能够做点什么吗？在 kanxue 大哥和诸位前辈的认可下，我做了新人版的版主。帮助别人就是帮助自己，这话很不错。在做版主到现在这个期间，学到不少，也是让自己去学习很好的动力，尽力去做个称职的版主。必须要说的是，在看雪论坛认识不少很好的朋友，尽管都还只是限于网上的交流，但是网络可以因人的真实而变得真实，我一直这样认为，所以我很珍惜！会有那么一天，在哪里碰上了，一起吃吃饭，喝杯小酒，是多么惬意的事啊！  
    到今天我来看雪论坛刚好整一年了，现在自己变平静多了，没那么多浮躁了，这是个好的开始，不在急切的希望自己 powerful 了，因为感觉这是水到渠成的东西，没有什么捷径可言的吧。同时也体会到了这样一句话的含义：勿在浮沙筑高台！基础打好了稳了，后面的进步就快了，可扩展的空间也广了！一些教授专家一直在喊着，到大学，主要学习的不是知识，而是掌握知识的方法。还是很有道理的，尽管我的老师们并没有很好的做到这一点。比如，我碰到了一个问题，第一个反映就是先搜索而不是发问，看是否有人碰到相同问题并解决了吗？很多时候，我们做的就是仅仅需要去找到它而已，所以现在我们面对海量的信息，如何快速的找到我们需要的信息是无比重要的必修课。事实上，我想很多时候，这些道理我们都明白，但不会放到心里面，一般都有这个坏毛病，直到受伤了疼了痛了，才知道要记住和吸取教训的！  
    我想象着看雪论坛下一个十年将会是什么模样？自己又会是什么模样？脑海中闪过无数个景象，虽不能定格，但我知道的是，那里都有着希望！这让我想起了鲁迅先生的那句话：其实世上本没有路，走的人多了，也便成了路!  
    恩，好了。就写到这里吧.现在大三了，快毕业了，对自己以后的路依然感到了些许迷茫。但我也会坚持着，努力着，和看雪论坛一起寻找那片属于自己的天空！
