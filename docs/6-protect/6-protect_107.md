

# 加密狗检测工具源代码

> 原文：[`www.pediy.com/kssd/pediy12/133064.html`](https://www.pediy.com/kssd/pediy12/133064.html)

此源代码绝对原创，检测机制是利用 USB 设备的 VID 和 PID，准确率 99%，为什么说 99%呢，因为针对 HASP 的狗还不是能很准确的判断，因为 HASP 的狗全部是一样的 VID 和 PID，判断型号需要从狗里读出狗的参数才能准确判断。  
  
本人发出来，是希望有人帮完善一下，做成能扩充狗型号，免除了每增加一种狗就要重新编译程序，本人实在是没什么时间去完善了。  
  
源码用 Delphi 7 编写，如果没有安装 D7，自行去找找下载了。
