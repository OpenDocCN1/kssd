
# CS V.J 破解实录

> 原文：[`www.pediy.com/kssd/pediy03/forum955.htm`](https://www.pediy.com/kssd/pediy03/forum955.htm)

用了几个星期来跟踪`INSTSCS.EXE`始终没有结果,突然想到在用`ICE`跟踪的时候,按`F12`键时第 11 次就死机了,会不会......

于是我就在读完密盘以后按`CTRL+D`调入`ICE`,"大约在 10%处

```
<S DS:0 L FFFFFFFF '9090'>
```

搜出在`0E24:F79B`处出现了我的密码，先碰碰运气再说,向下找可疑代码,

```
< 0805YYZIP >
```

这个`0805`会不会就是密码呢? 我们知道,`SCS40.DAT`的压缩是用`YYZIP`作的,"鬼才知道`YYZIP`是什么压缩软件,不管它.这一定就是了,因为在解压缩这前一定会验证密码的.

重新运行`INSTSCS.EXE`输入`0805`直到安装完成,哈哈 `^\_^`成功了。原来这么简单，
