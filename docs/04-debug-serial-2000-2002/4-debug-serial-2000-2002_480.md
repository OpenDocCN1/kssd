
# s-spline2.03

> 原文：[`www.pediy.com/kssd/pediy03/forum823.htm`](https://www.pediy.com/kssd/pediy03/forum823.htm)

想跟注册码的话简直要被它故意搞的无数个 `GetTickCount()` 烦死不可！

它设了好几个标志来标明是否注册版。

### 1. 决定启动时的 splash screen 是否显示 unregistered

```
0177:0041B44E  CMP        [004D47E8],EBX
0177:0041B454  MOV        BYTE PTR [EBP-04],05
0177:0041B458  JZ         0041B462
0177:0041B45A  CMP        [004D47F0],EBX
0177:0041B460  JNZ        0041B4E0
```

只有跳到 `0041B4E0` 才不会显示 unregistered。
