`超级兔子魔法设置 4.17pj`

`pj` 工具：`TRW2000`，此软件是用 `VB` 编的。

1、`BPX` ＿＿＿`VBASTRCOMP`

2、按 `CTRL＋N`

3、`BD＊`

4、慢按 `F10`，看到：

```
167：0076283585　MOV　ECX，[EBP+0C]
167：0076283588  MOV  EDI,[ECX-04]
167：007628358B  CMP EDI,ESI
```

下中断 `BPX` `7628358B` `DO` “`D` `ECX`”

5、狂按 `F5`（数百下，^\_^），注意数据区显示的密码。
