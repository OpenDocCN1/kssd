例如，我们输入注册用户名字是 1，那 1 转换为 16 进制的 ASCII 码是“31”，“31”不足八位，需要补全补为 318c048c ，翻转为 C840 C831 x1=c840 x2=C831 填到   CRM4-(x1)-56ei8-(x2) 得到的注册码就是：CRM4-138C56ei8-048C ，算法分析大概就是这样，知道了原理，我们就来写我们的算法注册机（编写语言 VB）。  
代码如下：  
Private Sub Command1\_Click()  
Dim LenText1, i As Integer  
Dim str, ValueText1 As String

LenText1 = Len(ValueText1)  
If LenText1 = 0 Then

For i = 1 To LenText1  
  str = str & Hex(Asc(Mid$(ValueText1, i, 1)))
