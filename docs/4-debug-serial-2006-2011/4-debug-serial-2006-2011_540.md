机器码思路：  
eax =AC5B5AEF  
ecx 右移八位 得到 AC5B5A  
后八位给 esi＝EF  
eax 给 ebx，edx＝AC5B5AEF  
esi 左移 8 位 ＝EF00  
ecx 后八位给 eax＝5A  
edx 右移 16 位＝AC5B  
esi 与 ecx 相加＝EF5A  
edx 后八位给 ecx＝5B  
esi 左移 8 位＝EF5A00  
ebx 右移 24 位＝AC  
esi 与 ecx 相加＝EF5A5B  
ebx 后八位给 edx  
esi 左移八位＝EF5A5B00  
esi 与 edx 相加＝EF5A5BAC  
  
然后对其以八进制输出就是机器码了  
  由此可以看出机器码是通过 C:\\卷标来得出来的，先进行反序，然后在以八进制输出就是机器码了！！
