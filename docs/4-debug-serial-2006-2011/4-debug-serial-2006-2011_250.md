【经验总结】  
  好长的算法，听偶细细道来~~  
  注册码第三位\*3E8；注册码第七位\*64；两个数的和，记为 A；注册码第七位\*2\*5，记为 B~；A+B 的和，记为 C~；C 加上注册码  
  第一位~~，记为 D~；我们记录的数值 D\*D，记为 E~；E 除以 C5~~；余数放在 ESI 中，记为 a；用户名的 ASCII 码累加和，记为 F~  
  ；余数 a 除 0A~~,记为 G~；G+F，记为 H~~；H 除 64，余数记为 b~；余数 a 除以 0A~~余数记为 c~；余数 b\*2\*5 记为 I；余数 c 加上 I,  
  记为 J~；注册码第四位\*64 放在 EAX 中~~，记为 K；注册码第二位\*2\*5，记为 L~~；K 加 L，记为 M~；M 加上注册码第六位，记为  
  N~~；J 和 N 中的值比较，不相等就 gameover!
