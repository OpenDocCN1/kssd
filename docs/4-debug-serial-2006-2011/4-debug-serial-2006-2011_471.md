  注册算法：  
  码表为：0123456789  
  注册名有 k 位(8<=k<=64)  
  计算第 N 位注册码：假设第 N 位用户名位的 ASII 为 X(n)，第 n 位码表的 ASII 位 Y(n)  
  
  (X(N%k)\*D+Y(N%A)+N\*N\*N\*k)/A 余数在查码表，结果即为第 N 位真的注册码  
  "6769－"＋所有位注册码即为即为最终注册码

  void CComExplorerDlg::OnOk1()
