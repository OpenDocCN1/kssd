【算法总结】  
  
1、注册码形式为\*\*\*\*-\*\*\*\*-\*\*\*\*-\*\*\*\*-\*\*\*\*共五部分组成，分别记为 sn1、sn2、sn3、sn4、sn5  
2、格式化读入字符串"1-3-1-4"，用于验证比较  
3、令 m=10，则 d=sn5%m，m=d+1  
4、d=sn1%m 与 1 比较、d=sn2%m 与 3 比较、d=sn3%m 与 1 比较、d=sn4%m 与 4 比较  
全部相等则注册码有效。
