

# 拼音加加 2.0 版

> 原文：[`www.pediy.com/kssd/pediy01/forum037.htm`](https://www.pediy.com/kssd/pediy01/forum037.htm)

我爱暴力！！！ 如何去除“拼音加加 2.0 版”的功能限制   
  
    今天买了一份最新的《电脑报》，看到上面有介绍一个新的输入法——拼音加加 2.0，说可以：无须切换的中英文混合输入，三重码显示等等。喔！小弟打字一向不快，又最烦上网时一会儿输入中文，一会儿输入英文，不断的换输入法，马上到 http://www.6h.com.cn 下载了一份。用一用，果然省事。   
    接下来就是研究其主页上所说的功能限制了。它如是说：   
1\. 在安装软件时征得用户同意(我不同意你也改呀！！！）后，拼音加加将把用户计算机中的网络浏览器的默认首页设为 http://vs.6h.com.cn。用户可以无限期免费使用拼音加加，而且其功能也和付费方式完全一样。   
2\. 如果用户希望保留浏览器的默认首页设置，就应当购买注册号。注册号可以直接在线购买到。注册费 30 元人民币。   
    付注册费，好像不是我的性格；让出浏览器的首页，也非我的所愿。怎么办？当然是破解了。   
    先要找准目标。安装此程序时我用 system mechanic 检测，知道它给我加了多少文件。试一试，知道注册程序是 c:\\windows\\system\\ime\\ rovasoft\\pyregagent.exe   
主程序是 c:\\windows\\system\\pyintau.exe   
    用 w2dasm 反汇编 pyregagent.exe，试着强迫其注册，但不能成功。但我知道了改变我浏览器首页的是 pyintau.exe，就改变方向，想让其运行时不去动我的首页，但也未获得成功。怎么办？   
    停下来，用你的大脑想一想。它用 http://vs.6h.com.cn?ID=#&AG=#改，我让它还是用我首页的路径替换不就行了吗？（比如我的首页是 about:blank，让他还是改为 about:blank）。就用 ultraedit 打开 pyintau.exe，搜索 http://vs.6h.com.cn?，只找到一处，将之改为 about:blank，多余的其它词都用....（00h）替换，将其后的一个 about:blank 也用...换掉。保存文件后执行一遍，ok！30 元省下来了！
