ClipYES!:   
  
由于很多人编辑文本文件时喜欢点击鼠标右键进行复制，粘贴工作，当使用   
ClipYES 复制了多个 text record，能否增加鼠标右键功能，当点击鼠标右键，   
移动鼠标到粘贴（p）处时，产生下级菜单，分别为刚复制的 text record，   
这样方便选择，还可增加一些智能处理能力，如常用的 text record 会自动   
上移等，几乎所有的 Windows clipboard tools 都无此项功能。

TRW20001.23:   
  
TRW2000 真的很好，短小精干，我一直喜爱，但她仍然存在一些问题：   
  
1、当 TRW2000 所在的目录字符大于 8 个时，如：c:\\trw2000123，按热键时存在   
plug-ins 装载失败的现象！   
  
2、一直困扰我的问题：先运行 TRW2000 后（1.22,1.23 版本），按 CTRL＋N 硬盘   
狂闪好一阵子才能出现调试界面，有时还死机。但 CTRL+M 没这样的问题。1.03   
1.13 的 TRW 也没 CTRL+N 上述问题!! 我的 PC: 赛扬 2 667 EP-3VCA2+ 128M PC133   
RIVA128/ZX 20G 迈拓 COM1 接口老鼠 WIN98，我以前的 P100 也存在这样的问题，   
上上个星期才把 PC 升级的，还是有这个问题，痛苦!不知道是不是软件的问题?   
是否我的 TRW2000.INI 没配好？但在 AMDK6-2 350 上 TRW 的新老版本却从没发现   
这个问题，显示卡是同一型号，TRW 的说明上写  If you press Ctrl-N and   
nothing happens, try pressingany key or moving the mouse. to see if   
anything happens。但没用。后找到一个折衷办法，RUN TRW1.03 版,CTRL＋N   
后退出,再 RUN TRW1.22 版，CTRL＋N 无上述怪现象发生,总之,还是老版本稳定!   
  
3、新版 TRW 设断如 BPX HMEMCPY 后，BL 看会是 BPX #0147:00009E62，断点多后   
会糊涂，能否象老版本(1.03)那样仍然显示 BPX HMEMCPY，或两种同时显示？   
  
4、1.23 版 CTRL＋M（N）后出现调试界面，再按热键却不能回去，只能 F5。   
  
5、调试界面显示 JUMP 时，能否在旁边加上↑↓，如 SOFTICE 一样方便观察？   
  
6、鼠标右键能否多加功能？
