
# 让 warkey 与魔兽争霸“同生共死”！

首先，感谢看雪里面帮助我的兄弟姐妹们。

我个人比较爱玩魔兽，于是提出一点个人的研究结果与大家共享，如有不足之处，希望大家批评指证，本人也将虚心接受。![](img/f43c1e514327696dccbb0da997496b2a.jpg "扮鬼脸")

这是关于如何 PEDIY 魔兽争霸中的某个 `DLL` 让它发挥点“另类”的作用，其实也能用于其他方面，大家可以自由发挥，呵呵！![](img/022c916b9660e467a8663bd57a4ae6d1.jpg "狂笑")

由于 `Game.dll` 比较大，所以分成两部分上传。直接将其和 `warkey.exe` 放入魔兽争霸目录中即可。![](img/e71d9210a215d5b66755d038631e0c83.jpg "恐怖!")

`warkey` 是魔兽争霸的一个小助手，它可以将小键盘上的按键转移到其他键，从而使操作更便捷。

PS：昨天忘记了一点，最后要将我们改动代码处设为新的 `OEP`，不然代码不会执行我们想要执行的部分。（具体步骤见 `DOC` 文档）
