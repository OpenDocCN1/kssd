
最后说一下，`IconEdit2(v2.4)`脱壳后，只需要修正`IAT`，并改一下`(1)(2)`两个陷阱，即可正常运行，没那么麻烦了。

添第二个段的时候，`PEditor`说`PE`头没有足够的空间添加段了，不知道是怎么回事，诚请高手指点一下！我看到有几个段的`size`是`0`，估计删掉应该可以吧，可是`PEditor`中却不能删，用`Procdump`的`PE editor`删掉了。然后就可以继续添加段了。最后用`rebuilder`只选中`make PE Header win nt/2000 compatible`进行`PE`头文件重建，就`OK`了。

不幸，还是不能成功存盘。继续跟踪知道，`dump`出来的数据在使用的时候已经改变了，是有什么程序又用了`SMC`把我们千辛万苦抓出来的数据和代码给改了，真是可恶呀！我也尝试了把这几个段改成只读，没成功。只好继续耐心的追踪，终于找到了这段`SMC`的代码在这里：

```
018F:0048A1EC  MOV       BYTE [004935DC],01 <-- 这里必须置 1，存盘判断

```

就是这里改变了我们`dump`出来的东西，把从`push`开始的全`NOP`掉吧。
