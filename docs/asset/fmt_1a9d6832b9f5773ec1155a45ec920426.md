### 判断偶对齐

```
if (addr & 1) cout<<"unaligned!"<<endl;

else cout<<"aligned!"<<endl;
```

以 `x` 字节对齐可以借用公式 `addr & (x - 1)` 来判断

对齐分为地址对齐和大小对齐，上面说的对齐指地址对齐，对于大小对齐则可以

```
if (size % align==0) cout<<"aligned!"<<endl;

else cout <<"unaligned!"<<endl;
```
