```
8B 44 24 04    mov eax,[esp+04]    ; 当前计数器加几
6A 01          push 01
01 41 38       add [ecx+38],eax    ; 关键代码，将该语句置空即可
E8 25 00 00 00 call 0041b43e       ; 没跟踪该调用的含义
C2 04 00       ret 04              ; 返回，该子程序结束
```

#### 1. 引言

`BrainsBreaker` 是一款很棒的拼图游戏。未注册版本有注册提示；部分拼图有 `Demo` 字样，这些拼图会限定所拼的块数。软件保护做得很好，对于水平仍旧很菜的我而言，尚不能搞定它。但因为最近没做别的破解，就把大致过程写出来凑个数，另外也是抛砖引玉，希望感兴趣的朋友们试试。期待高手做出完美的破解来。

#### 2. 破解过程

1.  去除 `"Demo"` 字样：最容易的部分。用 `Hex Editor` 打开 `BBrk32.EXE`，找 `"Demo"`。把找到的第二处 `Null` 掉。再找 `"(Demo mode)"`，同样 `Null` 掉。再看拼图画面，干净了许多。但是那些本来有 `"Demo"` 标志的拼图上还有个小的透明框。
2.  去掉透明框：

```
:004318B2 85C0                    test eax, eax
:004318B4 0F84EF000000            je 004319A9 /改 jmp
```

3.  去掉拼图开始及结束时的 `NAG`

```
:0043BF86 E889D80300              call 00479814
:0043BF8B 395D0C                  cmp dword ptr [ebp+0C], ebx
:0043BF8E 7532                    jne 0043BFC2 /改 jmp
```
