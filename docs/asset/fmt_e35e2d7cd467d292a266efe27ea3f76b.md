### 第二步：定位 OEP

通过观察代码结构，确定程序由 `Delphi` 编写。寻找 OEP，在 `GetModuleHandleA` 处设置断点，观察堆栈 `esp`。

当发现调用堆栈如下时：

```
0012FF94   004066D9  /CALL to GetModuleHandleA from mjcs.004066D4
0012FF98   00000000  \pModule = NULL
```

表明 OEP 已经执行过。通过逐步返回（Step Back），定位到真实入口点：

