
# 脱壳与数据提取流程

选择插件 `OllyDump`，点击 `Dump Debugged Process`。在弹出窗体的 `Modify` 栏里填 `136B`（默认是当前断点位置 `136C`，需修正）。点击 `dump`，随意填写名称并保存。假设保存的文件名为 `aaa.exe`，将其存储在原来程序的目录中。使用 `peid` 查看 `aaa.exe`，识别结果已变为 `VC6.0`，说明壳已脱除。运行测试正常，脱壳步骤完成。

## 提取资源文件

下一步是提取数据，尤其是资源文件，需使用 `ExeScope`。
1. 用 `EXESCOPE` 打开 `aaa.exe`。
2. 依次展开 `资源` -> `RC 数据` -> `200`。
3. 此时右侧出现十六进制和 `ANSICC` 数据。
4. 点击 `文件` -> `导出`，选择文件夹（如桌面），文件名设为 `aaa.rc`。

在此文件的资源中，除了 `RCDATA` 外主要是图标，`MID` 文件很可能位于 `RC` 数据中，但需进一步确认。使用十六进制编辑工具 `010Editor` 打开 `aaa.rc`（若习惯使用 `UltraEditor` 也可，两者功能类似）。

## MID 文件格式说明

在提取之前，需了解 `MID` 文件格式。每个 `MID` 文件开头包含特定十六进制代码：`4d 54 68 64 00 00 00 06 ff ff nn nn dd dd`。

- 前四个字节是 ASCII 字符 `MThd`，用于鉴别 `MID` 文件。
- 随后的四个字节指明文件头描述部分的字节数。`MID` 文件头占 `6` 字节，因此此处固定为 `00 00 00 06`。
- `ff ff`：指定 `MID` 的格式。`00 00` 表示单音轨，`00 01` 表示多音轨同步，`00 02` 表示多音轨不同步。
- `nn nn`：指定 `MID` 的轨道数。
- `dd dd`：指定一个四分音符的 `TICK` 值，用于控制节奏。

`MID` 数据区由若干个子数据构成，在多音轨格式中记录轨道信息。单音轨则直接追加数据。每个音轨以 `4D 54 72 6B`（ASCII `MTrk`）开头，后跟一个 `4` 字节整数，标志该轨道的字节数（不包括头部的 `4` 字节和该整数本身的 `4` 字节）。

## 提取 MID 数据步骤

1. 在编辑器中搜索 `MThd`（区分大小写）。在 `aaa.exe` 中位于地址 `13F3A`。
2. 检查后续字节：
   - `13F3A` 后 `4` 字节为 `00 00 00 06`（文件头长度）。
   - 再后 `2` 字节为 `00 00`（单音轨）。
   - 再后 `2` 字节为 `00 01`（轨道数为 1）。
   - 再后 `2` 字节为 `00 61`（四分音符 `TICK` 值）。
3. 文件头结束后进入数据区，前 `4` 字节确认为 `MTrk`。
4. `MTrk` 后 `4` 字节为 `00 00 17 80`，表示音轨数据量为 `1780`（十六进制）。
5. 计算结束位置：
   - 数据起始位置：`13F50`。
   - 数据结束位置：`13f50 + 1780 = 156D0`。
   - 因此，`MID` 文件数据范围从 `13F3A` 到 `156D0`。

## 保存文件

在编辑器中选中上述区域，按 `CTRL+C` 复制，新建文件粘贴，按 `CTRL+S` 保存为 `aaa.mid`。打开 `aaa.mid`，音乐播放正常，提取完成。
