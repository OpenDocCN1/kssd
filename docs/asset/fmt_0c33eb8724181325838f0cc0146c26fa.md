
# BootStar V6.02

> 原文：[`www.pediy.com/kssd/pediy06/pediy6966.htm`](https://www.pediy.com/kssd/pediy06/pediy6966.htm)

`BootStar` V6.02 是一款能够控制多操作系统的软件，看雪学院《论坛精华四》里面有 `arbiter[CCG]` 写的 `BootStar` v7.33 `keygen in pure win32asm` 的注册机，但是没有分析过程。碰巧我有 `BootStar` V6.02 的版本，所以就把分析过程写了出来。如果你想练手可以到 [http://www.star-tools.com](http://www.star-tools.com) 下载新的版本。

首先检查是 `UPX` 的壳，脱掉！我们输入下面的信息：

- User-ID: `dengkeng[DFCG]`
- Key: `123-45678-9ABCD-EFGH`

这个是指定的格式输入，因为如果你输入错误的话，它会告诉你出错了，然后在 `Key` 这一栏里面用 `***-*****-*****-*****` 这个格式表示出来，告诉你输入的正确格式。
