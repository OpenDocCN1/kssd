### 1.2 注册用户名地址定位

`0041CA5D`处：
```
0041CA5D     A1 885F4300        mov eax,dword ptr ds:[435F88]    // 这里就是  
```
地址 `ds:[00435F88]` 的值为 `00447384`。

### 1.3 写入注册用户名

内存地址 `00433FD0` 处数据：
```
00433FD0  63 79 74 6F 00 00 00 00  cyto....  
```

修改 `00447384` 处的指针：
```
00447384  00D92DCC                    // 修改前  
00447384  00433FD0  ASCII "cyto"     // 修改后  
```

### 1.4 分隔符逻辑追踪
