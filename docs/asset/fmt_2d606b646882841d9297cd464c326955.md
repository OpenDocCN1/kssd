
# 算法总结

（涉及数值都为 16 进制）

$(注册名各字符 \ hex \ 值的累加值) \times 1E82 + 1E240 \times 注册名字符的位数 + BEAE7$

结果再换成 10 进制，就是注册码啦。

注册名：`李逍遥`

注册码：`4D8 * 1E82 + 1E240 * 6 + BEAE7 = 93C5B0 + B4D80 + BEAE7 = AAFE17 = 11206167 (d)`
