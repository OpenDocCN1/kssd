
### 局部变量

*   `name`, 文本型
*   `len`, 整数型
*   `sn`, 文本型
*   `i`, 整数型
*   `C`, 文本型
*   `sum`, 文本型

### 代码逻辑

```
name ＝ 编辑框 1.内容
len ＝ 取文本长度 (name)
.计次循环首 (len, i)
    C ＝ 取十六进制文本 (取代码 (name, i))
    sum ＝ sum ＋ C
.计次循环尾 ()
sn ＝ “CMW201118” ＋ “-” ＋ sum
编辑框 2.内容 ＝ sn
```
