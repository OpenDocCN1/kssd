反向效验的代码：

```
//return init reg  

DWORD RevCRC(DWORD reg,DWORD*pdata,int n)  

{  

  for(int i=n-1;i>=0;i--)reg=RCRC32(reg,pdata[i]);  

  return reg;  

}  

//根据数据和效验值求出效验初值  
```
