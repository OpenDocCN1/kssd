## 3. 自定义 sendto 函数

此函数用于拦截正常的登录数据包，支持穿透路由器。

```c
extern "C" __declspec(dllexport) int WINAPI MySendTo(    // 导出函数，我们自己的 sendto 函数
    SOCKET s,
    const char FAR * buf,
    int len,
    int flags,
    const struct sockaddr FAR * to,
    int tolen
)
{
    int result;
    for (int tt = 0; tt < len; tt++)
    {
        *(buf_authorize + tt) = *(buf + tt);
    }
    len_authorize = len;
    tolen_authorize = tolen;
    flags_authorize = flags;
    strcpy(to_authorize.sa_data, to->sa_data);
    to_authorize.sa_family = to->sa_family;
    if (SAVE) Save();
    if (LOAD) Load();
    result = ::sendto(s, buf_authorize, len_authorize, flags_authorize, &to_authorize, tolen_authorize);
    return result;
}
```

## 4. 使用说明

- 加入一个对话框，在其中处理对程序工作的设置。
- 编译得到的 `.dll` 文件即可使用。
- 通过自定义的 `sendto` 函数，可以截获正常情况下的登录数据包，在路由器后使用即可穿透路由器，实现正常登录。

## 3. 检测结果与修改

上述代码清晰地展示了程序创建了系统进程列表，并逐项比对，以确定是否使用了代理或 BT 程序（如 `SyGate.exe`）。因此，之前受怀疑的 `00403AC0` 确实是检测函数。

我们需要对该检测逻辑进行“手术”，禁用线程启动。

**修改前：**

```asm
00403AEB   .  6A 00        push    0
00403AED   .  6A 00        push    0
00403AEF   .  6A 00        push    0
00403AF1   .  6A 00        push    0
00403AF3   .  51           push    ecx
00403AF4   .  68 109C4000  push    00409C10
00403AF9   .  E8 E0BB0000  call    <jmp.&mfc42.#1105_AfxBeginThread>
```

**修改后：**

使用 `jmp` 指令跳过检测线程的创建，并填充 `nop` 指令以保持对齐：

```asm
00403AEB   .- E9 10932100  jmp     0061CE00
00403AF0     90           nop
00403AF1   .  6A 00        push    0
```
