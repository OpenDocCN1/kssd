### 使用 OD 修改

上面只是我用 OD 来完成的。下面我要自己写代码完成了。

于是我查看那个 `dd 00441528`：

```
00441524  004411BA  Lobby.004411BA
00441528  00000D89
0044152C  78EB0090
00441530  83EC8B55
00441534  4D8908EC
00441538  F84D8BF8
0044153C  0CC0C181
```

于是我要写的就是向 `00441528` 写入 `00000D89`，向 `0044152C` 写入 `78EB0090`。

还有那个 `jmp` 的：

```
004415A2    ^\EB 84       jmp short Lobby.00441528
```

查看 `dd 004415A2`：

```
004415A2  AEEB84EB
004415A6  E58BC033
004415AA  0004C25D
```

于是我要写的就上面三个数：

- 向 `00441528` 写入 `00000D89`
- 向 `0044152C` 写入 `78EB0090`
- 向 `004415A2` 写入 `AEEB84EB`

其实第三个作用写一个 byte 就行了，但是懒得麻烦，直接写一个 int 一样。

### 代码实现

下面是代码，由 Delhi 写的：

```delphi
function hook(h: HWND): bool; stdcall
//h:目标程序的句柄
var
  pid: DWORD;
  phandle: HWND;
  lpNumberOfBytesWritten: DWORD;
  a1, a2: integer;
  b1, b2: byte;
  bo, bo1, bo2, bo3: bool;
begin
  result := true;
  
  a1 := $89501589; // 00441528
  a2 := $78EB0087; // 0044152C
  b1 := $84;       //004415A3; 写的是一个 byte，和写 int 一样道理
  
  try
    GetWindowThreadProcessId(h, @pid);
    phandle := OpenProcess(PROCESS_ALL_ACCESS, false, pid);
    
    bo := writeProcessMemory(pHandle, Pointer($00441528), @a1, sizeof(a1), lpNumberOfBytesWritten);
    bo1 := writeProcessMemory(pHandle, Pointer($0044152C), @a2, sizeof(a2), lpNumberOfBytesWritten);
    bo2 := writeProcessMemory(pHandle, Pointer($004415A3), @b1, sizeof(b1), lpNumberOfBytesWritten);
    
    if bo and bo1 and bo2 and bo3 then
    begin
      result := true;
    end
    else
    begin
      result := false;
    end;
  except
    result := false;
  end;
end;
```

于是你可以通过这个函数直接改他程序执行流程，达到你的目的。
