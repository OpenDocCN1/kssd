# 函数定义：`move`

```c
void move(char * tem,int le,int f)//tem 为二进制字符串,le 移位总数,f 为移位量
{
  int i,j;
  int tem1[100];
  if(le==-1)
    le=0x5a;
  for(i=0;i<100;i++)
    tem1[i]=tem[i];
  for(i=0;i<(le-f);i++)
    tem[i]=tem[i+f];
  for(i=(le-f),j=0;i<le;i++,j++)
    tem[i]=tem1[j];
}
```
