
# 大学的生活

> 原文：[`www.pediy.com/kssd/pediy10/84137.html`](https://www.pediy.com/kssd/pediy10/84137.html)

说句很老实的话，对于编程，我完全是菜鸟，因为在我上大学之前，我上网做得最多的事情就是玩游戏。
所以如果要我给自己一个评价的话，我只能说，我什么都不知道。
但是我却是由衷的喜欢计算机，因为在我刚开始接触到它的时候我就觉得它好神奇，会像变魔术一般，变出许多我从来不曾见过的东西，如此的奇妙，如此的让人向往。
现在我刚刚上大学，像许多刚刚上大学的人一样，半年多了，就只学过 `C`，而且是基础，然后就是数学，语文，历史等等。大学的生活就是上学去放学会，不会在教室多停留半分，一般也不会问老师什么问题，试想连课都不想听，更何况问问题？
大家都忙，忙着回去挥霍，挥霍时间，挥霍金钱，挥霍父母的爱，挥霍父母的希望，挥霍自己的光阴，挥霍自己的梦想~~~~~~
时间就这样一分一秒的过去，甚至都不知道自己所要追求的是什么？一时的痛快，一是的享受，还是一时的放纵？难道生活就是要混过去，平平凡凡？不，我不要，我不要！我不要像他们一样，我喜欢平凡，但平凡只是不想让别人打扰我宁静的生活，可是我的梦不能平凡，活着就要向世界证明我曾经的存在，就算只是一个闪耀的瞬间，我也无怨无悔。
我不要钱，不要利，因为我从来都没有想过我会因为这些东西而烦恼，因为我相信我自己，我相信这些东西我完全可以凭着我自己的能力去得到，我要的只是得到大家的认同与发自内心的尊敬，就算不能让所有人都记得我，但是至少我要让你们记得，也让你们做个见证，我浮冰－Ｉｃｅ总有一天能够做到，因为我与他们不一样。
在他们忙着玩游戏的时候，我在学习；
在他们忙着出去玩的时候，我在学习；
在他们忙着谈恋爱的时候，我在学习；
在他们忙着聚餐的时候，我在学习；
在他们忙着想什么时侯下课的时候，我在学习；
在他们忙着想放学侯做什么事情的时侯，我在学习。
图书馆就是我的另一个家，知道每天没有课的时候，我在哪里吗？图书馆；
每天中午睡午觉的时候，我在哪里？图书馆；
每天晚自习下课侯，我在哪里？图书馆。
为什么？我是傻瓜吗？不，不是，至少我不这么认为。你们也许不知道，现在坐在计算机旁边，敲着键盘，深夜都没有入睡的人其实是一个菜鸟，也许在这个论坛里面没有人比我更菜，因为我连一个小小的扫雷游戏都编不出来。因为我的觉悟是在大一的后半学期，也就是刚开学的时候。忽然觉得感悟出了什么，想到了自己的梦想，自己的未来，忽然心就澄清了许多，再回头看看以前，沧海桑田，时间如白驹过隙，转瞬即逝。从屁颠屁颠的小男孩转眼间就成了快２０的男人了，却什么都不会，一事无成，连上个大学都浑浑噩噩。我就问自己，难道你还要这样继续下去吗？不，我不要，所以才有了上面的那几句话。在这里也想提醒看到这篇帖子的朋友，无论你是谁，无论你家境如何，都希望你能够好好的珍惜时光，只要现在努力，什么都不晚，至少不要给自己留下另一个遗憾，当然如果你是和我水平一样的人，那么我们就来比赛吧，看看谁能够做得更好。可是我有一个条件，就是你必须有良好的品格，因为我不喜欢连道德关都没有过的人，当然我可以像任何人保证我也绝不是这样的人！
其实知道看雪只是在一个偶然的机会，在别的论坛看到的，因为我对计算机很有兴趣，所以就经常看关于这方面的论坛，但是都没有我现在还记得的，记得的都要钱。看到里面的人动不动就提到看雪，我一直在想，看雪有这么好吗？于是我在看雪申请了一个账号，看了看也不知道看雪好在哪里，请大家不要鄙视我哈![](img/e71d9210a215d5b66755d038631e0c83.jpg "恐怖!")。当然，那个时候我还是一个跟其他人没什么两样，一天就知道玩，于是后来就没有再怎么进来过。然后又是一次偶然的机会我又来了，但第二次的我和第一次的我完全不一样，因为我是为了找一样东西`win32asm`，因为我在看一本关于病毒的书，里面要求要有 `win32`汇编的基础，还要懂 `API` 函数的调用机制，我只知道一片茫然，但是不懂就不能不学，所以我就在网上下饿一个关于 `win32`汇编的电子书，然后电子书里面又要求要有 `win32asm.exe`，我根本就不知道那是什么，但是刚开始的时候那不是正常的事情吗？所以我在百度上面搜这个东西，就看见有人给的网站，上面说在看雪上面几乎要用的工具都能够找到，我才想起我还有一个看雪的号，刚回来的时候我甚至都不知道我的账号，要不是我的邮箱，可能我又要重新申请了。
顺便打个广告，谁可以给我一个下载地址啊？我到看雪都没有找到![](img/9d43c9aee695f95b024aafd1b69ffa5a.jpg "伤心")，可能是我能力不够，不知道怎么找，哎！真对不起广大人名群众。
说句老实话，我觉得看雪和其他的论坛都不一样，看雪里面有许多博学的人，有许多无私的人，心胸坦荡，光明磊落，遇事虚心请教，不骄傲，不燥，也不会用学到的知识去搞破坏，更可贵的是大家都很爱护这个共同拥有的家，忽然间我感觉有种家的温馨，所以才有了这篇文章，我知道从我写这篇文章开始，我便与看雪解下了不解的情缘。
在看雪，我没有去其他板块，因为我的能力还不能够理解那些我看不懂的语句，所以我一般都是在这看看。我看见看雪的斑竹们会很认真的回答菜鸟们的问题，还会给出许多有哲理的话来激励大家，不会因为我们问的问题太菜而嘲笑我们，而看不起我们。我是真心的尊敬，我知道就是因为有这些兢兢业业的斑竹们才会有今天的看雪。
所以从今天开始，我也要为了成为以为像你们一样的人而奋斗，你们就是我现在的目标，我要做的就是赶上你们，然后超过你们。我对自己有信心，因为我就是我，浮冰！
