#### 1) 寻找程序执行流程

分析 `bin` 目录中的 `idea.bat` 文件，找出如下语句（用于执行软件）

```
"%JAVA_EXE%" %JVM_ARGS% -cp "%CLASS_PATH%" %IDEA_MAIN_CLASS_NAME% %*
```

其中 `JAVA_EXE` 指向 `java.exe`; `IDEA_MAIN_CLASS_NAME` 指向 `com.intellij.idea.Main`

因此要分析 `com.intellij.idea.Main` 类的执行过程（IDEA 采用了插件的方式，即使是 `Main` 类也是用插件管理的方式来运行）
