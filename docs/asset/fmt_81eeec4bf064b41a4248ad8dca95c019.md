### 函数实现

```c
void __fastcall getOneBlack(BYTE *black,char *black_string,int len=8)  
{  
        for (; len>0; len--)  
        {  
                sprintf(black_string, "%02x", *black++);  
                black_string += 2;          
        }  
}  

int __fastcall rar_strncmp(LPCSTR lpString1,LPCSTR lpString2,int cCount)  
{  
        return CompareString(LOCALE_USER_DEFAULT,  
                             NORM_IGNORECASE|SORT_STRINGSORT,  
                             lpString1,  
                             cCount,  
                             lpString2,  
                             cCount) - CSTR_EQUAL;  
}
```

### 逻辑说明

`getOneBlack` 函数很简单，在这里就是每次取 8 个字节，按 16 进制转化为字符串 `black_string`，然后又调用 `rar_strncmp` 对字符串进行比较，这里用到了 `strTemp+10`，看上一篇可知 `strTemp` 存储的是：
