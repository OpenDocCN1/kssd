
## 线程自定义的函数：sleep 函数 1000374D

### 函数功能
睡眠【8480】秒。

```
【【8488】】=（（byte）【8488】-1）^a5
```

**字符串处理说明：**

*   `8518`：取字符串的一字节 ASCII `"n,Administrator,Guest,admin,Root,"`，置 `2c` 为零。
*   `8540`：ASCII `"n,1234,password,6969,harley,123456,golf,pussy,mustang,1111,shadow,1313,fish,5150,7777,qwerty,baseball,2112,letmein,12345678,12345,ccc,admin,5201314,qq520,1,12,123,1234567,123456789,654321,54321,111,000000,abc,pw,11111111,88888888,pass,pa"..."`，置 `2c` 为零。
*   `87B0`：ASCII `"360hotfix.exe|360rpt.exe|360safe.exe|360safebox.exe|360tray.exe|agentsvr.exe|apvxdwin.exe|ast.exe|avcenter.exe|avengine.exe|avgnt.exe|avguard.exe|avltmain.exe|avp32.exe|avtask.exe|bdagent.exe|bdwizreg.exe|boxmod.exe|ccapp.exe|ccenter.exe"..."`，处理完字符串就跳转，把 `7c` 和 `2c` 清零。
