4. 通过 `OD` 动态调试该段代码，很容易知道，只要注册表中：`RegYesNo` 键值为 `blowjj` 即注册成功。所以 `blowjj` 是注册成功标志。

```
[HKEY_LOCAL_MACHINE\SOFTWARE\Kooborp]

"RegYesNo"="blowjj"
```
