# 算法总结

注册验证非常简单：

- 注册验证与用户名无关，所以可以任意填写，并不参与注册码计算！
- 注册码整个计算过程是在安装目录下 `PunUnitLib.dll` 文件内完成的！

1. 取机器码十六进制来反排序。
2. 用到的常数为 `C56D-Q638`。
3. 注册码的组合方式为：
   注册码=`"C56D"+"-"+取倒（HEX（机器码倒数 1、2 位））+"-Q638"+"-"+取倒（HEX（机器码倒数后 3、4 位））`
   即：`SN3 + SN1 + SN4 + SN2`
