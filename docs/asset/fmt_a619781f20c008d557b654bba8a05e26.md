### 4. 算法总结

以我机器为例，

---------------------------------------------
用户码： 240
机器码： 495353
----------------------------------------------
2………………ASCII 值 50
4………………ASCII 值 52
0………………ASCII 值 48
连接成字符串“505248”

机器码的 `0.83` 次方即 `495353 ^ 0.83 = 53306.39117961` （双精度数）
`53306.39117961 + 547961 = 601267.39117961`
取`"601267.39117961"`右边的六位得： “117961”

---------------------------------------------------------------

比较下面的两项是否相同

`[HKEY_CURRENT_USER\Software\VB and VBA Program Settings\wordbbj\setting]`

"regSN"键值是否等于"505248"
"validate"键值是否等于"117961"

都相同就注册成功！
