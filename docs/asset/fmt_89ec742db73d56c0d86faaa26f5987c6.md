### 算法 总结

其实分析完了也就知道这个程序并不复杂，虽然用了浮点运算，好像没多大作用？算法如下：

1. 取用户号，将前 3 位换到最后。如 `783009226` -> `009226783`
2. 依次取变化后的用户号的数字，求其立方值
3. 依次求循环次数的立方值
4. 两者依次相加
5. 相加之和 依次 与 `A` 求模！每次求模的结果就是注册码了！
