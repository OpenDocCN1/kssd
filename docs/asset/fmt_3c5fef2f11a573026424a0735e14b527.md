
# 魔法转换 2.0

> 原文：[`www.pediy.com/kssd/pediy08/pediy8-29.htm`](https://www.pediy.com/kssd/pediy08/pediy8-29.htm)

## 题目
图像转换工具“魔法转换 2.0”注册码分析

## 功能
功能强大的图像转换工具（吹牛？）。包括图像浏览、批量转换、图像增强及作品预览四大部分。图像增强包括调整图像大小、调整层次、旋转、镜象，还有锐化、模糊、马塞克、浮雕、底片、旋涡、喷雾等效果。你可以将这些效果自定义成方案，然后再进行批量转换。而且它还支持拖入文件到批量转换列表。同时它还能方便的将图像生成`.EXE`可执行文件。

## 工具
`softice`，`PEID`，`Casper`

## 引子
今天又实验了一下这个图片批量转换工具，实在不敢恭维，里面没有帮助，我转换图片不成功，只是对其注册码机制感兴趣，所以才有了这篇破文。

拿`PEID`检查一下，还是用`ASPack 2.000 -> Alexey Solodovnikov`加壳的。用`CASPER`可以脱壳，方便抓取代码写破文。
