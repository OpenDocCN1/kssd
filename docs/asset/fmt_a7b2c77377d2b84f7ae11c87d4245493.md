
# VFX&EXE 文件加密的克星

> 原文：[`www.pediy.com/kssd/pediy04/kanxue346.htm`](https://www.pediy.com/kssd/pediy04/kanxue346.htm)

VFX&EXE 文件加密的解密的方法

准备工具：`UNALLFOX2.1`、`PEditor 1.7`(看雪上有)

以 `PCFT202`：

1. 先安装，然后要运行的文件，输入密码(`PCFT`)，然后把 `PCFT` 最小化
2. 启动运行 `PEditor 1.7`，选 `TASKS`
3. 不退出 `PCFT` 程序，重新热启动计算机
4. 把以 `C:\\WINDOWS\\History\\` 拷贝出来

   (把 `C:\\WINDOWS\\History\\` 拷贝出来，改名，

   用 `attrib *.* -s -h`

   然后用资源管理中拷贝 `0\\Aejbgdb#.exe` 出来，改名

   去隐藏 `attrib *.exe -h`

   用 `UNFOXALL` 反编译）

把两个进程 kill 掉就行了 `4dd466d0e1e0cc123afbe504da2462ca`
