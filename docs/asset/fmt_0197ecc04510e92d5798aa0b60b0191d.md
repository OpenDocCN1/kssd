### 经验总结

算法如下:

1. 注册码必须是 `14` 位
2. 注册码的第一,三,四,五,八,九,十一分别是 `6`,`2`,`1`,`9`,`0`,`5`,`3`,其他数位任意
3. 注册码形如 `6X219XX05X3XXX`
4. 注册后写入注册表

```ini
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\DRMRSX]

```
