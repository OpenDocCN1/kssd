## 一级解密反 C 代码

分析后给出这一级解密的反 C 代码：

```c
int k=0;
for(i=0;i<DetSize;i++)
{
   if(buf[i]==0xFF)
   {
     k=i;
     i++;
     if(buf[i]!=0xff)
    {
         PreOffset=buf[i]>>2;
     PreOffset++;
     preNum=buf[i] & 0x80000003;
     if(preNum<0)
     {
         preNum--;
       preNum |=0xfffffffc;
       preNum++;
     }
     preNum+=3;
     if(preNum>0)
     {
           for(;preNum>0;preNum--)
       {
             nbuf[j]=nbuf[j-PreOffset];
       j++;
       }
       j--;
     }
     else  
     {
       j--;
     }
    }
    else
    {
        nbuf[j]=0xff;
    }
   }
   else
   {
     nbuf[j]=buf[i];
   }
j++;
}
```

紧接着发现这只是一级解密，数据还是不可直接读取。
