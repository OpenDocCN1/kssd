## 找到软件保存注册信息时的另一处验证

到此，我们找到了软件保存注册信息时的另一处验证，即做如下修改：

```

004F57DF    8B46 5C         MOV EAX,DWORD PTR DS:[ESI+5C]    // 修改为：MOV EAX,DWORD PTR SS:[EBP-4]
```

```
004F5A4A    8B55 F0         MOV EDX,DWORD PTR SS:[EBP+8]     //第二处也可以这样修改：MOV EDX,DWORD PTR SS:[EBP-10]
```
