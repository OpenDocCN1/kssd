# 算法总结

1. 用户名不能小于 `9`，否则重复用户名到大于等于 `9` 为止
2. 用变形后的用户名长度与循环次数做一系列运算，加上循环对应的用户名 `ASC` 值
3. 将累加值各个位上的数字相加，若相加的值大于 `9`，则继续将各个位上的数字相加，直到小于等于 `9`
4. 将所得的数字相连即为注册码
