
## 一、简单修改授权对话框

为了使弹出的“授权使用”对话框显示自定义名称，利用 `PEID` 打开程序，点击 `EP` 段后的 `>` 符号，任选一个区段右击，选择“搜索全 0 处”（类似 `cave`）：找到 `RVA` 为 `130025`、偏移为 `130025`、长度为 `0xFDB` 的全 0 区域。利用 `UltraEdit` 将 `130025` 处编辑为 `"授权使用 laowang!"`，随后利用 `Hiew` 修改代码：

```
0042AF85   .   8D4424 5C     LEA EAX,DWORD PTR SS:[ESP+5C]                       ; |
0042AF89   .   83E1 03       AND ECX,3                                             ; |
0042AF8C   .   50            PUSH EAX                                              ; |Text
```

修改为：

```
0042AF85   .   68 25005300   PUSH 复件_Eb.00530025                                ; |Text = "授权使用 laowang!"
0042AF8A   .   90            NOP                                                   ; |
0042AF8B   .   90            NOP                                                   ; |
0042AF8C   .   90            NOP                                                   ; |
```

如此即可弹出“授权 laowang”对话框。
