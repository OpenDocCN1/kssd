
a. 如果该字符串 `0...9` 之间，则转为相应的数值，  
b. 如果为字母，则减去 `0x41` 再加 `8`，也就是 `A,B,C,D,E,F,G,H` 分别转成了 `8,9,A,B,C,D,E,F`  
c. 如果为 `-`，则忽略，不处理  

2. `SN_R[n]=BYTE(R2*16+R1)` 组成一个字节  

为了保证 `SN` 变换只出现 `0...F` 之间的数值，`SN` 字符应只控制在 `0...9,C...H` 之间，其中 `C,D,E,F,G,H` 分别代表 `A...F`  

验证 `SN`：

**算法总结：**

1. 对 `"&fp--fftxar"` 进行 `SHA1` 转换，得到：`SHA2[20]`
2. `Name` 字符串进行变换，`str1="\*" + Name + "english."`，再转为小写。
3. 对 `str1` 进行 `SHA1` 转换，得到：`SHA1[20]`
4. `SHA3[n]=SHA3[n]=BYTE(SHA2[n]+SHA2[n*2]+SHA1[n*2])` (`n=0...10`)
5. `SHA3[n]` 再与上面变换的 `SN` 比效，相等，则注册成功。
