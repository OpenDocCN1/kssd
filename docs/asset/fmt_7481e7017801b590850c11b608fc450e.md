总结一下：

然后取假注册码的中间 4 位并转化为对应的整数，假设=`EDX`

在取机器码的最后 5 位并转化为对应的整数，假设=`EAX`

在取到常数 `7C74B`，假设=`ECX`

接下来进行下面的运算：//返回值为 `EAX`

```
for(;EDX>=1;EDX--)
   {EAX=EAX/ECX;}
   EAX=EAX/ECX;//因为前面的判断条件是等于 1
for(;EDX>=1;EDX--)//作者通过堆栈实现的。
{
  EAX=EAX%ECX;
  EAX=EAX\*(机器码);
  EAX=EAX%ECX;
}
```

```
if(EAX!=TEMP)
   回将 EBX 清零
else
   将 EBX 低位置 1
```
