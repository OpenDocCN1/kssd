
`004271BB` `333A` `XOR EDI, DWORD PTR DS:[EDX]`
`004271BD` `D7` `XLAT BYTE PTR DS:[EBX+AL]`
`004271BE` `DB9F 0995DBFB` `FISTP DWORD PTR DS:[EDI+FBDB9509]`

OEP 已经面目全非了，但不要紧，我们只需要正确的 `IAT`。

回到先前的 `OD`，来到 `IAT` 的其实位置，将前 3 个 `IAT` 的二进制复制下来。

在到第二个 `OD`，大开内存，搜索刚才的二进制代码，将全部正确的 `IAT` 二进制代码复制到先前的 `OD` 中。

此时就可以关掉第 2 个 `OD` 了。
