```
0043CF2F  |.  8B45 00       MOV EAX,DWORD PTR SS:[EBP]                ; *

```

## 功能

把 `EBPSTACK` 栈顶的 2 个 `dword` 数据相加，结果存储在 `[EBP+4]`，`EFLAGS` 标志存储在栈顶。

## 例

```
  0013F97C   8021D2F0  !
  0013F980   00000000  ....
VM_ADDdw_EBPSTACK
  0013F97C   00000286  ..
  0013F980   8021D2F0  !
```
