看这两句：

```asm
mov eax,[ebp+pBufOfReadFile]

push dword ptr [eax+0ch]
```

那个`push`的就是`(DWORD) pBufOfReadFile[0xC]`，然后调用`inet_ntoa`把IP地址转换成了点分十进制的字符形式，最后得到了URL：`http://63.247.135.48/r.php?t=0`。
