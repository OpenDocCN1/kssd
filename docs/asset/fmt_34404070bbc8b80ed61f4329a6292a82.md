
# NewsReactor 1.0 Build 5009

> 原文：[`www.pediy.com/kssd/pediy03/forum1209.htm`](https://www.pediy.com/kssd/pediy03/forum1209.htm)

`NewsReactor` 1.0 Build 5009 的注册机制分析

by Fpc\[CCG\]&6767\[BCG\] @2001/08

tools: `SI`, `wdasm`, `BcB` 5.0

Homepage: `http://www.daansystems.com`

Features: `NewsReactor` is a tool to download binaries from usenet newsgroups.

- `NewsReactor` scans, combines and downloads files from a selected newsgroup.
- This program is shareware. You can register `NewsReactor` to get the full version.

这个软件的注册很有意思，分析加调试用了两天，巨爽，不是说软件，而是这个过程。本来要写 `crackme`，现在不用了，嘿嘿。

1. 它的未注册版在启动时会有一个几秒钟的 Nag。单击按钮“Enter RegCode”，在打开的对话框中输入名字：`LazyUser` 和注册码：`123654`；
2. `^D` 切换到 `SoftIce`，下命令：`Bpx hMemcpy`，按下 `F5` 返回到 Windows；
3. 单击“OK”，被拦下，因为有两个输入框，所以要按一次 `F5`，还会被拦下；
4. 按 n 次 `F12` 到程序领空，你会到下面(用 `wdasm` 的反汇编结果来表示)：
