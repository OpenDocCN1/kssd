### 二、主程序 mbox2w.exe 的脱壳

`Ctrl+S` 搜索以下命令序列：

```asm
  mov eax,dword ptr ss:[ebp-10]
  add eax,dword ptr ds:[edx+8]
  mov dword ptr ss:[ebp-8],eax
```

找到在 `00432B36` 处，下断，`Shift+F9` 中断后取消断点
