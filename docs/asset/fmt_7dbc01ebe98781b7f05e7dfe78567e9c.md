## 算法总结

- 用户名长度乘固定值 `1122` (`462h`) + 用户名第一位的 ASCII 乘固定值 `77700` (`12F84h`)，结果作为注册码第一段；
- 用户名第一位的 ASCII 乘固定值 `511632` (`462h*1C8h=7CE90h`)，结果作为注册码第二段；
- 用户名第一位的 ASCII 乘用户名长度，再乘 `5678` (`1621h`)，结果加上 `1122` (`462h`) 作为注册码第三段；
- 用 `-` 连接上面三段即为注册码。注册码记录在同目录下的 `quickbudget.ini`。

### KG 源码 (VB Code)

```vb
'VB6.0 精简版测试通过.
Private Sub Command1_Click()
    Dim Name As String
    Dim L As Integer
    Dim a, b, c, d As Long
    Name = CStr(Text1.Text)
    L = Len(Name)
    If L = 0 Then
        Text2.Text = "Input your name,Please!"
    Else
        a = 1122 * L + Asc(Mid(Name, 1, 1)) * 77700
        b = Asc(Mid(Name, 1, 1)) * 511632
        c = Asc(Mid(Name, 1, 1)) * L
        d = c * 5678 + 1122
        Text2.Text = CStr(a) & "-" & CStr(b) & "-" & CStr(d)
    End If
End Sub
```
