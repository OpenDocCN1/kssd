
```
void swap(int c[10], int d[10])
{
  __asm
  {
    mov eax, c[0]
    xchg eax, d[0]
    mov c[0], eax
  }
  cout << c[0] << d[0];
}

void main()
{
  int a[10], b[10], bl1, bl2;
  a[0] = 10;
  b[0] = 20;
  swap(a, b);
}
```

这样是对的输出 20，10。但是假如把 `swap(a, b);` 改成 `add(a, b);` 那么只会跳出一个丑陋的对话框。因为 `swap(a, b)` 没有问题，所以原因不再其它而在 `add` 函数自己内部的 `__asm` 中。这就是传数组，这个很特别的特例。我们在 `add` 函数里操纵的是数组的地址。如果你要 `add` 那么用类法二的方法吧！

```
void add(int c[10], int d[10])
{
  __asm
  {
    mov eax, c[0]
    mov ebx, [eax]
    mov ecx, d[0]
    add ebx, [ecx]
    mov [eax], ebx
  }
  cout << c[0];
}
```

这样就不会有丑陋的对话框了。以后不要再把两个地址加起来了。在函数中处理传入的数组尤其小心！所以上面的 `swap(a, b)` 其实是很高级的交换 `c[0]`, `d[0]` 的地址。

```
__asm
{
  mov eax, 10
  mov a, eax
}
```

或者

```
_asm
{
  mov eax, 10
  mov [a], eax
}
```

所以我们可以知道，假如是这样：

```
void add(int c, int d)
{
  __asm
  {
    mov eax, c
    add eax, d
    mov c, eax
  }
  cout << c;
}
```
