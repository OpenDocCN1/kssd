## 破解过程

`PEiD0.93` 查壳，显示为 `Microsoft Visual Basic 5.0 / 6.0`，没有加壳。

运行主程序，输入用户名和注册码，注册，程序会单出重新启动校验的提示。

用 `OllyDbg` 加载主程序，根据 VB 程序的特点下断点：`bp rtcMsgBox`，`F9` 运行，断下，

按 `Ctrl+F9` 程序弹出提示对话框，确定，程序返回到 `0086D16B` 处：

