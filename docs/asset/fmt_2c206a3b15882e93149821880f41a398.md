## 算法总结

1. 注册码要有`-`
2. 去除`-`后还需要 `25` 位数字或字母
3. 取 C 盘序列号 `211C1E09 - 007B33CF=20A0EA3A`
4. `25` 位字符中要有 `8` 位是 `20A0EA3A`，其他任意
