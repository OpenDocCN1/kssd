总结一下关键 `CALL2`：

第一次：`[ESP+C]=[ESP]=0` `*0A=0+1=1`

第二次：`[esp+c]=[esp]=1` `*0a=0A+1=0B`

第三次：`[esp+c]=[esp]=b` `*0a=6E+2=70`

类似于：

```
sum = 0
sum = sum * 0A + 注册码(i)数值本身
i++
```
