```
//根据由 Name 计算出的 DWORD，初始化 Bit 数组
abyBits[0]=0;
for (i = 1;i < 9;i++)
{
    //无符号数右移 shr
    abyBits[i] = ((DWORD)iNameKey >> (i)) & 1;
}
abyBits[9]=1;
```
