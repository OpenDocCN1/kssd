### Patch 点分析

实际 Patch 发现 Patch 点选择有点意思，如果

```assembly
修改  
0041636A     74 09             je short NOTEPAD.00416375   //跳走还有一次机会,核心 Patch 点  
```

IAT 还是有不少加密了

```assembly
如果改这个就还剩一个加密指针  
0041637C     74 54             je short NOTEPAD.004163D2 //最后一次机会，不跳 Over  
```

我选择的方式 2 修改

这里下硬件执行断点

```assembly
0041637C     74 54             je short NOTEPAD.004163D2  
```

重启 OD,F9 运行

立即中断

```assembly
0041637C    /74 54             je short NOTEPAD.004163D2  
```

修改为

```assembly
0041637C    /EB 54             jmp short NOTEPAD.004163D2  
```

取消硬件断点,运行到程序运行。

获取输入表

```assembly
0  000064AC  ?  0000  004105CB  
```

只剩下一个指针加密，不应该这样的?????

也好

`hr 4064A8`

为什么不是

`Hr 4064AC`
