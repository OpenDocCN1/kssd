### 总结

**注册机制:**

由用户名算出一个注册码并与输入的注册码比较,并且这个真码出现在内存中,
用户名长度=注册码长度

**注册算法模拟:**

设用户名字符对应 ASCII 为 `a[i]`,相应字符串为 `b[i]`

`t1=a[i]%A;`

```
    if (t2!=0) b[i]=t1+31;
    else       b[i]=a[i]%1A+31;}
else b[i]=a[i]%1A+41;
```
