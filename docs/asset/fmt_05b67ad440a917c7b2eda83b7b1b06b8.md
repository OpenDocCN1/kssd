
## `Sub1_IntToString`

`void Sub1_IntToString(long Num, char *format)`

这个子函数是将一个 32 位的数转化成一个长为 8 的串。

与 `sprintf(format, "%08X", Num)` 的结果有区别：

1. `Num` 要取绝对值
2. 从最低位每 5 位转化成一个字符，若是每 4 位转化成一个字符，就与 `"%08X"` 一样。
   - `00000 - 01001` ==> `'0' - '9'`
   - `01010 - 11111` ==> `'A' - 'V'`

## `Sub1_StringToInt`

`long Sub1_StringToInt(char *str)`

与上面的 `Sub1_IntToString` 刚好相反。

程序中只有一处 CALL 这个子程序，结果还必须是有效的年、月、日的组合。

- `year`: `1 ~ 9999`
- `month`: `1 ~ 12`
- `day`: `1 ~ days[month-1]`

若是闰年：
`days[] = {31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}`

否则：
`days[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}`

## `Sub2_StringToInt`

```c
unsigned Sub2_StringToInt(char *data)
{
    int i,j;
    int len = strlen(data); // 16
    unsigned EAX, EBX;
    EBX = 0xFFFF;
    for (i=0; i<len; i++)
    {
        EAX = (unsigned)data[i];
        EBX ^= EAX;
        for(j=0; j<8; j++)
        {
            if ((EBX&1) == 0){
                EBX >>= 1;
            }
            else{
                EBX >>= 1;
                EBX ^= 0xA001;
            }
        }
    }
    return EBX;
}
```
