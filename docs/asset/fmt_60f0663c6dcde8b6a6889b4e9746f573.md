## （一）重定位

其实大家见的多了，简单的有两个写法

1.

```
Call aa
aa:
Pop ebp
Sub ebp,offset aa
[ebp+offset var]
```

2

```
Call bb
Base=$
Bb:
Pop ebp
[ebp+offset var-base]
```

第二种写法实际上比第一种要省一个字节。这些看自己的实际和爱好了。
