## 总结

程序是怎么运算出注册码的,我到现在都还没有搞懂!请大哥哥指点!

注册信息保存在注册表的 `HKEY_CLASSES_ROOT\Ddfd` 的字符串值 `test` 里面,`test` 的值大于 `100` 就表示注册版本,小于否之!

这个程序是把机器码乘以密匙 `123456` 的积和我输入的注册码比较的,也就是说注册码就是机器码乘以密匙 `123456` 的积!

我们假定注册码是 `X` 机器码是 `Y` 那么:(`X=Y*123456`)

## 注册表修改方法

就是搬出我个人认为最好用的工具---->`REGMON` `4.32` 中文版!

运行 `REGMON`,在运行 `FRun.Exe`,你会发现程序获取了注册表 `[HKEY_CLASSES_ROOT\Ddfd]` 的值,在那里面有两个字符串值 `test` 和 `test1`,其中 `test1` 是程序随机产生的机器码,`test` 是否注册的标志!(大于 `101` 的是注册版)那么你懂了吧,把它改一改就可以了!呵呵...

或者自己动手做一个注册文件!新建一个 本文文档 内容如下:

```
REGEDIT4

[HKEY_CLASSES_ROOT\Ddfd]

"test"="101"
```

再把本文文档的扩展名由 `txt` 改成 `reg`

双击运行这个 `reg` 文件就变成注册版本了!!简单吧!
