
# 加密代码实现

```
lenth = strlen( Unicode );  

for (i = 0; i < lenth; i++)  
{  
  Unicode[i] = Unicode[i] ^ 0XB ^ 3;  
}  
printf ("加密字串为:\n");  
puts( Unicode );  
getchar();  
```

# 字符串汉化说明

最后我们找到了一些加密字串，只要把对应的英文翻译为中文后再加密替换原来的英文加密字串就可以汉化了。翻译后字串少于原字串时要补 `00` 的话就直接填 16 进制的 `08`，要补空格就添左括号“(`(`)”：
