引用:

先看 a 情况吧，进去后一路 `F8`

```
    00C5B816        0255 DF       add dl,byte ptr ss:[ebp-21]
    00C5B819        8B4D FC       mov ecx,dword ptr ss:[ebp-4]          //这个点比较好
```
