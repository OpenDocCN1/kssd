我这次没有用内存镜像断点到 `OEP`,下面的这个方法可以发现 `Stolen Code`(如果有)+`Oep` 二合一。

仍然是命令行断点

```
tc ebp\==12fff0       //当前 EBP 内容为 12fff0 就被中断，略微看看就可以找到 Stolen Code(如果有)或 Oep
```
