## `GetOneChar` 部分

;依次传递参数 `Arg1`, `Arg2`, `Arg3`,而 `Arg4` 则是传入的 `CL` 的值,可以看上面的反汇编代码

```asm
GetOneChar proc Arg1, Arg2, Arg3, Arg4   

push ebx   

push ecx   

push edi   

xor eax, eax   

xor ebx, ebx   

xor ecx, ecx   

mov bl, byte ptr Arg4   

mov edi, offset KKeyName   

mov al, [edi+ebx-1]   

mov bl, byte ptr Arg3   

xor al, [edi+ebx-1]   

mov bl, byte ptr Arg2   

mov cl, [edi+ebx-1]   

rol al, cl   

mov bl, byte ptr Arg1   

xor al, [edi+ebx-1] ;al 作为出口参数   

pop edi   

pop ecx   

pop ebx   

ret   

GetOneChar endp
```
