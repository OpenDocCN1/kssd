
# POPMAN 时常管家 2003 版

> 原文：[`www.pediy.com/kssd/pediy06/pediy6370.htm`](https://www.pediy.com/kssd/pediy06/pediy6370.htm)

## 软件简介

此软件可用电脑帮你打点日常数据库。主要有名片盒、财产表、支出表、收入表、成长录、区邮码、营养表等功能。用它来进行家庭理财非常错。如果你经营有个小店面的话，用它来记录每天的财目是非常方便的。软件的设计十分人性化。

## 分析

可我要找的是注册算法，所以这不是我们要的。不过我们知道了出错的代码也行，我们记下 `411B60` 这个地址。然后用 `PEiD` 查看软件是否加壳，还好，没壳。再用 `W32Dasm8.93+` 反汇编。反汇编后我们 Goto Code Location 处输入 `411B60` 确定，我们来到下面的代码：

