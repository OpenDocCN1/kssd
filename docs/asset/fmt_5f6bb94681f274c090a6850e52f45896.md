## Flash Desktop 2003 v1.0 - 创建 Flash 动感桌面壁纸

- **软件版本**：v1.0
- **软件类型**：精品软件
- **运行环境**：`Win9x`/`WinME`/`Win2000`/`WinXP`
- **界面语言**：`English`

`Flash Desktop` 可以帮助你快速的用 `Flash` 动画创建动感的 `Windows` 桌面壁纸，程序界面友好，非常容易使用，支持直接把转换好的动态桌面制作为 `EXE` 格式的自解压文件来让你的朋友和你一起分享！你是否厌倦了静止的桌面，那么快来到 `Flash Desktop` 的世界，来体验漂亮生动的动态桌面世界吧！

这个软件是在天天论坛里看到的，发现软件的注册码好像是老外的不爽。就下了自己跟了跟。安装后运行程序，出现注册提示框，习惯的填用户名：`fxyang` 试验码：`789456123012`。注册出现 `"Your Registration information have been recorded. In order to validate the registration information, Flash Desktop need to be restarted."` 提示后就退出。是个重起效验型的。

脱壳，用 `0llydbg` 跟踪了好几次，就是没有发现用户名和试验码比较后进入注册提示框...改比较跳转后程序飞了。真 TMD 后来想想--注册码的计算可能是在填信息后进行的。于是用 `TRW2000` 跟踪，下 `bpx hmemcpy` 中断后来到如下：
