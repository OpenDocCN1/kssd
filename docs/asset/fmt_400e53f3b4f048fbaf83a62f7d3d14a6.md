
# C32Asm 外壳脱壳分析笔记

保护:外壳（pll621 写的非常象是 `ASPACK` 的变种）

所用工具:`OLLDBG` 1.09

脱壳难度:一般

脱壳分析:大老

所属组织:`=BCG=` `=[DCG]=`

00401000 PUSH C32Asm.0056D001 ===================〉压入外壳处理部分的入口！
