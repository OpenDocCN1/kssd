
3. 注册码的后一半的计算同第一部分的计算方法一样（用一个循环计算的），但是参数改变了：

   1. 首先取固定参数`'mp'`二位和第一次计算的字符串的前二位，进行同第一步一样的计算。
   2. 第二次取第一次计算的字符串的第二个俩位和上面计算的二位注册码进行相同的计算，

   直到第一次计算的字符串用完，得到的字符串就是注册码的后一半。

4. 把上面二次的字符串连接起来就是正确的注册码
