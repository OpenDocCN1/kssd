### 算法总结

1. 把用户名逐位取 ASCII 值进行累加结果为 `A`。
2. 把软件名 `iovsoft Blu-ray Copy` 也进行逐位取值累加结果为 `B`。
3. 在让 `A`, `B` 进行下面的运算：(`A` * `B` + `0x20`) * `B` = `C`。
4. 把 `A` 和 `B` 运算的结果 `C` 与我们输入的注册码转化为 16 进制数比较。相同就注册成功。
