【破解内容】

`PEiD`检查，程序的编程语言是 `Microsoft Visual C++ 7.0`，无壳。

`od` 载入，软件开始，到注册处，填入 `1234abcd`。设断 `MessageBoxA`，按确定按钮，停下后按 `Ctrl+F9` 往上返，返到 `4070EB`，向上拉判断应是确定按钮的处理函数，开始分析。

这个软件是明码比较，做内存注册机很简单，我在这里使用修改代码使程序自己显示注册码的方法，当作练习。
