## 算法说明

首先要求注册名长度不小于八位，并且用 `Ucase` 来转为大写字符串。

逐位取注册名的 `asc` 值 + 所在位数 * 6 - 15 = A。

判断 A 是否在 7bit 的 asc 字符范围内，如果 A 小于 33 则加上 101，大于 126 就跳出，结束。

用 `chr` 函数将 A 转换为字符，并且连接起来构成注册码。

## 参考代码

```vb
Option Explicit

Private Sub Command1_Click()
    Dim i As Integer, j As Integer, k As Integer, key As String
    
    For i = 1 To Len(Text1.Text)
        j = Asc(UCase(Mid(Text1.Text, i, 1)))
        k = 6 * i
        j = j + k
        j = j - 15
        
        If (j < 33) Then
            j = j + 101
        End If
        
        If (j > 126) Then
            ' Do nothing or exit, original logic had empty if
        End If
        
        key = key & Chr(j)
    Next i
    
    Text2.Text = key
End Sub
```
