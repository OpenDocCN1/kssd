# 用户名处理逻辑

`CODE:007B267B`

1. 如果用户名长度等于 `17H`，则将用户名转为大写。
2. 如果用户名长度大于 `17H`，则通过一定规则截取用户名，组合成 `17H` 长度，并将所有字母转为大写。
3. 如果用户名长度不足 `17H`，则通过一个补码表将用户名补足至 `17H` 长度，并将所有字母转为大写。

转换后的用户名存入 `user1`。

# 计算索引与中间用户名

`CODE:007B267B`

以 `user2` 中 5 个字符为一组，计算索引 `AIndex`，并从 `buf[AIndex]` 选出字母，组成新的中间用户名 `user3`：

```pascal
while i <= Length(user2) do
begin
  s := copy(user2, i, 5);
  w := StrToInt(s);
  s1 := '';
  if w > 0 then
  repeat
    a := w div $25;
    AIndex := w mod $25;
    s1 := buf[AIndex+1] + s1;
    w := a;
  until a = 0;
  user3 := user3 + s1;
  i := i + 5;
end;
```

# 生成最终编码用户名

`CODE:007B267B`

从 `user3` 中，通过一定的运算，组合出最终编码后的用户名，新用户名长度为 `0CH`：

```pascal
userLen := Length(user3);
result := '';
for i := 1 to $c do
begin
  AIndex := i * userLen div $C;
  result := result + UpperCase(user3[AIndex]);
end;
```
