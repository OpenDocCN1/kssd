
# Oicq 99c Build 0820

> 原文：[`www.pediy.com/kssd/pediy03/forum375.htm`](https://www.pediy.com/kssd/pediy03/forum375.htm)

这是目前(2000.10.12)最新的 Oicq，本以为加密会很好，可破起来只用了十几分钟。不禁为腾讯公司感到悲哀。

在 `Oicq\dat` 下有 `Oicq2000.cfg` 文件，偏移 `0009` 为号码个数，后面有 `08000000` 隔开每个号码，保证你的 Oicq 号码的目录在 `Oicq\` 下，将 `Oicq2000.cfg` 中的号码改为你想要破的号。然后启动 Oicq，在列表中选择你要破的号码，密码任意。在 `trw2000` 中下 `bpx hmemcpy`，`F5` 切换到 Oicq，点确定，被拦下，经过 `N` 行，到 `449234` 显示出密码错误的对话框，向上看：

```
:449210 cmp eax,ebx
:449212 jnz near 449446;此处可跳过
```

在 `49210` 下断点，再运行一次，光标停在 `cmp eax, ebx`，此时 `eax=0`, `ebx=0`，修改 `eax` 为 `1`，跳到 `449446`，按 `F5` 运行，竟成功了，连我都不敢相信，检查一下聊天纪录、个人信息，全对！又试了几个，都没问题。不禁有些愕然，如果直接跳到 `449446` 不就不用密码了吗？将 `449212` 改为 `jmp 449446`，果然可以，不过程序开始时会提示程序被修改，过几次后 Oicq 会自动恢复，已很累不想继续追了，但应可以找到 CRC 比对处的。

我没对此前的版本测试过，相信应更容易。

以前用过一个 Oicq 密码终结者，用穷举法破译密码，遇到 `8` 位 `9` 位的密码不知要多少时候，没多大意义。破它的注册码倒有些意思。

特别提醒大家在公用机房上过机后，将 Oicq 下和你的号码一样的目录彻底删除，否则很容易被别人偷看聊天纪录，修改密码、个人信息，后果不堪设想。
