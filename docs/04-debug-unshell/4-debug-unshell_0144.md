## 一、stolen code 分析

使用 `ollydbg`，除 `int3` 异常外全部忽略。硬件断点设置仍然按原来不变，即在入口 `ESP-4=12FFC0` 处。`F9` 运行。出现第一次 `int3` 异常后，不是按 `shift-f9` 而是 `F9`，这是该程序的特例。
