
# PE 文件分析器

> 原文：[`www.pediy.com/kssd/pediy12/98602.html`](https://www.pediy.com/kssd/pediy12/98602.html)

来论坛也有段时间了，看了一些帖子，感觉对 `PE` 文件的了解是很基础的知识。

所以找来了一些书和帖子进行研究，但仅仅是看，印象不够深刻，过了没多久就忘了，下次碰到，还是一筹莫展。所以想编写一个软件来实现对 `PE` 文件的分析，供学习和参考之用。同时也让我对 `PE` 文件的结构有进一步的认识。

现把程序共享出来，供大家参考，并指出错误的地方，共同进步。

1. 有些 `PE` 文件中的一些字段有问题，如（有 `.exe` 文件的导出表目录中数据有问题），分析时会出错，这时需要将导出表目录取消，不进行分析。
2. 软件中只分析了少量目录，望大家理解。
3. 软件暂时只是一个查看 `PE` 结构的软件，还不提供对 `PE` 文件的修改。该部分功能希望我以后有能力实现。
4. 希望大牛不要对批评太严格了，还是鼓励为主。
