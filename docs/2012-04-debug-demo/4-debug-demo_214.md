
# 星空屏保

`http://www.pchome.net/dld/download.php?url=scrn/sky.scr`

我个人是很喜欢这个星空屏保的，有动听的音乐和美伦美寰的图片，不过未注册版会时不时在图片上显示“未注册“，”请注册“的字样，真是大煞情趣，我用`winhex`看了一下，找到`"unregister!"` `"please register!"`的字样，在 16 进制区用`00`字节替换完就好了，用了这么久也没问题，还好作者没加时间限制。

真是瞎猫碰到死老鼠了。 `4dd466d0e1e0cc123afbe504da2462ca`
