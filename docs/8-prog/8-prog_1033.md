

# 研究业余工具，粗糙点，将就吧~~~

> 原文：[`www.pediy.com/kssd/pediy12/142623.html`](https://www.pediy.com/kssd/pediy12/142623.html)

1.原理是利用 hOOk\_JournalRecord ，因为感觉只是去 尝试看一下，是否做了保护，所以没必要  
搞得很复杂。  
2.使用方法，先-- 设置周期  --点勾一下 --（若记录过多可以清除）  
若想在运行中 重新设定周期，可以 先撤勾，再来进行前面 周期设定 -- 勾一下 步骤  
3.这里只是 对 0--9 之间 输入的数字 测试 ，如果 放在 做了保护的输入框中，光标放入，不点击鼠标，也会 输出数字，说明 是做了保护的，如果点数字，就出来自己的数字说明就是没做保护的
