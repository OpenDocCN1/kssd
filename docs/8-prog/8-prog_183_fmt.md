
# 发一个脚本解释器，无聊的时候写的

> 原文：[`www.pediy.com/kssd/pediy10/94064.html`](https://www.pediy.com/kssd/pediy10/94064.html)

其实这个脚本解释器，是以前写的了，现在发上来吧，让大家找找 `bug` 也是好的吧

他的语言类似汇编语言，所以学过汇编语言就很容易懂的啦

首先要用记事本之类的文本编辑器编写 `sZ` 脚本，写完后保存为 `.sZ` 后缀的文件，然后打开 `sZ.exe` 再选择刚才的文件就可以执行了，压缩包里有几个例子，大家可以参考哈

**声明：请不要用于商业用途！**
