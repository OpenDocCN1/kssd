

# 扩展《Windows 编程循序渐进》中文件分割器

> 原文：[`www.pediy.com/kssd/pediy11/106024.html`](https://www.pediy.com/kssd/pediy11/106024.html)

写在前面的话：  
来看雪的第一帖  
前段时间在网上看见了《Windows 编程循序渐进》，刚刚学习 Windows 编程的我，被这本书诱人的名字所吸引，于是毫不迟疑的从当当买了一本回来。  
刚开始看这本书的时候，我觉得有些失望，因为《Windows 编程循序渐进》，很精练，言简意赅，作为菜鸟的我不知道步骤与步骤之间是怎么去实现的（大侠们别笑，这是真的），后来，通过我一遍又一遍的看，不断的在 VS2008 中尝试，总算能将目前所学过的各个示例都做了下来。这时候我突然发现，在不断的尝试中，我学会了很多东西，我猜，北极星 2003 略去那些简单的东西就是为了让像我一样的菜鸟在不断尝试中获得更快的进步，谢谢你（发自肺腑的），北极星 2003。  
  
我现在学习到了第十三章内存管理，书中的示例有一个文件分割器，可是我发现当要分割的文件大于 4G 时，就不行了，于是我就想扩充一下，有了这个想法之后，我从今天下午 2 点多搞到现在，总算是功能实现了。本来我想，我的代码很丑，就不要来这里献丑了，可我朋友却说，你代码很丑，所以更需要别人给你纠正啊。于是就有了这篇帖子。  
  
这个文件分割器分割/合并大文件的时候有些卡，可能是我把分割函数和合并函数创建在了 Dlg 类中的原因。明天我再改一下。  
  
源码我放在附件中了，编译环境 XP+VS2008 ，欢迎和我一样的菜鸟和我交流，也欢迎各路高手不吝赐教。  
  
再次感谢【北极星 2003】，你真的让我学到了很多东西，不光是代码，还有写程序的思考方式。
