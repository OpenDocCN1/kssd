
# 文件(文件夹)加密解密工具

> 原文：[`www.pediy.com/kssd/pediy12/136480.html`](https://www.pediy.com/kssd/pediy12/136480.html)

前阵子研究了一下国内的一些主流的文件(文件夹)加密解密软件，主要研究的还是宏杰加密，根据自己的琢磨加实践，也用类似的原理实现了一个，虽说没什么高的技术含量，但是路途也蛮辛苦的，因为基本都是晚上写的。

软件主要实现的功能：

1. 文件(夹)加密解密
2. 文件夹伪装保护解除伪装
3. 右键关联加密解密到系统菜单
4. 开机最小化启动到托盘(气球提示)
5. 支持文件(文件夹)拖动
6. 支持 `WIN2000`，`XP`，`VISTA`，`WIN7`
