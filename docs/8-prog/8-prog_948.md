

# ”彩屏“

> 原文：[`www.pediy.com/kssd/pediy10/60890.html`](https://www.pediy.com/kssd/pediy10/60890.html)

在网上发现一个很不错的程序，是 com 格式的，可惜没有源代码。于是我把它反编译后，看了一下后写出了下面的程序出来。在 MASM5 下编译链接运行后，你可以看到一片灿烂的烟花，非常好看，希望朋友们喜欢.  
code segment  
      assume cs:code  
      org 100h  
start:  
      mov al,13h  
      int 10h  
      les bp,\[bx\]  
s:  
      stosb  
      adc ax,di  
      db 64h  
      adc ax,\[046ch\]  
      jmp s  
code ends  
end start  
  
  
  
另外一种方法可以看到这种效果的是：把以下数据保存为 cai.bat,即批处理脚本存在好之后，直接双击运行就可以看到效果了。  
debug<cai.bat  
e100 b0 13 cd 10 c4 2f aa 11 f8 64 13 6 6c 4 eb f6
