

# PnigoSpy\[任意进程 API 监控工具\]

> 原文：[`www.pediy.com/kssd/pediy12/142250.html`](https://www.pediy.com/kssd/pediy12/142250.html)

希望能求个邀请码 Thx,自己写的小 Demo,发了源码,共同学习,Any comment is welcomed.  
PnigoSpy:  
开发环境：Win7 x64 VS2010 Detours3.0  
本程序可以对正在运行的任意进程的 API 调用进行监控，并在当前目录生成日志文件便于查看。  
执行程序查看帮助：  
![`img1.51cto.com/attachment/201111/152151741.jpg`](img/04794e72953deecf630c4f21708e48cf.jpg)  
\-l 列出当前运行的进程信息。  
\-p 指定要监控的进程 PID。  
\-o 在程序退出后结束程序。  
\-q 采用安静模式,不将监控信息显示到 cmd 中。  
\-h 查看帮助。  
![`img1.51cto.com/attachment/201111/152701322.png`](img/ef11fa60c0df378f24caf6e60dd1d8f6.jpg)  
查找到 calc.exe 的 PID:5768  
![`img1.51cto.com/attachment/201111/153824389.png`](img/9596cacd10af768b712ff745b0678033.jpg)  
下面我们开始进行监控：  
PnigSpy.exe -p 5768 /q /o log.txt
