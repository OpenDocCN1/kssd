

# 发个代码...嗯很垃圾的代码，初学的可以看下

> 原文：[`www.pediy.com/kssd/pediy11/126033.html`](https://www.pediy.com/kssd/pediy11/126033.html)

以前发过一篇 360 Hook 基本架构的代码，总有人找我要全部的....，好吧我发下源工程驱动部分，和用户层交互的 dll 部分的代码。需要的自己下了看。  
  
  
不过还是要说下，代码这东西可以抄，但是抄多了伤身体的.................  
  
代码质量不高，是初学的时候看大牛们的代码模仿做得。  
  
整个程序基本功能是，基本的 ARK 部分，和基本的监控过滤部分。  
  
监控过滤部分很搓........拦截规则纯属虚构，如有雷同........  
  
不过整个代码也花了我好几个月，看在辛苦的份上，凡是下代码的，回帖顶下，呵呵！  
  
用户层界面就不发了，没意义，也很丑..........  
  
整个代码部分要说明一下几点  
监控部分，的多线程安全做得不好，多线程同步上效率不是很高  
自我保护部分很挫，呵呵最好别看  
ARK 部分...没新意，适合初学者看看，就当资料包吧
