
# 网络版 U 盘小偷

> 原文：[`www.pediy.com/kssd/pediy12/144210.html`](https://www.pediy.com/kssd/pediy12/144210.html)

上个月照着书敲了些代码，自己改动了下，写成了篇 `u 盘小偷` 的帖子，结果成了正式会员，哇咔咔，那滋味真叫幸福啊![](img/f3773294bf3a914c9a8c0c242528a003.jpg "使眼色")。下面是单机版的 `U 盘小偷` 链接：[`bbs.pediy.com/showthread.php?t=142952`](http://bbs.pediy.com/showthread.php?t=142952)

本来打算尽快写出网络版的出来的，无奈这个月 `LZ` 有时堕落有时发呆，没几天干正事的，所以一直拖到现在才写成一个网络版的雏形，就发出来吧~~

关于这个网络版的 `U 盘小偷`，需要的就是结合单机的 `U 盘小偷` 和 `socket` 编程，`socket` 编程当初楼主上课有讲过，无奈楼主当初就以酱油男，想想都后悔啊！只好又再学一遍了。

楼主技术有限，代码里面有很多不足，关于文件传输的协议的设计楼主基本就是用 `sleep()` 解决的，客户端一股脑的发过来，接收端一股脑的接收。这个协议真是巨挫无比，楼主汗颜中。。。![](img/8665dab461df9ff5e20e52adf9adf6de.jpg "伤心") 所以窃取的文件可能会根据网络出现一些小问题，像漏掉了一截什么的，或者把几个文件写到了一个文件里面。。。楼主也知道，只是太懒了，不想再去设计什么协议的了。。。有兴趣的童鞋们可以在我的这个基础上做修改，不用担心版权问题。。。只不过改过之后能够和楼主交流交流想法楼主就很高兴了，很渴望能够和大家一起交流，一起进步。。
