

# 分享】发一个 WN7 下获得 TrustedInstaller 权限完全控制的补丁

> 原文：[`www.pediy.com/kssd/pediy11/107017.html`](https://www.pediy.com/kssd/pediy11/107017.html)

我最近使用 win7，发现及时拥有 administrator 的密码也不能完全控制电脑，  
什么世道啊，还有一个 trustedinstaller 比 administrator 都还要高，  
网上找了个补丁，说是能获得全部权限，只因为下载这个补丁我费了很多周折  
所以发出来，希望大家以后再使用这个方法的时候可以节省时间：  
  
  

代码:

```
导入.reg
Windows Registry Editor Version 5.00

\[HKEY\_CLASSES\_ROOT\\\*\\shell\\runas\]
@="获取权限"
"NoWorkingDirectory"=""

\[HKEY\_CLASSES\_ROOT\\\*\\shell\\runas\\command\]
@="cmd.exe /c takeown /f \\"%1\\" && icacls \\"%1\\" /grant administrators:F"
"IsolatedCommand"="cmd.exe /c takeown /f \\"%1\\" && icacls \\"%1\\" /grant administrators:F"

\[HKEY\_CLASSES\_ROOT\\Directory\\shell\\runas\]
@="获取权限"
"NoWorkingDirectory"=""

\[HKEY\_CLASSES\_ROOT\\Directory\\shell\\runas\\command\]
@="cmd.exe /c takeown /f \\"%1\\" /r /d y && icacls \\"%1\\" /grant administrators:F /t"
"IsolatedCommand"="cmd.exe /c takeown /f \\"%1\\" /r /d y && icacls \\"%1\\" /grant administrators:F /t"

```
