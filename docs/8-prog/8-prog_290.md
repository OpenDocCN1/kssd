SendMessage()函数发送的消息并不进入消息对列等待 GetMessage()函数取出，而是直接传给窗口函数。  
示例：  
LRESULT CALLBACK MouseProc(  
  int nCode,      // hook code  
  WPARAM wParam,  // message identifier  
  LPARAM lParam   // mouse coordinates  
)  
{  
  return 1;       //钩子函数返回非零值，系统不再把消息送到相应应用程序  
}

要让钩子过程与所有线程相关，必须把 SetWindowsHookEx 第四个参数设为 0，第三个为钩子函数所在 DLL。  
  
安装关联到所有线程的钩子，将挂钩函数写入 DLL 中，   
记得声明它为导出函数，在.def 文件中.

void SetHook(HWND hwnd)  
{    
  g\_hWnd=hwnd;  
  g\_hKeyboard=::SetWindowsHookEx(WH\_KEYBOARD,KeyboardProc,GetModuleHandle("HOOk"),0);  
  g\_hMouse=::SetWindowsHookEx(WH\_MOUSE,MouseProc,::GetModuleHandle("HOOK"),0);  
  //::SetWindowsHookEx(WH\_MOUSE,MouseProc,g\_hInst,0);  
}
