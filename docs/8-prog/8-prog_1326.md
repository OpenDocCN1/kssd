

# 发个使用 Native API 的编程示例代码：LzOpenProcess 杀冰刃

看到某些有需要的同学还不会使用 ntdllsdk 方便地进行 Native API 编程，因此发出来~  
这是个使用 Native API 编程的完整代码，希望对新手同学能有点帮助，里面的 ntdll sdk 也可以方便地直接拿来使用~~
