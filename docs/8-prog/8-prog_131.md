

# 一些乱七八糟的代码

> 原文：[`www.pediy.com/kssd/pediy12/142281.html`](https://www.pediy.com/kssd/pediy12/142281.html)

编译平台：Pelles C 6.50，这是一个支持 Win32SDK 的 C 语言编译工具，支持控制台，支持 WinMain，支持 C 语言，支持内联汇编，独立汇编，等，学习的好工具。  
给还没学习过的同学学习吧，不知道自己写了些什么乱七八糟的代码。![](img/d23858dd221cce728a3a61b46badb044.jpg "恐怖!")  
注意：发现有密码的就是压缩文件名字，里面还有些压缩包可能有 lpk.dll，下载了的同学自己注意下。
