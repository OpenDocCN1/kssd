

# NDISWDM 学习笔记

> 原文：[`www.pediy.com/kssd/pediy12/143685.html`](https://www.pediy.com/kssd/pediy12/143685.html)

最近在阅读 NDIS 驱动，感觉有点难度，随手笔记。  
NDISWDM 是微软 ddk 中提供的示例，这里基于 ndis 5.0 例子进行的笔记。该驱动属于 miniport 驱动，并与 NDISPROT 驱动进行通信。NDISPROT 是 ddk 中的协议驱动。两个驱动看下来，感觉 NDIS 的驱动确实有点麻烦，一方面与其他驱动结构上差别比较大，包括 api 方面，另一方面要时刻注意硬件的状态。下面是初步的笔记。如果你想快速阅读，可以直接略过第一部分 Adapter 的状态，个人觉得第二部分 IRP 的 Cancel 和第三部分对象的生命周期还是有点样子的。该笔记中并未介绍 NDIS 驱动的结构，假设了你已经了解 NDIS 驱动的基本知识。并请在阅读的之前，能先通读一下 NDISWDM 的代码。保持代码随手可翻的状态。  
下面开始吧。
