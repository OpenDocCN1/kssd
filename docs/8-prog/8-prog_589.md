

# 多桌面切换程序-通杀所有网管程序

> 原文：[`www.pediy.com/kssd/pediy09/pediy09-666.htm`](https://www.pediy.com/kssd/pediy09/pediy09-666.htm)

> 程序说明：  
>    程序启动后没用任何界面，只会再创建一个桌面，用 WIN+1 和 WIN+2 组合键在两个桌面间切换。一个桌面用于工作，一个桌面用于娱乐，互不干扰。
