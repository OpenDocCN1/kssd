ndiswrapper 简介：  
一些 usb 无线网卡厂商只提供 windows 下的驱动，那么你可以直接使用 ndiswrapper 来执行 windows 上的网卡驱动，是不是很 cool 呢？其实也算是 linux 不如 windows 流行的一个证据。

定位到 pe 的导入函数表，然后依次通过 get\_export 函数查询函数的地址，然后修改地址表。  
  
static int get\_export(char \*name, generic\_func \*func)  
{  
  int i, j;  
  
  struct wrap\_export \*exports\[\] = {  
    ntoskernel\_exports,  
    ntoskernel\_io\_exports,  
    ndis\_exports,  
    crt\_exports,  
    hal\_exports,  
    rtl\_exports,  
#ifdef ENABLE\_USB  
    usb\_exports,  
#endif  
  };  
  
  for (j = 0; j < ARRAY\_SIZE(exports); j++)  
    for (i = 0; exports\[j\]\[i\].name != NULL; i++)  
      if (strcmp(exports\[j\]\[i\].name, name) == 0) {  
        \*func = exports\[j\]\[i\].func;  
        return 0;  
      }  
  
  for (i = 0; i < num\_pe\_exports; i++)  
    if (strcmp(pe\_exports\[i\].name, name) == 0) {  
      \*func = pe\_exports\[i\].addr;  
      return 0;  
    }  
  
  return -1;  
}  
这个函数依次检查所有的导出函数表，以及 pe\_exports【sys pe 镜像导出函数表】返回函数地址。
