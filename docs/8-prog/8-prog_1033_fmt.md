
# 研究业余工具，粗糙点，将就吧~~~

> 原文：[`www.pediy.com/kssd/pediy12/142623.html`](https://www.pediy.com/kssd/pediy12/142623.html)

1. 原理是利用`hOOk_JournalRecord`，因为感觉只是去尝试看一下，是否做了保护，所以没必要搞得很复杂。

2. 使用方法，先`--`设置周期`--`点勾一下`--`（若记录过多可以清除）。若想在运行中重新设定周期，可以先撤勾，再来进行前面周期设定`--`勾一下步骤。

3. 这里只是对`0--9`之间输入的数字测试，如果放在做了保护的输入框中，光标放入，不点击鼠标，也会输出数字，说明是做了保护的；如果点数字，就出来自己的数字，说明就是没做保护的。
