

# GS 检测初探

> 原文：[`www.pediy.com/kssd/pediy12/144189.html`](https://www.pediy.com/kssd/pediy12/144189.html)

简单说说 GS：GS 引入的背景，由于缓冲区的溢出导致任意代码的执行从而导致严重的安全问题。GS 引入就是为了辅助开发者对缓冲区进行安全检查，从而在一定程序上避免缓冲区溢出而导致的安全问题。
