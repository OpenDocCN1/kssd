判断 PsImageNotifyEnabled  
PAGEDATA:005B7B38 \_PsImageNotifyEnabled db 0     
      if ( PsImageNotifyEnabled )  
      {  
            PsCallImageNotifyRoutines(v49, v38, &v56);  
      }  
PsCallImageNotifyRoutines 将会依次执行 PspLoadImageNotifyRoutine 指向的  
notifyroutine  
  
清除方法  
1: 将 PsImageNotifyEnabled=0  
优点,比较方便,但是 PsImageNotifyEnabled 是非导出变量  
只能通过 MiMapViewOfImageSection 或者 DbgkCreateThread 定位  
但是上面 2 个函数仍然是非导出函数,如果做安全工具的话可以使用 PDB 解析大法  
不然的话嘛...  
  
2:PsRemoveLoadImageNotifyRoutine  
标准卸载函数,但是仍然存在缺点,需要知道 notifyroutine 函数地址,  
以及存在 2000 系统不能解析 PsRemoveLoadImageNotifyRoutine 的问题
