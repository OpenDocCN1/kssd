
# 【翻译】KmdTutCn

> 原文：[`www.pediy.com/kssd/pediy10/79537.html`](https://www.pediy.com/kssd/pediy10/79537.html)

最近学习驱动，由于本人比较笨，看了罗云彬翻译的 KmdTurCn，还不大明白。又小翻了一下《Windows 驱动开发》，全是 VC 操作，虽然 C 咱看得懂，但 BC 与 VC 区别还是挺大的。有点晕。先放放以后再说。不过注意了一个罗云彬在最后说，原版的俄文后面还有几章没有翻译，哦，于是去看了看。后面四章没有翻译，也不知道是什么。突然脑子里冒出一个想法：既然 KmdTurCn 还没看多大明白，不如把 KmdTur 俄文的都给翻了吧？顺便再细学一遍嘛。这个想法让我自己吓一跳，但是还是尝试这么做了。不过这不知不觉中，竟然还真把它翻了一遍。历时 20 天。虽然翻译得很糙，但必竟是自己干的活。。。

放出来共享大家学习，翻译有不足之处大家见谅并指点，特别是后面四章，已经没有罗云彬大哥翻译作参考了，只能靠自己瞎猜。。。

这里是完整的中文翻译，一共 11 章。

PS：名字是这样，可不要误认为我把罗云彬大哥的翻译版本拿过来发的啊~~~~
