中秋的时候看了关于内核对象的内容, 为了加深理解, 就想试下文件的强制删除,只要把文件对象的引用计数改为 0 就可以了嘛... 不过郁闷的是根本就找不到那个文件对象![](img/9b2aec7f3d4bb041b2d419a59832192f.jpg "恐怖!"), 那个啊,然后就去网上找资料,怎么才能实现文件的强制删除呢?MJ 说有两种方法

       if (pwsz!=NULL)
     {
        pwsz++;
     }
//比较文件名是否相同,如果是,则删除
         if (strcmp(outBuf.Buffer, pwsz) == 0)
