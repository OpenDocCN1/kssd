

# 透露一个 SendMessage 的牛 X 参数

> 原文：[`www.pediy.com/kssd/pediy11/118391.html`](https://www.pediy.com/kssd/pediy11/118391.html)

SendMessage(hwnd,0x00F5,0,0);   
  
假如 hwnd 是一个按钮的句柄.当执行这行程序时,这个按钮的事情将被激活.  
  
在做一些国产游戏外挂的时候,用它做某些功能会比找 CALL 容易的多.  
  
比如在"兽血沸腾"这款游戏中, 获得"杂货店"界面的"修理"按钮的 hwnd.  
然后走到野外,运行上面的程序,你会发现你的鼠标变成了锤子,然后在自己的装备上点一下,看看"持久"是不是加满了.  呵呵,这样无论在哪里都可以原地修装备了.
