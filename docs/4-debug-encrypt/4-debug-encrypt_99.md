

# RSA 相关数学基础与算法简析

> 原文：[`www.pediy.com/kssd/pediy12/142510.html`](https://www.pediy.com/kssd/pediy12/142510.html)

本人做的一个 ppt，参考了网上和几本教材，对 RSA 的相关数学基础做了总结，并有简单的证明，最后对 RSA 算法做了简析。包含的算法主要大纲如下：  
  
  模加；  
  模乘；  
  扩展的辗转相除法（欧几里德（ Euclidean ）算法 ）；  
  求逆；  
  中国剩余定理；  
  素性测试算法。   
希望能帮助大家理解和实现 RSA，对 RSA 算法的实现，下次发帖的时候奉上。  
由于 ppt 中包含了很多公式和图片，就做成了 pdf，放在附件里供大家下载。
