

# 魔装网神 V3.5 

> 原文：[`www.pediy.com/kssd/pediy05/pediy50037.htm`](https://www.pediy.com/kssd/pediy05/pediy50037.htm)

用 SmartCheck 破解魔装网神(NetMyth) V3.5   
  
作者：softs   
  
软件介绍：    
    魔装网神是一个浏览器，主要特点如下：可以更换界面(Skins)，软件更漂亮。由于对系统缓存的最佳利用，软件的浏览速度比 IE 要快。魔装网神占用的内存比其他全副武装的软件要少得多。魔装网神平均每开 15 页占用 1%系统资源，而一个 IE 就 4%。能设置 255 个主页地址，方便打开你最常用的网页。一些网站在状态栏有字幕滚动效果，阻碍了用户观察当前网页读取状况、链接地址，现在你可以关闭掉这种效果。加入了黑名单功能，可以过滤掉指定的广告或不喜欢的网址。   
  
破解工具：SmartCheck 6.03   
开刀对象：魔装网神(NetMyth) 2001 V3.5 （目前最新版）   
  
    运行“魔装网神”，点击注册按钮，输入用户名：zhuliang 注册码：987654321 点击确定，然后魔装网神要求重启验证，那我们就先关闭退出。   
    启动 SmartCheck 载入 NetMyth.exe 后必须按要求配置好 SmartCheck（在载入 NetMyth.exe 过程中若出现英文提示，打上对勾，不显示 pcode(有时不出现)），然后点击 Start 按钮运行 NetMyth.exe，过了较长一段时间之后，出现魔装网神界面完全时，点击 End 按钮暂停 SmartCheck。   
  
    首先在 SmartCheck 左边的窗口找到“＋\_Load”字样，它实际上是程序启动的过程，点击它，然后按 Ctrl+F 键，输入 HEX，找到如下这么一段内容（注：如果在＋\_load 下连续两次查找 HEX，可直接来到 10 进制形式注册码出现处）：   
  
  
－\_load   
    ....   
    ....   
    Hex      ---------->（在＋\_load 下第一次找到的 Hex，经分析不是注册码出现处）   
    UCase   
    UCase   
    UCase   
    UCase   
    ....   
    ....   
    Left$   
    Right$   
    Left$   
    Right$   
    Left$   
    Right$   
    ....   
    ....   
    UCase   
    UCase   
    UCase   
    UCase   
    UCase   
    ....   
    ....   
    UCase   
    Hex    ----------------->（10 进制形式注册码出现处）   
          分析：   
                此处“HEX”在 SmartCheck 右边窗口中的内容如下：   
                - string (variant)   
                    - signed long \* .plVal = 0069F678   
                      Long = 37746866 0x023FF8B2 这就是我们要的注册码   
                          --------   
    Left   
    Right   
    Left   
    Right   
    Space$   
    Dir   
    Dir   
    Dir   
    GetAttr returns LONG:16   
    ....   
    ....   
  
    在上述关键“HEX”上方有一连串的“UCase”，自己点击看看吧，是黑名单出现处，包括您的注册用户名在内。   
  
将注册码 37746866 以 10 进制转换成 16 进制形式以便注册：得到 23FF8B2    
  
整理一下，得到我的正版注册码为：   
用户名：zhuliang   
注册码：23FF8B2   
  
注意：上述内容在破解过程中，您的 Hex 等窗口处的显示内容会稍稍有所不同，不过不影响破解交流的。
