好了开始吧：   
  
1、首先启动 smartcheck，然后打开“彩票王”，等载入完毕后，点 smartcheck 工具按钮中的开始按钮（小绿色的三角号，和你家的 DVD 播放按钮一样形状），一直等程序执行完毕，自己按照平时使用这个软件的样子输入注册码，当然是假的了。

注册码：AAAAA-BBBBB-CCCCC-DDDDD   
  
二、点击确定按钮出现“注册错误”的对话框。   
  
三、千万别关闭“彩票王”软件，返回到 smartcheck 程序，对看到的一系列对话小栏仔细看，这里你把那些小“＋”号打开，会发现里面好多东西，其中有好多的是对你输入的信息的记录和比较，在其进行了一系列的记录比较运算后，你会找到你的注册码的，位置就是在：   
\- Thread 0 \[thread id:4294725351 (0xFFFc4EE7)\]   
  Event reporting started:01-04-17 10:20:03   
  GetSetting   
  Date   
  Yeah   
  Integer(3)->String("3")   
\+ \_Load   
\+ \_Resize   
  \_Activate   
  \_Activate   
  \_Activate   
  \_Click   
\+ \_Click  ---------->把这个展开   
  \_Activate   
+  \_Resize   
  \_Time   
  
四、展开以后直接到最下面的倒数第二个\_Click，展开这个\_Click   
  
五、然后在找这个\_Click 下面的倒数第三的 Mid（注册码和个数）和第二个 Left（注册码的形式注意别要最后的"-"）,注意看 smartcheck 窗口的右边，你就看到了你的注册码！！！！注意形式。   
  
我的是：NBAG6-83969-2587R-1BE$O
