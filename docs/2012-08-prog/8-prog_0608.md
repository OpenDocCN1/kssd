
# 发个驱动开发 VC 工程建立小工具(源码)

> 原文：[`www.pediy.com/kssd/pediy12/133642.html`](https://www.pediy.com/kssd/pediy12/133642.html)

1. 这是个没技术含量的小玩儿， 方便而已。

2. 这个是升级版本， 修改了 `Demo` 文件的一个 bug， 增加 `X64` 的编译环境。

3. 用这个工具， 可以方便大家快速新建一个 `Demo` 的 `DDK` 驱动开发工程开发驱动程序。

4. 用这个工具， 也可以方便的编译其他的一些模块， 例如 `Winnt` 代码的 `ntfs` 或者 `nt` 的 `Cdfs` 等等。
