

# Linux 内核漏洞调试环境搭建

> 原文：[`www.pediy.com/kssd/pediy12/136828.html`](https://www.pediy.com/kssd/pediy12/136828.html)

本人 Linux 初学者,只是想感受一下 Linux 内核某些漏洞在 exploit 时用到的奇技淫巧便于一周之前开始折腾搭建一个 Linux 内核漏洞调试环境。历尽千辛万苦总算成功,收获颇丰,但不敢独享,放出来与兄弟们共享。![](img/f3773294bf3a914c9a8c0c242528a003.jpg "使眼色")如果文中有不专业的地方,恳请大家指正!![](img/906f120cfe711ccbc8463fd6eb86eee9.jpg "尴尬")  
  
修正：  
这两天又查了些资料，发现 2.6.35 版本之后的 Linux 内核中已经内置了对 KGDB 以及 KDB 的支持。使用 KDB 无须再打补丁了，关于在=>2.6.35 版本的内核中如何使用 KDB 参见  
http://kernel.org/pub/linux/kernel/people/jwessel/kdb/
