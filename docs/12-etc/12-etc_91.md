

# 移动恶意代码威胁及防范

> 原文：[`www.pediy.com/kssd/pediy10/93437.html`](https://www.pediy.com/kssd/pediy10/93437.html)

这是 Mcafee 反病毒实验室的研究人员写的一篇英语文章，主要针对 Windows Mobile 平台。  
  
本文介绍了 WM 平台上一些常见的威胁和攻击手段及其防御方法。这些威胁和攻击对于其他平台如 Symbian、IPhone 等都是可以实现的。  
  
这篇文章是上周末翻译的，今天校对之后发到论坛上，希望对移动平台的开发者、安全研究者有一定的参考意义。![](img/c72cb8eba397ac67dda6e1ac58a9b627.jpg "微笑")
