## 【详细过程】

1、安装 RIM 开发软件中的模拟器，我是安装了完整的 JDE 4.7 和模拟器的，其实只需要模拟器就行了；并准备好 OllyICE 这个调试工具（google 就行）；

2、找到你的模拟器所在位置，并修改其中的一个批处理文件，通常在这里：

`C:\Program Files\Research In Motion\BlackBerry JDE 4.7.0\simulator`

也有可能在这里：

`C:\Program Files\Research In Motion\BlackBerry Smartphone Simulators 4.7.0\4.7.0.65 (9500-Vodafone)`

由于我装了 JDE（自带模拟器），又单独装了一个模拟器，所以上面两个地址都有的，我选择上面一个模拟器进行破解工作。

在上述目录中，找到 `*.bat` 文件：

例如第一个目录中是这样的：`defaultSimulator.bat`、`9500.bat`、`9530.bat`（有 3 个）

而第二个目录中是这样的：`9500-Vodafone.bat`（只有 1 个）

你可以挑一个进行修改，例如我们修改 `9530.bat` 吧：

代码:
```
@echo off 
fledge.exe /app=Jvm.dll /handheld=9530 /session=9530 /app-param=DisableRegistration /app-param=JvmAlxConfigFile:9530.xml /data-port=0x4d44 /data-port=0x4d4e /pin=0x2100000A 
```

把最后这个 `/pin=0x******` 里面的 `******` 改成你自己的 BB 的 PIN 码，然后保存。

如何知道你自己的 PIN 码，不用多说了吧，机器的 Options-Status 里面就有。

3、保存好 `.bat` 文件之后，记得看看所在目录，如果你之前启动过模拟器，这个目录中会有些文件需要删除，你可以通过查看文件最后修改时间的方式，来决定删掉哪些文件，因为我开发 BB 程序的时候，它会生成这些缓存等文件，所以我把这些文件剪切到其他地方去了（这样即使弄错了还能挪回来，如果直接删掉可能就不容易恢复了）：

![](img/d4224246295c272cb8bce05781bc5d12.jpg)

（在每次破解前，我都挪走这些已经选择的文件）

4、挪走上述文件之后，就可以点击运行 `9530.bat` 文件了，这时候它会运行模拟器：

模拟器运行起来之后，是这样的：

![](img/6d7928d1905a7c6dd5f299cc2346b4f4.jpg)

5、点击菜单 `File-Load Java Program...`，选择 BerryWeather 1.5.35 的那个 `cod` 文件，这样，模拟器里就有 BerryWeather 1.5.35 了：

![](img/0cad6d316e39f3f96e5c8e58582a1943.jpg)

6、运行 BerryWeather 1.5.35，它会提示你注册：

![](img/1b35da992aca6b2c52876a15495003ca.jpg)

7、随便输入一个注册码（不要用 123456 这样的！因为这个在内存里会重复出现，要输个不容易重复的，比如我输入 335577）：

![](img/1bf8ca0d3c9650f6f847cd832194f5f8.jpg)

8、输好之后，按向下的箭头或回车，点一下 `Register` 按钮，程序会报错，说这个注册码不正确（废话，当然不正确）：

![](img/e90a9ea021a243ff0842169d594051cb.jpg)

9、这时候就可以打开我们的 OllyICE 调试工具了，打开之后，点菜单：`文件-附加`，然后选择 `fledge` 这个进程：

![](img/e4a187ceccd6ced3bfce14befa43c778.jpg)

10、确定之后，这个进程就被附加进来供我们调试了，然后按一下 `Alt+M`，调出 `Memory Map` 窗口（把它放在最前面，或者把 CPU 窗口关闭也行），好了，再按一下 `Ctrl+B`，调出查找二进制数值的窗口：

![](img/c1b03a7471abb8d4e3195dc80988d8bb.jpg)

在 ASCII 栏，输入刚才我们随便输的那个错误注册码 335577，然后确定。

11、找啊找，终于找到了：

![](img/a3c31209909ea237844efc547f266943.jpg)

看到我们的 335577 了吧，继续往下翻，就能看到你的 PIN 码了（例如我的 3053XXXX），继续往下翻，仔细看有没有 6 个数字这样的很像注册码一样的东西……

12、哈哈哈，终于找到啦：

![](img/1033f15cc7836dfc0c09dda259b91ea4.jpg)

看到了吗，229661，哈哈哈！把它记下来，到自己的 BB 上去注册 BerryWeather 吧！（2.0 以上版本不行，要 1.6.XX 以下的都行）

![](img/66dc8fa70f4c1a9952d61cdd01a4f822.jpg)
