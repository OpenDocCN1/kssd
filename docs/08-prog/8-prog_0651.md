
# 虚拟串口驱动

> 原文：[`www.pediy.com/kssd/pediy10/78927.html`](https://www.pediy.com/kssd/pediy10/78927.html)

采用注册表枚举系统当前可用的串口，使用一个没有使用的注册表项供使用。

用`inf`安装后可以用串口工具进行读写。

大家可以自己根据需要取消读写串口的互斥设置。

缺陷：
1. 符号链接保存到设备扩展时有问题，导致删除设备时不能删除符号连接。
2. 删除设备后，注册表有残留，可以手动删除。
