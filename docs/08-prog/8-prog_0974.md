
# 窗口及托盘自动隐藏显示(源码)

> 原文：[`www.pediy.com/kssd/pediy12/130751.html`](https://www.pediy.com/kssd/pediy12/130751.html)

给学习汇编的新人朋友发一款用汇编写的用来管理窗口和托盘的工具的的源代码，此款工具使用了列表视图、滑动条、列表框等系统控件，希望对新入门的新人有所帮助。

代码工程采用`RadASM`工程文件，希望高手不要拍砖......
