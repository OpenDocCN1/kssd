(1)反反跟踪  
该软件用了反跟踪代码，这种反跟踪原理和“亿虎 Email 邮差”如出一辙：  
通过判断两次时间差，如发现有两次时间差超过 N 秒，则报错，程序退出。  
（弹出消息框"The Application security is compromised. Quiting now"）
