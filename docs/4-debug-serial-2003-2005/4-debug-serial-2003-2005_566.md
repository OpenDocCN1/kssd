### 注册码字符处理过程,C 语言版
```c
注册码字符数组=string1[x]

int i=0;
int ESI=0;
int ECX=0;

char string2[x]=strpur(string1);   /*将 string1[x]的字母全转化为大写,并存入
                                     string2[x]中*/

for(i=0;i<=strlen(string2);i++)
 {   if('0'<=string2[i]<='9')
      {ESI=string[i]+ECX*35-30;}
    else if('A'<=string2[i]<='N')
          {ESI=string[i]+ECX*35-37;}
           else if('O'<string2[i]<='Z')
                   {ESI=string[i]+ECX*35-37-1;}
 }
```

从上面分析可知：

如果要算注册码，第一我们要知道 `sn1(ds:01449290)` 的值。

第二就是用它对 `35` 求余，就可以得到 `d` 的值了，再求余可以得到 `c` 了，如此类推，就可以求出注册码来了。如果求出来的余数大于 `9`，从程式中可知，它是这样处理的，它把 `10` 用 `A` 来代替，`11` 为 `B`……但有一点要注意，就是当余数大于 `24`(字符 `O`)时，那么对应的字母就要向后移一个了，如余数为 `25`，那么正确的字母应为 `26` 所对应的字母了。
