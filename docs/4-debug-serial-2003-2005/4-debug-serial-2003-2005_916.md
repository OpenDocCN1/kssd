1)破解总结:  
1>注册码和机器码位数是大概相对的,(除非遇上比较大的数).  
2>注册码利用了循环每位机器码的计算方式！  
  
2)破解推算:   (我的机器码是:0383FBFF)  
         
                   计算过程(先取每位机器码)  
第 1 位                30 xor (0 shr 8)   = 30(0)      
第 2 位          33 xor ((31\*2+3) shr 8)  = 33(3)  
第 3 位          38 xor ((98\*2+3) shr 8)  = 39(9)  
第 4 位          33 xor ((16C\*2+3) shr 8) = 31(1)  
第 5 位          46 xor ((30C\*2+3) shr 8) = 40(@)  
第 6 位          42 xor ((65B\*2+3) shr 8) = 4E(N)  
第 7 位          46 xor ((D07\*2+3) shr 8) = 5C(\\)  
第 8 位          46 xor ((1A6D\*2+3) shr 8)= 72(r)  
  
总结：我的注册码就是: 0391@N\\r

Public CF As Boolean  '定义 CF 标志位  
  
Public Function SHR(iShr As Long, n As Integer) As Long 'SHR 逻辑移位函数  
  Dim i As Integer  
  For i = 1 To n - 1  
    iShr = iShr \\ 2  
  Next i  
  CF = iShr And 1  
  SHR = iShr \\ 2  
End Function
