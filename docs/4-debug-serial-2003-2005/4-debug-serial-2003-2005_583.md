既然“导入编辑标题时进行数量统计，如你没注册，则统计到数量为 16 时就弹出提示”，即有会使用 Messageboxa 对话框函数：有了 OD，又岂用在这函数下断，用 OD 载入主程序或 Attach 它，导入标题，使其弹出提示对话框，然后在 OD 里暂停并在当前指令下断点，回主程序点“确定”，会提示 OD 拦截成功，点 return 按钮或“Ctrl+F9”，按一下 F8，是否返回了主程序领空？爽吗？那么你会想到判断的地方多数在附近吧，于是你就要向上翻找找 Cmp register，(fh，10h）+Jmp 类的指令了，怀疑的就断来看看改改的^\_^
