很容易可以发现,注册码是 EAX=ESI+00023F3A,而 ESI 是序列号前前六位,后者好像是一个固定的值.  
  
接下来把 EAX 转换成十进制就是我们需要输入的注册码.  
  
注册机:(这里要谢谢小虾的帮助^\_^)   
Dim x, z, a, b, m As String  
Private Sub Command1\_Click()  
x = Text1.Text  
If x = "" Then  
MsgBox "请输入序列号^\_^", 64, "注意"  
Else  
a = "23f3a"  
z = Mid(x, 1, 6)  
m = Format("&h" + z)  
b = Format("&h" + a)  
y = Val(m) + Val(b)  
Text2.Text = y  
End If  
End Sub  
（此注册机支持最新的星空电影院 V2.06^\_^）
