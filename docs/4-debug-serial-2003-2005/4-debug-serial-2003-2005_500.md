### ◆ 算法总结 ◆

以机器码 `NDFK-NIUY-UWTC-ZOTW-EI16` 为例，我们来总结一下算法。为了简化过程，只对其中的第一位进行详细算法分析，其它同理。固定字符串 `M` 为 `‘1z1h+2a0n-0g8y*9a1n|’`。

机器码的第一位字符为 `N`，其 `$` 为 `$4E`。因此，算法过程是：

```
M1= $4E MOR $31(‘1’) = 7F

M2= $7F * 2⁵ = $18CE

M3= $18CE - $7F = $184F

M4= $184F * 4 + $7F = $61BB

M5= $61BB * 2⁵ = $131686

M6= $131686 + $7F = $131705

M7= $131705 * 2 = $262E0A

M8= $262E0A MOD $1A = $12

M9= $12 +$41 = $53=========>Asc(M9)="S"，这就是正确的注册码的第一位了。以下同理，可以得出其它的正确注册码。
```
