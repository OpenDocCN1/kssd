过程说明：经分析该软件生成的注册码不是由机器码运算得来的，而是由本机 C 盘的卷号运算得来的。  
  
00810B28 处 eax=2BA9777B 是由 C 盘的卷号初步运算得到的，00810B2E 处的 call 是把这个值经过一系列运算  
  
生成的扰乱码"d1e6d708c38023"，而这个码在 00810B3F 处的计算注册码 call 中又被逆运算回相应的值，  
  
因此中间的分析过程略掉，只具体分析计算注册码 call 的内容。
