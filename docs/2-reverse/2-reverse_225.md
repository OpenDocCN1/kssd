
# ADPlus 联机手册

> 原文：[`www.pediy.com/kssd/pediy12/116095.html`](https://www.pediy.com/kssd/pediy12/116095.html)

`ADPlus`是`Debugging Tools for Windows`中的一个工具，用于生成内存转储文件，比`Dr. Watson`要强。上传的附件翻译自`Debugging Tools for Windows`联机手册。本来看雪主要是针对破解的。不过调试与破解还是有一定相关性，论坛上也许有人用得着。翻译得不好的地方欢迎批评，别骂我就行。顺便说一句，这个`chm`是我用自己爆破的`doc2chm 2.5`制作的。另外，偶然看到`www.dbgtech.net`上翻译了`Debugging Tools for Windows`联机手册的主体部分，但不知该网站是否以后坚持下去，把这个联机手册翻译完毕。
