

# Windows 调试工具入门-6(WinDbg 内核调试常用命令 2)

> 原文：[`www.pediy.com/kssd/pediy10/80235.html`](https://www.pediy.com/kssd/pediy10/80235.html)

本篇继续介绍 WinDbg 内核调试常用命令：  
  
一、内存相关  
    !address  
    !vm  
    !memusage  
    !pte  
    !pfn  
    !db 和!eb  
    !pool  
    !poolused  
    !poolfind  
二、对象相关  
    !handle  
    !object  
三、驱动设备相关  
    !drvobj  
    !devobj  
四、蓝屏 Dump 相关  
    !analyze -v
