
# TRW 抓图的方法

> 原文：[`www.pediy.com/kssd/pediy03/forum1195.htm`](https://www.pediy.com/kssd/pediy03/forum1195.htm)

还记得 `ver blue` 命令吗?当然是改变字体和背景颜色的.就是 `Ver` 命令包含机关,

`Ver keep` 试试,就是保持屏幕,任你抓!不过只能抓 `system` 代码屏幕,如果要抓运行的,就要

作一点处理, 调试程序时,如果向后继续运行有输出(E.g.跳出出错对话框),就会破坏屏幕显示,所以只好 `A *****:****** jmp eip` 使程序中止以免破坏屏幕,这时再抓图吗,明白了? 注意 `trw` 版本,我的是 1.22,其他版本没有测试. 

补充,如果不是非常快地跳出对话框等,也可以输入 `ver keep` 命令,一只手马上回车,另一只手按按 `print screen` 键,不过要手足够快,如果是星际高手,将很有帮助,否则看来只能按上述方法了
