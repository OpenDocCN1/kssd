运行 `旋转矩阵` `TRW`

输入 `C` 位注册码：`123456789123`

按 `CTRL+N` 激活 `TRW`

`G` 继续执行程序

`PMODULE` 来到 `矩阵` `天空` `TMMIME!CODE`

按 `F10` 跟踪到以下地址 ----->

