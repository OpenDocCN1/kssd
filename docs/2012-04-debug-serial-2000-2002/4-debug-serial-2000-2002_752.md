
# 有声有色 7.0

> 原文：[`www.pediy.com/kssd/pediy03/forum1159.htm`](https://www.pediy.com/kssd/pediy03/forum1159.htm)

有声有色 7.0 正式版破解实录（取注册码）
第一部分：取序列号； 第二部分：取注册码

由监视注册表可知，这个软件读取本机的 `BIOS` 初始时间，经过转换作序列号！

如:`123456` 转换为 `21/43/65` 等，故如把本机的 `boos` 时间改为 `0000000` 或 `111111` 等，即任意可作序列号！具体在：以下：

`[HKEY_LOCAL_MACHINE\Enum\Root\*PNP0C01\0000]`
`"BIOSVersion"="Award Modular BIOS v6.00PG"`
`"BIOSDate"="10/13/99"`

记住这个格式：

## 一、用 `TRW` 导入 `ConteZone.exe`，设置断点：`bpx hmemcopy`

输入序列号：`12345678` 用户名：`hongjian` 注册码：`7878787878`
