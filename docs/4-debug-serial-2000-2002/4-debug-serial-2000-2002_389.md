

# Macromedia Flash 3

 一次破解 Macromedia Flash 3 的奇怪经历   
  
    因为我的妹妹想学 Flash，我只有 Flash 5，而教程是 For Flash 3 的，学起来很不方便，于是我便下载了一个 Flash 3，安装成功。但是当我启动时，出现烦人的 NAG 窗口，提示 30 天试用期，讨厌！我记得以前看过一篇破解 Flash 3 的方法，于是我就在自己的资料库里找啊找啊，但是最终也没有找到，于是我打算自己动手破解。   
    首先，按 Buy Now 按钮，填写信息如下：   
    First Name:Headlines  Last Name:Infoboy   
    Company:Bisp   
    Address:Beijing China   
    City:Beijing          State:Null          Zip Code:100084   
    Country:China   
    Phone:N/A              Fax:N/A   
    E-mail:Infoboy@chinaren.com   
    然后，按下一步。   
    接着，如果你不购买其它产品的话，按下一步。   
    然后，填写信用卡信息如下：   
    Card Number:66666666666666666666（必须 20 位）   
    Expiration (Month/Year)12/20/2000（应该可以改成别的）   
    Name on card:Infoboy（就是我啦！）   
    Payment Type 选择 Visa   
    按下一步。   
    填写一些意见和反馈，呵呵。。。我填的是：shit!!!~~~ 按下一步。   
    按下一步。   
    下面是选择通讯方式，我家里无法上网啦，所以选择 Phone，按下一步。   
    接着提示输入 Unlock Code，ctrl+d，具体的我就不说了，其实我也没心情仔细分析，大约找到两个好象是 Code 的东东，一个是 0019849934，一个是 XFVRCIKRKG，先试第一个，不对，再试第二个，正确！   
    接着要求输入注册码，呵呵。。。填上 0019849934，正确，然后好象是提示打印什么，我没有理会，关闭，重新启动 Flash 3。   
    接着又要求输入一些信息，我输入了：   
    First Name:Infoboy   
    Company:Bisp   
    Product Code:FLW30-03143-77238-80660（是 5.0 的）   
    提示输入错误！：（   
    我调试了一会，就不想调了，我突然想到上面提示的打印什么东西，于是我打算重装 Flash 3，看看到底要打印什么。   
    重装之后，出现一个拷贝文件的对话框，完成之后，我重新启动 Flash 3，打算从头再来一遍，谁知道竟然没有提示窗口了，真是奇怪，呵呵。。。   
  
    注：我是在家里遇到这种情况的，但是今天在公司再试时，发现不行了，当我输入 XFVRCIKRKG 时提示出错，我有没有安装 Softice，而且我的操作系统是 Windows 2000，所以后面的步骤是我回忆着写的。我想出错的原因可能有这么几种，一是前面的信息填错了，和昨天填的不一样，所以 Unlock Code 错了；也可能是 Unlock Code 在每台机器上都是不一样的，所以以前的注册码已经不适应了。另外，我的机器上同时安装了 Flash 3 和 Flash 5，其中 Flash 5 已破解，但是并不在同一个目录里，不过我想大约也有些原因吧！   4dd466d0e1e0cc123afbe504da2462ca
