
# system mechanic3.5

> 原文：[`www.pediy.com/kssd/pediy03/forum594.htm`](https://www.pediy.com/kssd/pediy03/forum594.htm)

**system mechanic3.5g 破解注册手记**

*   **作者**：孙锋
*   **Email**：`sffs@263.net`
*   **主页**：`http://sffs.6to23.com`

1.  启动 `trw2000`
2.  随便输入注册信息
    *   Name: `sunfeng`
    *   SerialNumber: `1234567890`
3.  `Ctrl+N`
4.  下 `bpx hmemcpy`
5.  `F5` 返回程式空间
6.  点击 `OK`
7.  拦截到 `bd *`，`F12` 14 次
8.  `F10` 到第一个 `call`
    ```asm
    0167:004a8a7e call 004228d0 ; F8 进入
    ```
    `F10` 到如下位置：
    ```asm
    0167:004a8af0 move eax,[ebx+01e8] ; d eax ===18521-ST659-4717865626
    0167:004a8B30 move eax,[ebx+01e8] ; d eax ===17921-PR065-0877471786
    0167:004a8B70 move eax,[ebx+01e8] ; d eax ===19022-ND154-9666360675
    ```
9.  有注册表操作。
10. 得到 3 组注册码
    *   Name : `sunfeng`
    *   SerialNumber: `1234567890`
    *   在 `0167:004a8aed move eax,[ebx+01e8] ; d eax ===65655-ST550-1786561405` 处：
        ```asm
        0167:004a8aed move eax,[ebx+01e8] ; d eax ===65655-ST550-1786561405
                                                   70706-ND055-6636066455
        ```
    *   在 `0167:004a8B30 move eax,[ebx+01e8] ; d eax ===59595-PR014-7747175344` 处：
        ```asm
        0167:004a8B30 move eax,[ebx+01e8] ; d eax ===59595-PR014-7747175344
        ```

**自我审查与调整：**
1.  **Step 2 & 10 中的 Name/SerialNumber**：原文中 `sunfeng` 和 `1234567890` 是输入值。规则提到“变量名”。在这里它们更像是字符串数据。但在评论部分，`sunfeng` 和注册码被提及。为了符合“代码元素加反引号”的精神，且避免过度使用，我会给 `sunfeng` 和具体的注册码字符串加反引号，因为它们在这一上下文中是特定的标识符/数据点，类似于 `xxx.json`。
2.  **Step 8 & 10 的代码块**：原中文本中，汇编指令是混在行内的。根据规则“代码块前后加上三个反引号”，对于多行的汇编逻辑，应该使用代码块。对于单行指示（如 step 8 第一行），可以放在代码块中或行内。为了清晰，我将汇编指令行放入 `asm` 代码块中。
3.  **Step 10 的格式**：原文中 step 10 的文字描述比较乱。
    *   `Name : sunfeng`
    *   `SrialNumber: 1234567890`
    *   `在 0167:004a8aed ...`
    *   `0167:004a8B30 ...`
    我会将其整理为有序的子项或描述。
4.  **反引号细节**：
    *   `move` 是汇编指令，需加反引号吗？如果在代码块里，不需要。如果在文本里，需要。
    *   `eax`, `ebx`, `[ebx+01e8]` 是寄存器和内存表达式，在代码块里不需要，在文本里需要。
    *   我决定将汇编行全部放入代码块，因此代码块内部不需要加单反引号。
    *   文本中提到的单独操作，如 `F10`, `F12`, `bpx`, `hmemcpy` 需要加。
5.  **评论部分**：`sunfeng` 和注册码在评论中被引用，加上反引号以示区分。
