

# voptme

> 原文：[`www.pediy.com/kssd/pediy03/forum1067.htm`](https://www.pediy.com/kssd/pediy03/forum1067.htm)

用了 sharelock 加密，里面只有一个单向 hash，很简单。但是有个问题，在一台机器上可以注册成功，但是到了另外一台机器无论如何也不成了。   
  
能注册的机器是英文的，不能注册的是中文的。   
  
即使能注册，也还有问题。   
  
voptme 的注册号分成两部分，第一部分是 sharelock 标准的注册流程，第二部分是 voptme 自己定义的，但是找不到它在什么地方检查第二部分的 key。   
  
如果第二个 key 不对，在整理硬盘的时候就会有 internal error。
