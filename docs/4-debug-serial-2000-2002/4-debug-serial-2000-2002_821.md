运行 Hex Mines for Windows (32 bit) Version 4.01，等待漫长而又短暂的   
5 秒钟，点击“Register Now...“按钮，进入注册提示窗口，填写：   
User Name:tongxinshiwo  Registration Code:780822    
按 Ctrl＋N 激活 TRW，   
输入  bpx hmemcpy  ←…… 下断点   
输入  g            ←…… 继续运行   
返回注册窗口，点击 OK   
又返回 TRW，你会在屏幕下方看到：   
Break on BP1      ←…… 拦截成功   
输入  bc \*        ←…… 清除断点   
输入  pmodule      ←…… 等于按 F12 若干次   
这时，在屏幕中间你能看到绿色的那一行：   
015F:00429765  MOV    ESI,EAX   
按 F10（好长时间的，注意不要按过了。）向下走到   
015F:00401FB2  MOV    ESI,EAX   
输入  d eax        ←…… 察看注册码   
在屏幕右上方 PROT32 下面会有一个 7 位数字的真注册码和刚刚输入的假注册码，   
赶快记下来吧！我的是：6466732。   
6466732            ←……真注册码   
780822            ←……假注册码   
  
按 F5 返回，会提示“Invalid registration code!”，点击“确定”按钮，   
再点击“Register Now...“按钮，进入注册窗口，重新输入 User Name 和   
Registration Code，你就可以看到“Thank you for you registering!”。   
怎么样，高兴不？   
  
User Name:            tongxinshiwo   
Registration Code:    6466732   
  
注册后在默认的安装目录（HexMines4）下，文件 hex.ini 会存有注册信息   
hex.ini   
\[REGISTRATION\]   
NAME=tongxinshiwo   
CODE=6466732   
将它删除，即又为未注册版 。
