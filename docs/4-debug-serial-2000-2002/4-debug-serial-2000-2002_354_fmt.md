## 标题

只要你输入的 `RegCode` 是 12 个字符，它就会将你的注册资料写入 `hypermaker.ini` 中，所以你应该知道如何下断点了吧！那就是 `bpx GetPrivateProfileStringA`

## 内容

1. 如果用户输入的名字少于 3 个字符则重新输入。
2. 如果用户输入的名字少于 12 个字符则用空格凑齐 12 个字符。
3. 用串 `"123"` 加在 `ID#` 的后面，凑成 12 个字符。
4. 将第 2 步的 12 个字符和第 3 步的 12 个字符逐一异或，得到 12 个字节。
5. 对于得到的 12 个字节中的每个字节，进行下面的转换。转换的结果就是注册码。

转换非常简单，就是 12 个字节逐一和一张表中的 12 个字节相加，如果和不是大写字母，就通过不断加 `0x19` 或减 `0x19` 的方法使其变成大写字母。

```c
#include <stdio.h>   

#include <string.h>   

void main(void)   

{   

    char            Name[64];   

    char            ID[64];   

    unsigned long Table[12] = {9, 13, 7, 2, 12, 6, 20, 5, 5, 11, 18, 14};   

    unsigned long Key[12];   

    int             k, len;   

    do   

    {   

        printf("Input your name(at least 3 chars):");   

        gets(Name);   

        len = strlen(Name);   

    } while(len < 3);   

    do   

    {   

        printf("Input your ID#(XXXX-XXXX):");   

        gets(ID);   

    } while( (strlen(ID) != 9) || (ID[4] != '-'));   

    for(k = len; k < 12; k++)   

    {   

        Name[k] = 0x20;   

    }   

    strcat(ID, "123");   

    printf("Your registration key is: ");   

    for(k = 0; k < 12; k++)   

    {   

        Key[k] = (Name[k] ^ ID[k]) & 0xFF;   

        Key[k] += Table[k];   

        while(Key[k] > 'Z') Key[k] -= ('Z' - 'A');   

        while(Key[k] < 'A') Key[k] += ('Z' - 'A');   

        putchar(Key[k]);   

    }   

    putchar('\n');   

}
```
