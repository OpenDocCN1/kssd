### 破解音乐贺卡厂 4.04

**目标软件**：音乐贺卡厂 4.04 (`ecardiy`)

**软件作用**：傻瓜式多媒体贺卡制作工具，最后生成 `exe` 文件。

**注册费用**：18 元

**破解工具**：`TRW2000`

1. 我首先用 `FI` 发现它是用 `PECompact v.1.40-5` 加的壳，用 `ProcDump32` 脱了她，嘿嘿~~~~但是它好像有效验，一运行就有出错提示，而且反编译后也找不到字符串，只好跟踪了！

2. 运行 `TRW2000`，`ecardiy`

**软件序列号**：`1661197668` **注册名**：`DickieX` **注册码**：`78787878`

```
Ctrl+N 
bpx hmemcpy 
g
```

按注册框的确定，程序被拦截！

```
bc \* 
PMODULE 
```

来到 `ecardiy` 上空，发现这是用 VB 编的！

程序开始于：`00432365`。一次 `F12` 后出现错误提示，还是 `F10` 一步一步来！

……

```
0043243B CALL MSVBVM60!__vbaVarTsLt       //检查注册名不能少于 4 个字符
```

……

```
0043251F CALL MSVBVM60!__vbaVarTsGt       //检查注册名不能多于 30 个字符
```

……

```
004328D2 CALL MSVBVM60!__vbaStrCmp        //此时 d eax 看见 78787878,d ecx 看见正确的 ECD114888282!
```

……

```
00432946 CALL MSVBVM60!rtcMsgBox          //上面注册码不对,这里给出出错提示
```

……

### 3. 总结

**软件序列号**：`1661197668`

**注册名**：`DickieX` 或 **注册名**：`HeXi`

**注册码**：`ECD114888282` **注册码**：`ECD841268010`

注册成功后在程序所在目录下生成一个 `reguser.mcm` 文件，里面是注册名和注册码，删除后可重新注册。我不怎么懂 VB，所以没有去推它的算法！
