        Stealth Anonymizer 2.6   
        http://www.photono-software.de/Stealther/   
  
    该软件允许你掩饰身份访问、拦阻 cookie、观察、修改有关你的网络浏览器发出的私人信息。浏览访问时为每个页自动改变代理使之保证最大的安全。批量检查每个代理服务器其响应时间、验证其匿名性等。   
      它有三种浏览模式可选：直接连接，Stealth Mode, Super Stealth Mode。Super Stealth Mode，这种模式下用代理访问的进出数据全是加密，浏览器的代理首先要设置为 127.0.0.1:14000(或 localhost:14000) 。未注册不提代 Super Stealth Mode。注册方式：在线注册

工具：    FI   
    DEDE   
    TRW2000

首先运行该软件和 DEDE、TRW2000。由于该软件用 DELPHI4 编写，故可用 DEDE 方便地 DUMP 出来。看 DEDE 中 PROCETURES 栏，其中有 UnitName:u\_unlock    ClassName:Tfrm\_unlock 一项。这就是我们的目标。选中它，在右边框可以看到 Events:finished\_veri RVA:004928B8 Hint:0014 一项。双击它我们可以看到以下代码：   
  
00492905  E86A8EFFFF            call    0048B774   
0049290A  3C01                  cmp    al, $01   
0049290C  757F                  jnz    0049298D   
  
\* Possible String Reference to: "Unlock Key Verification Progress SU   
|                                CCESSFULL!"   
|   
  
看清楚的吗？！   
让我们来注册 Stealth Anonymizer 吧！选 File/Unlock Trial Version   
在其中随意填些字符，我填的是 B8B8B8B8B8B8B8B8B8B8B8B8B8B8B8B8   
用 TRW2000 设断点 BPX 0049290A，注册，中断，修改 al 为 01 即可。
