

# 智能五笔 v5.04

> 原文：[`www.pediy.com/kssd/pediy03/forum1086.htm`](https://www.pediy.com/kssd/pediy03/forum1086.htm)

智能五笔好用，这点相信大家没有异议。不过，智能五笔真是太~~~~~~贵了，而且它的注册条件也十分苛刻。这不就是逼着大家到处找破解吗？？下面的方法是   
小弟无意中发现的，供大家参考。但不能保证一定行，不过小弟的智能五笔运行到现在也还没有出现问题。   
1.先把智能五笔 5.03 的注册器解压到一个新文件夹(只要是空的都可以)。假设这个文件夹的名字为‘A’。打开智能五笔文件夹(chenhu2)，找到那个带有注册信息的文本文件(CHENHU4)并把它复制到 A 文件夹里。   
  
2.打开注册器，点击注册码，这时就会出现你的注册码并出现一个名为 chenyhzc.chu 的文件。用记事本打开这个文件看看，你会发现里面的号码和注册器里显现的注   
册码是一样的。但我发现，这个文件对智能五笔 5.04 的注册没有效果。原因就是这个文件里的号码，号码是正确的，但实际上在注册进去后是会发生变化的。比如说，在注册器中我的注册码显示为‘022197GJ’，但注册进去后却变成了‘.2297JG’。再用记事本打开 chenhu2 文件夹里的 chenyhzc.chu 文件看看，发现里的号码也是‘.2297JG’。比较一下就不难发现原注册码中‘0’变成了‘.’，‘1’消失了。这就说明，在 A 文件夹的那个 chenyhzc.chu 文件不是真正的注册文件，对解决智能五笔注册是没有作用的。   
  
3.现在要做的不是把 A 文件夹里的 chenyhzc.chu 这个文件复制到 chenhu2 文件夹中，而是打开智能五笔的用户注册，在注册框中输入你在注册器里看到的那个注册码，然后确定。再次打开智能五笔的用户注册框看看，你就会发现你刚才输入进去的注册码发生了改变。现在，智能五笔 5.04 的注册就大功告成了。   
  
以上的方法是小弟无意中发现的，而小弟用的是 5.04 版，不知道该方法对 5.03 有没有用，也不知道适不适合大家，只是供大家参考参考。还有，以上提及的注册码改变，在一般情况下，只要你注册器里显现的注册码是正确的话就都会发生改变。
