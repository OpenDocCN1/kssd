
# 超级魔法兔子设置

> 原文：[`www.pediy.com/kssd/pediy04/kanxue343.htm`](https://www.pediy.com/kssd/pediy04/kanxue343.htm)

**工具**：`softice`

**crack by**：`fwnl`

听说超级魔法兔子设置有内部版和共享版之分，内部版 3.97 可到自由鸟汉化找到，我看了半天也不知有什么不同。反正都可以注册成功就行，我就只要它这个功能，:)。

在网上找了好多超级兔子的注册码，可不是进了兔子的黑名单，如：`Sun Bird [CCG] Sn: CX-AYYABBPDOLG` （完全不能用），就是不完全注册码。如 `天若有情 sn:CXMSR-ZPZWTJWBCDZ` (可以注册，不过你怎么改都没反应)。即然大虾们都找出了注册码，我这菜鸟就自己碰碰运气，找一找。

开始我试过用兔子组件里的 `ms98.exe` 破。发现找到的注册码就是不能注册 `winspeed.exe` 组件，所以干脆就用 `winspeed.exe`。

首先在超级魔法兔子的目录下找到 `winspeed.exe` (我用的是超级兔子 4.0 中的 `winspeed.exe` 3.4)，打开会出来注册对话框，名字随便填，注册码我为了省事就按照正确注册码的形式 `CXMS-xxxxxxxxxx`（`CXMSR-` 是必需的，后面乱填 11 个字母），其它填法行不行，我没试过。点确定，然后点退出，因为兔子要在下一次起动时校验注册码。

`Ctrl+D` 呼出 `softice` （注意：要记得在 `winice.dat` 包含 VB5 的运行库，如没有，一定要添加）

下 `Bpx __vbaStrComp` ("`__`" 就是按下划线 2 下)，按 `F5` 返回，再点 `winspeed.exe`，程序立刻被中断后

下 `bc *`，这时按 `F10` 几下来到下面这里：( `******` 代表你在 `softice` 下看到的数字，因为每台机器看到的不相同，只好用 `******` 代替了)

```
        ******9f    PUSH EAX
        ******A0    PUSH DWORD PTR [EBP+0C]
        ******a3    PUSH DWORD PTR [EBP+10]
                CALL ******
                TEST EAX,EAX
```

然后下 `bpx ******9f do "d ecx"` （下中断时，不是 `bpx ******9f` 然后 `d ecx`，而是完整的）

(不下 `bpx ******9f`，一直按 `F10` 你会看到兔子在不断拿你的名字和黑名单比较。比到最后一个时 `d ecx` 就出真码)

然后要做的事就是狂按 `F5`。按十几下可看见黑名单，里面的名字是不是很眼熟，:)

```
                                   E.G.I.S........
                                   LI....HAO......
           SOFTICE 的内存窗口  ====>     ...S.W.N.E.T.C.
```

这时你可按 `Alt+PageDown` 往下看，看最后一个黑注册码是什么

`WINSPEED3.4` 版的看见的是 `JGMGRCTCWVK`

```
                                   J.G.M.G.R.C.T.C
                                   W.V.K.......5..
           SOFTICE 的内存窗口  ====>     ....6.......7..
                                   ....8.......9..
```

当你按 `F5` 几十下窗口出现 `JGMGRCTCWVK` 这个数据时，再按一下 `F5` 就可得正确的 11 位注码。

(如版本不同可能不是 `JGMGRCTCWVK`，反正就是最后一个黑名单就行)

(正确的注册码出现后，再按一下 `F5`，`softice` 的内存窗口这时就是空的啦，所以也可以记下按的次数找)

(最好用超级兔子 4.0 中的 `winspeed3.4` 来找，4.15 中的不行。找到的注册码所有版本都是可用的)

把得到的 11 位注册码加上前缀 `CXMS-`，就搞定收工了，再启动 `ms98.exe`，填上，所有的组件都应注册了。

功能我随便试了一下，好像能用，是不是所有的功能都能用，我就懒得试了，因为我只用它的右键菜单管理，和 IE 设置。

（个别低版本可能要填写 2 次才能注册）

我得到的注册码是：`fwnl` 注册码：`CXMS-TQFRGHICQYK`

注意：同样的名字可能每次得到的注册码都不一样，不过都能用。
