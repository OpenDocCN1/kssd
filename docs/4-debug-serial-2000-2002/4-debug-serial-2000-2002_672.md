

# 全功能数字时钟

> 原文：[`www.pediy.com/kssd/pediy04/kanxue205.htm`](https://www.pediy.com/kssd/pediy04/kanxue205.htm)

全功能数字时钟（http://www.csdn.net/soft/openfile.asp?kind=1&id=14184）：   
所有输入都支持复制.粘贴等功能，还提供电脑开机时间统计，只要打开【电脑开机时间】你就可以看到不断跳动的数字了啦，该数字以毫秒为基数单位，闹钟提示语可以是很长很长的语句(只要不超过 30000 字左右就可以了啦），全功能数字时钟她提供了标准时间的显示，还有公历年月日，以及星期等当然也包括农历的年月日还有农历属象，农历节气，和世界节假日提示，同时还提供了部分小点子，如果你把鼠标放到节假日提示框上面稍作停留，就可以看到不同的提示^\_^，还有阴阳历查询功能，只要选择好日期，下面就会显示出相应的农历年月日，当然如果正好是有节气的，那么还有节气提示。（好了，抄得我好累：））   
  
先下载安装，用 language 看一下，没有加壳，爽！再仔细一看，晕倒，VB 的！本来碰到这种程序我只能 uninstall,但看了一些 ollydbg 的教程，决定试一试！运行 Ollydbg,打开全功能数字时钟。exe，F9 运行！嗯！提示注册！靠！6 个大框框，来试试，返回 Ollydbg,查看--〉模块---〉选 MSVBVM60.DLL，再在左上框里点右键，选名称，然后在框里选中\_\_Vbastrcomp,按 F2 下断点，在框里填入，12345-23456-34567-45678-56789-12345678987654321，下一步！被 Ollydbg 断，返回！再右下角框里看到什么，一排 12345678987654321，下面是另外一排数字，记下！再按 F9,看到什么？呵呵~~出来 56789 的真注册码，按部就班，再按 4 下 F9,搞定另外四个框，关闭 Ollydbg！   
重新运行全功能数字时钟，填入注册码，我的是 WCL7R-XF457-74486-123Q5-WrGzs-55G3532434478915688!
