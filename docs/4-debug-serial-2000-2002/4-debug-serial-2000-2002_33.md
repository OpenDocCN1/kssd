

# ClapSE 3.0

> 原文：[`www.pediy.com/kssd/pediy01/forum043.htm`](https://www.pediy.com/kssd/pediy01/forum043.htm)

软件名称：ClapSE 3.0   
软件大小：2.16MB   
软件类型：共享 适用环境：Win9x/NT/2000   
软件介绍：    
用来抓取、管理和编辑图形文件和视频文件， 可以搜索、复制、剪贴，可以为图象舔加注释和声音，支持许多不同的视频设备   
和扫描设备，支持 BMP, DIB,WMF, PNG, AVI, GIF 和 JPG 等格式文件。   
  
设置断点 bpx hmemcpy   
程序被中断后,按 F12 若干次(出现错误画面次数-1)   
按 F10 若干次,可找到一比较指令,数据为十六进制格式
