

# 赝画鉴赏家 1.0

> 原文：[`www.pediy.com/kssd/pediy03/forum1006.htm`](https://www.pediy.com/kssd/pediy03/forum1006.htm)

游戏名称：赝画鉴赏家 1.0   
  
特色说明：   
  
1、找出两幅图不同处的桌面游戏，可随时暂停、退出，系统资源占用少；   
2、可选在不同图库中游戏，图库可随时扩充（更多图库请关注软件主页更新）；   
3、图中不同处并非每次都在同一地方，游戏更富挑战性。   
4、画面精简明快，操作简单。

Val returns double 3.17513e+008 \[displayed as single-precision floating point\]

(为什么会注意到这儿？因为后面有个这样的语句：Form\_nozhuce(Form)created )   
                                                  ^^^^^^^ 未注册？^-^   
  
选择 Show All Events 展开此滚动条，找 \_\_vbasrtcmp、\_\_vbafreestr、SysFreeString 这样的语句。   
  
功夫不负有心人，终于在这一条下的第九行，也就是第四个 SysFreeString 处找到了正确的注册码：Crack007-18733286411
