

# EmEditor v3.00 b3

 嗨！大家好，这是 EmEditor v3.00 b3 破解过程；   
  
让我们从这里开始吧……   
key1 是我们输入的第一串数字，我用 1000   
key2 是我们输入的第二串数字，我用 2000   
key3 是我们输入的第三串数字，我用 3000   
key4 是我们输入的第四串数字，我用 4000   
  
key1  key2  key3  key4   
  |      |      |      |   
1000 - 2000 - 3000 - 4000
