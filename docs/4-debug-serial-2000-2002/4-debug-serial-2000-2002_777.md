

# Do!Link

> 原文：[`www.pediy.com/kssd/pediy04/kanxue367.htm`](https://www.pediy.com/kssd/pediy04/kanxue367.htm)

你是不是经常要在一个网页里复制网址，然后把它粘贴到浏览器中打开   
  
？有了 Do!Link 这个软件,你就可以直接复制网址然后按右键→Do!Link   
就可以打开它了。软件挺管用的，可惜有时间限制，但没有输入注册码   
  
的地方，它安装后没有主程序，只是往 Windows 的 system 文件夹及注册   
  
表添加了一些东西，俺菜鸟不知到如何破，哪位大哥有空就把它解了，   
  
造福大家啊！
